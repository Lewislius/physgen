## 1. 本版结论：可以增加，但必须同时证明信息、执行与收益

建议将 D2 定义为：

> D 的连续过程生成与局部联合修正，加上进入实际生成路径的轻量条件过程推理分支 R，以及具有时空定位、可靠关系标签和实际输出梯度的 L_dep。

本版暂定五种生成器任务：

\[
\mathcal L_{D2}
=
\mathcal L_{\rm FM}
+\lambda_s\mathcal L_{\rm struct}
+\lambda_o\mathcal L_{\rm out}
+\lambda_a\mathcal L_{\rm align}
+\lambda_d\mathcal L_{\rm dep}.
\]

用户已允许超过四项；这里不为了凑数继续增加，也不把已有目标重新命名后算成新增贡献。

R 要回答“给定当前条件，后续可能如何响应”；L_dep 要监督“哪些前置变化与哪些后续响应存在有依据的依赖”。两者仍需通过 D 原有 A／B 接口影响实际视频，不能只生成解释或关系图。

“强”指监督对象比全局视频相似度更有针对性，不意味着它是严格物理求解器，也不意味着每个样本都满足硬因果保证。

### 1.1 不变的边界

| 项目 | D2 决定 |
|---|---|
| 固定语义 slot | 不使用 |
| 一种物理量对应一个 query | 不使用，包括质量、速度、接触、对象身份等逐项查询清单 |
| 连续过程表征 | 保留唯一 P；网格位置有时空坐标，通道不预设物理意义 |
| 局部修正 | 保留且仍是核心，不用高层推理替代接触、轮廓、原位置等细节处理 |
| 视频时间切段 | 不人为将接近／接触／响应分别生成；训练窗口不等于分段采样 |
| 推理筛选 | 不生成候选后选片，不因错重启，不使用 verifier 决定保留哪条视频 |
| Wan 计算 | 原生层只按顺序执行，不回早层或反复重放尾部 |
| 数据 | WISA／OpenVid，加从这些视频得到的可靠标注；不增加 x_err 配对库 |
| RAFT | 不采用 |
| 新模块数量 | 首先增加一种轻量推理调用方式和一种关系监督，不堆独立 LLM、图推理塔和物理参数头 |

## 2. D 已有什么，D2 真正补哪里

D 已有：

- 与视频联合去噪的 P；
- 实际路径的过程 FM；
- 同一 SharedCell 的历史条件预测训练视图；
- A 的过程写入、B 的实际响应读取与局部成组修正；
- L_out 和 L_align 对实际生成结果的监督。

所以，不能把“预测未来”“加一个因果名字”重新包装为 D2。

D2 需要证明的两个增量是：

1. **实际推理路径增量。**将原来主要作为训练视图的条件过程预测，显式用作当前采样中的过程提议，观察它是否帮助前期建立更正确的结构。
2. **监督信息增量。**加入独立于普通描述匹配的、有视频证据和空间时间定位的依赖标签，并监督真实输出是否呈现该依赖。

如果 R 只是把同一观察再算一遍，效果等价于普通模块加深，则不值得保留。如果 L_dep 的标签只由原 caption 换一种说法生成，没有新的依赖证据，就很可能与 L_align 冗余。

## 3. “增加推理模型”有三种含义，本版选择哪一种

| 方案 | 用途与限制 | D2 决定 |
|---|---|---|
| 大 VLM 离线整理标签 | 可以辅助提议作用、响应、时间范围和未知事实；仍需核验 | 可采用，数据准备成本单列 |
| 大 VLM 在线输出长计划／CoT | 具备语言先验，但文字如何稳定控制细粒度 P 仍需学习接口；也有延迟与幻觉风险 | 不作为首版默认 |
| 小型 latent 条件过程分支 | 与 P 同空间预测过程，可以直接进入 A／B；是否真有预测能力需监督和实验 | 首版主方案 |

[PhiZero](https://arxiv.org/html/2607.28624v1) 提供了“先推断状态转移、再渲染”的相关思路，但它依赖专门学习的转移编码与生成接口，不是将一段自由文本推理直接交给视频模型即可。

[Cosmos-Reason2](https://github.com/nvidia-cosmos/cosmos-reason2) 可作为离线语义标注候选；它的文字输出不直接充当连续 P、接触几何或精确力学量真值。

因此，本版所说的 R 是条件过程推理分支，不默认等于一个独立的数十亿参数语言模型。

## 4. R 的输入、输出与参数安排

### 4.1 输入：允许的条件和当前过程生成状态

\[
u_R=R_\theta(P_\sigma,C_{\rm obs},c,\sigma).
\]

其中：

- Pσ：当前联合采样中的唯一过程状态；
- Cobs：首帧或明确允许的历史视觉条件；
- c：动作意图／用户文本；
- σ：当前噪声水平。

首版优先复用已经存在的首帧／历史编码和小投影，不让稠密视频 teacher 因 R 的加入而自动进入每步推理。若使用原生 VAE 历史特征，必须先截取原始历史再编码，并核对时间感受野。

R 的受限预测调用不读取完整未来 GT，也不读取混入未来信息的所谓历史 H。正式首帧生成只给首帧，不因训练过历史视图就悄悄给测试模型额外帧。

### 4.2 输出：同一 P 空间中的过程速度提议

\[
\widehat P_{0,R}=P_\sigma-\sigma u_R.
\]

uR 是 P 的生成向量场估计，不是物理速度；P̂0,R 是当前对干净过程的估计，不是质量、力、加速度等参数清单。

R 不是先生成另一条视频，也不另外采样一套计划让评分器选择。P̂0,R 与 Pσ 是同一过程状态的两个视图，推理过程中只保留一份持久 P。

### 4.3 参数：优先复用，再验证是否需要分离

最小实现优先复用 D 中 SharedCell 的主体，增加必要的条件视图适配与调用方式。这样 D2-R 首先检验“受限条件预测进入实际路径”的价值，而不是引入另一套大网络。

共享参数有明确代价：训练 R 的调用会影响 A／B 使用的同一主体，不能声称冻结了一条调用路径就冻结了共享权重。

如果实测出现不可接受的任务冲突，可以单独测试小型独立 R 或小规模适配参数，但必须：

- 固定原 D 后再比较；
- 单列新增参数与训练成本；
- 与同容量普通 adapter 对照；
- 不直接升级为另一套完整物理 DiT。

### 4.4 条件预测不等于无条件确定未来

训练中的合法过程状态为：

\[
P_\sigma=(1-\sigma)T+\sigma\epsilon_P.
\]

σ<1 时它含加噪未来信息，因此 R 做的是条件过程去噪，不能称为完全不看未来的预测。需要从纯噪声端开始的完整预测测试，验证它是否真的利用前置条件。

首帧不足以确定初速度或隐藏材料参数时，应保留合法未来分布；不能用“推理”之名要求恢复某一个唯一 GT 未来。

## 5. 如何进入 D，而不破坏原来的计算合同

### 5.1 A：融合受限预测与当前生成证据

先计算 D 原有 A 的过程估计 uA,base，再融合 R：

\[
u_A^{D2}
=
u_{A,\rm base}
+\alpha(\sigma)\left(u_R-u_{A,\rm base}\right).
\]

A 的写入必须使用融合后的过程视图 P̂0,A＝Pσ−σuA，而不只是让新的 uA 进入日志或辅助损失。B 的关联核也读取这个实际过程条件。

α 首版采用有界、预先配置的渐进接入，初始为零；不是推理时根据“哪个候选更正确”择优。需要验证其 σ 范围和大小，不预设所有噪声处都应强用 R。

α=0 只有在其他输入、写入、参数与随机数路径都相同的情况下，才恢复原 D。新增 R 调用不得推进其他分支的随机数流或修改共享缓存。

### 5.2 B：仍根据实际观察修结构和细节

B 读取：

- A 写入后原生层产生的 H_B；
- 当前 Pσ 与融合后的干净过程估计；
- 原生细网格信息；
- D 的方向性时空关联位置。

B 继续输出：

\[
u_B=u_A^{D2}+\delta u_B,\qquad
H'_B=H_B+\Delta H_B.
\]

B 可以修接触前路径、交互边界、后续响应和原位置残留，不只是修纹理。原有 B 的增量接口与双零初始化合同保留；D2 不重新初始化已经有效的 B。

### 5.3 最小版不另存完整因果图

依赖信息首先通过受 L_dep 监督的连续过程预测进入 A 与 B 的关联核，不增加持久的事件节点表或关系图。

关系读出在首版用于训练和诊断，不必成为在线评分器。若以后测试将关系分数显式加入 K 的 attention bias，那是另一个可独立消融的增量，不在本版默认堆入。

这样可以先验证“过程表示学到依赖后，实际写入是否更有效”，避免同时改变推理、监督和一整套显式图结构。

### 5.4 因果方向不等于编辑方向

物理作用与响应具有时间方向，但修复可以双向修改视频时间轴。

例如修正“球已经飞走却没碰拍”，可能需要一起改接触前轨迹、接触瞬间和接触后响应。不能因为要学习因果，就把 B 的所有读写都硬限制为只看过去或只写未来。

### 5.5 一步仍只提交一次状态

A、R、B 的全部估计都基于本步同一个 Pσ，不在内部提前更新 Pσ。最后合并 CFG 后再同步推进 z 和 P。

条件／无条件分支分别执行其 R／A／B，隔离工作状态、条件和临时预测；不能让无条件分支复用条件分支的 uR。

## 6. D2 全流程示意

~~~text
首帧／允许的历史 + 文本 + 当前 Pσ
                  │
                  ▼
       R：受限条件过程预测
       得到 uR / 干净过程估计
                  │
当前 zσ → Wan 早层 → A 原有过程估计
                  │
          渐进融合 R 与当前证据
                  │
        A：写入当前早层特征
                  │
          原生中间层正常继续
                  │
        B：读取真实响应与细网格
                  │
        方向性关联取证／成组写回
        同步修结构、接触及局部细节
                  │
          剩余 Wan 层只执行一次
                  │
        原生视频速度 + 最终过程速度
                  │
       两 CFG 分支联合合成
                  │
       z / P 同步提交一次
                  │
          下一正常噪声步
                  │
          解码同一条视频
~~~

训练新增部分：

~~~text
WISA / OpenVid 真实视频
    ├─ 冻结稠密 teacher → T → 原有 L_struct
    └─ 可靠关系整理／核验 → 时空区域对与依赖标签
                              │
                      校准关系读出 Dψ
                              │ 冻结
         ┌────────────────────┴──────────────────┐
         ▼                                       ▼
实际使用的干净过程估计                      真实写入后的可读输出
         │                                       │
         └──── 同一个 L_dep 关系监督任务 ─────────┘
                    反传到过程与实际执行
~~~

没有重新生成分支，没有候选视频池，没有通过／不通过后重新采样的开关。

## 7. 新增 L_dep：到底监督什么

### 7.1 与已有损失的职责区别

| 损失 | 核心监督对象 |
|---|---|
| L_FM | 视频的正常生成分布 |
| L_struct | 实际 P 和 R 的过程预测目标 |
| L_out | 真实写入后视频的稠密过程／局部表征 |
| L_align | 视频是否执行了文本中的角色、动作和状态变化 |
| L_dep | 被定位的前置变化与后续响应之间，是否存在有依据的定向依赖 |

L_align 已包含部分因果顺序文本，因此 L_dep 不是天然独立有效。只有引入更明确的关系证据、空间时间对应和可靠无关关系，才可能提供额外监督。

单纯把“先撞后动”的文本相似度换名为 L_causal，不是本版要做的增量。

### 7.2 标签定义

令 ℛ 是某视频中被核验的时空区域对集合。每一对包含：

- 前置变化的时间范围与可见区域；
- 后续响应的时间范围与可见区域；
- 本片段中有证据支持的依赖标签 y；
- 标签可靠性 ρ 和未知状态。

这里的关系首先指可观察、可解释的作用—响应依赖。应将直接作用与“只是时间更早”“只是物体先出现”区分开；静态背景条件不自动等于触发原因。

i、j 是数据中可变的时空窗口索引，不是模型内部“施力者 slot／受力者 slot”。不要求所有视频具有固定数量的事件，也不要求每个位置承担预先指定的角色。

### 7.3 损失形式

\[
\mathcal L_{\rm dep}
=
\sum_{m\in\{\rm process,out\}}\beta_m
\frac{
\sum_{(i,j)\in\mathcal R}
\rho_{ij}\,
\operatorname{BCE}
\left(D_\psi(F_m,\Omega_i,\Omega_j,c_{\rm ctx}),y_{ij}\right)
}{
\sum_{(i,j)\in\mathcal R}\rho_{ij}+\varepsilon
},
\qquad \sum_m\beta_m=1.
\]

其中：

- Fprocess 是实际参与 A／B 写入的干净过程估计，不是另一份孤立的辅助 P；
- Fout 是真实写入后可读视频端点经冻结 teacher 得到的对齐特征；
- Ωi、Ωj 是关系两端的时空支持范围，需保留必要的交互上下文；
- Dψ 是拟先在可靠真实视频上训练、校准，再冻结使用的关系读出，不是当前已训练完成的模型；
- cctx 只提供必要动作／情境信息，不直接给出依赖标签或完整因果答案；
- β 只平衡同一关系任务的两个应用位置，不为每种物理现象设置新目标。

标注若只有事件级精度，就在区域集合上聚合计算，不将它扩张成“区域内每个像素都是因果点”的伪真值。不同尺度的读出与聚合必须在校准时覆盖，不能把整事件分类头未经测试直接用于单个 token 对。

高噪声处的过程估计／视频端点可能不可读。L_dep 的适用 σ 和窗口由独立校准决定，不用错误的高噪声关系评分强压唯一未来；早期过程仍通过覆盖全噪声区间的 L_struct 学习。某个视图不可用时跳过它，并对有效视图的 β 重新归一化；全部不可用时跳过本项。

### 7.4 两侧怎样做到语义对应

首版优先令过程和输出侧使用同一教师、取层、时空映射与训练集归一化：

\[
F_{\rm process}=\widehat P_{0,A}^{D2},\qquad
F_{\rm out}=\mathcal N_{\rm train}\mathcal A_{\rm grid}
\Phi(\widehat x).
\]

关系读出 Dψ 先在同一定义的 GT 特征上学习，随后冻结参数。这样两侧使用同一关系判别语义，而不是让两个独立可训练头自行约定一个容易优化的答案。

即使维度一致，生成特征也可能离开教师的真实数据分布；必须测量读出在过程预测和生成端点上的可辨识度，不能只靠训练集准确率背书。

如果以后更换 L_out 的教师为空间边界模型，应单独处理关系读出的输入空间，不把不兼容特征直接送入同一个头。

### 7.5 如何直接训练实际修改

实际输出侧梯度为：

~~~text
关系标签与生成视频依赖预测不一致
        → 冻结关系读出对输入的梯度
        → 冻结稠密 teacher 对生成输入的梯度
        → VAE / 原生输出头 / 尚未执行的主干层
        → B 的真实写入、A 的过程写入
        → R / SharedCell 的参数
~~~

Dψ 在生成器训练时不能跟着生成结果一起改答案；否则可能出现“视频没改对，读出却学会给它高分”。

过程侧和输出侧属于同一种依赖任务的深监督，但都要做单侧消融。只有过程分数提高、实际视频没改善，不能算 L_dep 有效。

这里仍使用标准加噪训练前向的可读端点，不为计算 L_dep 再展开完整采样链。最终效果用部署协议下的完整视频验证。

## 8. 监督数据怎样得到，而不是凭空假设已有强因果 GT

### 8.1 仍只用两套训练数据

来源限定于 [WISA-80K](https://huggingface.co/datasets/qihoo360/WISA-80K) 和 [OpenVid-1M](https://huggingface.co/datasets/nkp37/OpenVid-1M)。

它们的原视频和描述不是现成的完整因果关系真值。新增依赖标签需要实际整理，不能把“公开数据可用”写成“标注已经存在”。

### 8.2 推荐的标注流程

1. 选择能看到完整前置条件、作用与后果的片段，保留关键时间的足够取帧密度。
2. 使用离线 VLM 提议相关变化、时间范围及可见区域；标注器必须实际查看视频，不只读 caption。
3. 在可靠小集上人工复核直接依赖、共现、先后关系、遮挡和可能的其他作用来源。
4. 保存标签来源、视频证据、时间戳、空间支持和 unknown，而不是只存“物理正确”一个总分。
5. 对标签做源视频／场景隔离的留出校准，关系读出通过后才用于生成器训练。

[MECD+](https://arxiv.org/html/2501.07227v4) 的事件关系标注与前因贡献分析提供相关参考，也指出先后关系和存在条件可能造成虚假因果。这里借鉴其问题意识，不照搬长视频事件图管线，也不使用其数据扩大当前训练范围。

### 8.3 正例、负例与未知必须分清

| 类型 | 示例与处理 |
|---|---|
| 有证据的正依赖 | 可见拍面接触与随后球的对应方向变化；可见支撑移除与随后下落 |
| 有证据的无关关系 | 同片段中明确无作用联系的变化，不因时间相邻自动标正 |
| 仅存在条件 | 物体先出现不自动意味着它的出现触发了后来所有运动 |
| 不确定 | 接触被遮挡、反射无法区分、多种作用无法归因，保留未知 |
| 反事实文本 | 可以继续用于 L_align，但不能直接作为真实世界反事实轨迹 GT |

y=0 不是“这个位置必须不动”，而是“这对被标注变化之间不支持所指依赖”。重力、其他接触或其他动作仍可能造成运动。

y=1 也不是“只要两个物体靠近就必须出现明显位移”。具体响应要结合真实条件、材料与过程；不能用普遍“碰一下就必须飞走”的规则监督。

若可靠正／负关系覆盖不足，先不启动 L_dep 的长训练。全正标签不能训练可信关系区分，更不能将所有未标注关系默认为负例。

### 8.4 为什么不用遮挡前因直接制造硬反事实标签

“看不到球拍”是观察信息被遮挡，不等于现实里没有球拍或没有碰撞。不能因此强迫预测中的球停止。

遮蔽前因可用于诊断预测对证据的依赖，但同时受到信息缺失与分布变化影响。自然视频也存在隐藏因素；严格因果识别需要更强数据与假设，不能仅凭一个命名为因果的损失保证。[Interventional Causal Representation Learning](https://proceedings.mlr.press/v202/ahuja23a.html)

本版不制造错误视频配对，不训练反事实“修复视频”库，也不将任意生成视频与不同场景的 GT 强行对齐。

## 9. L_dep 与局部修正为何必须共同保留

单独预测出“接触导致响应”的关系，可能仍生成一个几何上没有接触的视频。因此：

- L_struct 保持过程分布学习；
- L_dep 加强可定位的依赖关系；
- L_out 继续监督接触边界、轮廓、旧位置与支撑背景；
- L_align 继续监督文本角色、动作是否完成；
- B 的成组写回负责把需要一起改变的位置联合处理。

| 常见问题 | D2 预期增加的帮助 | 不能替代的原有能力 |
|---|---|---|
| 没碰到却先飞走 | 前置预测与作用—响应依赖监督 | 细粒度接触、路径和响应时序修正 |
| 红球不动，蓝球自行移动 | 动作条件、主动角色与相关后果预测 | 实际视频文本执行及双方几何 |
| 同一物体出现副本 | 过程一致性可能提供间接帮助 | 原／新位置联合处理、身份数量核验；不能只靠因果边保证计数 |
| 动作变形、穿模 | 关系可约束交互过程 | 轮廓／材料／可见几何目标；单目不提供严格三维非穿透保证 |
| 背景漂移或伪影 | 区分相关作用与无关变化可能有帮助 | 背景底座、原生画质训练与稠密局部监督 |
| 静止却被认为成功 | 正依赖和实际状态变化监督避免仅满足“没有错误后果” | 完整任务、必要运动和 SA 验收 |

这些是待验证的作用机制，不是每一种错误都已被新损失解决的结论。

## 10. 多样性、强度与防投机

R 的预测基于同一随机 P 状态，不把多种合法过程先平均成固定计划后永久锁死。初始随机性、联合过程 FM 和正常采样机制继续保留。

需要防止两种投机：

1. 只压低错误响应，最后所有主体都不动；
2. 只追求明显响应，最后过度运动、物体变形或背景被带动。

因此依赖监督必须与真实完成和局部保持共同评估。门值、过程速度 uP 和 feature 范数不等于真实物理运动强度。

在单帧条件不足时，不把某一个 GT 的精确速度／路径当作所有合法未来的唯一答案。输出侧的逐样本对应监督限制在标准训练路径与可读条件；自由生成阶段报告全部 seed 的合法率、完整度及运动分布。

## 11. 训练和推理的计算成本

### 11.1 过程目标复用，不重复创建同义损失

R 的过程速度继续监督到：

\[
u_P^*=\epsilon_P-T.
\]

它与 A／B 的过程估计使用同一个 L_struct，深监督权重归一化。R、A、B 都读取同一合法 Pσ；不能先让 R 推进 P，再对新状态套原目标。

### 11.2 新增训练成本

必须单列：

- 离线依赖标注及人工复核；
- 关系读出 Dψ 的训练与校准；
- R 的小单元调用；
- L_dep 两侧的关系计算和必要输出 teacher 反传。

Dψ 的准备训练使用同一个依赖预测任务，但不是免费步骤。即使其参数被冻结，生成器阶段仍需要输入梯度。

若 L_out 已计算完全相同裁剪、取层与空间的 teacher 特征，可以复用；不同窗口／预处理不能随意复用缓存。

### 11.3 正式推理成本

首版 R 在预先配置的前／中噪声区间调用，是否延伸到后期另做消融；不依据错误评分临时重试或额外展开多条过程。

K 个 Euler 步、两路 CFG 时，原生完整 Wan 前向仍为 2K；增加的是 R 的小规模计算与融合。若实际 solver 使用更多模型求值，按真实 NFE 计数。

首版 Dψ 是训练／诊断读出，正式推理不需要它，也不运行离线 VLM 或视频 teacher。推理不产生关系评分后再选择视频。

## 12. 可实施伪代码

~~~text
z, P = one_joint_noise_sample(seed)
C_obs = encode_only_allowed_observation_once()
apply_native_image_condition(z)

for sigma, sigma_next in normal_schedule:
    snapshot = (z, P)

    for branch in native_CFG_branches:
        # 分支工作状态独立，不共享条件预测或可变缓存
        H_A = Wan_before_A(snapshot.z, branch)
        u_A_base, work_A = Cell(snapshot.P, H_A, branch, sigma)

        if sigma_in_predefined_reasoning_range:
            u_R = Cell_reasoning_view(
                snapshot.P, C_obs, branch.text, sigma
            )
            u_A = u_A_base + alpha(sigma) * (u_R - u_A_base)
        else:
            u_A = u_A_base

        H_A = write_A_using_actual_fused_process(
            H_A, snapshot.P, u_A, work_A
        )

        H_B = Wan_A_to_B(H_A)
        K = relation_kernel(snapshot.P, u_A, H_B, fine_observation)
        delta_u_B, write_message = Cell_B(snapshot.P, H_B, K, ...)
        u_B = u_A + delta_u_B
        H_B = H_B + group_scatter(K, write_message)

        v_z = Wan_remaining_layers_and_head(H_B)
        save_branch_fields(v_z, u_B)

    v_z, u_P = joint_CFG(branch_fields)
    z, P = joint_solver_commit(snapshot, v_z, u_P, sigma_next)
    restore_native_image_condition(z)

decode_the_same_video(z)
~~~

alpha=0 的对照中，新增调用不能改变原有随机数状态和缓存；否则即使公式退化为 D，数值轨迹也可能不等价。

训练时：

~~~text
真实视频 → z0、T
          → 采 sigma 和独立噪声
          → 合法联合 (zσ,Pσ)
          → 正常 R/A/B/原生输出前向
          → 原有四种任务
          → 有可靠关系且预测可读时，计算同一 L_dep 的两侧监督
          → 反传到实际过程与实际写入
~~~

全无有效关系的 batch 跳过 L_dep，继续正常任务，不制造标签或 NaN。

## 13. D2 的四组核心实验

| 配置 | 推理分支 R | L_dep | 目的 |
|---|---:|---:|---|
| D | 否 | 否 | 原始有效基线 |
| D＋R | 是 | 否 | 实际加入受限条件预测是否有用 |
| D＋L_dep | 否 | 是 | 独立依赖监督是否有用 |
| D2 完整版 | 是 | 是 | 两者是否产生额外协同 |

D＋L_dep 直接监督 D 已有、实际使用的过程估计和输出，不需要先加 R。因此四组可以拆开，不将新增数据、模型和监督全部混在一起。

所有组保留相同的原有历史预测训练视图；D＋R 不能额外多一大批过程训练数据后将收益都归给在线 R。

### 13.1 必需的补充消融

- 与 R 相同时间预算的普通小单元加深或更宽 adapter；
- 相同总耗时下，增加正常去噪步的简单模型；
- L_dep 仅过程侧、仅实际输出侧、两侧共同；
- 加入 R 后是否只改善关系读出而不改善实际视频；
- 主体／动作条件变化与无关背景变化的对照；
- 关系绑定变化与相同覆盖／修改预算的对照；
- R 共享主体与独立小分支只有在确有冲突时才比较。

高层关系准确率不是最终指标。应同时观察真实接触链、完整动作、数量身份、形变、背景、伪影、SA／PC 联合表现，以及已正确视频被改坏的比例。

### 13.2 可接受的结论与不可接受的结论

可接受：

- 在给定数据和预算下，R 减少某类前期结构错误；
- L_dep 带来超过普通语义对齐的依赖与实际输出收益；
- D2 在等计算量下改善完整交互，同时保留局部质量。

不可接受：

- 关系图／attention 更漂亮，所以学会了因果；
- teacher 给分更高，所以物理一定正确；
- 遮蔽前因后预测不同，所以证明了真实世界因果；
- 多了 reasoner 和第五项损失，所以具备 CVPR 级创新。

## 14. v4 的增量落地顺序

1. 固定已有效 D 的 checkpoint、数据和完整评估协议；如果 D 尚未训练，先完成其最小有效闭环，不直接叠 D2。
2. 在小型 WISA／OpenVid 子集建立可靠依赖标签，验证稠密特征和 Dψ 是否真的能识别目标关系。
3. 将已有历史预测能力接到 R 的实际生成路径，先做 alpha=0 的完整联合轨迹等价测试。
4. 只训练／接入 D＋R，展示前期过程和实际视频收益。
5. 单独训练 D＋L_dep，验证不是重复 L_align；无法提升就先查标签和读出。
6. 两个单项均有依据后再联合成 D2，报告协同与破坏率。
7. 最后考虑共享权重冲突、适用 σ 与更细局部窗口；不先扩建大 VLM 管线或显式因果图。

## 15. 必须验证的实现细节

- 不存在固定物理语义 query 或对象槽位表；
- R 不读清晰未来、混入未来的历史 token 或其他分支预测；
- R／A／B 不原地修改本步 Pσ；
- 两种 CFG 速度、分支工作状态和 solver 提交合同不变；
- alpha=0 时完整 z／P 轨迹与 D 一致；
- alpha>0 时实际 A 写入与 B 读取确实使用融合过程；
- 关系读出训练和评估按源视频／场景隔离；
- Dψ 不仅依靠文本、绝对时刻或对象名判断关系；
- 区域级标签不被伪造为逐像素因果标签；
- 未知关系不变成负例，可靠性不由可学习 gate 决定；
- 冻结 Dψ／teacher 仍保留生成输入梯度；
- 实际输出侧 L_dep 的梯度能到达 writer；
- 当前端点与完整采样视频分开记录；
- 训练 teacher 分数与独立过程检查共同报告；
- 不使用候选筛选、重启、主干回溯或错误视频配对。

## 16. 最终研究定位与停止条件

D2 的候选研究主张是：

> 将有依据的条件过程预测投入真实生成，并通过同时作用于过程表示与实际输出的依赖监督，使局部联合修改更符合前因—响应关系，同时不牺牲完整任务、身份、背景和局部几何。

它不是单纯“增加一个推理模型”，也不是“第五个 loss 更强”。

以下任何情况出现，都不应强行保留完整 D2：

- 可靠依赖标签无法取得，或读出主要依赖文本捷径；
- R 与同成本普通计算没有差别；
- L_dep 与 L_align 没有可分辨增量；
- 只改善辅助分数，实际视频不改善；
- 因果得分提升却导致静止、过度运动、数量／局部质量退化；
- 训练或部署成本超过其可证实收益。

本版保留可行的实验入口，但不承诺所有严重离轨错误可修复，也不预先保证创新优先权、实验增益或录用。最终保留哪部分，取决于数据可靠性、真实生成效果和公平消融。
