## 2. 三种张量空间与监督方向

| 张量 | 16帧384视图的示例形状 | 含义 |
|---|---|---|
| GT RGB | [B,3,16,384,384] | 固定时间／裁剪的真实参考视频 |
| F_GT | [B,4608,1664] | 冻结2.1 G最终层原生特征 |
| 网格GT | [B,8,24,24,1664] | 可逆重排，不修改token值 |
| P_init、P_i^-、P_i^+ | [B,8,24,24,1664] | 与GT同一表示定义的学生预测 |
| ΔP、有效D | [B,8,24,24,1664] | 状态候选／实际增量 |
| H_i、ΔH_i | [B,N_H,3072] | 当前Wan隐藏及残差，N_H来自真实grid_sizes |

监督直接为`P_i^+ ↔ F_GT`；执行为`H_i → Read_i → cell → P_i^+ → writer_i → H_i+ΔH_i`。没有“先把GT变成3072维hidden再比较”，没有“把P升维后才叫P”的辅助张量。cell中的Z／Y虽同为1664维，但属于临时计算状态，不能拿它们替代实际提交P来降低loss。

官方G输出1664维、tubelet2、patch16；列表、多层拼接和其他型号接口须单独断言。[2.1编码器](https://github.com/facebookresearch/vjepa2/blob/main/app/vjepa_2_1/models/vision_transformer.py)

## 3. 同维方案合理在哪里，还不能保证什么

直接P监督固定了表示坐标。Read／writer是学生的参数，改变它们不能改变F_GT；学生必须在固定教师空间降低实际状态误差。P近似目标时其内容更容易检查，也可进行明确标记的离线GT状态替换诊断。与P和R可以联合旋转／缩放的旧方案相比，监督链路更短、含义更清楚。

| 操作 | 本版处理 | 信息边界 |
|---|---|---|
| teacher输出可逆reshape／permute | 使用 | 正确重排不丢数值 |
| 按同一坐标选择监督token | 可明确抽样 | 未选位置该次不受直接监督，不等于全覆盖 |
| GT侧学习映射 | 不使用 | 避免目标共同漂移 |
| GT默认平均池化／额外L2归一化 | 不使用 | 分别损失空间区分／幅值信息 |
| 学生结构读出R | 删除 | 取消R吸收误差与窄读出瓶颈 |
| Read3072→1664 | 训练 | 有损任务观察，不要求完整保留Wan所有信息 |
| writer1664→3072 | 训练 | 控制接口，不是GT反变换或全H重建器 |
| teacher内部最终LayerNorm | 保留 | 固定预训练表示定义，不是新增标签压缩器 |

GT老师本身不是RGB可逆编码，真实视频也不自动是精确物理真值。取帧、画幅、遮挡和领域偏差仍会造成目标盲区；同维只是让监督来源可靠可追踪，无法创造教师未包含的信息。P直接MSE也可能偏向常见外观或条件平均，需要现象指标和合法多样性约束其实际用途。

## 4. 每个corrector的P到底如何对齐和更新

所有corrector使用同一个P网格。网格由生成请求的固定视图、时间戳和坐标决定，不需要GT值；首版固定经审核的384方形全过程视图，任意宽高比和长视频多窗须另过对应测试。

1. 从GT记录取帧时间、patch覆盖区和tubelet对应的两帧区间。坐标锚点不等于感受野，教师特征仍会利用更大上下文。
2. H按Wan实际grid_sizes还原，排除padding；因果VAE首帧和后续时间分组分别记录，不能将其当teacher的二帧均匀tubelet。
3. `O_i=S_H→P(Linear3072→1664(LN_H(H_i)))`。坐标统一用原始视图像素边界坐标与秒：teacher空间patch中心为`16a+8`，再经crop／resize的逆坐标变换回生成画面；时间锚点为两帧真实时间戳均值。Wan空间中心按VAE stride16与DiT patch2的32像素间距定义；时间使用因果latent的末帧锚点，参考stride4下第j个latent对应`t[4j]`、j=0为首帧。它们是声明的几何锚点，不声称等于神经网络的精确感受野中心，实际VAE若有不同索引／裁剪规则必须相应修正并重新测试。
4. S和U均沿实际坐标轴查找相邻锚点，以`a=(q-x_left)/(x_right-x_left)`得到线性权重并作三轴插值；边界查询若仍在有效画面／时间覆盖内则复制最近有效锚点，超出真实覆盖则置零并标记无效。writer只在教师视图覆盖的Wan位置写入，裁剪外与padding位置ΔH严格为零，不把边缘P外推到未观察画面。选定视图必须覆盖交互双方和关键背景；这不保证小crop能完成全局校正。mask来自请求几何，GT质量／可靠度mask只进入loss，不作为学生输入。整个corrector内复用当前O_i。
5. `Z=P_before+O_i+固定位置+sigma_embedding+site_embedding`。1664维的2-block SharedCell对Z作自注意力及文本交叉注意力；经共享最终LN产生1664维候选ΔP与逐token标量G。26头×64维，MLP1664→6656→1664。
6. `D=s_i η_i_eff G⊙ΔP`，`P_after=P_before+D`。不原地覆盖，不对持久P追加LayerNorm。直接监督这个P_after。
7. `Z_write=LN_write(P_after)`；方向`W_out Z_write`为3072维、无bias；gate为sigmoid(a(Z_write))的标量。相乘后由固定U_P→H采样回Wan网格，乘γ_eff，加到原始H。

初始化把当前噪声latent48、广播首帧latent48和首帧mask1按同一坐标对齐，经97→1664投影生成P_init。没有未来GT输入；文本4096→1664后在cell中作为条件。整个两层cell及条件／更新头共享，Read／写入LN／writer／写入gate按位置训练，B另有b_B。

固定位置编码在1664通道内依次拼接时间512、垂直576、水平576维正余弦编码，各轴独立，避免简单相加造成轴置换歧义；坐标归一化按记录的请求视图固定。attention的P有效mask来自请求几何，文本padding使用文本编码器mask，不能将GT质量mask泄漏进学生。所有mask全无有效键的样本应在进入attention前明确旁路／排除，避免全负无穷softmax。

两个不同上下文的教师编码，即使对应相同帧，目标token也未必一致。长视频窗口需固定唯一上下文或目标归属；禁止从完整双向GT编码中截历史token，冒充只看历史的条件输入。

## 5. 更新后监督、剩余误差及映射梯度

\[
L_{s,i}=\frac{\sum_u\rho_u w_u\|P_{i,u}^+-F_{GT,u}\|_2^2/1664}
{\sum_u\rho_u w_u+\varepsilon},\qquad
L_{struct}=\mathbb E[g_s(\sigma)\sum_{i\in\mathcal I}\alpha_iL_{s,i}].
\]

I仅含启用且有有效目标的最终提交态；A-only／B旁路时α_A=1，均启用时起步各1/2。前态如果是上个corrector输出，已在上个提交点受监督；不另加重复loss。内部多轮默认只监督最终P，不强迫每次计算单调改善。

同维之后，`E=F_GT-P_before`是当前表征剩余误差：

\[
\|P^-+D-F_{GT}\|^2=\|D-E\|^2.
\]

例如仅示意两个通道：GT=(1,0)，P_before=(0.6,0.8)，有效D=(0.2,−0.3)，P_after=(0.8,0.5)，逐通道MSE从0.4降到0.145。它说明有效更新减小表示误差，不说明这两个通道是速度，也不证明视频已经发生正确碰撞。

这已经通过P_after的loss训练有效D，无需新增ΔP损失。候选ΔP还乘门控／调度，不要除以零门控构造候选标签；也不要把F_GT(τ+1)−F_GT(τ)当成cell修订量。如果把右式E中的P_before detach，梯度将不同于左式，首版不这样改写训练。

令q=∂L/∂P_after，逐token标量G沿通道广播：

\[
\frac{\partial L}{\partial\Delta P_c}=s_i\eta_i^{eff}G_iq_c,
\qquad\frac{\partial L}{\partial G_i}=s_i\eta_i^{eff}\sum_c\Delta P_cq_c.
\]

| 参数／激活 | 结构loss的路径 | 实际输出任务的路径 |
|---|---|---|
| P_init、Read、cell、ΔP头和P gate | 经P_after | 经实际P_after→writer→后缀 |
| 当前writer与其gate | 本位置struct不经过它 | 经H+ΔH和真实后缀 |
| 前面corrector | 后面P依赖前面P／H时可传回 | 后缀直接／间接传回 |
| 固定teacher／VAE／Wan | 不更新权重；struct的GT停止梯度 | 参数冻结但必要输入梯度保留 |
| M3a冻结共享cell | 参数不更新 | 仍可作为可微函数将梯度传回B的Read |

B初始b_B=W_out_B=0：结构loss可以先训练b_B，视频任务可以先训练W_out_B；上游Read的梯度可暂时为零。起步更新后再检查Read等能否收到梯度。把整个冻结cell放进no_grad会切断B读取训练，是代码错误。

## 6. 为什么不用低维cell包一层1664维P

要区分“存储维度相同”和“可以预测充分的特征方向”。如果采用共享候选头`Wq+b_Δ`，q是256维、gate是逐token标量，那么多次累积也满足：

\[
P_{final}-P_0\in\operatorname{col}([W,b_\Delta]),\qquad
\operatorname{rank}([W,b_\Delta])\le257.
\]

在当前97→1664的线性初始化下，中心化P的自由线性范围至多354维；候选头无bias时353维。这是该具体架构的上界，不是所有瓶颈网络的通用定理：非线性全宽输出、不同头或逐通道gate会改变前提，但也会构成不同设计，不能口头当等价实现。

本版选择全1664维cell、MLP及候选头，直接去掉上述人为低秩限制，并以两个block控制深度。对1664维GT的线性表示不再被固定256维R限制；但有限深度、Read压缩、噪声信息不足和训练数据仍然限制预测。

需要报告常量均值基线、实际P误差、按现象／时空位置的关系指标、P方差／误差谱与真实输出。直接同维使诊断更简单，却不能把全宽配置当成已经证明更好的模型。若两层拟合／控制不足，先定位数据、观察或深度；增加深度要重新登记成本和对照。

## 7. ΔH及H+ΔH为什么没有唯一GT，如何训练

同维P解决不了hidden标签的非唯一性。干净GT的Wan隐藏来自不同σ；同一带噪输入的原生Wan隐藏又只是未校正模型的行为。任意把V-JEPA特征映射成3072维也不会自动成为正确H。因此不制造H_GT或ΔH_GT。

\[
H_i^+=H_i+\Delta H_i,\quad
v=F_{>i}(H_i^+,P_i^+;c,\sigma),\quad
\widehat z_0=z_\sigma-\sigma v.
\]

F包含真实剩余Wan层、同一策略下的后续corrector和原生输出头。FM在合法GT加噪路径对v监督；L_out经VAE解码后的真实端点与固定GT视频表征比较；L_align评价实际视频与正确描述。局部梯度为：

\[
\frac{\partial L_{video}}{\partial\Delta H_i}
=J_{F_{>i}}^\top\frac{\partial L_{video}}{\partial v}.
\]

多个共享调用与P传递还有额外路径，上式是局部导数。struct不经过本位置writer，不能独自证明或训练其视频作用。训练输出误差会提供可学习的残差方向；它不等于每条视频的修改必然改善，也不是推理时执行一次有GT的梯度下降。

原生FM为z_σ=(1−σ)z_0+σε、v*=ε−z_0；已知首帧与padding按原生I2V约定处理。输出端点不是最终CFG视频，完整自由采样必须单独评价。σ=0时端点对v的梯度为零，高σ又可能不可读，辅助输出损失在两者之间校准。

## 8. 每个corrector的实际收益必须单独检查

同一checkpoint固定样本、σ、H_i、P_i^-、文本、位置／噪声嵌入、缓存、RNG和后续策略。前缀只算一次，克隆全部必要状态，再分叉后缀。不同层H不能互相相减后当纯校正效果。

| 对照 | 有更新分支 | 对照分支 | 解释 |
|---|---|---|---|
| 本位置写入 | F(H+ΔH,P_after) | F(H,P_after) | 固定相同更新P，ΔH本身是否改善后缀输出 |
| 整个corrector | F(H+ΔH,P_after) | F(H,P_before) | 状态与写入合起来是否有益 |
| 后续补偿 | 两分支均按同一后续corrector策略 | 另做两分支均旁路后续corrector | 区分直接作用与后续补偿，不能混用不同后缀作一组比较 |
| 跨正常去噪步 | 同一完整前态继续正常更新后缀 | 同一前态跳过该更新后继续相同协议 | P的跨步作用是否仍有净收益 |

合法GT视图上`gain=loss_without−loss_with`，正值改善；分别报告FM／out／align的有效原始误差，不只报加权总分。教师看不清或σ不适用的零loss不能计为改善。自由采样有多种合法未来，用独立物理／任务／质量评价，不按某条GT强制逐token比较。

每组至少要相应的两个后缀，复用正分支仍需额外负分支及对应VAE／教师计算；m个位置的成本要逐一登记。这是离线研发验收，不是新增默认排序损失或生产候选筛选。无需为每个层输出杜撰GT，也不能省掉对实际执行结果的验收。

A-only先证明基础；通过角色、数量／身份、必要交互、顺序、完整成功及多样性准入后才训练B。M3a固定基础，高σ的q_B=0时完全旁路B，保证规定条件下早期(z,P,scheduler)前缀相同。交接后仍报告原正确子集破坏率、保持／细化收益以及全量净收益；小门控、低teacher误差或前缀一致都不是物理证书。

## 9. 参数、资源和工程契约

| 阶段／项目 | 原生P方案 |
|---|---:|
| M0接口与教师准备 | 正式训练0 |
| M1／M2a／M2b的A＋共享组 | 114,204,802（114.20M） |
| 匹配头独立准备 | 3,055,617（3.06M） |
| M3a仅B适配 | 10,236,418（10.24M） |
| 可选M3b联合／正式A+B推理新增 | 124,441,220（124.44M） |
| 4个全宽block替代首版2个时 | 联合213,109,124（213.11M），不是首版 |
| 16帧P token | 4608 |
| P与GT各自的BF16单状态存储 | 14.625 MiB |

细项按E第4.1节；共享权重按参数对象去重，P激活不进入optimizer。A-only的共享位置表包含预留B行；M3a构造时从A复制该行，冻结基础后B局部适配训练。M3a输出梯度穿过冻结核心，并非只训练最后一个线性层就一定足够。

全宽P单状态相对上一版native网格256维P增加6.5倍，参数和反向计算也明显增加。不能只凭10.24M可训练B参数判断GPU显存，冻结Wan后缀、VAE和教师仍需保留输入反传信息。内存高效attention与checkpoint要实测；尚无硬件可用性的结论。已正确缓存的1664维native GT可沿用，旧池化缓存不能恢复。

每个corrector返回`P_before, candidate_delta, gate, D_effective, P_after, delta_H, H_after, grid, sigma, active_mask`。loss、writer、跨步状态使用同一个P_after；日志detach，主计算图不detach／不原地覆盖。checkpoint重算须为纯函数，不重复提交全局P／缓存。

冻结参数不等于no_grad：GT可离线，预测端的Wan后缀／VAE／教师保留输入梯度；M3a整批无可训练有效路径时跳过优化器，不做纯weight decay更新。无效目标先填安全值再计算距离，0×NaN不能用mask消除。多卡按全局有效数与梯度归约系数一致归一化，各rank反向协议必须兼容。

## 10. 本轮验证范围与完成顺序

本轮11项契约检查已通过，结果见[检查记录](validation/20260909-native-p-contract-results.json)：原生1664维直接MSE、GT不变且无梯度、mask／σ归一化、无效NaN安全零值／有效NaN报错、监督后态和剩余误差的梯度等价、数值示例、全宽参数容器计数、26×64注意力CPU反传、B双零恒等与起步梯度例外、冻结cell／后缀对B读写的输入梯度、含bias低秩上界及网格reshape。相关边界合并计为11项；CPU图中的cell采用缩小宽度，完整1664维权重仅在meta设备做计数，未分配并训练124M参数。检查期间出现环境CUDA初始化警告，本轮没有CUDA验证。这些检查不等价于正式V-JEPA权重、完整Wan／VAE、真实坐标集成、GPU训练或生成效果验证。

1. M0实现正式加载、固定视图、native GT缓存、坐标对应、直接P loss和单项梯度，测量真实峰值与吞吐；教师领域辨识和VAE往返不过关，先修输入／观测范围。
2. M1训练A＋共享组，比较同架构FM-only与FM＋struct；16–32条仅作拟合／链路检查，再用源视频隔离开发集评价。M2a单独比较一次与多次更新。
3. 独立准备可靠匹配头，M2b再加入align并验收基础；不过关不进入B训练。
4. M3a在同一合格基础上只训练B适配，保留四项任务及逐位置归因；有稳定净收益即可形成完整首版。M3b、M4及M5由实际瓶颈决定，不作为掩盖失败的必经补救。

原生P、全宽cell、直接GT监督和明确hidden读写共同形成一套完整逻辑；仍需实验解决的是教师敏感性、带噪预测、控制能力、资源及泛化效果。不能给这些尚无数据的问题虚构“已经有效”的答案。[REPA](https://arxiv.org/abs/2410.06940)与[V-JEPA 2.1](https://arxiv.org/abs/2603.14482)提供研究依据，不替代本模型的检验。
