## 0. 当前实现：条件先验 P 与每五层独立校正

当前 `initialization: image_text_gt`：同一个初始化器在训练时以 75% 概率读取文字、独立首帧、当前 GT 片段的干净 VAE latent 和时空规格，以 25% 概率去掉 GT 视频条件。每个样本只生成一次 P₀，两种情况接受相同 JEPA 监督。推理／验证的 P₀ 只读取文字、首帧与时空规格；Wan 的噪声输入仍不进入初始化器。GT latent 保留全部时间位置、空间池化至最多 8×8，位置映射到教师 letterbox 坐标；JEPA token 本身不作为初始化输入。默认暖起关闭，保留显式同视频双视图对照，详见 [当前代码与验证](../../v4/evaluation/GT_CONDITION_PRIOR.md)。

所有 P 查询共同读取完整文本与首帧，有 GT 条件时还读取全片段池化视频 tokens，未来位置不填随机视频 latent，也不把已知首帧直接复制为某几个 P token。正确说法是每个位置都是模型预测，而不是“每个位置已具有足够且正确的物理知识”；精确未来仍存在条件不确定性。

默认 `parameter_sharing: per_block`、`a_blocks: [5,10,15,20,25,30]` 与 `a_every: 5`，在这六个 Wan block 后各自调用一套完整独立 A corrector；Read／Writer／gate／StateCore／条件投影／attention／归一化均不跨 block 共享。同一 block 在不同去噪 step 和自己的内部迭代中复用自己的参数。P 沿调用顺序接续，H 在当前位置写回后继续原 Wan；固定 block 序号编码提供深度条件。六次调用不在前向中更新模型权重，反向梯度分别累积到各 block 的独立参数，梯度累积结束后由优化器统一更新。A1 不用 B，后续 B1／AB 可另启用 B@18。

当前 `fusion: cross_attention` 用双向注意力替换旧的插值加法：P 查询 H 得到门控观察后更新，H 再查询已提交的 P 生成 ΔH。P/H 保持各自 token 数，不再做读写的时空插值；两路 1664 维、26 头全局非因果注意力在 A/B 及所有调用位置各自独立。双方时间／空间编码仍保留，残差加法仍保留。具体算法见第 4.3 节；旧 checkpoint 只有 RESUME／推理仍按其保存的插值结构执行。

当前训练 1000 条，A1 为 500 步，A2／A3／B1／AB 各 250 步；默认 A1 使用 FM＋更新态 L_struct＋小权重初始 L_prior，不启用 L_out 或 L_align。初始 L_prior 是可消融的粗时序蒸馏，设 prior_weight=0 后，普通视图中初始化器仍可经后续损失训练。代码与 CPU 检查不构成物理收益或 GPU 显存已验证的证据。

## 1. 本轮结论与明确撤回的设计

核心主张调整为：

> 使用统一corrector block，先通过监督和独立验收建立准确性较高、能够控制生成的过程基础；在保持已验收早期前缀的条件下，中期依据更清晰观察优化尚未确定的关系与细节，后期继续完善。结构性早期失败优先在基础阶段解决，不能把主要希望寄托在中后期救回。

不是“前期猜一个结构并永久锁死”，也不是“中期发现没碰撞，就更新 P 并重新跑完整 Wan”。

| 内容 | 当前决定 |
|---|---|
| 前期结构学习 | 具有明确监督、优化与生成控制验证；通过基础能力准入后才启用中期增量 |
| P 的监督来源 | 同一 GT 视频经冻结 V-JEPA 2.1 编码得到的稠密时空 token；仅作为训练目标 |
| P 的含义 | 由视频表征蒸馏约束的、可更新的过程状态；不等同于精确物理真值或独立扩散变量 |
| 中期结构修正 | 在可靠基础上优化；允许修正残余路径、接触与时序偏差，不把严重早期错误恢复作为默认工作模式 |
| 已成立的结构 | 作为软约束和学习依据保留，不冻结全部 P 或全部视频 latent |
| 同一步回到早层重跑 | 删除；也不通过反复重跑尾部偷换计算成本 |
| 轻量 recurrent | 在各位置自己的原生维度工作状态中迭代，不在循环里调用完整 Wan |
| 新的实际观察 | 来自当前前向中自然经过的后续层，以及下一正常去噪步 |
| 独立向量场残差 U | 不纳入当前主模型；统一通过内部特征写入和原生输出头 |
| 训练数据 | 只使用 WISA／OpenVid 的视频与描述，以及从这些视频提取的可靠教师目标 |
| 错误视频配对路径 | 删除 x_err 数据依赖及原 L_repair；不另建人为坏视频、扰动错误集或失败视频回收训练库 |
| 监督总数 | FM、更新态结构、初始条件先验；后续可加输出表征。L_align 不启用 |
| 推理筛选 | 不重启、不生成候选再择优、不调用 verifier 选择结果 |

研发验收可以比较多个模型配置，但不能把这种对照变成每次推理的选片策略。

## 2. “正确地基”需要包含什么，怎样才算经过验证

### 2.1 结构不是仅有粗轨迹或低频形状

以红球撞蓝球为例，过程结构至少应支持：红球承担主动接近角色；运动路径能够形成真实交互；蓝球的相关响应有相应前因；身份和数量贯穿过程连续。

接触间隙虽然很小，却可能决定事件成立与否，不能因为空间尺度小就归入“最后修纹理”。书从桌面移走后的空位、球拍与网球之间的关系、材料的来源与去向，都应进入过程建模。

这些是数据和验收维度，不转化为运行时固定语义 slot 清单。

### 2.2 “早期没有专门损失”不等于“早期没有梯度”

FM 可以通过生成主路径训练运动分布；它不是只能学画质。问题是普通全局目标未必充分重视短时交互，也不能保证新增 P 被有效使用。因此本版给实际 P 设置明确的过程监督，并通过实际输出监督训练写入效果。[Flow Matching](https://arxiv.org/abs/2210.02747)

必须分别验证：

1. **表示有效：** P 的受控读出能够反映过程关系，而非只识别球、球拍等名词。
2. **写入有效：** P 的变化能控制生成中的相应关系，而非只在辅助头里正确。
3. **早期优化有效：** 轻量优化后的 P 在开发集上优于未优化状态，并改善实际视频。
4. **保持有效：** 后续细化没有系统性破坏已经正确的角色、身份和交互关系。

探针预测、attention 图或训练 loss 下降，不能独立完成这四项证明。

### 2.3 训练验证与推理保证必须区分

训练阶段可以使用 GT／teacher；能力诊断可以明确标记地使用参考过程表征。正式推理没有未来 GT，因此不能保证每个样本的前期结构都正确。

“结构经过验证”指模型在独立开发条件下达到可信的结构预测、控制和输出表现，不是每条视频都经过在线 verifier 认证后才进入中期。

少步采样先验有时优于长步结果，但错误早期先验也会传播，不能据此一律硬锁。少步完整采样结果也不等于长采样链前几个步骤的中间状态。[PhaseLock](https://arxiv.org/html/2606.06361v2#S6)

### 2.4 “先把地基做对”成为中期训练的准入条件

这里的地基首先是条件支持的过程关系：谁作用于谁、必要的接近／支撑／接触是否能成立、动作与响应的顺序、对象身份和数量是否连续。首帧和文本未确定的精确速度、轨迹与响应细节保留合法变化。地基可靠意味着这些关键关系准确且可执行，不要求最早几步已经确定唯一完整未来或得到清晰纹理。

采用以下开发顺序，而不是仅给A改一个名字：

1. **先训练基础能力。** A1／A2／A3使用六套独立 A corrector，监督实际P并训练实际视频；完整视频是否执行必要关系是硬性验收内容。低L_struct或小gate不作为准入证据。
2. **基础不过关，先修基础。** 分别定位教师是否看得见目标、P是否能表达、writer是否能控制、推理状态是否偏离训练分布。角色、数量或交互路径经常错误时，继续改数据、监督、容量和插入位置，不以新增B掩盖问题。
3. **基础过关，再冻结它。** 保留A3的基础检查点、推理协议和独立开发结果；进入B1时冻结初始化器和六套完整 A 的全部权重，并在最早去噪区间关闭B的状态更新、写入及专属缓存。第5.4节给出这一前缀保持的精确条件。
4. **中期收益必须附带保持证据。** 同时报告原正确关系的保持、原正确视频的破坏率和总体净收益。不能仅凭失败样本有所改善就晋级。

“准确性较高”要在试验前明确目标现象、评价规则、最低基础成功率、最大允许破坏率、样本量和不确定性；这些是开发协议参数，不是teacher原生提供的概率。不能未经实测便把90%或95%写成已达到的准确率。完整基础准入表见E第7.4节。

本设计能给出的两种保证应分别陈述：**在明确条件下保持已学早期计算前缀不变，是计算契约；该前缀已在目标分布上具有较高结构准确性，是需要独立样本支持的统计结论。** 后者不等于每个新输入都正确，前者也不自动推出中后期必然越来越好。没有未来GT的单次推理，不用未校准的自评分来把这种区别抹掉。

## 3. 数据可行性：有错误标注集，不等于有合适的修复配对

### 3.1 本轮核查结论

不能说“公开世界里没有错误视频”。例如 VideoPhy-2 公开训练数据包含生成视频、语义和物理评分，以及违反规则的标注；但公开字段没有提供可直接用于本方案的同场景、同时序、同一初始条件的正确修复视频。[官方数据卡](https://huggingface.co/datasets/videophysics/videophy2_train)

IntPhys2 有可能／不可能事件评估内容，但官方说明将用途限制为评估，不能当成当前生成式训练数据来源。[官方说明](https://github.com/facebookresearch/IntPhys2#license)

因此，本版不假设已有可直接下载使用的修复配对库，也不为构建它增加工程主线。训练限定于：

- [WISA-80K](https://huggingface.co/datasets/qihoo360/WISA-80K) 的视频与标注；
- [OpenVid-1M](https://huggingface.co/datasets/nkp37/OpenVid-1M) 的视频与描述。

公开可访问不等于本地数据已经下载、通过完整性检查或具有严格物理真值；这些都需要在启动阶段核实。

### 3.2 删除的不只是一个变量名

不保留以下等价替代路径：

- 收集生成失败视频，再给它强配一个不同场景的 GT；
- 人为制造复制、乱序或轨迹扰动视频作为必要训练集；
- 把“自身错误状态库”“近邻回正样本”换名后继续作为第四项训练任务；
- 将任意自由生成结果当成与某条 GT 逐像素对应。

保留的是标准视频生成训练：

\[
x\sim\mathcal D_{\mathrm{WISA/OpenVid}},\quad
z_0=E_{\mathrm{VAE}}(x),\quad
z_\sigma=(1-\sigma)z_0+\sigma\epsilon.
\]

模型在这条正常训练前向中产生 P、特征写入、向量场和视频端点预测，再与该样本的可靠参考监督对应。

模型预测当然可能出错，但它是本次正常前向的预测结果，不是另外输入的错误视频数据。内部模块从这些预测及 GT 监督中学习，不能据此宣称已经覆盖任意严重离轨错误。

### 3.3 正常视频也不自动是严格 GT

WISA 的现象描述可帮助选片，但估计性温度、质量等字段不能直接当精确物理量真值。OpenVid 的画质和运动信息也不能证明接触、数量、因果都正确。

应抽查：完整前因与后果、接触可见性、原位置与新位置、镜头运动、重复剪辑、反射和遮挡。不可确认的区域设为未知或低权重，不强行生成标签。

## 4. 最小模型：条件先验、独立核心与顺序调用

### 4.0 统一模块定义；A／B表示调用类型，每个位置的参数独立

统一称 **corrector block（过程状态更新与特征校正模块）**。每个位置都执行同一类操作：读取当前Wan隐藏特征→结合P、文本和σ进行当前 block 的状态更新→提交实际P^+→由P^+产生特征残差→继续原生Wan。

\[
(H_i^+,P_i^+)=\mathcal C_{\theta_i,\psi_i}(H_i,P_i,c,\sigma),
\qquad i\in\{A@5,A@10,A@15,A@20,A@25,A@30,B@18\}.
\]

θ_i 包含位置 i 独占的 StateCore、文本／sigma／类型条件、读写注意力和状态更新头；ψ_i 包含位置 i 的读取、归一化、写入及门控。各位置的参数对象、存储和梯度互不共享。P 初始化器及其文本投影在单独的 initialization 参数组，不设训练读出 R。A@5、A@10、A@15、A@20、A@25、A@30 对应六套独立网络；B@18 为后续阶段另一个独立网络。

| 名称 | 本版含义 |
|---|---|
| corrector block | 完整的读取、状态更新、提交与特征写入操作，是A／B的统一模块类别 |
| StateCore／位置独立核心 | 当前 corrector 独占的1664维计算主体；其中2个Transformer block是内部深度，同位置内部迭代和跨去噪步复用 |
| A／B | 两种调用类型；每个 A 位置有完整独立参数，B 是可选的第18层独立 corrector |
| 早／中／后期 | 按真实噪声σ定义的去噪阶段，与Wan层深独立 |

**层深与去噪时间不能互相替代。** 同一次去噪前向会按层顺序经过A和B；它们并非天然分别只在早期和中期工作。本文新增的σ启用策略才使B在最早去噪段关闭、中期开始参与。A在后续阶段仍可利用更新后的P作为过程条件，初始化由独立的小型条件先验网络完成，后续由各位置独立 corrector 校正。

结构统一只表示相同的计算形式。六套 A 和 B 的完整参数均独立，固定深度编码保留，B 另有 b_B。A 阶段可训练约837.96M、完整 B 约136.22M、可选联合约974.18M；P₀ 初始化器不复用 A 的文本投影。代码分别构造各模块并核对优化器覆盖与存储隔离。

### 4.1 状态和观察

| 内容 | 作用与生命周期 |
|---|---|
| zσ | 唯一活动视频 latent，按正常采样器推进 |
| P | 受 GT 的 V-JEPA 2.1 特征监督的稠密时空过程状态；早期形成，中期可修订，传给下一正常去噪步 |
| 当前细粒度观察 | 当前真实 DiT 特征和原生 latent 局部信息；按需读取 |
| 上一观察缓存 | 可选，附带噪声和层位置；是上下文记录，不是第二套物理模型 |
| 原生维度工作状态 | StateCore 调用内的临时迭代变量，调用结束后提交一次写入 |

P 的位置是网格坐标，通道不人为对应质量、接触或速度。全局过程和局部细节由同一个小型时空更新主体交互，不另建物理 DiT、对象账本、轨迹塔或 LLM planner。

`P`是学生在正常前向中预测的状态，`F_GT`是固定教师目标。二者从初始化到每个提交态均采用同一网格和1664通道，监督时直接比较数值，不经过R或GT侧学习映射。P₀ 训练读取文本／首帧及可选 GT 视频 latent，推理只读取文本／首帧；文本、σ、深度和当前 H 在 cell 内参与后续更新，跨层和跨步传递自身 P。GT 的 JEPA 目标 token 不直接初始化或替换 P，GT 视频内容经初始化器学习映射；P 不另设噪声轨迹、速度预测头或独立 scheduler。

### 4.2 独立 A 位置：跨层级的过程形成与使用

早期噪声阶段，StateCore 在各指定深度读取当前特征、文本和已有 P，首帧信息已由条件先验提供，在原生维度状态中做少量学习到的更新，再向当前特征写入一次。

中期阶段，A 使用上一步传来的 P 作为过程条件；它不等待本步后面新发现的问题，再重新执行自己。

### 4.3 可选 B 类型：交接后的增量完善

原生 Wan 从 A 继续向前计算到 B。B 读取的是已经包含 A 写入影响的实际当前特征，而不是 A 预想中的结果。

B在第5.4节的σ策略启用后更新P，并向当前H写入结构／细节修正。随后仅运行尚未执行的后续层，本步新 P 先被后面的 A@20／A@25／A@30 使用，再传给下一正常去噪步。未启用时原样传递H和P，不生成B专属观察缓存。

A、B 使用同一种特征残差机制，各位置的核心与适配器均独立。B 在交接后另行启用；增加调用的计算成本与收益需要对照评价。

### 4.3.1 P、ΔP、A／B、ΔA／ΔB分别是什么

A／B是接口位置与相应参数组，不是两个需要逐元素标签的状态张量。本文将用户所说的ΔA／ΔB明确记为 `ΔH_A`／`ΔH_B`，即对Wan隐藏特征的真实写入。区分四种索引：视频时间τ、去噪步k、Wan层ℓ、StateCore迭代r；teacher层号又是独立的取特征配置。

当前只在第5、10、15、20、25、30层各训练一套独立 A corrector，其余 Wan 层没有新增 A；每套核心在不同去噪 step 复用自己的权重。内部若有多个更新，监督的是选定的实际更新后状态，不能将第r轮ΔP对应到teacher第r层，或对应到视频第r帧的运动差。

\[
D_i^{(r)}=s_i\eta_i(\sigma)G_{P,i}^{(r)}\odot\Delta P_i^{(r)},
\qquad P_i^{(r+1)}=P_i^{(r)}+D_i^{(r)},\quad i\in\{A,B\}.
\]

ΔP是候选方向，D是实际生效的状态增量。gate与候选方向的尺度可以互相补偿，因此原始ΔP的数值没有唯一的物理解释。P及这些增量都是每个样本的激活，优化器训练的是产生它们的权重，不是为每个视频保存一组可训练P。

参考张量P／候选ΔP／有效D均为`[B,N,1664]`，更新gate为`[B,N,1]`，η按`[B,1,1]`广播。P只在同一原生空间中做残差更新；不把临时工作量Z或3072维hidden重新命名为P。

每次corrector的具体操作为（所有可训练 attention、LN、投影、条件和门控均属于位置 i；固定几何编码可共用）：

\[
U_i=W_i^{read}\operatorname{LN}_i^H(H_i)+b_i^{read},\qquad C_i=e_\sigma+e_i+e_\ell,
\]
\[
R_i^{(r)}=\operatorname{Attn}_{read}\!\left(Q=\operatorname{LN}_q(P_i^{(r)})+E_P+C_i,\ K=\operatorname{LN}_{kv}(U_i)+E_H,\ V=\operatorname{LN}_{kv}(U_i)\right),
\]
\[
O_i^{(r)}=g_{read}(P_i^{(r)})\odot R_i^{(r)},\qquad Z_i^{(r)}=P_i^{(r)}+O_i^{(r)}+E_P+C_i,
\]
\[
Y_i^{(r)}=\operatorname{LN}_i\!\left(\operatorname{StateCore}_{i,1664}(Z_i^{(r)},W_c c+b_c)\right),
\quad\Delta P_i^{(r)}=W_\Delta Y_i^{(r)}+b_\Delta,
\quad G_i^{(r)}=\operatorname{sigmoid}(w_G^\top Y_i^{(r)}+b_G).
\]

Read为3072→1664，只改通道，U 保留 N_H 个 token；候选头为1664→1664。P 查询 U 的交叉注意力输出 N_P 个 token。每个位置自己的读取门是 LN→1664→1→sigmoid，线性权重初始化为零、bias=-2，初始约0.119。StateCore 保留两个不同参数的标准pre-LN Transformer block，每个包含1664维自注意力、文本交叉注意力、`1664→6656→1664`的GELU MLP；26个注意力头，每头64维。两路 P/H 注意力也采用1664维／26头，不同 A/B 位置各自独立，只在同位置内部迭代和跨去噪步复用；B1 冻结全部 A 核心，训练 B 的完整核心与读写。空间／时间位置编码固定，σ由1664维固定正弦输入经`1664→1664→1664` MLP（两层线性、中间SiLU）得到；位置类型embedding为2×1664。

各独立 A／可选 B 的 H 通道投影 U_i 只在本次 corrector 入口计算一次；内部每轮都以更新后的 P 重新查询同一个 U_i，得到新的门控 observation。cell内LayerNorm作用在计算分支，不对持久P直接重置／归一化。先r=1，迭代增加必须单独验证；重新查询不等于获得新的 Wan 层观察。

两路注意力均为全局非因果形式；P 和 H 不先拼接成一个序列。E_P 与 E_H 分别按各自真实时间、映射到教师 letterbox 后的空间位置编码，位置／条件进入 Q/K，V 来自内容。注意力取消了 N_H→N_P 的固定插值约束，但仍需要这些坐标区分“哪里、什么时候”。教师均匀抽帧、P 与教师的原生网格及损失对齐不变。

P 初始化改为条件查询网络：文本 [B,L,4096] 经初始化器独立文本投影到 1664，再经 LN／投影到 512；独立首帧 [B,48,1,h,w] 展平后经 LN／48→512 并加入图像位置。带类型编码的两类条件构成共同 Key/Value，覆盖完整 P 网格的 query＋时空位置经过两层 512 维、8 头全局自注意力／条件交叉注意力／FFN，最后经 LN 和 512→1664→GELU→1664 得到 FP32 P₀。图像坐标与 P 查询使用相同 letterbox 坐标系。

可训练 query 和位置投影属于网络权重，训练后从 checkpoint 恢复；每次 forward 不采样随机未来槽。所有时间位置读取全部文本与首帧。固定输出规格提供帧数、时长和空间位置，不提供真实未来值。相同文本／首帧／规格在确定性模式下得到相同 P₀，不同视频噪声通过后续 H 交互影响生成。

**原生宽度与初始化内部宽度需要区分。** 持久 P、StateCore 与 ΔP 更新头保持完整 1664 维。条件初始化器为限制新增成本使用 512 维内部网络，但输出头先升至 1664，再做非线性与 1664→1664 映射，不使用一个固定 512→1664 线性输出子空间约束所有状态。该选择仍有容量取舍，不能据此宣称已恢复教师的全部信息。

### 4.3.2 写入必须使用实际更新后的P

为避免“辅助P拟合正确、真正写入绕过P”，首版固定如下数据依赖：

~~~text
H_i → 当前类型的读取投影 U_i → P 查询 U_i → StateCore(P_i, 文本, sigma)
                              ↓
                        候选ΔP、gate
                              ↓
                    实际更新后的P_i^+
                       ↙             ↘
               直接P^+ → L_struct      U_i 查询 P^+ → 当前类型写入 → ΔH_i
                                           ↓
                                    Wan后续层 → 视频损失
~~~

\[
S_i=\operatorname{Attn}_{write}\!\left(Q=\operatorname{LN}_q(U_i)+E_H+C_i,\ K=\operatorname{LN}_{kv}(P_{i,valid}^+)+E_{P,valid},\ V=\operatorname{LN}_{kv}(P_{i,valid}^+)\right),
\]
\[
Z_i=\operatorname{LN}_i^{write}(S_i),\qquad
\Delta H_i=\gamma_i(\sigma)\operatorname{sigmoid}(a_i(Z_i))\odot W_i^{\rm out}Z_i,\qquad H_i'=H_i+\Delta H_i.
\]

S_i 保留 H 查询的 N_H 个位置，writer 只需1664→3072通道投影，直接得到同形 ΔH，不再用 \(\mathcal U_i\) 插值。valid 指剔除教师外层 letterbox 全补黑 patch 后的位置，部分内容覆盖 patch 保留；只依赖输出几何，推理无需 GT。P 自身仍保留完整 N_P 个 token，损失仍按真实内容面积加权。纯补黑通过自注意力的间接影响并未被完全消除。

写入矩阵不带bias并从零开始。H 的投影只作为写注意力的 Query，Value 来自实际提交 P；没有把 H 内容再直接残差相加到 S_i 的旁路。H 可以选择 P 中需要的信息，这不等于 P 中每个通道都是物理量，也不能单独证明修改有益。两路注意力是独立参数，读取关注“P 需要什么观察”，写回关注“H 需要什么先验”，不强制二者注意力矩阵互为转置。

相比插值相加，双向注意力可以学习跨时空的信息选择，适合不同分辨率和感受野的 P/H；原方法则有固定局部对应、较省计算和较少参数的优势。本版采用门控双向注意力作为默认，并保留旧 fusion 的明确兼容路径。不能宣称注意力一定优于加法；仍须在相同数据与生成设置下对照有效性、画质、状态漂移和成本。[Perceiver IO](https://arxiv.org/abs/2107.14795)是查询式读写的结构参考，并非本任务收益证据。

本步B提交的P_i^+既被本步写入消费，又作为P_next传递；否则若它仅在下一步使用、训练又每批detach，B的状态增量就可能只学辅助特征而收不到实际视频任务梯度。

### 4.4 计算契约

对 K 个正常噪声步，采用原生两路 CFG 时：

- 每个噪声步有条件 Wan 前向一次，无条件前向一次；
- 每个分支中的每个原生 block 在该步仅经过一次；
- StateCore 可以有额外小规模运算；
- scheduler 每步只提交一次；
- 不额外回跑已执行的早层或尾部。

因此完整 Wan 前向数仍约为 2K，而不是因内部轮次增长到 2K＋额外重算次数。实际耗时仍会增加小单元、投影和观察成本，不能把“不增加 Wan 次数”写成“没有额外成本”。

## 5. 前期怎样学习和优化结构

### 5.1 推理时的优化是学习到的 latent 更新

\[
P^{(r+1)}
=P^{(r)}+s_i\eta(\sigma)\,
G_P^{(r)}\odot\Delta P^{(r)}.
\]

StateCore 以同一首帧、文本、当前真实特征和当前 P 为条件，使用当前位置自己的权重进行一到少量状态更新，然后提交一次特征写入。它不是推理时使用 GT 反向优化，也不产生多个计划让评分器选择。

同一条件下，不同 seed 的单次初始噪声可以形成不同合法过程；每次请求仍只有一条活动轨迹，不另开计划采样分支。结构更新强度和轮数须经校准；门值和范数不能被解释成物理正确性概率。

当前新配置的 ΔH 写回额外乘 early=0.1+0.9×clip((1−sigma)/0.1,0,1)，仅减弱极高噪声写回，不抑制 P 本身更新。该系数不是可靠性概率或 ΔH/H 的范数上界；多次调用的累计影响仍需评价。

A的s_A固定为1。新增B时设 `s_B=tanh(b_B)`、b_B初始化为0，同时W_B^out初始化为0，使B在初始时既不改当前H，也不改传给下一步的P。只把ΔH_B置零仍可能通过P_next改变整条采样链，因此不足以保证初始等价。b_B是B专属的一个可训练标量，包含在参数预算中。

### 5.2 优化必须有监督目标和能力验证

冻结 V-JEPA 2.1 对同一 GT 视频编码，为实际 P 提供稠密时空表征目标。其空间定位与时间一致性使它适合作为过程表征教师；这是采用它的依据，不意味着每个 token 都是接触、速度或因果的真值。[V-JEPA 2.1 论文](https://arxiv.org/abs/2603.14482)

训练同时通过最终实际向量场和可读输出，约束这个P的写入是否产生正确过程。只增加L_struct时，GT教师前向可以离线缓存，无需对预测视频解码或对教师反传；当前 A1／A2 只用缓存教师目标，A3 启用 L_out 后才承担生成视频的解码及教师输入反传成本；L_align 不启用。

重点不是让小单元内部看起来“更合理”，而是优化之后：

- 角色和必要运动关系更容易成立；
- 接近与接触路径更可执行；
- 相关后果随前置条件变化；
- 视频确实执行，而不只是结构读出头分数提高。

直接对带噪隐藏状态进行可信表征对齐可借鉴 REPA；但通用图像表征并不自动包含物理交互知识，教师层与目标需要单独核验。[REPA](https://arxiv.org/abs/2410.06940)

### 5.3 不在纯噪声处逼迫唯一精确未来

单帧未必能确定初速度、质量和摩擦。同一描述也可以对应多种合法轨迹。早期监督优先采用条件充分的片段与可靠过程关系，不把一个 GT 的全部精确未来强压成唯一答案。

高噪声端点不可读时，先监督隐藏过程表征；实际输出的物理／细节监督只在经校准的可读噪声范围使用。不能把平均化、运动变小误当成结构更稳定。

完整 GT 教师目标可用于标准加噪样本的去噪表征学习，因为它只出现在损失端。接近纯噪声时，当前输入几乎无法确定该 GT 的具体未来，强逐 token 回归可能偏向条件平均。首版对 L_struct 使用固定噪声权重 g_s(σ)，在纯噪声端降为零、离开该端后逐渐增强，并对 λ_s 做训练 warmup；具体范围通过分噪声桶和跨 seed 多样性消融校准。corrector 的 Wan 深度与 σ 噪声阶段是两个不同维度；A 覆盖六个深度，不能把 A 类型等同于高噪声阶段。

### 5.4 沿去噪时间先建立基础，再启用中期增量

首版采用固定、离线校准的噪声交接点σ_h；σ从1向0下降。以B位置为新增中期能力，定义无可训练参数的启用系数：

\[
q_B(\sigma)=\operatorname{clip}\!\left(\frac{\sigma_h-\sigma}{w_h},0,1\right),
\qquad 0<w_h<\sigma_h<1.
\]

在既有公式中使用有效调度`η_B_eff=q_B·η_B`、`γ_B_eff=q_B·γ_B`。下文η／γ在执行公式中均指包含该启用策略的有效值；它们不与损失侧g_s／g_o混为一谈。q_B=0时直接旁路整个B，H、P及已有缓存保持原样；q_B>0后平滑启用。后期η／γ仍按开发集校准以限制不必要的结构重构，不能把残差小当成正确性保证。

| 去噪阶段 | corrector block的职责 | 基础准入／保持要求 |
|---|---|---|
| 高噪声到交接点之前，σ≥σ_h | A形成并多步完善过程基础；B完全旁路 | 不能在纯噪声处宣称具体GT未来已确定；检查分σ能力与合法多样性 |
| 交接后进入中期 | A继续使用P；B读取经过原生层执行的新特征，完善尚不确定的关系与细节 | 使用已通过基础验收的检查点；中期增量须低破坏且有净收益 |
| 低噪声后期 | 同类模块继续受控细化 | 保持角色、身份、必要交互和动作顺序，评价接触边界、形变、残留等 |

σ_h和w_h在开发阶段选定并记录，不能仅按“前20%步”猜一个普适边界，也不在每条推理中用teacher／verifier决定是否通过。应选在关键过程已具备较高可执行性、同时还留有足够修正步数的区间；若找不到这样的交接区间，应改进基础阶段或能力配置，而不是声称中期有可靠地基。

**B1的前缀保持条件：** 与通过验收的A-only基础检查点使用相同初始噪声、条件、初始化参数及A实际访问的全部权重（含各自核心、条件投影与位置嵌入）、原生Wan、σ序列、CFG、scheduler状态和确定性执行模式；B在所有σ≥σ_h的函数求值中严格旁路，且不改变RNG或缓存。这样可按采样步骤归纳，交接前的`(z_k,P_k,scheduler_state)`与基础模型一致，实测以适当数值容差验收。这保护的是已经学到的早期前缀，而不是断言其全部物理语义天然正确。

仅冻结A权重不够：若B在高噪声阶段写入z／P，后续A看到的输入已改变，早期轨迹仍会漂移。交接后即使A冻结，也会读取新的P和z，因此中后期语义保持仍须验证。AB解冻初始化器／六套A会改变前缀，故改为可选研究分支；必须重新通过基础能力和破坏率验收，不能沿用B1的前缀一致主张。

训练中A1／A2仍覆盖原生合法噪声路径；B1的优化样本优先来自q_B>0且损失可用的σ范围，这是显式改变训练σ分布。关闭B的高噪声视图只作监测，不给冻结前缀“假装训练”；整批无可训练有效路径时跳过backward和optimizer更新。此设置不增加参数、teacher调用或生产Wan重算。

## 6. 在已验证基础上顺序完善，保留修正残余结构偏差的能力

### 6.1 “地基”是软约束，不是不可修改的第一次预测

中期以已经过基础验收的模型为起点，优先保留已成立的身份、角色和前后关系，并依据更清晰观察修正：

- 接近路径和交互位置；
- 接触／支撑成立的细节；
- 响应开始的时刻与相关位移；
- 原位置残留、数量与身份连续性；
- 影响整个过程的局部几何偏差。

这不是只改纹理，也不是每次重新规划整段视频。更新是否保留正确关系，靠过程与实际输出监督验证，不靠“小残差一定安全”的假设。

### 6.2 “没有发生碰撞”的具体处理

主要工作情形是：早期已经形成红球接近蓝球的可执行路径，主动／被动角色、数量和先接触后响应的关系正确；中期corrector block根据更清晰特征细化接触帧、边界、形变及响应幅度，并验证这些关系未被破坏。

若当前B观察到残余路径偏差导致接触没有成立，B 自己的核心仍可更新P和相关特征，让后续层有机会修正。这是保留的容错能力。若大量样本从一开始就角色颠倒、凭空复制或完全没有接近路径，应判定基础阶段未过关，不能以不断增加中期迭代代替基础训练。

本步生成继续向前，下一正常噪声步自然读取更新后的 P。**不跳回本步 A，不重新调用完整 Wan，也不多跑一次尾部。**

视频是整段 latent 联合生成的，因此中期可以共同调整视频时间轴上的接触前、接触中和接触后；“下一去噪步”不等于“下一视频帧”。

### 6.3 能力边界必须承认

这条路径比最后几步只改局部纹理更有调整空间，但不保证任意严重早期错误都能在固定预算内纠正。

若角色、布局和运动拓扑同时严重错误，优先改进早期训练、数据与写入能力。剩余噪声步少、接口容量不足或教师看不清问题时，仍可能失败。失败结果计入评估，不以重启和候选选择逃避。

## 7. 后期细粒度完善与物理重点

后期以保持过程关系、改善接触边界、轮廓、形变和残留为主，抑制大范围结构重构。需要继续观察静止支撑、原位置和背景，不能只看移动主体。

本地 Wan2.2 TI2V-5B 的 VAE stride 为 (4,16,16)，DiT patch 为 (1,2,2)。只看进一步池化的 token 容易遗漏短接触；优先读取原生网格信息，通过局部重排／小投影保留子网格与通道细节，而非引入 RAFT。

四个问题由当前 corrector 的计算承担：

| 问题 | 实现依据 |
|---|---|
| 哪里与现象有关 | 当前文本与视觉特征交互，训练时使用可靠软区域参考 |
| 哪里对过程重要 | 关键交互及其前后上下文，包含作用双方、来源去向和腾空位置 |
| 哪里需要改 | 当前实际观察与过程条件的差异，由结果监督学习 |
| 怎样改、多大强度 | 带符号的特征更新和门控，通过下游实际输出反传训练 |

重要位置不一定有错；已经正确的接触不应被强制大改。训练权重保留背景底座，可靠性与重要性分开。ProPhy 式信号可作相关区域参考，不作为真实接触、力或修改方向真值。[ProPhy](https://arxiv.org/html/2512.05564v2)

首版不在每个接口反复解码视频。当前步的完整端点在输出头之后才出现，不能在 B 提前使用它而不付出额外计算。训练可为输出监督解码；推理可按需读取上一正常步记录，但必须标明其噪声时效。

## 8. 反馈是什么，不是什么

### 8.1 三种循环不能混称

| 计算形式 | 是否看到了新的主干结果 | 当前决定 |
|---|---|---|
| StateCore 在固定观察上更新原生维度工作状态 | 没有新的完整 Wan 结果 | 允许，但称为 latent 内优化 |
| A 写入后自然计算到 B，B 读取当前真实特征 | 看到了后续原生层的实际处理结果 | 主线 |
| 下一正常噪声步读取新特征与更新后的 P | 看到了正常采样进程中的新观察 | 主线／可选观察缓存 |
| 同一噪声步更新 P 后重跑完整 Wan | 有新完整结果，但成本高 | 删除 |

H_B 与 H_A 的差异同时包含层深变化和正常网络计算；跨噪声步的端点差还包含去噪变化。没有反事实对照时，不能把这些差值称为“本次修改的纯因果效果”。

### 8.2 主流程伪代码

~~~text
z ← 一次初始噪声，固定首帧 latent 槽
P_cond ← Prior(正向文本, 首帧, 时空规格)
P_uncond ← Prior(负向/空文本, 首帧, 时空规格)

for 每个正常噪声步 k:
    for branch in (cond, uncond):
        H ← Wan patch embedding(z)
        for block_index = 1 ... 30:
            H ← Wan block(H, 当前分支文本, sigma)
            if block_index % 5 == 0:
                H, P_branch ← 同一套 A corrector(H, P_branch, 文本, sigma, 深度)
            if 使用B and block_index == 18 and sigma < 0.65:
                H, P_branch ← B corrector(H, P_branch, 文本, sigma, 深度)
        v_branch ← 原生 Wan 输出头(H)
    合成 CFG 向量场
    scheduler 前进一步，恢复首帧约束

解码并输出同一条视频
~~~

所有内层小循环均禁止调用 Wan 或 scheduler。条件先验和各位置独立单元的相关能力必须通过预测、控制和输出实验验证。

## 9. 统一corrector block的状态与实际写入怎样接受监督

两者都需要监督，但“需要监督”不等于都需要错误视频或独立大网络。

### 9.1 每个corrector更新后的P：直接原生GT监督

冻结V-JEPA 2.1，从同一样本固定GT视图提取最后层原生特征。P始终与该目标同维、同坐标；监督端不存在可训练映射。Wan读写映射属于生成执行路径，不改变目标值。

| 接口 | 基准决定 |
|---|---|
| 主教师 | V-JEPA 2.1 ViT-G/16 384，`vjepa2_1_vitG_384.pt`，`target_encoder` |
| 编码器 | 官方2.1 `vit_gigantic_xformers`，完整未随机mask的RGB；不需要predictor |
| 教师状态 | eval且权重冻结；GT可no_grad／缓存，本任务不更新EMA |
| 输出 | 最终层零基47、1664通道，保留教师自带LN |
| P、ΔP、D | 教师原生token网格、1664通道，所有位置及去噪步相同约定 |
| 结构比较 | 直接`P_after`与固定`F_GT`逐通道MSE，FP32计算 |
| 禁止的目标处理 | 学习投影、默认池化、额外通道L2归一化；不把GT映射进Wan |
| Wan读写 | Read 3072→1664；P 查询 H 更新，H 查询 P 写回；writer 1664→3072；无读写插值 |

\[
F_{GT}=\operatorname{sg}[\Phi_{\mathrm{VJ2.1}}^{last}(Q_\xi(x))],\qquad
L_{struct}=\mathbb E\!\left[g_s(\sigma)\sum_{i\in\mathcal I}\alpha_i
\frac{\sum_u\rho_u w_u\|P_{i,u}^+-F_{GT,u}\|_2^2/1664}
{\sum_u\rho_u w_u+\varepsilon}\right].
\]

**监督每个启用corrector最终提交后的P_i^+。** A-only／B旁路时，六次 A 调用的损失取均值；A／B均启用时先按类型内取均值，再令两个类型各占 1/2，避免调用次数改变类型间权重。内部多轮默认只监督该corrector最后一次提交态；P_before用于同目标下前后误差诊断，若它是上个corrector输出，已在上个位置监督。同一视图内部不detach更新链。B1 冻结 A 权重；B 之后的 A 状态损失仍能经过冻结核心向上游 B 传梯度，B 前的 A 项才只作监测。

16帧384视图中，GT原生输出`[B,4608,1664]`可逆还原为`[B,8,24,24,1664]`，P的初始化、前态、后态以及增量均是这个形状。H是`[B,N_H,3072]`。张量同形只是必要条件；教师模型／权重／层、时间戳、裁剪、token顺序与目标上下文必须相同。

P网格由生成请求可复现的视图规格构造，推理不需要未来GT值。首版固定经审核的384方形全过程视图；16帧是接口示例，长事件必须保留足够上下文。坐标按teacher patch／tubelet、Wan grid_sizes、因果VAE首帧及后续时间分组连接；不按索引强行相减。长视频重叠窗固定目标归属，裁完整teacher token不等于裁视频重新编码。详见[坐标与状态审查](20260909-D-完整实现前不确定性与监督根因审查.md#4-每个corrector的p到底如何对齐和更新)。

ρ首版为审核有效mask，w=1；不由学生gate控制。目标无效位置预先填安全值，有效位置非有限数应定位故障；σ和样本归一化见E第11.6节。在纯噪声端不能强迫唯一GT未来。

直接监督取消了R与P共同重参数化、固定低秩读出和目标额外压缩造成的歧义。它不能取消教师本身／取帧的盲区，或保证生成器从信息不足的输入准确预测未来。需要比较P误差、常量目标基线、分现象关系及实际视频；同维不等于物理正确。固定干净教师对带噪学生的监督有[REPA](https://arxiv.org/abs/2410.06940)先例，但本方案效果必须独立验证。

教师配置变化必须同时重建P宽度、全部相关映射和缓存。官方G中间层列表为`[11,23,37,47]`，多层拼接6656维不能当单层1664维；蒸馏L为1024维且键不同。[官方模型接口](https://github.com/facebookresearch/vjepa2/blob/main/src/hub/backbones.py)

### 9.1.1 初始 P 是否一定需要独立监督

不需要独立损失才能获得梯度。普通视图的 L_struct 经 P_after→P₀ 训练初始化器；writer 非零后 FM／L_out 也沿真实输出路径训练它。初始零 writer 会使该时刻纯 FM 对初始化器的梯度为零，但结构监督仍有路径。暖起携带状态若 detach，则必须单独讨论该步初始化器是否参与训练。

当前加入可消融的 L_prior：分别对 P₀ 和固定教师 T 在每个时间槽内按有效内容面积做空间平均，保留全部时间顺序，计算加权 MSE。默认系数 0.02×前 200 步 warmup，不依赖 sigma；设 prior_weight=0 可移除。它旨在明确训练条件先验的整体／粗时序语义，避免初始化器完全依赖后续 H，不声称能单独保证每个空间位置的细节。

训练 GT 提供 JEPA 目标、Wan 加噪输入，并在保留 GT 条件的 step 通过干净 VAE latent 参与 P₀ 初始化。无 GT step 的初始化器同样接受 L_prior、L_struct 和生成损失训练。暖起默认关闭；主动开启时只生成一次 P₀，暖起从其 detach 副本出发，原 P₀ 保留 L_prior 梯度；关闭该项则暖起步排除初始化组更新。稠密细节仍由各更新态 L_struct 监督。

### 9.2 corrector：监督写入后的实际结果，不只监督它的建议

corrector 没有现成的“正确 ΔH”标签。这里不编造这种标签，而是采用结果监督：

\[
H'_B=H_B+\Delta H_\theta,\quad
v=\operatorname{Head}\!\left(F_{>B}(H'_B)\right),\quad
\hat z_0=z_\sigma-\sigma v.
\]

首版训练中，v 是正常条件分支的预测。这里的端点确实来自写入后的原生输出头，但仍只是当前噪声处的干净样本估计，**不是完成全部采样后的最终视频**。不为了得到这个训练目标额外展开完整采样链。CFG 与多步采样可能带来差异，因此验收必须运行部署协议下的完整视频，不能用单步端点成绩替代。

经过原生后续层和输出头得到预测，再对其可读视频表征与同一样本的 GT 表征比较。梯度路径为：

~~~text
GT 表征与实际输出的差异
→ 冻结教师对生成输入的梯度
→ VAE／原生输出头与后续 Wan
→ B 的真实特征写入
→ corrector 的方向、门控和位置独立更新参数
~~~

只让 P 预测正确、只回归门控热图、或只监督模块想象中的修改，都不等价于上述路径。

这监督的是“修改后应接近什么”，不是现成的正确修改方向标签。方向与门控从实际下游误差中共同学习：重要但已正确的位置可以少改，需要协同调整的多位置可以一起改。首版不再增加门控 BCE、残差真值回归或逐轮单调性损失。

### 9.3 当前损失与阶段

当前总损失为 `L_FM + λ_struct L_struct + λ_prior L_prior + λ_out L_out`。

| 任务 | 监督落点 | 当前作用 |
|---|---|---|
| L_FM | 标准 GT 加噪路径上的原生向量场 | 训练真实写回及正常视频生成 |
| L_struct | 每次调用提交的原生稠密 P | 学习教师表征，类型内／类型间分别平均 |
| L_prior | GT／无 GT 条件下单次预测 P₀ 的固定空间池化结果 | 小权重约束独立条件先验，保留时间次序，可消融 |
| L_out | 加入真实写回后的单步干净端点经 VAE／教师的特征 | A3 起在可读噪声区间稀疏执行 |

L_out 使用正常 GT 加噪视图的端点，预测分支保留输入梯度，教师权重冻结。当前默认 out_weight=0；A3／B1／AB 为 0.1，每四步在 sigma∈[0.05,0.4] 使用一次。这不是删除某层 ΔH 后的反事实差值；逐调用反事实只在离线归因入口执行。

### 9.4 文本条件与匹配任务边界

当前 v4 不训练 L_align 或匹配头。文本通过条件先验与 StateCore 文本交叉注意力影响 P 和视频，不能把未对齐的 V-JEPA token 与 UMT5 token 直接作余弦。历史版本中的文本匹配任务属于已撤回的执行路线，不能把它当成默认 A1 的必要准备。

### 9.5 如何判断 correct 是否真的正确

不承诺每次修改都正确。需要在固定开发集上，离线对比同输入、同 seed 的启用／关闭 corrector，并完整统计两组结果：

- 改善率：原本未正确执行的案例中，有多少得到改善；
- 破坏率：原本正确的案例中，有多少被改坏；
- 联合成功率：完整执行且物理关系合理；
- 目标错误、数量／身份和画质的变化；
- 相同 Wan 前向数及实际耗时下的收益。

这是研发对照，不是每次推理生成两条后选好的那条。对照指标不能只使用训练教师自评分，还需要独立人工或独立评价依据。

还需防止把普通联合训练收益误称为修正收益：先固定已学好的六套 A、P₀ 初始化器和原生 Wan，仅训练完整独立 B（核心与读写），观察该插入是否产生净改善；再联合微调，并同时比较上一检查点和本模型关闭 B 的结果。只关闭一个共同训练过的模块可能引入分布变化，不能独立完成归因。

在展示前固定“正确／改善／破坏”的评价口径与容忍范围，按输入／场景聚合不确定性。训练教师 loss 降低、门控较小以及最终绝对成绩较高，都不能单独证明 B 修复了原来的错误。

所以当前能建立的是“参考可信 → 真实写入可训练 → 完整结果有净收益”的经验性证据链，而不是逐样本、逐轮的数学正确性保证。只用正常视频训练时，对严重离轨状态的可恢复性尤其需要单独报告。

### 9.6 中间P与各类增量如何接受监督

| 对象 | 直接标签／目标 | 实际采用的训练方式 |
|---|---|---|
| A提交的P_A^+ | 对齐后的同源GT教师T | L_struct直接监督；FM／输出／文本损失经写入反传 |
| B提交的P_B^+=P_next | 同一个固定T、同一原生坐标，直接比较P | L_struct直接监督；本步真实写入使输出损失也训练其更新 |
| 内部P_i^(r) | 可以复用同一T | 首版只监督每个接口最终态；必要时给少数内部态低权重深监督 |
| 候选ΔP和有效增量D | 没有逐轮GT增量 | 监督P^-+D后的状态和视频结果，不把teacher状态直接回归给ΔP |
| ΔH_A／ΔH_B | 没有“正确Wan残差”标签 | L_FM、可读范围L_out通过实际后续Wan反传 |
| gate、b_B、读写投影、StateCore权重 | 没有正确度热图或参数标签 | 由上述任务联合训练，不把gate当物理正确概率 |
| H_A／H_B本体 | 首版不另设teacher逐层标签 | 保留原生表示自由度，通过实际输出训练必要适配 |

对一个加法更新，\(\partial L/\partial\Delta P=s_i\eta_iG_P\odot\partial L/\partial P^+\)。对首版逐token标量gate，还须沿通道求和：\(\partial L/\partial G_P=s_i\eta_i\sum_c\Delta P_c\,\partial L/\partial P_c^+\)。其中L可包含更新后P的结构损失和所有经过写入的输出损失；没有单独L_delta，也可以训练出更新方向。状态内部循环不能在每轮间detach，否则更早增量到后续结果的梯度会断开；跨去噪训练视图的截断则要显式声明。

V-JEPA的 `T(τ+1)-T(τ)`描述视频时间变化，不能当成“当前去噪迭代需要改多少”的标签。现在P与目标同为1664维，`F_GT-P_before`是可计算的当前特征剩余误差；`||P_before+D-F_GT||²=||D-(F_GT-P_before)||²`。这已经由更新后P的MSE实现，不另加L_delta，不把剩余误差叫作真实物理力，也不除以可能为零的gate去造候选ΔP标签。右式若detach P_before，会改变传向前面cell的梯度，不能声称等价。

不要求每个内部态都与最终T同等接近，不增加逐轮强单调下降或强制非零增量损失；中间计算可能需要临时改变表示，正确状态也应允许零更新。小幅度、梯度非零、teacher误差下降都不能保证实际视频改善。

### 9.7 逐corrector验证状态更新与真实写入的收益

每个位置都要区分可训练、被使用和有净收益。单项backward检查只能证明梯度路径；最终全模型成绩也不能单独证明每一位置的ΔH正确。基准保留A-only训练、B1固定六套 A 与先验、只训练完整 B，以减少共同补偿的混淆；可选联合AB重新验收。

固定同一checkpoint、样本、σ、文本、随机数和缓存，复制完全相同的corrector前H_i／P_i^-，使用相同实际后缀比较：

| 归因对象 | 启用分支 | 对照分支 |
|---|---|---|
| 本次ΔH写入 | 后缀(H_i+ΔH_i, P_i^+) | 后缀(H_i, P_i^+) |
| 整个corrector | 后缀(H_i+ΔH_i, P_i^+) | 后缀(H_i, P_i^-) |
| 后续补偿 | 两分支均按固定后续corrector策略运行 | 另做两分支均旁路后续corrector的诊断，不能混合比较 |
| 跨步P作用 | 从相同前态继续完整有更新采样后缀 | 从相同前态继续无该更新后缀 |

合法GT加噪视图中分别计算各有效输出误差的`gain=loss_without−loss_with`，正值才表示该度量下的改善；不能只报梯度非零。自由采样用任务／物理关系和画质评价，不与单一GT未来强做逐token对应。所有结果包括失败与破坏；独立评价不只复用训练teacher。

这项逐位置对照为必做的离线研发验收，至少增加相应负分支后缀／教师计算，位置更多则成本增加；它不变成默认训练排序loss或生产候选筛选。需要的完整克隆状态和证据范围见[根因审查第7–8节](20260909-D-完整实现前不确定性与监督根因审查.md#7-δh及hδh为什么没有唯一gt如何训练)。H_i+ΔH_i不另设伪造隐藏GT，以实际后缀输出判断它是否可执行且有益。

若某位置仅有结构读出下降或最终收益依赖后续补偿，应按实际证据描述；持续无效或有害则改该位置／writer或删除它，不以全局总分替它证明。原正确关系保持、破坏率、全量联合成功、质量、多样性和成本仍是最终验收，当前不具备逐样本逐轮单调改善的数学保证。

### 9.8 将监督落到训练代码的共同约定

当前单步训练、掩码／噪声归一化和梯度处理以 [v4 实现方案](../../v4/20260909-D-原生P校正器训练与推理实现方案.md)及实际代码为准；E 文档保留历史研究方案，不作为当前四项损失或匹配头的执行要求。本D的架构实现须满足以下约定：

| 环节 | 必须实现的行为 | 要避免的问题 |
|---|---|---|
| 状态记录 | 保存本次实际P_before、候选ΔP、有效D、P_after和ΔH；writer与L_struct读同一个P_after | 辅助副本被监督，实际路径未被约束 |
| GT条件边界 | 训练可用干净 GT latent 辅助初始化，同时训练无 GT 路径；JEPA token 只作为标签 | 训练只依赖 GT，部署缺少输入且没有对应路径训练 |
| 原生任务 | 依照I2V首帧和padding规则计算FM；端点只恢复允许的首帧 | 已知区域错误加噪／重复监督，或贴回未来GT |
| 实际输出任务 | 按σ选择可读端点；保留VAE／教师输入梯度，当前无匹配头 | 预测分支意外断图或局部窗口标签不成立 |
| 归一化 | 先有效token再样本／状态；固定σ衰减不被重新归一化抵消 | 增加深监督点或减少抽样后悄悄改变loss尺度 |
| 无效／异常 | 无有效辅助目标时返回图兼容零值并跳过昂贵编码；有效区域NaN须定位 | `0*NaN`传播、零标签伪装未知、掩盖数值错误 |
| 阶段切换 | 重新核对冻结组与optimizer成员，清除残留梯度，验证每个独立 Parameter 只注册一次 | 名称上冻结A，实际仍更新它或重复计数 |
| 状态与计算图 | 同视图无detach、不原地覆盖P；checkpoint重算不提交全局状态 | backward版本错误、重复修改状态、跨视频串用P |

单次调用的 L_struct 不经过该次写回；六个独立位置顺序执行后，后续位置的 L_struct 可以经 H→Read 回传到较早调用的 writer。因此较早位置的独立 writer 也可能收到结构损失梯度，但这只约束后续 P，并不直接证明生成视频改善；FM／out 才经实际输出约束写入。结构监督无R；冻结教师只传递输入梯度，不更新权重。B初始化时部分上游梯度为零是预期，需在受控起步更新后再验收；有效梯度也不等于已经产生物理收益。

单视图训练不展开完整CFG采样。生产推理仍按原有两分支和scheduler契约执行；每步损失下降能否转化为完整视频改善，必须用第9.7节的独立对照确认。这里补齐可执行的设计约定，不把训练入口、预训练教师实测或生成效果当作已经完成。

## 10. 只用 WISA／OpenVid 的训练实现

### 10.1 数据准备

视频按真实时间取帧，保留前因、交互和结果；训练与测试按源视频和场景隔离。先选择条件明确的碰撞、反弹和物体连续性片段，再扩展复杂手部、形变与材料过程。

教师参考只从同一训练视频提取。缓存记录源视频／分区、帧索引与真实时间戳、窗口上下文、裁剪与缩放、颜色归一化、padding 掩码、教师代码版本、权重校验值／编码器键、取层、网格变换和可靠性。先确定训练视图，再计算该视图的教师目标；改变随机裁剪、翻转或时间采样时重算或读取对应独立缓存，不能默认翻转缓存等于重新编码。

GT VAE 往返必须保留目标现象；教师提取必须能区分需要学习的过程信息。二者不满足时先修数据和监督，不先叠模块。

GT 全视频编码 token 可以携带前后帧上下文，这是监督标签的组成部分。推理输入不含未来 GT，训练有 GT／无 GT 两种条件；若做“只看历史预测未来”的能力测试，须对历史片段独立编码，不能先编码完整 GT 再截取其前几帧 token 充当历史特征。

### 10.2 分阶段训练

当前使用缓存范围内 1000 条有效训练视频，保留 200 条验证视频；三类 GPU 入口共享配置，slots_per_trial 控制卡数。默认 A1，六个 A 位置的完整参数分别独立。

| 阶段 | 内容 | 优化器步数 |
|---|---|---:|
| A1 | 独立条件初始化器＋六套完整 A；每次调用 1 轮；FM＋struct＋prior | 500 |
| A2 | 相同参数，每次调用 2 轮 | 250 |
| A3 | 在 A2 上增加 L_out | 250 |
| B1 | 冻结已训练先验与全部六套 A，训练 B@18 的完整核心与读写；prior 为冻结先验监测项 | 250 |
| AB，可选 | 全部新增参数联合训练 | 250 |

不根据 loss 自动晋级。B1 应以确实训练过当前先验的 A3 为基础；旧 latent 或 image_text 初始化权重迁入 image_text_gt 架构时，新初始化器须先在 A／AB 阶段训练，不能直接冻结。500 步用于快速观察，不代表充分训练或物理收益已经确认。

### 10.2.1 需要训练哪些模块、参数约多少

Wan2.2-TI2V-5B、VAE、UMT5和V-JEPA 2.1首版全部冻结。训练新增StateCore、条件先验初始化器、ΔP方向与gate、A／B读写适配、B状态缩放。没有独立P速度场，也不默认加入LoRA。

本地Wan为30层、隐藏宽3072、文本宽4096。原生P及StateCore宽1664，各位置核心为2个Transformer block（26头×64），4倍MLP；不同位置参数独立，同位置内部迭代和跨去噪步复用，无R。计入所有bias与归一化后的当前参数预算如下；E 文档旧预算不再适用。

| 阶段／组成 | 可训练参数 |
|---|---:|
| A1／A2／A3：独立初始化＋六套完整 A | 837,957,970，约837.96M |
| B1：完整独立 B 核心、适配及b_B | 136,224,516，约136.22M |
| AB 可选联合 | 974,182,486，约974.18M |

正式 A+B 新增权重为974.18M，其中初始化组（含独立文本投影）20,610,880个参数，每套 A 为136,224,515，B 为136,224,516。双向注意力与读取门每个核心各有22,182,785个参数。corrector 在各 rank 完整复制，全部权重约3.63 GiB；A／B／AB 加上活动组梯度和两份 Adam 状态约12.99／5.15／14.52 GiB，每卡预算未计 Wan／激活／通信。教师不进入推理；历史训练读出 R 已删除，此处 R_i 仅表示 attention 读取的临时激活。16 帧原生 P 持久状态采用 FP32，单个约 29.25 MiB；注意力通过 SDPA 和非重入 checkpoint 实现，六次调用增加计算与激活，不能沿用旧模型的显存预期。

这些是明确结构的预算，尚非完整v4的实测训练结果。映射和cell一起训练是可行的；B1训练独立 B 的完整网络，同时冻结初始化器和全部 A，容量是否够仍需验收，不能提前承诺提升。

旧 checkpoint 缺少 parameter_sharing 时保持历史 shared 架构；若要改为独立模型，须新训当前配置或在 A／AB 用 INIT_FROM 拆分复制全部兼容参数并重建优化器；仅拆分不清零 writer。旧 checkpoint 的 RESUME／推理按保存的参数归属与 fusion 执行，缺少 fusion 字段视为 interpolate。INIT_FROM 加法权重到新结构仅允许 A／AB：复用兼容权重、新建读写注意力与读取门，并将 A/B writer 和 B.b 归零，重新训练新写回接口；旧 latent 初始化迁入 image_text_gt 时替换先验；旧 image_text 迁入时只新增 GT 输入层。B1 必须加载已训练当前注意力的基础，不能冻结随机新模块。原 GT 缓存无需重做。

### 10.3 状态训练与推理差异

单噪声训练先由文本、首帧和可选 GT 视频条件预测 P₀，再结合当前特征更新 P。需要跨步状态时，可用两个标准 GT 加噪视图模拟有噪声标记的状态传递，每个视图仍有正确 FM 标签；这不是实际模型 rollout，必须如实报告差异。

若以后研究完整正常采样展开，不能给离开原直线加噪路径的状态沿用旧 ε−z0 标签。本版不将这种展开变成新的错误状态训练库，也不把它设为数据建设前提。

### 10.4 不能把普通视频对应误称为因果干预真值

两套自然视频中的变化提供重要统计与过程监督，但一般不是严格的受控干预数据。训练不得凭空补上精确质量、力或守恒标签。

因果能力的主张需要未见条件与前因变化的独立测试，而不是仅凭同一教师特征对齐成功。静止不是通用正确答案，合法多样性也不能被对单一 GT 的过强回归抹掉。

## 11. 逐项问题的作用与边界

| 现象 | 前期工作 | 中期顺序修正／后期完善 |
|---|---|---|
| 红球不动、蓝球自行运动 | 学好主体角色、必要运动和交互关系 | 联合修订路径与响应，不回头重跑本步早层 |
| 球拍未触球、球先飞走 | 过程目标包含交互前提，不只识别球拍名词 | 当前层修接触与起飞时序；必须同时看球拍、球与前后帧 |
| 书掉落后桌面又有一本 | 身份与连续移动进入过程学习 | 兼顾移动书和原位置；不能只增强运动主体 |
| 动作重复、过程不完整 | 全段过程监督与描述对应 | 更新整段 latent 的时序关系，不设固定事件计数 slot |
| 形变、穿模和伪影 | 先避免错误轨迹与不合适形变先验 | 细网格、几何上下文和实际输出监督；受 VAE／教师能力限制 |
| 源量不减、接收端增加 | 训练窗口覆盖源、途中和接收端 | 同一 P 关联多区域；普通视频不能提供精确守恒真值 |
| 初期已经严重走错 | 加强早期监督和控制能力，验证优化有效 | 中期可以修结构，但固定计算预算下不保证全部可达 |

## 12. 工程约束与预算

已核对的本地基础：[Wan 前向](/home/liuzhirui/model/Wan2.2/wan/modules/model.py:410)、当前 [P0 推理入口](/home/liuzhirui/Project/physGen/code/v3/inference/infer_trace_writer.py:649)。本轮没有训练或修改模型代码。

- 包装原生 forward，A、B 顺序执行，不采用递归模型调用。
- 推理时每分支、每噪声步的 block 访问次数必须有测试；禁止回溯早层和尾部重放。
- 冻结权重不等于禁止输入梯度，尤其输出教师／VAE 与 B 后的 Wan。
- 当前完整端点只能在输出头之后取得；缓存附噪声和层位置。
- 更新 P 影响下一正常步骤，并不意味着旧早层缓存仍可跨步骤复用。
- 先测量小单元、观察、训练输出教师的成本；主干调用数不变不代表墙钟时间不变。
- 采用一阶调度验证状态提交，再核对原多步求解器；对照必须同一求解器与 CFG 协议。
- 正式推理不需要 GT、视频教师、匹配打分器或修复数据集。

## 13. 研究借鉴与创新边界

| 来源 | 有价值的部分 | 不移植的结论／实体 |
|---|---|---|
| [REPA](https://arxiv.org/abs/2410.06940) | 实际带噪隐藏状态的可信目标对齐 | 不把普通图像语义直接当物理结构 |
| [V-JEPA 2.1](https://arxiv.org/abs/2603.14482) | GT 稠密时空 token 作为 P 的冻结监督目标 | 不把视频特征当精确物理量、文本 embedding 或逐位置正确性概率 |
| [RIN](https://arxiv.org/abs/2212.11972) | 将主要迭代放在紧凑 latent，并在数据与 latent 间读写 | 不照搬其完整生成骨干、latent 组织或论文速度提升 |
| [SCD](https://arxiv.org/abs/2602.10095) | 区分过程推理和反复渲染，检查冗余计算 | 原文研究自回归视频，不能据此直接缓存双向 Wan 全部早层 |
| [VACE](https://arxiv.org/abs/2503.07598) | 可训练时空条件适配 | 不复制大型编辑框架 |
| [TempAct](https://arxiv.org/html/2606.28016v2) | 全段与转移执行分开关注、避免硬条件切换 | 不复制独立 LLM planner、固定生成分段及 RL |
| [PHANTOM](https://arxiv.org/html/2604.08503v3) | 说明教师动态表征与视频耦合已有近邻 | “增加 physics latent”不能作为独立创新 |
| [ProPhy](https://arxiv.org/html/2512.05564v2) | 从可信视频提取相关区域的软提示 | 不把相关性当错误位置或真实物理强度 |

创新需要证明：前期优化确实产生可执行结构；中期顺序修正能保持正确关系并修复偏差；细粒度实际观察在相同主干调用预算下有净收益。小单元多迭代本身、soft gate 和多尺度特征都不足以单独支撑强创新。

使用 GT 的 V-JEPA 特征本身已有近邻，升级为 2.1 也不能单独构成创新主张。PHANTOM 使用视频／物理两个并行 latent flow 分支及相互注意力；本 D 保持单一视频流、原生 P、位置独立单元和顺序写入，不引入第二条 P 的流匹配采样链。架构差异需要通过与普通特征蒸馏及相同计算预算基线的对照证明价值，不能仅靠命名区分。[PHANTOM 方法](https://arxiv.org/html/2604.08503v3#S4)

## 14. 当前最终取舍

正确基础不等于永久冻结基础；中期结构修正不等于回头重跑骨干。我们将两者结合为：

**前期有监督地形成与优化过程 → 当前层读取实际状态并顺序修缮 → 下一正常去噪步接续新 P → 后期保持关系与细化。**

初始结构和 corrector 各有明确监督落点，实际写入必须通过输出验证。数据仅用 WISA／OpenVid，损失至多四项，不恢复错误视频配对，不以推理筛选或额外完整重算掩盖能力缺口。
