## 1. 核心流程

通过可信视频监督，先让去噪前期形成准确性较高且可执行的过程状态P，并通过独立验收；再在保持已学早期前缀的条件下，中期利用更清晰观察优化尚未确定的关系与细节。严重早期结构错误频发时先处理基础训练。

```text
当前噪声视频 zσ
→ Wan 早层
→ corrector block @ A：形成／优化或使用P，向早层写入一次
→ 原生中间层继续计算
→ corrector block @ B：交接σ前完全旁路，之后读取真实H_B并更新P／特征
→ 原生剩余层与输出头
→ CFG 合成视频速度
→ scheduler 推进视频 latent
→ P_next 传给下一正常去噪步
```

P 是过程条件与可更新的内部状态。它由首帧、文本、同一次视频噪声及当前特征形成，在 SharedCell 中更新并跨步传递；正式推理不输入未来 GT。

A／B是Wan内部的较浅／较深层位置，早／中／后期是去噪σ区间，两者不同。两处corrector结构均为“读取→共享核心更新P→实际P驱动写入”。SharedCell是模块内的共享核心，A／B的局部读写投影仍独立，不因更名而改变参数预算。

## 2. 模型部件

| 部件 | 职责 |
|---|---|
| 原生 Wan、VAE、文本编码器 | 提供视频生成、视频 latent 和文本条件 |
| 稠密过程状态 P | 保存当前视频的过程关系；时空位置明确，通道不预设物理意义 |
| corrector block | 统一的读取、P更新与特征写入模块类别，部署在A／B位置 |
| SharedCell | corrector内部共享的小型时空计算核心 |
| A位置适配 | 较浅层的局部读取／写入；先单独训练并验收基础能力 |
| B位置适配 | 较深层的局部读取／写入；在交接σ后启用，以完善已有基础 |
| 冻结V-JEPA 2.1 ViT-G/16教师Φ | 从同源GT提供最后层1664维稠密token目标；GT可缓存，预测视频分支保留输入梯度，仅用于训练 |

## 3. P 怎样形成、优化和传递

第一次根据可用条件低成本形成 P。前期在 A 的低维状态中进行少量共享更新：

\[
P_i^{(r+1)}=P_i^{(r)}+D_i^{(r)},\qquad
D_i^{(r)}=s_i\eta_i(\sigma)\,G_i^{(r)}\odot\Delta P_i^{(r)},
\quad i\in\{A,B\}.
\]

这里的优化是训练学到的前向更新，推理时不用GT反向求解。P／ΔP／D是每条视频的激活，优化器训练产生它们的权重。P宽256，更新gate是逐token的标量并广播到通道；s_A=1，s_B=tanh(b_B)。固定观察上多迭代几轮只增加计算深度，没有得到新的Wan观察。

A 向早层写入一次：

\[
H'_A=H_A+\Delta H_A.
\]

Wan 正常计算到 B，产生已经受 A 影响的真实中层特征。B 读取当前特征、P、原生细网格及可选历史观察：

```text
if q_B(σ) == 0:
    H_B', P_next = H_B, P  # 完全旁路，不生成B专属缓存
else:
    H_B', P_next = corrector_block_B(H_B, P, text, σ, context)
    # 内部先更新P，再由同一个实际P产生写入方向与gate
```

此后只计算尚未执行的原生层。新P_next既驱动本步B写入，又在下一正常去噪步进入A，不回到本步A。A的writer同样读取实际P，不能另走隐藏特征旁路。中后期A主要使用已有P作为软过程条件。

B加入时同时令写入矩阵W_B^out=0和b_B=0，保持当前隐藏特征及跨步P都不变。仅把写入置零不足以保证整条采样链初始等价；候选ΔP头和门控不能把所有乘法因子一起封死为零。

另设固定启用策略`q_B(σ)=clip((σ_h-σ)/w_h,0,1)`，σ从1向0下降，`0<w_h<σ_h<1`；B的η和γ都包含q_B。σ_h和w_h由开发集校准，不是每个视频的正确性自评分。M3a冻结基础权重、保持相同输入与采样协议并在交接前完全旁路B，才能使训练后的新增位置保持基础模型的早期z／P／scheduler前缀；仅冻结A不能保证这一点。

过程重要性、运动强度和特征修改强度分别评价。门值或残差范数不代表物理正确率，重要但已正确的位置可以少改。

## 4. 四项训练任务

仅使用 WISA／OpenVid 正常视频、描述，以及从这些视频得到的可靠教师目标。总目标至多四项：

\[
L=\lambda_fL_{\rm FM}+\lambda_sL_{\rm struct}
+\lambda_oL_{\rm out}+\lambda_aL_{\rm align}.
\]

| 任务 | 监督对象与用途 |
|---|---|
| L_FM | 正常 GT 加噪路径上的视频向量场，学习画面和动态分布 |
| L_struct | 实际路径的早期／更新后 P，让过程关系有明确表征目标 |
| L_out | 真实写入经后续 Wan 执行后的输出表征，训练修正效果 |
| L_align | 实际视频与描述的角色、动作及过程对应 |

视频 FM 使用：

\[
z_\sigma=(1-\sigma)z_0+\sigma\epsilon,\qquad
v^*=\epsilon-z_0,\qquad
L_{\rm FM}=\mathbb E\|v_c-v^*\|^2.
\]

结构监督使用同一GT视图的冻结V-JEPA目标，先按真实时间／空间对齐，再做通道L2归一化N；小型线性R将实际P从256维投影到1664维：

\[
T=\operatorname{sg}[N(\mathcal A_{\rm grid}(\Phi^{\rm last}(Q_\xi(x))))],
\]

\[
L_{\rm struct}=\mathbb E\!\left[g_s(\sigma)\sum_r\alpha_r
\frac{\sum_u\rho_u w_u\left(1-\langle N(R(P^{(r)}))_u,T_u\rangle\right)}
{\sum_u\rho_u w_u+\varepsilon}\right].
\]

M1只监督A的最终提交P；B启用的样本监督A与B最终P，初始α各1/2；B旁路时只选A且α=1。内部轮次仅按需少量深监督，不逐个Wan层配teacher层。16帧384视图示例可将教师`8×24×24`空间池化成`8×12×12`目标；实际按事件上下文选择长度，不能把VAE时间索引当teacher索引。GT与学生必须对应同一时间戳、crop和缓存版本。

ρ首版为审核有效mask，w=1；g_s在纯噪声处为0并按σ校准。监督权重固定，不能由gate调低以逃避训练。ΔP、有效D及ΔH_A／ΔH_B没有独立GT增量标签：通过更新后P及实际视频结果反传训练，不把teacher状态或相邻视频帧特征差当作去噪增量。

B 写入后经原生输出头得到条件速度 v_c，再形成当前端点估计：

\[
\widehat z_0=z_\sigma-\sigma v_c,\qquad
L_{\rm out}=\mathbb E\!\left[g_o(\sigma)
\frac{\sum_u\rho_u^o w_u^o\left(1-\langle\Psi_o(\widehat x_0^{\rm write})_u,
\operatorname{sg}\Psi_o(x)_u\rangle\right)}{\sum_u\rho_u^o w_u^o+\varepsilon}\right].
\]

Ψ_o是同一教师最后层经固定输出网格映射和通道归一化后的特征。该端点是当前噪声处的预测，只在教师可读且有有效输出梯度的σ范围与可信窗口监督；σ=0时这条端点路径不给速度梯度。完整采样效果仍需单独验收。冻结教师、VAE和Wan参数时，必须保留生成输入到真实写入的梯度。若L_out只是原生latent端点MSE，则等于重新加权的FM，应删除冗余项。

L_align先用真实视频—描述对应和核验过的不匹配文本，以BCEWithLogits训练小型匹配头；再冻结它，以`softplus(-score(实际预测视频, 正确文本))`监督可读生成结果。视觉来自V-JEPA、文本来自冻结UMT5，匹配头读取实际视频而非给P自评分。不制造错误视频，也不训练全是正标签的“物理正确”分类器。

## 5. 一次训练前向

```text
1. 正常视频 x 经 VAE 得到 z0；冻结教师提取同源目标 T。
2. 采样 σ 和视频噪声 ε，构造 zσ 与 FM 目标。
3. 条件 Wan 正常运行到 A，形成／优化实际 P 并写入 ΔH_A。
4. 原生层继续到B；按阶段及当前σ启用同类corrector，或原样旁路。
5. 原生剩余层与输出头产生 v_c 和当前端点估计。
6. 计算当前里程碑启用的结构、视频、输出和对齐任务。
7. 仅反向更新当前阶段允许训练的参数组；整批无有效可训练路径则跳过更新。
```

首版冻结原生Wan、VAE、文本编码器和视频教师，写入从零初始化开始。基础模型通过准入后，M3a固定A／共享主体／R，只训练B必要适配及b_B；可停在此阶段形成完整结果。可选M3b联合训练会改变共享基础，必须重新验收。初始化首步部分上游梯度为零是预期，起步更新后再检查视频任务能否到达ΔP。

M3a优化主要采样q_B>0的合法GT加噪视图，记录这一σ分布。高噪声B旁路、其它组又冻结时，loss可能不带梯度，只作监测，不能调用无梯度backward或只做weight decay更新。

完整训练伪代码与掩码、归一化、trace、冻结组和多卡验收见 [E第11.5–11.7节](20260908-E-实际过程监督与反馈校正_增量模型构建及周度验证方案.md#115-四项损失怎样放进同一个可实现的训练步骤)。同视图P更新不detach、不原地覆盖；GT缓存可no_grad，预测RGB／教师路径不可断图。无有效辅助目标返回图兼容零值并跳过昂贵编码，有效区域NaN则定位故障。

训练先用单个标准 GT 加噪视图。需要模拟跨步状态时，可让较高噪声的合法 GT 视图产生 P 和观察，再传入当前合法视图；这仍不等价于自由采样 rollout，不能给离轨状态继续套用原 FM 标签。

隔离历史预测在此版用于能力诊断：先截取允许的历史再独立编码，未来只进入目标分支；不能先双向编码完整视频再截历史，也不能复用看过未来的 P 或缓存。

## 6. 完整推理流程

```text
输入：首帧 I0、提示词 c、一个 seed

z ← 一次初始视频噪声，施加原生首帧条件
P ← 首帧、文本、同一噪声的低成本初始化
previous_observation ← empty

for 每个正常噪声步 k:
    v_u ← 无条件 Wan 完整前向一次
           # 不读取或更新 P

    在一次有条件 Wan 前向内：
        H_A ← 原生早层正常计算

        H_A', P_A ← corrector_block_A(H_A, P, c, σ_k)
        # 按σ设置更新强度和小循环次数；模块写入一次

        H_B ← 原生中间层从 H_A' 正常计算
        if q_B(σ_k) == 0:
            H_B', P_next ← H_B, P_A  # 保持前缀，不建立B专属缓存
        else:
            H_B', P_next ← corrector_block_B(H_B, P_A, c, σ_k)
            # 同一运算类型与共享核心，读取当前真实H_B；调度包含q_B

        v_c ← 原生剩余层与输出头正常计算

    v_cfg ← v_u + s(v_c-v_u)
    记录可用观察及其 σ、层位置
    z ← scheduler.step(v_cfg, σ_k, z)
    恢复原生首帧约束
    P ← P_next

输出：VAE 解码同一条最终 z
```

每个正常噪声步两路 Wan 各执行一次，scheduler 推进视频一次；每个原生 block 在每条分支只访问一次。SharedCell 小循环不调用 Wan 或 scheduler，不回早层、不重跑尾部。

## 7. 细粒度修正与反馈

B 优先读取当前 H_B、原生 VAE／DiT 网格及其子网格信息，通过局部重排和小投影保留细节，并共同关注接触双方、原位置、支撑和前后时刻。

前期形成结构，中期仍可调整路径、接触和响应，后期抑制不必要的大范围重构。整段视频 latent 联合生成，因此 B 可以影响视频时间轴上接触前后的关联区域。

当前完整端点只能在输出头之后取得，B 不能提前读取。上一正常步观察是带噪声时效的可选上下文；H_B−H_A 和跨步差值都混有原生计算／去噪变化，不能直接解释为某次写入的纯因果效果。

首版不调用 RAFT，不在每个接口反复解码视频；先检查 GT 的 VAE 重建与教师表征是否保留关键细节。

基础准入见 [E第7.4节](20260908-E-实际过程监督与反馈校正_增量模型构建及周度验证方案.md#74-进入中期训练之前必须通过的基础准入)：教师目标可靠、P表达过程、P控制实际视频、完整基础成功率及关键关系达到预先约定标准、σ交接区间可用。任一核心条件未过关，先修基础；不能靠继续堆中期迭代宣称已有正确地基。

预算基于P宽256、4个共享小block、Wan宽3072的明确参考规格，尚非完整v4实测；联合精确数为9,074,052，推理删除R和匹配头后新增生成参数约8.65M。M2b已需要预测视频VAE／V-JEPA反传；M3的out／align仅在相同视图时复用该编码。约9M可训练参数不等于只占小量显存。

固定输入和 seed 比较原生、上一里程碑、当前模型及关闭 B 的结果；全部输出进入统计。联合训练后的开关消融可能带来分布变化，还需固定早期模块的 B 增量训练对照。

消融区分B完全关闭（状态与写入都关）、只关有效D_B、只关ΔH_B、只关跨步P；它们回答不同问题。单项梯度证明可训练，开关响应证明使用，完整视频的改善率／破坏率与净收益才支持有效校正。

独立验收覆盖完整任务执行、角色、接触、数量／身份、形变、画质、改善率、破坏率与成本。教师分数、attention 图或小门控不能独立证明修正有效。

在基础原本正确的样本上，单独报告角色、身份、必要交互和顺序的保持率／破坏率及细化收益，并同时保留全量结果；不能只看修好了多少原失败。以碰撞为例，前期先形成红球接近蓝球、身份连续和先接触后响应的可执行关系，中期细化接触帧、几何、形变与响应幅度。频繁出现角色颠倒或凭空多球意味着基础训练未过关。

前缀保持是明确条件下的计算契约，基础物理准确性是独立测试支持的统计结论。二者都不能推出每个新样本或每轮更新必然正确；正式推理沿固定σ策略执行，不在线用GT或自评分认证后再继续。

自然视频不提供精确力学或严格干预真值；单帧可能对应多种合法未来，不能用静止和平均化冒充正确。固定预算下对严重错误的恢复能力仍有限，正式推理不通过候选筛选、重启或额外主干重算隐藏失败。
