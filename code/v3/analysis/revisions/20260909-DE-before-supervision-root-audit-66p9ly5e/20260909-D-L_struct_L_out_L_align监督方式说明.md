三项监督分别回答三个问题：

| 损失 | 检查的问题 | 直接监督对象 |
|---|---|---|
| `L_struct` | 实际过程状态 `P` 是否接近 GT 的 V-JEPA 2.1 稠密表示 | A／B 实际生成路径中的 `P` |
| `L_out` | corrector 的写入经过 Wan 执行后，是否产生更接近 GT 的视频结果 | 写入后的当前视频端点预测 |
| `L_align` | 视频是否真正执行了文本要求的角色、动作和顺序 | 生成视频与过程文本的匹配关系 |

## 1. `L_struct`：监督内部过程状态 `P`

训练样本是一段审核后的 WISA／OpenVid 视频 `x`。冻结 V-JEPA 2.1 视频编码器，输入未随机 mask 的 GT 视频，提取最后一层原生归一化的稠密 token。默认主教师为 ViT-G/16 384，检查点 `vjepa2_1_vitG_384.pt`，读取 `target_encoder`，最后层通道1664。只需要编码器，不需要JEPA predictor、分类头或PCA图。[官方模型入口](https://github.com/facebookresearch/vjepa2/blob/main/src/hub/backbones.py)

教师使用 `eval()` 和冻结参数，GT分支在 `no_grad()` 下运行或预先缓存。教师不会在D训练期间通过EMA或反向传播更新。令 `Q_ξ` 为记录时间戳和裁剪的RGB预处理，`A_grid` 为固定的网格映射，`N` 为通道L2归一化：

\[
T=\operatorname{sg}\!\left[N\!\left(\mathcal A_{\mathrm{grid}}
\bigl(\Phi_{\mathrm{VJ2.1}}^{\mathrm{last}}(Q_\xi(x))\bigr)\right)\right].
\]

其中 `sg` 表示停止梯度。对齐操作的名字不是写入接口A，目标端也没有可与学生共同收缩的训练投影。

模型在正常加噪训练路径中，通过接口 A 和 SharedCell 形成实际使用的过程状态：

\[
P^{(0)},P^{(1)},\ldots,P^{(r)}.
\]

`P` 是学生在正常带噪前向中形成、并真实写入Wan的状态；`T`只出现在损失端。由于通道不同，使用共享的逐token线性投影 `R: D_P → 1664`，它仅读取P，不另读取GT、H或文本。首版固定使用归一化余弦距离：

\[
S^{(r)}=N(R(P^{(r)})),\qquad
\mathcal L_{\mathrm{struct}}
=\mathbb E_{x,\sigma,\epsilon}\!\left[g_s(\sigma)\sum_r\alpha_r
\frac{
\sum_u\rho_u w_u\,
\left(1-\langle S^{(r)}_u,T_u\rangle\right)
}{
\sum_u\rho_u w_u+\varepsilon
}\right].
\]

公式中：

- `u` 是时空网格位置，例如“第 12 帧附近、画面右侧某一区域”，不是“速度 slot”或“蓝球 slot”。
- `r` 是学生状态取样点，不是教师层。M1取A提交前的最终P；加入B后取A输出和B更新的P_next。
- `R` 将P投影到教师空间，A／B共享；首版保持线性，复杂读出作为单独消融。
- 距离在FP32中计算，归一化带epsilon；MSE／L1可作为后续对照，不同时叠加多个默认距离。
- `ρ_u` 首版是经数据审核后的有效网格掩码，可信有效位置为1，无效为0。教师本身没有物理正确度输出，遮挡可靠度不能凭空生成。
- `w_u` 首版取1；以后有经核验的重要区域参考才加权，且保留背景底座。
- `α_r` 在实际被监督状态之间归一化；加入B后的起点可为A／B各1/2，内部每轮深监督暂不默认启用。
- `g_s(σ)` 在纯噪声端降低监督，避免要求几乎没有GT信息的输入预测唯一精确未来；按噪声桶校准，与λ_s的训练warmup分开。

`ρ` 和 `w` 都来自训练参考，不能由 corrector 的可学习 gate 控制，否则模型可能通过主动减小监督权重逃避错误。全部目标都不可信的窗口不计算此项。

### 1.1 为什么选V-JEPA 2.1，为什么先取最后层

V-JEPA 2.1的训练改进强调稠密特征的空间定位与时间一致性，并在局部视觉和过程预测任务上给出实证。相对于只保留整段语义的向量，这类token与D的时空网格P更匹配。这支持将它用作表征教师；并不直接证明它能监督好每一次碰撞或守恒。[V-JEPA 2.1论文](https://arxiv.org/abs/2603.14482)

论文的多层深监督属于教师自身的预训练方法，不意味着我们必须同时蒸馏四层。其附录D.1支持最后层作为有用的起点，因此首版先用最后层；只有领域校准或生成消融显示不足时再加中间层。[最后层与多层的实验](https://arxiv.org/html/2603.14482v1)

本地G编码器最后层索引47；支持的中间层为 `[11,23,37,47]`。`out_layers`返回列表，`return_hierarchical=True`返回通道拼接结果。不能直接用任意层号，也不能把四层输出误当作单层1664维。2.1实现位于 [vision_transformer.py](/home/liuzhirui/model/vjepa2/app/vjepa_2_1/models/vision_transformer.py)，与旧版 `src/models` 的实现不同。

### 1.2 张量如何对应

以16帧、384×384教师视图为例，patch大小16、时间tubelet大小2：

```text
GT RGB:             [B, 3, 16, 384, 384]
V-JEPA 2.1 G:       [B, 4608, 1664]
还原稠密网格:        [B, 8, 24, 24, 1664]
空间2×2池化目标:     [B, 8, 12, 12, 1664]
学生实际P示例:       [B, 8, 12, 12, 256]
R(P):               [B, 8, 12, 12, 1664]
逐位置归一化并算余弦距离
```

这里只在空间做平均池化，不把视频时间平均成一个向量。教师网格与P覆盖相同时间／画面位置；P不需要和Wan token数量相同，读写时用明确坐标连接。Wan因果VAE对首帧的处理与teacher的两帧tubelet不同，不能简单按索引或固定整数比例相减。

16帧是最小接口示例。如果“接近—接触—响应”超出该长度，需32／64帧或有足够上下文的窗口，按真实时间和共享裁剪取样；窗口目标对应整段P的相应区域。提高时间采样密度和保留完整过程要一起考虑。把长视频均匀缩成16帧可能恰好跳过接触，池化成12×12也可能抹掉间隙，需要单独消融。

每个样本先固定教师视图；长视频分窗时固定上下文和重叠网格归属，避免把不同上下文产生的token混作同一位置的完全相同标签。教师会聚合上下文，所以裁token不等于裁视频重编码。示例中的D_P=256也不是无损压缩承诺：线性R有容量限制，可对照更宽P，允许存在表示误差，最终以生成收益判断。

### 1.3 使用完整GT会不会泄漏未来

作为损失标签是允许的：训练输入来自该视频的标准加噪状态，模型学习从带噪状态恢复有用表示；正式推理的P由首帧、文本、当前特征和自身历史产生。GT教师不进入正式推理，也不直接替换训练中的学生P。将带噪隐藏表示对齐干净教师目标有REPA的先例，但其结果不直接保证本D有效。[REPA](https://arxiv.org/abs/2410.06940)

需要防止另一种泄漏：先用双向视频教师编码完整GT，再把前几个token作为“只看历史”的输入。这些token已经可能看过未来；历史条件必须由允许可见的历史片段单独编码。训练的目标端与输入端必须明确分开。

### 1.4 两球碰撞示例

假设 GT 视频展示：

```text
红球从左侧接近
→ 红球接触蓝球
→ 蓝球在接触后向右运动
→ 红球减速
```

我们希望GT教师特征能够保留以下可见变化，并应先在开发片段上核验：

- 红球接近蓝球的路径；
- 两球间距缩小并形成接触；
- 蓝球的运动发生在接触之后；
- 两个球的身份和位置随时间连续变化。

模型的 `P` 不会显式设置“红球速度”等人工通道。`L_struct` 要求 `R(P)` 在相应时空位置上接近教师从真实视频提取的过程特征。

若教师及选定余弦度量确实对这些变化敏感，那么只表示“两球存在”的P会在对应位置得到较大误差。若教师忽略短接触或运动先后，误差未必能反映该错误；不能仅凭这个例子假定相应监督已经存在。

### 1.5 `L_struct` 能做什么，不能做什么

它主要训练：

```text
当前视觉和文本条件
→ 怎样形成 P
→ 怎样在 SharedCell 中更新 P
```

但 `L_struct` 不能单独保证 Wan 使用了 `P`。即使 `P` 对齐教师很好，后续写入太弱或被 Wan 忽略，最终视频仍可能没有执行碰撞。

教师能力也是前提。如果教师只能识别“红球”和“蓝球”，却分辨不了接触及响应顺序，那么 `L_struct` 无法凭空提供相应监督。

教师目标固定能避免目标与学生共同变成常数，但学生仍可能输出接近平均的特征或利用静态背景降低loss。因此要检查跨视频方差、运动区域表现、条件变化与合法多样性，不能认为冻结教师就消除了全部退化。

## 2. `L_out`：监督写入后真正得到的视频结果

接口 B 观察中层特征 `H_B`，corrector 产生特征写入：

\[
H'_B=H_B+\Delta H_\theta.
\]

随后由 Wan 尚未执行的原生层和输出头真正执行这次写入：

\[
v=\operatorname{Head}\!\left(F_{>B}(H'_B)\right),
\]

并根据当前噪声状态形成干净视频 latent 的即时估计：

\[
\widehat z_0=z_\sigma-\sigma v.
\]

经VAE解码和可微RGB预处理得到当前视频预测 `x̂₀_write`。输出侧候选也使用同一冻结V-JEPA 2.1，定义 `Ψ_o(y)=N(A_o(Φ_last(Q_ξ(y))))`；`A_o`可以保留原生细网格，预测与GT必须使用同一协议。只在可读噪声范围启用 `g_o(σ)`：

\[
\mathcal L_{\mathrm{out}}
=\mathbb E\!\left[g_o(\sigma)
\frac{\sum_u\rho_u^o w_u^o
\left(1-\langle\Psi_o(\widehat x_0^{\mathrm{write}})_u,
\operatorname{sg}\Psi_o(x)_u\rangle\right)}
{\sum_u\rho_u^o w_u^o+\varepsilon}\right].
\]

这里没有为 `ΔH` 准备人工的正确残差标签。`L_out` 监督的是：

> corrector 写入以后，经过真正的 Wan 后续层，得到的视频结果是否更接近 GT。

### 2.1 梯度路径

```text
输出视频与 GT 的特征误差
→ 冻结教师对生成输入的梯度
→ VAE
→ Wan 输出头和 B 后剩余层
→ H_B + ΔH
→ corrector 和写入投影
```

教师参数虽然冻结，但预测视频进入教师的计算不能放在 `no_grad` 中，否则梯度无法返回 corrector。

GT分支可缓存；生成分支每次重新计算且保持浮点Tensor，禁止PIL／uint8、`.numpy()`、视频落盘重读或离散回答进入梯度链。L_struct本身不需要这条在线教师反传路径，因此L_out成本较高不等于P监督不可行。

### 2.2 两球碰撞示例

假设 B 当前观察到：

```text
红球已经接近蓝球
但两球之间仍有小间隙
蓝球却已经开始向右运动
```

corrector 可能尝试：

- 调整红球接触前的路径；
- 缩小两球间不合理的间隙；
- 调整蓝球开始响应的时间；
- 保持两个球的轮廓、数量和身份。

D 不为这些操作分别提供“正确 `ΔH`”。模型把写入后的 `H'_B` 交给 Wan 剩余层，得到 `x̂₀_write`。

若教师度量能区分“未接触就响应”，写入后仍有此问题时，相应窗口与GT的特征差异就可提供梯度。如果写入修好了接触，却使红球变形、复制或破坏背景，相应局部窗口和全段表示也可能产生误差。两类敏感性都必须实测，不能把所有错误都视为教师必然可见。

### 2.3 书移动示例

假设 GT 是一本书从桌面掉到地面。监督窗口不能只裁地面上的书，还应覆盖：

```text
桌面原位置
+ 下落路径
+ 地面新位置
+ 前后时间状态
```

否则模型可能只在地面生成一本新书，没有清除桌面上的原书。结果区域看起来接近 GT，完整状态却是错误的。

### 2.4 `L_out` 的限制与启用条件

第一，`x̂₀_write` 只是当前噪声水平下的端点估计，不是完成全部采样步骤后的最终视频。最终效果必须使用部署协议下的完整采样视频验收。

第二，如果 `L_out` 只是对原生 latent 端点做 MSE，则：

\[
\|\widehat z_0-z_0\|^2
=\sigma^2\|v-v^*\|^2.
\]

它本质上只是重新加权的 `L_FM`，没有增加新的过程监督。这种情况下应删除 `L_out`，而不是为了凑齐四项损失而保留。

第三，原始GT与VAE往返重建本身存在特征差。主目标仍取原始GT，启用前先检查教师距离是否被无法恢复的VAE细节主导；若目标现象在VAE中已经丢失，先调整数据／视图或暂缓该项，不能声称corrector能补回任意细节。

第四，2B教师对生成视频保留输入梯度，再叠加解码器与Wan后续层，显存风险显著高于离线GT监督。先用小batch和短窗口完成真实反向／显存测试。无法承受时先设λ_o=0、保留M1／M2；若换ViT-L，必须为L_out同时使用L的GT和预测特征并重新校准，不能直接比较L与G两种空间。主方案不默认增加第二套教师。

第五，由 `ẑ₀=zσ−σv` 可知，对v的梯度含σ因子。σ=0时该输出损失不能训练写入，高噪声处又可能没有可读预测；g_o需同时考虑端点质量和梯度强度。结构侧的池化缓存也不能上采样后冒充输出侧原生细网格目标。

## 3. `L_align`：监督视频是否按文本执行

`L_align` 负责视频与文本之间的过程对应，主要解决：

> 视频可能有运动，也可能在视觉特征上接近正常视频，但运动的角色、动作或顺序不是提示词要求的内容。

当前 D 不使用错误视频库，而是先在 WISA／OpenVid 上训练一个小型视频—文本匹配头：

- 正例：正常视频与它的真实描述；
- 负例：同一正常视频与经过核验的不匹配描述。

视频本身不被修改，改变的是文本对应关系。匹配头可以查看整段视频，也可以查看包含前后上下文的事件窗口。

匹配头校准后冻结，再对当前可读生成预测和正确文本计算匹配损失，使梯度通过视频输入返回生成模块。本轮将首版固定为：匹配头准备阶段用核验正／负描述训练BCEWithLogits；生成训练阶段用 `softplus(-score(预测视频, 正确文本))`。视觉端复用冻结V-JEPA 2.1，文本端复用冻结UMT5，轻量匹配头结构与参数量见E第4.2节；对比或排序目标后续再消融。

V-JEPA 2.1本身是视觉编码器，不能直接与Wan文本embedding求余弦得到匹配分数。其“多模态tokenizer”指图像／视频输入，并不提供现成文本对齐。如果复用其视觉token，需要训练上述小匹配头；P教师的确定不自动完成L_align设计。

### 3.1 两球碰撞示例

真实视频内容是：

```text
红球主动撞击蓝球；
接触后蓝球向右移动；
红球减速；
只碰撞一次。
```

真实描述作为正例。可以构造以下经过视频证据核验的负文本：

```text
蓝球主动撞击红球。               # 角色互换
红球没有接触蓝球，蓝球自行移动。 # 前提错误
蓝球先移动，随后红球才撞上它。   # 顺序错误
两球发生了两次碰撞。             # 次数错误
```

如果生成结果变成“蓝球自己先动”，即使画面质量很好，正确文本与生成视频的匹配分数也应较低，`L_align` 会推动模型恢复正确角色和顺序。

### 3.2 `L_align` 的边界

`L_align` 不是完备的物理错误判别器。例如提示词只写“两球发生碰撞”，生成结果出现轻微穿模，文本匹配头仍可能判断语义基本匹配。穿模、轮廓异常、小接触间隙和局部复制更依赖 `L_out`、教师能力以及最终独立评价。

匹配头也不是正式推理时的 verifier。正式生成不运行两个候选结果，再按匹配分数选择其中一个。

## 4. 三项监督如何互补

仍以红球撞蓝球为例：

| 模型结果 | `L_struct` | `L_out` | `L_align` |
|---|---|---|---|
| `P` 只知道有两个球，不知道接触顺序 | 教师度量敏感时提供监督 | 可能惩罚 | 匹配头有效时惩罚 |
| `P` 过程正确，但 Wan 没有执行，蓝球不动 | 可能已经很低 | 重点惩罚 | 重点惩罚 |
| 视频发生碰撞，但主动／受动角色相反 | 教师足够强时惩罚 | 教师足够强时惩罚 | 重点惩罚 |
| 语义正确，但球发生穿模或复制 | 未必敏感 | 需校准教师对局部错误的敏感性 | 未必敏感 |
| 动作和物理都正确，但背景被改坏 | 背景底座提供部分约束 | 全段／随机背景窗口惩罚 | 通常不敏感 |

三项监督的职责可以概括为：

```text
L_struct：让 P 表示应该发生什么过程
L_out：检查 P 和 corrector 写入后，视频实际变成了什么
L_align：检查实际视频做的是不是文本要求的那件事
```

它们与标准视频 Flow Matching 组成总目标：

\[
\mathcal L
=\lambda_f\mathcal L_{\mathrm{FM}}
+\lambda_s\mathcal L_{\mathrm{struct}}
+\lambda_o\mathcal L_{\mathrm{out}}
+\lambda_a\mathcal L_{\mathrm{align}}.
\]

实施顺序上，先用`L_FM + L_struct`验证P的生成控制，再分别验证额外迭代与L_align；基础通过独立准入后，在B位置加入L_out。首版可停在仅B适配的M3a，联合M3b为可选；第11节给出五个主链检查点及可选第六个检查点的预算。

## 5. 不能由这些损失直接推出的结论

- `L_struct` 下降不能独立证明视频使用了 `P`。
- `L_out` 下降不能代替完整采样视频的部署评估。
- `L_align` 下降不能证明所有局部物理错误都已消失。
- 三项损失共同下降也不能证明模型获得了严格因果定律、精确守恒或三维碰撞求解能力。
- 教师分数、匹配头分数和最终评估器不能完全同源，否则容易形成自证闭环。

最终需要分别验证：`P` 是否包含有用过程信息、改变 `P` 是否控制视频、corrector 是否在完整采样中提高改善率并控制破坏率，以及视频是否同时满足任务执行和物理关系。

## 6. 合理性、可行性与预期效果的具体判断

### 6.1 合理：给P一个与视频过程对应的学习目标

P原本就希望承载空间布局、对象关系和时间变化，GT视频特征提供了一种无需精确质量／力标签的学习目标。稠密视频token比纯文本语义或整段平均向量更适合与P逐位置对应。当前学生已处于正常GT加噪训练路径，目标与训练样本有明确对应，不需要错误视频修复配对。

它能帮助P从“可以任意变化的内部变量”变成“能够读出GT视频表征的状态”。随后由FM、A／B写入和输出监督决定这些信息是否有利于视频生成。形式合理与控制有效是两项不同的证据。

### 6.2 可行：P监督的主要工作是离线编码和可微的小投影

| 环节 | 判断 | 需要验证 |
|---|---|---|
| GT→冻结V-JEPA token | 官方代码支持 | 正式权重、预处理、取层和领域特征 |
| token→P目标网格 | 确定映射可实现 | 时间坐标、视图、padding和池化信息损失 |
| P→R→L_struct | 常规可微运算 | 主路径P有梯度，读出无旁路 |
| L_struct改善最终视频 | 有合理机制但未验证 | FM-only对照、写入控制、独立完整视频指标 |
| L_out经VAE和教师反传 | 原理可实现，资源风险较高 | 完整反向、可读sigma、峰值显存 |
| L_align | 匹配头规格与BCE／softplus目标已固定 | 仍需真实正负文本核验、独立训练及输出梯度／领域效果校准 |

只计算L_struct时，教师结果可以离线缓存，训练GPU无需同时保留2B教师；推理也不增加教师开销。缓存并非免费：16帧384的G单层原始token约14.625 MiB，空间池化后约3.656 MiB／视图，64帧为四倍。需要同时考虑I/O、数据增强和存储。

### 6.3 有希望有效，但收益最可能先体现在哪些方面

根据表示形式作出的研究推断是：首先更可能改善对象布局、时间连续性、较明显的运动变化和过程可读性；对短接触、先后关系的改善依赖采样与教师度量；精确守恒、微小穿模、不可见力学参数没有直接保证。这些是预期层级，不是实测结果。

主要失败模式及对应措施：

| 失败模式 | 表现 | 对应措施 |
|---|---|---|
| 高噪声无法确定唯一未来 | 平均轨迹、动作减少、seed差异缩小 | g_s与λ_s校准，条件充分片段，多样性评估 |
| 教师只有外观语义 | loss下降，接触先后仍错 | 外观相近过程不同的自然片段校准，换层／窗口 |
| 辅助读出吸收任务 | R(P)很好，视频不使用P | 限制R、FM梯度、P写入对照 |
| 坐标／缓存错配 | 模型学模糊布局，loss难降 | 共享视图与时间记录，增强后重算对应目标 |
| 过强特征回归 | 主体更稳但视频质量／多样性下降 | 损失warmup、模块梯度与独立生成评价 |
| 教师盲区被模型利用 | 教师分数提高、人工观感恶化 | 独立人工／外部评价，不以同一教师自证 |
| 学生状态分布不匹配 | 单步训练好，多步部署差 | 学生自生P跨噪声视图训练，完整采样验收 |

在接近纯噪声时，对独立抽取的GT未来做强回归会产生条件平均的压力；保留FM不等于消除这一压力。使用噪声权重的同时，应验证早期P是否仍有用，不能把监督全移到容易恢复GT的低噪声处再宣称早期规划成功。

### 6.4 用哪些实验判断“确实有效”

1. **教师校准：** 在源视频隔离的自然GT片段中，用外观相似、过程不同的案例检查局部距离和小探针；不要只看PCA图。
2. **结构蒸馏收益：** 同架构、数据、训练预算下比较FM-only与FM＋L_struct，独立列出教师预计算成本。
3. **P特有的价值：** 与普通Wan隐藏层对齐的REPA式基线比较，再做P写入开关及受控变化测试。随机打乱导致崩坏只说明依赖，不证明语义控制正确。
4. **关键设计消融：** 最后层／多层，稠密／全局token，12×12／24×24网格，时间覆盖与sigma权重；按最小必要顺序进行。
5. **真实部署验收：** 固定多seed、完整CFG采样，报告事件完成、角色、接触／响应、身份数量、质量、运动与合法多样性，加入独立人工检查。
6. **B增益：** A-only检查点→冻结A及共享核心／R训练B→联合训练；同时记录改善率和破坏率，避免把一般蒸馏收益都归因于反馈修正。

若只观察到P或教师loss降低，结论应停留在“表征拟合改善”；只有完整视频的独立指标净改善，才可说该监督在测试范围内有效。

## 7. 实现边界与本轮核查结果

### 7.1 单个实际P状态的最小损失示意

下列代码只表达已对齐网格后的损失，不包含教师加载、Wan包装或完整训练入口。多个实际P状态按α归一化求和即可，不增加新的损失类别。

```python
import torch.nn.functional as F

def struct_loss(p, target, readout, weights, g_sigma):
    # p: [B, N, D_P]; target: [B, N, D_teacher]
    # weights: [B, N]，固定的rho*w；g_sigma: [B]
    pred = F.normalize(readout(p).float(), dim=-1, eps=1e-6)
    target = F.normalize(target.detach().float(), dim=-1, eps=1e-6)
    assert pred.shape == target.shape
    assert weights.shape == pred.shape[:2]
    assert g_sigma.shape == (pred.shape[0],)
    weights = weights.detach().float()
    distance = 1.0 - (pred * target).sum(dim=-1)
    denominator = weights.sum(dim=-1)
    per_sample = (distance * weights).sum(dim=-1)
    per_sample = per_sample / denominator.clamp_min(1e-6)
    active = (denominator > 0).float()
    return (per_sample * g_sigma.detach().float() * active).sum() / active.sum().clamp_min(1)
```

所有输入需在同一device，权重非负、特征有限；无效目标应预先排除／填安全值，不能指望`0 * NaN`变成0。这个公式在全部权重为0且输入有限时返回保留计算图的零损失。

## 8. 对研究主张的影响

使用GT的V-JEPA特征是合理的监督选择，但不是新的独立贡献。PHANTOM已经使用V-JEPA 2表征并联合建模视频／物理latent；单纯改为2.1不足以支持创新性。[PHANTOM方法](https://arxiv.org/html/2604.08503v3#S4)

本D继续采用一个视频流、紧凑可更新P、共享单元以及A→B顺序写入，不给P新增独立flow、噪声轨迹或scheduler。研究重点应通过实验落在：P是否具有实际控制力，中层实际观察是否带来净修正，以及相同Wan调用预算下的收益；需要与普通特征蒸馏和更简单适配器比较。

## 9. 中间P、ΔP与A／B的监督应如何安排

### 9.1 首先区分量、参数和四种时间／层索引

当前D采用统一corrector block，在A和B两个层位置调用，不是在全部Wan层生成独立ΔP。A／B表示位置及其适配参数，H_A／H_B表示原生隐藏特征；本文把“ΔA／ΔB”统一写成ΔH_A／ΔH_B。两处均执行读取→共享状态更新→实际P驱动写入；Wan层深与去噪σ是独立维度，B是否在早期工作由σ策略决定。

| 索引 | 含义 | 能否直接与teacher对应 |
|---|---|---|
| 视频时间τ和空间位置u | 生成视频中某个事件所在位置 | 可以按真实时间、裁剪与网格对齐 |
| 去噪步k或噪声σ | 同一整段视频当前的去噪状态 | 各合法训练视图可使用同一GT目标，强度按σ校准 |
| Wan层ℓ | 同一前向内部的网络深度 | 不等于teacher层，不要求层号一一对应 |
| SharedCell内部更新r | 在低维工作状态中的第几次修改 | 没有GT迭代轨迹；只监督选定更新后的状态 |

P、ΔP和ΔH是样本相关的激活，不是各自一套模型参数。训练优化器更新的是生成这些量的投影、注意力、MLP、方向头和gate等权重；正式推理不针对单条视频优化P。

### 9.2 GT教师监督的是状态，不是去噪增量

记实际生效更新为D，候选方向仍记ΔP：

\[
D_i^{(r)}=s_i\eta_i(\sigma)G_i^{(r)}\odot\Delta P_i^{(r)},
\qquad P_i^{(r+1)}=P_i^{(r)}+D_i^{(r)},\quad i\in\{A,B\}.
\]

对同一GT视图提取一次固定T；A和B的提交状态通过同一R、同一坐标映射接受L_struct。无需生成“GT的第1轮P、第2轮P”。教师最后层是目标取层配置，学生每次更新可以反复朝同一目标学习。

本次σ策略使B在σ≥σ_h时完全旁路，其余区间平滑启用。上述η_B按有效值`q_B(σ)·η_B`理解，写入γ_B也包含q_B；参数梯度公式相应使用有效调度。q_B不参与学习，不是正确性分数。旁路样本只监督A且α=1，B启用时才选A／B实际提交态，初始α各1/2。

首版选择：M1监督A的最终提交状态；B加入后监督A、B最终状态，归一化深监督权重。若以后需要在内部加辅助点，可以只选一个中间态并降低其权重；不默认要求每一轮、每个层都达到最终目标，更不为它们分配独立强loss。

不要使用以下错误对应：

- `ΔP ≈ T`：T是状态，反复加进去可能重复累积或过修。
- `ΔP ≈ T(τ+1)-T(τ)`：右边是视频时间上的变化，左边是去噪计算中的修改，时间轴不同。
- `ΔP ≈ T-R(P)`：前者256维、后者1664维，而且经过归一化后不再是简单线性残差关系。
- 把teacher第r层当学生第r轮的目标：两种网络和计算过程没有这种天然对应。

若暂时采用未归一化平方距离、R(P)=WP+b，且两边使用相同计算图，可以写成：

\[
\|R(P+D)-T\|^2=\|WD-(T-R(P))\|^2.
\]

这说明监督更新后的状态本身就给增量提供了误差信号，并没有获得一个额外的真实ΔP标签。它是特定距离下的代数关系；当前归一化余弦目标不能直接套用，也不能随意增加detach后声称梯度完全等价。

### 9.3 ΔP没有独立标签，为什么仍能学到方向

首版P／ΔP为`[B,N,256]`，更新gate由`256→1`投影及sigmoid产生，为`[B,N,1]`，逐token广播到通道；η(σ)按`[B,1,1]`广播。对单个样本和token的加法更新，局部链式法则为：

\[
\frac{\partial L}{\partial\Delta P_c}
=s_i\eta_iG_i\frac{\partial L}{\partial P_c^+},
\qquad
\frac{\partial L}{\partial G_i}
=s_i\eta_i\sum_c\Delta P_c\frac{\partial L}{\partial P_c^+}.
\]

标量gate的梯度要沿广播通道求和，不能沿用逐通道向量gate的逐元素公式；gate的logit梯度还要乘G_i(1−G_i)。若改为256通道gate，参数预算和公式均须修改。b_B是跨token和调用位置共享的标量，其梯度汇总各次使用并乘tanh的导数。

这里的L既可包含L_struct，也可包含经P^+写入到实际视频的FM／out／align。训练会根据“修改后的状态和输出误差”更新候选方向、强度与相关共享参数，因而不必为每个Δ都再配一个损失。这是节点的局部导数；共享网络参数的总梯度还要累加所有调用路径。

例如仅在二维教师读出空间作示意：T=(1,0)，原读出为(0.6,0.8)，余弦损失0.4；一次更新使读出变为(0.8,0.5)，归一化后余弦损失约0.152。它表明该更新改善了特征对齐，但不能据此断定蓝球响应时刻已被修好，仍需实际视频损失和独立评价。此数值例子不是V-JEPA实测，也不是球的坐标。

同一视图内不要detach每轮P或A→B传递，否则早期ΔP到后续状态／视频结果的梯度会断开。跨去噪视图为节省显存做截断可以作为明确的训练选择，但不能声称截断前的更新仍受未来输出梯度监督。

### 9.4 哪些量需要直接监督，哪些由结果训练

| 量／参数 | 直接GT目标 | 训练信号和边界 |
|---|---|---|
| P_A^+、P_B^+ | 同源V-JEPA T | L_struct直接监督；实际写入路径再接受视频任务梯度 |
| 内部中间P | 可复用T | 首版不逐轮全监督，必要时少量深监督 |
| 候选ΔP、有效D | 没有独立增量GT | 通过更新后P和真实视频结果训练 |
| ΔH_A、ΔH_B | 没有正确Wan残差GT | 用FM、out、align训练真实作用 |
| H_A、H_B | 首版不设逐层teacher标签 | 保留原生层表示；普通隐藏层对齐可作为比较基线 |
| 更新gate、写入gate、状态缩放 | 没有物理正确度GT | 从上游真实任务梯度学习；不能用重要区域直接标注“必须改” |
| A／B的读写投影、共享权重 | 不需要逐参数标签 | optimizer依照当前冻结设置更新 |
| R | 结构读出目标T | 只参与L_struct；保持轻量，M3a冻结以固定读出尺度 |

同一接口的L_struct位于P^+处，本身不经过其后写入投影。B的P监督可能经H_B间接到达A写入，但这不代替实际视频任务。可训练参数被冻结时不会得到权重更新，梯度仍可能穿过该模块到达它的输入，二者要区分。

### 9.5 单项损失的梯度应该到哪里

以下针对同一次合法GT加噪前向，表中的“可达”指计算图具有该路径；σ权重为0、零初始化、数值抵消或参数被冻结时，不保证该step梯度非零。

| 单独审计的损失 | 应有的路径 | 不应误要求的路径 |
|---|---|---|
| A状态的L_struct | R→P_A^+→A状态更新／读取／共享组 | 不经过随后A的writer，也不经过B |
| B状态的L_struct | R→P_B^+→B状态更新；还可经输入P、H_B回到A | 不经过随后B的writer |
| L_FM | 原生速度→冻结Wan后缀→ΔH_A／ΔH_B→实际P及状态更新 | 不经过训练读出R或GT教师 |
| L_out | 预测教师特征→预测RGB→VAE decoder→原生速度→写入及P路径 | 不更新教师／VAE权重，不经过R |
| L_align | 冻结匹配头→预测视觉token→预测RGB→实际视频／写入路径 | 不更新匹配头／视觉教师／文本编码器权重，不经过R |

同一模块的“权重冻结”和“输入不可求导”不同。M3a中共享ΔP头、gate头、R均冻结，B的读取投影和b_B仍可通过这些冻结计算接受梯度。反之，若把整个共享主体或预测教师放进`no_grad`，会切断这条路径。默认GT视频和描述本身不作为需要优化的张量。

这张表用于定位错误：P的struct梯度正常而writer始终没有视频梯度，说明只证明了表征学习；输出梯度到ΔH却到不了P_after，要检查writer是否绕过P或detach；P_after有梯度而候选ΔP在B起步时为零，要先核对s_B=0的合法初始化，再看起步更新之后。多轮更新允许某轮暂时为零，但长期全部有效D为零且移除D不影响视频，就不能声称增量校正已被使用。

## 10. 如何约束模型确实使用P，并验证校正有益

### 10.1 将实际更新后的P设为新增写入的必经输入

首版采用D第4.3.2节的数据依赖：

```text
当前H、文本、sigma、已有P
         ↓
     SharedCell
         ↓
   ΔP与gate → 有效D → 更新后的P^+
                       ├── R → L_struct
                       ├── 写入方向和gate → ΔH → Wan后续层 → FM/out/align
                       └── 下一正常去噪步
```

R不另看H或文本，写入方向及gate不另从H或私有工作状态绕开P^+。这样至少排除了“P只服务辅助损失、真正残差完全走另一个网络”的明显旁路。B的P^+既进入本步写入又进入下步状态，避免仅缓存而在训练中从未被真实输出消费。

这种结构依赖不能强制每个通道都是可解释物理量。隐藏表示允许坐标变换，gate和方向存在尺度补偿；P也可能携带一般视频信息。合理主张是某种状态／增量对可见过程产生了有益作用，而不是它的每个元素都代表力或速度。

### 10.2 保持已有能力，允许有理由的修改

主线继续只有四类生成器损失。FM维护真实视频分布，struct约束状态，out约束实际输出视觉过程，align约束文本事件。保持背景与有效过程覆盖，防止仅改善运动主体而复制物体或破坏其它区域。

不默认新增“所有Δ必须接近0”“每轮必须严格更好”“gate必须非零”等强约束；前者可能消灭校正，后两者可能强迫无意义修改。通过小学习率、λ的warmup、固定η／γ范围及梯度裁剪控制数值规模，残差相对范数只作监测，不作物理正确证明。正确状态允许D=0和ΔH=0。

新增B必须同时满足初始 `ΔH_B=0` 和 `P_B^+=P_B^-`。因此W_B^out置零，并设 `s_B=tanh(b_B)`、b_B=0；只把写入置零仍会通过改变P_next干扰后续A。初始输出损失先训练写入矩阵，struct可训练b_B；其他上游梯度随后出现，不要求第一个step所有参数都非零。

### 10.3 三类证据缺一不可

1. **梯度证据：** 分别对四项损失做backward，检查P^+、有效D、ΔH和相关参数；只证明可训练，不证明有收益。
2. **使用证据：** 固定权重和生成协议，禁用状态更新／写入／跨步传递，检查输出是否响应；只证明模型依赖它，不证明依赖正确。
3. **收益证据：** 与同架构FM-only、上一检查点和受限B训练比较，在独立完整视频上看净改善，同时检查画质与多样性。

四个开关要明确区分：

| 对照 | 本步写入 | P_next | 检查的问题 |
|---|---|---|---|
| B完全关闭 | 不写入ΔH_B | 不提交B更新；若启用B专属缓存也关闭 | B整体的作用 |
| 只关闭D_B | 仍从未更新P执行B写入 | 保持未更新P | 状态增量是否有用 |
| 只关闭ΔH_B | 不进行B写入 | 仍提交更新P | 当前写入与未来状态的作用区别 |
| 只关闭跨步状态传递 | 当前A／B照常执行 | 下步不接续该状态，按约定重建 | 持续过程状态的作用 |

关闭某个共同训练模块会引入分布变化，所以不能只做一个开关就完成归因。固定A／共享组／R仅训练B，可以更直接检验新增B的收益；联合训练则需另看A是否被改坏。

### 10.4 如何评价一次或一组更新是否“改好了”

teacher误差的前后差可作为同一checkpoint、相同R和目标下的表示诊断；它不是最终物理得分。若要定位单次B更新，可离线复制完全相同的B前H／P状态，分别保留和关闭更新，再各自计算后缀及输出指标。这个对照确实需要额外计算，应计入诊断预算，不能伪装成主训练／推理只运行一次的免费监督。

不直接使用H_B−H_A当“修正方向”，因为两者还相差原生层计算。也不默认加入逐轮输出排序loss：若没有无更新对照，就不知道是否相对改善；若增加对照，就必须承认额外尾部／教师前向成本。首版以GT结果监督和离线对照建立证据。

以假设的10条视频为例：原来6条正确，B使原来4条错误中的2条变正确，同时把原来6条正确中的1条改坏，则最终7条正确。改善率2/4，破坏率1/6，净成功率提升1/10。这个例子说明既要看改善也要看破坏；它不是本模型的实验数据。正式评价按场景聚合不确定性，还要同时报告质量、运动和合法多样性。

损失最小化没有逐样本必然改善的数学保证。教师看不见某种错误、主干执行能力不足或训练／推理状态分布不同，都可能使更新无效。目标应是可复验的总体净收益，并报告失败范围。

### 11.2 使用全部损失的核心安排

地基优先主链采用五个检查点M0／M1／M2a／M2b／M3a，其中四个生成器训练设置继承权重，匹配头另行准备；M3b为可选第六个检查点／第五个生成器设置。进入M3a之前先过E第7.4节基础准入；联合解冻后须重新验收。

| 阶段 | 训练内容 | 生成器损失 | 当前训练参数 |
|---|---|---|---:|
| M0 | 教师、对齐、身份初始化、单项梯度和资源检查 | 不进行正式训练 | 0 |
| M1 | A＋共享组＋R，先一次更新 | FM＋struct | **7.49M** |
| M2a | 增加共享更新次数，保存独立检查点 | FM＋struct | **7.49M** |
| 匹配头准备 | 冻结视觉／文本编码器，只训练小匹配头 | 独立GT匹配BCE | **3.06M** |
| M2b | 冻结合格匹配头，继续训练A＋共享组＋R | FM＋struct＋align | **7.49M** |
| M3a | 基础准入后固定A／共享组／R，B在交接σ前旁路，只训练B适配与b_B | FM＋struct＋out＋align | **1.58M** |

M3a的ΔP候选头与P更新gate属于冻结共享组，B通过新的读取投影和b_B适配它；M3b才共同微调这些共享参数。M3a的A结构loss可以记录，但它不会更新已冻结A。所有阶段的optimizer都按参数对象去重，不按A／B调用次数重复登记。

初步先完成M0、M1、M2a，以16–32条GT检查拟合和梯度，再在隔离开发集检查P控制／迭代收益；之后才进入实际输出教师反传和B校正。M2a无收益可继续保持一次更新。M4细粒度读取、M5更多迭代／历史观察都不是四项损失的必要阶段。

按E的可选M4配置，新局部读取约0.123M；单独适配时只训练这部分，联合时约9.20M。M5若只多次调用同一单元则新增权重为0；新增投影或block时必须重新计数。

### 11.3 所有损失都开时的成本和稳定性

M1／M2a只需要缓存的GT教师特征，不需要生成视频的教师反传。M2b的匹配头看实际输出视频，视觉端使用V-JEPA，因此它已需要VAE解码和教师输入梯度；不能等到M3才测这条重计算链。M3的out与align使用同一视觉模型和视图时可复用一次教师前向，不同窗口不能强行复用不对应的特征。

损失在有效token、有效样本和选定状态间归一化，保留固定σ权重；λ_f取1，各辅助λ从小值warmup，并检查缩放后的梯度范数／冲突。不能因为有四项就都设为1，也不能用学生gate把监督权重降成0。冻结的大模型仍可能需要存输入梯度所需的激活，约9M可训练参数并不能推导出单张48GB能训练。

## 12. 可行性检查与仍未验证的部分

参数预算已用PyTorch标准模块的meta参数容器核算，包括MHA、Linear、LayerNorm、embedding、B缩放标量和匹配头；它只验证给定规格的权重数量，没有建立完整Wan适配或训练吞吐测试。

本轮已用CPU合成小图验证：B双重零初始化保持P和当前输出一致；第一次反向给W_B^out和b_B有效梯度（范数／绝对值约0.339、0.0343）；一次起步更新后，单独输出损失通过冻结后缀、实际写入、P^+到达候选ΔP（梯度范数约8.81×10^-7），冻结后缀权重无梯度。初始化时ΔP候选的梯度为零是预期现象。此检查没有Wan、VAE、正式teacher或真实视频，只证明给定计算图的连通性；梯度很小也提示完整实现需监测实际强度，不能只检查非零。正式M0还须验证整个采样链的状态一致性。

检查时分别报告：前向数值正确、梯度可达、冻结参数确实不变、初始化等价、teacher领域敏感性，以及独立完整视频净收益。前四项是代码可行性，最后两项才触及监督和校正的实际效果；不能以参数预算或合成图成功代替训练结果。

### 12.1 已补齐的训练实现细节与文档位置

完整训练步骤统一写在 [E第11.5–11.7节](20260908-E-实际过程监督与反馈校正_增量模型构建及周度验证方案.md#115-四项损失怎样放进同一个可实现的训练步骤)。关键流程是：GT端冻结编码／缓存→一次标准条件Wan前向并返回实际状态→FM与状态损失→只对合格端点进行可微视频解码／教师编码→输出与文本任务→按当前阶段参数组反传更新。

| 需要落实的问题 | 已采用的处理 |
|---|---|
| 多个P和GT如何对应 | 固定教师最后层、相同GT视图与真实时间／空间映射；A／B共享R，选定实际提交状态，α归一化 |
| ΔP／ΔH是否另设真值 | 不编造增量标签；状态结果与真实视频结果反传，具体梯度见第9.3／9.5节 |
| 如何防止P只做辅助拟合 | writer方向及gate读取同一个实际P_after；保留FM／out／align到P路径，配合禁用及独立收益对照 |
| 首帧／padding | 依照原生I2V计算有效FM区域，预测端点只恢复允许的首帧；不贴回未来GT |
| 无效样本／高噪声 | 区分数据无效和σ门限；掩码预处理防NaN，全无效辅助项返回图兼容零值并跳过昂贵分支 |
| 随机抽样／低频辅助loss | 明确有效分母与计算频率；需要保持原期望时按纳入概率修正，另报方差／成本 |
| 输出教师如何省算 | 相同视图的out／align复用一次有梯度编码；不同视图分开，分块VAE解码验证上下文边界 |
| 训练哪些参数 | 按第11节阶段表；optimizer去重并清除阶段切换的残留梯度，冻结组不被旧optimizer误更新 |
| 中间变量如何检查 | 保存实际trace，用retain_grad／autograd.grad做受控单项审计；正式训练只对总loss反传一次 |
| 多卡与显存 | 归约有效样本数、验证动态未使用参数及各rank空分支；不长期保存带图日志，实测峰值显存 |

### 12.2 “方案能实现”和“现在已经验证”分开验收

目前不存在必须取得“每层真实ΔP”才可实现的前提：标准张量投影、坐标对齐、可微教师输入和普通反向传播足以表达本方案。仍可能出现以下实际失败，不能承诺不会报错：

- **形状／缓存错误：** teacher层返回列表被当Tensor、1664／1024混用、时间轴或crop不对应、gate广播错误。用M0的shape、时间戳和cache key断言定位。
- **计算图错误：** 预测分支no_grad、原地覆盖P、checkpoint重复提交状态、四次backward误用已释放图。按E的单步与trace契约处理。
- **数值／优化错误：** 无效目标NaN、零分母、σ=0导致输出梯度为零、多个乘法因子同时零初始化、阶段冻结与optimizer不一致。区分合法零梯度与故障，不把所有零梯度当异常。
- **资源错误：** 冻结2B教师仍需输入反传激活，完整视频解码和多轮状态均增加显存；参数量小不能排除OOM。先过M0资源检查，再在M2b启用实际输出路径。
- **学习效果不足：** 目标可拟合但teacher对错误不敏感，或者P／ΔP被使用却使视频变差。这不是自动求导能排除的问题，须看独立视频净收益、破坏率与多样性。

因此文档已经给出监督落点、实施步骤、风险处理和阶段验收，但v4完整训练入口、正式教师领域测试、实际显存／吞吐及视频提升仍待实现和实验；不能把这些待验证项写成已通过。

## 13. 统一corrector block后，怎样落实“先把地基做对”

### 13.1 统一操作，不把位置差别包装成两种原理

A、B都属于同一种corrector block：读取当前Wan特征，更新同一种P，再由实际P产生特征残差。共享核心相同，局部读写投影适应不同层特征；B的零初始化缩放属于增量训练配置。A／B仅作为旧位置别名保留，不能因为分别叫“结构接口”“修正接口”就声称两个独立算法。模块更名不改变参数量或四项损失的梯度分工。

早／中／后期指去噪σ区间；A／B指Wan层位置。两者必须分开：在早期去噪的一次前向中，同样会经过Wan中层。要让新增中期能力真正晚些参与，必须显式按σ关闭B，而不是依靠给B取名“中期”。

### 13.2 监督与验收先服务基础，再服务细化

| 目的 | 训练约束 | 必须补上的效果证据 |
|---|---|---|
| 基础表征包含必要过程 | L_struct监督实际P的同源GT表征；高噪声强度校准 | 角色、交互前提、顺序、身份能被读出，教师对这些关系有辨识力 |
| 基础能生成正确过程 | FM和M2b的实际视频L_align通过writer训练；必要时另做提前L_out的明确对照 | A-only完整自由采样成功且保持合法多样性，P不只是辅助预测器 |
| 新增能力不改早期计算 | M3a冻结基础全部权重，σ交接之前完全旁路B | B训练为非零之后，交接前z／P／scheduler状态仍与基础checkpoint一致 |
| 中期完善但不系统性破坏 | 继续监督实际P和输出，M3a从双重零初始化开始 | 基础正确子集的关系保持、完整成功保持、质量改善与全量净收益同时成立 |

准入是开发阶段对模型的要求：基础不合格先继续训练／修改基础，通过后才训练中期增量。生产推理沿预先校准的σ策略运行同一条视频，不在线读取GT、不等一个自评头发放“正确证书”。V-JEPA 2.1提供稠密视频表示；将这些表示用作监督是合理的设计选择，但它们不是本文模型每次更新都遵守物理规律的证明。[V-JEPA 2.1](https://arxiv.org/abs/2603.14482)

### 13.3 碰撞例子与可以保证的范围

合格基础应支持红球主动接近、两球数量／身份连续、路径可形成交互和响应具有前因；中期再完善接触帧、接触几何、形变及响应幅度。初速度等条件未知时保留多种合理结果，不能为了早期“确定”而强迫复制唯一GT未来。

如果基础经常产生蓝球无前因自发运动、红球没有接近路径或多出一颗球，应判定基础阶段未过关。中期保留纠正残余偏差的能力，但大量严重错误不应成为默认输入状态，更不应用更多迭代掩盖。

可按D第5.4节条件保证**已学早期前缀不被新增位置改动**；无法由此保证**该前缀每个样本的物理结构都正确**，也无法保证**中期每一轮都单调变好**。交接后即使参数冻结，A读取的z／P也会变化。实际保持需按E第8.5.1节报告原正确关系的破坏率、子集收益和全量结果，不将小残差或低teacher距离当作物理证书。

M3a是这一首版的优先完成形态，训练约1.58M；可选M3b约9.07M联合训练会改变共同基础，需重新通过准入，不能继续宣称保留原有前缀。实现上按有效σ采样；整批B被旁路且其它参数冻结时跳过无梯度backward，防止常量loss报错或无监督的weight decay更新。
