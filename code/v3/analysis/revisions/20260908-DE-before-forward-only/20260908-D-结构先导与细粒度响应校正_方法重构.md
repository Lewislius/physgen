## 1. 结论：需要重构，但不是再增加几套网络

**C 版适合作为局部校正基线，尚不足以支撑“能够解决严重数量、因果和运动结构错误”的主张。** 应把“在已经形成的结构上反复补残差”改成：

> 从去噪开始就用学习到的过程信息参与运动结构形成；在同一条生成轨迹内，持续读取真实预测的粗细两种视图，通过早期结构接口和直接速度场接口改写；训练不仅告诉它哪里错，还要求修改后的实际结果接近可信的正确过程。

本版暂称 **结构先导—响应校正**。这只是工作名称，创新性取决于机制和证据，不来自命名。

### 1.1 明确接受、排除和暂缓的内容

| 设计问题 | D 版决定 | 原因 |
|---|---|---|
| 错了就整段重新生成 | 排除 | 没有学会修当前错误，也不符合任务要求 |
| 同时生成多个候选再由 verifier 挑选 | 排除 | 正式推理始终只有一个活动视频状态，所有测试输出均计入结果 |
| 内部多轮校正 | 保留 | 下一轮必须看到上轮修改后的实际输出，而非只更新自己的设想 |
| 局部加噪／有限回退 | 用户允许，但首版不启用 | 只有在单轨迹修改的能力诊断确有缺口后，才作为独立可选实验；不能变成不断重试 |
| 固定阶段分段生成视频 | 不采用 | 全段共同建模；“早期／后期”首先指去噪进度，不是分开生成接近、接触、离开三段 |
| 前期结构限制 | 采用软、可撤销的过程条件 | 提前减少角色、运动方向、交互路径错误；不把初次预测当成真值锁死 |
| 物理重点细节 | 作为主线能力 | 小面积、短时刻的接触／支撑变化可能决定整个事件，不能只依赖全局视频特征 |
| 固定语义 slot／实体账本 | 不设 | 使用带时空坐标的稠密表征，不规定第几个 query 代表对象、接触或速度 |
| StateBridge、Reader–Writer–Corrector | 不强制保留名称或拆分 | 只保留必要职责，参数主体共享 |
| RAFT、完整光流分支、另一个大物理 DiT | 不加入 | 当前主线不需要这些实体 |
| 损失数 | 四项 | 视频生成、过程预测、过程执行、实际修正；删除 C 的单独门控误差回归 |

### 1.2 与 C 版相比，真正变化在哪里

| C 版 | D 版 | 要解决的能力缺口 |
|---|---|---|
| 主要在固定中间接口的小残差范围内回写 | 过程状态进入早期 DiT；另有原生 VAE 网格上的速度残差出口 | 减少结构先定错、末端只能补纹理的问题 |
| 同一步循环复用同一个前部输出 H0 | 结构条件改变后重新计算完整有条件 DiT | 下一轮重新建立时空关联，而不是永远沿旧前部表示工作 |
| 粗粒度状态加中间视觉特征 | 增加原生细网格观察，以及选定轮次的现有 VAE 解码细节读取 | 看见接触小缝隙、短瞬态、旧位置复制和轮廓问题 |
| 门以参考误差图为主要独立监督 | 对“经过真实回写后，视频实际改变了什么”进行配对监督 | 错误分数不是修正方向，也不是可执行的修改强度 |
| 关联矩阵转置近似回溯前因 | 不把注意力转置称为因果逆运算；用前置条件变化和过程配对训练 | 去掉尚缺证据、又增加解释负担的 TLU 机制 |

**不是承诺 D 已经足够，而是让它具备更合理的修改入口、观察分辨率和学习信号，并给出能够否定该方案的实验。**

## 2. 为什么不能只靠增加循环次数

### 2.1 写入位置、幅度和时机共同限制能力

C 在某一噪声步内的输出属于以下集合：

\[
\{f_{\mathrm{tail}}(H_0+A,c,\sigma): A\in\mathcal B\}.
\]

其中前部输出 H0 固定，累计写入 A 受限于同一个幅度范围。增加轮数可以更好地探索这个集合，却不会自行改变接口和范围。**这只是单噪声步的限制，不是证明整条跨步轨迹永远不可达**；跨步时输入和 H0 会变化，非线性尾部也可能产生较大语义变化。

对于本文采用的 rectified-flow 记号：

\[
z_\sigma=(1-\sigma)z_0+\sigma\epsilon,\qquad
\hat z_0=z_\sigma-\sigma v,\qquad \sigma:1\rightarrow0.
\]

固定当前 z 时，直接改变速度预测产生的端点变化满足：

\[
\Delta\hat z_0=-\sigma\Delta v.
\]

因此在很低噪声下，有限的速度改动对端点的作用会变小。不能等到最后再要求一个保守模块大幅改写整段运动，更不能用除以趋近于零的 σ 来无限放大更新。D 的应对是**结构从前期参与形成，中期保留联合改动能力，后期主要处理可观察的局部细节**，而不是声称一个 gate 可以消除所有限制。

### 2.2 三类“积重难返”必须分别处理

1. **输入本身冲突**：首帧已有两本书，文本又要求始终只有一本；或者要求固定画面之外才能发生的交互。保持首帧不变时可能无解。需要指出条件冲突，不能暗中换首帧或把失败当成功。单张静态图像本身也不能证明对象初速度为零。
2. **模型早期自行定错结构**：例如红球的路径从蓝球旁绕过。这属于应当解决的生成错误，应在早期／中期通过结构条件和较强的联合更新修正。
3. **表示或监督看不见错误**：VAE 已经抹去瞬时接触，或者 teacher 分不清一本与两本。再循环十次也不能自动补上信息来源。

### 2.3 论文证据究竟支持什么

- **PhaseLock** 报告部分 I2V 设置中少步运动先验优于长步结果，分析了后续细化中的相位退化；它也明确指出，错误的少步先验会把最终结果引向错误。支持“保留有价值的过程信息”，**不支持“早期信息总是正确，应该全部锁死”**。[论文与局限](https://arxiv.org/html/2606.06361v2)
- **TBS** 在结构化推理、导航和机器人任务中观察到运动路线早期确定。它采用验证与重启搜索，D 不采用其解法；它提供的是“晚期修补可能不够”的相关证据，不是自然物理视频的普遍不可能性定理。[论文](https://arxiv.org/html/2606.13861v1)
- **Self-Refining Video Sampling** 已有步内循环和空间选择性细化，因此“循环 + 门控”本身不新。其 Predict-and-Perturb 使用扰动，本版不直接移植；自一致也不等于物理正确。[论文](https://arxiv.org/html/2601.18577v1)

还要分清三条坐标轴：**视频时间、去噪进度、网络层深**。“中间层能读出物理信息”不等于“去噪前几步一定包含正确物理”。[Interpreting Physics in Video World Models](https://arxiv.org/abs/2602.07050) 研究的是视频编码器的层级表征；其分布式编码发现支持不采用固定物理量 slot，但不能直接外推为本地 Wan 的因果保证。

## 3. 跨领域借鉴：只保留直接服务主线的机制

下表的应用判断是本项目的设计推论，不代表原论文验证过本方案。参考工作不限于物理视频；既保留可迁移机制，也明确近邻工作已经做过什么。

| 要解决的问题 | 主要来源 | 取其有用之处 | 不照搬的内容 |
|---|---|---|---|
| 早期关联与后期渲染怎样分工 | [SCD / Causality in Video Diffusers is Separable from Denoising](https://arxiv.org/abs/2602.10095) | 将过程信息保留在紧凑状态中，避免把所有职责都交给后部渲染 | 原文主要研究自回归视频；不直接把其缓存和一次计算结论搬到双向 Wan |
| 怎样使结构条件真正进入视频主干 | [VACE](https://arxiv.org/html/2503.07598v1) | 时空条件的可训练适配接口、较早层的条件介入 | 不搬入完整编辑工具箱、多条件生成任务或另一套大型 Context Blocks |
| 正确定位后为什么仍改不动 | [FlowAnchor](https://arxiv.org/html/2604.22586v1) | 区分修改位置与有效强度，避免长视频稀释局部修改信号 | 它是免训练视频编辑，源／目标速度差不是我们的物理误差；不直接照搬归一化放大规则 |
| 模型为什么不会改自己生成的错误 | [SOAR](https://arxiv.org/html/2604.12617v1) | 在偏离标准训练路径的状态上学习恢复，而非只看常规加噪 GT | 原文的近邻回正假设不覆盖任意自由生成；不能随便给一个失败视频配一个不同 GT |
| 物理关系如何进入非 slot 表征 | [V-JEPA 2.1](https://arxiv.org/abs/2603.14482) | 稠密视频特征作为可信程度可校准的预测目标 | 不把教师特征当物理定律或真实力场；中间层和末层均需校准 |
| 怎样减少只按自身惯性预测的捷径 | [Causal-JEPA](https://arxiv.org/html/2602.11389v2) | 有选择地遮蔽历史，让预测依赖交互上下文 | 不采用对象 slot；其对象遮蔽优于某些 tube 遮蔽，不能宣称我们的稠密遮蔽必然等效 |
| 物理相关区域的监督从哪里来 | [ProPhy v2](https://arxiv.org/html/2512.05564v2) | 现象提问与通用提问的注意力差异，提供软区域参考 | 不复制 MoE、物理类别 query 清单、负载均衡损失；相关性不等于错误或影响强度 |
| 文本角色、动作顺序与次数如何学 | [VideoComp](https://arxiv.org/abs/2504.03970) | 细微动作替换、时序扰动及组合负例的构造思想 | 不增加一套分层排序损失和视频文本模型 |
| 全局顺序正确却在动作转移处执行失败 | [TempAct v2](https://arxiv.org/html/2606.28016v2) | 区分全段安排与局部转移执行，强调面对自身已生成历史的训练 | 不移植 planner–executor 双模型、固定 span 提示词切换和分组 RL；见下节 |
| 动态 latent 与视频相互作用是否已经有人做 | [PHANTOM](https://arxiv.org/html/2604.08503v3) | 说明教师动态表征与视频生成耦合是合理近邻路线 | 已有双 latent flow 分支和双向交互；“增加 physics latent”不能列为独立创新 |
| 单轨迹世界模型校正是否已经有人做 | [OMR](https://arxiv.org/abs/2608.29904) | 必须把单轨迹反馈作为近邻基线来比较 | 不在正式推理中运行外部世界模型梯度；我们的更新规律需要通过训练内化 |
| 动作区域加权是否已经有人做 | [CAER](https://arxiv.org/abs/2608.30897) | 关注动作结果在全局损失中被稀释的问题 | “物理区域权重大”不是独立创新，也不把条件差分自动解释为因果效应 |

这次不加入频域锁相分支、反向因果注意力头、对象数据库或物理定律专家组。它们各自可能有用，但目前没有必要同时进入主流程。**本版优先检验一个问题：受过程学习约束、能看到细节和真实修改后果的共享单元，能否学到有效的生成内更新。**

### 3.1 TempAct：有价值，但不应把整套框架搬过来

核对版本是 2026-07-02 的 v2。TempAct 面向自回归视频：LLM 产生带时间跨度的步骤条件，视频执行器在自身生成的历史上执行；联合 RL 以不同层级反馈改进计划与转移执行。训练中有多计划及共享历史下的多续段探索。**这是训练期的分组探索，不能据此把它说成推理时 best-of-N 筛选。** 它还使用相邻步骤条件平滑，减轻硬切换的问题。[方法 §4、实验 §5](https://arxiv.org/html/2606.28016v2)

对本项目最有价值的不是“加一个 LLM 把事件分段”，而是提醒我们：**全段事件安排正确，不代表转移时刻真正执行正确。** 例如“先挥拍后飞球”在粗时序上成立，实际接触仍可能不存在。下述是本项目的改造方案，不是声称 TempAct 已验证这些物理能力。

**吸收一：全段过程与转移窗口共同训练，但不拆视频生成。** 在 L_exec 的同一个 BCE 任务中混合两类输入视图：全段判断完整过程；带前后上下文的重叠窗口判断当前状态转移。窗口只是监督取样范围，不是独立生成段，不需要 planner 在推理时分配五个语义阶段。

**吸收二：用同一前置状态附近的错误差异教执行。** 在有对应关系的数据中，保持布局、相机和已发生历史一致，制造“响应提前、交互缺失、动作残留、动作重放”等局部差异。这样 L_repair 更容易把监督落到真正出错的转移，避免把不同相机／外观的差异误当成物理纠错方向。不生成一组候选再择优，而是用明确的训练对。

**吸收三：观察过渡，不做硬提示词开关。** P 已有时间坐标，同一文本在不同视频时刻通过 P 的文本交互得到不同表征；训练窗口覆盖变化前、变化中、变化后的上下文。既不能完全看不到接下来要发生的交互，也不能把未来结果提前画进当前帧。这里增加的是有对应证据的训练视图，不是新的提示词调度器或固定进度槽。

不采用的部分：独立可训练 LLM planner、按固定 latent span 切换长步骤提示词、嵌套的多候选 RL、额外计划奖励／美学奖励／KL 目标。它们有自己的应用价值，但会改变本项目的骨干、成本和消融问题；不能因为论文有效就全部加入。

也不能把论文结果理解为“SFT 原理上不能学顺序，所以我们必须 RL”。我们的选择是先在既有四项任务内，把时序有效性监督放到实际生成状态及可对应的转移窗口上；是否足够仍靠实验。**时间先后是因果合理性的必要线索之一，不是充分条件**：球拍动作在前、球飞在后，仍可能是无接触响应；这部分依然需要细节观察和受控交互监督。

## 4. 最小架构：一个共享单元，两个写入口

### 4.1 哪些是状态，哪些只是临时视图

| 内容 | 形态和生命周期 | 作用 |
|---|---|---|
| 视频状态 z | Wan 原生 VAE 时空 latent；唯一活动采样状态 | 最终要生成和修正的整段视频 |
| 过程状态 P | 低维稠密时空网格，跨噪声步保留 | 融合首帧、动作条件、过程预测和当前观察；不是不可更改的计划 |
| 粗／细观察 | 当前 DiT 特征、当前端点估计、选定轮次的 VAE 解码特征 | 按需计算，用后释放；不再另设视觉、运动、轨迹、细化四套持久 latent |
| 速度修正 U | 与原生 VAE 网格同形状；单噪声步内累计，跨步清零 | 提供带方向、可撤销的直接输出修正 |
| 首帧与文本 | 固定输入及已有编码 | 外观和任务条件；不保存未来 GT，不含实体语义清单 |

P 的网格单元只是位置，不是对象槽位。对象移到哪里，信息就通过时空注意力传播到哪里；一个对象可以占很多位置，同一位置也可随时间被不同对象占据。通道不预先规定质量、接触、速度等含义。

U 不是第二条视频轨迹，更不是候选视频。它类似本次速度预测的累积工作缓冲，最终只参与更新同一个 z。

### 4.2 一个共享计算主体

暂用 `SharedCell` 表示一个参数共享的小型时空 Transformer。建议原型为 2–4 个 block、宽度 256；具体参数属于待测初值。

内部只做三件事：

1. 粗网格上进行跨完整视频时间的过程预测与状态融合，承担可修订的隐式规划职责。
2. 从局部细网格和当前文本条件读取细节，把局部变化放回全段上下文，学习前置条件与后果的关联更新；这是否达到关系推理能力需实测。
3. 输出更新后的 P，以及原生网格上的修改方向 D 和强度门 G。

粗网格可使用分解式时空注意力；细网格采用局部窗口／局部到粗网格的交互，避免原生细网格全局 N² 注意力。不能把 soft gate 乘法称为稀疏加速：首版仍计算全场景细网格，小门只决定修改量。

`initialize`、`assimilate`、`predict`、`correct` 是同一单元的调用模式，通过输入掩码和少量模式／轮次嵌入区分，不是四个独立大模型。辅助预测头、G 头、D 头只是小型读出。

### 4.3 写入口 A：较早层的过程条件

P 经共享低维投影，与早期 Wan token 交互。首版检验两个位置：patch embedding 后、第 10 个 block 前，均指本地 30 层配置；位置只是原型，不宣称天然最优。

这使“谁接近谁、哪些时刻需要互动、原位置应该随移动改变”等过程信息在大部分时空计算之前参与生成。不是先由一个小模型独立生成确定轨迹，再把轨迹硬贴到视频。

主干基础权重可以先冻结，训练这些条件投影和共享单元；**冻结权重不意味着关闭输入梯度**。只有当受控能力测试表明该入口仍不足时，再在相同早期层加入少量 Q/K/V LoRA，并单独证明必要性；不预先把全层 LoRA 变成必选模块。

### 4.4 写入口 B：原生 VAE 网格的速度残差

小输出头产生与 Wan 速度输出同形状的带符号增量，直接作用于速度场。它不必全部经过冻结尾部的表示映射，因而补充了中间特征回写的方向限制。

作用包括调整接触前后的短时位移、移除旧位置残留、恢复局部轮廓等。**直接写速度并不天然保证这些编辑正确**；正确性来自实际输出监督、过程学习和稳定性约束。

这两个接口由同一个 P 和同一个共享单元协调。不是一个网络管数量、另一个管碰撞、第三个管形状。

## 5. 前期如何限制结构，同时保留后续修改能力

### 5.1 起点：首帧和简短动作，不再生成长阶段 JSON

从首帧原生视觉 latent、T5 动作条件、时空位置和同一初始化噪声的池化视图初始化 P。使用同一噪声是为了允许不同 seed 对应不同合理过程；不额外产生几个计划让 verifier 挑选。

学习的限制是：首帧内容与角色应连续，动作应产生必要状态变化，交互前提与响应应相容。**这些是训练中的过程约束，不是运行时手工填入一组固定 q。**

首帧可以提供身份与初始布局，但不能单凭单帧恢复速度、质量和摩擦。文本若只说“红球撞蓝球”，模型要在可能的条件分布中生成合理过程；若需要验证精确动力学，则测试条件必须进一步可辨识。

### 5.2 随去噪进度改变侧重点，不对视频硬分段

| 去噪区间 | 主要工作 | 仍然允许的修改 |
|---|---|---|
| 高噪声前期 | P 引导全局布局延续、角色、运动路径和交互前提 | 允许较大结构调整；不信任尚不可读的 RGB 细节 |
| 中期 | 联合修正互动双方、接触窗口、来源／去向和全段事件过程 | 粗结构与细节均可调整，常是重要的校正区间 |
| 低噪声后期 | 读取更清楚的细节，修接触边界、轮廓、短时响应和残留伪影 | 保留小幅结构修改入口，不把早期 P 或任何视频片段永久冻结 |

首版用噪声条件化的共享网络学习分工，固定少量启用校正的步位。先比较早／中／晚校正效果，不同时添加一个可学习分段控制器。可用前约 30%、中约 40%、后约 30% 的采样步作初始分组，但阈值需结合实际 shifted sigma 记录校准，不能把步号当均匀噪声。

### 5.3 “保持正确结构”不是不再观察它

P 必须可被新观察修订；低需求区域可以减少写入，但仍参与读取。球已经离开后的桌面虽然静止，却必须继续被观察，否则最容易出现第二本书或第二个球。

训练同时包含两种配对状态：早期正确、后期出现退化；早期错误、需要改变其后果。前者教保持与细化，后者教撤回与重构。二者使用同一个实际修正目标，不增加“锁定早期”损失。

吸收 TempAct 的转移视角后，P 的训练还需区分“未来结果提前出现”和“过去动作迟迟不结束”。这些错误不能仅靠让 P 更平滑解决；过度平滑恰可能把相邻事件混在一起。使用明确前后状态的监督训练时间相关表征，不要求 P 在某个固定帧号机械切换。

### 5.4 是否需要 planner／reasoner：职责有价值，独立实体暂不需要

**客观判断：仅有细粒度误差检测和局部残差，并不足以替代过程规划与关系推理。** 但也没有证据表明本任务必须同时加入一个 LLM planner 和一个独立 reasoner。现有架构先以同一 SharedCell 实现两种职责，不能只改名字而不改变训练和验证。

| 职责 | 需要回答的问题 | 读取什么 | 修改什么 | 当前取舍 |
|---|---|---|---|---|
| 隐式过程规划 | 由当前条件出发，什么过程能够实现文本动作 | 首帧／当前可信状态、动作文本、全段时间坐标、P | 稠密 P 中的未来过程表征，再通过早期接口影响生成 | 保留职责；不输出人工事件清单、固定轨迹或多个候选计划 |
| 交互关系推理 | 当前细节是否满足动作前提；修改此处会影响哪些后果 | P、细节观察、互动双方与前后时间上下文、上轮实际响应 | 联合修订 P 与有方向的速度更新，而不只调 G | 保留职责；与规划／校正共享参数，没有独立推理大模型 |
| 独立符号／LLM 规划器 | 是否需要复杂显式任务分解、工具或可读计划 | 外部语义上下文 | 文本步骤或符号计划 | 首版不加入；目前会增加成本、错误传播和消融负担 |

具体计算顺序是：**过程预测 → 当前细节核对 → 跨位置／跨时间融合 → 联合更新 → 读取真实后果**。这是一个连续更新过程，不生成多个假设视频再用评分选一个；每轮只产生本条轨迹接下来要执行的一个更新。

为什么细节必须参与推理：

- 球拍与球之间的小缝隙，可以否定“碰撞已发生”的过程假设。合理更新可能需要改挥拍路径和球的起飞时刻，而非只把两者轮廓粘在一起。
- 桌面旧位置多出一本书，应联系此前书的移动和身份连续性。只做局部外观编辑可能删掉错误的一本，甚至把下落的书一起消掉。
- 接触处压缩、液体细流或支撑边缘变化，虽然面积很小，却可能影响随后的大范围运动；不能在送入 P 前只做平均池化把它们抹平。细节先经局部编码与上下文交互，再压入粗状态通道，同时保留直接细网格写入路径。

为什么不对所有背景做强规划：关键交互通常需要更多过程约束，但静态区域仍提供支撑、阻挡和旧位置证据。保持全局低成本读取，让当前细节和过程差异决定实际更新；不额外建立一个“重要性 planner”逐区域出具计划。

监督仍是原来的四项：L_dyn 训练前置条件到后续状态的预测；L_exec 约束全段及转移执行；L_repair 教共同修改产生正确实际结果；L_video 保留可生成的视觉分布。不新增推理文本蒸馏、链式思维或单独规划 loss。若使用教师解释，只作离线数据核验线索；合理解释不能代替视频中的接触和状态变化证据。

**验证标准比模块名称重要。** 在相同参数和调用预算下，与“只读当前局部细节、无跨时刻 P 交互”的版本比较；再做受控前因变化与实际输出干预测试。如果只提高辅助预测或只输出好看的注意力图，不能声称实现了物理 reasoner。若共享方案已经有效，就不拆网络；若失败，先判定是监督、表示、交互范围还是容量不足，再决定是否扩大架构。

## 6. 细粒度：看哪里、为什么重要、哪里错、怎样改

### 6.1 四个问题不等于四个预测网络

| 问题 | 信息来源与实现 | 不能混淆的内容 |
|---|---|---|
| 哪里与现象相关 | 文本—视觉交互；训练时参考 ProPhy 式区域信号 | 名词相关区域不等于全部事件区域 |
| 哪里对过程重要 | 学习到的前置条件—后果预测；受控干预数据；包含接触、支撑及被腾空的位置 | 运动幅度不等于因果影响；静止支撑也可重要 |
| 哪里当前需要修改 | 当前实际端点、细节观察、P、上一轮真实变化共同进入 G／D | 重要但已经正确的区域不必被加强改写 |
| 如何修改、力度多大 | 有方向 D、强度 G，经实际执行后的输出监督学习 | G 不是力的大小、可靠性概率，也不是独立 verifier 的通过分数 |

不构造 `相关 × 重要 × 错误` 三个硬掩码相乘。任一图漏检都可能把必要修改永久屏蔽。全局读取始终存在，背景监督有正权重。

### 6.2 两种尺度，一份状态

**粗观察**保留整段时间关系，回答前后是否连贯、动作是否重复、源和接收端是否同时变化。

**细观察**先读取未进一步空间池化的原生 VAE 网格，以及 Wan 早／后部特征的小投影视图。不能只把整个物体平均成一个向量；细节头需要知道边缘、间隙、旧位置和邻近时刻的差异。

还要正视本地分辨率：Wan2.2 TI2V-5B 的 VAE stride 为 `(4,16,16)`，DiT patch 为 `(1,2,2)`，所以一个 DiT token 的名义空间步幅约为 32×32 像素；时间压缩也可能把短接触合到 latent 通道中。token 不是独立小图片，但仅在池化 token 上做全局判断，确实可能看不清一个短促接触。

因此在选定的中／后期校正轮中，增加**现有 VAE 的细节观察视图**：

1. 对当前端点估计调用现有 VAE 解码，不调用新的外部视频理解模型。
2. 读取解码器较高分辨率的中间特征，并可复用最终帧；不重新生成一段候选视频。
3. 将局部空间和子帧信息通过 packing／小投影压回细网格通道，避免单纯时间平均丢失接触顺序。
4. 使用相同 SharedCell 融合这些观察，不另加一个“细节物理网络”。

解码细节并不能恢复 VAE 永远不能表达的信息。必须先测试 GT 经 VAE 往返后是否还保有相关接触、形状和数量。如果重建就失败，应调整有效分辨率、数据取景或明确任务边界，而不是用循环掩盖表示缺口。

### 6.3 高重要性不意味着处处强改

训练参考权重采用简单的正底座形式：

\[
w_i=\operatorname{Normalize}\bigl(1+\beta\,p_i^{\rm ref}\bigr),\qquad 0\le p_i^{\rm ref}\le1.
\]

可靠性另外作为监督有效权重使用。p 可以来自可信事件区间、软定位或受控数据中的作用范围，不从注意力大小直接推断真实作用力。

建议重点窗口带上发生前后的上下文，并同时覆盖作用双方。书下落的窗口既含下落书，也含桌面旧位置；倒水既含接收容器，也含水源与中间流动。必须保留全段训练样本，避免只学会一个局部动作而不知道何时结束。

窗口采用不固定长度、可重叠的取样方式，训练位置可来自可信转移标注，并加时间偏移以避免模型记住固定边界。推理仍读取全段粗网格和全场景细网格，不依赖外部 teacher 替它找出窗口；没有新增在线事件检测器。

不因为某处“物理很重要”就把 G 目标设成 1。**正确且重要的细节需要被看见、学好和保持，不一定需要被改。** 强度图的验收看实际修改量及其效果，而不是只看热力图是否漂亮。

### 6.4 多样性、一致性与各向同性

完整状态过程要求合理地发生变化：接近、互动、响应及必要的终态应在时序中出现；这些词是说明和评价维度，不是固定生成阶段或 slot。

多样性指不同 seed 下存在多种有效轨迹、速度、细节和外观，而不是靠对象乱动、复制、重复动作增加变化。训练不能把所有自由生成视频强行拉向一个 GT。

如果“各项同性”指各项一致性，应联合检查身份、数量、动作、因果、形状与文本。如果指物理各向同性，则只对保持物理条件的变换做数据增强：例如共同变换场景与运动方向；不能旋转图像却不旋转重力和边界条件。首版不增加各向同性 loss。

## 7. 内部多轮校正：究竟读什么、改什么、怎样提交

### 7.1 使用一个视频状态，不依靠候选选择

在噪声 σ 下固定当前视频状态 z。P 在轮间更新，U 在该步内累计。基础无条件预测可缓存；有条件预测在结构条件改变后重算：

\[
b^{(r)}=\operatorname{Wan}(z_\sigma,c,P^{(r)},\sigma),
\]

\[
v^{(r)}=v_u+s\bigl(b^{(r)}-v_u\bigr)+U^{(r)},
\qquad
\hat z_0^{(r)}=z_\sigma-\sigma v^{(r)}.
\]

s 为 CFG scale。**将 U 放在 CFG 合成之后**，避免额外校正不知不觉再乘一次 CFG；结构条件对 b 的影响仍受 CFG 放大，训练与推理要使用一致的约定。共享单元接收 s 作为数值条件；常规 FM 在 s=1 的条件预测上训练，实际修正训练另覆盖部署所用的 CFG。

所有端点观察按原生 I2V 约定恢复固定首帧。首帧区域的直接更新为零；不能借纠错偷偷改用户输入。

### 7.2 下一轮读取的是实际输出，不是上轮提出的 D

共享单元读取：当前端点、早／后层投影、可用的 VAE 细节、P、首帧和文本、噪声及轮次、上轮实际端点变化。上轮的写入缓冲 U 可以作为已执行操作的上下文。

同一步内的实际变化为：

\[
\delta^{(r)}=\hat z_0^{(r)}-\hat z_0^{(r-1)}.
\]

跨噪声步时，端点差还包含正常去噪变化，不能将它全解释为校正效果。原型把本轮“上次实际修改”输入清零或显式标记为跨步观察，不冒充同噪声响应。

单元输出新 P、带符号方向 D 和门 G：

\[
(P^{(r+1)},D^{(r)},G^{(r)})=\operatorname{SharedCell}(\text{当前观察与上下文}),
\]

\[
U^{(r+1)}=U^{(r)}+a(\sigma)G^{(r)}\odot\mathcal N(D^{(r)}).
\]

G 为逐时空位置的非负修改强度，方向由 D 承担；`N` 是避免单个输出数值爆炸的逐位置 RMS 限幅，例如 `D / max(1, RMS(D))`，不是对整段视频做归一化。a 是噪声条件下的数值尺度，先使用经校准的简单曲线，不另建预算控制器。

这一写入**允许后轮通过相反方向撤销前轮的错误修改**。关闭 G 不会清除已经写入的 U，也不阻止 P 继续读入新信息。G 与 D 的分解不是唯一的，因此不能把 G 宣称为经过概率校准的错误率；实际应同时记录 `a·G·N(D)`。

随后重新计算完整有条件 Wan，得到新的实际端点。因为 P 已改变，C 版的 H0 缓存不再有效。不能一边声称早期结构已更新，一边继续复用旧前部特征。

### 7.3 同一步内迭代，采样器只前进一步

```text
输入：首帧 I0、短动作 c、一个 seed
z ← 一次初始化噪声，并按原生 I2V 方式固定首帧
P ← SharedCell.initialize(I0, c, pooled_same_noise)

for 每个去噪步 k:
    U ← 0
    previous_endpoint ← empty
    vu ← 无结构适配的无条件 Wan(z, sigma_k)   # 本步内 z 不变，可缓存

    for r = 0 ... R_k:
        b, features ← 有条件 Wan 完整前向(z, c, P, sigma_k)
        v ← vu + CFG * (b - vu) + U
        endpoint ← 恢复首帧(z - sigma_k * v)
        observation ← 粗/细特征 + endpoint
        if 本步启用解码细节:
            observation ← observation + 当前 endpoint 的 VAE 细节

        if r < R_k:
            P, D, G ← SharedCell.correct(
                observation, P, previous_endpoint, U, I0, c, sigma_k, r)
            U ← U + noise_scale * G * signed_normalized(D)
            previous_endpoint ← endpoint
        else:
            P ← SharedCell.assimilate(observation, P)  # 吸收最后一次真实结果

    z ← scheduler.step(v, sigma_k, z)    # 每个 k 仅提交一次
    z ← 原生首帧约束(z, I0)

输出：解码唯一最终 z；不经过候选筛选
```

R_k 表示额外校正轮数，不是视频时间中的动作次数。先采用固定的校正步位和 R=1／2，避免在尚未证明有效时引入学习式停止和重试控制器。即使最终仍错，也要计入失败，不能继续抽到通过为止。

### 7.4 数值和计算边界

- 不在内循环重复调用 scheduler.step，否则会混淆隐藏状态迭代与采样时间推进。
- 不用 `Δv = -Δz / σ` 强迫末期大改；直接学习有限速度输出，严重结构错误主要在前／中期训练和处理。
- U 的方向范围比固定尾部小残差更直接，但有限步数、尺度、网络容量仍有限，不能宣称任意错误都可达。
- 外层首版可先用明确的单步 Euler 参考实现核对闭环，再评估原有高阶求解器；改变采样器时须同步重跑基线。单步内不跳改 z，有助于避免无理由清空求解器历史，但跨步持久 P 的数值影响仍要测试。
- 推理不运行训练用的过程判别器、VLM 或视频教师反向传播。

## 8. 四项损失：删掉“只监督错误图”的独立项

总目标：

\[
\mathcal L=\lambda_v\mathcal L_{video}
+\lambda_d\mathcal L_{dyn}
+\lambda_e\mathcal L_{exec}
+\lambda_r\mathcal L_{repair}.
\]

| 损失 | 单一主要任务 | 监督落点 |
|---|---|---|
| L_video | 学好视频生成分布 | 正常配对训练的条件 flow-matching 速度 |
| L_dyn | 学习给定前置条件后的过程变化 | 同一共享单元的无未来泄漏预测输出 |
| L_exec | 识别并推动完整任务执行 | 实际生成视频相对于文本的过程有效性 |
| L_repair | 学会把当前错误过程修向可信对应过程 | 真实回写、重算后的端点细节表征 |

不另设轨迹、接触、数量、身份、形变、守恒、频谱、注意力、门控或循环单调性 loss。上述错误是四个训练任务的数据覆盖维度，不是暗藏的十项优化目标。

### 8.1 L_video：Flow Matching 不是“只能学画质”

\[
\mathcal L_{video}=\mathbb E\!\left[
\frac{\sum_i w_i\|v_{\theta,i}-(\epsilon-z_0)_i\|^2}{\sum_i w_i}
\right].
\]

在正确数据和足够容量下，FM 可以学习包含物理关联的视频分布；不能从原理上说它学不到物理。问题在于全局去噪目标、数据偏差及小面积短时事件的权重，未必足以教会细致的交互和反事实响应。本版保留其基础作用，加上另外三个明确任务。

权重有正底座且归一化；重点来自可信参考，不用模型自己的 G 给自己降低监督。不要直接给自由 rollout 沿用原 GT 噪声对的 `epsilon-z0` 标签。

### 8.2 L_dyn：从前置条件预测，而不是把真实未来编码进去

冻结视频教师 E，选择经校准的稠密层特征作为目标：

\[
\mathcal L_{dyn}=\mathbb E\bigl[\rho\cdot
\operatorname{Huber}(\operatorname{Pred}_{\theta}(\text{历史},c),
\operatorname{sg}E(x^{ref}_{future}))\bigr].
\]

ρ 表示该目标的可靠程度和可监督位置。同一个 SharedCell 完成预测，因此知识有机会进入实际写入，而不是停留在独立辅助塔。

必须单独构造预测训练视图：只编码允许看到的历史，未来仅进冻结目标分支；清空该视图的历史 P，不带入看过未来的生成缓存。不能先让双向教师编码完整视频，再把未来 token 遮住，因其历史 token 可能已含未来信息。

少量受控数据改变作用方向、是否发生接触、支撑是否解除等条件，让未来响应随条件改变。自然视频的相关性和注意力不是因果识别的充分证据。稠密遮蔽只作经验证的训练选项，不假定复制 Causal-JEPA 的收益。

确定性 Huber 预测对多解未来存在均值化风险。因此该目标优先用于短时、条件较充分、可对应的状态转移；不把一个预测均值硬编码成唯一视频轨迹。自由生成的多样性由随机 z、视频目标和条件数据保留，必须实测。若多解平均已成为主要瓶颈，应以概率预测替换本项，而不是再加第五项损失。

### 8.3 L_exec：文本对应的是完整事件，不是几帧“像是发生过”

用冻结视频表征和一个小型时序／文本判别头，学习一个二元交叉熵任务：给定视频和当前描述，这个完整过程是否正确执行。训练正负样本包括角色反转、无因响应、漏做、重复、复制、静止冒充完成等。

判别器校准阶段用可信标签 y：`BCE(C(x,c), y)`。用于生成器训练时冻结其参数，对实际生成端点或短展开结果计算 `BCE(C(x_hat,c), 1)`。这是同一个过程有效性任务的教师校准与生成训练，不增加独立排名、接触或数量目标。

**TempAct 启发下的修订：同一个头、同一个 BCE，混合全段与转移窗口两种数据视图。** 窗口判别输入增加窗口范围／相对时间和对应的任务语义查询，标签回答“这段可见前后状态是否构成当前要求的合法转移”，不是“这个短窗口是否完成了整段所有动作”。这些查询是训练标签的描述，不是运行时 event slot；teacher 只能按可见证据给标签，遮挡或上下文不足时标记未知。

例如接触前的一小段“蓝球暂时不动”可完全正确；不能因为它还没呈现最终运动就作为静止失败。全段视图负责最终动作确实发生，转移视图负责不提前响应、不错过互动、不残留或重放旧动作。一个最终均分不能让局部严重错误被背景画质抵消，因此两种视图分开取样、分别记录指标，但不另设局部排序或奖励损失。

`x_hat → 冻结编码器／判别头 → 损失` 必须保留对 x_hat 的梯度，再经 VAE／Wan 回到共享单元。VLM 的离散回答不能直接反向传播；它只能离线提供标签。高噪声端点不可读时不强行让清晰视频判别器评分，应在经校准的中后期或短 rollout 结果上使用。

这个头**只在训练和独立诊断中存在，不参与推理选片、重启或通过判定**。一个全局 BCE 仍可能被教师盲点和捷径利用，不能代替配对修正与局部观察；必须用独立评估器和人工复核防止自证。

### 8.4 L_repair：监督修改后的实际结果，而非只预测“有错”

设当前实际端点为 q，更新 P 和 U、重算完整有条件 Wan 后的实际端点为 q+；z_ref 是与该错误状态明确对应的可信正确视频 latent。这里 q 只是公式中的端点变量，**不是 query／slot 集合**。

定义固定特征映射 Φ，包含经固定尺度标准化的原生 latent 与现有 VAE 解码细节视图。各位置在同一对应网格上比较，按需要加入有效区域／可靠性权重：

\[
\Delta\Phi_{actual}=\Phi(q^+)-\operatorname{sg}\Phi(q),\qquad
\Delta\Phi_{ref}=\operatorname{sg}\bigl(\Phi(z_{ref})-\Phi(q)\bigr),
\]

\[
\mathcal L_{repair}=\operatorname{Huber}_{w,\rho}
(\Delta\Phi_{actual},\Delta\Phi_{ref}).
\]

这个式子代数上等价于对修改后输出的对应表征做恢复监督，**不把简单重写公式包装成新型损失**。它与普通 L_video 的关键区别是：训练对象包括真实可配对的错误／偏离状态，监督必须经过两个写入口和真实重算；细粒度特征也使短接触与局部残留不只由全局像素均值支配。

梯度教 G 与 D 的组合怎样产生有效变化，而不是只教 G 学一个误差热图。对于本来正确的配对样本，参考改变为零，学习减少无效改写；对于复制错误，修改目标要包含复制位置和被露出的背景。多个内部轮次可以复用同一目标，但不另加“每一步必单调改善”约束；是否实际改善要通过记录证明。

限制必须明确：

- 仅对具有可靠空间、时间、场景对应的错误／正确对使用。无对应参考的视频只用适用的其他任务，不凑配对。
- 严重结构错误的修复样本主要放在仍有修改余量的噪声阶段。不能在 σ 接近零时强迫模型以无限速度恢复完全不同的场景。
- 这不是常规直线 FM 的速度标签；不把错误状态配上原来的 `epsilon-z_ref` 并宣称仍然正确。
- 它使“如何改”更可学习，但不能保证多轮收敛、所有编辑可达或物理定律被唯一识别。

## 9. 监督和训练：teacher 可以替代部分 GT，不能替代证据

### 9.1 三类数据各尽其用

| 数据 | 可用监督 | 不允许的用法 |
|---|---|---|
| 核验过的真实过程／受控仿真 | 四项均可按对应关系使用；提供少量因果与数量校准锚点 | 把仿真域效果当自然视频泛化已解决 |
| 可靠程度可校准的自然视频与 teacher 信号 | L_video、L_dyn、可信 L_exec；软重点权重 | 把 VLM 注意力直接当真实接触、力、精确修改向量 |
| 模型自身生成的失败状态 | 可信标签、错误统计；明确保留配对关系时用于 L_repair | 为任何失败视频随便找一段“看起来正确”的 GT 做逐位置回归 |

ProPhy 式信号主要解决“哪里可能相关”，不负责生成正确轨迹。错误类型标签、作用范围与完整过程标签要分别校准；未知区域不直接标为正确或不重要。

### 9.2 怎样得到配对错误，不用推理时筛选逃避

1. **受控过程对**：在相同场景资产和相机下构造正确／错误过程，明确哪个改动导致接触错位、无因响应、身份复制或终态重放。错误过程不是物理真值，只是输入扰动；正确端提供恢复目标。
2. **可恢复的编辑扰动**：对正确视频制造短时位移、复制、局部时间延迟等，保存精确对应；同时检查扰动是否产生容易被模型识别的合成接缝捷径。
3. **近邻自生成偏离**：从与参考视频有明确耦合的训练状态进行少量自身 rollout，保留足够上下文；只有参考仍有效时才使用配对修复。
4. **自由生成的真实失败**：用于过程标签和独立评估。没有可靠修正目标时不伪造它；不能要求 teacher 仅凭一个分数提供正确的高维更新方向。

配对数据特别增加三种转移偏差：结果提前出现、前一个动作拖延到下一动作、已完成状态重新回到未完成并重放。每个样本保存对应窗口和前后上下文，优先在同一场景／相同前置历史下比较。仅拼接或倒序产生的接缝可能构成捷径，需混入真实模型错误及人工核验样本。

数据质量核验不同于正式推理筛选：训练需要知道标签是否可靠，而每个正式请求仍只输出本条轨迹的结果。不依赖“生成大量成功候选蒸馏”作为核心数据来源，也不通过只保存成功输出虚报效果。

### 9.3 从易到难，任务不随阶段增加

**训练阶段一：接口与表征。** 用正常 FM 数据和历史预测视图训练共享单元、两个接口的小投影；让新增出口从接近零的影响开始，不扰乱原生分布。并行校准训练用过程头。

**训练阶段二：明确配对的纠错。** 增加 L_repair，覆盖小误差与严重结构误差，优先接触、复制和角色不一致。内部展开一轮，确认实际输出确实被改变；同时保留正确样本以抑制过修。

**训练阶段三：自身反馈和完整任务。** 展开 1–2 轮，逐步加入实际生成状态及 L_exec，缩小训练时只看 GT 特征、推理时只看自身预测的差距。过程预测仍使用隔离的历史视图，不能泄漏未来。

四项损失的权重从有效监督的尺度校准，记录梯度方向冲突与背景退化。若动态任务只改进辅助预测却不影响生成，就要调整共享／写入位置或删掉无效设计，不再添加一堆新约束。

## 10. 能否解决用户列出的错误：逐项说明作用与边界

| 错误 | 本版必须做出的实质修改 | 为什么比末端小残差更有针对性 | 仍需承认的边界 |
|---|---|---|---|
| 红球不动，蓝球自己移动 | 前期改变红球路径和角色绑定；联合修改接触前后两球响应 | 过程条件在早层参与，直接速度出口可改变全段而非只补接触纹理 | 首帧／文本不充分时仍存在动力学多解；不能保证任意场景都学会 |
| 球拍没碰到球，球先飞走 | 细读拍面—球间隙和相邻帧；同时改接近时序与离开响应 | 不只看终点或大尺度轨迹，配对监督包含具体时空作用点 | 单目遮挡下真正三维接触可能不可判定，不能把二维重叠当唯一标准 |
| 书落下后旧位置再出现一本 | 读取全段和旧位置，删除复制并恢复露出的背景 | 全局 P 与全场景细读避免只关注那本正在下落的书 | 稠密记忆不是严格实体守恒机制；还需遮挡、出入画和可分裂对象的区分 |
| 同一事件执行两次且不完整 | 改后段重放和终态，同时保留第一次完整过程 | 全段执行监督和持续状态，不用固定阶段钟重新触发动作 | 不能仅从低运动量推断结束，也不能把本来要求两次的文本标错 |
| 一直静止却说完成 | 学习动作要求的状态变化，并用静止负例约束 | 不是只优化“不违反物理”的静态画面 | 也不能奖励无关镜头晃动或错误对象的移动 |
| 源不减少、接收端增加 | 联合修改来源、途中和接收端，检查过程变化 | 粗层关联覆盖远端，细写覆盖流出／流入边界 | 无真实体积、遮挡和三维数据时不能保证精确数值守恒 |
| 形变、碎块化和穿模 | 在结构正确的前提下修局部轮廓、短时形态和几何关系 | 细节观察直接来自可见端点；训练看真实修改是否修好 | VAE 上限、复杂三维几何和 teacher 盲区仍可能限制；不能一概归为“因果模块不够强” |
| 后期画质提高但动作退化 | P 跨步保留过程信息，观察实际退化后定向纠正 | 不是只保存一个早期快照，也不是无条件放大所有运动 | 稳定但错误的 P 可能自洽，需要配对纠错与独立评估揭示 |

结论是：**D 对这些问题提供了明确、可训练的干预路径，但目前没有足够证据保证全部解决。** 尤其不能从“能回归物理特征”跳到“能生成正确物理过程”，也不能从少数成功例子跳到开放世界可靠性。

## 11. 本地 Wan 可行性与工程实现边界

### 11.1 已核对的接口，不把设计当成已实现

本轮只进行了只读接口核查，没有修改模型代码、训练或生成新视频。

- [model.py](/home/liuzhirui/model/Wan2.2/wan/modules/model.py:410)：原生流程为 patch embedding、时间／文本编码、逐层 blocks、head。新增早期条件要修改此流程或建立适配包装。
- [TI2V 配置](/home/liuzhirui/model/Wan2.2/wan/configs/wan_ti2v_5B.py:16)：30 层、3072 隐藏维度、VAE stride `(4,16,16)`、patch `(1,2,2)`。本文位置和分辨率说明以此配置为准。
- [textimage2video.py](/home/liuzhirui/model/Wan2.2/wan/textimage2video.py:549)：原生循环进行 CFG、scheduler step 并重新施加首帧约束。内部纠错循环应位于一次 scheduler step 之前。
- [VAE decode](/home/liuzhirui/model/Wan2.2/wan/modules/vae2_2.py:812)：本地解码按时间推进并维护缓存；不同端点的解码不能混用旧缓存。增加细节观察需要明确的 feature-return 包装，不是当前 API 已经免费提供。

### 11.2 缓存、梯度与细节读取的必要规则

1. 同一步内 z、σ 不变且无条件分支不受 P 影响时，才能缓存无条件预测；跨步失效。
2. P 或 U 改变后，细节观察必须对应当前实际端点。尤其 P 改变后，早部特征不得复用。
3. VAE 的时间缓存只服务同一次完整解码。不能独立裁出一个后段 latent 就假装与完整视频解码完全一致；流式读取也要保持前置上下文。
4. 冻结 Wan／VAE／teacher 参数时，训练实际输出监督仍需保留到输入的梯度。推理可关闭梯度；训练不能把关键路径包进 `no_grad`。
5. 默认 VAE 包装输出有 clamp。训练细节目标优先使用合适的 pre-clamp 特征，检查饱和导致的梯度问题；最终视频导出继续使用正常范围处理。
6. 解码细节只在若干中后期步启用，流式提取后压缩保存；这是降低观察成本，不是把视频分段生成。没有细节观察的轮次显式标记缺失，不把旧特征当当前证据。

### 11.3 成本必须重新计算，不能沿用 C 的尾部重跑估计

假设 50 个外层步，原始 CFG 每步做两个完整 Wan 前向，约 100 次完整前向。若在其中 10 步各做 2 次额外校正，并缓存无条件分支，则多 20 次完整有条件前向，**仅 DiT 前向数量约增加 20%**。实际还增加共享单元、早期接口、VAE 细节解码及内存搬运；不能把 20% 写成已测墙钟开销。

如果所有 50 步都做 2 次额外循环，则仅 DiT 前向约翻倍，不是“几乎免费”。公平对照需要相同完整前向次数或墙钟预算。

举例：97 帧、704×1280 输入在该 VAE 设置下约有 25×44×80 个 latent 位置。48 通道的 FP32 U 约 16.1 MiB；粗 P 若使用 25×6×10×256 个 BF16 元素，约 0.73 MiB。**这些只是张量本身，不是训练总显存**；Wan 激活、细网格投影、全分辨率解码和展开图通常更重要。

工程首版先测 R=1，再测 R=2；采用 activation checkpointing 和短展开。若细节解码开销不可接受，先比较减少其调用次数与减少特征层，而不是增设一个教师蒸馏视觉塔来补另一个模块。

## 12. 面向 CVPR 的创新候选：集中，而不是全面认领

### 12.1 主贡献候选只有两条

**候选一：可学习的结构先导与细节校正协同。** 一份分布式过程状态既在结构形成前参与生成，又根据原生细网格／解码细节和实际响应被修订。需要证明它同时减少早期结构错误与晚期过程退化，而非简单增加参数或多跑 DiT。

**候选二：面向实际生成响应的纠错学习。** 从配对的过程错误中训练共享单元，监督经过真实重算后产生的改变，联合学习改哪里、沿哪个方向和多大力度；正式推理不依赖外部 verifier、世界模型反向传播或候选淘汰。创新重点是过程错误数据、闭环学习与强弱写入的整合机制，不是第 8.4 节的代数改写。

细节观察、早期接口、速度残差、gate、recurrent 都是已有基础思想。单独列成四五个“全新模块”反而会削弱论文可信度。我们只能提出有依据的创新假设，不能在没有实现、实验和更充分近邻比较前保证 novelty 足够或投稿录用。

### 12.2 与近邻的区别必须可实验验证

| 近邻 | 不能再认领的内容 | 本版需要证明的增量 |
|---|---|---|
| PHANTOM | 物理 latent 与视频交互、教师动态监督 | 单一轻量状态＋实际响应纠错是否有更好的效果／成本 |
| SRVS | 内部多轮、区域选择性细化 | 学习到的更新规律是否优于利用原模型先验反复细化 |
| PhaseLock | 前期运动信息保持 | 可撤销过程状态是否既保留正确先验又能修早期错误 |
| FlowAnchor | 修改定位与强度分开 | 物理过程监督是否使修改具有因果／交互意义，而不只是编辑更明显 |
| OMR | 单条生成轨迹的物理反馈 | 不在推理反传外部教师时，内部可学习校正是否仍有效 |
| VACE／SOAR | 条件编辑能力、偏离状态纠错学习 | 全段物理关系与短时关键细节的联动纠错是否超出一般编辑收益 |
| TempAct | 时间安排与转移执行分开学习 | 不增加 planner 和分段提示时，稠密过程状态及转移监督能否改善顺序，并进一步改善真实交互而非仅动作排列 |

### 12.3 什么证据才能说“模型学到了物理信息”

至少满足以下四类证据，而不只是最终好看：

1. **预测**：不看真实未来，前置条件变化后能预测相应响应；和相同容量、只学 FM 的模型比较。
2. **干预**：受控改变接触、支撑、作用方向时，结果相应变化；没有原因时不机械保留后果。
3. **利用**：打乱／替换 P、移除预测监督后，生成中的相应行为发生可解释变化，而非只影响一个辅助 probe。
4. **泛化**：新外观、新布局、近失碰与成功碰撞、新组合任务上仍成立。多个随机 seed 全量计入，不能 best-of-N。

这些最多支持模型学习了可迁移的过程与交互信息；恢复唯一真实质量、摩擦或完整因果图需要额外可辨识证据。

## 13. 最小验证与消融：先找瓶颈，再扩模型

### 13.1 在大训练前完成三项能力诊断

**表示诊断。** GT 经 VAE 往返，检查关键接触、复制、形变是否仍可见；校准 teacher 对同一组正确／错误对是否敏感。

**接口诊断。** 在少量明确配对样本上，使用已知参考做受控优化，分别测试 C 的固定中间小残差、早期结构接口、直接速度接口和二者组合。它只是离线“接口能否产生所需改变”的实验，不是正式推理优化或筛选。优化失败不构成数学不可达证明，但可暴露训练前的实际瓶颈。

**响应诊断。** 对 r=0、1、2 记录实际变化、正确区域损伤和错误类型变化。必须区分提出的 D 看起来合理与重算后的输出确实正确。

若 GT 重建已失败，先处理表示；若参考可达但模型不会定位，处理观察与数据；若只会定位不会改，处理实际修正监督／写入口；若只在训练教师评分上变好，处理教师盲点。不能把所有情况都归结为 R 不够大。

### 13.2 消融不按每个小投影逐一拆模型

| 对照 | 主要回答的问题 |
|---|---|
| 原生 Wan；另加等预算更多步版本 | 收益是否只是多算力 |
| C 版固定中间回写 | 更强的结构／输出接口是否必要 |
| D 同架构，仅 L_video | 收益是否来自物理过程学习而非参数增加 |
| D 完整方案 | 总体效果与成本 |
| D 去掉早期结构入口 | 是否缓解早期路线、角色和数量错误 |
| D 去掉直接速度入口 | 细节和较强更新是否还有效 |
| D 不读解码细节，保留原生细网格 | 细节观察是否值得成本 |
| D 开环／不读上轮实际响应，匹配调用次数 | 循环是否真正利用反馈，而非重复前向 |

再对三项辅助损失分别做移除实验；这是训练任务消融，不新增模块。最初只做必要的能力诊断和核心对照，只有初步收益成立才展开完整矩阵。局部加噪、LoRA、学习式步位选择都不进入默认消融组合。

### 13.3 评估要求

- 在保持输入一致的配对比较中报告碰撞／近失碰、角色、数量身份、单次完整执行、形变穿模、伪影和文本对齐。
- 报告联合成功率：同一视频中动作完成、角色正确、交互合理、数量身份连续且画面可用；不能分别在不同视频上满足指标。
- 报告静止失败率、无因响应率、重复动作率及新增错误率，避免改善一个问题却引入另一个。
- 对转移单独报告提前响应、转移延迟、相邻动作混合与结束后重放。另做“移除转移窗口视图、保留同量全段训练”的数据消融，确认 TempAct 启发的改造有独立价值。
- 记录每个 seed 的完整结果和成本；多 seed 是统计评估，不是推理选优。多样性同时报告全量分布、有效比例及有效样本中的变化范围。
- 使用独立人工核验与不同于训练教师的评价工具。已有 [Physics-IQ Verified](https://arxiv.org/abs/2606.18943) 对原基准的输入／参考质量作了审计，提示评估数据本身也必须核验。
- “接口参考优化可达”“教师 oracle 输入”和“真实首帧＋文本输入”的结果分列，不能混成正式能力。

## 14. 局部加噪／回退的最终态度：允许研究，但不做默认解法

最新要求允许合理的局部采样，因此不将其一概视为禁区；但现阶段并非不可缺少。先让上面的单轨迹确定性闭环成立，才有理由讨论额外的修复自由度。

若受控实验显示某类中期结构错误确实难以通过现有接口改变，可另立一个有限局部再条件化实验，必须同时满足：

1. 只有一个活动视频状态，不建立候选树，不保留若干结果择优。
2. 只对有依据的局部及必要前因后果范围操作，保留首帧和未涉及内容；不能只重画接收端而不改原因。
3. 使用预先声明的固定调用预算，调用后继续当前轨迹；不因为 verifier 不通过而反复重试。
4. 在训练中覆盖对应混合噪声状态。本地 Wan 接受逐 token 时间参数，不等于它已学会任意区域混合噪声修复。
5. 重建受影响的 DiT／VAE／求解器缓存，并计入全部计算与可能的多样性变化。

**SVG 的主箭头不经过此选项，也不以它作为“难例最终总能修好”的兜底承诺。** 如无独立、可重复的收益，就不加入正式方法。

## 15. 最终收敛：保留什么，删除什么

保留：一份可更新的稠密过程状态；一个共享预测／校正单元；早期结构条件和直接速度残差两个接口；全段关联与细节观察；真实输出反馈；可信 teacher／配对过程学习；四项损失。

删除或不默认加入：固定物理量 slot、长阶段 JSON、多个独立 R/W/C 网络、注意力转置式“因果逆图”、完整物理 DiT 分支、独立重要性塔、单独 gate loss、RAFT、整段重生成、候选验证筛选、无条件锁死早期预测、自动重试控制器。

**最重要的研究问题不再是“能不能让模型多想两轮”，而是“它能否利用学习到的过程信息，提前形成可行的结构，并从当前视频的细节与实际响应中学会有效且有限度的修改”。** 如果这一点不能在等预算和独立验证下成立，应删减或重构，而不是继续堆模块或靠筛选掩盖。
