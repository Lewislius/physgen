## 1. 本轮结论与明确撤回的设计

核心主张调整为：

> 通过可信视频监督，使实际生成路径在去噪前期形成并优化可执行的物理过程；中期结合当前真实特征修正结构偏差，但只向尚未执行的网络层和下一正常去噪步传播；后期在保持过程关系的基础上完善细节。

不是“前期猜一个结构并永久锁死”，也不是“中期发现没碰撞，就更新 P 并重新跑完整 Wan”。

| 内容 | 当前决定 |
|---|---|
| 前期结构学习 | 必须有明确监督、优化与生成控制验证，不能只靠命名一个 physics latent |
| P 的监督来源 | 同一 GT 视频经冻结 V-JEPA 2.1 编码得到的稠密时空 token；仅作为训练目标 |
| P 的含义 | 由视频表征蒸馏约束的、可更新的过程状态；不等同于精确物理真值或独立扩散变量 |
| 中期结构修正 | 保留；可修路径、接触位置、响应时序及身份连续性，不局限于纹理 |
| 已成立的结构 | 作为软约束和学习依据保留，不冻结全部 P 或全部视频 latent |
| 同一步回到早层重跑 | 删除；也不通过反复重跑尾部偷换计算成本 |
| 轻量 recurrent | 在共享小单元的低维工作状态中迭代，不在循环里调用完整 Wan |
| 新的实际观察 | 来自当前前向中自然经过的后续层，以及下一正常去噪步 |
| 独立向量场残差 U | 不纳入当前主模型；统一通过内部特征写入和原生输出头 |
| 训练数据 | 只使用 WISA／OpenVid 的视频与描述，以及从这些视频提取的可靠教师目标 |
| 错误视频配对路径 | 删除 x_err 数据依赖及原 L_repair；不另建人为坏视频、扰动错误集或失败视频回收训练库 |
| 监督总数 | 至多四项：FM、早期过程结构、实际输出表征、视频文本过程对齐 |
| 推理筛选 | 不重启、不生成候选再择优、不调用 verifier 选择结果 |

研发验收可以比较多个模型配置，但不能把这种对照变成每次推理的选片策略。

## 2. “正确地基”需要包含什么，怎样才算经过验证

### 2.1 结构不是仅有粗轨迹或低频形状

以红球撞蓝球为例，过程结构至少应支持：红球承担主动接近角色；运动路径能够形成真实交互；蓝球的相关响应有相应前因；身份和数量贯穿过程连续。

接触间隙虽然很小，却可能决定事件成立与否，不能因为空间尺度小就归入“最后修纹理”。书从桌面移走后的空位、球拍与网球之间的关系、材料的来源与去向，都应进入过程建模。

这些是数据和验收维度，不转化为运行时固定语义 slot 清单。

### 2.2 “早期没有专门损失”不等于“早期没有梯度”

FM 可以通过生成主路径训练运动分布；它不是只能学画质。问题是普通全局目标未必充分重视短时交互，也不能保证新增 P 被有效使用。因此本版给实际 P 设置明确的过程监督，并通过实际输出监督训练写入效果。[Flow Matching](https://arxiv.org/abs/2210.02747)

必须分别验证：

1. **表示有效：** P 的受控读出能够反映过程关系，而非只识别球、球拍等名词。
2. **写入有效：** P 的变化能控制生成中的相应关系，而非只在辅助头里正确。
3. **早期优化有效：** 轻量优化后的 P 在开发集上优于未优化状态，并改善实际视频。
4. **保持有效：** 后续细化没有系统性破坏已经正确的角色、身份和交互关系。

探针预测、attention 图或训练 loss 下降，不能独立完成这四项证明。

### 2.3 训练验证与推理保证必须区分

训练阶段可以使用 GT／teacher；能力诊断可以明确标记地使用参考过程表征。正式推理没有未来 GT，因此不能保证每个样本的前期结构都正确。

“结构经过验证”指模型在独立开发条件下达到可信的结构预测、控制和输出表现，不是每条视频都经过在线 verifier 认证后才进入中期。

少步采样先验有时优于长步结果，但错误早期先验也会传播，不能据此一律硬锁。少步完整采样结果也不等于长采样链前几个步骤的中间状态。[PhaseLock](https://arxiv.org/html/2606.06361v2#S6)

## 3. 数据可行性：有错误标注集，不等于有合适的修复配对

### 3.1 本轮核查结论

不能说“公开世界里没有错误视频”。例如 VideoPhy-2 公开训练数据包含生成视频、语义和物理评分，以及违反规则的标注；但公开字段没有提供可直接用于本方案的同场景、同时序、同一初始条件的正确修复视频。[官方数据卡](https://huggingface.co/datasets/videophysics/videophy2_train)

IntPhys2 有可能／不可能事件评估内容，但官方说明将用途限制为评估，不能当成当前生成式训练数据来源。[官方说明](https://github.com/facebookresearch/IntPhys2#license)

因此，本版不假设已有可直接下载使用的修复配对库，也不为构建它增加工程主线。训练限定于：

- [WISA-80K](https://huggingface.co/datasets/qihoo360/WISA-80K) 的视频与标注；
- [OpenVid-1M](https://huggingface.co/datasets/nkp37/OpenVid-1M) 的视频与描述。

公开可访问不等于本地数据已经下载、通过完整性检查或具有严格物理真值；这些都需要在启动阶段核实。

### 3.2 删除的不只是一个变量名

不保留以下等价替代路径：

- 收集生成失败视频，再给它强配一个不同场景的 GT；
- 人为制造复制、乱序或轨迹扰动视频作为必要训练集；
- 把“自身错误状态库”“近邻回正样本”换名后继续作为第四项训练任务；
- 将任意自由生成结果当成与某条 GT 逐像素对应。

保留的是标准视频生成训练：

\[
x\sim\mathcal D_{\mathrm{WISA/OpenVid}},\quad
z_0=E_{\mathrm{VAE}}(x),\quad
z_\sigma=(1-\sigma)z_0+\sigma\epsilon.
\]

模型在这条正常训练前向中产生 P、特征写入、向量场和视频端点预测，再与该样本的可靠参考监督对应。

模型预测当然可能出错，但它是本次正常前向的预测结果，不是另外输入的错误视频数据。内部模块从这些预测及 GT 监督中学习，不能据此宣称已经覆盖任意严重离轨错误。

### 3.3 正常视频也不自动是严格 GT

WISA 的现象描述可帮助选片，但估计性温度、质量等字段不能直接当精确物理量真值。OpenVid 的画质和运动信息也不能证明接触、数量、因果都正确。

应抽查：完整前因与后果、接触可见性、原位置与新位置、镜头运动、重复剪辑、反射和遮挡。不可确认的区域设为未知或低权重，不强行生成标签。

## 4. 最小模型：一个共享主体、一种写入机制、两个顺序接口

### 4.1 状态和观察

| 内容 | 作用与生命周期 |
|---|---|
| zσ | 唯一活动视频 latent，按正常采样器推进 |
| P | 受 GT 的 V-JEPA 2.1 特征监督的稠密时空过程状态；早期形成，中期可修订，传给下一正常去噪步 |
| 当前细粒度观察 | 当前真实 DiT 特征和原生 latent 局部信息；按需读取 |
| 上一观察缓存 | 可选，附带噪声和层位置；是上下文记录，不是第二套物理模型 |
| 低维工作状态 | SharedCell 调用内的临时迭代变量，调用结束后提交一次写入 |

P 的位置是网格坐标，通道不人为对应质量、接触或速度。全局过程和局部细节由同一个小型时空更新主体交互，不另建物理 DiT、对象账本、轨迹塔或 LLM planner。

`P` 是学生在正常前向中预测的状态，`T` 是教师从 GT 得到的监督目标。二者可以有不同通道数，通过只读取 P 的小投影 R 对齐；训练和推理均由首帧、文本、当前带噪特征和自身历史生成 P。禁止用未来 GT token 初始化或替换正式训练中的 P；P 不另设噪声轨迹、速度预测头或独立 scheduler。

### 4.2 接口 A：在当前前向的较早位置建立过程条件

早期噪声阶段，SharedCell 读取当前早层特征、首帧、文本和已有 P，在低维状态中做少量学习到的更新，再向当前特征写入一次。

中期阶段，A 使用上一步传来的 P 作为过程条件；它不等待本步后面新发现的问题，再重新执行自己。

### 4.3 接口 B：在当前前向的中层读取并修正

原生 Wan 从 A 继续向前计算到 B。B 读取的是已经包含 A 写入影响的实际当前特征，而不是 A 预想中的结果。

B 可以更新 P，并向当前 H 写入结构／细节修正。随后仅运行尚未执行的后续层。本步新 P 被下一正常去噪步的 A 使用。

A、B 是同一种特征残差机制的两个顺序位置，参数主体共享，允许必要的层投影与轻量输出接口；不是两套独立大模型。实际位置先小规模验证，不默认铺满大量 block。

### 4.3.1 P、ΔP、A／B、ΔA／ΔB分别是什么

A／B是接口位置与相应参数组，不是两个需要逐元素标签的状态张量。本文将用户所说的ΔA／ΔB明确记为 `ΔH_A`／`ΔH_B`，即对Wan隐藏特征的真实写入。区分四种索引：视频时间τ、去噪步k、Wan层ℓ、SharedCell迭代r；teacher层号又是独立的取特征配置。

当前主线只在A／B执行SharedCell，没有在30个Wan层逐层产生独立ΔP。内部若有多个更新，监督的是选定的实际更新后状态，不能将第r轮ΔP对应到teacher第r层，或对应到视频第r帧的运动差。

\[
D_i^{(r)}=s_i\eta_i(\sigma)G_{P,i}^{(r)}\odot\Delta P_i^{(r)},
\qquad P_i^{(r+1)}=P_i^{(r)}+D_i^{(r)},\quad i\in\{A,B\}.
\]

ΔP是候选方向，D是实际生效的状态增量。gate与候选方向的尺度可以互相补偿，因此原始ΔP的数值没有唯一的物理解释。P及这些增量都是每个样本的激活，优化器训练的是产生它们的权重，不是为每个视频保存一组可训练P。

参考张量P／ΔP／D为`[B,N,256]`，P更新gate为`[B,N,1]`的逐token标量，η(σ)按`[B,1,1]`广播。标量gate沿通道共享，不是256维向量gate；这一选择与E的参数预算一致。

### 4.3.2 写入必须使用实际更新后的P

为避免“辅助P拟合正确、真正写入绕过P”，首版固定如下数据依赖：

~~~text
H_i → 层专属读取投影 → SharedCell(P_i, 文本, sigma)
                              ↓
                        候选ΔP、gate
                              ↓
                    实际更新后的P_i^+
                       ↙             ↘
               共享R → L_struct      层专属写入 → ΔH_i
                                           ↓
                                    Wan后续层 → 视频损失
~~~

\[
Z_i=\operatorname{LN}_i^P(P_i^+),\quad
\Delta H_i=\gamma_i(\sigma)\,
\mathcal U_i\!\left[
\operatorname{sigmoid}(a_i(Z_i))\odot W_i^{\rm out}Z_i
\right],\qquad H_i'=H_i+\Delta H_i.
\]

\(\mathcal U_i\)是固定坐标重排／插值到当前Wan网格，非独立模型；写入矩阵不带bias。方向与写入gate均读取实际P_i^+，不直接从H_i或SharedCell未提交的私有状态另开一条可绕过P的输出路径。H_i仍可通过读取影响P，FM仍经过原生Wan。这样的依赖强制新增写入经过P，但不能保证P每个通道都是物理量，也不能单独证明修改有益。

本步B提交的P_i^+既被本步写入消费，又作为P_next传递；否则若它仅在下一步使用、训练又每批detach，B的状态增量就可能只学辅助特征而收不到实际视频任务梯度。

### 4.4 计算契约

对 K 个正常噪声步，采用原生两路 CFG 时：

- 每个噪声步有条件 Wan 前向一次，无条件前向一次；
- 每个分支中的每个原生 block 在该步仅经过一次；
- SharedCell 可以有额外小规模运算；
- scheduler 每步只提交一次；
- 不额外回跑已执行的早层或尾部。

因此完整 Wan 前向数仍约为 2K，而不是因内部轮次增长到 2K＋额外重算次数。实际耗时仍会增加小单元、投影和观察成本，不能把“不增加 Wan 次数”写成“没有额外成本”。

## 5. 前期怎样学习和优化结构

### 5.1 推理时的优化是学习到的 latent 更新

\[
P^{(r+1)}
=P^{(r)}+s_i\eta(\sigma)\,
G_P^{(r)}\odot\Delta P^{(r)}.
\]

SharedCell 以同一首帧、文本、当前真实特征和当前 P 为条件，进行一到少量共享权重更新，然后提交一次特征写入。它不是推理时使用 GT 反向优化，也不产生多个计划让评分器选择。

同一条件下，不同 seed 的单次初始噪声可以形成不同合法过程；每次请求仍只有一条活动轨迹，不另开计划采样分支。结构更新强度和轮数须经校准；门值和范数不能被解释成物理正确性概率。

A的s_A固定为1。新增B时设 `s_B=tanh(b_B)`、b_B初始化为0，同时W_B^out初始化为0，使B在初始时既不改当前H，也不改传给下一步的P。只把ΔH_B置零仍可能通过P_next改变整条采样链，因此不足以保证初始等价。b_B是B专属的一个可训练标量，包含在参数预算中。

### 5.2 优化必须有监督目标和能力验证

冻结 V-JEPA 2.1 对同一 GT 视频编码，为实际 P 提供稠密时空表征目标。其空间定位与时间一致性使它适合作为过程表征教师；这是采用它的依据，不意味着每个 token 都是接触、速度或因果的真值。[V-JEPA 2.1 论文](https://arxiv.org/abs/2603.14482)

训练同时通过最终实际向量场和可读输出，约束这个 P 的写入是否产生正确过程。只增加 L_struct 时，GT 教师前向可以离线缓存，无需对预测视频解码或对教师反传；昂贵的输出教师梯度是 L_out 阶段的独立成本。

重点不是让小单元内部看起来“更合理”，而是优化之后：

- 角色和必要运动关系更容易成立；
- 接近与接触路径更可执行；
- 相关后果随前置条件变化；
- 视频确实执行，而不只是结构读出头分数提高。

直接对带噪隐藏状态进行可信表征对齐可借鉴 REPA；但通用图像表征并不自动包含物理交互知识，教师层与目标需要单独核验。[REPA](https://arxiv.org/abs/2410.06940)

### 5.3 不在纯噪声处逼迫唯一精确未来

单帧未必能确定初速度、质量和摩擦。同一描述也可以对应多种合法轨迹。早期监督优先采用条件充分的片段与可靠过程关系，不把一个 GT 的全部精确未来强压成唯一答案。

高噪声端点不可读时，先监督隐藏过程表征；实际输出的物理／细节监督只在经校准的可读噪声范围使用。不能把平均化、运动变小误当成结构更稳定。

完整 GT 教师目标可用于标准加噪样本的去噪表征学习，因为它只出现在损失端。接近纯噪声时，当前输入几乎无法确定该 GT 的具体未来，强逐 token 回归可能偏向条件平均。首版对 L_struct 使用固定噪声权重 g_s(σ)，在纯噪声端降为零、离开该端后逐渐增强，并对 λ_s 做训练 warmup；具体范围通过分噪声桶和跨 seed 多样性消融校准。A 位于网络早层与 σ 处于高噪声是两个不同维度，不能混用。

## 6. 中期仍修结构，但修正在正常计算顺序中传播

### 6.1 “地基”是软约束，不是不可修改的第一次预测

中期应保留已成立的身份、角色和前后关系，同时允许依据更清晰观察修正：

- 接近路径和交互位置；
- 接触／支撑成立的细节；
- 响应开始的时刻与相关位移；
- 原位置残留、数量与身份连续性；
- 影响整个过程的局部几何偏差。

这不是只改纹理，也不是每次重新规划整段视频。更新是否保留正确关系，靠过程与实际输出监督验证，不靠“小残差一定安全”的假设。

### 6.2 “没有发生碰撞”的具体处理

若当前 B 的实际特征提示两球路径没有形成接触，SharedCell 在当前接口联合更新过程表征和相关位置的特征，使尚未执行的后续层有机会修正接触及响应。

本步生成继续向前，下一正常噪声步自然读取更新后的 P。**不跳回本步 A，不重新调用完整 Wan，也不多跑一次尾部。**

视频是整段 latent 联合生成的，因此中期可以共同调整视频时间轴上的接触前、接触中和接触后；“下一去噪步”不等于“下一视频帧”。

### 6.3 能力边界必须承认

这条路径比最后几步只改局部纹理更有调整空间，但不保证任意严重早期错误都能在固定预算内纠正。

若角色、布局和运动拓扑同时严重错误，优先改进早期训练、数据与写入能力。剩余噪声步少、接口容量不足或教师看不清问题时，仍可能失败。失败结果计入评估，不以重启和候选选择逃避。

## 7. 后期细粒度完善与物理重点

后期以保持过程关系、改善接触边界、轮廓、形变和残留为主，抑制大范围结构重构。需要继续观察静止支撑、原位置和背景，不能只看移动主体。

本地 Wan2.2 TI2V-5B 的 VAE stride 为 (4,16,16)，DiT patch 为 (1,2,2)。只看进一步池化的 token 容易遗漏短接触；优先读取原生网格信息，通过局部重排／小投影保留子网格与通道细节，而非引入 RAFT。

四个问题由共享计算承担：

| 问题 | 实现依据 |
|---|---|
| 哪里与现象有关 | 当前文本与视觉特征交互，训练时使用可靠软区域参考 |
| 哪里对过程重要 | 关键交互及其前后上下文，包含作用双方、来源去向和腾空位置 |
| 哪里需要改 | 当前实际观察与过程条件的差异，由结果监督学习 |
| 怎样改、多大强度 | 带符号的特征更新和门控，通过下游实际输出反传训练 |

重要位置不一定有错；已经正确的接触不应被强制大改。训练权重保留背景底座，可靠性与重要性分开。ProPhy 式信号可作相关区域参考，不作为真实接触、力或修改方向真值。[ProPhy](https://arxiv.org/html/2512.05564v2)

首版不在每个接口反复解码视频。当前步的完整端点在输出头之后才出现，不能在 B 提前使用它而不付出额外计算。训练可为输出监督解码；推理可按需读取上一正常步记录，但必须标明其噪声时效。

## 8. 反馈是什么，不是什么

### 8.1 三种循环不能混称

| 计算形式 | 是否看到了新的主干结果 | 当前决定 |
|---|---|---|
| SharedCell 在固定观察上更新低维工作状态 | 没有新的完整 Wan 结果 | 允许，但称为 latent 内优化 |
| A 写入后自然计算到 B，B 读取当前真实特征 | 看到了后续原生层的实际处理结果 | 主线 |
| 下一正常噪声步读取新特征与更新后的 P | 看到了正常采样进程中的新观察 | 主线／可选观察缓存 |
| 同一噪声步更新 P 后重跑完整 Wan | 有新完整结果，但成本高 | 删除 |

H_B 与 H_A 的差异同时包含层深变化和正常网络计算；跨噪声步的端点差还包含去噪变化。没有反事实对照时，不能把这些差值称为“本次修改的纯因果效果”。

### 8.2 主流程伪代码

~~~text
z ← 一次初始噪声，施加首帧条件
P ← 首帧、文本、同一噪声的低成本初始化
previous_observation ← empty

for 每个正常噪声步 k:
    运行本步无条件 Wan 一次

    在一次有条件 Wan 前向内：
        正常计算到 A
        前期：SharedCell 在低维 P 中优化少量轮
        中后期：读取已有 P，不回头等待 B 的新结果
        在 A 写入一次过程条件

        正常计算到 B
        读取当前 H_B、细网格信息、P、可用历史观察
        SharedCell 进行结构／细节更新
        在 B 写入一次，并得到 P_next

        正常计算剩余层和原生输出头

    合成 CFG
    记录本步可用的实际观察及其 sigma
    scheduler 前进一步，恢复首帧约束
    P ← P_next

输出同一条视频
~~~

所有内层小循环均禁止调用 Wan 或 scheduler。共享单元不是独立 planner／reasoner；相关职责必须通过预测、控制和输出实验验证。

## 9. 初始结构和 corrector 分别怎样接受监督

两者都需要监督，但“需要监督”不等于都需要错误视频或独立大网络。

### 9.1 早期结构：监督实际 P，并验证生成控制

**本轮采纳：以冻结 V-JEPA 2.1 对 GT 的编码结果监督实际 P。** 采用完整、未做随机 mask 的 RGB 视频编码器输出；不使用 JEPA predictor 的补全结果、分类头概率、全局平均向量或三通道 PCA 可视化。这里的 GT 是训练视频参考，教师输出仍是软特征目标。

| 首版接口 | 决定 |
|---|---|
| 主教师 | V-JEPA 2.1 ViT-G/16，384 分辨率，检查点 `vjepa2_1_vitG_384.pt`，编码器键 `target_encoder` |
| 实例来源 | 官方 2.1 编码器实现 `app/vjepa_2_1/models/vision_transformer.py`；2B 的 G 对应 `vit_gigantic_xformers`，不与 1B 的小写 g 混淆 |
| 模型状态 | `eval()` 且参数冻结；GT 分支 `no_grad()`，本任务不更新教师 EMA |
| 取层 | 默认最终 block 的原生归一化稠密输出；G 的零基索引为 47，通道数 1664 |
| 多层特征 | 作为消融；本地 G 支持的层为 `[11, 23, 37, 47]`，不默认拼接四层 |
| 学生读出 R | 逐 token 线性投影 `D_P → 1664`，A／B 共享；仅允许读取 P，不另从 H、文本或 GT 绕路预测目标 |
| 距离 | token 通道 L2 归一化后的余弦距离，FP32 计算；MSE／L1 仅作为后续消融 |
| 推理 | 不加载 GT 教师；同一 SharedCell 和 A／B 顺序写入继续工作 |

官方发布了大小不同的 2.1 模型；ViT-L 蒸馏版可作为成本消融，但它使用 `ema_encoder`、1024 通道，不能把它的输出与 G 的目标直接比较。换教师须重新定义 R、生成对应 GT 缓存并独立训练／对照。[官方模型入口](https://github.com/facebookresearch/vjepa2/blob/main/src/hub/backbones.py)

设 Q_ξ 是带时间戳和裁剪记录的固定 RGB 预处理，\(\mathcal A_{\rm grid}\) 是固定网格对齐，\(N(a)=a/\max(\|a\|_2,\epsilon)\)。监督为：

\[
T=\operatorname{sg}\!\left[N\!\left(\mathcal A_{\rm grid}
\left(\Phi_{\rm VJ2.1}^{\rm last}(Q_\xi(x))\right)\right)\right],
\qquad S^{(r)}=N\!\left(R(P^{(r)})\right),
\]

\[
\mathcal L_{\mathrm{struct}}=
\mathbb E_{x,\sigma,\epsilon}\!\left[
g_s(\sigma)\sum_r\alpha_r
\frac{\sum_u\rho_u w_u\left(1-\langle S_u^{(r)},T_u\rangle\right)}
{\sum_u\rho_u w_u+\varepsilon}\right].
\]

u 是时空网格位置，r 是学生实际状态的取样点，不是教师层号。M1 只监督 A 提交前的最终 P；加入 B 后监督 A 输出和 B 提交的 P_next，初始可各取 α=1/2。内层迭代的额外深监督属于同一个 L_struct，只有验证需要时加入，所有有效 α 归一化。\(\mathcal A_{\rm grid}\) 不是写入接口 A。

**对齐必须保留时间和空间，而非只对齐张量尺寸。** 输入 `[B,3,F,384,384]` 在 F 为偶数、patch=16、tubelet=2 时得到 `[B,(F/2)·24·24,1664]`，按时间、高、宽还原。最小 16 帧教师视图可得 `[B,8,24,24,1664]`，空间 2×2 平均池化得到目标 `[B,8,12,12,1664]`；学生示例为 `[B,8,12,12,256]`。这些是起步规格，不把 Wan 的 VAE 时间索引硬当成教师 tubelet 索引。

16 帧只是接口原型，不是所有事件的固定长度。正式训练的教师视图必须覆盖对应过程及前后文；32／64 帧或长片段窗口按真实时间取样。P 可以覆盖整段视频，窗口监督通过记录的时间和空间坐标读取对应 P 区域。首帧的因果 VAE 特殊时间布局、窗口边界及 padding 需显式映射。先对齐再归一化；默认不额外压缩时间维。空间池化可能抹掉小间隙，需与 24×24 网格对照。

首版每个训练样本使用一个确定的教师视图；长视频分窗时固定上下文及网格归属，不把不同上下文编码出的重叠token同时当成同一P位置必须完全相等的标签。教师token可含全局上下文，空间／时间截取token也不等于先裁视频再编码。D_P=256仅是容量起点，线性R有维度瓶颈，不保证能无损恢复1664维教师特征；需检查表示保真与生成收益，不能把L_struct必须降到零作为验收条件。

可靠性 ρ 来自数据可见性／质量抽查和有效网格掩码，V-JEPA 原生不输出“物理正确概率”。首版在已审核有效位置设 ρ=1、无效位置为 0；没有独立可靠度依据时不伪造细粒度置信度。重要性 w 首版取 1，后续仅使用经核验的软区域权重并保留背景底座。二者都固定且停止梯度，不由学生 gate 或特征误差自适应缩小；全部无效的样本跳过该项。

这条损失直接训练实际 P 及其更新，但不单独保证 Wan 采用 P。R 应保持轻量，避免复杂解码器在辅助分支完成全部任务；必须同时用 L_FM／后续 L_out 验证写入，进行同架构 FM-only 和去除 P 写入的对照。教师可通过探针读出的能力，也不自动意味着余弦距离会对所有物理错误敏感。

本选择的合理性来自稠密视频表示与 P 的形式匹配，以及噪声隐藏状态向干净教师特征对齐的已有方法基础；在本 D 中的实际增益仍是待检验假设。[REPA](https://arxiv.org/abs/2410.06940) 不能直接证明本模型的碰撞或因果能力。教师领域校准、P 的生成控制、多样性和完整视频的独立评估是共同验收条件。

### 9.2 corrector：监督写入后的实际结果，不只监督它的建议

corrector 没有现成的“正确 ΔH”标签。这里不编造这种标签，而是采用结果监督：

\[
H'_B=H_B+\Delta H_\theta,\quad
v=\operatorname{Head}\!\left(F_{>B}(H'_B)\right),\quad
\hat z_0=z_\sigma-\sigma v.
\]

首版训练中，v 是正常条件分支的预测。这里的端点确实来自写入后的原生输出头，但仍只是当前噪声处的干净样本估计，**不是完成全部采样后的最终视频**。不为了得到这个训练目标额外展开完整采样链。CFG 与多步采样可能带来差异，因此验收必须运行部署协议下的完整视频，不能用单步端点成绩替代。

经过原生后续层和输出头得到预测，再对其可读视频表征与同一样本的 GT 表征比较。梯度路径为：

~~~text
GT 表征与实际输出的差异
→ 冻结教师对生成输入的梯度
→ VAE／原生输出头与后续 Wan
→ B 的真实特征写入
→ corrector 的方向、门控和共享更新参数
~~~

只让 P 预测正确、只回归门控热图、或只监督模块想象中的修改，都不等价于上述路径。

这监督的是“修改后应接近什么”，不是现成的正确修改方向标签。方向与门控从实际下游误差中共同学习：重要但已正确的位置可以少改，需要协同调整的多位置可以一起改。首版不再增加门控 BCE、残差真值回归或逐轮单调性损失。

### 9.3 四项任务，严格不恢复错误视频配对

\[
\mathcal L
=\lambda_f\mathcal L_{\mathrm{FM}}
+\lambda_s\mathcal L_{\mathrm{struct}}
+\lambda_o\mathcal L_{\mathrm{out}}
+\lambda_a\mathcal L_{\mathrm{align}}.
\]

| 任务 | 主要监督落点 | 为什么需要 |
|---|---|---|
| L_FM | 标准 GT 加噪路径的原生向量场 | 学习视频分布，训练写入能产生正常视频 |
| L_struct | 实际早期 P；中期更新后的同类过程表征 | 让过程结构有明确学习目标，减少旁路和空状态 |
| L_out | 写入后实际视频预测的可信时空表征 | 监督 corrector 经主干执行后是否接近正确过程与细节 |
| L_align | 视频与描述的角色、动作和过程对应 | 减少“动了但没按文本执行”，与物理过程监督互补 |

L_out 是正常 GT 训练前向上的输出表征监督，不是旧版错误视频配对修复损失。本轮将其候选教师也固定为同一冻结 V-JEPA 2.1，但启用条件独立于 L_struct：先通过生成输入梯度、教师领域敏感性、GT 的 VAE 往返差异和显存检查。令 \(\Psi_o(y)=N(\mathcal A_o(\Phi_{\rm VJ2.1}^{\rm last}(Q_\xi(y))))\)，其中 \(\mathcal A_o\) 保留已校准的原生稠密网格和事件上下文，g_o(σ) 只在可读噪声范围非零：

\[
\mathcal L_{\mathrm{out}}
=\mathbb E\!\left[g_o(\sigma)
\frac{\sum_u\rho_u^o w_u^o
\left(1-\langle\Psi_o(\hat x_0^{\mathrm{write}})_u,
\operatorname{sg}\Psi_o(x)_u\rangle\right)}
{\sum_u\rho_u^o w_u^o+\varepsilon}\right].
\]

GT 侧可以缓存，生成侧必须用同一模型、层、时间与裁剪协议重新前向并保留输入梯度；教师参数冻结并不允许对生成侧使用 no_grad。预测侧 resize／normalize 保持浮点 Tensor，不经过 PIL、uint8、视频落盘或离散 VLM 回答。

可读范围还需保留有效梯度：由端点公式知对v的梯度带有σ因子，σ=0时L_out不能通过该路径训练写入，高噪声时端点又可能不可读，应在二者之间校准。若L_struct仅缓存了池化目标，L_out所需原生细网格应另行提取，不能靠上采样恢复已丢失的信息。

L_struct 的实现不依赖昂贵的在线教师反传。若 G 的预测视频反传暂时无法承受，先保持M1／M2a的GT特征监督实验，将λ_o和λ_a设为0；M2b的L_align也需要这条预测分支，不能仅关闭L_out便认为消除了其成本。不以资源限制否定P监督，也不偷偷用另一个特征空间代替。结构目标可以做空间池化，输出目标可保留更细网格，但微小接触和穿模是否进入教师可辨范围仍要实测。

如果 L_out 退化成同一标准路径上的原生 latent MSE，则有
\(\|\hat z_0-z_0\|^2=\sigma^2\|v-v^*\|^2\)，它只是重新加权的 FM。此时应删除冗余项，使用三项，不为了“四项齐全”保留。

### 9.4 没有错误视频时，对齐任务也要重写

不再声称使用包含大量错误视频的物理有效性 BCE 教师。只用正确视频作为正例、所有标签都设为 1，会产生退化解。

可在 WISA／OpenVid 的视频—描述对应上训练一个小型匹配头：真实对应为正例，经过核验的不匹配描述为负例；不修改或制造坏视频。角色交换等文本负例只有在视频证据足够时才使用，避免错误负例。

同一匹配任务可以覆盖全段和带上下文的转移窗口。冻结匹配头后，对正常生成预测计算可微对齐目标；它不是推理 verifier。

V-JEPA 2.1 提供视觉特征，没有直接与文本对齐的接口；不能把视频 token 与 Wan 文本 embedding 直接做余弦当作 L_align。若复用其视觉特征，仍需单独训练上述匹配头，并独立检查角色／顺序负文本的可分性。更换 P 的教师不自动完成文本监督。

这种监督能改善文本与过程对应，但不等价于从物理错误视频学到完备的错误识别能力。穿模、微小接触与复杂守恒仍主要依赖可靠过程／输出表征及最终独立评价。

首版把匹配任务落实为：固定V-JEPA视觉token与冻结UMT5文本token，经各自投影送入小型带时空位置的联合匹配头，用经核验正负描述训练BCEWithLogits；训练生成器时冻结该头，以 `softplus(-score(实际生成视频, 正确文本))` 作为L_align。匹配头自身的预训练损失是独立准备任务，不是新增的第五个生成器损失。它必须看实际输出视频，不能只读P给P自评分。

### 9.5 如何判断 correct 是否真的正确

不承诺每次修改都正确。需要在固定开发集上，离线对比同输入、同 seed 的启用／关闭 corrector，并完整统计两组结果：

- 改善率：原本未正确执行的案例中，有多少得到改善；
- 破坏率：原本正确的案例中，有多少被改坏；
- 联合成功率：完整执行且物理关系合理；
- 目标错误、数量／身份和画质的变化；
- 相同 Wan 前向数及实际耗时下的收益。

这是研发对照，不是每次推理生成两条后选好的那条。对照指标不能只使用训练教师自评分，还需要独立人工或独立评价依据。

还需防止把普通联合训练收益误称为修正收益：先固定已学好的 A、共享主体和原生 Wan，仅训练 B 新增的必要读写投影，观察该插入是否产生净改善；再联合微调，并同时比较上一检查点和本模型关闭 B 的结果。只关闭一个共同训练过的模块可能引入分布变化，不能独立完成归因。

在展示前固定“正确／改善／破坏”的评价口径与容忍范围，按输入／场景聚合不确定性。训练教师 loss 降低、门控较小以及最终绝对成绩较高，都不能单独证明 B 修复了原来的错误。

所以当前能建立的是“参考可信 → 真实写入可训练 → 完整结果有净收益”的经验性证据链，而不是逐样本、逐轮的数学正确性保证。只用正常视频训练时，对严重离轨状态的可恢复性尤其需要单独报告。

### 9.6 中间P与各类增量如何接受监督

| 对象 | 直接标签／目标 | 实际采用的训练方式 |
|---|---|---|
| A提交的P_A^+ | 对齐后的同源GT教师T | L_struct直接监督；FM／输出／文本损失经写入反传 |
| B提交的P_B^+=P_next | 同一个T、同一坐标及共享R | L_struct直接监督；本步真实写入使输出损失也训练其更新 |
| 内部P_i^(r) | 可以复用同一T | 首版只监督每个接口最终态；必要时给少数内部态低权重深监督 |
| 候选ΔP和有效增量D | 没有逐轮GT增量 | 监督P^-+D后的状态和视频结果，不把teacher状态直接回归给ΔP |
| ΔH_A／ΔH_B | 没有“正确Wan残差”标签 | L_FM、可读范围L_out和L_align通过实际后续Wan反传 |
| gate、b_B、读写投影、SharedCell权重 | 没有正确度热图或参数标签 | 由上述任务联合训练，不把gate当物理正确概率 |
| H_A／H_B本体 | 首版不另设teacher逐层标签 | 保留原生表示自由度，通过实际输出训练必要适配 |

对一个加法更新，\(\partial L/\partial\Delta P=s_i\eta_iG_P\odot\partial L/\partial P^+\)。对首版逐token标量gate，还须沿通道求和：\(\partial L/\partial G_P=s_i\eta_i\sum_c\Delta P_c\,\partial L/\partial P_c^+\)。其中L可包含更新后P的结构损失和所有经过写入的输出损失；没有单独L_delta，也可以训练出更新方向。状态内部循环不能在每轮间detach，否则更早增量到后续结果的梯度会断开；跨去噪训练视图的截断则要显式声明。

V-JEPA的 `T(τ+1)-T(τ)`描述视频时间变化，不能当成“当前去噪迭代需要改多少”的标签。即使R线性，`T-R(P)`也在教师空间，不可直接与256维ΔP相减。只有未归一化平方距离等特定条件下，更新后状态回归才可改写为投影增量匹配剩余误差；这通常是同一任务的另一种写法，并未得到额外物理真值。

不要求每个内部态都与最终T同等接近，不增加逐轮强单调下降或强制非零增量损失；中间计算可能需要临时改变表示，正确状态也应允许零更新。小幅度、梯度非零、teacher误差下降都不能保证实际视频改善。

### 9.7 怎样证明P／ΔP真正参与了有益校正

证据按三层收集：首先用独立单项backward确认P、有效D、ΔH及相应参数收到预期梯度；其次对固定模型进行受控禁用，确认这些路径确实影响输出；最后在独立完整视频评价中检验净收益。共享参数、同一teacher或仅随机打乱P均不足以独立归因。

离线成对对照需要分清：关闭整个B（状态与写入都关闭）；只令D_B=0但仍从未更新P写入；只令ΔH_B=0但仍传递新P；只取消P跨步传递。保持输入、seed、采样器、CFG、步数和其它开关一致。每种对照测的是不同机制，不能把“关闭写入但保留新P”称为B完全关闭。

若需诊断单次更新的影响，可在开发测试中复制完全相同的B前H／P状态，分别从有更新与无更新路径继续后缀，并用相同输出指标比较；这是额外的离线计算，明确计费，不进入正式单轨迹推理或主训练循环。不能直接比较H_A和H_B，把层深变化当校正效果。

主要验收仍使用上一检查点和完整部署视频，报告原失败样本的改善率、原成功样本的破坏率、联合成功率、画质和多样性，并按场景给出不确定性。只改善自身teacher距离，应称为表示拟合改善；只有独立视频结果净改善，才支持“有效校正”。首版不额外加入依赖重复尾部前向的逐次收益排序损失。

### 9.8 将监督落到训练代码的共同约定

完整单步伪代码、掩码／噪声归一化、张量广播和梯度审计统一见 [E第11.5–11.7节](20260908-E-实际过程监督与反馈校正_增量模型构建及周度验证方案.md#115-四项损失怎样放进同一个可实现的训练步骤)。本D的架构实现须满足以下约定：

| 环节 | 必须实现的行为 | 要避免的问题 |
|---|---|---|
| 状态记录 | 保存本次实际P_before、候选ΔP、有效D、P_after和ΔH；writer与L_struct读同一个P_after | 辅助副本被监督，实际路径未被约束 |
| GT隔离 | GT教师token仅进入目标分支；允许的首帧、文本和带噪视频进入学生 | 把未来GT表示当条件，推理缺少输入 |
| 原生任务 | 依照I2V首帧和padding规则计算FM；端点只恢复允许的首帧 | 已知区域错误加噪／重复监督，或贴回未来GT |
| 实际输出任务 | 按σ、目标可靠度和事件视图选择可读端点；保留VAE／教师／匹配头输入梯度 | 只训练读出头、预测分支意外断图或局部窗口标签不成立 |
| 归一化 | 先有效token再样本／状态；固定σ衰减不被重新归一化抵消 | 增加深监督点或减少抽样后悄悄改变loss尺度 |
| 无效／异常 | 无有效辅助目标时返回图兼容零值并跳过昂贵编码；有效区域NaN须定位 | `0*NaN`传播、零标签伪装未知、掩盖数值错误 |
| 阶段切换 | 重新核对冻结组与optimizer成员，清除残留梯度，共享权重去重 | 名称上冻结A，实际仍更新它或重复计数 |
| 状态与计算图 | 同视图无detach、不原地覆盖P；checkpoint重算不提交全局状态 | backward版本错误、重复修改状态、跨视频串用P |

L_struct在当前P处不经过其后writer，不能单靠它训练ΔH；FM／out／align经实际输出训练writer和上游状态路径。R只接受L_struct，冻结教师和匹配头只传递输入梯度，不更新权重。B初始化时部分上游梯度为零是预期，需在受控起步更新后再验收；有效梯度也不等于已经产生物理收益。

单视图训练不展开完整CFG采样。生产推理仍按原有两分支和scheduler契约执行；每步损失下降能否转化为完整视频改善，必须用第9.7节的独立对照确认。这里补齐可执行的设计约定，不把训练入口、预训练教师实测或生成效果当作已经完成。

## 10. 只用 WISA／OpenVid 的训练实现

### 10.1 数据准备

视频按真实时间取帧，保留前因、交互和结果；训练与测试按源视频和场景隔离。先选择条件明确的碰撞、反弹和物体连续性片段，再扩展复杂手部、形变与材料过程。

教师参考只从同一训练视频提取。缓存记录源视频／分区、帧索引与真实时间戳、窗口上下文、裁剪与缩放、颜色归一化、padding 掩码、教师代码版本、权重校验值／编码器键、取层、网格变换和可靠性。先确定训练视图，再计算该视图的教师目标；改变随机裁剪、翻转或时间采样时重算或读取对应独立缓存，不能默认翻转缓存等于重新编码。

GT VAE 往返必须保留目标现象；教师提取必须能区分需要学习的过程信息。二者不满足时先修数据和监督，不先叠模块。

GT 全视频编码 token 可以携带前后帧上下文，这是监督标签的组成部分。正式学生输入不含未来 GT；若做“只看历史预测未来”的能力测试，须对历史片段独立编码，不能先编码完整 GT 再截取其前几帧 token 充当历史特征。

### 10.2 分阶段训练

1. M0检查教师、零写入、状态提交与梯度，不作为效果训练阶段。
2. M1训练A、共享单元和R，使用FM＋结构监督，先验证实际控制。
3. M2a在相同主干次数下增加共享单元的更新次数，损失仍为两项；保存独立检查点。
4. 独立训练并冻结视频文本匹配头；M2b在A模型上加入L_align，保存三项损失检查点。
5. M3a新增B，当前写入与状态增量都从零起步；固定A、共享主体和R，仅训练B的读写／门控／状态缩放，加入L_out，使用四项生成器损失。
6. M3b联合训练A、B、共享主体和R，持续使用四项损失，检查B收益和A退化。

核心链路共六个验证检查点（M0、M1、M2a、M2b、M3a、M3b），对应五个生成器训练设置，另有一个独立匹配头训练任务。M4细粒度读取和M5额外迭代／历史上下文是后续可选增量，不是启用四项损失的前提。初步可先完成M0、M1、M2a，验证梯度、P控制与迭代，再承担在线教师成本。

M2b的L_align若采用V-JEPA视觉特征，已需要预测视频解码和教师输入反传；不是到L_out才有这项成本。M3中两项输出任务的教师模型／视图相同才可复用同一个有梯度视觉前向。

### 10.2.1 需要训练哪些模块、参数约多少

Wan2.2-TI2V-5B、VAE、UMT5和V-JEPA 2.1首版全部冻结。训练新增SharedCell、条件／初始化投影、ΔP方向与gate、A／B读写适配、B状态缩放和训练期R；匹配头独立预训练后冻结。没有独立P速度场，也不默认加入LoRA。

本地Wan为30层、隐藏宽3072、文本特征4096维。参考规格取P宽256、SharedCell含4个不同参数的小block，每个block包含自注意力、文本交叉注意力和4倍宽MLP；这个4-block主体在A／B及所有内部轮次间复用。全部规格、偏置和归一化的计数见E第4.1节。

| 训练设置 | 可训练参数（参考规格） |
|---|---:|
| M1／M2a／M2b：A＋共享部分＋R | 7,494,018，约7.49M |
| 独立匹配头准备 | 3,055,617，约3.06M |
| M3a：只训练B专属适配及状态缩放 | 1,580,034，约1.58M |
| M3b：全部生成适配部分联合训练 | 9,074,052，约9.07M |

推理去掉R和匹配头后，新增生成参数约8.65M；冻结的Wan等基础模型仍然存在。上述数值由明确的参考参数容器核算，v4尚无完整实现，不是已运行模型的实测。提高内部轮数不会增加独立参数，但会增加计算和激活；只训练约9M也不等于训练显存很小。宽512、同样4个block时联合训练约26.78M，需作为独立容量实验，不在阶段间悄悄换宽度。

### 10.3 状态训练与推理差异

单噪声训练可先使用当前真实特征生成 P。需要跨步状态时，可用两个标准 GT 加噪视图模拟有噪声标记的状态传递，每个视图仍有正确 FM 标签；这不是实际模型 rollout，必须如实报告差异。

若以后研究完整正常采样展开，不能给离开原直线加噪路径的状态沿用旧 ε−z0 标签。本版不将这种展开变成新的错误状态训练库，也不把它设为数据建设前提。

### 10.4 不能把普通视频对应误称为因果干预真值

两套自然视频中的变化提供重要统计与过程监督，但一般不是严格的受控干预数据。训练不得凭空补上精确质量、力或守恒标签。

因果能力的主张需要未见条件与前因变化的独立测试，而不是仅凭同一教师特征对齐成功。静止不是通用正确答案，合法多样性也不能被对单一 GT 的过强回归抹掉。

## 11. 逐项问题的作用与边界

| 现象 | 前期工作 | 中期顺序修正／后期完善 |
|---|---|---|
| 红球不动、蓝球自行运动 | 学好主体角色、必要运动和交互关系 | 联合修订路径与响应，不回头重跑本步早层 |
| 球拍未触球、球先飞走 | 过程目标包含交互前提，不只识别球拍名词 | 当前层修接触与起飞时序；必须同时看球拍、球与前后帧 |
| 书掉落后桌面又有一本 | 身份与连续移动进入过程学习 | 兼顾移动书和原位置；不能只增强运动主体 |
| 动作重复、过程不完整 | 全段过程监督与描述对应 | 更新整段 latent 的时序关系，不设固定事件计数 slot |
| 形变、穿模和伪影 | 先避免错误轨迹与不合适形变先验 | 细网格、几何上下文和实际输出监督；受 VAE／教师能力限制 |
| 源量不减、接收端增加 | 训练窗口覆盖源、途中和接收端 | 同一 P 关联多区域；普通视频不能提供精确守恒真值 |
| 初期已经严重走错 | 加强早期监督和控制能力，验证优化有效 | 中期可以修结构，但固定计算预算下不保证全部可达 |

## 12. 工程约束与预算

已核对的本地基础：[Wan 前向](/home/liuzhirui/model/Wan2.2/wan/modules/model.py:410)、当前 [P0 推理入口](/home/liuzhirui/Project/physGen/code/v3/inference/infer_trace_writer.py:649)。本轮没有训练或修改模型代码。

- 包装原生 forward，A、B 顺序执行，不采用递归模型调用。
- 推理时每分支、每噪声步的 block 访问次数必须有测试；禁止回溯早层和尾部重放。
- 冻结权重不等于禁止输入梯度，尤其输出教师／VAE 与 B 后的 Wan。
- 当前完整端点只能在输出头之后取得；缓存附噪声和层位置。
- 更新 P 影响下一正常步骤，并不意味着旧早层缓存仍可跨步骤复用。
- 先测量小单元、观察、训练输出教师的成本；主干调用数不变不代表墙钟时间不变。
- 采用一阶调度验证状态提交，再核对原多步求解器；对照必须同一求解器与 CFG 协议。
- 正式推理不需要 GT、视频教师、匹配打分器或修复数据集。

## 13. 研究借鉴与创新边界

| 来源 | 有价值的部分 | 不移植的结论／实体 |
|---|---|---|
| [REPA](https://arxiv.org/abs/2410.06940) | 实际带噪隐藏状态的可信目标对齐 | 不把普通图像语义直接当物理结构 |
| [V-JEPA 2.1](https://arxiv.org/abs/2603.14482) | GT 稠密时空 token 作为 P 的冻结监督目标 | 不把视频特征当精确物理量、文本 embedding 或逐位置正确性概率 |
| [RIN](https://arxiv.org/abs/2212.11972) | 将主要迭代放在紧凑 latent，并在数据与 latent 间读写 | 不照搬其完整生成骨干、latent 组织或论文速度提升 |
| [SCD](https://arxiv.org/abs/2602.10095) | 区分过程推理和反复渲染，检查冗余计算 | 原文研究自回归视频，不能据此直接缓存双向 Wan 全部早层 |
| [VACE](https://arxiv.org/abs/2503.07598) | 可训练时空条件适配 | 不复制大型编辑框架 |
| [TempAct](https://arxiv.org/html/2606.28016v2) | 全段与转移执行分开关注、避免硬条件切换 | 不复制独立 LLM planner、固定生成分段及 RL |
| [PHANTOM](https://arxiv.org/html/2604.08503v3) | 说明教师动态表征与视频耦合已有近邻 | “增加 physics latent”不能作为独立创新 |
| [ProPhy](https://arxiv.org/html/2512.05564v2) | 从可信视频提取相关区域的软提示 | 不把相关性当错误位置或真实物理强度 |

创新需要证明：前期优化确实产生可执行结构；中期顺序修正能保持正确关系并修复偏差；细粒度实际观察在相同主干调用预算下有净收益。小单元多迭代本身、soft gate 和多尺度特征都不足以单独支撑强创新。

使用 GT 的 V-JEPA 特征本身已有近邻，升级为 2.1 也不能单独构成创新主张。PHANTOM 使用视频／物理两个并行 latent flow 分支及相互注意力；本 D 保持单一视频流、紧凑 P、共享单元和 A→B 顺序写入，不引入第二条 P 的流匹配采样链。架构差异需要通过与普通特征蒸馏及相同计算预算基线的对照证明价值，不能仅靠命名区分。[PHANTOM 方法](https://arxiv.org/html/2604.08503v3#S4)

## 14. 当前最终取舍

正确基础不等于永久冻结基础；中期结构修正不等于回头重跑骨干。我们将两者结合为：

**前期有监督地形成与优化过程 → 当前层读取实际状态并顺序修缮 → 下一正常去噪步接续新 P → 后期保持关系与细化。**

初始结构和 corrector 各有明确监督落点，实际写入必须通过输出验证。数据仅用 WISA／OpenVid，损失至多四项，不恢复错误视频配对，不以推理筛选或额外完整重算掩盖能力缺口。
