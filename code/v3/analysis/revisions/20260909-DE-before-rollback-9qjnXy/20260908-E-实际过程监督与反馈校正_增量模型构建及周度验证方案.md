## 2. 最终最小模型合同：先明确，防止实现时走样

### 2.1 状态与采样

\[
T=\operatorname{sg}[\mathcal N_{\rm train}\mathcal A_{\rm grid}\Phi_{\rm proc}(x)],
\quad z_\sigma=(1-\sigma)z_0+\sigma\epsilon_z,
\quad P_\sigma=(1-\sigma)T+\sigma\epsilon_P.
\]

两个噪声由同一个 seed 派生的独立子流生成。P 是与 T 坐标、维度一致的连续时空状态，不含预设物理通道或查询槽。

本步 Pσ 是不可变输入：

~~~text
A：读 H_A + Pσ → u_A、临时工作状态 → 写入当前 H_A
              ↓ 原生层继续
B：读 H_B + Pσ + u_A + 细网格 → u_B、关联组写入 → 写当前 H_B
              ↓ 剩余原生层一次
输出 (v_z, u_P=u_B)
              ↓ 合并原生 CFG 两分支
同步提交 z_next、P_next 一次
~~~

A／B 及低维内部迭代不提前推进 Pσ；不能用被修改到离轨的 P 状态继续套原 εP−T 标签。干净过程估计 P̂0=Pσ−σu 只是一个视图，不是已确认的唯一正确计划。

首版采用联合 Euler，先核对符号、噪声约定和条件 mask。以后接 UniPC 等求解器时，z／P 使用兼容阶段及各自历史，按实际 NFE 记录预算。

### 2.2 梯度与四项任务

| 项目 | 监督对象 | 额外部署成本 |
|---|---|---|
| L_FM | 正常视频速度 εz−z0 | 无训练教师 |
| L_struct，即过程 FM | 实际 A／B 与历史预测视图的过程速度 εP−T | 共享小单元及 P 状态 |
| L_out | 真实写入后、经原生输出头得到的可读视频端点表征 | 正式推理不运行输出教师 |
| L_align | 实际视频与核验后的角色／动作／前后状态文本对应 | 正式推理不运行匹配头／VLM |

A／B 深监督和前置预测视图使用同一个过程目标。L_out 的全段／关键窗口／背景采样属于一个稠密表征任务。L_align 的帧段／整段描述属于一个匹配任务；不各自新增独立任务权重。

冻结教师和冻结主干参数不等于整条前向 no_grad。若输入来自 writer，必须保留通向输入的导数，否则 corrector 无法由实际结果学习。

### 2.3 CFG

条件和无条件分支从相同 (zσ,Pσ) 出发，各自产生临时 (vz,uP)。两分支均运行小单元，不互相借用清洁过程预测，不单独更新全局状态。两种速度按相同 CFG 公式合并，再交给 joint solver。

单步不增加完整 Wan 次数，但无条件分支的小模块成本不能省略报告。训练必须覆盖原生条件 dropout 约定，避免只训练条件过程头却在推理使用无条件过程输出。

不要给每种物理现象建一个独立模型类。数据中可以有可变长度描述与时间窗口，但不会变成 Cell 中固定的“碰撞 slot、质量 slot、速度 slot”。

建议接口：

~~~text
cell(P_sigma, observation, text, sigma, layer_or_view, work=None)
    -> process_velocity, work, write_payload

relation_kernel(P_sigma, clean_process_view, current_features, coordinates)
    -> continuous_locations, association_weights

write_B(current_features, locations, weights, write_payload)
    -> updated_current_features

joint_step(z_sigma, P_sigma, branch_fields, scheduler_state)
    -> z_next, P_next, next_scheduler_state
~~~

工作宽度先从较小规模试起，例如 256 通道、少量共享 block；P 的通道数由目标空间决定，不等于工作宽度。时空网格要从接触可读性与显存测试选择，不按“一个对象一个 token”设计。K 是几何采样预算，不是物理量数量。

## 4. M0：先验证数据、teacher 和原生通路

M0 是工程与监督可用性前提，不声称它本身已提升生成效果。必须尽快完成，避免消耗一周只写基础设施。

### 4.1 锁定原生对照

从现有 v3 manifest 和真实配置核对 checkpoint、VAE、条件输入、负面提示、帧率、尺寸、CFG、scheduler。新基线必须明确记录权重路径和版本，不继续依赖含糊目录名。

采用与目标任务一致的固定首帧／文本对照；不把 P02–P18 这几条已反复观察的历史个案作为唯一测试集。

建立三个不混用的集合：

- 小型调试集：用于定位实现错误；
- 固定开发集：用于阶段调参与周度展示；
- 封存测试：用于最终比较，不反复看结果调模型。

按源视频、场景和近重复划分，避免相邻裁剪跨训练／测试。现有六个审查个案的精确观察和限制见 D 第 2 节。

### 4.2 WISA／OpenVid 数据合同

每条至少记录：

~~~text
dataset, source_video_id, split, original_caption
frame_timestamps, sampling_policy, crop_transform
visible_transition_windows, grounded_descriptions_if_reliable
unknown_or_occluded_facts, camera_motion_flag
teacher_checkpoint, layer, preprocessing, grid_mapping, target_version
~~~

这是离线元数据，不是运行时语义槽清单。接触不可见、物体数量受遮挡影响或参数无法测定时，保留未知。

数据卡：[WISA-80K](https://huggingface.co/datasets/qihoo360/WISA-80K)、[OpenVid-1M](https://huggingface.co/datasets/nkp37/OpenVid-1M)。可公开获取不代表已在本机完成下载或清洗。

### 4.3 教师先考核，后选型

首轮只比较两个稠密候选：[V-JEPA 2.1](https://github.com/facebookresearch/vjepa2#models) 与 [InternVideo-Next](https://github.com/OpenGVLab/InternVideo/tree/main/InternVideo-Next)。先选择一个作 Φproc／Φout，不默认并列堆叠。

能力审查包含：

1. 接近、接触及响应顺序是否可区分；
2. 主动角色和受动角色是否可分；
3. 真正压缩、仅手靠近和静止是否可分；
4. 额外对象、旧位置残留、尺度／轮廓异常是否可见；
5. 快慢／位移变化是否有响应，而非只对相机变化敏感；
6. 局部裁剪是否仍保留双方和时序，GT VAE 重建是否保留关键细节。

使用有核验标签的小样本、受控读出及独立留出检查。可以为教师诊断制作只用于评估的可辨识扰动，但不能因此建立训练用错误视频集；报告诊断合成偏差。

若动态可辨而边界不可辨，再比较 [LingBot-Vision](https://github.com/Robbyant/lingbot-vision) 作为 L_out 替换来源。它不是开箱即用的深度图头，不能虚构 WISA／OpenVid 已有深度 GT。

教师对某问题不敏感时，提高对应损失权重通常不能凭空得到信息。先改取帧、层、裁剪和目标，再决定是否替换教师。

### 4.4 离线语义来源不是新的推理塔

在可靠子集上测试 [Cosmos-Reason2](https://github.com/nvidia-cosmos/cosmos-reason2) 生成状态变化、可见作用与后果、时间窗及 unknown。只使用两数据集的视频，输出人工抽查后才入库；不上传本地视频到未经授权的外部服务。

常规低帧率可能漏掉短接触，关键窗需要更密取帧并核对时间。模型文字自信不等于可靠性，低置信／遮挡样本跳过相应语义监督。

不同时建 MECD 图、PhiZero tokenizer 与多个 VLM 标注队列。其他方法能力与取舍见 D；本阶段以一个可用稠密 teacher 和一条可靠文本整理路径为上限。

### 4.5 工程出门条件

- 零写入输出与原生基线在数值容忍内一致；
- A／B 顺序 hook 与 block 调用计数正确；
- GT VAE 重建与 teacher 目标对齐可视化通过；
- 训练单步显存／耗时实测；
- 主干冻结时 writer 梯度仍非零且数值稳定；
- 未因目标归一化抹掉有效运动程度。

能推理不代表能训练。冻结 teacher 的生成输入反传、VAE 解码和剩余 Wan 激活都需要显存，不能只按可训练参数量估算。

## 5. M1：一个 A 接口，先证明过程被学到并实际使用

### 5.1 编码增量

加入联合 P 噪声状态、一次 SharedCell、A 的实际写入、过程速度输出与联合 Euler。B 暂不启用；uA 是本分支过程场输出。

Cell 读取当前 H_A、Pσ、首帧／文本条件与 σ。写入使用 Pσ 与 P̂0,A 的信息，不能只把清洁估计当永久确定计划。

A 写入头零初始化以接近基线；不要把门和全部方向分支都封死导致无法学习。将最初仅输出投影有梯度、稍后主体才有梯度的现象记录清楚。

### 5.2 训练增量

启用 L_FM＋L_struct。P 的标签来自同一个视频的冻结稠密目标。条件 dropout 同时用于视频与过程分支。

使用正常联合加噪样本，不把 GT 清洁 T 作为正式条件直接输入 writer。输入中的 Pσ 是生成状态本身，不是一个免费的未来 GT 条件；全采样推理从纯噪 P 开始。

原生过程目标先用均匀合法网格 FM，不任意按 GT 物理热图改变逐 token 向量场权重。物理丰富片段可以通过数据分层增加覆盖；其训练分布变化需记录。

### 5.3 对照与交付

至少比较：

- 原生 Wan；
- 同容量 A 适配、仅视频 FM 的基线；
- 同容量加入实际过程 FM 的 M1；
- 旧清洁 P 回归方案的小规模同预算对照，检验是否更易静止或平均化。

展示实际完整视频的角色、必要运动、接触链与身份保持；同时提供过程读出和成本。不能只展示 P 的 PCA 图。

参考 T 写入是明确标记的控制能力诊断，不作为正式生成结果。若参考过程都不能控制视频，先改写入接口；若参考有效、自预测无效，先改过程学习，暂不加循环。

## 6. M2：因果前提预测与状态变化语义，分两个检查点

因果是主线，但两个改变要分开保存以便归因。

### 6.1 M2a：同一小单元的前置条件预测视图

从原始视频先截历史，再独立编码，组合允许的条件与加噪未来 P，预测同一过程 FM 目标。

必须做到：

- 不读取完整视频 H_A／H_B 或双向混合的所谓历史 token；
- 不跨视图复用包含未来的 P 工作状态或缓存；
- 保留首帧条件训练比例，不能只在多历史帧下学会预测；
- 正常完整描述之外，加入经过核验的起始动作描述／文本 dropout；
- 在纯噪未来状态开始的预测测试中验收，不能只看含 GT 信息的中噪声去噪表现。

额外训练调用只有小单元和必要历史编码，不增加完整 Wan。多个视图按同一个 L_struct 归一化，不新增因果分类 loss。

比较 full-view-only 与加入前置视图，匹配训练样本数或总算力并同时报告。A 的正式生成仍必须改善；单独预测探针提升不算通过。

### 6.2 M2b：实际视频的 L_align

吸收 [State-Change Counterfactuals](https://arxiv.org/html/2503.21055) 和 [Verbs in Action](https://arxiv.org/abs/2304.06708) 的监督思想，不照搬完整模型。

为真实视频建立可确认的前后状态、实际作用和完整过程描述；负文本针对未执行、角色错、缺前提、错顺序、错误数量或不符合事实的次数。每次负例只改一个因素，避免模型只凭某个词判断真假。

匹配头：

- 输入冻结视频 teacher 的时序 token 与原生冻结文本编码；
- 使用小型时序／跨模态读出，保留局部窗口和全段的对应；
- 在 WISA／OpenVid 的可靠视频—描述对上训练同一个对比匹配目标；
- 冻结后用于生成输入，梯度仍传回实际视频；
- 不把只读文本的 P 作为唯一视觉输入，不训练全正“物理正确 BCE”。

先验收匹配头的正负区分、词频偏差与 text-only 捷径，再训练生成器。它若不能区分角色和错顺序，不能继续加大 L_align 期待自然解决。

此时生成器三项任务：FM、过程 FM、对齐。低／中噪声可读端点用于实际语义监督，最终用完整部署视频验收。

### 6.3 M2 展示目标

- 主体真执行，而不是只出现正确物体；
- 前提成立时出现对应响应，前提不成立时不凭空出现该响应；
- 静止失败和角色互换减少；
- 因果相关变化比无关背景变化更能影响预测；
- 多 seed 合法变化没有被压成同一结果。

这些是观察条件下的预测与控制证据，不声称已识别所有隐藏力学因果。

## 7. M3：尽早加入可监督的局部 corrector，不把细节拖到最后

### 7.1 M3a：先把 B 的真实写入链路接通

新增中层 B，先采用简单有限邻域／中心写入，复用 SharedCell。读取实际 H_B、Pσ、A 的过程估计与原生细网格，输出临时 uB 及当前 B 写入。

B 之后只继续尚未执行的原生层；本步不回 A、不再跑一次尾部，不提前使用尚未形成的完整端点。中期修结构和局部几何都允许，不限于纹理。

B 采用 uB=uA＋δuB，新增过程增量头和特征写入头同时零初始化。只把特征写入置零不够：若过程输出已从 uA 换成不同的 uB，下一步 P 仍会改变，不能声称等价于 M2。δuB 是同一 P 速度的增量，不是新增视频向量场残差或第二套状态，L_struct 仍监督总 uB。

可以短阶段冻结已学共享主体和 A，仅训练必要 B 读写接口；联合训练后 A 也受共享权重更新影响，不能错误声称“冻结一条调用路径”就保证 A 不变。

### 7.2 M3b：L_out 训练实际修改

加入第四项 L_out：

~~~text
H_B + 真实写入
    → 尚未执行的 Wan 层／原生输出头
    → 当前噪声的干净端点估计
    → 可微 VAE 解码
    → 冻结稠密教师
    → 与同样本 GT 的对应窗口比较
    → 梯度回到 B 的方向、门、读写和共享参数
~~~

不是监督 corrector 自己的建议或正确性分数，也不假设存在正确 ΔH 标签。

必须保留全段低成本观察、关键转移及背景采样。重点窗同时包含作用双方和前后时刻；旧位置／原支撑在物体移动后仍需监督。可靠性与重要性分开，不由可学习 gate 反过来决定损失是否计算。

当前端点不是完整采样终点；不能额外展开全链再仍把旧 FM 标签当正确轨迹标签。可读 σ 范围通过教师与 VAE 的实际可辨识度校准，不使用未经测试的固定“第几步”。

### 7.3 M3 必须展示的局部收益

连续帧而非挑一张最好截图：

- 接触间隙与双方相对位置；
- 书／球／多米诺的局部轮廓及材料允许形变；
- 原位置残留和背景支撑；
- 响应开始时间与必要运动；
- 伪影变化。

同时列出上一模型已正确事件被改坏的比例。开启／关闭 B 属于离线研究对照，不在正式推理中生成两条后择优。

M3a／M3b 分别保存，便于区分新增接口容量与实际结果监督的价值。对联合训练模型单纯关 B 有分布变化，还需比较前一里程碑及固定早期模块训练的 B 结果。

## 8. M4：核心研究增量——方向性同核联合修正

### 8.1 M4a：连续方向性读取

从当前过程与实际观察预测少量连续时空偏移，保留时间位置和子网格细节。空间／时间索引只是几何位置，不对应物理量或对象清单。

对照 M3 的固定各向同性邻域，只改变读取位置学习方式。先保持中心写入，确认方向性取证本身是否有效。

近邻不等于必须很近：允许关系跨度跨越作用前后、原位置／新位置。保留全段低成本 P 上下文，不能只读当前最动的位置。

### 8.2 M4b：同一核 scatter 到多个关联位置

同一组采样点聚合为关系组消息，再为各采样端点产生不同、有符号的更新，用同一坐标／权重写回当前 B 层。

必须测试：

- gather 与 scatter 的时间／空间坐标一致；
- 多位置写入的梯度流；
- 重叠覆盖归一化；
- 越界位置和 padding；
- 高噪声下位移范围稳定；
- 子网格读入到 DiT 通道写回的可辨识性。

不手工规定某个点负责“删除”、另一个点负责“新增”，也不对更新强加质量守恒式的特征总和约束。删除残留和形成响应应从实际结果学到。

### 8.3 最重要的归因实验

| 对照 | 要回答 |
|---|---|
| 固定邻域中心写 vs 学习方向邻域中心写 | 方向性取证是否提供有效信息？ |
| 同样方向读取，中心写 vs 成组多位置写 | 关系是否真的进入执行，而不是只被读到？ |
| 近似相同覆盖与修改预算，正确绑定 vs 打乱绑定 | 收益是否来自正确关联，而非只是改得更多？ |
| 相同总耗时的更宽普通 adapter | 是否只是容量和计算增加？ |
| 同时监测数量、背景、SA | 接触改善是否牺牲其他必要正确性？ |

借鉴 [RDCL](https://arxiv.org/html/2502.12425) 的关系贡献诊断思想，但不复制其多塔和成套损失。模型内部绑定干预不是世界中的严格反事实；只将它作为多项证据之一。

### 8.4 M4 晋级条件

与上一有效检查点相比，短接触、旧位置残留、局部形变等目标错误净减少，完成度和 SA 不退化；改善不是仅训练教师分数上升。否则保留更简单的 M3，针对监督或写入范围查因。

## 9. M5：只有值得才增加小单元内部多轮

A→B 和下一正常去噪步已经提供顺序反馈。额外 recurrent 深度是独立可选增量，不是模型必须“看起来复杂”的部分。

可以做 1／2／3 次共享小单元工作状态更新，固定当前 Pσ 与原生观察，不在小循环里调用 Wan 或 scheduler。每次调用结束只提交一次本接口写入／过程估计。

对照：

- 固定 Wan NFE，小单元多轮与单轮；
- 相同总耗时，单轮宽 adapter；
- 相同总耗时，更多正常去噪步的简单模型；
- 有／无真实 H_B 响应读取；
- 改善率、破坏率和合法多样性。

固定观察上的多轮只是计算加深，不声称看到了新的完整视频；A→B 的差异含层深计算，不能直接称作本次修改的纯因果响应。

默认不建复杂历史 cache。已有 z／P 持续状态足够时就停止；额外 memory、独立 planner、RL 或直接视频速度残差都需新证据。

## 10. 运动强度与多样性贯穿各阶段，不再新增一个运动模块

### 10.1 数据和目标

- 按真实时间、可见位移程度与事件完成度分层采样；
- 保留低、中、高程度的合理过程，不只选大运动；
- 标明相机运动，避免用背景变化替代主体运动；
- 教师固定训练统计，不逐片抹平强度；
- L_align 加入可靠程度描述，模糊时不制造精确速度标签；
- L_out 对关键状态变化窗口保留足够权重，背景不归零。

不把 residual 范数或 gate 当物理强度。不要最小化所有加速度，也不要最大化运动总量。

### 10.2 阶段共同指标

片内：必要变化、完整过程、动作次数是否符合具体文本、主体真实运动。

片间：全部 seed 的变化、合法率、合法子集的变化；三者一起报告。不能只报告“通过筛选后的多样性”。

当不同合法方向可能相互抵消时，均值方向近零不代表运动强度低。过程分布建模只提供表达能力，是否学到真实覆盖要实测。

### 10.3 与新模型清单的关系

PhiZero／PSI 等提供状态转移和条件响应分布的观点，但不自动成为需要部署的大模块。PSI 原论文使用 SeaRAFT 标签，当前不移植其数据管线；也不引入多虚拟作用、多未来候选的正式生成过程。确需离线替换区域参考时，先审核许可、接口、正确率和成本。

## 11. 训练流程与资源控制

### 11.1 一次正常训练迭代

~~~text
1. 取 WISA/OpenVid 的 x、原始条件和可靠过程描述。
2. 得到 z0、固定稠密目标 T；核对时间／裁剪／版本。
3. 采 σ、独立 εz/εP，构造合法联合 (zσ,Pσ)。
4. 一次正常 Wan 分支前向，A→B→原生输出；过程状态不提前提交。
5. 计算视频 FM 和实际过程 FM。
6. 抽取前置预测视图，仅额外调用历史编码及共享小单元，复用过程目标。
7. 在可读噪声条件计算 L_out、L_align；不可用窗口跳过相应目标。
8. 反传四类任务；记录各梯度及有效样本／窗口数量。
~~~

标准训练一般采一条条件／dropout 分支，不必每次运行完整部署 CFG；但训练采样必须覆盖部署分支约定。完整 CFG 视频另用于验收。若增加 CFG 感知训练，计算必须单独计入，不能写成免费。

GT teacher 目标可离线缓存；生成端 teacher 不能用离线缓存替代，其输入变化且需要反传。随机裁剪与缓存不匹配时重新提目标，不靠错误索引凑合。

### 11.2 资源预算顺序

1. 原生小样本推理与零写入；
2. 低分辨率、短而完整的物理片段；
3. 冻结主干，训练小单元／投影，核对显存；
4. 输出 teacher 使用小规模及稀疏批次／窗口；
5. 需要时用梯度检查点、混合精度与梯度累积；
6. 只有参考过程控制能力证实容量不足后才评估少量 LoRA。

不通过缩短到丢失接触／后果的片段节省成本；不能把每四帧抽一次导致微接触消失后称为“教师看不懂”。

### 11.3 尚未消除的训练／推理差距

单步联合 FM 训练属于合法配对路径，正式采样使用模型自身状态，仍有误差累积。正常视频训练也没有覆盖所有严重离轨错误。

当前不恢复错误视频库、回退重启或大规模采样展开。用固定完整推理审查偏差；若早期就偏离，先查数据、过程控制和写入容量，而不是给离轨状态套不成立的原 GT 速度标签。

## 12. 代码单元测试：这些必须先于长训练

### 12.1 状态／计算合同

- Pσ 在 A／B／内部循环和两 CFG 分支中保持输入不可变；
- A/B 只返回临时场，global commit 仅一次；
- 条件与无条件同时输出 video/process field，CFG 公式一致；work、关联核和临时消息按分支隔离，交换分支执行顺序结果不变；
- 两个随机子流独立可复现，batch 间不串 P；
- 每个原生 block 在每次模型求值中一次；
- 无 forward 递归调用 Wan，无尾部重放；
- 当前 B 不引用尚未产生的完整端点；
- 联合 Euler 的符号与解析 toy case 一致；
- 多步 solver 的双状态 history 及 evaluation count 明确；
- 原生首帧条件 mask 正确，过程预测条件不偷用清晰未来；GT 未来仅用于构造加噪状态与监督目标。

### 12.2 信息与梯度合同

- T 的时间、裁剪和网格与学生输出严格对应；
- 教师、固定归一化、压缩映射不被生成器共同训练塌缩；
- 历史在原始输入处截断，完整编码后的 mask 测试不能代替；同时核对 VAE 时间感受野，禁止从全 GT 时间编码结果中取未核验的“历史”条件；
- 预测视图不读完整 H、缓存或结局泄露文本；
- L_struct 到实际 Cell 的梯度有效；
- L_out／L_align 到真实 B 写入和后续原生链的梯度有效；
- 冻结教师保留生成输入梯度，GT 支路停止梯度；
- 共享权重联合训练确实影响 A/B，不错误假设路径独立；
- 所有未知标签和无效窗口可被跳过，loss 不产生 NaN；
- 不用可学习 gate 缩小监督权重逃避训练。

### 12.3 局部算子合同

- 没有物理语义 query 或固定实体槽；采样索引只对应几何；
- gather/scatter 的连续坐标、插值与坐标梯度通过有限差分检查；
- 单点、重叠、边界、全 padding 情形可控；
- 多端点更新分别作用到预期当前层位置，不直接覆盖视频输入；
- 归一化重叠权重，避免覆盖次数造成无意放大；
- 细网格重排后可恢复索引，不把局部子位置混为同一点；
- B 的过程增量与特征写入双零初始化时，完整 (z,P) 轨迹与前一里程碑一致；
- 完全关闭 B 时同时恢复 uP=uA；仅关闭特征写入而保留过程修订是另一项消融，不能混称为关闭 B。

### 12.4 实验记录

显式记录数据版本、teacher、目标层／维度／压缩、条件、σ 分布、CFG、分辨率、帧率、NFE、小单元调用、训练预算、秒／视频与峰值显存。不能只报告 trainable params 和 Wan 次数。

## 13. 每周展示与阶段晋级

### 13.1 固定展示包

每周使用同一格式：

1. 原生、上一有效检查点、当前检查点的完整视频并排。
2. 目标错误的连续关键帧，并可回看全段。
3. 任务完成、角色／因果链、数量／身份、形变／穿模、背景／伪影分别统计。
4. SA、PC、联合结果及必要运动完成，不以静止的 PC 掩盖未执行。
5. 失败改善与原正确样本破坏；所有固定 seed 纳入。
6. 本周唯一主要机制的消融及真实成本。
7. 未通过项、下一步查因，而不是只放最好样例。

局部改善率分母必须明确；不能只挑原先失败而不统计原先成功。训练教师分数与独立人工过程核验冲突时，以发现评价偏差处理，不能只选好看的指标。

### 13.2 建议节奏

| 周度／阶段 | 有用交付 | 晋级问题 |
|---|---|---|
| 第 1 周：M0＋M1 小闭环 | 可复现基线、teacher 能力审查、早期 A 实际视频 | P 是否既有信息又能控制？ |
| 第 2 周：M2a／M2b 两个检查点 | 前置预测、状态变化对齐的视频收益 | 角色、前提依赖和未执行是否改善？ |
| 第 3 周：M3a／M3b | 顺序 B 与真实局部结果监督 | 不回跑主干能否修细节／结构，破坏率如何？ |
| 第 4 周：M4a／M4b | 方向读取与关联写回分开比较 | 同核联合修改是否胜过中心修正？ |
| 第 5 周：有依据才做 M5 | 小单元多轮或更好的数据／目标覆盖 | 等时间预算下是否值得？ |
| 后续：封存测试与重复训练 | 泛化、最近邻基线、统计与论文证据 | 知识、控制、局部执行是否形成闭环？ |

这是数据与算力可用时的参考安排，不是已测工期。若 M1／M2 的核心瓶颈没解决，暂停新增模块，但仍交付完整诊断和可复现结果。

### 13.3 晋级规则

在实验前确定目标指标、允许退化范围和预算。通过需同时满足：

- 目标错误净减少，不只是 loss 下降；
- 完整执行与物理合理性联合改善；
- 非目标数量、背景、SA 和画质未出现不可接受退化；
- 收益不被更多数据、训练时间或主干重算混淆；
- 在多场景上成立，说明样本数和不确定性。

无效模块不进入最终默认配置。模型可以最终停在 M3 或 M4，不为了展示“循环”而保留 M5。

## 14. 典型失败如何查因

| 观察 | 优先查什么 | 不要立即加什么 |
|---|---|---|
| P loss 低但视频不执行 | 控制诊断、实际 writer 梯度、接口位置 | 更多 P 槽位或独立 planner |
| 主体还是不动 | 数据完整性、条件不足、teacher 动态敏感性、分布平均化 | 最大化运动奖励 |
| 接触局部好了但多出对象 | 旧位置／新位置覆盖、关系绑定、数量文本可靠性 | 全局 gate 增大 |
| 过程正确但局部形状差 | VAE 重建、子网格读取、L_out 教师边界能力 | 完整物理 DiT |
| P 预测正确但 B 改坏 | 输出目标、覆盖归一化、更新幅度、共享参数退化 | 逐轮正确性分数和候选择优 |
| 只有前置探针进步 | 历史视图是否脱离实际控制、信息捷径 | 将其直接命名因果模型 |
| 因果描述漂亮但事件未发生 | L_align 是否只看文本／名词，局部窗是否看到了过程 | 更长 CoT |
| 很多正常片段也出现强运动 | 强度数据失衡、相机混淆、过度 CFG | 再增加 motion loss |
| 多轮不如多算几步 | 同预算下简单模型是否已足够 | 强行保留 recurrent 作为创新 |

## 15. 投稿前必须补全的证据与下一步

最近邻不能只选原生 Wan。至少对照或公平重现与主张直接相关的联合过程生成、转移表征、表征对齐和局部响应方法；其训练数据与预算不同要明确，不靠引用不同论文表格拼出排名。

核心论文证据应围绕：

- 过程状态确实具有条件后果预测信息；
- 信息通过实际路径控制生成；
- 关联取证与多位置写回有独立局部收益；
- 没有把数量、背景、文本执行和合法多样性作为代价；
- 顺序反馈／内部多轮在公平算力下成立；
- 不依赖错误视频配对、推理筛选或主干回溯。

先启动 v4 的 M0 和 M1 最小闭环，再按结果推进。强化学习、独立 reasoner、显式深度／动力学塔不作为当前前提；只有可靠基础、明确残余问题和对应净收益证据出现后，再决定是否增加。

最终需要的是“条件过程学习—实际生成控制—细粒度联合修改”的证据链，而不是一串模块名。可行性通过工程与训练验证，创新性通过最近邻比较和关键消融建立，不能在方案阶段保证录用。
