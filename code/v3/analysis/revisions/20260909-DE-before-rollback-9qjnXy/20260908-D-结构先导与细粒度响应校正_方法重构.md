## 1. 先给结论：因果过程和局部修正是两条共同主线

> 让实际生成路径学习“由当前条件能够发生什么过程”，并用这个过程分布组织细粒度取证与联合修改：既让作用与响应对得上，也让交互双方、原位置与新位置、接触前后能够一起改对。

本版不再满足于“P 看起来包含物理信息＋一个标量门控制修改强度”。具体补强两处：

1. P 不再只是对单个 GT 未来进行确定性回归的记忆，而成为与视频共同去噪的连续过程状态。实际路径监督与前置条件预测视图共同训练同一个小单元。
2. 局部修正不只更新某个中心位置：学习方向性时空关联，用同一关联核联合读取、形成组内消息，再向关联位置协同写回。让“如何关联”进入实际修改，而不只是进入 attention 可视化。

“不要独立 reasoner”不是最终教条；当前判断是先把条件后果预测、过程更新和局部执行放进同一共享单元。若同预算实验表明它无法学到必要依赖，再讨论新的推理能力，不能一开始同时加 LLM、图推理器和多套 latent 塔。

### 1.1 必须遵守的模型边界

| 项目 | 当前决定 |
|---|---|
| slot／物理量 query 清单 | 禁止。不设质量、速度、接触、对象等一一对应的 query，也不把事件描述转成固定运行时槽位 |
| P 的组织 | 连续稠密时空网格，通道语义由学习形成；几何索引不等于物理语义槽 |
| 数据 | 只用 WISA／OpenVid 视频与描述，以及从这些视频得到的可靠教师目标 |
| 错误视频输入 | 不使用 x_err，不建立修复配对库，不把伪造坏视频换个名字加入训练 |
| 正式推理 | 单条联合生成轨迹；无 best-of-N、verifier 选片、因错重启 |
| 原生主干 | 每个正常噪声步、每个 CFG 分支顺序执行一次；不回早层、不反复重跑尾部 |
| 视频分段生成 | 不人为切成“接近／碰撞／离开”分别采样；使用软事件窗口训练，不切断整段生成 |
| RAFT | 不调用，不复制依赖它的预处理／训练管线 |
| 损失 | 四种任务：视频 FM、过程 FM、实际输出稠密表征、实际视频过程文本对齐 |
| 创新表述 | 不把 latent、门控、循环、deformable attention 或联合 FM 本身写成首次提出 |

训练数据整理和离线研究对照不是正式推理筛选；所有正式生成结果都进入评估，失败不能被隐藏。

## 3. 五个容易混淆的概念

### 3.1 因果不等于顺序，也不等于生成器内部的反馈

需要区分：

- 时间顺序：接近在接触前，接触在相关响应前。
- 前提依赖：没有该作用，不应凭空出现由它导致的响应；其他真实作用仍可能引起运动。
- 条件后果预测：根据可见初始条件与动作意图，预测后续过程的合理分布。
- 严格物理因果识别：区分隐藏因素、干预及反事实机制；只靠自然视频不能自动保证。
- 模型内部修改效果：改变某个写入是否引起输出改善；它与世界中的因果关系不是同一问题。

本版重点训练前三者，使用受控诊断验证控制能力；不把观察相关、VLM 解释或 attention 权重直接解释为物理因果真值。

### 3.2 “各向异性”至少有三层

1. 区域非均匀：背景、接触边界和响应区域不应同权处理。
2. 时空方向性：接近方向、接触法向附近、前因与后果的时间跨度，决定应读取和修改哪些位置。
3. 材料本构各向异性：材料沿不同方向有不同力学性质，需要额外可信材料数据。

当前拟实现前两层，不声称仅凭方向性 attention 学出了第三层。ProPhy 的 anisotropic response 主要支持非均匀 token／区域响应，不能直接当作材料各向异性证据。[ProPhy](https://arxiv.org/html/2512.05564v2)

### 3.3 多样性既要片内“过程完整”，也要片间“合法变化”

片内要求必要状态转移真正发生，而不是静止得分高；片间要求同条件下存在合理速度、时机和路径变化，而不是把不同合法未来压成一条平均轨迹。

不最大化运动幅度，不以全局光流或画面变化作为成功。物理合理的停顿、碰撞后的减速和落定也应保留。

### 3.4 三种强度不是一回事

- 物理过程重要性：这个局部是否决定事件成立。
- 实际运动强度：主体位移、速度、形变幅度等，需考虑时间与尺度。
- 模型修改强度：门值或特征残差范数。

接触点可能位移很小却最重要；背景支撑几乎不动却必须保持；大的特征修改也不等于更大物理力。

### 3.5 局部不是孤立，也不是最后几步才处理

两球之间很小的间隙可以决定“有没有撞到”。书的原位置和新位置可能相距很远，但属于同一次状态变化。局部修正应是稀疏的关联区域联合修正，而不是只放大一个小方框。

## 5. P 到底是什么，怎样得到，如何装入过程信息

### 5.1 定义：一份连续过程随机状态，不是手工物理参数表

Pσ ∈ R^(Tp×Hp×Wp×Dp)，位置对应统一时空网格，通道不预定义物理意义。它与视频 zσ 一起表示当前对整段过程的生成状态。

训练中的参考为：

\[
T=\operatorname{sg}\left[\mathcal N_{\rm train}\,
\mathcal A_{\rm grid}\bigl(\Phi_{\rm proc}(x)\bigr)\right].
\]

- x 是本样本可靠视频；Φproc 是冻结稠密视频 encoder。
- Agrid 是固定取层、时间戳对齐、空间映射，不能把全局 pooled vector 伪装成局部网格。
- Ntrain 使用训练集固定统计；必要降维使用训练集拟合后冻结的线性压缩，并先验证压缩没有损失转移／运动能力。
- 不逐视频归一化运动幅度，不把每段的最大运动强制缩到相同值。
- T 的坐标、维度、归一化定义固定。P 直接在这个目标空间生成，不额外训练一个可与目标共同塌缩的“语义翻译塔”。

因此两条处理路径不同：GT 经 teacher 编码得到目标；学生从带噪联合状态、当前观察和条件预测目标空间的过程。但最终比较的维度、坐标和监督含义明确对应，并非两个未经校准的 latent 强行相等。

### 5.2 为何从“清洁 P 回归”改成过程分布

\[
z_\sigma=(1-\sigma)z_0+\sigma\epsilon_z,\qquad
P_\sigma=(1-\sigma)T+\sigma\epsilon_P,
\]
\[
v_z^*=\epsilon_z-z_0,\qquad u_P^*=\epsilon_P-T.
\]

σ 从 1 向 0 推进。两个噪声来自同一 seed 派生的独立随机子流；是一个联合样本，不是两个候选视频。

正式推理从 εz、εP 开始，不读取未来 GT。视频和 P 同步采样，避免把单帧下多种合法未来都要求确定性编码成唯一一条“平均计划”。但过程 FM 也不保证没有模式坍缩；高噪声处一次干净端点估计仍可能呈条件均值趋势，需要完整采样和多 seed 评估。

这不是否定 FM：视频 FM 本身能学习动态，不只是美学优化；不足之处是目标和信息通路未必充分强调短交互、角色与过程执行。[Flow Matching](https://arxiv.org/abs/2210.02747)

联合视频／物理 latent FM 已由 [PHANTOM](https://arxiv.org/html/2604.08503v3) 研究，不能作为我们的原创主张。当前价值在于让它成为低成本因果过程学习与定向修改的基础，不复制其镜像物理分支。

### 5.3 信息容量不是靠给通道命名获得

需要让 P 同时具备：

- 时间顺序与局部变化可分辨；
- 不同作用角色、前置条件和结果可区分；
- 运动程度、身份持续和关键几何变化没有在压缩中消失；
- 在未见布局／外观上保持预测能力；
- 通过写入实际控制视频。

这些是教师审查、数据覆盖及探针的要求，不是 P 的固定子槽或通道分组。若这些能力不成立，就替换教师、对齐方式或数据；不能靠“物理 latent”这个名称补足。

## 6. 因果过程学习：同一 SharedCell 的两种条件视图

### 6.1 主路径视图：监督真实生成正在使用的过程预测

SharedCell 在 A／B 读取真实当前特征及同一个 Pσ，预测过程速度 uP。过程信息经实际特征写入进入视频生成，视频 FM、L_out 和 L_align 的梯度继续训练这个执行通路。

不能只在旁边建一个预测很好的 P 头，而让 Wan 绕开它生成。

### 6.2 前置条件预测视图：必须进入主线，不只是事后探针

从本样本的原始视频先截取可见历史，再独立编码：

~~~text
允许的首帧／历史片段 → 独立历史编码与小投影
                     + 动作意图／文本 dropout
                     + 合法加噪的未来 Pσ
                     → 同一 SharedCell
                     → 未来过程速度预测
                     → 同一个 L_struct 目标
~~~

这使模型学习“从前置条件预测转移”，而不只是看过完整事件后重建其特征。它是同一种条件过程 FM 的训练视图，不增加第五项目标，不引入独立 reasoner 大模型，也不额外运行 Wan。

严格边界：

1. 不能先把完整视频送进双向 encoder，再截取所谓历史；也不能读混入未来的 H、P 前缀或缓存。VAE 的时间感受野也需核对：除明确允许的加噪未来 Pσ 外，完整 GT 经时间编码后截出的首帧 latent 不能未经检查就充当无未来历史。
2. σ<1 时，未来 Pσ 含加噪 GT 信息，是合法条件去噪，不是完全无未来预测；纯噪未来的完整预测能力需单独测试。
3. 正常生成继续保留完整用户指令；预测视图可采用只描述起始动作的可靠文本和文本 dropout，诊断时不能把细致后果提前写进条件。
4. 单帧可能缺少速度等信息。首帧条件必须保留为主要训练设置；额外历史视图只能增强训练，不能在评估中悄悄给模型额外帧。
5. 权重共享本身不是“因果能力已控制生成”的证据，必须比较加入该视图前后的实际视频，并做前因敏感性与写入控制实验。

### 6.3 在推理里，推理与修正如何结合

A 用当前联合状态与条件提出可执行过程假设；B 把它与主干随后产生的实际响应共同作为更新依据。预测与观察不一致是修正线索，不是已知错误真值。

不新增一个“因果评分器”决定要不要重新生成。共享单元学习的更新应同时影响过程速度和关联位置的实际写入。若历史预测只改善辅助分数、不改善生成，这个视图就未完成职责，应修接口或删除无效实现，而不是把它计为贡献。

## 7. 主模型与状态提交：不回头重跑

### 7.1 只有两个顺序接口

A 位于一次原生 Wan 前向的较早层，B 位于其后的中层。两者共享小型时空计算主体，只保留必要的层投影和写入接口。

\[
u_A={\rm Cell}_\theta(P_\sigma,H_A,c,\sigma,A),\quad
\widehat P_{0,A}=P_\sigma-\sigma u_A.
\]

A 写入时保留 (Pσ, P̂0,A, σ) 两种视图，不只依赖高噪声下可能平均化的清洁估计。随后正常计算到 B，读取已经受 A 影响的 H_B，再修订过程速度与本层特征。

本步 Pσ 在 A、B 和所有内部小循环中不可原地改变。内部迭代只更新临时工作状态或速度估计；最终 uB 随视频速度一起交给 scheduler。

B 的过程输出采用 uB=uA＋δuB，新增过程增量头与 B 特征写入头均零初始化，使刚加入 B 时完整联合轨迹仍等价于只有 A 的模型。δuB 只是同一过程速度的修订，不是额外视频向量场残差 U；L_struct 监督总 uB，不另加残差标签或损失。

否则，若先把 P 移到另一条状态，再继续用原 εP−T 给它监督，就不再是声明的标准过程 FM 标签。

### 7.2 B 能修整段视频时间轴上的结构

B 的读取和写入覆盖整段 latent 的选定关联位置，因此可以一起调整接触前路径、接触间隙和之后响应。去噪时间与视频时间不同：“当前去噪步只向后运行网络”不等于只能修改视频后几帧。

中期发现没有形成碰撞时：B 对当前相关特征及过程速度做修正，剩余原生层顺序继续；下一正常噪声步使用更新后的联合状态。不能跳回本步 A 或再次调用整条尾部。

### 7.3 CFG 两分支与两种速度必须一致

原生条件／无条件分支都读取同一个 (zσ,Pσ)，分别得到临时 (vz,uP)，任何一支不独立提交状态。无条件分支使用自身条件约定，不读取条件分支提前算出的清洁 P。work、关联核和临时消息也必须按分支隔离；交换两分支执行顺序不应改变最终结果。

\[
(v_z,u_P)_{\rm cfg}
=(v_z,u_P)_{\rm uncond}
+s_{\rm cfg}\bigl[(v_z,u_P)_{\rm cond}-(v_z,u_P)_{\rm uncond}\bigr].
\]

再一次同步更新：

\[
z_{\sigma'}=z_\sigma+(\sigma'-\sigma)v_{z,\rm cfg},\quad
P_{\sigma'}=P_\sigma+(\sigma'-\sigma)u_{P,\rm cfg}.
\]

这是首版 Euler 契约；采用多步求解器时，两种状态必须使用兼容的阶段、时间点与各自历史。不能 z 用二阶、P 随意 Euler 后仍称严格同步。CFG 下过程目标与部署误差需实际检查，不能假设大引导越好。

### 7.4 伪代码

~~~text
z, P = one_joint_noise_sample(seed)   # 独立子流，一条联合样本
apply_native_image_condition(z)

for sigma, sigma_next in normal_schedule:
    snapshot = (z, P)                # 本步不可由 A/B/CFG 分支原地提交

    for branch in native_cfg_branches:
        H_A = Wan_blocks_before_A(snapshot.z, branch)
        u_A, work = SharedCell(snapshot.P, H_A, branch, sigma)
        H_A = write_A(H_A, snapshot.P, u_A, work)

        H_B = Wan_blocks_A_to_B(H_A)
        K = relation_kernel(snapshot.P, u_A, H_B, native_fine_observation)
        u_B, group_message = SharedCell(..., gather_with(K))
        H_B = H_B + scatter_with_same_kernel(K, group_message)

        v_z = Wan_remaining_blocks_and_head(H_B)  # 只执行一次
        save_temporary_branch_fields(v_z, u_B)

    v_z, u_P = joint_CFG(fields)
    z, P = one_joint_solver_commit(snapshot, v_z, u_P, sigma_next)
    restore_native_image_condition(z)

decode(z)                            # 同一条视频
~~~

K 个正常 Euler 噪声步、两路 CFG 仍为 2K 次完整 Wan 分支前向；新增成本是两分支的小单元、读写和投影。若求解器每步需要多次模型求值，按真实 NFE 计数，不伪称固定 2K。

## 8. 核心局部模块：同核取证与多位置联合写回

### 8.1 为什么只有空间 gate 不足

给蓝球位置一个大 gate，并不保证红球真的撞到了它；只在书的新位置增强形状，也不自动清除原位置的残留；只补网球轮廓，不能补全触拍前后的逻辑。

因此“需要改哪儿”和“哪些位置必须一起改”都应学习。后者是本版重点研究的增量。

### 8.2 连续稀疏关联，不设语义 query

以当前网格位置 i 为锚，由 P 与实际 H 学习 K 个连续时空位置 r_ij、关联权重 a_ij；权重经组内 softmax 为非负，坐标统一到带真实时间映射的时空参考系，再映射到各自网格：

\[
r_{ij}=r_i+\Delta r_{ij},\qquad
o_{ij}={\rm Sample}(H_{\rm fine},P_\sigma,\widehat P_{0,A};r_{ij}).
\]

i、j 只是网格和采样索引。没有“第一个点必须是施力者、第二个点必须是受力者”的规定，也没有按物理量命名的 query。

偏移带时间与空间坐标，邻域可拉长、偏向运动方向并跨前后时刻；主体交互也可以是多方、多点，不硬限制二元对象数。保留稠密低成本上下文，防止稀疏读取漏掉原位置或静止支撑。

### 8.3 关系组形成一个消息，再向相关端点分别修改

\[
m_i={\rm Cell}_\theta(\{o_{ij},r_{ij},a_{ij}\}_{j=1}^{K},c,\sigma),
\qquad
\delta_{ij}=W_{\rm write}(m_i,o_{ij},r_{ij}).
\]

读取和写回使用同一组位置／插值核：

\[
\Delta H(v)=
\frac{\sum_{i,j}a_{ij}\,b(v,r_{ij})\,g_{ij}\,\delta_{ij}}
{\varepsilon+\sum_{i,j}a_{ij}\,b(v,r_{ij})}.
\]

b 是可微插值／splat 权重；g 是学习到的有限更新门。覆盖重叠需归一化，避免“被更多采样点覆盖”自动意味着更大修改。更新有符号，可在旧位置抑制残留、在新位置形成响应，但不是手工删除／添加对象规则。

这条公式是待实现的设计，不是已证明更优的方法。连续采样与 scatter 的坐标梯度、边界和重叠处理必须做数值测试。

### 8.4 写入哪里，怎样保留真正细粒度信息

读取优先使用：

- 当前 H_B 的原生 token，而不是只有池化物体向量；
- 当前 zσ 的原生 VAE 网格子块，经可学习小投影保留局部结构；
- P 的有噪／清洁估计视图与时间位置；
- 关联位置的接触前后上下文与非运动支撑。

原生 latent 比像素仍粗，读它不等于已经看见清晰高分辨率接触。先验证 GT 经 VAE 重建后细节是否还在；若压缩已经抹掉关键间隙，不能靠反复读同一 latent 保证修复。

写入统一落到当前 B 层特征。可以用子网格到 DiT 通道的小型投影保留端点差异，不直接覆盖 zσ，也不在 B 偷用尚未算出的本步完整端点。推理不反复解码 GT／视频，不额外增加视觉大塔。

### 8.5 它怎样同时服务各类问题

| 问题 | 关联取证与联合修改 | 仍须监督／验证的部分 |
|---|---|---|
| 无接触却有响应 | 共同读主动方路径、可能接触处与后果时段，协同改路径和响应 | 前提依赖不能只靠注意力学名词，需历史预测及过程文本 |
| 原位置残留／复制 | 原位置、搬移路径、新位置共同写回 | 不能靠 latent 总量守恒保证对象数；要核对可见身份／数量 |
| 刚体变形、穿模 | 读双方轮廓、支撑、接触前后几何 | 单目可见几何不证明三维非穿透；材料允许形变不能一律抑制 |
| 视频文本错配 | 过程 P 和组消息读取动作／角色条件 | L_align 必须作用于实际视频，不能只匹配读过文本的 P |
| 背景漂移／伪影 | 原支撑及随机背景仍被观察和监督 | 不把背景权重设零，保留原生画质训练；教师可能对纹理伪影不敏感 |
| 动作很小、未完成 | 按完整过程及程度描述训练，保留未来分布 | 不奖励更大 residual；真实完成与合理强度分开统计 |

不强加特征更新反对称或 latent 总和守恒：特征之和不是质量，遮挡／出画也不等于对象消失；断裂、液体和可变形物体更不适合机械对象数规则。

## 9. 四项损失：知识、执行和语义各有落点

\[
\mathcal L=
\mathcal L_{\rm FM}
+\lambda_s\mathcal L_{\rm struct}
+\lambda_o\mathcal L_{\rm out}
+\lambda_a\mathcal L_{\rm align}.
\]

L_struct 在本版被过程 FM 替换；L_proc 若在代码中出现只是它的别名，不是第五项。不给数量、接触、形变、gate、运动、循环分别再加独立目标。

### 9.1 L_FM：正常视频生成分布

\[
\mathcal L_{\rm FM}=\mathbb E\|v_\theta(z_\sigma,P_\sigma,c)-(\epsilon_z-z_0)\|^2.
\]

使用正常 GT 加噪路径，遵守原生首帧 mask 与条件 dropout。它训练画面与动态分布，不宣称它只能学习画质。

### 9.2 L_struct：实际过程速度及前置预测的同目标监督

\[
\mathcal L_{\rm struct}
=\mathbb E_{m,\sigma,\epsilon_P}
\sum_{r}\alpha_{m,r}
\frac{1}{|\mathcal G_{\rm valid}|}
\sum_{u\in\mathcal G_{\rm valid}}\|u_{P,\theta}^{m,r}(u)-(\epsilon_P-T)_u\|^2.
\]

m 是完整实际路径或历史条件训练视图，r 是选定 A／B／小单元估计，α 归一化。不是给每轮定义不同物理任务。

首版对合法过程网格使用均匀 FM，剔除 padding 等无效位置；教师可靠性先用于样本审查。物理重点通过数据分层、L_out 的窗口与 L_align 加强，避免对过程 FM 随意施加依赖 GT 内容的逐 token 权重后，仍声称学到了未加权的精确联合分布。监督窗口的可靠性和重要性停止梯度，不受可学习 gate 控制；未知事实不能伪装成已知负例。

这项损失说明学生学习教师过程分布，不足以证明学到真实力学定律，也不能独自保证 writer 被使用。

### 9.3 L_out：实际写入后结果的稠密监督，局部修正的核心训练落点

\[
\widehat z_0=z_\sigma-\sigma v_\theta,\qquad
\widehat x=D_{\rm VAE}(\widehat z_0),
\]
\[
\mathcal L_{\rm out}
=\mathbb E_{\Omega}
\,d\!\left(\Phi_{\rm out}(\widehat x|_\Omega),
\operatorname{sg}[\Phi_{\rm out}(x|_\Omega)]\right).
\]

Ω 包括低分辨率全段、重点转移及空间关联窗口和随机背景；预测与 GT 使用相同时间、裁剪与尺度。局部窗口不能只裁“飞走后的球”，还应覆盖作用双方、原位置和前后状态。窗口采样方案属于同一表征距离任务，不另加十种隐藏物理损失。

Φout 首先复用经过审查的稠密视频教师。若其对轮廓／残留没有辨识力，单独比较以 LingBot-Vision 等边界特征替换此项的方案；不自动把所有教师拼接叠加。替换后必须保留过程与文本验收，并记录额外模型成本。

该预测是当前噪声处、真实写入后由原生输出头得到的干净端点估计，不是完成全链采样的最终视频。只在校准后的可读噪声区间计算，不用模糊高噪声端点硬拟合唯一 GT 未来。

梯度必须经过冻结教师对输入的导数、VAE、后续 Wan 和实际写入，抵达 corrector；“冻结参数”不等于把生成支路放入 no_grad。

若只是对原生 latent 端点做 MSE，它与正常 FM 仅差噪声权重，不算新物理监督，应删除冗余包装。

### 9.4 L_align：实际视频的状态变化、前提和指令执行

使用一个小型时序视频—文本匹配头 ψ。先在两套数据的可信正对应与核验文本负例上训练，再冻结；生成器阶段以实际输出视频表征进入同一个匹配目标：

\[
\mathcal L_{\rm align}
=-\log\frac{\exp\!\left(s_\psi(\widehat x_\Omega,c_\Omega^+)/\tau\right)}
{\exp\!\left(s_\psi(\widehat x_\Omega,c_\Omega^+)/\tau\right)+
\sum_j\exp\!\left(s_\psi(\widehat x_\Omega,c_{\Omega,j}^-)/\tau\right)}.
\]

该头保留时间位置与词级交互，不只比较全局名词向量。头本身训练也是这一个匹配任务，数据标注及训练成本单列，不隐藏成免费的 teacher。

负例一次改变一个可确认因素，例如：

- 同样两球，却把主动／受动角色互换；
- 保留物体，去掉真实发生的接触或必要动作；
- 响应出现在作用之前；
- 书移动后，描述旧位置仍保留同一本实体副本；
- 真实只有一次击球，却描述再次击球；
- 真实压缩明显，却描述仅接近而未压缩。

这些是对同一真实视频不匹配的文本，不是合成错误视频，也不是真实干预 GT。多次弹跳若被文本要求则必须当正例，不能统一做“只能一次”的监督。

正负词项分布需平衡，进行 text-only 捷径测试；不可确认的接触、遮挡数量和程度跳过相应对比。Cosmos 等离线描述也需逐项证据，不因解释长就认为可靠。

没有错误视频时，全是正标签的“物理正确 BCE”无法训练可靠判别能力；因此不用它。L_align 训练的是已核验对应关系，不是完备物理裁判。

### 9.5 为什么这四项不是万能约束

正确过程预测、实际输出梯度及状态变化文本可以共同提高能力，但不提供严格计数守恒、三维碰撞求解或任意错误修复保证。模型若仍对某类伪影失明，应改教师、窗口或数据并重新验证，而不是宣称该问题已被某个泛化损失“覆盖完毕”。

## 10. 运动强度和多样性：用分布与完成度，不用“越动越好”

### 10.1 训练数据中的必要处理

对可靠训练片段记录可见运动程度、事件完整性、相机运动、遮挡和持续时间，用于分层采样与描述，不建立运行时语义槽。

避免 OpenVid 画质高但有效交互弱的片段稀释全部学习；也不能只保留极强运动，造成轻触、缓慢滑动、落定等过程缺失。采样平衡是数据策略，不额外增加强度奖励。

时间差使用真实 Δt；可见位移按物体尺度或画面尺度注明单位；分离相机引起的全局变化。若没有可靠几何标定，就报告像素／相对尺度运动，不写成真实米每秒或力。

### 10.2 不能把平均方向近零解释成没有运动

\[
\|\mathbb E[v]\|\ne\mathbb E[\|v\|].
\]

左右两种合法未来可以方向均值近零但各自明显运动。联合过程采样保留这个可能性，仍需比较完整样本分布。这个数学区别不意味着教师的任意 feature 差值就是物理速度。

不额外加最大化速度、扩大 feature 差、增大 gate、最小化全局加速度或单独“多样性 loss”。

### 10.3 评估怎样不被静止或乱动骗过

同时报告：

- 片内任务完成与必要状态转移；
- 主动主体、作用成立、响应顺序；
- 运动程度分布与持续时间，含静止失败比例；
- 全部 seed 的输出多样性；
- 合法子集的多样性及其合法率，两者一起给出。

不只展示合法子集而隐藏失败，不从多个 seed 中为每个输入挑最好结果。用于估计分布的多 seed 实验不是推理候选筛选。

## 11. 前期的地基如何学对，中后期如何有足够修改能力

早期目标是有依据且可执行，不是第一次预测永久正确。过程 FM 在全噪声区间学习，历史预测强调前置依赖，A 的实际写入使它尽早参与主干。

中期仍可调整路径、时序、身份关系和关键几何；B 的多位置写回比单中心门控提供更有针对性的可修改范围。后期缩小不必要的大范围重构，但不能把全部 P 硬锁死。按实际 σ 校准更新尺度，而不是笼统把前十步叫结构期。

现有研究中的“早期物理、后期画质破坏”是特定模型与实验观察，不是所有 DiT、所有层和所有现象的普遍定理。需在自己的模型记录早／中／后过程读出与最终执行，不能据此预先决定只能在早期修物理。

如果角色、布局和接触拓扑从开始就严重错误，剩余步数和小单元容量可能不足。当前不以回退重采样作默认补救；优先检查：

1. 教师与数据是否能表达正确的转移；
2. 参考过程能否通过当前 A／B 控制视频；
3. 写入位置、空间范围与子网格分辨率是否足够；
4. 自预测过程和标准训练路径是否有过大差距；
5. 必要时在明确证据下增加少量主干适配容量，而非先加更多循环。

只用自然正确视频的标准加噪训练，不等于覆盖所有严重离轨错误。失败要报告，不能承诺每次修改都正确或每轮必然变好。

## 12. 反馈、多轮与训练分布：三件事分清

| 形式 | 获得了什么新信息 | 决定 |
|---|---|---|
| 同一个观察上迭代 SharedCell 工作状态 | 只有计算加深，没有新主干观测 | 可选，必须等算量验证 |
| A 写入后自然计算到 B | 已经过后续原生层处理的实际响应 | 主线 |
| 下一正常 σ 步继续读取新 z、P 和特征 | 正常采样提供的新证据 | 主线，不加独立历史塔 |
| 同步过程 FM | 训练 P 与视频的合法联合状态，避免任意旧缓存训练标签错位 | 主线 |
| 多次重跑 Wan／尾部后择优 | 额外大计算及筛选 | 不采用 |

H_B−H_A 包含层深和原生计算变化，跨步差值包含正常去噪变化，不能直接称作写入的纯因果效果。真正修改效果通过离线受控消融测量，正式推理不生成两条再选择。

首版不缓存复杂历史。若下一步的联合状态和真实观察已足够，就不要再建 memory；只有删掉某种历史信息明确损害效果时才讨论增加。

## 13. 因果与局部修正的关键实验证据

### 13.1 过程知识、实际控制、修改效果分别证明

- 知识：独立前置条件预测、过程读出、状态变化／角色／程度区分；冻结 teacher 分数不是唯一指标。
- 控制：在合法且条件兼容的诊断中，改变过程条件是否引起对应视频变化；参考 T 输入是标注清楚的能力上界，不当正式结果。
- 修改：B 改善多少原先失败，又破坏多少原先正确；完整视频而非单步端点作最终判断。

自然近邻不是严格反事实；遮蔽输入、改变文字、交换 latent 都是诊断性干预，不能伪装成真实世界 do 操作。

### 13.2 因果主线的必要对照

1. 只有完整视图过程监督 vs 加入前置预测视图，匹配训练预算。
2. 固定动作意图、变化可见前提；检查相关响应是否随之变化。
3. 对前提未成立的情形，检查是否凭空出现该响应；不把所有无接触运动都误判为错。
4. 变化无关背景，检查它是否造成同样大的“因果”变化。
5. 未见布局、物体外观与相机条件下重复上述检查。

### 13.3 局部模块最重要的三阶消融

固定 K、参数、训练数据和计算：

1. 固定各向同性邻域＋中心写入；
2. 学习方向性邻域＋中心写入；
3. 相同方向核＋关联位置成组写回。

第三项若只因修改面积更大获益，不足以证明关系价值。补充对照应尽量匹配覆盖区域、更新能量与写入次数，仅打乱关系伙伴绑定。绑定正确比绑定打乱更好，才支持“关系指导执行”的解释；严重离分布打乱需披露，不能单独作为因果证明。

### 13.4 独立验收，不能只追 PC

[VideoPhy-2](https://arxiv.org/html/2503.06800) 区分语义执行与物理常识。报告 SA、PC 和联合结果，同时单列完整任务、数量／身份、局部形变、背景及伪影。静止场景物理上未必荒谬，但没有执行指令就不是我们的成功。

除了自动评价，需要关键窗口连续帧和盲评；训练 teacher、匹配头与最终评估器不能完全同源自证。报告场景聚合的不确定性、训练随机性和不同推理 seed；不把小样本趋势写成稳定结论。

## 14. 创新定位：当前可争取的研究主张，不是包装后的组件列表

已知相邻工作包括：PHANTOM 的联合物理／视频建模、PhiZero 的转移表征与 reason-then-render、VideoREPA 的表征对齐、ProPhy 的非均匀响应、State-Change Counterfactuals 的过程文本监督。已有这些工作，单说“增加物理 latent 和因果监督”不足以支撑强创新。

本版更聚焦的可证伪主张是：

> 由条件过程学习得到的时空关系，能否通过同一稀疏关联核的联合取证与多位置执行，改善短时交互、身份去向和局部形变，同时保持完整指令执行与合法运动分布，而不增加主干回溯？

至少要看到：

- 前置预测训练使过程信息更有用，而不只是多一个训练头；
- 相同过程信息通过关联写入比中心写入更有效；
- 不只是改了更多位置或增加更多计算；
- 局部更好时，角色、数量、背景和 SA 不被牺牲；
- 在新条件、多个 seed 和封存测试上成立。

“同核 gather/scatter”也不是自动具有原创优先权。投稿前还要围绕局部编辑、稀疏消息传递、生成控制与 learned optimization 继续检索最近邻；若实验只显示常规组件叠加的小收益，应收缩主张或重新设计，不预先保证 CVPR 强创新／录用。

## 15. 最小保留清单与下一步

保留：一份连续 P、一个 SharedCell、A／B 两个顺序接口、方向性同核成组读写、主路径与前置预测视图、四项任务、可靠局部／过程监督。

删除或暂不加入：固定物理 slot、独立 planner／reasoner 塔、显式对象账本、成套深度／轨迹／光流分支、GeoPhys 筛选、x_err、单独 gate 真值、残差真值、强运动奖励、独立循环单调性损失和无证据的复杂 memory。

后续按 E 在 v4 逐步实现。每次增加机制都保存独立检查点，展示实际视频、改善／破坏和成本。研究可以追求每步增量有效，但不能承诺尚未验证的每一步必然提升；未通过就修当前瓶颈，不继续堆实体。
