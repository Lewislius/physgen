## 1. 一分钟理解

目标是让 Wan2.2 在生成视频的同时生成一份连续过程状态 `P`，再用 `P` 学到的方向性时空关系组织局部取证和联合写回：作用方与响应方、原位置与新位置、接触前后都能作为同一关系组一起修改。

```text
一条联合噪声样本 (zσ, Pσ)
→ Wan 早层到接口 A：预测过程、写入早层结构
→ 原生中间层继续计算
→ 接口 B：读取真实中层响应，修订过程并联合写回关联位置
→ 原生剩余层输出视频速度
→ 视频速度和过程速度一起做 CFG
→ 联合求解器同步更新 (z, P)
→ 下一正常噪声步
```

本版有两个关键变化：

1. `P` 不再由首帧和文本确定性初始化，也不再直接回归一个清洁 `P`。它是与视频共同去噪、共同采样的连续随机过程状态。
2. 局部修正不只给中心位置加 gate。模型学习一组方向性时空关联，用同一组位置完成读取、组内推理和多位置写回。

## 2. 必须遵守的边界

| 项目 | 当前契约 |

| 数据 | 只用 WISA／OpenVid 正常视频、描述及由这些视频得到的可靠教师目标 |
| `P` 的组织 | 连续稠密时空网格；不设质量、速度、接触、对象等固定语义 slot／query |
| 错误视频 | 不使用 `x_err`，不建立错误—修复视频配对库 |

| 正式推理 | 一条联合轨迹；不做 best-of-N、verifier 选片、失败重启或分段采样 |

## 3. 核心变量与联合 Flow Matching

训练视频 `x` 经 VAE 得到干净视频 latent `z0`。冻结的稠密视频教师产生过程目标：

\[
T=\operatorname{sg}\!\left[\mathcal N_{\rm train}\,
\mathcal A_{\rm grid}(\Phi_{\rm proc}(x))\right].
\]

`A_grid` 固定教师取层、时间戳和空间映射，`N_train` 使用训练集固定统计。不能把全局 pooled feature 扩展成伪局部网格，也不能逐视频归一化掉真实运动程度。必要的线性降维需在训练集拟合后冻结，并先确认没有丢失转移、身份和运动信息。

视频与过程状态使用相同噪声水平 `σ`，噪声由同一个 seed 派生的两个独立随机子流给出：

\[
z_\sigma=(1-\sigma)z_0+\sigma\epsilon_z,
\qquad
P_\sigma=(1-\sigma)T+\sigma\epsilon_P,
\]

\[
v_z^*=\epsilon_z-z_0,
\qquad
u_P^*=\epsilon_P-T.
\]

其中 `Pσ ∈ R^(Tp×Hp×Wp×Dp)` 与 `zσ` 一起描述整段视频当前的生成状态。它的通道意义由学习形成，不对应手工物理参数。

正式推理从 `(εz, εP)` 开始，不读取未来 GT。这样可以表示同一首帧和文本下多种合法的速度、时机与路径，而不是把所有未来压成一个确定性平均计划。

## 4. 同一个 SharedCell 的两种训练视图

### 4.1 实际生成路径视图

SharedCell 在接口 A、B 读取真实 Wan 特征、当前 `Pσ`、文本、首帧和噪声水平，预测过程速度 `uP`。过程信息必须通过特征写入实际影响视频，使 `L_FM`、`L_out` 和 `L_align` 的梯度也训练这条执行通路。

只在旁边训练一个可读出的 `P` 预测头，而让 Wan 绕开它生成，不满足本方案。

### 4.2 隔离的前置条件预测视图

```text
先截取允许的首帧／历史片段并独立编码
+ 动作意图或文本 dropout
+ 合法加噪的未来 Pσ
→ 同一个 SharedCell
→ 预测未来过程速度
→ 同一个 L_struct 目标
```

这个视图让模型从可见前提学习后续转移，是主训练的一部分，不是第五个损失，也不是独立 reasoner。

必须防止未来泄漏：不能先用双向编码器处理完整视频再截历史，不能复用看过未来的特征、`P` 或缓存；还要核查 VAE 的时间感受野。`σ<1` 时的 `Pσ` 本身含有合法加噪目标信息，因此纯噪未来的条件预测能力仍需单独测试。

正式生成仍使用完整用户指令。额外历史帧只用于明确配置的训练增强，评估时不能暗中增加输入。

## 5. A／B 顺序接口与状态提交

接口 A 位于 Wan 较早层，接口 B 位于其后的中层。两者共享小型时空计算主体，只保留必要的层投影和写入头。

在 A：

\[
u_A={\rm Cell}_\theta(P_\sigma,H_A,c,\sigma,A),
\qquad
\widehat P_{0,A}=P_\sigma-\sigma u_A.
\]

A 同时保留有噪 `Pσ` 与清洁端点估计 `P̂0,A`，形成早层写入 `ΔH_A`：

```text
H_A' = H_A + ΔH_A
```

随后 Wan 原生中间层从 `H_A'` 正常计算出 `H_B`。B 读取这个已经受 A 影响的新观察，并输出：

```text
u_B = u_A + δu_B
H_B' = H_B + ΔH_B
```

`δu_B` 是同一过程速度的修订，不是额外的视频速度残差。B 的增量头和特征写入头零初始化，使刚加入 B 时接近只有 A 的模型。

同一步内的 `Pσ` 是只读快照。A、B、SharedCell 内部迭代和两个 CFG 分支都不能原地提交 `P`；内部循环只能修改临时工作状态或速度估计。最终 `uB` 与视频速度一起交给求解器，统一产生下一步 `P`。

B 的时空读写覆盖整段视频 latent 的关联位置，所以能同时调整接触前路径、接触间隙和接触后响应。去噪网络只向后执行，不代表只能修改视频时间轴的后几帧。

## 6. 方向性同核取证与联合写回

单中心 gate 不能表达“哪些位置必须一起改”。对锚点 `i`，模型根据 `P` 和实际特征学习 `K` 个连续时空位置及组内权重：

\[
r_{ij}=r_i+\Delta r_{ij},
\qquad
o_{ij}={\rm Sample}(H_{\rm fine},P_\sigma,\widehat P_{0,A};r_{ij}).
\]

位置偏移同时包含时间和空间坐标，可沿运动方向跨越接触前后时刻。`i、j` 只是网格索引，不预设谁是施力者或受力者，也不限制为两个物体。

关联位置先形成组消息，再分别产生有符号的端点更新：

\[
m_i={\rm Cell}_\theta(\{o_{ij},r_{ij},a_{ij}\},c,\sigma),
\qquad
\delta_{ij}=W_{\rm write}(m_i,o_{ij},r_{ij}).
\]

读取和写回使用同一位置与插值核：

\[
\Delta H(v)=
\frac{\sum_{i,j}a_{ij}b(v,r_{ij})g_{ij}\delta_{ij}}
{\varepsilon+\sum_{i,j}a_{ij}b(v,r_{ij})}.
\]

分母归一化重叠覆盖，避免采样点多的区域自动得到更大修改。更新可在原位置抑制残留、在新位置形成响应，但不硬编码删除、添加、反对称更新或 latent 总量守恒。

B 优先读取当前 `H_B` 原生 token、`zσ` 的 VAE 子网格、`Pσ/P̂0,A`、接触前后上下文和静止支撑。写入统一落在当前 B 层特征，不直接覆盖 `zσ`，也不读取尚未产生的本步最终端点。

## 7. 四项训练任务

\[
\mathcal L=\mathcal L_{\rm FM}
+\lambda_s\mathcal L_{\rm struct}
+\lambda_o\mathcal L_{\rm out}
+\lambda_a\mathcal L_{\rm align}.
\]

### 7.1 视频 `L_FM`

\[
\mathcal L_{\rm FM}
=\mathbb E\|v_\theta(z_\sigma,P_\sigma,c)-(\epsilon_z-z_0)\|^2.
\]

它在正常 GT 加噪路径上训练视频画面和动态分布，并遵守原生首帧 mask 与条件 dropout。

### 7.2 过程 `L_struct`

\[
\mathcal L_{\rm struct}
=\mathbb E_{m,\sigma,\epsilon_P}
\sum_r\alpha_{m,r}\frac{1}{|\mathcal G_{\rm valid}|}
\sum_{u\in\mathcal G_{\rm valid}}
\|u_{P,\theta}^{m,r}(u)-(\epsilon_P-T)_u\|^2.
\]

`m` 表示实际生成路径或前置条件预测视图，`r` 表示选定的 A／B／内部估计。首版在非 padding 的合法过程网格上做均匀 FM；不让可学习 gate 控制监督权重。代码中的 `L_proc` 若存在，只能作为此项别名，不能算第五项任务。

### 7.3 实际输出 `L_out`

\[
\widehat z_0=z_\sigma-\sigma v_\theta,
\qquad
\widehat x=D_{\rm VAE}(\widehat z_0),
\]

\[
\mathcal L_{\rm out}
=\mathbb E_\Omega d\!\left(
\Phi_{\rm out}(\widehat x|_\Omega),
\operatorname{sg}[\Phi_{\rm out}(x|_\Omega)]
\right).
\]

`Ω` 同时覆盖低分辨率全段、重点转移／关联窗口和随机背景。重点窗口应包含作用双方、原位置和前后状态，不能只裁结果区域。

只在教师已校准的可读噪声区间计算此项。梯度必须经过冻结教师对输入的导数、VAE、B 后 Wan 和真实写入抵达 corrector；冻结教师参数不等于把生成支路放进 `no_grad`。若该项只是原生 latent 端点 MSE，它只是重加权 FM，应删除。

### 7.4 视频—文本过程 `L_align`

先用真实匹配描述和经核验的不匹配文本训练一个小型时序视频—文本匹配头，再冻结它训练生成器。负文本每次只改一个可确认因素，例如主动／受动角色、必要接触、响应顺序、身份残留或动作次数；不制造错误视频。

匹配头必须保留时间位置和词级交互，并通过 text-only 捷径测试。遮挡、接触和数量无法确认时跳过对应负例。此项训练的是过程与文本对应关系，不是完备的物理正确性裁判。

## 8. 一次训练前向

```text
输入：正常视频 x、描述 c、首帧 I0

1. VAE 编码 x 得到 z0；冻结教师得到 T。
2. 采样 σ、εz、εP，构造联合状态 (zσ, Pσ) 和两个 FM 目标。
3. 可选地从原视频先截取历史，独立编码前置条件预测视图。
4. 对原生 CFG／condition-dropout 约定下的每个训练分支：
   a. Wan 正常运行到 A；SharedCell 预测 uA 并写入 ΔH_A。
   b. 原生层从 A 正常运行到 B。
   c. 用方向性关联核联合读取；B 输出 uB 和 ΔH_B。
   d. 原生剩余层与输出头得到视频速度和当前干净端点估计。
5. 计算 L_FM、L_struct、L_out 和可选 L_align。
6. 反向更新 SharedCell、A/B 读写投影和必要学生投影。
```

首版冻结 Wan、VAE 和视频教师；文本匹配头预先校准后冻结。接口必须支持零写入等价初始化，新增 B 的 `δuB` 头和特征写入头零初始化。若可靠参考过程仍无法控制视频，再检查接口、分辨率和容量，并在证据支持下评估少量 LoRA，不默认解冻整个 Wan。

## 9. 完整推理流程

```text
z, P = one_joint_noise_sample(seed)   # 两个独立子流，一条联合样本
apply_native_image_condition(z, I0)

for sigma, sigma_next in normal_schedule:
    snapshot = (z, P)                 # 本步只读

    for branch in native_cfg_branches:
        H_A = Wan_blocks_before_A(snapshot.z, branch)
        u_A, work = SharedCell(snapshot.P, H_A, branch, sigma)
        H_A = write_A(H_A, snapshot.P, u_A, work)

        H_B = Wan_blocks_A_to_B(H_A)
        K = relation_kernel(snapshot.P, u_A, H_B, native_fine_observation)
        u_B, message = SharedCell(..., gather_with(K))
        H_B = H_B + scatter_with_same_kernel(K, message)

        v_z = Wan_remaining_blocks_and_head(H_B)
        save_temporary_branch_fields(v_z, u_B)

    v_z_cfg, u_P_cfg = joint_CFG(branch_fields)
    z, P = one_joint_solver_commit(
        snapshot, v_z_cfg, u_P_cfg, sigma_next)
    restore_native_image_condition(z, I0)

video = VAE.decode(z)
```

两个 CFG 分支都读取同一个 `(zσ,Pσ)`，各自保存临时 `(vz,uP)`，且工作状态完全隔离。分支执行顺序不能影响结果：

\[
(v_z,u_P)_{\rm cfg}
=(v_z,u_P)_{\rm uncond}
+s_{\rm cfg}\big[(v_z,u_P)_{\rm cond}-(v_z,u_P)_{\rm uncond}\big].
\]

首版 Euler 同步提交：

\[
z_{\sigma'}=z_\sigma+(\sigma'-\sigma)v_{z,{\rm cfg}},
\qquad
P_{\sigma'}=P_\sigma+(\sigma'-\sigma)u_{P,{\rm cfg}}.
\]

若换多步求解器，`z` 和 `P` 必须使用兼容的阶段、时间点和历史。模型成本按真实 NFE 统计；不能只数外层 schedule 步数。

## 10. 训练与推理最容易混淆的点

- `P̂0=Pσ-σuP` 是当前过程端点估计，不是已经提交的新 `P`。
- `ẑ0=zσ-σvz` 是当前视频端点估计，不是完整采样后的最终视频。
- A 后自然运行到 B 提供了新的主干观察；固定观察上多次更新 SharedCell 只增加计算深度。
- `H_B-H_A` 混有层深和原生网络计算，跨步差值还混有正常去噪变化，不能称为某次写入的纯因果效应。
- 过程重要性、可见运动强度和特征修改强度是三件事；不最大化速度、feature 差、gate 或 residual。
- 多 seed 用于估计条件分布，全部结果都应统计；不能为每个输入挑最好视频作为正式结果。

## 11. 验收与消融

工程正确性至少检查：

- 关闭写入时与同协议原生 Wan 数值等价；
- 每个原生 block 的访问次数符合单次前向契约；
- 两个 CFG 分支共享快照但隔离临时状态，交换执行顺序结果不变；
- `z` 与 `P` 在 CFG 后由同一求解器同步提交；
- A、B、关联坐标、scatter 和投影有有限且非零的有效梯度；
- 冻结教师与 Wan 不切断 `L_out/L_align` 到写入模块的输入梯度；
- 每条视频清空状态，padding、坐标边界和重叠归一化数值稳定。

过程能力需分开证明：

1. **知识**：前置条件预测、角色／状态变化读出和未见布局泛化有效。
2. **控制**：合法地改变 `P` 或前提时，视频中的对应过程随之改变。
3. **修改**：同输入同 seed 下，B 改善原失败的比例高于破坏原正确结果的比例。

局部模块做三阶等预算消融：

1. 固定各向同性邻域＋中心写入；
2. 学习方向性邻域＋中心写入；
3. 相同方向核＋关联位置成组写回。

还需匹配覆盖区域、更新能量和写入次数，并打乱关系伙伴绑定。只有正确绑定优于打乱绑定，才支持“关系指导执行”的解释。

最终报告完整任务执行、角色与接触顺序、数量／身份、局部形变、背景与伪影、静止失败比例、合法率和合法样本内多样性。训练教师、文本匹配头与最终评价不能完全同源自证。

## 12. 增量实施顺序

1. **M0**：核查数据、VAE 细节保真、教师能力、A/B 包装、零写入、CFG 快照和调用次数。
2. **M1**：实现联合 `(z,P)` Flow Matching、A 写入和实际路径 `L_FM+L_struct`。
3. **M2**：加入隔离的前置条件预测视图，验证它是否改善实际控制，而不只改善辅助分数。
4. **M3**：增加 B 的 `uB=uA+δuB`、实际输出 `L_out` 和顺序修正。
5. **M4**：加入方向性同核 gather/scatter 与原生细网格，完成三阶局部消融。
6. **M5**：校准并加入 `L_align`；只有既有阶段出现净收益时，才考虑更深 SharedCell、少量历史信息或主干 LoRA。

每个里程碑单独保存检查点，并报告视频收益、破坏率和真实成本。若某阶段只降低教师损失、没有提高完整视频结果，先修正或删除该机制，不继续叠加模块。

## 13. 当前能力边界

- WISA／OpenVid 是自然视频，不能提供严格干预因果、精确质量、力、摩擦或三维碰撞真值。
- 教师若只识别物体类别，`P` 就不会因名称而自动获得物理过程能力。
- 单帧和文本可能无法确定唯一未来；联合 FM 允许分布建模，但仍可能模式坍缩。
- 只用正常视频的标准加噪训练，对严重离轨状态的恢复能力有限。
- 方向性关联和同核写回是待验证设计，不自动等于材料本构各向异性、物理守恒或原创优先权。
- 固定预算下不能保证每次修正都改善，也不能用重采样和筛选隐藏失败。

当前最小主张是：**条件过程学习得到的时空关系，能否通过同一稀疏关联核完成联合取证与多位置执行，在不增加主干回溯的条件下改善短时交互、身份去向和局部形变。**
