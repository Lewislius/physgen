## 2. 三种张量空间必须分开

以16帧、384×384的教师视图为形状示例；它不是所有训练视频长度的限制：

| 张量 | 示例形状 | 含义 |
|---|---|---|
| GT RGB视图 | `[B,3,16,384,384]` | 固定时间与裁剪对应的训练视频 |
| F_GT | `[B,4608,1664]` | V-JEPA最终层原生输出；已含教师自带的层归一化 |
| F_GT网格 | `[B,8,24,24,1664]` | reshape／轴顺序变化，数值不改 |
| P_i^-／P_i^+ | `[B,8,24,24,256]` | 所有corrector共享坐标约定的学生状态 |
| R(P_i^+) | `[B,8,24,24,1664]` | 学生对固定教师特征的预测 |
| H_i／ΔH_i | `[B,N_H,3072]` | Wan当前位置隐藏特征；N_H取自实际grid_sizes |

**教师GT不需要变成Wan的3072维。** 监督路径是`P_i^+ → R → F_GT空间`；控制路径是`P_i^+ → writer_i → H_i空间`。这是两个不同功能的映射，不应合并成“先把GT变成各层hidden再监督”。

官方G实现维度1664、视频tubelet2、patch16，默认最终层返回Tensor；多层接口可能返回列表或拼接，必须做shape断言。[官方编码器](https://github.com/facebookresearch/vjepa2/blob/main/app/vjepa_2_1/models/vision_transformer.py)

## 3. GT经过什么处理，哪些处理会损失信息

保留完整缓存`F_GT=sg(Φ_last(Qξ(x_GT)))`。Qξ是已记录的取帧、裁剪、RGB归一化；它本身可能遗漏事件或改变观测，必须在编码之前检查。教师Φ也不是RGB的可逆编码，不能声称它保存了所有物理细节。本文能保证的是不再在其输出后默认追加未知或有损的目标映射。

| 操作 | 信息／语义后果 | 基准决定 |
|---|---|---|
| 正确reshape、permute | 可逆重排，不改变token数值 | 使用，并测试往返一致 |
| 按相同坐标选择token | 所选token未变，但未选择位置不受该次监督 | 预算抽样允许；选择规则／概率明确，不冒充完整覆盖 |
| 学生侧R：256→1664 | GT不动；预测能力受学生容量限制 | 使用，A／B共享轻量线性读出 |
| GT侧可训练1664→256／3072 | 若无独立固定目标约束，可与学生共同漂移甚至退化 | 基准禁止 |
| 固定GT平均池化 | 不会自动制造“错误标签”，但不可逆且可能消除区分事件的信号 | 从默认去掉；只作压缩消融 |
| token通道L2归一化／余弦 | 保留方向，丢失幅值差异 | 从L_struct基准去掉；保留为显式度量消融 |
| 教师内部最后层归一化 | 是固定预训练编码器输出定义的一部分 | 保留，不混称为外加压缩器 |

池化的简单反例：四个标量token`(1,-1,1,-1)`与`(-1,1,-1,1)`的逐位置关系不同，但平均都为0；维度对齐成功不能证明监督信息充分。该反例说明信息损失，不证明真实V-JEPA某个通道代表碰撞。

本次选择native网格＋native特征MSE，是为了建立可检查的监督基准，**尚未证明它的生成效果比池化＋余弦更好**。后续若压缩方案在关键关系和输出上不退化，可以作为有证据的效率配置，不能预先当成无损等价。

## 4. 每个corrector的P到底如何对齐和更新

首版固定同一P网格贯穿所有corrector，层深不改变P坐标或通道。网格由生成请求的帧数、时间取样和固定画幅视图规格决定，在没有GT的推理中也能构造；GT只为这些位置提供目标值。第一套实现固定经过审核的384方形全过程视图，任意宽高比／长视频多窗必须另过对应契约，不能静默裁掉交互双方。

1. 教师token的空间锚点来自其16×16 patch覆盖区，时间锚点来自对应两帧的真实时间戳；保留tubelet区间而非只记第几个token。
2. Wan的H从`grid_sizes`还原，排除padding；时间坐标按因果VAE的首帧及后续时间分组记录，不假定与教师tubelet等距同索引。坐标锚点不是感受野边界，教师／VAE都可能利用周围上下文。
3. `Read_i`先将H逐位置归一化并投影3072→256，再按记录的时间／空间坐标采样到P网格。轴上通过相邻坐标及线性权重插值，非均匀时间不得简单套整数缩放；边界和无效区域规则固定。
4. SharedCell初始工作量固定为`Z=P_i^- + Read_i(H_i) + Pos + Embed(σ) + Embed(i)`，交叉注意力使用已投影文本。4个共享小block后经共享最终LN输出候选ΔP及逐token标量gate。
5. 提交`P_i^+=P_i^-+s_i·η_i_eff·G_i⊙ΔP_i`，再用同一个P_i^+执行R读出、writer写入以及允许的状态传递。既有参数预算涵盖上述投影、归一化和头；固定位置／坐标算子不增参数。

内部重复更新时固定本次真实H观察，迭代次数不等于多次Wan观察。B的有效η和γ包含q_B；B旁路时不生成新的提交态。P网格改变必须建立新配置，不能在不同层随机重建、重排或插值后还声称监督的是同一状态。

教师上下文先固定，再与P对应；从完整教师token中截一段不等于只编码那段视频。长视频重叠窗指定唯一目标上下文／归属，同一P位置不能同时被不同上下文目标强制拟合成两个值。

## 5. 直接监督更新后P；更新前P只用于诊断

对每个启用corrector i，取其最终提交P_i^+；R(P)=WP+b，教师通道D_T=1664：

\[
L_{s,i}=\frac{\sum_u\rho_u w_u\,
\|R(P_{i,u}^+)-F_{{GT},u}\|_2^2/D_T}
{\sum_u\rho_u w_u+\varepsilon},\qquad
L_{\rm struct}=\mathbb E[g_s(\sigma)\sum_{i\in\mathcal I}\alpha_iL_{s,i}].
\]

I只包含本次启用且有有效目标的实际提交态。A-only或B旁路时α_A=1；A／B启用时起步各1/2。M3a的A项可作固定监测，只有B参数更新。内部若有r轮，默认监督r=最后一轮，不把SharedCell内部每个Transformer层当作独立corrector。

若只监督P_i^-且它不依赖当前cell，当前cell的ΔP参数不会从这项损失获得梯度。P_i^-若恰是上个corrector提交态，它在上个位置已被监督；不另添加重复loss并称为当前cell训练。

令q=∂L/∂P_i^+，逐token标量G沿通道广播，则：

\[
\frac{\partial L}{\partial\Delta P_c}=s_i\eta_i^{eff}G_iq_c,
\quad
\frac{\partial L}{\partial G_i}=s_i\eta_i^{eff}\sum_c\Delta P_cq_c.
\]

因此无需独立ΔP标签。对本版MSE还有恒等式`R(P+D)-F_GT = WD-(F_GT-R(P))`；右侧剩余误差在1664维教师空间，不是256维真实ΔP，也不允许随意detach后宣称梯度等价。

前后读出误差`L_s(P^-)-L_s(P^+)`用同一次前向、相同R和目标比较，只作更新诊断。它不能替代实际视频校正收益；也不要求每个内部轮次都严格下降或强制非零修改。

## 6. 低维P的监督强度不能凭“升维成功”判断

固定GT使学生不能通过把目标投影缩成零而获得零损失；但是R和P联合训练仍可能主要拟合共有外观、均值或训练集模板。R不从H／GT／文本另读信息；在P恒定时，线性R只能输出恒定特征，不能恢复不同样本的完整目标。

基准必报：①常量均值预测的误差；②实际学生误差；③按现象和位置划分的过程关系指标；④R的秩／奇异值与P方差；⑤固定checkpoint中P干预对实际输出的影响。跨训练步更换R后，不能把读出误差的下降全部归因于P内容提高。

把M个native GT token排成矩阵X，按通道均值中心化。对不加权MSE和任意学生编码，256维P＋共享线性R的最佳自由重建误差受rank-256近似限制，其下界为：

\[
\frac{1}{M D_T}\sum_{j>256}s_j(X_{centered})^2.
\]

这是假设学生能任意选择编码的容量下界，实际从噪声预测只会更难；大数据可在训练子集上估计谱，不能混入封存测试。高方差保留也不保证低方差的关键接触信息保留，必须同时验证目标关系。若瓶颈确在容量，改宽度／状态表示并重新训练；不添加复杂辅助解码器替学生完成任务。

## 7. ΔH及H+ΔH为什么没有唯一GT，如何训练

H属于给定模型、层、条件与σ的内部表示，许多不同H都可能经后缀产生同样正确的视频。V-JEPA特征与Wan特征即使通道相同，也没有天然坐标同构。用干净GT在σ=0得到的Wan隐藏层去监督带噪σ的H，会同时改变噪声条件；用同一带噪输入的冻结原生Wan隐藏层当“校正GT”，则往往只是要求适配模型复制原生行为。

因此首版**不制造H_GT或ΔH_GT**。定义实际后缀F_{>i}包含剩余Wan层、按既定策略运行的后续corrector和原生输出头：

\[
H_i^+=H_i+\Delta H_i,\qquad
v=F_{>i}(H_i^+,P_i^+;c,\sigma),\qquad
\widehat z_0=z_\sigma-\sigma v.
\]

L_FM在合法GT加噪路径监督v；L_out对解码后的真实端点与GT在固定教师空间比较；L_align对实际端点视频与正确描述评分。这些输出任务的梯度穿过真实后缀到达H_i^+和ΔH_i。忽略其它分支时，局部导数为：

\[
\frac{\partial L_{video}}{\partial\Delta H_i}
=J_{F_{>i}}^\top\frac{\partial L_{video}}{\partial v}.
\]

L_struct位于P^+处，本身不经过本位置writer，不能单独训练ΔH。这是必须保留实际视频任务的原因。共享参数、后续corrector依赖和P缓存会增加其它梯度路径，不能把上述局部公式当全部总梯度。

**输出误差指导残差学习，是明确可实现的监督；当前预测相对不写入是否更好，是另一个必须测量的问题。** 训练误差梯度并不等于每个样本都改善，学习到的更新也不是推理时执行一次有GT的梯度下降。

## 8. 每个corrector都必须做的实际收益检验

冻结同一个checkpoint，固定样本、σ、输入P、H、文本、位置编码、缓存、随机数和后续策略。前缀只计算一次，复制全部必要状态后从同一位置分叉，不能拿不同层的H相减。

| 对照 | 正分支 | 负分支 | 可回答的问题 |
|---|---|---|---|
| 本位置写入作用 | F_{>i}(H_i+ΔH_i,P_i^+) | F_{>i}(H_i,P_i^+) | 在相同更新P下，这次ΔH是否改善实际后缀输出 |
| 整个corrector作用 | F_{>i}(H_i+ΔH_i,P_i^+) | F_{>i}(H_i,P_i^-) | 状态更新与写入合起来是否有益 |
| 后续补偿诊断 | 两分支均保留同一后续corrector策略 | 另做两分支均旁路后续corrector的实验 | 收益是否依赖后续模块补偿；两种后缀问题不同，不能混为一个分数 |
| 跨正常去噪步作用 | 从完整相同前态继续单条有更新后缀 | 相同前态继续无该更新的完整后缀 | 当P影响未来步时，单步结论是否仍成立 |

在合法GT加噪视图上以完全相同的原始误差ℓ计算`gain_i=ℓ_i^-−ℓ_i^+`：正值改善、负值破坏、零值无差异；分别报告FM、输出表征和文本任务，不只给一个可掩盖退化的加权总数。只在可读范围评价输出任务，不能把无效零loss计作胜利。

完整自由采样中未来可能与GT不同，使用任务／物理关系与画质评价，不强行按某条GT像素或token计算gain。基线正确子集的破坏率与全量成功率都保留，按场景给出不确定性。

这个协议增加的是**强制的离线研发验收**，不是每个训练step新增排序loss或生产候选筛选。每个正负对至少需要对应后缀的两次计算；若复用正分支，仍需额外负分支，视频教师也按各分支计算。对m个位置逐一检查会有随m增长的诊断成本，不声称免费得到每层收益。

训练先以A-only监督唯一新增路径，再以M3a固定共同基础只训练B适配，降低联合补偿的混淆。可选M3b须重做逐位置验收；如果某位置长期无益或有害，修改／删除该位置或写入机制，不能靠最终总分给它补发“有效corrector”结论。

不采用默认逐层强制单调loss：中间状态可能需要表示重组，没有额外反事实计算就无从得到可信局部收益；强制每层非零或严格改善还会惩罚合理零更新。若未来研究带反事实的训练，它是另一个明确成本和目标的实验，不能悄悄加入本基准。

## 9. 代码契约与资源变化

每个corrector可返回`P_before, delta_candidate, gate, D_effective, P_after, delta_H, H_after, grid, sigma, active_mask`。直接结构loss读取实际P_after；writer也读取同一张量；日志副本detach，训练路径不detach／不原地覆盖。H与P都是样本激活，不是为每个样本单独登记的参数。

目标端只允许冻结教师＋固定预处理／reshape／索引；保存未经额外L2归一化的native token。预测分支的冻结Wan后缀、VAE和教师必须保留输入梯度。M3a整批B旁路且其它参数冻结时跳过无梯度backward；GT无效位置预先填安全值，`0*NaN`不能用掩码消除。

| 项目 | 原12×12示例 | native 24×24基准 |
|---|---:|---:|
| 16帧视图的P token数 | 1152 | 4608 |
| 单状态P，256通道、2字节 | 0.5625 MiB | 2.25 MiB |
| 单层GT缓存，1664通道、2字节 | 3.65625 MiB | 14.625 MiB |
| P自注意力成对项相对数 | 1 | 16 |
| A-only训练参数 | 7,494,018 | 7,494,018 |
| M3a仅B适配参数 | 1,580,034 | 1,580,034 |
| 可选联合训练参数 | 9,074,052 | 9,074,052 |

参数不变只因位置编码固定、投影宽度与层数未变。上表状态存储不包含多轮反向激活、注意力、Wan、VAE、教师和优化器，不能据此估总显存；实际总耗时也不是恰好16倍。优先小batch／短但覆盖事件的视图、内存高效注意力和受控重算；监督token抽样只能减少读出／loss部分，不会自动减少完整P自注意力。

旧池化缓存无法恢复native GT，必须重新提取或使用保留的原始缓存；旧模型的固定位置／网格配置也须核对。超显存时先明确降低的是视频上下文、网格还是模型宽度并重新验收，不能静默换成弱GT后仍沿用本基准结论。

## 10. 完成顺序与不能提前写成已解决的事项

1. **先实现M0的真实接口。** 正式权重加载、固定视图、native缓存、坐标对应、teacher与VAE领域敏感性，以及完整单项backward／显存检查。
2. **实现并训练A-only。** 先证明P_after拟合固定目标且实际writer能控制必要过程；与同架构FM-only、常量读出、容量基线比较。不得只展示loss曲线。
3. **基础准入后训练M3a。** 保持高σ前缀、只训练B位置适配；全部四项任务可用时继续做逐位置作用／收益检验。
4. **再决定可选项。** 内部多轮、联合M3b、细粒度M4和历史M5都由明确的瓶颈与收益支持，不作为掩盖基础失败的补丁。

本轮解决的是对齐方向、目标信息损失的默认处理、实际监督点、SharedCell输入融合和逐位置归因协议。正式教师是否足够物理敏感、256维容量是否够、固定Wan能否执行目标、能否在指定硬件上训练、完整自由采样是否净改善，仍需真实实验。这些不是可以靠补写公式消除的不确定性，表中已逐项列出失败时应改哪一层原因。

REPA提供了将学生带噪隐藏预测对齐固定干净教师表示的先例；它并不证明当前D的低维P、写入位置、native MSE或物理收益已经成立。[REPA](https://arxiv.org/abs/2410.06940) V-JEPA 2.1提供稠密视频表征及相关任务证据，但不是我们每个corrector校正成功的认证器。[V-JEPA 2.1](https://arxiv.org/abs/2603.14482)
