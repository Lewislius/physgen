## 1. 核心流程

通过可信视频监督，在去噪前期形成并优化可执行的过程状态 P；中期利用主干自然产生的新特征继续修正结构；后期保持过程关系并完善细节。

```text
当前噪声视频 zσ
→ Wan 早层
→ A：形成／优化 P，向早层特征写入一次
→ 原生中间层继续计算
→ B：读取真实 H_B 和细网格，更新 P_next 并写入当前特征
→ 原生剩余层与输出头
→ CFG 合成视频速度
→ scheduler 推进视频 latent
→ P_next 传给下一正常去噪步
```

P 是过程条件与可更新的内部状态。它由首帧、文本、同一次视频噪声及当前特征形成，在 SharedCell 中更新并跨步传递；正式推理不输入未来 GT。

## 2. 模型部件

| 部件 | 职责 |
|---|---|
| 原生 Wan、VAE、文本编码器 | 提供视频生成、视频 latent 和文本条件 |
| 稠密过程状态 P | 保存当前视频的过程关系；时空位置明确，通道不预设物理意义 |
| SharedCell | A／B 共享的小型时空计算主体，处理过程状态与当前观察 |
| 接口 A | 较早层的过程形成／优化与特征写入 |
| 接口 B | 中层的真实观察、结构／细节修正与状态更新 |
| 冻结视频教师 Φ | 从同源 GT 提供可信的过程和输出表征目标，仅用于训练 |
| 小型视频—文本匹配头 | 用可靠正负文本对应校准，训练生成器时冻结，推理时移除 |

不设质量、速度、接触或对象对应的固定语义 slot，不另建物理 DiT、LLM planner、对象账本或轨迹塔。教师的具体模型与层需先做能力审查。

## 3. P 怎样形成、优化和传递

第一次根据可用条件低成本形成 P。前期在 A 的低维状态中进行少量共享更新：

\[
P^{(r+1)}
=P^{(r)}+\eta(\sigma)\,G_P^{(r)}\odot\Delta P^{(r)}.
\]

这里的优化是训练学到的前向更新，推理时不用 GT 反向求解。固定观察上多迭代几轮只增加计算深度，没有得到新的 Wan 观察。

A 向早层写入一次：

\[
H'_A=H_A+\Delta H_A.
\]

Wan 正常计算到 B，产生已经受 A 影响的真实中层特征。B 读取当前特征、P、原生细网格及可选历史观察：

```text
P_next, ΔH_B = SharedCell.correct(H_B, P, fine_context, history_context)
H_B' = H_B + ΔH_B
```

此后只计算尚未执行的原生层。新 P_next 在下一正常去噪步进入 A，不回到本步 A。中后期 A 主要使用已有 P 作为软过程条件。

过程重要性、运动强度和特征修改强度分别评价。门值或残差范数不代表物理正确率，重要但已正确的位置可以少改。

## 4. 四项训练任务

仅使用 WISA／OpenVid 正常视频、描述，以及从这些视频得到的可靠教师目标。总目标至多四项：

\[
L=\lambda_fL_{\rm FM}+\lambda_sL_{\rm struct}
+\lambda_oL_{\rm out}+\lambda_aL_{\rm align}.
\]

| 任务 | 监督对象与用途 |
|---|---|
| L_FM | 正常 GT 加噪路径上的视频向量场，学习画面和动态分布 |
| L_struct | 实际路径的早期／更新后 P，让过程关系有明确表征目标 |
| L_out | 真实写入经后续 Wan 执行后的输出表征，训练修正效果 |
| L_align | 实际视频与描述的角色、动作及过程对应 |

视频 FM 使用：

\[
z_\sigma=(1-\sigma)z_0+\sigma\epsilon,\qquad
v^*=\epsilon-z_0,\qquad
L_{\rm FM}=\mathbb E\|v_c-v^*\|^2.
\]

结构监督使用同一视频的冻结教师目标，并由小投影 R 对齐实际 P：

\[
T=\operatorname{sg}[\mathcal A(\Phi(x))],\qquad
L_{\rm struct}=\sum_r\alpha_r
\frac{\sum_u\rho_u w_u\,d(R(P^{(r)})_u,T_u)}
{\sum_u\rho_u w_u+\varepsilon}.
\]

其中 \(\mathcal A\) 是固定取层与网格对齐操作；\(\rho\) 表示参考可靠性，\(w\) 保留背景底座，\(\alpha_r\) 归一化中间态监督权重。监督权重不能由可学习 gate 控制，未知窗口不伪造标签。

B 写入后经原生输出头得到条件速度 v_c，再形成当前端点估计：

\[
\widehat z_0=z_\sigma-\sigma v_c,\qquad
L_{\rm out}=\mathbb E[\rho w\,
d(\Phi(\widehat x_0^{\rm write}),\operatorname{sg}\Phi(x))].
\]

该端点是当前噪声处的预测，只在教师可读的噪声范围与可信窗口监督；完整采样效果仍需单独验收。冻结教师、VAE 和 Wan 参数时，必须保留生成输入到真实写入的梯度。若 L_out 只是原生 latent 端点 MSE，则等于重新加权的 FM，应删除冗余项。

L_align 先用真实视频—描述对应和核验过的不匹配文本校准小型匹配头，再冻结它监督可读生成结果。不制造错误视频，也不训练全是正标签的“物理正确”分类器。

## 5. 一次训练前向

```text
1. 正常视频 x 经 VAE 得到 z0；冻结教师提取同源目标 T。
2. 采样 σ 和视频噪声 ε，构造 zσ 与 FM 目标。
3. 条件 Wan 正常运行到 A，形成／优化实际 P 并写入 ΔH_A。
4. 原生层继续到 B，读取真实观察，更新 P 并写入 ΔH_B。
5. 原生剩余层与输出头产生 v_c 和当前端点估计。
6. 计算当前里程碑启用的结构、视频、输出和对齐任务。
7. 反向更新 SharedCell、P 形成／更新模块及必要读写投影。
```

首版冻结原生 Wan、VAE 和视频教师，写入从零初始化开始。B 加入时先固定已学好的 A／共享主体，只训练 B 必要投影；确认有收益后再联合训练并检查早期能力退化。

训练先用单个标准 GT 加噪视图。需要模拟跨步状态时，可让较高噪声的合法 GT 视图产生 P 和观察，再传入当前合法视图；这仍不等价于自由采样 rollout，不能给离轨状态继续套用原 FM 标签。

隔离历史预测在此版用于能力诊断：先截取允许的历史再独立编码，未来只进入目标分支；不能先双向编码完整视频再截历史，也不能复用看过未来的 P 或缓存。

## 6. 完整推理流程

```text
输入：首帧 I0、提示词 c、一个 seed

z ← 一次初始视频噪声，施加原生首帧条件
P ← 首帧、文本、同一噪声的低成本初始化
previous_observation ← empty

for 每个正常噪声步 k:
    v_u ← 无条件 Wan 完整前向一次
           # 不读取或更新 P

    在一次有条件 Wan 前向内：
        H_A ← 原生早层正常计算

        前期：SharedCell 在低维 P 中做少量更新
        中后期：读取已有 P
        H_A' ← H_A + ΔH_A

        H_B ← 原生中间层从 H_A' 正常计算
        P_next, ΔH_B ← SharedCell.correct(
            H_B, P, 原生细网格, previous_observation, I0, c, σ_k)
        H_B' ← H_B + ΔH_B

        v_c ← 原生剩余层与输出头正常计算

    v_cfg ← v_u + s(v_c-v_u)
    记录可用观察及其 σ、层位置
    z ← scheduler.step(v_cfg, σ_k, z)
    恢复原生首帧约束
    P ← P_next

输出：VAE 解码同一条最终 z
```

每个正常噪声步两路 Wan 各执行一次，scheduler 推进视频一次；每个原生 block 在每条分支只访问一次。SharedCell 小循环不调用 Wan 或 scheduler，不回早层、不重跑尾部。

## 7. 细粒度修正与反馈

B 优先读取当前 H_B、原生 VAE／DiT 网格及其子网格信息，通过局部重排和小投影保留细节，并共同关注接触双方、原位置、支撑和前后时刻。

前期形成结构，中期仍可调整路径、接触和响应，后期抑制不必要的大范围重构。整段视频 latent 联合生成，因此 B 可以影响视频时间轴上接触前后的关联区域。

当前完整端点只能在输出头之后取得，B 不能提前读取。上一正常步观察是带噪声时效的可选上下文；H_B−H_A 和跨步差值都混有原生计算／去噪变化，不能直接解释为某次写入的纯因果效果。

首版不调用 RAFT，不在每个接口反复解码视频；先检查 GT 的 VAE 重建与教师表征是否保留关键细节。

## 8. 增量实施与验收

| 里程碑 | 增加的内容 | 主要验收 |
|---|---|---|
| M0 | 数据、教师、A/B 包装与基础测试 | 零写入等价、有效梯度、调用计数、状态隔离 |
| M1 | A、实际 P、FM＋结构监督 | P 既能读出过程，又能控制视频 |
| M2 | 前期低维优化；过程对齐另存检查点 | 优化前后是否改善完整过程，分别归因 |
| M3 | B 顺序修正与 L_out | 原失败改善、原正确破坏及视频净收益 |
| M4 | B 的原生细网格和局部上下文 | 接触、轮廓、残留改善，结构不退化 |
| M5 | 可选历史观察与更多小单元迭代 | 等耗时、等主干调用预算下是否值得 |

固定输入和 seed 比较原生、上一里程碑、当前模型及关闭 B 的结果；全部输出进入统计。联合训练后的开关消融可能带来分布变化，还需固定早期模块的 B 增量训练对照。

独立验收覆盖完整任务执行、角色、接触、数量／身份、形变、画质、改善率、破坏率与成本。教师分数、attention 图或小门控不能独立证明修正有效。

自然视频不提供精确力学或严格干预真值；单帧可能对应多种合法未来，不能用静止和平均化冒充正确。固定预算下对严重错误的恢复能力仍有限，正式推理不通过候选筛选、重启或额外主干重算隐藏失败。
