# 原生 P 蒸馏与写回流程：当前 A1 简明说明

对应 2026-09-12 的 v4 实际代码。默认 1000 条训练样本，200 条验证样本；A1 500 步，后续 A2／A3／B1／AB 各 250 步。A1 使用 FM＋L_struct＋小权重 L_prior，B 和 L_out 不启用。

**目标：训练时借助 GT 视频和冻结 V-JEPA 教师学习整段高层表征；推理时只凭文本、首帧预测初始 P，再结合 Wan 当前特征更新 P、产生 ΔH。** P 是模型预测，不是已知的物理真值，效果仍需生成对照验证。

## 1. 训练有 GT，推理没有 GT

| 路径 | 训练 | 推理 |
|---|---|---|
| P₀ 初始化器 | 75%：文字＋首帧＋干净 GT 视频 latent；25%：去掉 GT 视频条件；始终有输出时空规格 | 文字＋用户首帧＋输出时空规格 |
| Wan 输入 | GT 视频 latent 加噪，首帧槽固定 | 首帧槽固定，未来采样 latent 从高斯噪声开始 |
| 教师 T | GT 经冻结 V-JEPA 编码，只用于损失 | 不运行教师，不读取目标特征 |

同一个初始化器按上述概率接收或不接收 GT 视频条件，每个样本只生成一次 P₀，两种情况都用 JEPA 特征监督。无 GT 的训练路径与推理可用输入一致；没有第二个初始化器或两份 P₀ 之间的蒸馏。详细输入、梯度与验证见 [GT 初始化说明](../../v4/evaluation/GT_CONDITION_PRIOR.md)。

## 2. P₀ 预测整段，不填充随机未来位置

```text
文本 [1,L,4096] → 初始化器独立文本投影 → LN／投影 ──┐
首帧 [1,48,1,h,w] → 图像 tokens＋位置 ───────┤
可选 GT latent → 保留时间、空间池化最多8×8 ──┤ 所有查询共同的 K/V
                                            ↓
整段时空位置＋可训练 query → 两层条件预测网络
                                            ↓
                              P₀ [1,4608,1664]
```

以 101 帧、512×288、16 帧教师视图为例，P 为 8×24×24 个 token，首帧图像为 18×32 个 VAE token。初始化器内部宽度 512、8 头，两层全局自注意力／条件交叉注意力；输出用非线性原生宽度头得到 1664 通道 FP32 P。

每个时间位置都读取完整文本与首帧，有 GT 条件时也读取当前片段全部 GT 池化 tokens；query 是训练后的模型参数，不是每次新采样的随机视频块。相同条件与输出规格在确定性模式下得到相同 P₀。位置覆盖完整与物理预测准确是两回事，条件未确定的速度、时刻和轨迹仍有不确定性。

## 3. 每五层一套独立 corrector，同一 block 跨去噪步复用

```text
P₀ → A@5 → A@10 → A@15 → A@20 → A@25 → A@30 → 下一去噪步
      ↑       ↑       ↑       ↑       ↑       ↑
     H₅      H₁₀     H₁₅     H₂₀     H₂₅     H₃₀
```

A@5、A@10、A@15、A@20、A@25、A@30 各有完整独立的 Read、Writer、归一化、gate、条件投影、两层 StateCore 和两路 P/H attention。P₀ 初始化器与可选 B@18 也有独立参数。固定深度编码保留；参数独立由六个分别构造的模块保证。每次先读取当前 H，再更新 P，最后由提交后的 P 产生 ΔH。前向只更新 P/H；反向分别累积梯度，优化器统一更新各自参数。**同一去噪 step 的不同 block 不共享；同一 block 在不同去噪 step 复用自己的参数。**

```text
H [1,3744,3072] → LN＋Read(3072→1664) → U [1,3744,1664]
P 查询 U：CrossAttention(Q=P, K=U, V=U) → R [1,4608,1664]
observation = gate_read × R
Z = P + observation + 时空位置 + sigma条件 + A/B类型 + Wan深度
  → 当前位置两层 1664 维 StateCore（全局 self-attention＋文本 cross-attention）
P_next = P + eta × gate_state × delta
U 查询 P_next：CrossAttention(Q=U, K=P_next, V=P_next) → S [1,3744,1664]
S → LN＋gate_write＋writer(1664→3072) → ΔH [1,3744,3072]
H_next = H + ΔH
```

上图省略了注意力前的 LN 与 Q/K 位置／条件编码。两路注意力均为1664维、26头全局非因果形式，不同 block 和 A/B 各自独立，只在所属位置的内部迭代和不同去噪 step 间复用；H/P 不拼接，读写均无需时空插值。写回的 K/V 剔除外层教师补黑的全黑位置，常见视图有2688个有效 P token；完整 P 仍为4608个 token。H 只查询 P，不另向 S 添加 H 内容残差。

observation 是每次从当前 H 选择性读取的临时信息；P 是接续保存的学生状态。gate_read 初始约0.119。H 不负责初始化 P，但后续可以让条件先验适应这次生成的具体位置和运动。A2 的第二轮以更新后的 P 重新查询同一 U。交叉注意力取消的是固定插值融合，残差加法和真实时间／空间编码仍保留；优势是内容选择灵活，代价是更多参数和计算。

A1 每次调用内部更新一轮。后续 B1／AB 额外在第 18 层加入完整独立 B corrector（B_core＋适配器），sigma≥0.65 时旁路；默认 A1 没有 B 调用。B1 冻结 P₀ 和全部六套 A，训练 B_core 与 B 适配器；A1 尚未训练的 B_core 不会在 B1 被错误冻结。独立参数增加权重、梯度、Adam 状态和通信量，每个 step 的六次调用数量保持不变。

## 4. 损失与初始化梯度

| 损失 | 当前计算 | 用途 |
|---|---|---|
| L_FM | Wan 向量场对 noise−clean 的 MSE，排除首帧 | 训练真实写回及去噪 |
| L_struct | 各调用提交 P 与原生教师 T 的内容加权 MSE | 稠密表征监督；先类型内平均，再平均 A/B 类型 |
| L_prior | 初始 P₀、T 按每个时间槽分别空间池化后的 MSE | 小权重明确训练整段条件先验，保留时间顺序 |

默认总损失为 `FM + 0.1*w*clip((1−sigma)/0.2,0,1)*struct + 0.02*w*prior`，w 为前 200 步的渐增权重。L_prior 不乘 sigma 衰减，设 prior_weight=0 可消融。当前没有 L_out 的在线解码／教师前向。

**不加 L_prior，初始化器也能更新。** 非暖起视图的结构损失可以通过 P_next→P₀ 回传；writer 学开后，FM 也可以通过真实 Wan 后缀训练初始化器。零 writer 在最初使纯 FM 对初始化器的梯度为零，但结构监督仍有梯度。额外 L_prior 的目的，是让 P₀ 自身承担粗时序预测任务，减少只依赖后续 H 的可能，并不保证每个空间 token 都已足够准确。

默认 `state_warmup_every: 0`，每个训练样本一次 Wan 前向。显式开启暖起时，同一视频先后构造两个合法加噪视图，前一次的 P detach 后交给后一次；P₀ 只生成一次并保留 L_prior 梯度，关闭 L_prior 时暖起不更新初始化组。它训练接收更新过的 P，但不是实际 scheduler 采样展开，不能证明长程连续性收益。换视频重新初始化，推理同一视频的多个去噪步才接续 P。

## 5. 早期写回与推理

高噪声写回乘 `0.1+0.9*clip((1−sigma)/0.1,0,1)`，让极高噪声时少写、P 仍可更新；early_write_width=0 可消融。该门不是正确性概率，也不是 ΔH/H 的上界。零 writer 只保护训练初始化，训练后的生成效果必须实测。

CFG 正向／负向分支使用自己的文本初始化和接续 P；首帧条件始终保留。默认 50 步时，每个 CFG 分支有 300 次 A 状态更新。教师不参与推理，参数不在推理中更新。

当前配置为 `parameter_sharing: per_block`、`a_blocks: [5,10,15,20,25,30]`。旧 checkpoint 缺少 parameter_sharing 时按 shared 恢复；要转为独立参数须用当前配置新训，或用 A／AB 的 INIT_FROM 将旧权重分别复制给各 block，数值相同但存储与梯度独立，优化器重新创建。仅拆分时不清零 writer。旧 checkpoint 的 RESUME／推理按保存的初始化、fusion、参数归属和调用位置执行，缺少 fusion 时仍用插值加法。INIT_FROM 加法旧权重到当前 cross_attention 架构，只迁移兼容权重、新建两路注意力和读取门，并将 A/B writer 与 B.b 归零；若还需替换旧先验则同时处理。迁移须在 A／AB 阶段训练新增网络，不能直接进入冻结六套 A 的 B1。已有数据缓存可复用。旧 image_text → image_text_gt 同样通过 A／AB 的 INIT_FROM，仅新增 GT 输入层，保留原先验与 writer；旧 RESUME 不会自动切换初始化方式。

当前 A 阶段可训练 837,957,970 个参数，B 为 136,224,516，AB／模型总参数为 974,182,486。corrector 在每卡完整复制，A 阶段权重＋梯度＋Adam 状态静态预算约 12.99 GiB，尚未计入 Wan／激活／通信。独立性、梯度和 checkpoint 的检查见 [验证说明](../../v4/evaluation/INDEPENDENT_CORRECTORS.md)，不代表已验证 GPU 峰值或生成收益。
