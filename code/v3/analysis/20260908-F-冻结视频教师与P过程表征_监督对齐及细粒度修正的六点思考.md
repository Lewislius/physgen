## 1. 冻结的视频 teacher 到底是什么

### 1.1 当前文档尚未落实具体 teacher

现有文档中的 Φ 是待选定的视频编码器，没有确定具体 checkpoint、提取层、取帧方式与特征网格。因此，当前 L_struct 还不能直接被称为已经可用的“物理结构监督”。

“冻结”仅表示生成器训练时不更新 teacher 的参数，不表示它的输出天然正确，也不表示该表征能够覆盖所有物理现象。

### 1.2 建议优先测试的候选

优先测试 **V-JEPA 2.1 的稠密视频编码器**，先使用官方 ViT-B/16，必要时对比 ViT-L/16。该模型针对局部空间结构和时序一致的稠密特征进行了改进，并公开了对应权重，适合作为过程表征教师的候选，而不是只取一个全局视频分类向量。[官方模型与权重](https://github.com/facebookresearch/vjepa2#models)、[V-JEPA 2.1 论文](https://arxiv.org/abs/2603.14482)

这里说的是“优先测试的候选”，不是“我们已经采用并验证了它”。首轮需明确记录：checkpoint、特征层、输入帧率与窗口、分辨率、时间／空间压缩，以及教师目标缓存的版本。

### 1.3 它提供什么，不提供什么

- 提供：带有空间和时间位置的视频特征，可用于学习局部内容、运动及跨帧关系。
- 不直接提供：真实质量、力、精确接触标签、三维非穿透约束或因果图。
- 不天然提供：与当前文本编码器一致的语义空间。
- 不保证：能够分辨“差一点碰到”与“真正碰到”，或者可靠识别重复物体和异常形变。

因此，teacher 的能力测试应先于大规模训练。需要检查其特征或轻量读出是否能够分辨运动角色、交互前后、身份连续性、局部边界和形变，并避免只靠物体类别完成判断。

**如果 teacher 看不见目标错误，学生对齐得再好，也没有获得对应的监督信息。** 更换名称、增大权重或增加循环次数，都不能补出目标中不存在的信息。

## 2. P 究竟如何得到，它与 teacher 是什么关系

### 2.1 P 是学生自己产生的过程状态

P 不是 teacher 输出的另一个名字，也不是训练时直接复制 GT 得到的状态。它由学生模型根据当前可用信息产生，用于当前这一条视频的生成。

可以采用如下组织形式：

\[
P\in\mathbb R^{B\times T_p\times H_p\times W_p\times d_p}.
\]

其中，B 是批大小，T_p、H_p、W_p 是时空网格大小，d_p 是通道维度。具体大小尚未定型，需要结合表示能力和计算预算验证。

网格位置对应哪里、何时；通道采用分布式表示，不人为设置“质量 slot”“接触 slot”“球 1 slot”等清单，也不把整个视频压缩为一个没有位置结构的向量。

### 2.2 初始化、形成、修订与传递

第一步，低成本初始化：

```text
首帧特征 + 文本特征 + 同一次初始噪声的压缩信息 + 时空位置
    → 小型可训练融合模块
    → P_init
```

首帧提供初始布局与身份线索，文本提供任务与角色条件，噪声保留不同合法生成过程的可能性，位置编码建立时空索引。这一步本身并不会凭空产生物理知识。

第二步，接口 A 形成与优化：

```text
当前真实早层特征 H_A + 已有 P + 条件信息
    → SharedCell 的少量低维更新
    → 更新后的 P
    → 向当前 Wan 特征写入一次
```

第三步，接口 B 顺序修订：

```text
A 写入后自然计算得到的 H_B + P + 原生细网格信息
    → 同一共享更新主体
    → P_next 与当前特征修改
```

第四步，跨正常噪声步传递：本步继续运行尚未执行的后续层；P_next 交给下一正常去噪步，而不是触发本步早层重算。

这些是当前方案的计算关系。初始化网络的具体层数、网格宽度、读取位置和更新轮数，仍需在 v4 原型中确定。

### 2.3 长期知识与当前状态必须区分

跨视频的过程知识主要学在 SharedCell、初始化和读写投影等模型参数中；P 是这些知识结合当前输入后形成的单视频状态。

P 期望包含当前视频中的运动角色、交互前提、路径、前后响应和身份连续性，但这些是需要训练与验证的能力，不是已经被证明存在的语义。

P 也可能错误。因此不能将“P 表示期望过程”进一步推成“P 永远正确，当前视觉特征与 P 不同就一定是视觉特征错了”。

## 3. P 与 GT 经 teacher 后的内容如何对齐

### 3.1 两条路径不同，也不天然具有相同语义

当前设计属于学生—教师表征蒸馏：

```text
教师侧：
GT 视频 x → 冻结视频编码器 Φ → 时间／网格对齐 → 目标 T

学生侧：
GT 的标准加噪 latent + 首帧／文本
    → Wan 早层 → SharedCell → 实际 P → 小投影 R → R(P)

监督：比较对应时空位置上的 R(P) 与 T
```

教师侧看到了清晰的视频，学生侧从当前条件和带噪观察中预测相关信息。两边不需要使用相同网络；需要建立的是可学习、可验证的信息对应，而不是假设它们本来就是同一个东西。

### 3.2 对齐需要满足三个条件

**位置对应。** 保持实际时间戳、裁剪、区域和尺度的对应。不同 VAE／teacher 的时间压缩和首帧处理可能不同，不能只把 token 数插值成一样，就认为事件时间已经一致。

**通道对应。** 学生投影 R 将 P 映射到教师目标空间。R 应尽量简单，不允许绕过 P，直接从 GT、清晰完整视频特征或其他强分支重建目标。

**信息对应。** 教师目标必须包含任务需要的动态或交互信息。尺寸一致、余弦相似度高，不等于已经对齐了物理语义。

一个基本写法是：

\[
T=\operatorname{sg}\!\left[A_{\mathrm{align}}(\Phi(x))\right],
\]

\[
\mathcal L_{\mathrm{struct}}
=\frac{\sum_u\rho_u w_u\,d\bigl(R(P)_u,T_u\bigr)}
{\sum_u\rho_u w_u+\varepsilon}.
\]

A_align 表示固定的目标取层与时空对齐操作，不是写入接口 A；u 是网格索引，不是语义 slot。rho 是参考可靠性，w 是保留背景底座的学习权重。二者不能由可学习门控自行缩小，否则模型可能通过降低监督权重逃避误差。

### 3.3 表征蒸馏不自动等于物理知识蒸馏

L_struct 可以促使 P 保留 teacher 可读出的信息，但不能自动把通用视频特征变成物理因果表征。

VideoREPA 在其 CogVideoX 微调实验中报告过直接特征对齐导致语义质量与整体连贯性下降，并采用时空 token 关系蒸馏缓解该问题。我们的新增 P 与直接对齐已有主干特征并不完全相同，但仍需检查表征空间不匹配和语义退化风险。[VideoREPA](https://arxiv.org/html/2505.23656)

因此，当前更准确的定位是“过程表征蒸馏”，不是已经成立的“物理结构真值监督”。直接特征对齐与关系对齐可以作为候选进行对照，不默认同时叠加多个目标。

## 4. L_out 是什么，为什么还需要它

### 4.1 它本质上是输出端监督

当前流程为：

\[
H'_B
\rightarrow \text{剩余 Wan 层}
\rightarrow v_\theta
\rightarrow \hat z_0=z_\sigma-\sigma v_\theta
\rightarrow \hat x_0
\rightarrow \mathcal L_{\mathrm{out}}.
\]

这里的 v_theta 是原生生成向量场，不是物体的真实运动速度。hat x_0 来自当前训练前向的干净端点估计，不是完成全部去噪后的最终视频。

不为这个损失额外生成整条视频，也不重跑完整 Wan；训练只在经过校准、端点可读的噪声范围计算相应监督。

### 4.2 “P 很好但生成没有执行”是什么意思

例如，P 的读出已经能够表达“红球接近蓝球，碰撞后蓝球运动”，但特征写入方式无效，实际视频中仍然没有碰撞。

只监督 P，可能得到一个很好的辅助表示，却没有训练好如何把它转化成有效的生成控制。

L_out 检查的是：**corrector 修改特征后，经过后续 Wan 得到的输出预测是否更接近可信目标。** 误差通过实际执行路径反向传给 corrector，训练修改方向、门控和写入投影。

```text
可信目标与输出预测之间的误差
    → 冻结教师对生成输入的梯度
    → 可微解码／后续 Wan／原生输出头
    → 实际特征写入
    → corrector 与相关可训练参数
```

直观地说，不仅检查“计划是否正确”，还检查“执行是否有效”。但这里 P 并非独立 planner，而是实际参与生成的内部状态。

### 4.3 L_out 的价值取决于它能分辨什么

- 普通外观特征距离，主要仍是输出相似性监督。
- 如果只是原生 latent 的端点 MSE，它与标准路径上的 FM 仅差噪声权重，不应包装成新的物理监督。
- 只有目标度量对动态、交互、身份和细节确实敏感，才有额外的过程监督价值。

**损失位于输出端不是问题；问题是其监督内容。** 可靠的输出端交互监督也可以训练内部过程能力，而内部 latent 上的通用视觉对齐也可能主要学到外观。

冻结教师参数不等于对生成分支使用 no_grad。目标 GT 可以停止梯度，但预测分支必须保留输入梯度。

### 4.4 它仍不能保证每次修改都正确

L_out 训练“修改后应接近什么”，没有提供现成的正确残差标签，也不保证每轮修改单调改善。

单步端点改善还不能代替完整视频验收。需要在部署 CFG 和正常采样协议下，离线比较启用／关闭 corrector 以及上一模型检查点，完整统计改善与破坏，而不是正式推理时生成多条再择优。

## 5. 怎样让 P 不只是保存一些视觉特征

### 5.1 先保留表达过程所需的信息结构

优先压缩通道、适度压缩空间，不将整个时间轴平均成几个固定阶段。接触双方、原位置、支撑物和后续响应需要共同参与更新。

同时，不要求所有像素级细节都挤进 P：**P 保存过程关系，原生细网格提供局部证据，二者交互。** 是否“保存足够”，需要由任务表现决定，不能只看通道数或参数量。

### 5.2 建议增加真正需要预测过程的训练视图

目前从整段带噪视频对齐整段 GT，可以训练去噪与识别，但不能独立证明模型知道前因怎样产生后果。

建议研究同一 L_struct 表征预测任务下的历史／关键转移预测视图：

- 输入只允许看到历史片段及允许使用的文本条件；
- 共享更新单元根据这些条件预测后续区域的教师表征；
- 未来视频内容只能进入目标分支；
- 输入侧必须在编码之前隔离未来，不能先双向编码完整视频，再遮掉未来 token。

为避免增加完整 Wan 重算，可以先由同一轻量单元处理历史侧输入，复用过程更新参数与小投影，而不增加独立动力学大模型。历史侧编码也需检查时间感受野，不得从完整视频缓存中取出已经混入未来的“历史特征”。

这一训练视图不需要错误视频库，也不是恢复 x_err；它改变的是可见信息，不是制造必须配对修复的物理错误视频。

### 5.3 必须承认辅助预测的边界

上述视图仍是辅助能力训练，不等于真实生成路径本身已经学会因果推理。共享参数也不自动保证知识被主路径使用，因此不能删除实际生成路径上的 P 监督、写入训练和控制实验。

首帧或短历史也未必能确定唯一未来。对条件不充分的样本，不能把某一个 GT 的精确轨迹强制当作唯一答案，导致平均化、运动变小或多样性丢失。

预测任务、时空关系蒸馏以及普通特征蒸馏的取舍需要实验决定；不应把多种独立任务全部藏进一个 L_struct 名字里。本建议优先复用同一表征预测目标与不同可见输入视图，不另起第五项生成器主损失。

### 5.4 P 的物理信息需要三类证据共同支持

1. **信息有效：** P 能读出或预测需要的过程关系，而非只识别物体类别。
2. **控制有效：** 对 P 中相关信息作适当改变，视频中的相应行为按预期变化，而非仅随机打乱后崩坏。
3. **结果有效：** 完整视频的任务执行和物理关系改善，且不是靠更多计算或静止规避任务。

即使上述证据成立，从自然视频监督中学到过程预测与符合观测的逻辑，也不等同于识别了严格、可干预的物理因果机制。不能据此宣称模型掌握了全部真实物理定律。

## 6. 细粒度修正必须同时补齐信息入口与有效监督

### 6.1 只有“读取细网格”不够

细网格提供修改的可能性，不直接告诉模型哪里错、怎样改或多大修改才正确。需要同时设计读取、写入和监督三条对应关系。

### 6.2 最小读取与写入实现

读取端：B 同时读取当前中层特征 H_B、未经额外平均的原生 latent 局部网格以及 P。通过局部时空注意力联合观察接触双方和前后时刻，而不是只读取一个池化后的物体向量。

写入端：把局部更新按位置写回当前 H_B，由尚未执行的原生层处理。不只将粗 P 插值放大后称作细节修正，不回到已执行的早层。

这些能力由现有共享单元与必要读写投影承担，不默认新增视觉、轨迹、运动、物理等多套独立分支。

### 6.3 将 L_out 落到关键时空窗口

建议将单一全局视频距离，改为同一表征距离下的全段与局部时空窗口采样，重点覆盖：

- 接触双方，以及接触前、接触中和接触后；
- 物体的新位置与原位置；
- 支撑、轮廓和可能形变的区域；
- 全域随机窗口，避免只关注 GT 前景而遗漏背景中的异常复制。

GT 与预测使用相同的时间窗口及裁剪对应，保留必要上下文。它仍是一类输出表征任务，不为每个现象增加一项独立损失。

重要性和错误性必须分开：重要但已经正确的区域不应被强制大改；已经离开原位置的物体，其原位置也可能是关键监督区域。可靠性权重不能由可学习更新门自行控制。

如果 teacher 本身看不见小间隙或身份差异，裁剪与加权仍然不够，必须更换或补强目标表征。原始 GT 的 VAE 往返也必须能保留目标细节；编码阶段已经丢失的信息，不能靠宣称“细粒度读取”解决。

### 6.4 逐项问题的真实约束强度

| 问题 | 当前缺口 | 必要补强与边界 |
|---|---|---|
| 数量／复制 | 通用语义特征可能把两本相同的书看成同类 | 需要对身份、来源去向和旧位置敏感的监督；当前不能宣称具有显式数量守恒约束 |
| 背景变化 | 只监督移动主体会遗漏原位置与场景异常 | 保留全场景与背景监督；不能把镜头运动、遮挡变化或合法环境变化强制冻结 |
| 穿模／接触 | 2D 投影重叠不等于真实 3D 穿透 | 使用可信的可见接触证据；普通视频特征不是严格非穿透约束 |
| 形变 | 外观距离不能自动区分合理变形与结构崩坏 | 教师与数据需要覆盖合理形变，不能统一惩罚所有形状变化 |
| 因果顺序 | 只检查最终动作出现，可能遗漏错误前因 | 前置条件与后果必须共同监督；时间先后本身仍不等于严格因果证明 |

因此，当前方案没有这些问题的完备显式约束；有的是可能帮助它们改善的软监督路径，需要逐项验证覆盖能力。不能把一个教师特征距离宣称为同时解决数量、因果、穿模和形变的通用物理约束。

### 6.5 本轮六点思考的收敛判断

最优先的工作不是继续增加 corrector 轮数，而是验证：选定的 teacher 与训练任务，是否真的让 P 学到需要的过程信息，以及这些信息能否控制生成。

只有在“参考可用 → P 学到信息 → 写入能生效 → 细粒度输出出现净改善”的证据链逐步成立后，多轮更新才有清晰的作用基础。否则，多轮读写可能只是在反复处理一个缺乏物理依据的状态。
