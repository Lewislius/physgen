R19CT 整体重构：请求对齐的物理内容、当前视频状态专家、原生特征执行
日期：2026-11-14。替代已撤下的 native-activation-v3，不续训其41步。
本文件描述实现与设计依据。未完成本版生成评测之前，不声称画面/PC/SA/Joint已提升。

一、这次具体要改变的能力
此前C主要是请求侧静态内容；每个视频位置查询C后即向视频写入。读取状态不同，
并不代表C已经理解当前帧的局部状态及跨帧关系。此次改成完整闭环：
原始请求与Qwen条件 → 两个内容专家形成C → C读取当前视频 → 帧内关系/跨帧状态处理
→ 返回对应视频位置 → 在实际原生FFN中形成生成特征。
这是内容形成、视频反馈、时序处理和执行的共同重构；FFN接口只是末端。

三、完整设计和张量含义
1. 内容层
   保留本地冻结Qwen3-VL对request-only reasoning的4096维编码与256个learnable Q。
   物理内容专家包含对reasoning的交叉读取、对请求语义的交叉读取、Q间交互和全宽FFN，
   迭代两轮。语义专家对原始T5请求token进行独立自注意力和FFN增强，不改原生文本通路。
   路由C的初始值取自原始请求的native T5/Wan表示，查询由物理词的同一原生坐标形成；
   不使用随机Qwen/T5点积来假装初始对齐。路由与执行均有独立可学习全宽修正。
   C_route = 对原始请求的语义读取 + 学习到的路由修正。
   C_execute = 原生物理词表示 + 学习到的执行修正。
   执行C保留完整物理信息，防止语义协调变成把物理内容稀释掉。它随后必须经过当前视频
   状态专家处理，没有原始C直接叠加到视频的支路。错误reasoning仍是输入风险，模型并非
   事实校验器；上述设计提供语义和视频条件下的处理能力，不宣称自动消除全部错误。

2. 每个注入层的当前视频读取
   原生视频self-attention → 原生冻结文本cross-attention，得到h_text。
   独立可训练物理Q/K读取h_text和C_route，形成逐帧、逐位置、逐物理槽的兼容分数A。
   用A转置并在视频位置上归一化，使每个C槽读取该帧相关视频内容；得到[B,T,256,3072]。
   值投影是共享全宽可训练V，初始化为恒等。避免各层把状态旋转进互不一致的V坐标后，
   再交给同一个状态专家处理。这里读取的是当前带噪生成状态，不是真实未来帧。

3. 全宽物理状态专家
   当前视频槽先以C_route/C_execute作条件cross-attention，再进行帧内槽关系attention、
   同一槽的跨帧attention、完整3072→14336→3072 FFN。它处理变形、流动、出现/消失等
   一般可见过程；不要求刚体、固定对象、轨迹、光流或接触标签。
   attention/FFN从官方Wan第14层复制初始化，参数独立训练，绝不从历史项目权重继承。
   使用实际注入层的原生去噪时间scale/shift/gate，另学全宽时间修正；不是按噪声阈值
   开关物理分支。跨帧RoPE只旋转物理头的时间部分，使用视频展示时间，不给learnable Q
   虚构像素坐标；展示时间与扩散噪声时间明确分开。
   全部注入层共享状态专家，提高400步内参数利用率；逐层Q/K和执行输出各自可训练。
   专家只更新本次去噪计算的内部状态，不额外预测未来轨迹，不做独立未来rollout。

4. 回写和生成执行
   A在物理槽方向归一化，包含每关系槽数先验及零值选项，读取增强后的当前物理状态。
   读写共用兼容场，使读取位置和返回位置有明确对应；关系attention允许不同条件槽之间
   交换作用。它不保证学到正确因果对象，故需要实际模块配对，而不能以公式作为效果证明。
   保留读取幅度，不把弱物理读取经最终LayerNorm重新放大成等强写入。
   原生FFN中：a = Wan_FFN_in(native_normalized_h_text)；
              a_conditioned = a + O_physics(逐位置物理状态)；
              h_out = h_text + native_time_gate * Wan_FFN_out(GELU(a_conditioned))。
   O_physics是3072→14336全宽映射，零初始化。完整分支初始输出为0；后续由真实视频
   生成目标学习。没有独立视频解码输出基底，没有GELU之后无约束的特征符号翻转乘法。
   原生文本Q/K/V/O冻结，同层只查询一次；后续层/采样步仍会看到联合更新后的状态。
   初始等价仅保证起点，不等于训练后画面保证。没有删除物理Q，也没有以缩小物理强度代替学习。

四、400步训练与数据
原始T2V1600样本顺序、噪声、条件drop、有效batch4不变；官方基础权重初始化，全程联合400。
新语义/物理内容专家、状态专家、物理Q/K/V/输出和原有video self-attn/FFN LoRA参与训练；
原生文本不改。无新增损失或额外训练阶段：0.8平均FM + 0.2多尺度高误差区域项。
FM是去噪空间目标，不把数值下降解释成视频物理改善，也不把FM速度当成视频运动速度。
不增加刚体/守恒/材料类别约束、相邻帧差分、RGB变化项、VJEPA或评测模型反馈。
原始提示词、T5文本、已有Qwen特征和目标视频缓存不变；8条API试修仅为诊断，不参与训练/评测。
完整模型GPU检查使用4次可丢弃更新验证梯度/显存；不保存其权重，正式400另起进程从头训练。

五、验收和评测
实际画面、主体结构与物理过程优先；与固定同协议40及完整60历史版本比较SA/PC/Joint。
目标仍为PC≥3.85并争取3.9，SA≥3.25，Joint≥13/40，并改善60例；不允许用黑画面、静止或
极度形变换物理分。全部主评测视频都检查，并对重点失败例查看时间过程而非只看一个截图。
固定16对照：关闭C、关闭语义内容专家、关闭当前视频反馈、关闭跨帧处理、无关/空reasoning、
固定训练均值C。它们是同权重推理干预，不能替代独立重训的因果消融；先核实新增功能有贡献。
此轮T2V不扩展WMB/Physics-IQ。I2V的EI需基于自身实测单独定稿，不能照搬本版。
只提交blk-96g单张实际RTX6000；H100在模型加载前退出；保持30分钟常规检查。

六、方法背景与证据边界
Perceiver IO的读取—潜空间处理—查询输出提供规模可行的结构参考：
https://arxiv.org/abs/2107.14795
CogVideoX展示不同模态的专门处理及去噪条件化深层融合的价值；并不意味着必须做MoE：
https://arxiv.org/abs/2408.06072
ProPhy强调语义物理先验和细粒度视频条件配合；其训练数据、标签及模型设置与此处不同，
不能拿论文提升比例替代本版结果，也不照搬依赖领域类别标签的专家路由：
https://arxiv.org/abs/2512.05564
这些工作支撑结构选择，本文的具体有效性仍由本地真实视频、40/60及配对结果确定。
