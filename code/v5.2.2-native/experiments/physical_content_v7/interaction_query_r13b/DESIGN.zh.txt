R13B：物理条件控制原生时空读取，保留直接物理写入

设计决定依据
R13A完整400步、40/60例和六组固定16已全部完成并被拒绝：40为SA2.925/PC3.475/Joint9，60为2.866667/3.550/11。它把R10A独立物理写入换成FFN输入scale/shift，没有解决整体质量问题。
R13A固定16仅scale为SA3.3125/PC3.5625/Joint5，仅shift为3.125/3.8125/5，两项一起3.125/3.750/6；正常与训练均值C的SA全部相同，正常PC略低而Joint多010一例。部分SA加分的视频反而出现车轮消失、蛋异常跳动和绳索破碎。不能靠删掉一项、固定均值或恢复更多运动宣布成功。
R10A原400的独立补测：关闭额外state_value乘法后，SA3.0625/PC3.9375/Joint5；原正常3.0625/3.875/4。相对关闭全部C，保留的直接C写入仍PC+.3125、SA-.1875。这证明直接写入有局部价值和副作用，额外乘法没有净SA收益；它不证明删除该项就已修复完整40。
WMB70与Physics-IQ20场景/60视角补测进一步显示，高物理评分可以伴随请求遗漏；R10A的Physics-IQ Verified .236692低于R1 .265103和Wan+LoRA .260036。该证据在本版设计前已经完成，原始评分/视频保留。

实现
保留原R10A Qwen→Q→C增强、C_route/C_execute及原生词路由辅助；ContentBlock、Enhancement与map_content保持原实现。保留原版WISA缓存、原版reasoning和已拟合接口。每第三个Wan block仍设置一处物理融合，总计10处。

1. 在当前block的原生视频self-attention前，用当前视频状态读取同一物理C，得到逐位置消息M。原生视频查询改为：
   q_raw = Wan.self_attn.q(native_input)
   q = native_norm_q(q_raw * (1 + W_interaction M))
   attention = Attn(RoPE(q), RoPE(k_native), v_native)
   output = native_o(attention)
   只有未来位置得到新增查询调节。K/V保留原生视频特征；现有LoRA是否更新仍由训练阶段决定。原生Q/K归一化、真实视频时空RoPE、原生输出投影与去噪时间门均保留。没有给物理Q槽硬编造视频坐标。

2. 在self-attention后，以原R10A的文本前视频状态再次读取同一C，保留直接写入W_output M；它与原生文本更新相加，再进入原生FFN。原来W_output(M + W_state(state)*M)中的额外state乘法移除，原矩阵预算改作W_interaction。前后两次读取共享物理K/V、时间查询和参考槽参数，但各自使用当前状态。不是独立请求生成分支，也不池化未来视频成额外状态预测器。

该结构将一部分物理作用明确放在“读取哪些原生视频信息”上，同时保留已观察到有效的直接C写入。旧残差也能通过后续层间接影响注意力，因此不能说旧模型完全没有时空交互；这里改变的是物理控制的作用位置和职责。条件化查询仍可能学习错误读取关系，直接写入仍可能干扰SA，最终有效性必须由生成和对照决定。

初始化与训练
从官方Wan/Qwen基础权重全新开始，不载入旧实验权重或优化器。W_output与W_interaction均零初始化；新W_interaction替换原W_state，保持R10A参数/优化器分组预算与初始化抽样顺序。原生文本cross-attention Q/K/V/O不开放。
本次为可比实验继续选择128+272，共400步、accumulation4、1600次样本曝光。128+272是本次选择，不是不可变的Goal约束。
第1—128步：冻结全部Wan及原LoRA，更新物理增强和两种物理执行作用；第129—400步：物理模块与原self-attention/FFN LoRA联合更新。真实训练中两条物理作用始终启用，每样本一次完整生成前向/反向。
两阶段损失均为0.8平均FM+0.2多尺度高误差聚合+路由C原生词对齐。路由辅助前32步升到0.03并保持至400；不约束执行C。不增加判别器、奖励、JEPA、光流、轨迹、RGB变化目标或新标签。局部高误差项只是减轻平均稀释，不是完整物理损失。FM标量不作为质量达标证据。

评测使用相同首帧、提示词、噪声、50步采样、gamma5。主任务默认完成40+额外20合并60，并完成固定16的全部关闭、交互关闭、直接写入关闭、无关reasoning、空reasoning、训练均值C六组对照。关闭是检查/推理消融，真实训练不关闭支路。推理消融不冒充从头重训消融。
