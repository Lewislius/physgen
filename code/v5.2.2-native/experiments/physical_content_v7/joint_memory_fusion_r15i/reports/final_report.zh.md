全部对照固定同一训练权重、输入与seed42，改变两路CFG中的指定读取／条件。它们不是分别重训的结构消融；正常减对照的正值表示正常分支更高。无关／空reasoning仍保留该样本自身的首帧及请求输入。

物理分支整体收益很弱：正常对关闭C仅PC+0.0625（2胜13平1负），SA−0.0625，Joint仍同6例。它没有达到预期的显著PC和联合收益，且010存在夸张水面副作用。

双读取尚未形成稳定互补：请求关联单路与联合版的16例PC逐例完全相同，Joint同6例；仅SA两例互换、均值不变。直接单路SA和PC均高0.0625，但Joint少010一例。联合版没有同时胜过两条单路；010/038的实际失败与请求关联侧相近。

已训练物理Q在此模型有可测作用：正常比原生Q替换的SA/PC各高0.0625、Joint多2例，且没有任何SA或PC降低样例。保留独立Q有本模型的配对依据，但不足以弥补I对B全40的退化。

样本相关C有部分PC价值：正常比固定训练均值PC高0.1875（3胜13平0负）、Joint多1例；同时SA低0.0625。不是所有有效性都来自公共C，但这点收益尚不充分；038均值C反而保持主体更好。

正确reasoning的利用不均衡：对无关reasoning，正常SA+0.125、Joint+2，但PC−0.1875；对空reasoning，正常SA+0.0625、Joint净+1，PC−0.375（0胜11平5负）。这不是reasoning完全没被使用，而是当前执行没有把正确条件稳定转化为物理及画面收益。

PC自动评分会漏掉严重错误：无关reasoning的010严重绿黄纹理破坏仍PC5；空reasoning的038主体消失仍PC5。因此不能用空内容PC4.0625直接选作达标方案。视频证据必须与分数共同保留。

训练记录：400次更新、1600个样本；128步接口训练后272步联合训练。数据顺序、噪声级别、条件丢弃和学习率安排与B一致。FM和高误差项是单样本单噪声步损失，不作为生成质量证明。

Joint为何没有提高：I、B原版和B400联合读取的SA通过样例完全相同，均为11例；Joint也完全相同，均为10例。I提高了一些SA均分，但没有新增跨过SA≥4的样例；PC通过数却从B的23下降到17。即使当前11个SA通过样例全部物理通过，也不足以达到12/40，必须同时增加真正语义通过的样例。

实际画面：全部5个预先选定样例已查看。I修复了H在027/034/038的大片网格，但004近静止、010拖把与水面异常、034没有明确持续膨胀、038滚筒中途消失再出现。实际画面仍不满足综合目标，不能以局部伪影修复或Joint通过替代完整过程质量。
