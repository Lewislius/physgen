R16A-NOZERO：从头训练的零值参考移除对照

用户明确要求沿用当前R16A设计，另训一版不包含零值参考的模型。原R16A Search68429继续运行。此版本不是R16A400推理时关闭零值项，而是从官方Wan基础模型初始化新的增强、融合和LoRA，训练与正常推理都没有零值参考。

唯一架构改动：每个物理融合层删除reference_key参数，不再计算参考分数，不拼接零值V；最终softmax只在物理内容上归一化。原生请求关联先验、直接物理Q/K/V/O、路由C、执行C、状态交互和原生文本通路均保留。语义先验仍进入直接C分数，C之间的相对分数公式不变。

移除10层各3072个参考键参数，总计30720。预计可训练参数从R16A的764443648变为764412928；增强模块、物理Q/K/V/O的容量均保持。原生文本Q/K/V/O继续冻结。

对齐项：原版缓存、seed42、1600条训练样本、128步增强／融合训练＋272步联合训练、相同学习率、相同0.8平均FM＋0.2多尺度高误差FM＋路由词对齐损失。采样仍为Euler50、shift5、gamma5、相同首帧和持久化噪声。两版各自使用自己的400步权重，完成同一40例＋不重叠20例组成60，以及固定16例机制／内容对照。

预先验证：Q/C模块AST与原R16A相同；除参考键外的小模型初始状态逐参数完全相同；非零输出状态下，新模型前向等价于原R16A移除参考选项的前向；所有读取模式均无零值槽；原生初始化、生成梯度、两阶段参数归属、CFG双分支和保存恢复已覆盖。完整GPU预检再次记录实际参数量及梯度，预检权重丢弃后正式从头开始。

此设计检验“允许少写的参考项是否削弱了有效物理利用”。移除它会使注意力全部分配给物理内容，但不保证PC、SA、Joint一定提高，也不代表所有位置都得到有益修正。最终判断以同协议40／60、固定16例和实际视频为准。旧的R16A同权重no_reference16仍属于推理干预，必须与本次从头训练的NOZERO结果分开记录。
