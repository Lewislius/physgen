R11A-rework：保留R10A联合物理生成，增加独立原生请求生成监督
2026-11-03。替代失败67214的采用资格；不覆盖其源代码、权重、视频或结果。

核心结构
原始请求 → 原生T5 → Wan原有文本cross-attention。
首帧+请求 → qwen3.8-flash生成文本reasoning → 本地冻结Qwen3-VL4096编码 → Q256两轮物理enhancement → 全宽C → R10A并行physical fusion。
Wan原有self-attention/FFN LoRA保留。文本cross-attention的Q/K/V/O用官方冻结权重。
物理Q/C及fusion的参数集合、完整前向计算与R10A一致；比失败R11A去掉23,592,960个新增文本适配参数及post-text物理读取改动。
没有新增语义投影/门控/记忆库/评分器。原R10A的两个C职责为寻址和执行，不再把每个中间字母包装成独立有效模块。

训练
从官方基础权重和新数据的训练输入拟合接口新初始化。禁止使用R10A/R1/失败R11A项目权重初始化；只恢复本次运行自己的checkpoint。
相同seed42、accum4、400updates/1600samples、sigma/noise/drop计划。
对同一microbatch的同一参数状态：
native：原生文本+首帧预测真实训练视频目标；FM+原多尺度tail仅更新Wan原self-attention/FFN LoRA。
full：启用物理enhancement/fusion预测同一目标；FM+原tail更新原Wan LoRA以及物理模块，原routing词辅助继续只监督物理路由。基础Wan和原生文本Q/K/V/O冻结。
两次backward顺序执行，中间没有optimizer.step；每4条样本更新一次。LoRA累积两路生成梯度后取平均，再按原阈值裁剪；物理参数只有full一路，保留原损失强度。取平均只做一次，不在每个microbatch反复减半已有梯度。
nativeLoRA从第1步训练400次，采用原native400的128步warmup；物理仍400次、原32warmup和各组LR。旧R10A原生LoRA只有272次。实质训练计算为每样本两路，预算大于旧版，明确披露。
无新可学习模块或可调权重：LoRA的两个生成视图等权平均，物理模块保留完整生成+原routing辅助；原辅助系数及全部物理LR不变。目标不是降低C余弦或强迫运动增大。

为什么这样改
完整40显示失败R11A PC3.45/SA2.90/Joint6，R10A为3.75/2.825/7，native400为3.45/3.075/10。
R10A固定16正常比no_c PC高.25但SA低.1875。现有物理执行有价值，原生请求执行受损也有实据。
新训练使原生生成能力独立接受真实目标监督，同时保留完整路径中Wan LoRA与物理模块的联合适配，不再新增文本Q/K/V/O适配和post-text融合。
12:04准备版曾将full的Wan LoRA冻结。重新核对后，该选择隔离梯度却切断了R10A后272步已有的联合学习通路；失败67214的组合结果不能证明原有LoRA应冻结。本次在任何提交前改为full联合更新，原120444快照/验证记录保留为未训练的准备历史，不新增候选训练。
独立native损失提供语义/画面监督，但不能保证两路梯度完全不冲突；不采用额外梯度投影、门控或动态权重，仍由同例正常/no_c和完整40/60实测判断。
这是有依据的待验证方案；不把功能测试当成SA/PC已改善，也不保证完整物理输出天然保持native语义。

评测/简化依据
训练到400，保留128/250/400检查点，不增加中途评测。
先原40，再固定额外20并聚合60；报告5分均分和>=4的SA/PC/Joint通过率。gamma5/nativeCFG5、seed42、50Euler、shift5。
