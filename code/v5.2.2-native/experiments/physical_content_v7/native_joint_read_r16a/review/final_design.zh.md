R16A：原生请求关联引导的直接物理读取

目标是在原生训练／推理采用同一结构的情况下，超过 B400＋I 联合读取的 VideoPhy2-40／60，并同时改善真实过程和画面。40例还须 PC≥3.8、SA≥3.125、Joint≥12/40；本轮不启动 WMB／Physics-IQ。以下是提交依据，不是已经取得的提升。

已核实的主要问题

1. B400＋联合读取与正式 I 的区别不在训练长度或数据。两者的 Q/C 增强模块、读取核心公式、1600条样本顺序、噪声、条件丢弃、400更新及学习率一致。B先用请求关联读取训练，400步后才冻结换联合读取；I从训练开始采用联合读取，并增加独立物理Q。因而训练塑造的C、投影和后期LoRA不同。
2. 40例 B400＋联合读取为 SA2.900／PC3.775／Joint10；I为3.025／3.475／10。60例分别为2.816667／3.816667／12和2.950／3.466667／12。明确退步的是PC；I的SA略升，但两者均未达标。
3. 固定16例，B联合相对自己关闭物理的PC净收益为0.250；I只有0.0625。I仅请求关联读取与完整联合读取的PC逐例相同，直接通路没有形成预期的可见互补。I替回原生Q后PC和Joint还下降，因此没有根据删除独立物理Q。
4. Search68408／Run69795已完成冻结诊断：3个预先选定的训练输入／噪声点、每个3层。在相同输入上，直接C的平均注意力份额从B联合的75.64%降至I的47.88%；请求关联值占比从20.61%升至40.16%；零值参考项从3.75%升至11.96%。物理写入／原生文本更新RMS从1.861降至0.945。请求关联值的公共方向能量也更高。这支持“训练后直接物理执行被弱化”的判断；样本量有限，不能将这些数值等同PC下降的完整因果证明。
5. 两路K/V梯度余弦在所测18项中均为正，没有观察到普遍反向冲突。故不增加梯度冲突手术、detach或新损失。冻结语义接口常量B/I一致，参数量I比B多9443万，不能归因于I整体参数更少。

最终结构

保留B／R10A的增强模块、路由C与执行C、分组信息以及状态交互。保留独立可训练物理Q/K/V/O，原生文本Q/K/V/O冻结。物理分支维持256槽、增强4096维、注入3072维；整体可训练参数预计与I相同764443648，完整GPU预检再记录实际值。

原来的联合读取将“直接C键”和“请求键＋预先平均的C值”放在同一个softmax中竞争。R16A改为同一组原始C执行值只读一次：

- 用原生文本查询读取真实请求token，得到每个视频位置的请求关注分布。排除人工padding，保留EOS；原生文本输出计算不变。
- 请求键与路由C键建立关联，结合前一步得到每个位置的C概率先验。
- 独立物理Q读取C键，其匹配分数加上该先验的log，再与一个原有零值参考键共同归一化；最终直接读取执行C的V值。
- 保留原有状态交互和独立物理O，向Wan残差写入。已知首帧位置不注入。

简写为：C先验＝softmax(Q_native K_request^T) · softmax(K_request K_C^T＋分组先验)，最终读取＝softmax(Q_physical K_C^T＋log(R×C先验)，参考项) · [V_C，0]。每个点积保留原有head维度缩放，R是已有关系组数，不是新可调系数。

请求关联负责选择内容和位置，物理Q负责执行内容选择。关联与直接匹配共同决定同一组C的权重，不再使用两个竞争的值库，也不先把执行值平均成请求值库。先验总质量仍为R，参考项为1；请求关联无信息时退化为原来的直接C读取。不新增门控、缩放系数、低维瓶颈或可训练参数，也不以强制放大物理更新作为成功标准。

训练和评测

400步从官方基础初始化，使用原版缓存；前128步更新增强／融合，冻结Wan LoRA，后272步联合更新Wan self-attention／FFN LoRA。全程单样本单次生成计算，损失保持0.8平均FM＋0.2多尺度高误差区域FM＋路由C词对齐，辅助权重前32步升至0.03。执行C不受词对齐约束。训练与正常推理调用同一读取函数；不使用B/I权重初始化或充当监督。

顺序是400步→完整40例→不重叠20例并合成60→固定16例配对。对照包括关闭物理、仅直接读、仅请求先验、物理Q同时负责请求寻址、旧联合读、无关reasoning、空reasoning、固定训练均值C。正常16从40中复用。后四类检查内容贡献；机制对照为同权重推理干预，不冒充重新训练的消融。

主要数值与B400联合、I、B、R10A、R9、R1对齐比较。固定查看VP004／010／027／034／038及按分数差选出的过程问题：静止不能代替现象发生，局部形变、对象消失、材质伪影不能被高PC掩盖。物理写入幅度和FM标量仅作诊断。最终是否达成目标，由完整40／60、配对对照和实际视频共同决定。
