R13A执行接口草案：物理条件调节原生视觉运算
状态：方案比较中，未定稿、未创建训练作业。等待R12B无关reasoning及训练均值C完整16。

针对的已观察问题
R12B400完整40为SA2.950/PC3.500/Joint8；物理开启比no_c16虽PC+0.125，却SA-0.1875、Joint-1。VP038的物理写入伴随滚筒中段变形/消失和刷漆结果缺失，而无C可见实际漆带。R10A执行修正也有PC收益和SA/Joint代价。单独增加独立请求值、原生文本值乘法或文本后寻址没有解决这个问题。现有代码将物理消息直接映射为Wan隐藏状态上的新残差；存在“读到了条件，却没有变成合适的视觉操作”的实际风险。

候选结构
保留R10A的Q增强、C_route/C_execute、关系内交换、全宽接口和按当前视频状态寻址。保持原生文本Q/K/V/O冻结，采用R10A的文本前查询输入；不使用R11B独立请求输出、R12A视频池化回读或R12B文本乘法。
物理注意力仍得到每个未来位置的消息M。变化在M的执行方式：不再产生一个独立向量直接叠加隐藏状态，而产生原生FFN输入的scale和shift。

令u为Wan原本送入FFN的、已经含原生文本与去噪时间调制的输入：
  u_phys = u * (1 + W_scale(M)) + W_shift(M)
  hidden_next = hidden_after_native_text + native_time_gate * native_FFN(u_phys)

首帧的两项物理调制严格为0，未来位置正常学习。W_scale/W_shift零初始化，起点精确复现同一原生Wan+初始LoRA。保留原生FFN权重；接口阶段冻结Wan，联合阶段更新已有self-attention/FFN LoRA，梯度通过真实FFN回到Q/C与融合。没有新增独立视觉预测器、判别器、请求输出或手工位置/物理标签。
这一形式把“怎么处理已有视觉状态”交给已预训练的视觉变换；不是在独立C写入之后加一个裁剪或阈值。原生去噪门负责该运算的时间响应，不另外规定gamma曲线。外部推理gamma仍为5。
两张D×D调制矩阵替换旧独立输出矩阵与state_value矩阵，若增强/寻址原样保留，总参数规模可与R10A匹配。它不能保证保住原有PC：原独立残差可能确有FFN调制难以表示的有用能力。这是本版需要通过实际生成检验的主要风险。

与其他可选方向的取舍
独立请求分支已被R11B干预明确指出有害，不能原样重用。联合开放原生文本QKVO没有已有正面对照支撑，不作为本次解决办法。
让C调节视频self-attention值同样有意义，但会同时改变作用时点与时空信息传播，当前失败视频尚不能支持优先采用它。本版若选择FFN接口，就不并行训练第二个R13候选。
不添加C去相关或大幅值目标；不将FM标量下降当物理过程改善。是否保留现有执行C和路由结构，仍结合最后两项控制及历史R9/R10A/R10B证据决定。
