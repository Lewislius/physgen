本版结构
1. 保留完整R10A物理主干：Qwen物理reasoning→Q256、两轮增强→全宽routing/execution C→10处Wan状态相关融合。原有参数、初始化抽样、物理公式、损失、学习率与128+272阶段保持。
2. 独立保存“用户到底要求生成什么”：复用现有冻结Qwen3-VL的原始请求逐词状态。这些状态已经含自己的首帧上下文，且位于因果文本序列的物理分析之前；不拿API文本当隐藏特征，不用未来视频，不增加Qwen模型/下载/API调用。
3. 一个共享4096→3072全宽线性映射，初始化为现有训练侧拟合接口，随后接受真实视频生成梯度。请求词不经过Q压缩、物理C均值或物理relation分组。
4. 在原10处融合位置，用Wan当前视频状态产生的原生query读取请求词。K/V及其norm使用冻结原生Wan参数，和物理C保持独立的注意力归一化。每处用3072→3072全宽零初始化输出写入未来帧；不引入额外门控、分类器、角色状态、低维目标或新损失。
5. 新增参数106,957,824：共享请求映射12,585,984；10个全宽输出94,371,840。此前未提交草稿的rank32输出已替换；不把语义写入限制在32维子空间。容量增大是设计选择，尚不能据此宣称质量提高。
6. 原始T5与Wan原生cross-attention Q/K/V/O保持冻结。空请求是0个词，独立语义残差严格为零；负CFG仍保留自己的图像条件物理reasoning。默认真实训练与推理始终启用新通路。关闭它只用于测试/消融。

训练
全新官方基础模型和新项目模块，使用已完成API修订1600样本缓存；不从R10A/R1项目权重续训。
步骤1–128：冻结Wan及其LoRA，更新物理enhancement/fusion、请求映射/输出；梯度穿过冻结Wan，学习对真实视频有用的写入。
步骤129–400：继续上述更新，同时联合更新原有Wan self-attention/FFN LoRA。没有同时两路训练、梯度平均或额外阶段。
每步累积4个微批次，共1600个原定样本；每个样本只计算一路完整视频生成。
两阶段均为L = 0.8×全局FM + 0.2×原多尺度高误差区域损失 + λ×routing C词对齐；λ在前32步升至0.03。执行C及请求分支不被强迫匹配原生文本特征，接受真实视频生成目标。真实请求/文本dropout保持相同；禁止未来监督作为推理输入。
