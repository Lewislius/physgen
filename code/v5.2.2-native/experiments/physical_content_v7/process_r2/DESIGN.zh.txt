物理内容 R2：从真实后续状态监督执行，2026-10-30

状态：已实现，正在准备独立新训练；不是已经改善生成的结论。

为什么做这一轮

R1 在 step400 保留了 C 内部差异，但真实验证集8例的离散 SA/PC 评分与匹配 baseline 逐例相同。实际视频仍遗漏冰块融化、液体进入瓶内、多米诺连续传递等过程。正确/无关/空/均值/关闭注入的同输入对照已显示内容可以改变输出，但“改变输出”尚不等于“有益”。特别是 VP015 的均值 C 下抬桨更明显，完整 C 更接近静止；VP010 的完整 C、均值和关闭注入对应不同擦拭轨迹，完整 C 并未稳定胜出。

这组证据使下一轮重点落在执行监督：只要求 C 接近原生文本语义，仍不能要求它驱动真实的后续状态；只减少 FM 的平均稀释，也没有直接比较模型预测的可见过程与真实过程。

保留的设计

Qwen 输入物理 reasoning → learnable Q 两轮更新 → 3072维完整 C → 十处原生 Wan 状态相关物理融合。保留 Q256、局部 self-attention 与跨关系汇总、词内容锚点、原生 T5、首帧条件以及 joint 阶段的 Wan LoRA。R1 代码、训练、checkpoint 和评测均不改变。R2 从官方基础模型重新初始化项目参数；不拿 R1 step400 或任何历史项目权重预训练新修订。训练输入缓存与由同一训练划分拟合的静态语义接口复用，来源不变。

新增监督

同一个训练微批先照常由输入图像和请求生成 C、预测 FM 速度 v。根据这次真实训练噪声得到 x0_hat = x_sigma - sigma * v，并固定已知首帧。通过冻结的官方 Wan VAE 解码预测视频，在对应观测时刻，与真实训练视频比较冻结的官方 Qwen 视觉特征。使用视觉输出层与三层 DeepStack 特征，保持空间位置与观测顺序。目标视频只进入这条训练损失，不能进入 C、Qwen 输入 reasoning 或常规推理条件。

每个有效观测位置的距离为 1 - cos(phi(pred), phi(real))。每层使用 0.8 × 所有有效位置的平均误差 + 0.2 × 误差最高四分之一的平均值，再对四层求平均。这是已有视觉模型的有序状态匹配，不是物理判别器；没有分数奖励、RGB变化量、光流、轨迹或要求不同帧保持相同外观的损失。

每次更新仍累积4个微批，按 step % 4 轮换其中一个微批；仅当它原有 sigma 落在 [0.2, 0.8] 时加入该监督，不重抽噪声、不改变样本顺序。从既有每3帧加末帧的28帧网格中选择一个早期帧对、一个中期帧对，并始终选择末尾78/80帧，单次共6帧。早中位置随数据 cursor 确定性采样，跨训练覆盖整段。始终观察最后状态，针对事件迟迟不完成的问题，同时保持长时连续解码和完整梯度。

单个微批目标：
L = L_FM_tail + lambda_C(step) L_C_semantic + I_selected lambda_state(step) L_observed_state。

lambda_state 在32步内从0逐步升到0.5。这个0.5只作用于被选中的微批；所有微批仍统一除以累积数4。约60%的更新会有一次状态监督，即长期有效频率约为全部微批的15%。不把未执行该项的零值误读为该损失收敛。日志同时保存 process_active、process_samples、原始/加权状态损失、选中帧和各层距离。

候选的128步接口期冻结所有 Wan 参数，包括 LoRA；随后872步同时训练增强、融合和 Wan LoRA。匹配 baseline 全1000步训练 Wan LoRA，采用相同数据、noise、样本顺序、FM 和状态监督。baseline 没有 C 语义项。候选与 baseline 的参数量不同，且 baseline 的 Wan LoRA 更新次数更多；报告中继续披露。

已有可行性证据及边界

在 R1 step400 的两个真实训练样本上，状态特征损失经过 VAE/Wan 回到 C 的梯度范数约为0.00137、0.00123，对应 FM→C 约0.000345、0.000329；与 FM 梯度余弦为0.553、0.186，物理输出层也有梯度。该次无参数更新探针峰值显存约53.26 GiB。这证明实现路径可用，不证明本轮能提高生成。

已有视觉特征对真实视频静止替代、时序替代有响应，但对4个失败生成例子的比较中，有3例静止首帧的距离反而低于生成视频。这意味着它同时重视外观/结构，也不是单独可靠的物理质量评测指标。它的真实目标距离为零，仍可提供直接状态匹配信号；效果必须由实际配对视频、过程完成情况和外部评测证明，不能靠该损失降低宣布成功。

执行与判定

先执行一次丢弃权重的工程检查，覆盖 fresh interface 和 joint 的完整反传、Adam状态、冻结视觉模型/VAE、真实目标到 C 的梯度。再开启完全独立的 fresh 训练。step400 后生成相同真实验证8例、完整固定 VideoPhy2-40，以及相同4例的正确/无关/空/均值/关闭/仅锚点对照。R1、R2和native baseline保存全部配对数据。以后续真实过程更符合请求、正确内容有选择性收益、视觉稳定性没有恶化为判定，不能用任意更大运动、更低FM或更小C余弦代替。

输入 reasoning 的另一次仅提示词修订已否决：原8个训练输入中，明确静止桌面仍被生成成灯光变暗，云层被描述为扩展到地面，海滩被添加缺少依据的逐渐变干。未覆盖原缓存，未混入这轮评测。输入内容真实性仍是独立待解决问题，不能把这轮执行监督称作已经修正 reasoning。
