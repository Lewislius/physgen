模块有效性测试：第一波完成后的执行要求
2026-10-31，依据用户最新要求

执行顺序

按最新纠正，以当前R1的400步配对结果和内容对照决定下一轮实质修正。400步已经不能当作“训练太少”；不能等待1000步替缺少早期收益的设计证明有效。66855已完成，66856继续，但1000步仅作为scaling参考，不再阻塞新修正。旧guidance与R2自动串联66857已终止，避免其非托管脚本在PAUSED状态下继续并进入旧长训练；新的64步实验使用独立入口，先检验少步数的生成收益，再决定是否延长。

停止追加加密逐帧检查。现有配对视频与内容对照用于判断过程遗漏、结构破坏和局部收益；把新增计算用于实际修改和小规模生成对比。

主要条件对照使用同一固定16例

用户随后明确：模块有效性测试采用10到20例的小规模有效测试，不需要每项铺满40。采用16例，按过程类型选取，保留4个已有对照以复用结果。完整VideoPhy2-40继续承担总体生成效果比较。模块子集结论仅报告其16例范围，不混写成40例提升。

在明确选定且记录的同一checkpoint上，保留同一首帧、原生T5请求、噪声、采样步数及其他权重，比较：
  1. 本样本正常Qwen reasoning生成的C。
  2. 无关reasoning：保留本图与本请求，仅替换分析文本并用冻结Qwen重新编码。
  3. 空reasoning：保留本图与本请求，去掉分析文字；不把它称为完全无Qwen信息。
  4. 本样本token均值C：去除C内部token差异，仍保留样本之间差异。
  5. 关闭物理注入：同一checkpoint正负CFG分支均关闭物理输出。

复用协议和来源一致的已完成输出；现有4例对照是诊断起点，后续扩为固定16例。无关文本的供体映射、编码模板与正负条件处理规则必须记录，不能一边替换reasoning、一边悄悄替换首帧或原生请求。正常输入只是原缓存内容，并不意味着其中每句物理解释已经正确。

区分“没有Qwen场景信息”与“没有模块”

还需要用训练集生成的固定跨样本平均C，保持物理融合模块存在而去除样本相关的Qwen信息，以区分公共分支偏置与场景内容作用。这与同一视频内部token均值、空reasoning、关闭整个模块是不同问题。均值只能从训练侧输入内容得到，不能从测试未来视频得到；定义和计算样本集合单独记录。使用同一小规模子集，不默认扩到40。不能只用全零隐藏张量造成的异常输出证明Qwen内容有效。

针对增强和融合结构的消融

第一波已有anchor_only能检查“保留语义锚点、移除学习到的C修正”时的变化。后续根据实际失败，选择Q更新/self-attention、状态相关value交互和融合输出中的主要疑点做对照。已有checkpoint上的推理开关只回答当前模型是否依赖该路径；判断结构有没有训练价值，需补官方底座初始化、相同数据/顺序/噪声/目标/总更新预算的独立训练对照。不要把临时删除一个共同训练的模块后变差，直接写成该结构必不可少。仅选择能区分当前主要假设的结构对照，避免堆积无关实验。

保留和删除self-attention都应允许被结果支持。若做RoPE，需要位置对应真实词序或已有语义布局，不能把任意Q槽编号解释为物理坐标，也不能用旋转C降低cosine充当内容改善。当前R3保留self-attention，先解决直接生成梯度与真实后续状态监督；再按早期结果选择匹配训练的结构消融，不等1000步。

重复性、有效性与报告

核心对照报告SA、PC、Joint，以及同案例的胜/平/负和实际过程完成情况。模块子集固定16例；对关键差异使用预先记录的较小相同案例集合做额外seed复测，并包括没有提升的案例，不能只保留成功演示。先检验主要假设，再选有必要的结构消融，不把所有模块和所有开关做成全组合。外观保持、错误形变、因果顺序和过程完成共同判断，不把静止或任意变化量当成物理改进。

正确C要优于不相关/均值/关闭条件，同时在匹配baseline上带来实际生成收益。只让错误输入变差、只降低训练loss、只增加C数值差异均不满足目标。40例是本项目固定I2V适配子集，报告该范围，不包装成官方完整VideoPhy2排行榜。

继续遵守：暂不做VBench；不续训R1 native baseline到1000；不主动下载新模型或恢复未完成下载。所需新模型须先向用户说明用途、大小、必要性并等待授权。使用已有模型完成当前工作。
