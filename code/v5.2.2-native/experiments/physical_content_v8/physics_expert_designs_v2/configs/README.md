# 配置使用说明

这些YAML是待实现训练器的显式配置契约，不是可以直接提交到现有旧runner的YAML。新训练器需要实现字段映射、拒绝未知字段、验证本地路径和训练参数归属。不要把它们直接交给旧runner后忽略新字段。

首选：`p2_s3.yaml`、`p4_s3.yaml`、`p1_s3.yaml`。`*_s5.yaml`为独立训练的每5层版本。`c0_*`与`c1_*`用于匹配训练基线，`p2_post_s3.yaml`用于位置控制，`p4_single_mix_s3.yaml`用于等参数协同对照。

`p2_s3_r32.yaml`与`p2_s5_r128.yaml`是后续机制/预算对照，不是首轮全扫要求。S5-R128与S3-R64接近训练参数预算，但同时改变rank和频率，不是频率单因素实验。

null路径不是“文件不存在时自动下载”的授权。编码AI需读取项目实际路径配置，并核对源代码、数据、权重版本。默认保持单视频每GPU、accumulation4；梯度累积不等于拥有多个独立训练视图。

参数预算来源及假设见公共契约和各方案。预算字段不能取代真实`named_parameters()`审计。
