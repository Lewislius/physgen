R19DT：来源约束的物理内容、视频—物理交互执行、原生特征选择
状态：核心设计已确定，准备独立400步训练。当前尚无新版生成成绩。

这版针对的是整条条件执行链，不以增加一个门控系数作为主要改动。

已有依据
CT 的同协议 40 例为 SA 2.900、PC 3.925、Joint 8/40，60 例为 2.8167、3.9667、10/60；实际视频有主体丢失、异常几何及平涂崩坏，不能接受。
同一固定 16 输入，原生执行来源 token cosine 0.18155，而学得的执行修正 0.99484，最终执行 C 0.93311、路由 C 0.99859；执行修正范数约为来源的 3.51 倍。原实现允许输入被学习到的公共向量覆盖。
关闭整条物理支路，002/004/009/010/013/025/026/038 等的对象或工具关系恢复，但并非所有物理过程因此正确。016 的正常触碰过程、027 的正常揉面形态也有保留价值，不能只靠关闭物理完成目标。
已审查的首 8 个视频反馈对照中，置零池化视频输入后，多例错误仍保留；原始分辨率全 81 帧平均绝对差仅为 normal/no-C 的约十分之一（0.02376 对 0.25438）。这是输出依赖性证据，不是画面评分；016 确有可辨识作用。仅关闭语义内容组也未修复最早 6 例的关键损伤。
因此需要同时处理：物理内容是否来自条件，执行是否真正依赖当前视频，以及怎样在生成特征上执行。不能只追求 C 余弦变低，也不能把新增大模块或存在梯度当成效果。

完整计算
1. 读取与增强：256 个 4096 维 learnable Q，读取冻结 Qwen 的物理分析及原始请求词，进行两轮请求交互、槽间自注意力、全宽非线性更新。Q 用于学习如何选择和组合来源；不再直接生成可无限盖过来源的 C 增量。
2. 内容：执行 C 从本条物理关系对应的原生 Wan/T5 词特征中加权选择；路由 C 从原始 caption 的有效原生特征中选择。权重非负且和为 1，padding 不参与。二者仍为完整 3072 维。来源范围约束内容，后续物理专家承担非线性执行表达，二者职责分开。相似物理内容可以相似，不额外训练多样性目标。
3. 状态读取：每个注入层用独立可训练物理 Q/K，从已经完成原生文本更新的视频状态，联合匹配直接执行 C 和请求关联的路由 C。两个地址指向同一物理槽，使用联合 softmax 的确切合并，不是分别归一化后平均。独立共享全宽 V 将当前视频局部内容读入每个关系槽。原生文本 Q/K/V/O 冻结，每层只执行原生文本注意力一次。
4. 物理执行：当前视频槽特征与物理条件的逐通道交互，进入全宽关系注意力、跨视频时间注意力及 14336 维 FFN。时间位置编码用真实视频时间，绝不把 Q 槽编号当成时间。值和输出不带可独立生成常量的偏置；去噪调制只有比例与门，不产生平移。因此没有视频值、或没有物理执行内容时，专家都不能凭另一支单独编造一个写入状态。权重可从官方注意力和 FFN 初始化，但删除偏置后的交互模块并非原生 block 的等价复制。
5. 融合：按位置读回交互结果，保留联合注意力的有效质量及零值参考，不再对读回消息做消除有效幅度的最终 LayerNorm。独立全宽 O 把消息投影为每个位置的 14336 维特征选择，作用在实际原生 FFN 的 GELU 后激活上：f_new = f_native * 2*sigmoid(O(message))。之后走同一个原生 FFN 输出投影（含普通视频 LoRA）。从零初始化时精确保留原生计算；正常训练后可加强或削弱具体特征。不是直接把 C 变成一幅新增外观场再叠入视频，也不在本层重复读取被物理修改的文本注意力。

相对历史设计的实质区别
R18G 的状态条件 FFN 提供了执行方向，但其低秩条件执行不是本版完整结构。DI 已经使用全宽 FFN 调制，不能把全宽本身再次称作新的有效性证据。CT 的大专家仍能绕开视频值且 C 被自由增量盖过，本版改变这两处函数结构，并将修改位置从 pre-GELU 加性值改为实际 post-GELU 特征选择。
R15B+I 是 I2V 参照；只借鉴其联合条件读取思想，不将它的分数作为 T2V 提升证据，不加载其权重。完整设计需要自己的 400 步及 40/60 结果。

训练与配套
官方 Wan 初始化，新模块及 rank32 self-attention/FFN LoRA 从头学习；原生文本投影保持冻结。总计 400 次更新、每次累积 4 个样本，与 CT 相同的 1600 条 T2V 缓存顺序及噪声/条件丢弃协议；全程联合更新，不额外叠加训练阶段。
损失仍为 0.8 平均 FM + 0.2 多尺度高误差区域项；无 verifier、无 RGB 变化/刚体/接触/轨迹/跨帧差值附加损失，无路由对齐辅助。
取消已不需要的 Qwen→原生 C 回归接口；只用训练集统计 Qwen 输入均值/尺度。已从 1600 条、92601 个词计算，未读取评测目标。推理 60 例正负输入复用现有缓存，无 API、新模型下载或目标视频条件。
