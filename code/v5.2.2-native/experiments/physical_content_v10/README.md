# 两套T2V＋两套I2V：NoChunks v2

本轮取消分段物理内容与局部描述监督。保留N1/N2两种明确机制，分别接官方TI2V-5B的T2V、I2V任务入口。不是四个新物理网络；每版独立1000步、batch4。

- T1：纯文本输入＋原生语义关联定位物理写入。
- I1：首图＋文本＋同一双路径机制；首帧为已知边界。
- T2：纯文本输入＋全宽物理直写＋原生FFN视觉特征条件适配。
- I2：首图＋文本＋同一原生视觉执行；只写未知未来。

首先服务原I2V固定40目标的是I1/I2；T1/T2用于同参数量T2V竞争，不能拿T2V分数顶替历史I2V验收。建议主要实施I2/T2，I1/T1保留为机制竞争，但没有实验分数支持性能排序。

需要重新编码的只有T2V input-only physics缓存，因为旧缓存已经含首图；这不是新增teacher、分段标签或改造噪声。

状态：文档与配置检查完成；未进行真实Wan GPU集成、训练或视频生成；不提供未经校准的中心分数预测。目标PC>=3.85/3.95、SA>=3.25、Joint>=14仍是同一I2V模型的验收条件。
