R19BT：原生物理表征与完整物理执行分支

目的与判断
目标仍是同协议 VideoPhy2-40/60 的 PC、SA、Joint 和真实画面一起提高。
本版针对 T2V，400 步，主要参照 R18G 和已完整评测的 R19AT。
粒度不是增加 token 数、门控数或注入幅度；真正有价值的是物理内容对应到正确的视频状态，并得到正确执行。

已知证据
1. AT 正常40：SA3.100 / PC3.550 / Joint8；G 为2.975 / 3.725 / 9。
   AT 固定16：正常3.1875 / 3.8125 / 4；无关3.2500 / 3.5000 / 4；
   空分析3.1875 / 3.9375 / 4；训练均值3.1875 / 3.8125 / 4；
   关闭物理3.4375 / 3.6875 / 4；执行器换回官方3.1250 / 3.7500 / 3。
   内容并非完全无用，学习执行也有局部贡献，但正确内容尚不能稳定优于空/均值，物理通路也可能损伤语义。
2. AT 视觉复盘中存在人物消失、错误器具、过程未执行、形体不合理等问题。
   部分 no-C 的单级评分差异并未得到同等强度的视觉支持，不能把全部分差都当成确证。
3. 既有物理读取已按视频 token 查询 C；视频执行已接受噪声时间调制。
   因此“增加逐位置/逐去噪阶段注入”不是尚未具备的功能，也不足以构成下一版的改进理由。
4. 旧固定 Qwen→Wan 线性锚点拟合的训练归一化误差0.4986；对60条评测输入，
   按样本平均归一化误差0.6666，中心化预测能量/原生目标能量0.5705。
   这些是初始化接口近似误差，不是物理信息丢失百分比，也不是训练后全部 C 的误差。
   输入物理描述的真实 T5/Wan 编码已经缓存，可以直接使用，无需模型下载、API或新标签。
5. 历史 R11B 的独立原始请求残差在16例中，正常SA2.8125/Joint3，关闭请求残差SA3.1875/Joint6。
   R15H 仅改变文本查询的语义响应也没有明确综合收益。因此不重复这两种孤立的“语义增强”。
6. ProPhy 的粒度提升伴随物理类别和 VLM token 定位监督，不是只靠增大分支。
   本版不声称复制其定位监督，也不把它的跨模型全量评分和我们的子集均分直接比较。

最终架构
输入请求→现有 Qwen 物理分析，同时保留两种表示：Qwen 隐状态和同一分析的冻结 T5/Wan 原生词表示。
Qwen→可学习Q256×4096→两轮关系内读取/关系间交换，产生全宽物理增强。
原生3072维物理词锚点加上学得的增强，形成路由 C 与执行 C。原来的线性估计只保留作对照。
物理分支继续使用独立、可训练、官方初始化的 Q/K/V/O，并联合读取直接 C 和请求关联 C。
读取依赖当前视频状态，保留全宽能力，不通过人为缩小物理幅度来换取语义分数。

在十个融合位置，完整物理块拥有独立可训练的视频自注意力、请求交叉注意力和全宽 FFN，
全部从对应官方块复制；原生 Wan 文本 Q/K/V/O 保持冻结。物理块直接读取原始请求的原生文本编码。
更新 = 原生 Wan 块输出 + [物理块(h + O(读取C), 请求, 噪声时间) - 物理块(h, 请求, 噪声时间)]。
这保留直接物理写入及其后续视频交互、请求响应和非线性执行，不把物理值仅当作最终外观残差。
两个物理块调用共享参数。O 为全宽零初始化；物理读取开启后，全分支接受真实视频生成梯度。
零初始化只确定初始行为；不保证训练后画面自动稳定，最终仍检查真实视频。
预计可训练参数2,306,362,368，以正式模型日志确认；扩容本身不是质量证明。

为什么值得做
原生物理锚点直接修正已测得的跨空间近似误差，为物理词与请求/视频状态的匹配保留更完整的原生表示。
完整物理视频块使物理更新能够影响跨位置关系和过程执行；独立请求读取为这种执行提供对象、属性和过程约束。
语义分支参与物理状态更新的执行，而不是新增一个与物理残差互相竞争的原始请求外观残差。
这些提供了提交下一版的具体依据；还不能据此宣称PC/SA/Joint已经提高。

粒度与强度的明确取舍
保留现有逐视频 token 的状态相关读取和官方噪声时间调制；不添加没有当前证据的额外位置/阶段门控、硬幅度上限或手工增益表。
不强制所有物理现象局部稀疏：重力、扩散、照明等可能需要广泛响应。
本次重点改善被分配的内容及执行能力，而不是人为制造更多不同位置的差异。
将“同帧物理读取错移”作为16例对照：确定性地循环置换位置，保留每帧读取向量及幅度分布。
这比取均值更少混入强度变化；但它仍只是推理干预，分数下降并不能单独证明所有位置都已正确定位。

训练
官方基础初始化，不继承旧项目 checkpoint；与 G/AT 相同1600条 T2V 数据、顺序、噪声和条件丢弃，联合400步。
损失只有0.8×平均FM + 0.2×四尺度高误差区域项，保持既有25%尾部设置。
取消路由拟合辅助：原生物理编码已经成为输入，再拟合回同一编码会直接压制需要学习的路由修正。
不加逐阶段新损失、跨帧运动标签、监督路由、MoE、评测器反馈或未来视频条件。
FM数值不用于宣布生成收敛或指标改善。

评测和归因
同一最终400步 checkpoint 完成固定40、补充20和合并60；固定50采样步、shift5、CFG5、seed42。
固定16例：正常、关闭物理、物理块请求读取换回冻结官方、锚点换回线性估计、
同帧物理读取错移、无关分析、空物理分析、训练均值C。
空分析保留原始请求；平均C和关闭物理不是同一干预。
所有模块干预是同权重推理依赖检查，不能冒充独立重训的单因素因果实验。
40/60全部视频检查横线、雪花、大色块、场景崩解、极端形变及真实过程，评分不能抵消画面失败。
本版没有自动 WMB/Physics-IQ；I2V 的跨基准门槛继续遵守实际 Goal。
