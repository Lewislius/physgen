所有版本共同的训练流程

Q = 128，工作区宽度 4096，最终 P 为无偏置 4096→3072 线性层；P 后保留原有 FP32 LayerNorm、可训练 gain/bias 和 Wan 原生 C 注入。Qwen 完全冻结；输入仅包括首帧、caption、现有 requirements 和 Qwen 条件分析。未来视频 latent 只用于训练目标。

初始化槽位 → 第一次 Message 得到 R0
          → 共享 Message 第一次 refinement 得到 R1
          → 共享 Message 第二次 refinement 得到 R2
          → P(4096→3072) → alignment → C → Wan

interface 64 optimizer steps：训练 C 路径，冻结全部 Wan（含 LoRA）
joint    160 optimizer steps：训练 C 路径及 Wan LoRA
L = FM + 0.1 × temporal FM
每 4 个 microbatch 更新一次参数；总计 224 optimizer steps / 896 样本访问
训练 seed = 42；生成验证每个样本都使用 seed = 42，不加样本下标

沿用原有优化器、学习率、dropout、噪声采样和缓存。没有 verifier、JEPA、强化学习、额外损失或额外训练阶段。所有版本共同保留既有归一化；D 仅增加无参数的身份 RMS 归一化。

B / C：有明确边界的长度池化初始化

先对冻结 Qwen memory 使用现有 RMSNorm，再 gather 原有 content_positions。按 content_mask 去掉 padding 后，在 token 维压缩为 128 槽，每槽仍为 4096 维。这是长度池化对照，不预设语义角色，也不把平均向量称为物理摘要。

N ≥ 128：第 j 槽取 [floor(j*N/128), floor((j+1)*N/128)) 的均值。
N = 384：每连续 3 个有效 token 取均值。
1 ≤ N < 128：按输出区间中心选择最近的有效 token，必要时重复。
均值累积使用 FP32，结果转回当前计算 dtype。
R_init = Pool128(U_content) + E

池化仅设置初始残差状态。每次 Cross 仍然读取完整 Qwen memory，视觉 token 和非 content span 不从 memory 删除。B 保留原 Self；C 删除 Self 及其输入 LayerNorm，其他更新相同。

D：每轮保留查询身份

E 仍是同一组 1×128×4096 可训练参数，在一次前向内不变；工作状态 R 随样本和轮次变化。没有另一组身份参数、固定物理角色或正交损失。

E_hat = E / sqrt(mean(E², feature_dim) + 1e-6)

R0：保持原有首次 Cross 查询 q = Wq(LN(E))。
R1 / R2 的 Cross：
    q = Wq(LN(R) + E_hat)
    k = Wk(LN(memory))
    v = Wv(LN(memory))
    R ← R + Wo(Attention(q, k, v))

明确选择 identity_start_round: 1：首次读取已从 E 构造查询，新增身份项从 R1 开始，避免在 R0 重复加入 E 改变初始查询强度。E_hat 在 LayerNorm 后、Wq 前加入；不执行每轮 R ← R + E_hat。E 保留全部梯度路径。

D-S 的 Self 不变。D-N 完全删除 Self。D-I 在 R1/R2 的 Self 使用：

h = LN(R)
q = Wq(h + E_hat)
k = Wk(h + E_hat)
v = Wv(h)
R ← R + Wo(Attention(q, k, v))
R ← R + FFN(LN(R))

D-I 的新增身份项只进入 Q/K，不直接进入 V；V 使用已有工作内容。R0 的 Self 与 D-S 相同。实现将 K 输入与 V 输入分开，避免一次给整个 memory 加 E 而把身份同时注入 V。

公平初始化、checkpoint 和恢复

五版先按原 Q 的顺序构造完整 Message，再为 C / D-N 删除 Self。因此公共层、query_seed 和之后的随机数流相同，避免“删层改变随机数消费顺序”造成额外差异。所有训练从原始 v5.2.2-native/checkpoints/initialization/generator.pt 初始化，不从 66443 的最终权重继续训练。

新 revision 为 v31–v35，明确记录结构；实际状态保存模型、优化器、scheduler、样本 cursor 和 RNG。每版 run_name 独立。后续恢复或推理须使用本实验目录的代码；原版加载器不认识新 revision。

检查、提交和继续训练

以下命令从本实验目录执行。--check 为只读检查，不分配 GPU；--submit 才提交任务。B 使用 amp-80g 单卡，其余四版使用 blk-96g 单卡；B 检查单张可见 GPU 和至少 75 GiB 显存，其余检查单张 RTX PRO 6000 / RTX 6000 Blackwell，均在加载模型之前检查。

bash train/train_b.sh --check
bash train/train_c.sh --check
bash train/train_d_n.sh --check
bash train/train_d_s.sh --check
bash train/train_d_i.sh --check

bash train/train_b.sh --submit
bash train/train_c.sh --submit
bash train/train_d_n.sh --submit
bash train/train_d_s.sh --submit
bash train/train_d_i.sh --submit

提交沿用现有 Determined 环境和镜像，使用显式空 submission_context，不上传缓存或模型。每个 SH 默认动作是 --check。可以从任意目录用 SH 的绝对路径执行。

# 仅在已经分配的对应单卡环境中直接训练：
bash train/train_d_n.sh --local

# 继续某个 D-N run；会读取该 run 的 config.yaml 和 latest.pt：
bash train/train_d_n.sh --resume /absolute/path/to/saved/run

# CPU 行为、梯度、恢复测试：
CUDA_VISIBLE_DEVICES='' bash tools/runtime_python.sh tests/test_q_variants.py
