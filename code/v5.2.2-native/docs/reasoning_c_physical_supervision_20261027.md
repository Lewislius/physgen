# H 和 Q 的物理监督设计与训练根因分析

日期：2026 年 10 月 27 日

本文面向 physGen v5.2.2 的下一轮实验设计，回答三个问题：当前 reasoning 和 C 到底学到了什么，已有训练数据与生成结果暴露了哪些问题，以及怎样提供准确、有效的物理监督。

**核心判断：应优先补上 C 的物理依赖监督，以及这些依赖在 Wan 中的时空执行监督。** 当前训练具备真实视频去噪目标，却没有明确要求模型学会区分物理事实、条件依赖、过程顺序和作用区域。文字分析、消息迭代、条件注入这几个环节之间，缺少可核实的学习目标。

现有无 verifier 的 v29/v30 是对照配方。本文中的新增损失均属于设计方案，未接入训练。旧 v25/v27 的诊断结果与新无 verifier 版本分开讨论。

## 1 主要判断与优先级

| 判断 | 依据 | 对下一步的影响 |
|---|---|---|
| 文字 reasoning 没有被当前训练纠错 | Qwen 编码边界为 no_grad，memory detach，生成分析使用冻结角色 | 要训练文字分析本身，必须明确增加可训练的 reasoning adapter 和 SFT |
| C 的物理内容缺少直接目标 | 当前损失只有 FM 和 temporal FM，requirements 只是输入文字 | 优先监督最终 C 中可读取的事实与物理依赖 |
| 旧 C 缺少可靠的样本选择性 | 正确 C 与其他样本 C 的匹配 FM 几乎相同，关闭 C 反而更低 | 不能靠增大 C 幅度或增加迭代次数解决 |
| 条件执行能力不足 | 已见过的台球、多米诺训练样本仍未生成正确过程 | 需要把监督落到真实生成路径的时间和区域 |
| 标注范围与训练片段存在具体错配 | 多米诺片段已在传播中，caption 却描述触发前后完整事件 | 新 reasoning 标签必须依据实际训练窗口整理 |
| 并非所有模块都在负优化 | Wan LoRA 有匹配 FM 收益；H 的 C 在多米诺样本上改善布局保持 | 保留有效能力，重点修复物理信息的表达与执行 |

首版增强方案优先组合：

1. **C 的事实与条件依赖监督。**
2. **实际 C 条件消息和 Wan 局部表征的时空过程监督。**
3. 时空关系蒸馏作为独立后续增量。

新增文本 SFT 应作为明确的独立变量。单纯扩大 Q、增加迭代轮数或提高注入强度，当前证据不足以支持将其列为首要方向。

## 2 当前模型和训练目标

### 2.1 当前数据与条件路径

普通生成条件来自首帧、caption 和从这些合法输入得到的 requirements。冻结 Qwen 先生成紧凑物理分析，再把首帧与文本编码为 4096 维 memory。

H 从内容 token 出发进行消息更新；Q 从 128 个可训练 query seeds 出发，先完成一次 grounded read R0，再进行消息细化。最终状态经过 4096 到 3072 的投影和通道对齐，形成接入 Wan 的 C。

当前修正后的 H 和 Q 都使用两轮细化。Q 的 R0 是细化前的初次读取，因此共执行三次共享更新块；H 执行两次。

Wan 在每第三个 block 的原生 cross-attention 中读取 C。文本与 C 使用分开的 softmax，再合并消息。查询来自当前 Wan hidden state，因此读取方式随生成状态改变；C 本身在一次采样中保持为预先生成的条件，不会观察生成过程后重新推理。

这一区别很重要：**状态相关的读取已经存在，但它不等于一个会持续观察生成结果并纠正物理推理的 C 模块。**

实现依据：[消息更新](../physgen_native/message_conditioning.py)、[冻结 Qwen 编码](../physgen_native/multiround_knowledge.py)、[原生条件注入](../physgen_native/native_attention.py)。

### 2.2 当前无 verifier 配方

| 项目 | H 和 Q 当前配置 |
|---|---|
| 训练 seed | 42 |
| 消息细化轮数 | 2 |
| interface 阶段 | 64 个 optimizer steps |
| joint 阶段 | 160 个 optimizer steps |
| 梯度累积 | 4，每次前向一个视频 |
| interface 更新 | C 的归一化、消息块、输出投影、对齐参数；Q 另含 query seeds |
| joint 更新 | 上述参数与 Wan LoRA |
| Qwen | 冻结 |
| verifier | 不构造，不打分，不产生损失或反馈梯度 |

两个阶段的损失均为：

$$
L_{\mathrm{current}}
=L_{\mathrm{FM}}+0.1L_{\mathrm{temporal\ FM}}.
$$

参考：[H 配置](../configs/native_h_content_message_no_verifier_simple_wisa3857.yaml)、[Q 配置](../configs/native_q_seed128_message_no_verifier_simple_wisa3857.yaml)。

### 2.3 这些损失能教什么

FM 的输入含有加噪后的真实视频 latent，目标是 noise minus clean latent。它训练生成模型恢复数据分布，包含真实动态的信息。训练中的这条加噪路径是标准监督计算，不是普通推理时提供真实未来。

Temporal FM 对预测误差在视频时间维上的差分施加二次惩罚。它加强误差的时序结构约束，但没有定义接触、传播、持续释放、材料转变等物理语义。

**FM velocity 是沿去噪路径的导数，不能当作视频中的物理运动速度。**

当前损失可以间接推动 C 学习，但同一目标也能通过原生文本、首帧和加噪视频中的信息降低。对于短预算、高维新条件模块，单靠这种间接学习，没有建立可靠物理接口的保证。这里的问题是监督不够具体，而不是 FM 本身没有学习动态的能力。

参考：[训练损失路径](../physgen_native/operator_training.py)、[temporal FM 定义](../physgen_native/sequence.py)。

### 2.4 reasoning 文字和可训练 C 的区别

| 对象 | 当前是否学习 | 当前监督 |
|---|---|---|
| Qwen 输出的四行物理分析 | 否 | 没有文字 SFT |
| H 或 Q 的消息更新 | 是 | 最终视频损失间接反传 |
| 最终 C 的物理语义 | 可被间接更新 | 没有独立事实或关系目标 |
| Wan 对 C 的使用 | joint 阶段可调整 LoRA | 没有局部过程对应目标 |

代码中存在历史 analysis_sft_loss 和 relation_sft_loss 接口，不代表当前 H/Q 已经使用它们。requirements 进入条件构造，也不等于 requirements 已经作为监督答案参与优化。

## 3 训练样本上的模块证据

### 3.1 诊断范围

本节使用旧的最终 224 步 checkpoint：

- H：v522-h-content-message-verifier-frozen-simple_66356，历史 v25。
- Q：v522-q-seed128-message-verifier-frozen-simple_66353，历史 v27。

这两个旧模型实际上保留了固定 judge 的评分反馈，并非用户要求的“完全无 verifier”。旧 H 的细化出口为 1，旧 Q 为 2，不能把它们的轮数消融直接解释为当前两轮 H/Q 对照的结果。

匹配诊断包含 8 个确实参与训练的样本和 4 个验证样本，分别使用 0.25、0.65、0.95 三个固定噪声水平。不同 C 干预保持首帧、原生文本、噪声和噪声水平一致。这是固定 checkpoint 上的干预，不是各条件重新训练的比较。

### 3.2 正确 C 没有显示出稳定匹配优势

| 条件 | H 训练 FM | Q 训练 FM | H 验证 FM | Q 验证 FM |
|---|---:|---:|---:|---:|
| 正确 C | 0.213928 | 0.213518 | 0.208787 | 0.208986 |
| 其他样本的 C | 0.213820 | 0.213513 | 0.208815 | 0.208981 |
| 关闭 C | **0.211492** | **0.211223** | **0.207451** | **0.207420** |
| round0 | 0.213518 | 0.213433 | 0.208632 | 0.208910 |
| 继承 LoRA 且关闭 C | 0.212106 | 0.212106 | 0.208084 | 0.208084 |
| 基础 Wan 且无 C 无 LoRA | 0.214396 | 0.214396 | 0.210716 | 0.210716 |

每个训练均值对应 24 次匹配计算，每个验证均值对应 12 次；不是 24 或 12 个独立视频样本。

开启正确 C 相对关闭 C，训练 FM 增加 H 1.15%、Q 1.09%。Q 的正确 C 与错配 C 平均 FM 差仅约 0.00000487。

这支持的判断是：**在这些旧模型和匹配样本上，C 尚未体现可靠的内容选择性。** FM 对关键物理事件未必足够敏感，因此还要结合下面的纯噪声生成结果判断，不能把这张表直接当作整体视频质量排名。

来源：[匹配结果](../analysis/hq_causal_diagnosis_20261027/training_results/paired_summary.json)、[诊断结论](../analysis/hq_causal_diagnosis_20261027/training_results/findings.json)。

### 3.3 C 的幅度不小

实际 attention 消息在输出投影前，C 分支相对原生文本分支的 RMS 比值为：

| 模型 | 最小值 | 中位数 | 最大值 |
|---|---:|---:|---:|
| H | 3.01 | 6.05 | 32.62 |
| Q | 4.91 | 9.02 | 43.09 |

这不是最终视频贡献或整个 residual stream 的倍数。但它排除了“只要把 C 放大一些就能解决”的简单解释：分支已经能产生较强消息，却没有相应的匹配优势。

通道均值和方差对齐，只初始化表示尺度，并不把 Qwen 的物理语义自动转换为 Wan 能执行的语义。当前仍需要学习输出投影、键值读取和实际过程之间的对应关系。参考：[对齐实现](../physgen_native/context_alignment.py)。

### 3.4 实际生成暴露了过程执行不足

**台球 wisa0003617。** 训练目标中球明显滚动；旧 H/Q 从纯噪声生成时大部分时间维持原位，随后补出球杆或手。16 步与 50 步采样均未恢复目标过程。关闭 C 或回到基础 Wan 也没有解决。

**多米诺 wisa0005325。** 真实目标展示局部、已经开始的连锁传播。H 使用完整 C 时较好保持螺旋布局，但没有执行对应传播；关闭 C 后布局严重变形。Q 则出现整体旋转、收缩或塌成圆盘，round0 和完整更新的可见行为接近。

因此，H 的 C 在该例有结构保持价值，但结构保持还没有转化为正确的物理过程。Q 的后续更新尚未展示清晰的过程收益。

### 3.5 对各模块的判断

| 模块或设计 | 已体现的价值 | 主要不足 |
|---|---|---|
| 基础 Wan | 场景外观和一般视频先验 | 复杂过程不能可靠执行 |
| 当前 Wan LoRA | 无 C 时相对继承 LoRA，训练 FM 改善 H 0.29%、Q 0.42% | 拟合收益尚不等于事件正确 |
| H 内容条件 | 多米诺个例的布局保持改善 | 没有形成对应连锁传播 |
| Q128 条件 | 提供固定容量工作区和槽位交流 | 内容选择性与迭代收益不足 |
| 多轮消息更新 | 有可训练的计算路径 | 缺少各轮应完成什么的监督 |
| 通道统计对齐 | 初始化尺度，维持完整通道接口 | 不保证跨模型语义匹配 |
| 旧固定 judge 反馈 | 能识别部分失败案例 | 同时存在评分盲区与过强反馈，不能替代具体物理监督 |

旧 verifier 问题与当前监督缺口应分别处理。移除错误保留的评分反馈解决了对照实验定义问题，但不会自动补上 C 的语义目标和生成端的执行目标。

## 4 训练数据的实际问题

### 4.1 当前缓存缺少可直接使用的显式物理标签

当前训练清单共 3666 条：

- category 为 unlabeled 的有 1848 条。
- category 缺失的有 1818 条。
- 顶层没有有效的 physical_laws、physical_phenomena 或 physical_properties 字段。
- 当前数据加载器未把物理类别、过程顺序或区域标签作为训练目标。

这是当前项目缓存和训练路径的情况，不代表原始 WISA 数据集没有相关标注。原始标注若要复用，还需要对应到实际裁剪片段，不能直接把完整源视频的标签套在短窗口上。

来源：[缓存清单](../../../data_cache/wisa_4000/base/manifest.json)、[数据加载实现](../physgen_native/data.py)。

### 4.2 有效训练覆盖很短

| 项目 | 旧 H/Q 实际训练数据 |
|---|---:|
| 不同训练视频数 | 896 |
| 占 3666 条训练池的比例 | 24.44% |
| 单条视频在该轮训练中出现次数 | 1 |
| 片段时长中位数 | 2.67 秒 |
| caption 英文词数中位数 | 130 |
| 81 帧占源视频总帧数比例的中位数 | 32.4% |

短训练预算中，新的高维消息模块很难只靠整体 FM 自动学会内容筛选、物理依赖和跨模型执行。这个判断支持提高每个样本的监督质量，而不能简单推出“只需训练更久”。

来源：[数据审计](../analysis/hq_causal_diagnosis_20261027/training_content_audit.json)。

### 4.3 具体的片段与描述错配

| 样本 | 实际片段或内容 | 错误使用方式 |
|---|---|---|
| wisa0005325 多米诺 | 约 1.33 秒，传播已开始，只覆盖部分过程 | 把 caption 中手部调整、开始触发、完整结束全当成该窗口目标 |
| wisa0005723 黄油 | 已是黄色液体，刀在刮动和涂抹 | 当成固体到液体的融化监督 |
| wisa0024912 杯子 | 杯口蒸汽，butter knife 是背景描述 | 仅靠 butter 关键词归入融化过程 |

多米诺 caption 的内容，与生成中补出手部动作相一致，但仅凭这种对应不能归因其全部错误。可以确认的是：caption 和真实片段在过程范围上形成了矛盾监督。

已有一部分 caption 做过片段级修订，不能把整个数据集都视作错误。新标注应优先修复已确认的窗口错配，并保留自然连续变化、缓慢变化和合理稳定状态。

### 4.4 新标注需要区分两类事实

**条件侧事实**来自首帧和生成请求，用于监督 C 应表达什么。单帧不能确定的运动状态、温度、质量、时刻，应保留条件性。

**结果侧证据**来自真实训练片段，用于监督 Wan 的过程表征和生成目标。这些未来证据可以作为训练目标，但不能进入普通推理的 C 输入。

从视频观察到 A 先于 B，不足以自动证明 A 导致 B。因果依赖标签需要清楚的适用条件、可信的物理机制或受控干预证据。

## 5 相关工作的启示

### 5.1 ProPhy

ProPhy v2 用物理类别关系监督全局路由，用 VLM 现象注意力减去背景注意力形成局部软标签，监督细粒度路由，并配合专家负载均衡。

| Wan 消融设置 | Joint |
|---|---:|
| 基础模型 | 24.8 |
| 完整 ProPhy | 26.5 |
| REB 仅保留对齐损失 | 21.6 |
| REB 仅保留负载均衡 | 26.3 |

结果支持具体物理对齐的研究方向，也说明完整收益不能全部归给对齐损失。[ProPhy 方法与消融](https://arxiv.org/pdf/2512.05564v2)

对本项目的适配判断：其批内样本对损失不能直接用于当前单样本前向；梯度累积四次不会产生一次计算图内的四样本关系。更适合先采用逐样本事实和关系监督。H/Q 也没有同样的专家路由器，不能把专家负载均衡直接套到 128 个 query 槽位上。

### 5.2 VideoREPA

VideoREPA 对齐视频教师与生成模型的帧内、跨帧 token 关系，避免直接强制特征空间逐元素匹配。其消融中，PC 从仅扩散损失的 23.2 提升到完整 TRD 的 29.7；只保留空间或时间部分都弱于完整方案。[VideoREPA 方法与消融](https://arxiv.org/html/2505.23656v1#S4.SS5)

本项目可借鉴关系蒸馏方式，将它放在 Wan 视频表征上。关系相似度不是因果真值，应配合过程阶段与条件依赖监督。它属于后续独立增强，不意味着恢复当前已经移除的 VJEPA2 处理链路。

### 5.3 CoECT

CoECT 把物理过程拆成有序事件，并通过视觉关键帧承接执行。其消融中，去掉关键帧合成的下降大于去掉叙述修订，说明生成端的视觉落实很重要。[CoECT 方法与消融](https://arxiv.org/html/2603.09094v2#S4.SS4)

本项目借鉴过程对齐思想，使用已有真实训练片段提供目标，保持 Wan 承载演化状态，不新增独立未来预测器或关键帧生成分支。

## 6 第一优先级是监督 C 的事实与物理依赖

### 6.1 监督内容

| 信息类型 | 示例 | 标签依据 |
|---|---|---|
| 可见初始事实 | 多米诺已经部分倒下；杯口存在可见蒸汽 | 首帧证据 |
| 生成请求 | 球已经在滚动；继续出现扩散 | 用户文本或训练请求 |
| 条件与响应 | 有足够接触使相邻块失稳，才有对应的局部传递 | 带适用条件的物理机制 |
| 持续与终止 | 接触传播链在无法继续接触的位置可能中断 | 条件性机制，不臆造实际未来 |
| 保持与允许变化 | 多米诺布局应保持；蒸汽允许扩散、变形和消散 | 材料和过程相关约束 |
| 未确定因素 | 单帧无法唯一确定速度或未来精确时刻 | 输入信息范围 |

类别监督可以作为辅助，但“这是碰撞”不能替代“谁与谁接触、随后发生什么、哪些条件必须满足”的监督。

### 6.2 损失定义

令 C 的第 r 轮输出为 $C^{(r)}$，问题为 $q_j$，可靠答案为 $a_j^*$。训练用读出器只读取 C 与问题：

$$
L_C=
\frac{
\sum_{r,j}w_{rj}
\operatorname{CE}\left(p_\psi(a_j\mid C^{(r)},q_j),a_j^*\right)
}{
\sum_{r,j}w_{rj}
}.
$$

明确的标签使用交叉熵；有合理多解的答案可使用软分布监督。没有有效标签时跳过对应项。权重反映标签适用性和证据质量，不能直接把教师自报置信度当成可靠概率。

这里有四个重要选择：

1. **监督最终投影后的 C。** 只监督内部 4096 维状态，可能在最终投影时丢失所需信息。
2. **读出器不另读原 caption 或视频。** 否则可以绕过 C 回答问题。
3. **问题模板需包含不同答案。** 同场景类型中区分实际条件，避免背景关键词捷径。
4. **读出器仅用于训练，不替代完整 C。** 不新增低维生成瓶颈。

重构 caption 只能证明内容保留。关系问题、条件变化问题与跨场景组合，才能进一步约束依赖表达；这些语言侧结果仍需和实际生成效果结合。

### 6.3 两轮更新的监督安排

第一轮重点保留初始事实、来源和直接关系；第二轮增加传播、持续、终止及多条件依赖，同时保留第一轮的重要信息。

两个出口使用同一套读出任务和明确的问题集合。可以对复杂关系在第二轮赋予更高监督权重，但不强迫每个样本都必须发生表示变化，也不把形式上的单调改善当成物理推理的定义。

H 与 Q 均可使用这套目标。Q 的槽位无需人为绑定为某个固定物理定律，避免将潜在表示的排列自由度误当作错误。

### 6.4 文字 reasoning 的 SFT

保持当前 Qwen 冻结时，C 的监督只能改进 H/Q 的信息加工。若希望四行分析本身学会纠错，需要明确引入可训练 reasoning adapter，并使用经整理的分析答案训练。

分析答案应包括输入中成立的事实、条件性解释和适用边界，不能把真实未来中的唯一结果伪装成首帧就可确定的结论。

文本 SFT 与 C 监督是两个实验变量，应分别判断。文字更流畅，不等于 C 更有效，更不等于视频物理正确。

## 7 第二优先级是监督生成路径中的时空过程

### 7.1 需要从训练片段获得的目标

| 过程 | 可监督的内容 | 不应强制的内容 |
|---|---|---|
| 多米诺传播 | 局部倒下、已倒区域、尚未波及区域和先后关系 | 补出窗口之前的手部触发 |
| 液体倾倒 | 出液区域、流出过程、承接区域及其变化 | 没有尺度与完整观测时的精确体积守恒数值 |
| 蒸汽或烟雾 | 出现区域、扩散、变形和消散 | 将气团作为刚体保持外形 |
| 材料形变 | 受作用区域和可见响应 | 让背景整体同步变形 |
| 缓慢转变 | 当前时间窗内有证据的状态变化 | 强制短视频完成整个相变 |

对持续过程使用时间区间和局部证据，不强行将所有视频切成同一种离散事件模板。无法确定的区域或时段不应标为明确负例。

### 7.2 教师只产生固定训练目标

教师读取真实训练视频，输出过程条目、证据时段和空间软标签：

$$
Y=\operatorname{stopgrad}\left(T(V_{\mathrm{gt}})\right).
$$

学生从实际生成路径读取 C 条件消息以及相应 Wan hidden state：

$$
L_{\mathrm{ground}}
=\ell\left(S_\theta(C,H_\sigma),Y\right).
$$

空间 attention 可提供弱定位提示；是否发生过程、时间先后等关键标签应有可见依据。不能把一张注意力热图直接当作物理因果真值。

目标与学生 token 之间需要按视频时间和实际空间覆盖建立对应，尤其要处理 81 帧到 latent 时间维的压缩。将一个很短的接触或局部变化稀释到整个时段，会失去监督作用。对观测采样未覆盖的短暂事件，应标为未观测，而不是没有发生。

### 7.3 监督应接在实际条件作用路径上

应优先监督原生 C attention 形成的实际消息，以及被它影响的 Wan 局部表征。仅从一个旁路特征预测物理类别，可能只训练了分类能力。

空间和时间定位要与生成 FM 共同优化。训练用读出头自身也可能学到捷径，因此模型是否学会执行，最终要看选择性条件干预和纯噪声生成。

### 7.4 与旧固定 verifier 反馈的区别

| 项目 | 旧固定 judge 反馈 | 拟议固定目标监督 |
|---|---|---|
| 教师或 judge 输入 | 模型生成的视频 | 真实训练片段 |
| 输出 | 对生成结果的支持评分 | 事实、过程和局部目标 |
| 教师输入梯度 | 通过 judge 进入生成视频和 C | 无，教师离线产生并停止梯度 |
| 学生学习路径 | 评分经生成轨迹反传 | 学生表征和生成损失直接反传 |
| 无 verifier 对照 | 不符合其定义 | 另立增强监督实验，仍无需构造评分 judge |

监督损失反传到 C 是正常的学生学习。它与对冻结 judge 的评分函数求生成视频梯度，是两条不同的路径。

## 8 后续增量是时空关系蒸馏

保持完整 C 和原生 Wan 演化状态，在部分 Wan 层的局部视频表征上，对齐固定视频教师的帧内和跨帧关系。

可将候选目标写为：

$$
L_{\mathrm{rel}}=
d\left(R_{\mathrm{space}}(H_\sigma),
\operatorname{sg}(R_{\mathrm{space}}(F_{\mathrm{gt}}))\right)
+
d\left(R_{\mathrm{time}}(H_\sigma),
\operatorname{sg}(R_{\mathrm{time}}(F_{\mathrm{gt}}))\right).
$$

这里的关系可以是归一化特征相似度，教师未来特征只作训练目标。不会向普通推理提供未来视频，也不要求 C 从单帧准确编码所有未来纹理。

该项主要补强结构与动态表征；它不能代替方向明确的过程顺序监督，也不是完整物理 verifier。

当前配方没有该项。引入哪个视频教师、如何获得有效空间时间对应，应在独立版本中定义，不直接恢复旧 JEPA 缓存或处理路径。

## 9 首版训练方案与梯度归属

### 9.1 首版目标

$$
L_{\mathrm{proposed}}=
L_{\mathrm{FM}}+
0.1L_{\mathrm{temporal\ FM}}+
\lambda_C L_C+
\lambda_g L_{\mathrm{ground}}.
$$

时空关系蒸馏 $L_{\mathrm{rel}}$ 作为独立后续增量。文本 SFT 也单独评估，不把所有新目标一次叠加。

各辅助损失先按有效问题、区域和时间项归一化。系数不能直接照搬另一论文，也不能根据损失标量大小就判断其作用强弱。旧反馈出现过很小标量对应很大参数梯度的问题；新方案更关键的改进，是提供局部、具体、可核实的学习目标。

### 9.2 保留两阶段与两轮细化

| 阶段 | 步数 | 学习目的 | 更新参数 |
|---|---:|---|---|
| interface | 64 | C 表达正确关系，并适配 Wan 的实际读取方式 | H/Q、归一化、输出投影、对齐参数、训练用读出头 |
| joint | 160 | 将关系落实为视频过程 | 上述参数与 Wan LoRA |

训练 seed 保持 42，H/Q 都保持两轮细化，Q 保留 R0。教师目标离线固定，Qwen 在首版仍冻结，Wan 在 interface 阶段全部冻结。

冻结 Wan 参数不等于切断 Wan 对输入 C 的导数：interface 阶段仍需通过冻结 Wan 将相应生成和局部监督传回 C。不能把整个学生 Wan 前向放进 no_grad。

如果单独研究文字 SFT，应明确列出 reasoning adapter 的参数归属和对应损失，而不是继续声称文字生成部分完全冻结。

### 9.3 数据准备顺序

1. 对实际训练窗口整理 caption 与 requirements，优先修复已确认错配。
2. 为同一窗口建立条件侧事实与结果侧证据，明确两者用途。
3. 先覆盖台球、多米诺、液体、蒸汽、形变等已有训练样本，再扩展到训练池。
4. 使用清楚的关系标签作为硬监督，用空间定位和不确定关系作为软监督。
5. 将整理结果放在独立版本的监督记录中，保留现有缓存和 checkpoint。

## 10 如何判断新增监督是否真正有效

### 10.1 比较顺序

| 方案 | 新增内容 | 回答的问题 |
|---|---|---|
| A | 现有纯 FM 加 temporal FM 无 verifier 对照 | 移除旧评分反馈后的基础表现 |
| B | A 加 C 关系监督 | C 是否保留并组合了有效物理内容 |
| C | B 加时空过程落地监督 | 正确关系能否改善对应视频过程 |
| D | C 加时空关系蒸馏 | 动态和结构一致性是否进一步提升 |

这些是比较设计，不代表已提交实验。比较应固定初始化、训练样本顺序、预算、seed、推理设置和两轮更新。

### 10.2 需要同时成立的证据

**内容表达有效。** C 的关系读出能在同类场景中区分不同条件，并在新组合上保持正确；不能只依赖场景类别或问题模板。

**过程执行有效。** 从纯噪声生成时，台球发生合理滚动，多米诺发生局部顺序传播，液体和气体出现对应的连续变化；同时保持布局、材料与身份上的适用一致性。

**条件作用具有选择性。** 在同一首帧、文本、噪声下改变相关 C 内容，主要影响对应过程；同义表达应大体稳定，不相关内容不应导致全局崩坏。

**第二轮有具体收益。** 第二轮补上第一轮遗漏的关系或改善相关过程，而不仅仅改变 latent 数值。

正确 C 与错误 C 的干预是诊断方式，不将“故意让错误 C 生成更烂”作为新的排名训练目标。缺少真实反事实视频时，也不能把任意错配条件对应的视频都标成物理不可能。

### 10.3 优先验证训练样本的可学习性

首先要求已参与训练的代表性样本产生正确过程，再检验验证集和新组合。单步去噪重建包含真实未来信息，不能替代纯噪声生成。

不能只以 FM 更低、文字更流畅、attention 更集中或 VideoPhy2 分数更高作为成功依据。应共同检查过程是否发生、先后是否合理、后段是否一致，以及相关条件能否选择性地改变结果。

## 11 不优先采用的设计

| 设计 | 主要问题 |
|---|---|
| 仅增加物理类别分类 | 容易学习场景关键词，无法表达过程条件 |
| 仅增加文字 SFT | 解释正确与视频执行之间仍有缺口 |
| 增大注入强度 | 旧 C 已具有较强消息幅度，不能由幅度推出有效语义 |
| 增加 Q 槽位或更多轮数 | 在缺少直接目标时继续增加学习负担 |
| 强制更大变化量 | 可能奖励全局形变，误伤合理缓慢变化 |
| 将未来特征逐元素硬塞进 C | 单帧条件无法唯一决定全部未来细节 |
| 从单帧估计未经证实的物理量并硬套方程 | 监督前提不成立，容易制造伪精确目标 |
| 对所有材料使用同一种一致性约束 | 刚体、流体、气体、形变和消散需要不同适用条件 |
| 将任意时间倒放都标成物理错误 | 一些可见过程本来就近似可逆 |
| 用低分或未知一概代表过程不存在 | 缺乏观测不能当作否定证据 |

方案保持一般可见过程的范围，不引入光流、点跟踪、物理速度目标或独立未来状态预测器。Wan 继续承载演化状态，完整 C 继续作为条件接口。
