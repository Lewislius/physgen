# C 的软／硬监督与生成有效性训练方案

日期：2026 年 10 月 27 日  
适用对象：physGen v5.2.2-native 的 H-content 与 Q-seed128 消息条件路径  
文档状态：下一版训练设计；本文新增目标尚未接入现有训练。

**核心目标：让每轮 C 都带着明确的物理／因果学习目标更新，并让最终 C 承担实际生成过程的训练误差。**

用户关心的是：C 从初始信息经过几轮处理后，究竟保留了什么、推导出了什么，以及这些信息是否帮助视频生成。为此，训练需要同时约束“C 包含有效信息”和“这些信息能被 Wan 使用”。

本方案以直接监督为主线：C 的硬标签监督、软分布监督，以及生成过程反馈。后段过程的持续与终止是重点学习内容。训练步数作为支持这些目标的预算问题讨论；C 的关闭／打乱对照暂不作为本方案重点。

## 1. 当前 C 的学习缺口

现有条件路径可以概括为：

```text
首帧 + caption + requirements
        ↓
冻结 Qwen：物理分析与特征 memory
        ↓
H：内容状态 → 两轮消息更新
Q：128 个 query → 初始读取 R0 → 两轮消息更新
        ↓
4096 → 3072 投影与通道对齐
        ↓
最终 C → Wan 根据当前视频状态读取 C → 生成视频
```

C 的来源包含图像、文字和冻结 Qwen 特征。当前问题在于：消息更新没有直接的物理语义学习目标，主要靠最终视频去噪误差间接调整。

本次讨论对应的两个无 verifier 训练为：

| 路径 | Search | Run | 修订 |
|---|---:|---:|---|
| H-content | 66438 | 67818 | v29 |
| Q-seed128 | 66443 | 67823 | v30 |

二者的训练目标都是：

$$
L_{\mathrm{base}}=L_{\mathrm{FM}}+0.1L_{\mathrm{temporal\ FM}}.
$$

FM 可以从真实视频学习动态和物理规律，但没有直接规定 C 应表达哪些事实、条件依赖、持续机制和终止条件。Temporal FM 约束的是视频时间上去噪误差的差分，也没有直接定义这些物理语义。

因此，以下几件事应分别理解：

| 当前可观察到的现象 | 它能说明什么 |
|---|---|
| C 的向量经过多轮变化 | 消息计算确实发生 |
| C 的梯度非零 | 最终损失可以更新 C 路径 |
| FM 正常优化 | 去噪目标在参与学习 |
| 从 C 中能读出正确物理关系 | C 表达了相关信息，需要新增语义监督 |
| C 所条件化的生成过程得到改善 | 信息具备生成用途，需要生成过程反馈 |

**本方案直接训练后两项。** FM 的标量降幅只作为辅助信息，不据此判断物理能力是否充分学习。

## 2. 三类监督及其分工

| 监督类型 | 直接学习目标 | 监督形式 | 主要作用位置 |
|---|---|---|---|
| C 硬监督 | 明确事实、要求与适用物理依赖 | 答案标签的交叉熵 | 每轮最终 C |
| C 软监督 | 合理关系判断、条件性与不确定性 | 教师答案分布蒸馏 | 每轮最终 C |
| 生成过程反馈 | 事件实现、作用响应、持续与终止 | 实际生成视频的物理过程损失 | 经视频与 Wan 反传至 C |

“硬监督”表示答案明确的标签监督，不表示用硬阈值决定视频能否运动。“软监督”表示学习答案分布和关系判断，不等于随意减小损失权重。

物理关系覆盖液体、气体、扩散、波动、形变、出现与消失，以及刚体过程。监督围绕过程本身组织，保留不同材料和现象的演化方式。

## 3. 硬监督：明确要求 C 包含什么

### 3.1 将物理信息变成可回答的任务

以倒水为例，训练问题可以包括：

| 问题类型 | 示例 | 标签依据 |
|---|---|---|
| 初始事实 | 液体来源与承接区域分别在哪里？ | 首帧中可确认的事实 |
| 生成要求 | 当前请求是持续倾倒还是停止倾倒？ | 原始生成请求 |
| 作用关系 | 在持续流入且没有流失时，承接区域的液体量应如何变化？ | 明确适用条件下的物理关系 |
| 持续条件 | 维持这个过程需要什么来源或作用？ | 该过程的适用机制 |
| 终止与保留 | 停止供给后，什么应停止，什么可以继续存在或变化？ | 物理机制与当前条件 |

监督应包含关系和条件。只预测“这是倒水／扩散／形变”这样的类别，提供的信息不足以支持过程执行。

### 3.2 在每轮实际输出 C 上接训练读出器

使用共享的语义读出器 $D_\psi$：

$$
p_{rj}=D_\psi\left(a\mid C^{(r)},q_j\right).
$$

其中，$C^{(r)}$ 是第 $r$ 轮最终投影、对齐后的 C，$q_j$ 是物理问题，$a$ 是答案。

训练路径为：

```text
第 r 轮消息状态 → 最终投影与对齐 → C^(r)
                                      ↓
                            共享读出器 + 物理问题
                                      ↓
                                预测答案与标签比较
                                      ↓
                         更新消息模块、投影和对齐参数
```

读出器只读取 C 和问题，样本信息通过 C 提供。原始 caption、首帧和完整 Qwen memory 不再作为读出器的另一条输入路径。

监督放在 **Wan 实际接收的 3072 维 C** 上，使最终接口保留所需信息。内部 4096 维消息状态继续作为完整工作空间。读出器仅用于训练，完整 C 继续作为生成条件。

对硬标签集合 $\mathcal H$，定义：

$$
L_{\mathrm{C,hard}}
=\sum_{r=1}^{2}\alpha_r
\frac{1}{|\mathcal H|}
\sum_{j\in\mathcal H}
\operatorname{CE}(p_{rj},y_j).
$$

硬标签来自明确事实、明确请求及具有适用条件的可靠关系。自动教师对含糊现象的推断采用软监督。

## 4. 软监督：表达条件性和多种合理判断

烟雾扩散、液体形态和材料恢复通常没有唯一精确未来。软监督让 C 表达合理的关系和不确定性。

例如，对“烟源停止后，已有烟雾会怎样”这个问题，合理的知识包括：已有烟雾可以继续扩散、变形和逐渐消散。停止释放与已有烟雾立即消失是不同事件。

教师对相同问题及相同答案空间提供分布 $p_j^T$，学生从 C 中读出对应分布：

$$
L_{\mathrm{C,soft}}
=\sum_{r=1}^{2}\alpha_r
\frac{1}{|\mathcal S|}
\sum_{j\in\mathcal S}
\operatorname{KL}\left(
\operatorname{stopgrad}(p_j^T)\;\|\;p_{rj}
\right).
$$

这里对齐的是物理问题的答案分布。不同 latent 空间中的向量不要求逐元素相等，教师 token 也不需要与 Q 的 128 个槽位一一对应。

C 的语义教师以首帧、请求和适用物理知识为依据，产出的目标包含条件性描述。真实训练视频可以提供生成过程的结果侧目标；首帧无法确定的精确未来不应变成 C 必须断言的确定事实。

同一任务采用与标签性质对应的硬或软监督；两类损失分别按有效任务数归一化。

## 5. 两轮消息更新各自承担学习目标

两轮出口使用同一个读出器和共享任务集合，最终出口获得更高的总权重。第一轮侧重基础关系，第二轮加强持续、终止和组合依赖，同时继续学习基础事实。

| 出口 | 主要学习内容 | 持续保留的内容 |
|---|---|---|
| 第一轮 C | 初始事实、来源、受影响区域、直接作用关系 | 输入中的有效事实与请求 |
| 第二轮 C | 传播、持续、终止、多条件依赖 | 第一轮应保留的事实和直接关系 |

以烟雾为例：第一轮应表达烟从哪里出现、当前是什么状态；第二轮进一步表达来源持续时如何发展、来源停止后已有烟雾如何继续变化。

这是监督权重的安排。一个简单样本可以在第一轮已经表达充分，训练不要求每一轮的向量都大幅改变，也不额外添加“后一轮分数必须超过前一轮”的排名目标。

实现上可沿用现有 `all_rounds=True` 返回的各轮 `conditions`。H 保留两轮更新；Q 保留初始读取 R0 和两轮细化。损失接到两个细化出口。

## 6. 生成反馈：让 C 中的信息真正用于视频

### 6.1 从语义表达走到过程实现

从 C 中读出“持续倒水会改变杯内状态”，说明信息可以被读取。要让 Wan 用好这条信息，还需要实际生成过程的训练目标。

使用最终 C 生成视频：

$$
\hat V=G_\theta(I_0,T,C^{(2)};\epsilon).
$$

过程监督器读取生成视频、原始条件及训练用过程目标，评价具体过程的实现情况：

| 监督内容 | 需要模型学会的行为 |
|---|---|
| 要求的过程发生 | 倒水、扩散、形变等请求在视频中实际实现 |
| 作用与响应对应 | 可见来源、接触或作用与相关区域的变化相联系 |
| 合理持续 | 支持条件仍然成立时，过程继续合理发展 |
| 合理终止 | 条件变化后，过程适当改变或停止 |
| 状态连续 | 材料、来源及其变化在整个过程中保持合理联系 |

过程目标来自实际训练窗口和适用物理关系，允许合理的生成差异。像素级形状、精确轨迹和精确发生时刻不作为所有生成结果必须复制的答案。

### 6.2 将物理误差传回 C

```text
C^(2) → Wan 完整采样 → 生成视频 → 具体物理过程损失
  ↑                                      │
  └──── 消息模块 ← C 的梯度 ← 完整生成路径 ──┘
```

首版沿用 C-only 物理反馈的参数归属：生成反馈时固定监督器和 Wan 的参数，保留它们对输入的导数，让物理误差更新 C 路径。联合阶段的 FM 与 temporal FM 继续训练 Wan LoRA。

这样，物理反馈直接推动 C 学习能够影响输出的表达。语义读出器的答题损失与真实生成损失共同训练 C。

反馈计算可复用项目已有的短步完整视频采样与反传路径。完整 81 帧视频由 Wan 生成，监督器沿用原生 832×480 的 28 帧观测，覆盖每第三帧及最终帧。需要增强的是过程目标的具体性与时间分工。

## 7. 将后段持续与终止纳入明确训练目标

本次两个 Run 在高噪声单步重建中的后段变化恢复较弱，且不同样本的失败方向不同：凝胶变化不足，湖面变化与参考的对应较差。因此训练目标应教会模型何时、何处发生何种变化，以及何时保持或趋于稳定。

建议将生成过程损失组织为：

$$
L_{\mathrm{process}}
=\frac{
w_{\mathrm{all}}L_{\mathrm{whole}}
+w_{\mathrm{late}}L_{\mathrm{late}}
}{w_{\mathrm{all}}+w_{\mathrm{late}}}.
$$

- $L_{\mathrm{whole}}$：完整过程中的实现、响应与连续性。
- $L_{\mathrm{late}}$：后段的持续、终止与最终可见状态。

后段损失单独按有效目标归一化，使早段表现不能掩盖末段错误。监督器判断后段时保留前面的来源和作用信息。

例如，烟源停止后烟雾仍可以扩散；倾倒停止后杯内液体仍可以晃动；形变作用解除后材料可以恢复，也可能保留形变。监督依据过程与材料确定，合理稳定状态同样是有效答案。

时间分段只用于组织监督和分配损失。演化状态仍由原生 Wan 承载，C 保持完整条件表示。

## 8. 总目标与梯度归属

拟议总目标为：

$$
L=
L_{\mathrm{FM}}
+0.1L_{\mathrm{temporal\ FM}}
+\lambda_hL_{\mathrm{C,hard}}
+\lambda_sL_{\mathrm{C,soft}}
+\lambda_gL_{\mathrm{process}}.
$$

各项先按自身有效任务数或过程项数归一化；$\alpha_r$ 与各 $\lambda$ 属于待配置的训练权重，本文未将它们声明为已验证的最优值。

| 训练项 | C 消息模块、投影与对齐 | 语义读出器 | Wan LoRA | 教师／过程监督器 |
|---|---|---|---|---|
| C 硬监督 | 更新 | 更新 | 不更新 | 提供固定标签 |
| C 软监督 | 更新 | 更新 | 不更新 | 提供停止梯度的分布 |
| 生成过程反馈 | 更新 | 不参与 | 保留输入导数，此项不更新参数 | 反馈期间固定参数，保留视频输入导数 |
| FM + temporal FM | 更新 | 不参与 | interface 冻结，joint 更新 | 不参与 |

Qwen 的条件编码角色继续冻结。新目标训练 H/Q 如何组织和输出物理信息；文字分析本体的 SFT 属于另一项改动。

新增语义损失接入已有 interface／joint 阶段。若使用 verifier LoRA，沿用已有独立校准阶段；无需为逐轮 C 监督增加额外训练阶段。

## 9. 训练目标怎样组织

现有样本可以整理为以下训练目标结构。该结构是拟议的目标接口，不表示缓存中已经存在这些字段。

```text
sample_id
├── C 条件侧目标
│   ├── 初始事实问题与答案
│   ├── 原始请求问题与答案
│   ├── 带适用条件的物理依赖问题
│   └── 教师软答案分布
└── 生成结果侧目标
    ├── 实际片段中的可见过程
    ├── 来源、作用与响应关系
    ├── 过程对应的时间证据
    └── 后段持续、终止和状态目标
```

硬标签采用可确认的事实与关系。自动视频教师提供的观察和推断属于弱监督，按其内容使用软分布或过程目标。普通推理仍只使用合法的首帧与文字条件，真实未来只用于训练答案。

这套目标可以在现有样本上组织，原始缓存、历史日志与 checkpoint 保留。新增监督接入时使用新的训练修订。

## 10. 训练步数与本方案的关系

两个无 verifier Run 都完成 224 步、累积 4，总计使用 896 个训练样本，约占 3666 条训练池的 24.4%；联合阶段使用 640 个样本。对于新消息模块，这个学习量有限，训练不足是值得考虑的原因。

但当前配方中独立 C 物理监督的训练次数为零。增加原有训练步数能增加间接学习机会；本方案则明确增加每次更新所包含的学习内容。

本设计先将软／硬监督和生成反馈接入既有阶段。后续增加训练量时，应为这些目标提供充分的数据覆盖和重复学习机会，以过程生成表现判断收益，而非以 FM 接近零作为结束条件。
