Native 的意思是，演化状态留在 Wan 内部

C 提供条件，H 承担当前状态

C 是连续向量，可以理解为生成器随时读取的条件笔记。它不是写好的未来帧，也不是人工规则表。

H 是 Wan 当前的时空隐藏状态。同一组 C，会被不同时间、位置、网络深度和噪声水平下的 H 读取。接口让 C 选择当前状态的更新方式。

每 3 个 Wan block 注入一次；仅更新未来位置。系统没有独立的 M／S 未来状态展开。

概念示例，不是实测结果。

  1. 首帧显示容器和液体；文本要求继续混合。
  2. Qwen 整理接触、持续作用和未知条件。
  3. Wan 生成形态与颜色分布的变化。
  4. 训练检查过程是否持续、是否符合要求。
展开注入公式

m = Attention(H, C)

ΔH = gate(H, σ, a) × W_o[SiLU(W_h Norm(H)) ⊙ W_c m]

H_new = H + condition_strength × ΔH

m 是当前状态从 C 读取的信息。a 是连续局部可见变化强度，σ 是噪声水平。a 进入软门控，低强度不会关闭生成或复制首帧。对应实现。

三种“时间”，数的东西不同

81帧

视频时间

最终片段中的画面位置。VAE 把它压缩为 21 个 latent 时间位置；实际秒数由样本时间戳决定。

50步

去噪时间

普通推理从噪声得到视频的更新次数。每一步处理整段时空状态；训练反馈另用 4 步补全。

2轮

条件内部更新

复用 Qwen 后 4 层整理条件的次数。通常在 Wan 去噪开始前完成，不是逐帧运行 Qwen。

FM velocity 是去噪路径的导数。RGB 变化强度是可见变化的弱监督。二者都不能直接叫作物体运动速度。

反馈能到达 C，还需要方向有用

过程损失看怎样变化

覆盖全部 81 帧，在 1／2／4／8／16／32／64 帧跨度上比较有符号 RGB 变化。每个时间对独立归一化，保留后段的贡献。

常规训练从含参考未来的加噪 latent 得到视频估计。这属于训练监督。

verifier 看条件与过程是否匹配

先用参考视频、生成补全和过程缺失视图训练评分头；再固定评分头，通过生成视频把反馈传回 C。

冻结的 V-JEPA 读取覆盖首尾的 21 个双帧位置，同一上下文处理。它不是逐帧 RGB 过程损失。

v8 为什么强调“响应”

候选证据使用 tanh(f_t − f_0)，再扣除同一时间对的零响应读出。这个结构减少时间恒定的加性特征偏移带来的捷径。它不能保证任意冻结 RGB 视频都有恒定特征，也不把静止自动判为错误。评分实现。

为什么要固定评分条件

生成 C 可以接受训练或在线修正；verifier 的评分条件来自合法初始输入的固定编码。这样，优化的是候选视频对原始要求的符合程度，不是同时改动“答案”和“判题条件”。

为什么固定 Wan 仍然要经过它反传

只有经过“C 如何改变视频”这条计算关系，反馈才能到达 C。联合阶段 verifier 项不更新 Wan 和注入接口参数，但保留它们对 C 的导数。FM 和过程目标仍更新生成路径的相应参数。

4 步训练反馈和在线修正有什么区别

训练反馈从参考 latent 与噪声混合的状态开始，完整经过 4 步，对 C 映射和 Qwen LoRA 训练。在线修正使用正在生成的视频的一步干净估计，固定所有模型参数，只改变当前 C，供同一轨迹后续步骤使用。两者都不是最终 50 步视频的精确梯度。

现有证据与要回答的问题

2026-10-25 的真实模型短检查执行了三个训练阶段，验证了反馈能到达 C，以及参数更新归属符合设计。这个记录不证明完整训练后的视频物理质量已经改善。

  1. C 的内容有用吗？ 固定首帧与噪声，比较正确 C、关闭 C、替换条件后的 C；检查变化是否符合条件。
  2. 反馈方向有用吗？ 比较原始 C、梯度修正、等幅随机修正；分数升高和梯度非零都不够。
  3. 过程能持续吗？ 看中后段、材料与属性连续性、视觉质量，并在多个场景和种子上重复。
