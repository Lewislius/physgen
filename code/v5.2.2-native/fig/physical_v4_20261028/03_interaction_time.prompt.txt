(a) 从实际 PTS 建立时钟
“RGB PTS [B,81]” -> “减去首帧 PTS；映射 latent 时间块” -> two outputs: “τ [B,21] / 代表时刻” and “Δτ [B,21] / 时间间隔”.
Both -> “拼接 Fourier(τ), Fourier(Δτ), τ/D, log(1+D)” -> “[B,21,2F+2]” -> “clock MLP / (2F+2)→3072” -> “clock [B,21,3072]”.
One small timing example: “81 帧／24 FPS：τ_rgb[n]=n/24；首末跨度 D=80/24 秒”.
Separate purple box: “σ [B] / 扩散噪声；单独编码至 3072” with no merger that confuses σ and τ.

(b) C 条件化的全宽物理交互 F_interact
Inputs arranged clearly:
“u_cond / u_scope 各 [B,128,21,3072]”
“g_cond / g_scope 各 [B,128,3072] → 沿 T 广播”
“V_rule [B,128,3072] → 沿 T 广播”.
All feed “角色输入融合 F_mix / 5×3072 → 3072” -> “s [B,128,21,3072]”.
Separate green branch “C [B,128,4096]” -> “全宽调制投影 / 4096→2×3072” -> “γ, β 各 [B,128,1,3072]”.
s and gamma/beta -> “(1+γ) ⊙ Norm(s) + β” -> “[B,128,21,3072]” -> “交互 FFN / 3072→D_int→3072” -> “h [B,128,21,3072]”.
clock and sigma feed F_mix as additional state/time conditioning (broadcast across R); keep them separate from the five role inputs. Short note: “D_int 为待定的内部宽度；调制是全宽特征计算，不是运动强度”.
