本次以图示将 V4 中尚未展开的接口具体化；并不声称新模型代码已实现：
- 物理 query 独立线性投影 3072->3072，空间/时间条件属于 C 分支。
- F_mix 显示五路 3072 宽内容输入的融合，另接时间/噪声条件；交互 FFN 中间宽度 D_int 未定，不编造数值。F_out 显示两路 3072 状态融合至 3072。
- C 调制以 4096->2×3072 表示 gamma/beta 两个全宽向量；它是最终执行接口的一部分，不提前压缩 Qwen 推理。
- clock 输入宽度 2F+2，F 是单组 Fourier 编码宽度，尚未固定；输出 3072。
- C-only 语义读出每批轮换一个注入层，将其实际三组 K/V 展平为三组 3072、concat 到 9216，再经全宽 bridge 到 4096。此处显式采用轮换层读出，避免同时拼接十层导致不必要的宽度膨胀。
- Q 推理轮数 K 未定；图中不沿用旧实现的随机 MessageBlock，不把旧 2 轮配置画成新模型已验证超参数。
- 首帧几何映射 G=[B,P0,P]，本例 P0=P=390，但对应必须来自预处理几何，不因为 token 数相同就假设索引相同。
