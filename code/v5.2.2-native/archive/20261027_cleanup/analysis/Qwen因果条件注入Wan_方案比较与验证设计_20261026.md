**Qwen 因果条件注入 Wan 的方案比较与验证设计**

日期：2026 年 10 月 26 日。范围：设计建议，尚未实现或提交对应实验。

**建议优先验证 C 驱动的原生归一化调制，再验证作用于 Wan 内部投影的条件 LoRA。** 两者都能让 reasoning latent 参与原生 Transformer 子层的计算。当前证据还不足以判断哪种接口能提高本项目的物理过程质量，因此推荐顺序依据实现适配性、训练成本和可诊断性，而不是已经测得的效果排名。

这次比较保留 Qwen reasoning、集中条件 C、连续局部变化强度和 verifier 到 C 的反馈。VJEPA2 保持停用；视频状态仍由 Wan 演化，不增加独立的未来预测器。Qwen 是否完全冻结是另一个实验因素，不与本次接口比较同时改变。

**当前接口已经包含状态相关的低秩变换。**

当前 C 最多包含 128 个 3072 维 token。Wan 在第 3、6、9……30 个 block 完成后，共执行 10 次条件注入。每次先用当前待生成帧的隐藏状态和视频时间读取 C，再通过 64 维的状态与条件乘性交互产生残差：

\[
m_i=\operatorname{Attention}(Q(h_i,\tau_i),K(C),V(C))
\]

\[
\Delta h_i=g_i\,U\left[\operatorname{SiLU}(S s_i)\odot Tm_i\right],
\qquad h_i\leftarrow h_i+\Delta h_i.
\]

这里，i 是视频时空位置；s_i 来自当前隐藏状态及视频时间的归一化表示；g_i 还读取噪声水平和预测变化强度。视频时间 τ 与去噪噪声水平 σ 是两个独立变量。首帧对应 token 不接受这项直接残差，但仍参加 Wan 原生注意力计算。

这已经是一种由条件选择作用方式的低秩算子。单纯把同一结构称为“动态 Adapter”或“超网络”，不构成新的注入方案。值得比较的改变是：C 影响哪些原生计算，以及局部状态如何决定其作用。[当前条件接口](/home/liuzhirui/Project/physGen/code/v5.2.2-native/physgen_native/conditioning.py:63)、[原生 block 与注入的执行顺序](/home/liuzhirui/Project/physGen/code/v5.2.2-native/physgen_native/generator.py:64)

| 候选方式 | C 实际控制什么 | 对当前项目的潜在价值 | 主要限制 | 建议顺序 |
|---|---|---|---|---|
| 原生归一化调制，AdaLN / FiLM | 自注意力与 FFN 输入的通道缩放、偏移，以及残差门控增量 | 复用 Wan 已有接口；不要求视频 token 先从 C 中检索消息 | 条件汇总可能损失细粒度关系；全局调制的局部选择性需要验证 | 第一项 |
| 条件 LoRA | 原生 Q/K 或 FFN 投影中的低秩变换系数 | 可以直接改变视频 token 之间的信息交互和状态变换 | 更容易扰动预训练行为；仍依赖 C 的有效内容和正确监督 | 第二项 |
| 视频与 C 联合注意力 | 两类 token 在层内双向交换信息 | 让条件表示结合当前视频状态再参与计算 | 对预训练 Wan 改动较大，需要处理模态投影、位置编码和条件漂移 | 后续探索 |
| 现有局部读取加原生调制 | 局部细节通过现有读取传递，整体条件另控制原生子层 | 同时保留细粒度条件读取和较直接的调制路径 | 增加参数和分支，需证明收益超出单一接口 | 单项对照后再考虑 |

**第一项候选让 C 调制原生子层的输入和残差。**

Wan 的 block 本身已有六组调制量，分别作用于自注意力与 FFN 的输入偏移、输入缩放和输出门控。它们当前由噪声嵌入与层参数形成。因此可以在这些量上增加来自 C 的增量，保留原生值。[Wan block 实现](/home/liuzhirui/model/Wan2.2/wan/modules/model.py:180)

先将 C 汇总成较小的表示 c，再结合层标识与 σ，生成每层的 Δγ、Δβ、Δg。为了保留当前的状态依赖和连续变化强度，再使用局部软系数 κ_i；它读取当前状态、视频时间、σ 和变化强度，不执行隐藏状态对 C 的交叉注意力。对一个原生子层，可写为：

\[
u_i=
\left(1+\gamma_0+\kappa_i\Delta\gamma_l(c,\sigma)\right)
\odot\operatorname{LN}(h_i)
+\beta_0+\kappa_i\Delta\beta_l(c,\sigma)
\]

\[
h'_i=h_i+
\left(g_0+\kappa_i\Delta g_l(c,\sigma)\right)
\odot F_l(u)_i.
\]

F_l 表示原生自注意力或 FFN；γ₀、β₀、g₀ 包含 Wan 原有调制。自注意力仍读取整组视频状态，公式中的下标 i 只表示其输出位置。新增调制进入子层内部，能够在该子层计算之前改变特征使用方式。

FiLM 以条件生成特征缩放与偏移；DiT 在其类别条件图像生成实验中比较过多种接口，adaLN-Zero 表现优于所测试的 cross-attention 方案。这支持把调制作为候选，但这些实验没有验证 Qwen reasoning latent、冻结的 Wan 或视频物理过程。[FiLM 原论文](https://arxiv.org/abs/1709.07871)、[DiT 接口比较](https://arxiv.org/html/2212.09748v2#S3.SS2)

针对当前项目，第一版设计应满足以下条件：

- 新增调制输出从零开始，保留 Wan 原有噪声调制和残差通路。不能把原生 block 的门控整体清零。
- C 的汇总可用少量可学习查询读取其全部 token；查询不来自视频隐藏状态。这使纯调制版本具备独立于现有 Q/K/V 读取的条件路径。汇总向量不预设为“温度槽”“速度槽”等物理变量。
- 局部变化强度只参与软调节。强度接近零时，原生生成仍然工作，新增路径也不被硬阈值关闭。
- 首帧 token 的新增调制置零；明确的关闭条件操作应恢复没有新增调制的行为。需要防止带偏置的小网络在 C 为零时仍产生隐含条件。
- 第一轮沿用相同的 10 个层位置，避免把注入位置数量的变化混入接口比较。调制参数不按每层分别建立庞大的全维 MLP，可用共享小网络与层标识控制规模。

局部选择性是这一方案最需要验证的地方。共享的通道调制应用于不同隐藏状态时会产生不同结果，但这不保证它能够区分火焰附近的纸张和无关背景。局部门控提供额外适应能力，仍需要通过生成结果证明。

**一个数值示例可以说明调制如何依赖当前状态。**

假设只观察归一化隐藏状态中的两个通道，纸张区域为 [0.8, 0.3]，背景区域为 [0.02, 0.6]。C 产生缩放增量 [0.25, 0]，暂时令偏移为零、κ 为 1，则进入下一子层前的特征增量分别为：

| 位置 | 原特征 | 缩放造成的增量 |
|---|---|---|
| 纸张区域 | [0.8, 0.3] | [0.20, 0] |
| 背景区域 | [0.02, 0.6] | [0.005, 0] |

相同的调制系数可以对不同状态产生不同幅度的作用。这是演示用数字，不是当前模型测量；两个通道也没有被识别为真实的“可燃性”或其他物理量。后续 Wan 仍需学会把这些特征变换转化为正确的视频过程。

**第二项候选让 C 决定原生投影中的低秩变换。**

普通 Wan LoRA 在训练后共享同一组适配权重。条件 LoRA 可以进一步根据 C 和 σ 改变适配方式。一个适合小规模比较的受限版本是：

\[
a_l=H_l(c,\sigma),\qquad
\Delta W_l=U_l\operatorname{diag}(a_l)V_l.
\]

\[
y_i=W_l^{\mathrm{base}}h_i+
\kappa_i U_l\left[a_l\odot(V_lh_i)\right].
\]

U、V 是训练得到的共享低秩基，a 是随输入条件和去噪阶段变化的系数；若基线已有普通 Wan LoRA，将它作为共同的基础部分保留。κ_i 继续提供局部状态和变化强度的软调节。这种实现只生成少量系数，无需为每个样本生成完整的 3072×3072 矩阵。

优先考虑两个位置，并分别消融：

- **原生 Q/K 投影**：C 影响视频 token 如何彼此匹配，从而改变同一去噪步骤内的时空信息交互。这里的 Q 和 K 都来自视频，C 负责调节投影。
- **原生 FFN 投影**：C 影响当前特征如何被变换，作用于每个位置的状态更新。它与 Q/K 的关系匹配作用不同。

当前接口本身已有乘性低秩算子，因此这里的主要变化是进入原生投影、在原生注意力或 FFN 内发生作用。不能仅凭“动态权重”这个名称断言表达能力或效果必然更强。

TC-LoRA 已研究依据条件和扩散时间生成 LoRA 权重。其具体实验针对深度条件图像生成，论文将视频扩展列为后续方向；不能据此声称它已经证明视频因果一致性改善。上述共享低秩基加条件系数的设计，也比其直接生成 A/B 矩阵的方式更受限。[TC-LoRA 方法与实验范围](https://arxiv.org/html/2510.09561v2#S3)

Wan 的 Q/K 在投影后还有 RMSNorm。只把整个 Q 或 K 乘一个正标量，其效果通常会被归一化大幅抵消；有效的条件化应改变通道结构或方向，同时保留原生 RoPE 与 Q/K 归一化。新增分支还应避免将输出矩阵和全部条件系数同时初始化为零，以免双方都得不到启动学习所需的梯度。

**火焰与烟雾的例子说明应期待什么变化。**

以“火源接触纸张，纸张可能被点燃”为例，C 应表达可见接触、材料和后续发展的依赖。条件调制可以改变 Wan 对相关状态特征的处理；条件 Q/K 可以改变纸张位置与火源、相邻纸张及其他时间位置的信息交互；条件 FFN 可以改变纸张已有状态向炭化、形变等外观状态的变换倾向。

这些都是预期学习行为。代码不应预设“某个头负责传热”，也不能把注意力权重解释成热传导量。正确生成还取决于初始状态、条件的可靠性和训练监督，不能要求所有纸张都立刻燃烧，或把更大的火焰一概视为改善。

对于烟雾，C 可能表达“持续出现、逐渐扩散、局部变淡”的过程要求。两个候选接口应允许 Wan 在整个时空状态中表达这种分布变化，不需要把烟雾转换成被跟踪的刚体或预先给定轨迹。检验重点是扩散、出现与消散是否连贯，以及背景是否保持合理。

**联合注意力可以探索，但当前不宜作为第一项改造。**

联合注意力使视频 token 与条件 token 在同一层内交换信息，两类 token 都可以成为 Query。MM-DiT 已使用模态各自的权重实现图文双向信息流。[MM-DiT 原论文](https://arxiv.org/abs/2403.03206)

迁移到当前 Wan 时，需要适配其已训练的投影和视频位置编码，并处理高噪声视频状态使 C 偏离原始要求的风险。如果探索，应保留原始 C 作为锚点，层内条件更新只服务当前 Wan 计算，不发展为独立的未来状态预测器。其改动范围和训练需求使它适合放在较小接口的对照之后。

仅交换现有注意力的 Q 与 K/V，会得到“每个 C token 对视频的读取结果”，输出长度也变成 C 的长度；还需要把结果写回视频 token，才能影响视频生成。因此交换 Q/K/V 本身不是完整的替代注入接口。

**判断是否更有效，需要把接口能力与条件质量分开。**

历史 66215 评估使用的是 v8 的第 16 步 checkpoint，条件与连续 reasoning 能改变输出，但尚未建立稳定的物理效果优势。它不足以证明当前问题来自 cross-attention，也不能排除训练量、C 的内容和反馈质量的影响。[已有配对结果](/home/liuzhirui/Project/physGen/code/v5.2.2-native/analysis/results_66215_20261026/paired_summary.json)

如果 C 本身包含错误的依赖，增强注入会更有效地传播错误；如果 verifier 给出错误方向，换接口也不会自动修复监督。因此比较接口时，Qwen 编码、reasoning 轮数、C 的输入来源、训练目标和 verifier 版本应保持一致。

建议先比较三个单一接口，只有单项出现明确收益后再评估组合：

| 对照 | 注入方式 | 主要回答的问题 |
|---|---|---|
| A | 当前局部读取与状态条件算子 | 现有基线达到什么质量与成本 |
| B | C 驱动的原生调制，保留局部软门控 | 不通过现有 H→C 检索，是否更容易学会使用 C |
| C | 条件 LoRA，分别检验 FFN 与 Q/K 位置 | 改变原生状态变换或关系匹配，哪项有收益 |
| D | 最有收益的单项与现有局部读取组合 | 保留细粒度读取是否进一步改善结果 |

共同 Wan、Qwen 和 C 映射的初始化、训练样本顺序、梯度累积与目标权重保持一致。新旧接口需要等预算的训练比较；将随机新接口直接放入已经训练的旧 checkpoint 做一次推理，只能检查兼容性。若使用已有接口权重迁移，需单独记录迁移方式和之前的训练预算。除优化步数外，同时报告可训练参数量、峰值显存和实际 GPU 时间。

完整视频比较固定首帧、T5 输入、采样器、种子和去噪步数，覆盖多个独立场景与种子。案例应包含火焰、烟雾、液体、波浪、形变、出现与消失等过程，继续使用现有数据。训练目标和注入接口分开改动；未来若实施参数结构变化，采用新的 checkpoint revision，保留既有快照。

条件干预应至少包括正确 C、关闭 C、语义等价改写，以及与首帧相容但改变过程要求的条件。后者需要同步处理相关条款与 reasoning，避免残留旧条件；原生 T5 也不能与新要求冲突，可在这类机制检查中固定为中性的场景描述。不同要求可以有多个合理未来，不能把同一条真实未来当作所有干预条件的唯一像素答案。

评估应分别回答以下问题：

1. **C 是否包含有效信息？** 相容的过程要求能否被区分，等价表述能否保持一致；错误或缺失的输入依赖是否在输出前就已存在。
2. **注入是否产生有选择性的作用？** 改变过程要求后，相关生成行为是否按要求改变；无关背景是否基本稳定。记录梯度、调制量和输出敏感性用于定位问题，不把它们当成物理正确性的证明。
3. **完整生成是否改善？** 检查语义遵循、过程合理性、后段连续性和视觉质量，使用独立评价与盲看配对视频。按案例汇总多个种子并报告不确定性，避免把同场景的多个种子当成多个独立场景。

保留 verifier→生成视频→C 的可微反馈，但不把训练使用的同一个 verifier 分数作为唯一成功标准。更大的残差、更明显的变化、更低的单步恢复误差或非零梯度，都不能替代完整生成的验证。

工程上先做 B 的理由是 Wan 已有相应调制入口，便于保持预训练行为并隔离条件路径；C 提供更直接改变时空交互的候选，需要更细的分位置比较。所有实验都应在现有单 GPU 配置和环境内评估实际成本，不预先承诺训练时长或质量提升。
