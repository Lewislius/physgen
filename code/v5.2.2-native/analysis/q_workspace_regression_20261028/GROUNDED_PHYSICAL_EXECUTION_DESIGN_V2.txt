2026-10-28：有来源的 latent reasoning 与物理关系执行设计

历史方案提示：用户随后明确要求从官方预训练基础模型开始新的项目训练、完全不使用 verifier。因此本文关于继承 66443、保留旧 Q 分支和视频评分/读出反馈的建议已被撤销。后续方案以 PHYSICAL_BLOCK_FROM_BASE_NO_VERIFIER_V3.txt 为准，本文保留用于记录设计变化和已有证据。

状态：基于已有代码、训练记录和视频的设计修订，尚未实现或训练新模型。本文件保留先前的事实分析，替代 CONCLUSIONS_AND_DESIGN.txt 第 6–8 节中仅在旧 Q 上添加语义残差的架构建议。新方案不能被表述为已经改善了视频质量。

目标：同时获得物理现象/因果关系准确性与画面/运动稳定性。允许有物理依据的快速变化、形变、破裂、分合、扩散、出现和消失；不把泛化任务缩窄成对象身份保持。初始生成函数采用 66443 / v30 / final224 的完整 checkpoint，而不是原 v11 初始化器。

一、这次必须修正的判断

1. 首帧空间证据、隐空间物理推理、当前视频状态中的执行，是三个不同问题。增加 token 差异、增加隐藏宽度、加长分析提示词，均不能单独完成这三件事。
2. 减少自由生成的文字分析，不等于删除 Qwen latent reasoning。应保留并训练后者，同时去掉“必须先生成一段正确的文字分析，后续才能正确生成”的依赖。
3. H 和 Q 都需要认真设计。原有旧 H 的部分表征诊断更敏感，并不证明其完整视频优于旧 Q；不能据此直接宣布只用 H。Q 的近同质化也不是 Q 范式原则上无效的证明。
4. 独立 K/V 是必要考虑的接口改进，但它本身不是物理模块。专用设计必须改变“何种证据被读取、响应怎样依赖当前状态、监督如何落实到视频”这条计算路径。
5. 4096 与 3072 的选择，应按计算职责决定：Qwen 中的理解与 latent reasoning 留在 4096；Wan 当前状态中的条件读取、响应形成与写入在 3072 完成。不能把整个执行过程都提前算成一个静态 C。

二、已有证据限定了什么结论

五个运行的 FM + temporal FM 目标和主要训练/推理日程相同。新版条件梯度没有比旧 Q 更大，alignment 增益也接近；现有记录不支持把退化归因于梯度爆炸或该增益突然增大。共享的数据覆盖比例与参数总量不是本次相对退化的解释。

旧 Q 在已有四个验证输入上的最终 token-centered RMS / total RMS 约为 0.00267。相同 K/V 的 attention 输出不依赖 query；近同质的 K/V 因而可能形成近似公共修正。这个机制有数学依据，但不等于已经证明新版全部失稳来自此处，也不等于旧 Q 的物理过程正确。

P01 的车/垃圾桶形体混合、P02 的未接触先响应与颜色改变、P05 的斜坡/滑块作用错位，要求解决关系内容与执行对应。仅降低运动、约束多样性或复制旧视频不能满足目标。

四个新版从原始初始化器出发，并未继承 66443 的完整已训练生成函数。因此下一版明确继承完整旧基线，不再把“相同初始预训练 Wan”当成“继承旧 Q 的生成稳定性”。

当前 message 路径冻结 Qwen、detach memory，之后的 MessageBlock 是独立训练的 cross/self/FFN，而不是 Qwen 已训练的推理层。保持 4096 宽度不等于已经利用了 Qwen 的原生 latent reasoning。代码中的 v14/native reasoning 工具提供了可复用的计算原语，但不意味着 v14 成品已被证明更好。

三、首帧网格：确切含义与用途

正常生成时，Qwen 输入的是首帧。当前 native 832×480，视觉 patch=16，空间合并=2，因此输入网格为 30×52，合并后为 15×26，共 390 个视觉 token。image 模式为满足 temporal_patch_size=2 复制同一图像；这不产生第二个时刻的运动证据。

Wan 的 VAE 空间 stride=16，patch=2，单个 latent 帧也有 15×26 个空间 token。相同名义网格可建立“来自原图同一区域”的初始对应；不能把它当成语义特征相等、精确接触几何相等或后续空间位置不变。

这份证据不足以给出：实际初速度、质量/摩擦等未提供参数、遮挡后的状态、细小接触点、未来事件时间与位置。32×32 是名义采样单元，不是局部独立感受野；Qwen 和 Wan 的特征都含上下文。

保留的信息应包括视觉 token 的行列/归一化坐标、来源类型、原始文本跨度、合法条件的来源，以及未知项。坐标使用实际预处理后的几何变换和 token 排列，不假定所有分辨率或裁剪均同构。

一种直接用于接口的设计是：关系表示在 H 中读取初始证据，得到可学习的来源关联 A[r,i]；在相同初始图像区域的 Wan 首帧 hidden 上作对应读取：g[r,l] = sum_i A[r,i] h[l,0,i]。这使来源信息进入 Wan 自己的特征坐标系，而非要求 Qwen 特征与 Wan 特征天然相等。

A 是需要学习的来源关联，不是物理因果真值或未来运动路径。它只提供初始参考，后续作用位置必须读取当前 Wan 状态。对画外来源、仅文本给出的条件和不可见前提，来源表示必须允许无对应可见区域，不能强行绑定某个 patch。流体/气体的关联可以覆盖区域，分裂/合并可以改变当前响应范围，不引入对象 ID 或跟踪轨迹。

四、Qwen 幻觉与 latent reasoning 的分工

现有四行提示词已经要求区分观察、要求和未知，但 P02 分析仍把两球静止写成观察，并要求额外击打红球。单帧不证明静止，而原始要求已包含红球滚动。这直接说明“提示词写了约束”不等于模型遵守约束。P05 的文字即使区分了滑块与斜坡，视频仍可能移动斜坡，说明文字正确也不等于执行正确。

新主路径直接编码首帧与原始请求，不再必须生成自由文字分析、复杂事件图或绝对时间表。既有自动 clauses 的 mixed/both 来源标签也不能作为可靠真值，来源需要从原始输入重新明确。

原生 Qwen latent reasoning 继续承担多条件结合、空间关系、过程依赖与未知信息表达。生成侧 knowledge LoRA 接受物理监督；不是用未经训练的多轮随机 Transformer 代替 Qwen 推理。关系可用连续隐表示分布式编码，不要求每个槽绑定一个对象、一个物理类别或一条写成文字的规则。

训练中的物理问答/简短解释用于约束隐表示；这些问题、正确答案和真实未来不会成为普通生成时的额外输入。可解释文字是训练读出，不是必须执行的自由生成程序。隐表示仍可能出错，不能把 latent 形式当作无幻觉保证。

五、H 与 Q 的完整设计选择

H 路线：
  保留首帧视觉与原始请求的内容 hidden、原始跨度/来源/位置，并使用 Qwen 已训练的层做内容相关的 latent refinement。计算发生在匹配的 4096 维原生 hidden 层级；不能直接把最终归一化 hidden 当作原始词向量重复送入第一层。
  优点是来源可寻址、信息不必先全部挤入匿名槽，较容易监督“依据是什么”。缺点是文本长度与措辞可影响消息数量，保留内容不自动等于提炼物理依赖；文本 token 与视觉 token 在原生因果 mask 下的可见上下文也不同。图像前缀 hidden 不能被宣称已经读过后面的请求。

Q 路线：
  保持 128×4096 工作空间，以首帧/文本 H 为持续可读的证据记忆。通过原生 Qwen prefix KV 和原生层执行初始 grounding 与后续 refinement；循环反馈使用匹配输入空间的全宽映射。必须保留 native norm、mRoPE、层级和可微前缀的正确关系。
  优点是固定计算容量、可反复综合多处证据，适合作为集中的物理推理工作空间。缺点是存在公共分量积累、来源混合和忽略部分条件的解。解决方式是最终 Q 的物理语义和真实执行训练，而非槽正交、熵最大化、随机 identity 或强制每个槽不同。

本轮推荐的主线是 Q 推理 + H 可寻址证据：
  H 负责证据与来源，Q 负责集中进行 latent reasoning；物理执行层读取 Q 的关系信息，并利用 H 的来源关联和 Wan 的当前状态完成落地。H 不单独输出一个可以绕过 Q 的物理响应分支；训练专用语义读出也不能通过直接读取原始 H 而绕过 Q。
  这与把 H、Q 简单拼接再做普通 attention 不同：两者分别承担证据定位和物理关系形成。C 是包含关系表示、来源记忆及关联的条件结构，不再仅指一个丢失全部来源的匿名 128×3072 张量。

纯 H 是合理的备选设计，不因本轮推荐组合而被判为无效；纯 Q 也不能因旧槽趋同就被否定。目前证据支持的是两者各有缺口，而不是哪一种新方案已经有视频效果优势。不安排 H/Q/多种注入/多种损失的笛卡尔积实验。

六、4096→3072 的具体接口

知识理解、证据结合、Qwen latent reasoning：4096。
与当前 Wan hidden、真实时间共同计算“此刻如何响应”：3072。

提前 P:4096→3072 再做全部 reasoning，会丢失部分通道并失去直接复用 4096 原生 Qwen 层的条件；若随后新建随机 3072 Transformer，本质是在另训一套推理算子。反过来，仅把随机模块加宽到 4096 也不会产生原生语义。宽度选择的依据是预训练算子的复用与计算职责，不是数值越大越好。

本轮建议在接口处用 C 专属投影完成最后的降维：
  K_condition[l] = W_condition[l] R,     4096→3072
  K_apply[l]     = W_apply[l] R,         4096→3072
  V_relation[l] = W_value[l] R,         4096→3072
其中 R 是 Q 路线的最终关系状态，或 H 路线的内容相关关系表示。两个 K 的区别是“到当前状态读取何种条件”和“将响应写向何种当前内容”，不是额外的自由文字字段。

这些映射不同于原生文本 K/V。也可用共享 P 后接各层 K/V 参数化；但全部线性层共用 P 时，各层都会丢失 P 的共同核空间。直接映射让不同用途/层自行选择保留信息，代价是参数和显存增加。采用直接映射是新接口的设计选择，不能反过来宣称当前退化已经被证明是 4096→3072 的秩损失造成。

只比较普通一组 K/V、10 个注入层：独立直接 4096→3072 K/V 约 2.517 亿参数；共享 P 加 3072 K/V 约 2.013 亿，差约 5033 万。专用条件/作用双 K 另有成本，必须在实现预算中明确计算，不把完整方案称作轻量接口。LoRA 是参数更新约束，不等价于把 C 压成低维状态。

七、专用物理执行层究竟做什么

旧式一次读取：当前 query 对静态 C 做 attention，然后写入结果。它可以按内容检索，却没有显式区分“读取该关系的当前前提”与“形成该前提下的响应”。旧注入已经有分开的 text/C softmax，不能把再拆 softmax 当作新贡献。

拟议执行层在现有 Wan 注入位置内部完成三个步骤，无独立未来状态和额外 rollout：

  1. 来源结合。将 R 所依赖的初始视觉/文本证据映射到 Wan 的初始参考表示 g；来源不可见时保留文本/未知来源，不虚构图像位置。
  2. 当前条件读取。用 K_condition(R,g) 作为关系查询，从当前 denoising 状态中读出全宽 u[r,t]。空间多头读取可以覆盖接触两侧、来源/接收区域或一片介质；已由 native Wan 时空 attention 处理的 hidden 提供上下文。
  3. 条件相关响应。共享的全宽执行算子 F_phys 用 u、关系内容、真实时间和噪声阶段形成当前 K_apply_t 和 V_response_t，再由当前位置 query 读取并写入 Wan。

简化表达（省略层、头、batch 与归一化）：
  a[r,t,p] = softmax_p( <K_condition[r], q(h[t,p])> )
  u[r,t]   = sum_p a[r,t,p] LN(h[t,p])
  (k[r,t],v[r,t]) = F_phys(K_apply[r], V_relation[r], u[r,t], g[r], clock[t], sigma)
  m[t,p]   = Attention(q(h[t,p],clock[t]), k[:,t], v[:,t])
  h_out    = native_block_update + O_C(m)

F_phys 采用 3072 维残差计算，允许完整有符号响应，包括不新增某种作用；不能用一个“运动强度 a”代替它。不新增 C 作用并不冻结视频，native Wan 仍然推进整个可见过程。初始参考不固定未来作用位置；每个 denoising step、层与视频时刻均读取当前状态。

扩散模型高噪声状态不是确定的真实世界状态。这里读取的是当前生成假设中的证据，F_phys 需要知道 sigma 并学习不确定性，不能在高噪声时用硬接触判定去触发事件。sigma 与真实视频时间是两种不同变量。

物理专用性来自：关系内容的物理监督、条件读取与响应形成的分工、初始来源到当前状态的绑定，以及完整生成过程的物理训练。把模块命名成 physics，或对同一 token 做几次线性变换，都不自动赋予它物理能力。

例子：
  碰撞：当前接触条件改变响应；不能因为 caption 提到碰撞，就提前把碰撞后的状态写入。
  滑动：读取当前支撑与接触状态，响应应落在滑动部分，支撑结构的变化取决于其实际条件。
  液体/气体：读取来源、介质/边界与当前分布，响应可覆盖、扩展或分裂区域，不要求可追踪对象 ID。
  波：区分扰动传播与介质整体搬移；不能把画面中的纹理传播直接解释为物质整体飞走。
  熔化/破裂：条件成立时允许形态与拓扑变化，不能用普遍刚性约束破坏合法物理现象。

八、与原生文本及 Wan LoRA 的参数关系

原生 T5/text embedding、文本 cross-attention Q/K/V/O 及其继承的 LoRA，在该主方案中保存基线参数；C 使用自己的投影、key norm 和输出 O_C。Wan 的 self-attention LoRA 在 joint 阶段学习执行，原有时空 attention/RoPE 保留。

保留原生 query 作为查询基础，真实时间修正在 C 执行支路中形成；若增加 C 侧查询适配，其参数也归 C 支路，不让 C 的语义适配直接改写原生文本 K/V。hidden 改变仍会影响后续文本 attention，所以“参数分开”不等于两路输出在整个网络中完全独立。

这仍是训练 Wan 执行 C：物理梯度更新 C 写入及 Wan 时空处理的 LoRA，而非只让 C 迎合永远冻结的执行器。没有必要仅因 Wan 使用 LoRA，就自动解冻所有文本 K/V。旧参数保持与可学习执行的职责要明确。

九、真实时间如何接入

保留 native Wan 的视频位置 RoPE 与 diffusion timestep。新增实际秒数 tau、相邻时间间隔 delta_tau、要求的总时长，进入 C 支路的 query/F_phys；latent 时刻依据 VAE 的真实时间对应和 sample times 构建，不使用不恰当的均匀 linspace 替代元数据。

不能把时间归一化到 0–1 后丢失真实时长，否则 1 秒与 5 秒相同帧数的过程仍会混同。也不能将原生 RoPE 的帧序号直接替换为秒数，破坏已有时序表征。

单帧与文本不能唯一确定的碰撞秒数不由 Qwen 编造；接触后的响应阶段由当前状态读取。隐消息不是物理力或速度，不通过简单乘 delta_tau 宣称实现了动力学积分。实际时间只提供学习物理节奏所需的信息，效果仍须由真实时标的数据训练。

十、有效监督：保留少数有明确职责的目标

总目标：L = L_FM + 0.1 L_temporalFM + lambda_C L_C + lambda_E L_execution。

1. FM 与 temporal FM：保留真实训练视频的生成监督和跨时刻误差约束。temporal FM 的目标是去噪向量场误差的时间差分，不是视频速度，也不是直接的接触/传播监督。再加一个等价 latent 帧差 MSE 没有明确新增信息，故不加。

2. L_C：对实际可注入表示的物理问答/简短事实读出。
   在 Q 路线，只从最终 Q 所生成的接口 K/V（必要时轮换一个注入层）及中性问题读取答案，不能再访问原始图像、caption、H 旁路或标准答案。训练专用全宽 readout 接冻结语言解码器。H 路线用相应最终接口表示。
   语义目标覆盖：观察与要求的区别；作用条件与响应；来源/受影响部分；持续与终止条件；哪些信息未知；本过程允许与不允许的形态变化。
   例如 P02 的原则是：图像不确定速度，滚动来自请求；碰撞引发的响应需要相应接触；不能凭空增加一次击打；无对应物理过程时不应任意改变球的材料外观。例子用于说明监督定义，不把 demo 输入转入训练集。
   L_C 梯度穿过接口映射、latent reasoner、生成侧 Qwen LoRA。不能继续使用 message 模式下的 no_grad/detach 后宣称训练了 Qwen 推理。最终 C 可读不证明 Wan 会执行，因此下一项不可省略。

3. L_execution：针对模型实际生成过程的具体物理事实。
   用实际生成视频回答中性过程问题，与证据支持的目标关系计算可微监督，例如接触/响应顺序、变化发生在哪个区域、来源与扩展是否相连、何种形态变化有依据。监督正常持续与合法变化，既不奖励静止，也不把所有形变视为错误。
   视频读出器得到视频、真实时间和问题，不把完整期望答案或自由分析文本作为视觉事实提示，以降低照着文本猜答案的捷径。监督不限于一个整体 supported 分数。
   梯度经过解码器、完整采样过程，进入执行层、C 专属 K/V/O、Qwen latent reasoning，以及 joint 阶段的 Wan self-attention LoRA。必须同时教会写消息和执行消息。
   使用从噪声出发的采样过程，覆盖部署的 CFG/shift/时间范围。若使用短轨迹近似，要明确它与 50 步推理不同；不能把真实未来加噪的一步重建当成已训练完整生成物理性。不要把 CFG 向量场误当普通 FM target 直接回归。

L_C 和 L_execution 复用同一组有证据来源的物理依赖，但分别约束“条件中确实含有信息”和“视频确实落实了信息”。不再为每个内部张量加一个看似丰富的独立损失。

十一、监督来源与 Qwen 幻觉必须正面处理

不能让同一个未经纠正的 Qwen 自行编一段关系、再给自己的关系打高分，便称为有效物理监督。要在现有 wisa_4000 上建立独立训练标注 sidecar，保留原缓存与分割，标明直接可见事实、原始请求、条件性物理知识及未知项。真实片段提供过程发生的证据；物理解释与反事实依赖必须和可见事实区分。

用于 C 的目标必须由合法首帧/文本及适用物理知识确定，或明确为条件性结论；不能把未来视频揭示的唯一轨迹/碰撞时间强塞进静态 C 的真值。未来视频可用于执行监督与视觉读出器训练，不能进入普通推理条件。

也不能默认真实训练视频完全物理正确，或默认旧 Q 视频是物理教师。未知参数不凭空赋值；画外来源、开放系统、光照变化不套用简单的可见总量守恒或像素颜色恒定。标签制作与纠正是训练工作本身，不能由加长提示词取代。

视频读出器本身也必须接受上述可核实事实的训练，不能只换一段提问便假定它识别接触与先后顺序已经可靠。可在 interface 期间用独立的 reader 适配器更新处理带事实标注、已 detach 的视频；进入生成器的执行更新时冻结 reader 参数，但保留对视频输入的导数。reader 的事实学习与生成器的物理目标分开归属梯度，避免双方共同把错误答案变得容易。没有可靠事实标签时，不能用当前模型自评替代这部分训练。

执行读出仍使用已有原生 832×480、每三帧加末帧的 28 帧观察；它不能提供对每个 RGB 瞬时伪影的完备保证。真实视频 FM/temporal FM 及基线生成先验仍承担密集视觉与时序学习。不能把一个 VLM 语义损失包装成已解决所有几何连续性。

十二、为什么能以旧基线稳定性为起点，同时学习新的物理变化

完整继承 66443 conditioner、alignment、Wan LoRA 和采样设置，旧 Q 路径作为继承生成函数的一部分保留。新增的 H/Q latent reasoning 与专用执行层使用独立写入，最后 O_C 零初始化，其余读出与 K/V 正常初始化。初始新模型的生成函数因此与旧基线相同（正常浮点/后端差异另论）。不能把所有层都置零导致学习路径失活。

旧 Q 的公共修正不是新关系表示的训练目标。新分支允许完整有符号修正，Wan self-attention LoRA 也参与 joint 学习，所以它有能力改变旧版错误的物理现象。不会对旧版所有输出施加强匹配来冻结其错误。

零初始化仅保证起点，不保证训练后稳定。之后的稳定性由真实视频生成学习、过程相关的保持/变化监督及训练正确的条件执行共同获得；不能靠限速、减小全局强度或统一刚性约束来宣称解决问题。

完整函数继承还有一个必须说清的边界：保留的旧 Q 基线分支仍含原来的四行文字分析，且使用冻结的原始 Qwen 角色；新增物理推理分支不再依赖这段分析，并使用独立生成侧 LoRA。不能同时宣称“严格保留旧函数”和“已从整个系统移除旧文字分析”。前者服务于稳定起点，后者若以后要做，需要另行处理函数迁移；本方案不把这项额外迁移列成当前必要阶段。

十三、训练与实现边界

保留两种训练职责：interface 阶段学习 latent 物理表示、来源绑定与专属接口，继承 Wan 冻结；joint 阶段联合训练物理执行与 Wan self-attention LoRA。当前 64+160、累积4 可以作为已有预算参考，不能把它当作新目标必然收敛的依据，也不虚构一个已证明有效的新步数/损失权重。

完整采样物理反传会显著增加训练计算。应使用单 GPU、现有环境和 checkpoint/recompute；计算频率和预算需要按真实完整图成本安排。不能在实现时悄悄断开梯度、降低监督几何，或仅保留尾部若干步，然后仍声称实现了完整执行训练。

本方案涉及新 C 数据结构、生成侧 Qwen LoRA 梯度、原生 latent reasoning 接入、初始证据对应、物理执行层、真实时间输入、两个明确的物理监督目标，以及专用的完整基线迁移。必须新建 revision；不能覆盖旧实验，也不能依赖现有跨架构初始化器自动保留完整基线。

建议的实现落点：
  multiround_knowledge.py / knowledge.py：合法证据、来源/位置、无强制自由分析的可微前缀。
  recurrent_reasoning.py / latent_reasoning.py：复用原生 Qwen 计算，正确处理循环反馈、位置和层级。
  新 C 数据结构与 condition 模块：H 证据、Q128 关系、来源关联、有效 mask。
  native_attention.py 的新 revision 分支：独立 C 投影、来源映射、当前条件读取、3072 维物理响应。
  generator.py：传递真实时间、当前/首帧状态；保留原生 RoPE 与文本路径。
  operator_training.py：明确 Qwen/C/Wan LoRA 梯度所有权，接入 L_C 与完整执行目标。
  runtime.py：显式复制 66443 全函数并添加零初始写入，重建新 optimizer 日程。

本轮不增加 slot 多样性损失、无条件减运动损失、普遍刚性损失、任意 attention 热图拟合、无标签质量保证的自我评分，或辅助未来状态预测器。也不把大规模对比实验当作这些实现工作的替代品。
