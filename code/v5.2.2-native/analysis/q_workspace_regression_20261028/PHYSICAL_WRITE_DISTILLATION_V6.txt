2026-10-28：V6，直接监督实际物理写入的 baseline 设计

状态：迭代设计，供用户审查；尚未实现、训练或得到指标。替代V5讨论稿。
后续设计评估：本稿的D*=g e尚不能当作正确Wan残差目标。局部attention只提供弱关联，文本V/O均值只提供语义参考；二者组合没有给出正确物理响应的向量或幅度。R<=4时每层D*的时空×通道矩阵秩至多为R，硬回归还可能限制复杂局部响应。应修订此监督定义后再实施，不能依据已完成的流程图将当前回归目标视为已成立。候选改进方向是监督实际读取的时空关联，由FM学习响应值与幅度；这也需要解决C槽与教师关系的对应，不能直接将[B,S,128]与[B,S,R]作比较。
用户要求：必须学习正确有效的差异化写入。旧Q公共修正只是历史机制线索，不能作为期望终点，也不能用“允许槽位相似”替代解决执行问题。

1. 对V5的具体修正

V5的C->桥接->冻结Qwen语言解码CE可以训练信息可读性，但没有直接约束Wan实际收到的局部消息；teacher forcing和语言先验又可能降低对C的依赖。删除这项CE及桥接。
仅在Wan当前状态上做attention提供了差异化的表达能力，缺少对应的局部学习目标。本版新增真实训练视频驱动的物理写入蒸馏，损失直接落在真正加回Wan的deltaH上。
不再将原生时序能力或时间编码本身表述为因果顺序已经解决。

保留：冻结Qwen、Q128与H证据、4096处理后3072投影、独立C K/V、原生文本通路、原生Wan时空attention/FFN、两阶段学习、官方基础模型新初始化、无verifier。

2. 生成计算图

  首帧+原始请求 -> 冻结Qwen的多模态H与简短物理推理
  -> Q物理增强模块 -> C[B,128,4096]
  -> P(4096->3072) -> Cw[B,128,3072]
  -> 第3、6、...、30层物理融合 -> deltaH_l[B,7800,3072]
  -> 加回对应未来位置 -> 原生FFN/后续时空attention -> 视频。

原始请求仍经原生T5/text cross-attention进入Wan。
增强模块为一个共享cross-attention/self-attention/FFN block，两次读取H。Q在潜在空间学习提炼物理信息；不训练Qwen本体。
Q/H选择：H提供视觉和语言的证据，Q负责综合关系；H-only也能使用本版写入监督，但本轮只实现Q主线。
不规定Q槽为对象身份、区域或阶段，不要求槽位正交。学习成败依据实际deltaH的语义和时空差异，而不是人为增加槽间距离。

3. 监督目标从哪里来

只在预处理真实训练视频时，复用冻结Qwen提取少量有可见依据的物理关系短句及其软时空证据图。输入为本次缓存对应的真实裁剪、caption，WISA phys_law只作候选关系参考，不强行采用原片裁剪外事件或估计参数。
每个视频最多4条短句，描述场景相关的接触/传播/支撑/持续变化等关系；无需复杂因果图、对象ID或精确事件秒数。
对每条短句，提取Qwen相关回答token到视频视觉token的attention；另以通用视频描述得到背景attention，使用正的差值形成关系的软证据图。只提取相关query行，不存储整段视频的N×N attention矩阵。
对没有可见依据的关系不制作确定目标。该步骤处理真实训练数据，既不读取生成视频，也不做生成视频评分或奖励。

具体软图：
  b_r[j] = max(a_relation_r[j] - a_background[j], 0)
  u_r[j] = b_r[j] / max_valid_j b_r[j]
  g_r[j] = u_r[j] / max(1, sum_r u_r[j])
零支持的关系不参与；r为物理短句，j为实际教师视觉网格索引。
用实际输入裁剪/缩放信息和采样PTS，将g从Qwen网格映射到Wan的21×15×26网格。映射只做已有坐标与时间区间的重采样，不训练额外的区域路由网络。
首版沿用28个RGB观察时刻和原有空间尺寸。软图的时间精度受观察密度和教师能力限制，不把插值解释为补出了未观察到的接触瞬间。

这是一项新增的自动弱标注缓存，有真实计算成本；不是原WISA已经提供的精确时空真值。它避免了原先三套人工来源/范围/阶段标签和对应网络，但不能说“完全没有新增标注处理”。
教师前向离线执行，之后训练只读软图与文本编码；无需在每个训练step反传8B语言解码器。

4. 将物理语义与时空证据合成Wan可用的目标场

用冻结的原生T5和Wan text embedding编码每条物理短句。对有效内容token取均值，得到t_r[B,3072]，不将padding计入均值。
每个注入层使用官方、冻结的原生text V/O权重，把t_r转换到该层残差表示的坐标系：
  e_l,r = W_o,l^0 W_v,l^0 t_r
只使用线性权重，不重复添加原生value/output bias。
这提供原生文本条件的语义参考，不将其解释为已测量的力、速度或正确运动轨迹。

组合得到每个实际位置的物理目标消息：
  D*_l[t,p] = sum_r g_r[t,p] e_l,r

g给出真实视频中不同位置/时刻的关系证据分布，e给出对应物理关系的原生条件表示。D*不作为生成输入，只作为训练目标。
不需要将C的第几个槽与第几个文字token一一对齐；也不让模型把未来证据作为推理条件。
若目标只来自抽象物理文字而没有g，仍是全局语义条件；若只用g而没有e，只学会注意位置。本版用同一个目标场同时约束两者。

5. 两项损失，直接训练实际写入

  L = L_FM + lambda_write (1-sigma) L_write

L_FM仍为真实配对视频的完整有效未来token flow matching：
  z_sigma=(1-sigma)z_real+sigma*epsilon；首帧固定。
  L_FM=mean ||v_theta-(epsilon-z_real)||^2。

L_write比较实际加入Wan残差的deltaH_l与D*_l；不新建一个只为完成辅助任务的可训练读出头。
在每层、每个样本的完整有效未来场上直接回归：
  s_l=max(RMS(stopgrad(D*_l)),1e-3)
  L_write=mean_l,t,p,d SmoothL1((deltaH_l-stopgrad(D*_l))/s_l)
归一化尺度只由教师决定，不用学生自身幅度作分母。均值/RMS用FP32；没有支持目标的样本跳过本项。
保留不同位置与时刻的相对强弱，也保留目标在原生Wan条件空间中的非零尺度。不采用只有余弦/关系矩阵的尺度自由目标，因为它允许学生把消息缩得几乎不起作用仍取得良好的对齐值。

重要性质：
  - 当D*随时空变化时，全局相同的deltaH不能达到最优；即使C的attention权重不同，只要最后写入仍相同，也无法绕过该目标。
  - 多种关系的e不同时，目标既包含作用分布差异，也包含语义方向差异。
  - 消息缩到接近零仍会产生监督误差。目标尺度来自原生文本V/O的条件表示，绝不解释为测量到的物理运动强度；最终运动仍由完整生成路径的FM学习。
  - 零初始化deltaH仍有有限、非零的目标梯度，首先更新O_C，随后进入V_C、K_C、C和P；阶段B同时经过Wan的状态查询路径。
  - (1-sigma)只调训练辅助损失：高噪声时当前输入对具体未来分支信息较少，降低单条视频局部目标的影响；FM始终训练整个噪声区间。它不控制推理时的运动或C输出。

起始lambda_write=0.02，属于建议配置，尚未验证最佳。该监督是有噪声的物理条件场蒸馏，FM仍是生成主目标。
本版的“目标场+实际写入场回归”是本项目的具体改造，不应称为已由ProPhy原文验证的同一损失。回归的是新物理分支的输出，不将整个原生Wan hidden强行改成教师特征；教师的局部误差仍可能影响学习，因此FM保持主目标，SmoothL1和小辅助权重不能被宣传成消除了标签噪声。

6. 融合接口与参数精简

每层：
  KC_l = norm_kC_l((Wk_l^0 + Bk_l Ak_l) Cw)
  VC_l = (Wv_l^0 + Bv_l Av_l) Cw
  QC_l = norm_q(Wq_l^0 X + E_l(tau,delta_tau))
  deltaH_l = WoC_l Attention(QC_l,KC_l,VC_l)

Wk/Wv的基础矩阵复制官方同层参数并冻结，与原生文本通路没有共享的可训练增量；C专属LoRA rank32，输出增量从零开始。
WoC为完整3072×3072的可训练矩阵，零初始化。C内容始终经过完整3072维通路；低秩只用于K/V的增量，不把C的唯一传输通道压成32维。
保留Q增强block约2.01亿、C O约0.94亿、C K/V LoRA约393万、Wan LoRA约5702万、P与时间映射约2045万，以及少量seed/norm。总可训练参数约3.78亿，较V5约5.75亿减少约34%。
删除C->Qwen的语义桥接及其反向语言解码；教师/T5预处理均冻结且不计入可训练参数。

7. 时间、稳定性和训练阶段

tau/delta_tau继续是已有PTS的普通时间条件，仅进入C分支query。保持原生Wan时空位置编码和diffusion sigma机制。主要时空对应信号来自D*，不能只指望时间编码教会事件顺序。
官方Wan基础权重、新O_C零初始化和新LoRA零输出提供起点；稳定性学习由完整视频FM、带真实视频依据的写入场目标、原生时空attention/FFN适配共同承担。
不以少动、槽趋同、跨帧恒等或普遍刚性为目标。液体、气体、波、混合、破裂等按各自可见物理关系构造目标。

阶段A：训练Q增强、P、C K/V增量、O_C和时间映射，Wan冻结；FM和write两项损失同时使用。
阶段B：继续A，并warmup新Wan self-attention与FFN LoRA；原生文本cross-attention参数保持基础值。
先运行同一条训练线，保留首个64A+160B检查点用于初版交付，后续继续同一联合阶段；不把224步当作达到30%目标的充分条件。
不从旧项目checkpoint继承。训练/推理CFG条件保持一致。

8. 预期有效的依据与必须准确表达的边界

本轮明确补上了V5缺失的、实际写入层面的时空物理监督。关键预期是：空间/时间不同的物理关系必须在最终写入场中体现；信息可读却不被使用、只有key不同而最后输出一样，都不再足以完成辅助目标。
ProPhy报告了用VLM视频attention建立局部物理弱目标并用于物理生成训练的方法；它也明确承认标签噪声，并报告单独使用其绝对对齐项可能退化。本版将可见物理关系的空间分布与原生条件语义组合后直接监督新增写入分支，保留FM为主目标；该具体改造仍需实际训练验证。
VideoREPA支持用真实视频关系指导生成并指出直接硬匹配特征可能损害预训练能力；本版不引入其视频编码器/JEPA，不冒称已经复现其效果。
冻结Qwen3-VL-8B提取的弱目标不等于ProPhy使用Qwen2.5-VL-32B得到的已验证质量；不保证所有接触时刻精确，不声称从观察视频完成严格因果识别。
