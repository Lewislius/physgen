2026-10-28：Q workspace 退化分析与下一版设计

目标：以 66443 / v30 / final224 的实际生成状态为起点，同时改善物理过程准确性、画面稳定性和运动连续性。适用范围包括刚体、液体、气体、波、形变、相变以及出现和消失。这里的“连续性”允许有物理依据的碰撞、破裂、分裂、合并和快速变化；不把所有过程限定为对象身份保持或匀速运动。

本报告使用现有 checkpoint、训练日志、代码和视频，不包含新训练得到的质量结论。D-N 不纳入判断。视频观察重点是 P01–P05，以及训练期间保存的 source0000042 / seed42 验证视频。existing_evidence.json 记录的是读取当时已有的输出，不能据此宣称整个新版本评测已经完成。

1. 对退化的判断

四个新版本确实改变了生成行为，而且 P01–P05 的部分变化明显损害了视觉与物理正确性。当前最有依据的主问题是：条件表示与生成器之间的作用关系发生改变，而新增的差异没有受到直接的物理语义和过程执行监督。不能把“128 个 token 更不同”直接当成“更好的物理信息”，也不能把“128 个 token 趋同”直接证明成旧版稳定的唯一原因。

旧 Q 的趋同确实提供了一个有数学依据的机制解释：当各槽的 K/V 近乎相同，attention 读出的消息近乎不依赖当前 query。但这可能是图像或场景相关的公共修正，未必幅值小，也不是所有输入共享一个常数。它仍会经后续层产生不同影响。新版本是否真的增加了多少有效槽间差异、这种差异是否就是突变的直接来源，现有新版本日志没有记录足够的激活信息，不能把机制解释冒充已完成的因果分解。

训练集覆盖比例、总参数量、共同的数据缺陷、共同的噪声采样范围，不能单独解释本次“相对旧 Q”的退化。它们不是本报告的差异归因。相对变化集中在 Q 的构造/读取、由此学到的 conditioner 和 Wan LoRA，以及这些变化在完整采样过程中的作用。

2. 视频中实际发生了什么

P01：旧 Q 的车保持了较完整的轮廓，存在移动和视角变化，但没有正确完成所要求的接触后倾倒。四个新版本在约 f24–f40（1.0–1.67 秒）出现明显抬起、翻转，B/C 还把车与垃圾桶的形体混在一起。这不是合理碰撞需要的短暂速度变化，而是运动与几何状态都走错。

P02：旧 Q 也有两球离开桌面的错误，因此不能把旧视频当成物理教师。新版本还出现额外球、花色/颜色变化、蓝球在红球没有完成接触前就运动的情况。问题包括物理前提、响应顺序和外观变化依据，而非单纯“动得太快”。

P03：各版本都未可靠完成“接近—拍面接触—同一球反向离开”的过程。新版本出现无可靠接触依据的飞离、消失或重新出现；旧版也不是正确击球示范。

P04：旧 Q 的骨牌多数保持站立，新版也没有形成正确的逐个传播链，伴有手和局部形体异常。画面变化少不足以构成成功；必须发生正确传播。

P05：多个版本把斜坡与滑块的作用角色混淆。B/C 的整块斜坡发生平移、旋转或明显形变；旧 Q 和 D 系列也没有稳定实现“滑块沿坡下滑，再在地面减速”。这是将过程落实到画面中的对应关系出错。对液体/气体，相应问题应表述为来源、传递、受影响区域、持续条件对应错误，而不是固定对象 ID 错误。

逐帧证据：P01_comparison.jpg 至 P05_comparison.jpg。每张图从上到下为 Q66443、B、实验 C、D-S、D-I，列为 f0、f8、f16、f24、f40、f60、f80。均为相同 demo 输入、seed42、81 帧、24 FPS、50 steps、shift5、CFG5、condition strength1。GPU 后端并非完全一致，不能声称逐 bit 等价；比较中没有发现帧率被加倍。

4. 旧 Q 趋同与稳定性的关系，应如何理解

已有的旧 Q 四验证样例分析记录：最终 C 的 token-centered RMS / total RMS 约 0.00267。以 source42 为例，工作空间的 RMS 从 R0 的约 4.17 增长到 R2 的约 11.70，而槽间相对差异继续缩小。这表明反复共享的 cross/self/FFN 更新很容易积累公共分量。最终 LayerNorm+affine 控制总体尺度，却不会自动赋予差异正确的物理含义。

对一个 attention head，m(q)=sum_i a_i(q)v_i，其 query 导数由注意力加权的 K/V 协方差决定。所有 K/V 完全相同时，m 对 q 的导数为零。近乎相同时，可形成近乎公共的状态修正。若产生了差异很大但语义不可靠的 K/V，改变 query 就可能选出错误消息。这是一条合理的稳定性机制，但新版本的实际 Jacobian 没有被现有材料测定。

因此旧版稳定性的可继承对象是“整套已适配的生成函数”：原 Q conditioner、投影、alignment、Wan LoRA、原生 Wan、采样设置共同形成的结果。把稳定性归结为某一个表征统计，会遗漏其余部分；直接重新初始化再训练也无法继承这套函数。

5. 目前的监督缺在哪里

当前所有五个版本的主要训练目标相同：FM + 0.1 temporal FM。Qwen 是冻结的；_encode_message 有 no_grad，输出 memory 又被 detach；message 模式不安装生成侧 Qwen LoRA。训练更新 message conditioner 和 Wan LoRA，不会修正 Qwen 自己生成的文字分析。现有 analysis_sft_loss / relation_sft_loss 属于旧的 multiround/v14 路径，当前 message 配方并未使用。

更重要的是，最终 C 没有直接的语义监督，也没有要求它独立保留“已观察到什么、要求是什么、作用依赖什么、什么变化需要前提、哪些信息未知”的任务。三次 MessageBlock 调用表示三次特征更新，不能仅凭名字认定为三次有效物理推理。

P02 和 P05 的文字分析在五个版本中基本或完全相同；P05 的文字明确区分木块、斜坡与摩擦，但视频仍可让斜坡移动。因此“文字分析写得更正确”不能单独解决这次故障，必须贯通文字/图像证据、最终 C、当前视频状态和实际生成结果。

现有 temporal FM 计算的是：e = predicted_FM - (noise - clean_latent)，然后约束 e 在 latent 视频时间上的差分。它不是物理速度标签，也没有直接监督接触、来源、传播、相变或身份。对单步 x0 估计，x_hat0 - x0 = -sigma * e；简单再加一个 latent 帧差误差，可能只是给已有目标重新加权。FM 可以从足够合适的数据中学习物理规律，但当前日志没有证明它已经建立这种因果对应。

当前注入使用原生 query，对 text 和 C 分别 softmax，再将两路消息相加，每三层一次。全宽 affine 只对齐尺度统计，没有把 Qwen 语义自动对齐到 Wan 的 K/V 语义。新版本改变 Q 的读取方式后，这个语义接口又形成了不同解。B/C 的等长度 pooling 不是因果片段划分；D 的 slot identity 不是物理角色或过程身份。

采样时 v_CFG=5*v_positive-4*v_negative。两路条件映射变化引起的场差异满足 delta_v_CFG=5*delta_v_positive-4*delta_v_negative，因而错误的条件差异可能被放大。但两路误差也可能抵消，不能宣称必然放大五倍。该去噪场不是视频中物体的速度。50 步积分积累的是生成状态差异，最终可表现为飞离、变形或过程顺序错误。

训练 sigma 范围 0.02–0.95，而当前 50 步 shift5 采样有 11 个评估点高于 0.95；这是共同的适配覆盖缺口，不能单独解释相对退化。它说明未来训练不能只在带真实未来成分的 noisy target 上优化，再假定改动能可靠迁移到纯噪声生成。

6. 下一版的架构：保留基线函数，学习具有物理语义的状态相关修正

推荐以 66443 final224 为唯一主线起点，完整继承 conditioner、query seed、投影、alignment 和 Wan LoRA。保持 Q=128、workspace=4096、最终接口=3072、R0+两次 refinement。增加能力时采用函数保持的初始化，使新版本在开始学习前与这个基线一致。

可用的具体参数化为 C_new(x)=C_66443(x)+P_delta R_theta(x)。P_delta 是 4096→3072 的全宽线性写入，初始为零；R_theta 是读取相同合法证据的 128 槽因果表示，继承旧 message 权重，接收新的语义训练。传入 Wan 的仍是 128 槽。C_66443 路径保存原有作用，学习分支负责新增信息。零初始化只解决初始函数继承，后续正确性来自下面的语义与执行监督，不能把它本身当成物理修复。

R_theta 应从有来源标记的图像/请求/条件分析中保留因果关系。token 分段应尊重语义片段，保留条件与结论、持续与终止的关联；不以词数等分或随机 ID 的分散程度作为内容质量目标。128 槽是全宽信息容量，不是 128 个对象，也不强行分配固定物理类别或固定事件数。

对状态的执行仍交给 native Wan。其现有 query 已依赖当前 spatiotemporal hidden state；应训练这种读取在当前状态下选择正确的物理依赖，而不是另加一个独立未来预测器。C-only 监督约束记住什么，执行监督约束这些信息在视频状态上如何起作用。跨帧传播、形变、流动等可以由同一机制表达，不需要轨迹、光流或对象跟踪。

真实时间是另一条必要的输入：当前原生 Wan 路径接收 times 参数，却不使用逐帧实际秒数；它仍有原生视频帧位置编码，不能说模型没有时序信息。duration 只进入 Qwen 文本。建议将实际 tau_t、delta_tau 的全宽编码以零初始化的可学习增量接入现有状态读取，保留原生帧位置编码。这个改动服务于物理时间尺度，不是改变输出 FPS 或对视频做减速处理，也不应被当成本次相对退化的已证实原因。

这种设计允许由物理条件驱动的快速变化：碰撞可以改变速度，气球可以破裂，流体可以拓扑变化；同时要学会在缺乏对应作用时维持合理状态。总体目标是过程连续性和条件正确性，不是所有画面保持原样。

7. 对 C 直接增加何种监督

核心采用训练专用的语义读出：仅提供最终 C 和问题，不把原始图像、caption 或完整分析再次交给读出器。读出器复用冻结语言模型与全宽接口，回答来自现有训练片段的物理关系问题。这样降低问答损失必须让相关信息经由 C 传递，而不能绕开 C。

问题覆盖观察与要求的区别、可知与未知、作用来源、传递条件、响应、持续与终止、条件变化带来的结果。不同过程用自然语言表达同一类依赖，而不是一套对象 ID 或硬编码动作表。例如：
  - 刚体接触：未接触前，是否已有依据出现碰撞响应；支撑面与被作用部分有什么关系。
  - 倾倒液体：持续液流来自哪里；来源减少和接收处增加由什么连接；倾倒停止后哪些变化还能延续。
  - 气体扩散：浓度分布的扩展依赖什么；有无持续来源、边界或流动；不能从单帧确定的量保持未知。
  - 波：扰动从何处传播、依赖什么介质；传播图案和介质本身的变化有什么区别。
  - 熔化/形变/燃烧：允许哪些形态或物质变化，依赖什么条件，条件撤去后如何继续或终止。

反事实问题用于学习因果依赖，但不能把凭单帧猜测的某一未来轨迹当成唯一真值。当前图像、文本和真实训练视频可提供不同层次的监督依据；真实未来仅作为训练标签，不进入通常推理条件。

这比只训练 Qwen 输出四行“正确分析”更切中当前链路。若要纠正文字分析中的错误，可以在同一 interface 预算内加入生成侧 knowledge LoRA 的文本 SFT，但它是辅助项，不能替代最终 C 和视频执行的训练。它还需要新的 message 专用训练路径，不能误认为现有 no_grad/v14 接口已经实现了。

8. 让生成器真正学习物理过程，同时保留画面能力

建议主目标保持清楚：L = L_FM + 0.1 L_temporalFM + lambda_C L_C_semantic + lambda_E L_execution。

L_execution 的目标来自真实训练视频中按时间组织的过程证据，包含发生了什么、什么仍在持续、变化依赖什么、哪些属性或结构应保持/允许改变。监督应作用到模型实际生成的完整过程；不能只把真实未来加噪后的一次重建称作生成物理正确性。

复用现有 Qwen 原生视频读取和输入梯度设施，训练教师读取真实片段形成短的有序过程证据；对生成片段以相同方式计算可微的语义支持/问答损失。使用真实时间，保留原生 832×480，以及现有每三帧加末帧的 28 帧观察配置。损失不是一个整体“好/坏”分数，而是对具体过程事实的监督。梯度要到达 C 和负责执行的 Wan 增量，不能只要求 C 迁就固定且不会执行的生成器。

为了覆盖部署轨迹，执行监督以纯噪声、部署使用的 CFG/shift/采样过程为基准，使用完整轨迹的 checkpoint/adjoint 梯度。不要把 CFG 合成的向量场直接当普通条件 FM 再用同一 noise-clean target 回归，因为 CFG 改变了生成分布。若计算预算使用更短的训练采样器，需明确那是近似方案，不能把 8 步监督宣称成 50 步部署完全一致。

具体先保持原来的 64 interface + 160 joint、累积4、单GPU预算结构：
  - interface：继承的 Wan 全部冻结；主要学习 C 的语义、写入映射，并保留真实视频 FM。无需重建五个随机架构分支。
  - joint：C 与小学习率 Wan 增量共同学习执行。可每8个 joint step 加一次完整过程损失，共20次；常规每步仍学习真实视频 FM。新增 Wan 更新相对完整基线初始化为零。这个安排不增加阶段数，但过程反传显著增加计算量；不把步数相同说成耗时相同。

这里不把旧 Q 的完整生成视频当作物理真值，因为它也会让球飞起或让骨牌不倒。稳定性来自基线函数继承、受真实数据支撑的联合更新、对合理状态保持与合法变化的条件监督；物理改进来自新的 C 语义和完整过程执行目标。全局运动惩罚、无条件帧差最小化或一味增大 temporal FM 会奖励少动，不能承担这一任务。

教师本身也可能误读过程；训练事实必须有明确证据来源，并保留未知与不可见条件。这是监督定义的一部分，不能把语义特征相似度改名为已解决的物理规律。连续介质、可见范围外的来源/汇和开放系统尤其不能强套可见区域总量守恒。

9. 数据与接口的实际工作内容

新四版本未改变训练缓存或监督内容，因此并未从训练目标上解决旧数据可能存在的问题。现有样本含自然风景、舞蹈、近乎不动的物体、流体及其他过程；查看前8个实际训练片段只能证明样例内容，不能代表全数据质量。

下一版需要在现有 wisa_4000 上新增独立的训练监督 sidecar，记录真实可见过程与条件关系，并在短预算中覆盖有完整因果发展的片段及一般场景。保留原始缓存和原分割；不引入位移/速度标签、对象跟踪、固定镜头筛选或新的低维物理类别瓶颈。采样按过程证据覆盖组织，而不是靠画面变化强度挑“动得多”的视频。

时间数据中，全部记录使用原视频连续81帧，原始 FPS 不统一；全缓存时长约1.33–5.33秒。这提示真实时间条件需要进入生成器，不证明视频被错误加速。新旧版本共享这套数据，也不能将它解释为相对退化的独立原因。

实现落点是新 revision 的完整基线继承、message 全宽语义残差、C-only 语义训练接口、原生状态读取的真实时间条件、operator_training 的执行损失及其梯度所有权。baseline_reference.json 已记录现有基线的精确路径、配置与配套视频；它是基线定义，不是已经训练的新模型。

现有 runtime.initialize_generator 对同一 message 架构可以迁移完整 conditioner；架构改变时有显式限制。新结构必须明确保留基线分支和新参数，不能默认一次通用迁移就获得函数继承。直接 resume 已完成224步的原运行也不是新的224步训练，应该建立新的 revision 和优化器日程。

10. 证据与设计的界限

已经确认：输出中的具体错误；各版本训练/推理配置；旧 Q 的历史趋同记录；监督与梯度路径；新版本未继承66443；正常完成训练且没有更大的后期梯度；新旧 alignment 尺度接近；冻结 Wan 阶段已经存在生成行为差异。

主判断：目前最需要解决的是“C 中的物理信息如何被保留并在当前视频状态中正确执行”，而不是继续把 slot 差异、重建 MSE 或任一单独统计当成生成目标。关于公共修正、状态敏感性和 CFG 放大的解释具有机制依据，但本报告没有将其宣称为已量化的唯一根因。

下一版选择一条从完整66443出发的主线：函数保持的全宽因果表示扩展 + 直接语义监督 + 真实生成过程的执行监督。架构改动和训练目标共同承担“准确物理现象与稳定画面同时成立”的目标。上述新训练尚未运行，不能声称视频质量已经改善。
