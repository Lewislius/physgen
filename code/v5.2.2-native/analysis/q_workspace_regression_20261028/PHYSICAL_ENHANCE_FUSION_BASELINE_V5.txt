1. 针对的根本问题

现有证据支持“C 的内容与生成器的读取/执行没有被共同教对”，不支持把训练样本覆盖率或参数量直接当作这次相对旧 Q 退化的原因。
已有记录中，旧 Q 的槽间差异很小，attention 可能主要提供场景相关的公共修正；四个新版本改变读取方式后，未新增物理语义监督。这提供了一种解释新消息导致运动/形态走错的机制，但尚不是唯一根因的因果证明。
旧 Q 也有物理错误，不能作为物理教师；遵照用户要求，不继承其 checkpoint。

本轮解决链条：
  合法首帧/文本 -> 冻结 Qwen 的多模态证据与简短推理 -> 可训练物理关系 C
  -> 由 Wan 当前时空状态读取 C -> 原生 Wan 时空 attention / FFN 学习执行
  -> 真实配对视频提供完整生成监督。

核心区别：C 是共享的条件性物理关系记忆；真正随位置 p、视频时刻 t、去噪状态 sigma 变化的是融合输出 delta H_l[t,p]。不让 C 在首帧阶段预编造未来逐帧坐标或事件秒数，不把 token 彼此不同本身当成目标。

2. 总体结构：两个生成模块，一个训练专用语义读出

  I0 + 原始请求
       -> 冻结 Qwen：H [B,M,4096]
       -> 物理增强模块：Q [B,128,4096] -> C [B,128,4096]
       -> RMSNorm / P(4096->3072) / RMSNorm -> Cw [B,128,3072]
       -> 物理融合模块，在 Wan 第 3,6,...,30 层读取

  原始请求 -> 冻结原生 T5 -> 原生 Wan 文本 embedding / cross-attention
  首帧 + 噪声视频 -> 原生 Wan -> 文本与 C 分别注入 -> 原生 FFN -> 视频

训练专用：Cw -> bridge(3072->4096) -> 冻结 Qwen 语言解码器 -> 物理目标文本 CE。
推理没有该语义读出，也不需要 WISA 标注、真实未来帧或训练答案。

Qwen、T5、VAE 和 Wan 基础权重均来自官方预训练模型。新增 Q/C、投影、输出接口和新 LoRA 重新初始化；独立 C K/V 可以从同层官方 Wan K/V 复制初值，但之后独立学习，绝不读取历史项目 LoRA、alignment 或 optimizer。

3. 物理增强模块：保留推理，训练其物理信息提炼

3.1 冻结 Qwen
Qwen 全程不安装可训练 LoRA。首帧与原始请求编码、简短物理分析生成均不反传，可缓存。
只使用一个简短任务提示：结合首帧与请求说明相关作用条件、变化和应保持的属性；不编造未知条件、坐标或时刻。分析长度以 128 token 为初始上限，不要求复杂角色表、事件图或反事实树。
H 保留原始视觉网格、原始请求和分析的 contextual hidden，而非只保留生成分析。这样 Q 可以重新读取实际输入；错误分析仍有可能影响 C，因此真正的纠正信号必须来自训练，不能只靠提示词。
H 的视觉网格是首帧依据，只代表初始空间。未来状态由 Wan 承担，不从该网格声称获得未来位置。

3.2 Q 范式为首轮主线，H 是证据记忆
使用 128 个可训练 query，4096 宽，32 heads × 128。
一个共享的全宽 refinement block，顺序为：
  cross-attention(Q,H) + residual
  self-attention(Q,Q) + residual
  FFN(4096->8192->4096) + residual
均使用 pre-norm。整个 block 连续执行两次，总共两次读取，不再额外加第三次 R0；两次共享参数。
最终 C 仍为 [B,128,4096]，不设置对象槽、固定物理类别槽、空间槽或阶段槽，不强制正交或多样性。
这属于冻结 Qwen 证据上的可训练 latent 关系提炼；不称为“Qwen 本体正在训练的原生 latent reasoning”。

H-only 的可行替代是直接把内容 hidden 经同一投影与融合接口送入 Wan，并接受同样的 C 语义/生成监督。其优点是少一次压缩提炼；代价是更依赖输入长度和词序，关系信息与描述细节混合。首轮选 Q 的理由是固定接口和关系聚合，不是 H 缺少物理能力。本轮只实现 Q 主线，不并行训练另一条 H 实验。

3.3 物理专用性
物理专用性来自这段 latent 被直接训练去保留场景相关的条件—响应、持续/传播及允许变化/保持，并通过视频生成联合学习；不是给普通 attention 改一个名称便声称得到物理模拟器。
首轮不增加没有明确监督职责的专家路由、状态交互 MLP 或显式方程求解器。用可训练的 C 与 Wan 原生执行结构承担这些学习职责。

4. 物理融合模块：C 独立 K/V/O，原始文本保留

沿用现有 Wan30层，在第3、6、...、30层的 cross-attention 位置注入，共10处。
设 Hs 为该层原生 self-attention 更新后的状态，X=norm3(Hs)。

文本分支：
  q_raw = Wq_text X
  QT = norm_q(q_raw)
  KT = norm_k(Wk_text T)，VT = Wv_text T
  YT = Wo_text Attention(QT,KT,VT)
保持原生文本 attention 的参数、归一化、softmax 和输出投影；不把 C 拼进文本 softmax。

C 分支，每层有自己的 K/V/O：
  KC_l = norm_kC_l(WkC_l Cw)
  VC_l = WvC_l Cw
  QC_l[t,p] = norm_q(q_raw[t,p] + E_l(tau[t],delta_tau[t]))
  deltaH_l[t,p] = WoC_l Attention(QC_l[t,p],KC_l,VC_l)

WkC/WvC/WoC 均为 3072->3072 全宽映射，不与文本共享可训练参数。K/V 可复制官方同层 K/V 的权重初值；C 分支使用独立 key norm，V/O 不额外添加与内容无关的 bias。WoC 零初始化，其他新增参数按常规初始化。QC 复用原生 query 线性投影，没有额外一套 query 矩阵。

合流：
  U = Hs + YT + pad_first_frame_zero(deltaH_future)
  Hout = U + 原生FFN及其原生噪声调制(U)

真正的执行器包括同层原生 FFN 与后续原生时空 attention。联合阶段在这些部分加入新 LoRA，让它们适应 C；不要求一个始终固定的生成器自己猜懂新消息。
新增物理分支不直接修改观测首帧，首帧继续作为 I2V 条件。未来帧照常生成，不复制首帧。

为什么与错误时空含义有关：
  C 只提供关系记忆；每处 deltaH 都由当前位置的 Wan 状态查询它。
  当前状态已经由原生视频 self-attention 读取时空上下文；局部是否接近/接触、液体在哪里、支撑面在哪里，必须由训练学到的表示参与读取，而不是只由固定槽编号决定。
  实际 K/V/O、C 和 Wan 执行参数通过同一个完整视频 FM 目标联合优化。目标来自每个有效未来位置，而不是只看最终 C 的语言是否通顺。
这是学习正确对应的途径，不是已有精确空间/阶段标注的替代真值；attention 本身不提供正确接触时刻的数学保证。

5. 时间只作为普通条件

保留原生 Wan 的视频时空位置编码与 diffusion sigma 处理。
使用已有 PTS：tau[k]=PTS[4k]-PTS[0]，k=0..20；future delta_tau[k]=tau[k]-tau[k-1]。
这里的 tau 是每个 latent 时间组的末端索引约定，不声称 VAE 每个 latent 只含该一帧信息。
tau 与 delta_tau 各做 128 维标准 sin/cos 编码，拼成 256 维，再由每个注入层一个 Linear(256->3072) 得到 E_l；同一时刻所有空间位置共享该时间向量。
这条小支路仅进入 C query，原生文本 query 不加该项。没有独立“时钟网络”、时间 attention、历史 rollout 或阶段头。
PTS 是呈现时间；慢动作/延时没有已知时间缩放时，不能称为真实世界物理秒数。WISA n1 不用于该输入。时间条件有助于学习时间尺度，不能单独纠正因果顺序或证明正常速度。

6. 维度审查

当前缓存/骨干示例：B=1，RGB81帧832×480。
  video z              [B,48,21,30,52]
  native patch conv     48->3072, patch=(1,2,2)
  native X              [B,8190,3072]，8190=21×15×26
  known first frame     390 tokens
  future X              [B,7800,3072]
  Qwen H                [B,M,4096]，M由原生视觉/文本长度决定
  Q/C                   [B,128,4096]
  enhancement heads     [B,32,128,128]，H KV token长度为M
  Cw                    [B,128,3072]
  Wan text context      [B,512,3072]，由原生T5输出经Wan文本embedding获得
  C K/V per layer       [B,24,128,128]
  C future Q            [B,24,7800,128]
  C attention output    [B,24,7800,128] -> [B,7800,3072]
  deltaH padded         [B,8190,3072]，首390项为零
  native FFN            3072->14336->3072
  semantic bridge       [B,128,3072] -> [B,128,4096]

所有 C 内容先在4096维处理，最后投影3072。低维时间编码只编码两个标量，不是把 C 压成256维。
结构简化不等于新增参数极少：上述全宽 Q block 约2.01亿、十层 C K/V/O 约2.83亿；计入投影、桥接、时间映射和下面的 Wan LoRA，约5.75亿可训练参数（忽略少量norm/bias）。这是维度计算，不是显存/速度实测，也不用于解释旧实验的稳定性退化。Qwen8B无需优化器状态；语义读出仍有输入梯度计算成本。

7. 两项损失，两阶段都使用

总目标：L = L_FM + lambda_phys L_C_phys。
首轮起始建议 lambda_phys=0.05；这是待训练的配方选择，不是已经确认的最佳值。

7.1 L_FM：训练“生成正确过程”
  z_sigma=(1-sigma)z_real+sigma*epsilon，已观测首帧固定。
  L_FM=mean_valid_future ||v_theta(z_sigma,I0,text,Cw,times,sigma)-(epsilon-z_real)||^2。
每个有效未来时空位置参与；它更新 C 增强、投影、融合 K/V/O，阶段B也更新 Wan LoRA。
真实视频提供过程、外观和形态共同出现的监督；这是联合视频去噪分布学习，不是显式速度/接触标签。FM velocity 是去噪路径导数，不能解释为视频运动速度。
噪声训练覆盖接近纯噪声到低噪声的完整有效区间；首轮建议 uniform(0.001,0.999)，不沿用0.95上限来排除最初去噪区间，也不只训练容易从低噪声输入恢复的未来。此修改解决执行条件学习的训练覆盖，不把它说成新旧退化的既证原因。

7.2 L_C_phys：训练“实际进入生成器的 C 保存物理信息”
  L_C_phys=-mean_n log p(a_n | bridge(Cw),固定中性任务提示,a_<n)。
答案限定为64–96 token左右的简短场景物理说明，包含适用条件/响应，以及该过程允许改变和应保持的内容；不是额外的三个损失或三个网络。
语义读出只看最终 Cw，不另看 H、图像、caption 或分析。bridge 可训练，复用的 Qwen 语言解码参数冻结。
这里从最终 Cw 读出，不再轮换层后拼接多组 K/V；独立 K/V 的执行学习直接由 FM 承担。这样减少额外训练接口，也避免把每一层K/V硬要求为同一语言表示。
梯度通过冻结语言解码器的输入回到 bridge、P 和 C。冻结参数不等于 no_grad：证据编码可 no_grad，语义读出不可 no_grad。该分支不进入 Wan/生成视频做评分，因此不是 verifier。

8. 物理目标文本的现有数据来源

使用已经关联的 WISA 当前 caption/合法输入与原始 phys_law，一次性离线整理为短的条件性机制文本，保存独立 sidecar，保持现有train/val分割与缓存不变。
例：两球碰撞场景描述相关接触与响应、可见外观应保持；染料扩散描述染料与介质相互作用后的分布变化、连续过程与边界条件，不规定固定对象形状。
目标文字不强迫每个过程都匀速、不变色或不变形；溶解、燃烧、液体混合、破裂等保留其合理变化。
只把当前片段/请求支持的内容写成该场景事实；物理规律给出的未知前提写成条件句，不把原片裁剪外的倒塌/燃烧或数值估计编成已发生事件。无法获得有依据的物理目标时，该样本仍用于 FM。
不制作空间框、作用mask、时间区间或对象轨迹。原 WISA 物理文本是 caption 派生的弱标注，整理并不能将它升级为精确物理真值。训练答案只进入 CE，不喂入常规 C 编码输入。
一次自动整理的费用与时间要计入实现预算；本文件没有声称目标集已制作完成。

9. 两个阶段内渐进训练

阶段A：训练物理增强、P、C独立K/V/O、时间投影、语义bridge；Wan基础参数与Wan LoRA均冻结。L_FM和L_C_phys从开始同时存在。
WoC零初始化使训练起点的生成器函数保持官方Wan；第一次FM反向主要训练WoC，随后梯度进入上游。语义CE从开始即可训练C/P，不会因WoC初值为零而被切断。

阶段B：继续A的模块与优化器，解冻新Wan LoRA：
  self-attention q/k/v/o，全部30层；
  native FFN两层Linear，全部30层；
  rank=32，alpha=32，新增LoRA输出因子初始为零。
原生 text cross-attention 参数保持冻结，包括其q/k/v/o。它的输入状态仍会因联合训练变化；不宣称训练后文本输出完全不变。
用普通学习率warmup逐渐加入Wan更新，不逐帧调小物理消息、不引入运动强度门控。
起始学习率建议：A新增模块1e-4；B新增模块5e-5；Wan LoRA1e-5，B前16步线性warmup。保持accumulation=4、现有训练随机种子与单GPU环境。

首个可交付checkpoint沿用64步A+160步B的短流程，不把224步当作从头新模块已充分学习或达到30%提升的证据。若在四天内继续优化，沿同一条B阶段训练续跑；不是再添加第三阶段或另起多架构实验。

CFG条件必须训练/推理一致：正常分支使用原始文本与C(I0,request)；空文本分支保留首帧、使用空文本与C(I0,empty)。训练以0.1概率同步删除两个文本入口，并且不对缺失请求施加原场景答案CE。取消单独删除原生T5而保留完整C的额外dropout规则；不靠人为放大C分支推动运动。首轮沿用标准一次CFG组合，C strength=1，不新增独立C guidance倍率。

10. 对“稳定且发生正确物理现象”的具体承担

  起点稳定：官方Wan原有图像/视频能力，零初始化新增输出和LoRA输出；不是继承旧项目生成函数。
  信息正确：C语义学习条件与响应，并保留实际首帧/请求的证据记忆；不只训练定律名称。
  执行对应：当前位置/时刻的Wan状态读取共享C，C自身K/V学习物理语义到Wan查询空间的对应。
  时序落实：原生时空attention保持，实际PTS补充时间尺度，完整视频FM联合训练；native FFN和self-attention LoRA适应C。
  外观与允许变化：文本原路径、首帧条件和真实视频目标共同训练；语义目标包含过程允许/不需要改变的内容，不加入普遍刚性或“少动即好”的损失。

本轮没有一个硬机制能承诺所有生成不跳变；C语义读得出也不等于视频必然执行。最有希望的改进点是现在两端都有对应学习职责，并通过真实生成前向连接，而不是再增加自由的消息差异。实际指标和视频质量仍须由新训练给出。
