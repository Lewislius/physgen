2026-10-28：无需区域/事件补标的 Physical Block 设计 V4

状态：历史设计稿，尚未实现或验证。用户后续要求连同已删除损失对应的区域/阶段结构一起简化，并采用物理增强与物理融合两模块。当前供检查方案见 PHYSICAL_ENHANCE_FUSION_BASELINE_V5.txt。本文件及其配图保留为历史记录；下文“新方案/当前”等表述仅指写作当时。WISA 来源关联文件继续有效。

一、此次决定与保留目标

删除 L_source、L_scope、L_phase，以及相应的区域/阶段读出头；不制作人工框、mask、接触时刻或阶段区间。独立 temporal FM 也不进入新方案。
采用两个训练目标：完整视频 L_FM 与 C 的物理语义 L_C_phys。没有替换成三个伪标签损失，没有训练/推理 verifier、reward、排序或视频判分。
目标仍是物理现象准确、条件关系落实、运动与画面稳定。稳定不能用静止、限制位移、禁止真实形变来替代；对液体/气体/波/出现消失等不要求固定主体身份。
只从官方预训练 Qwen/Wan/T5/VAE 开始；项目新增模块、Q seed、Qwen/Wan LoRA、optimizer 新初始化。旧项目 checkpoint 不参与初始化或蒸馏。

二、为什么不是直接删掉三个损失

V3 的 C 来源读取和最终 K_exec/V_exec 写回分别学习。无精确对应监督时，读到某处状态、却把响应写给别处的自由度仍然存在；辅助头能解码出位置/阶段，也不等于 Wan 已正确执行。因此新版本改变执行计算本身，而不只缩短损失清单。
核心修改：C 提供条件性物理关系与算子调制；Physical Block 从当前 Wan 状态计算响应；受影响区域的读取与响应写回使用同一份软空间关联。真实视频 FM 直接训练这一完整路径。
这能消除独立读写路由之间的一类错配，但不自动证明学习到的空间关联就是正确的物理区域；该关联仍须由数据与训练学会。

三、C 与 Q/H：保留推理，避免预编造未来执行表

原生文本路径保持：原始 caption -> T5 -> 原生 text cross-attention -> Wan。
物理路径：首帧 + 原始请求 -> Qwen 原生多模态 H -> 原生 latent reasoning -> C -> Physical Block。

推荐 H 证据记忆 + 128 个 Q 推理状态，宽度均为 4096。H 保留视觉网格与文本内容，Q 综合关系；生成侧 Qwen LoRA 接收梯度，不沿用当前 message 路径的 no_grad/detach。Q 数量不是对象数量，不要求 token 正交或彼此不同。
H-only 仍是可实现范式：对原生内容 hidden 做 refinement，以同一执行接口读取。主线选择 Q 是为了显式保留可训练的关系推理工作空间，并非声称 H 不能表达物理。

C 表达适用条件、相互作用、允许变化和依赖关系，例如接触成立后可能产生响应、液流与入口/受影响区域的关系。C 不从首帧预编造每个未来时刻的唯一位置、接触秒数或轨迹。条件发生与否及其当前作用位置由 Wan 的当前视频状态参与判断。
C 不是只保留抽象定律名；它需要结合当前首帧/请求，保留相关材料、形态、来源及相互关系。自由生成长推理文本不是推理时必须执行的脚本。

四、独立 C 接口与自动几何来源

Qwen 证据与推理在 4096 完成；各注入层的 C 专属 K_cond、K_scope、V_rule 投影直接 4096->3072，key norm 与输出 O_phys 独立于原生文本投影。V_rule 用作交互算子的规则上下文，不单独作为一组静态画面修正写入所有未来帧。

R 为关系 hidden，X_l[t,p] 为原生 Wan 当前状态。
R 对首帧 H 的软读取产生 A0_cond/A0_scope。根据已知图像裁剪/缩放几何，将这份视觉权重对应到 Wan 首帧网格，形成 g_cond/g_scope。若两种 patch 覆盖不同，按几何重叠映射，不仅凭 token 数量相同做索引复制。不可见/文本来源不伪造像素。

已知的是两个编码器观察了同一首帧区域；未知的是物理语义应指向哪些区域。前者无需标注，后者由后述生成训练学习，不将几何对应冒充物理真值。

五、Physical Block：当前状态交互，作用读取与写回共享关联

以下公式省略 batch、head 与层号；实际使用多头分块计算。p 是当前空间网格，r 是关系状态，t 是视频时刻。

1. 每个当前时刻重新读取两种角色：
   A_cond[r,t,p]  = softmax_p score_cond(R[r],g_cond[r],X[t,p],xy[p],tau[t],sigma)
   A_scope[r,t,p] = softmax_p score_scope(R[r],g_scope[r],X[t,p],xy[p],tau[t],sigma)
   u_cond[r,t]  = sum_p A_cond[r,t,p]  W_cond_state X[t,p]
   u_scope[r,t] = sum_p A_scope[r,t,p] W_scope_state X[t,p]

   score 使用可学习的 C K 与 Wan state query。两种角色分别提供条件证据和待响应状态，并不宣称它们天然就是接触图/分割图。每个 head 可关注不同区域，关联允许重叠、分散及随帧变化；无对象 ID、无初始坐标硬锁定。

2. C 调节全宽状态交互算子：
   h[r,t] = F_interact(u_cond[r,t],u_scope[r,t],g_cond[r],g_scope[r],V_rule[r],sigma; Mod(R[r]))
   d[r,t] = F_time_response(h[r,0:T],u_scope[r,t],tau,delta_tau,sigma)[t]

   Mod 为全宽通道/算子调制，不是运动强度分数。响应共同依赖条件状态、受影响状态与规则上下文；不把静态 V_rule 通过另一条加法旁路直接写到视频 hidden。F_time_response 是同一 Wan block 内的关系状态处理，没有独立未来预测器或 rollout。

3. 使用读取作用状态的同一 A_scope 写回：
   delta_X[t,p] = O_phys(concat_heads(sum_r A_scope_head[r,t,p] * d_head[r,t]))

   同一多头 A_scope 同时用于 scope 状态的读取和响应写回；不再由一个独立 K_exec 路由把响应重新分配给另一批位置。这是计算图绑定，不是 attention 热图监督或运动幅度门控。
   每个 head 的 A_scope 在有效空间上归一化；关系响应可含正负全宽内容。多关系贡献通过 O_phys 合成，不用位置硬阈值或位移上限。首帧仍遵守 I2V 的固定观测约定，没有新增物理写入。
   这是沿用关系池化的多头结构约束，不能保证所有细粒度物理响应都可由一个关系向量表达；128 个关系状态、多头读写与原生 Wan 的逐位置/时空更新共同提供表达能力，不能把 R 当作唯一视频状态。

这份结构针对“依据读到了，但响应写错地方”：同一个当前区域参与形成响应，并接收该响应；若读错了，真实视频 FM 的反向传播同时经过读与写路径更新该关联。条件来源与响应位置仍可不同，例如加热源与被加热区域，不强迫它们重合。

六、时间与画面稳定性怎样进入计算

同一关系算子共享于所有视频时刻；每一时刻的消息取决于当前状态与关系历史，不生成互不关联的逐帧执行脚本。
使用已有 81 帧 PTS 与 21 个 latent 时间块的实际时间/跨度。时间 attention 的相对项使用 tau[t]-tau[j] 和 delta_tau[j]；物理分支可读取 j<=t 的关系历史。
保留原生 Wan 时空 RoPE、双向联合视频 attention 与扩散时间 sigma 机制。原生 hidden 已含双向上下文，所以物理分支的历史读取是顺序偏置，不能当作严格因果识别证明。
PTS 是呈现时间；慢动作/延时没有可靠现实时间缩放时，不声称知道真实物理秒数。n1 不作时钟或事件时间。

稳定性由以下训练与结构共同承担：
  - 官方 Wan 的图像、时序和原生文本能力作为起点；新增 O_phys 与 LoRA 的输出因子零初始化，其他模块正常初始化。这不是旧 Q checkpoint 的函数。
  - 状态交互值来自当前 Wan 状态和 C 规则共同计算；读写区域共用关联，减少无依据的空间改写。
  - 原生 Wan self-attention 与全视频 FM 继续学习外观、形态及整个过程；真实视频为合理变化提供目标。
  - 联合阶段训练 Wan self-attention LoRA，让执行器实际适应物理条件。
不使用压小运动、跨帧恒等、普遍刚性或 latent 守恒等缺乏物理量定义的约束。这里没有新增一条能数学保证不变形的损失，也不能宣称上述结构已验证稳定。

七、只保留两个有不同职责的目标

1. 完整视频 L_FM
   z_sigma=(1-sigma)z_real+sigma*epsilon，已观测首帧固定。
   L_FM = mean_valid_future ||v_theta(z_sigma,first,text,C,times,sigma)-(epsilon-z_real)||^2。

   目标来自真实配对视频，每个有效未来时空位置都有监督，无需框或时间标签。它通过同一生成前向更新 C、独立 K/V、共享读写关联、交互/时间算子，joint 时也更新 Wan LoRA。FM velocity 不是视频内物体速度。
   它提供生成分布与时空重建的学习信号，不直接赋予每个 hidden/attention 一个唯一可辨识的物理含义。该局限不能用“FM 本身已经保证因果”掩盖。

2. C 物理语义 L_C_phys
   从实际传给 Physical Block 的 C K/V 表示，通过一个训练专用全宽桥接进入原生语言解码器；只对目标答案 token 做教师强制 CE：
   L_C_phys = -mean_n log p(answer_n | actual_C_KV,neutral_question,answer_<n)。

   解码端不再看到首帧、原 caption 或 H，不能走另一条回答问题的旁路。原生语言解码权重固定，训练桥接与生成侧 C/Qwen LoRA；同一 Qwen 基础参数可共享，不复制额外 8B。梯度必须进入实际 K/V 与 reasoner。
   该项用于训练 C 携带场景相关物理语义，不以问答正确替代执行正确；执行学习由真实生成路径的 FM 负责。冻结解码权重也不能保证不会发生语义捷径，因此不将 CE 下降作为已经改善视频的结论。

   监督材料：已关联的 WISA phys_law、当前片段 caption/合法请求和首帧可知条件。使用离线自动文本整理得到简短条件性机制说明，保留依据，不制作区域框或事件秒数，不要求另一次全视频 MLLM 标注或人工校正流水线。
   整理目标是“若何种条件成立，会出现何种响应/变化”；不写唯一未来轨迹，不将原片裁剪外事件当作当前片段已经发生，不把 n0/n1/n2 数值估计当实测量。现有 phys_law 是候选材料，不能原样全部当确定真值。首帧/请求无法确定的事实保留条件性。
   自动整理仍是弱监督，不能保证消除原始错误。若数据无法支持某条机制，就不能把它伪装成已观测物理事实。这里不另建人工密集标注工作；离线文本整理有一次性计算成本，尚未执行或形成最终目标集。
   标签只作训练答案，不作为 C/Wan 的额外推理条件。无条件 CFG 分支不接受要求它猜被删除请求的语义答案。

总目标：L = L_FM + lambda_phys L_C_phys。不存在第三个隐藏的排名/对比/守恒/伪区域标签损失。
具体 lambda 和训练步数尚未形成已运行配置，不用虚构数值宣称充分训练。

八、两个阶段内的渐进，不增加训练阶段

阶段 A / interface：官方 Wan 与其新 LoRA 冻结。新 Qwen 生成侧 LoRA、原生 latent reasoning 接口、C 投影、Physical Block、C 解码桥接训练。
  两项损失从开始都存在；完整视频、真实时间和完整 Physical Block 自始参与前向。前期建立 C 物理语义与基本条件接口，同步通过 FM 学习在原生 Wan 上执行。
  采用普通学习率 warmup；不把 C 先独立训练成问答器后才接生成器。接口内不再存在 source/scope/phase 权重递进，因为它们已经删除。

阶段 B / joint：继续两项损失及所有新物理模块；新增 Wan self-attention LoRA 的学习率从零平滑提高，C/Physical Block 优化状态连续。
  可以使用 r(u)=3u^2-2u^3 对 joint 初期学习率做连续 warmup；此日程调学习率，不调推理注入/运动强度。原生 text Q/K/V/O 与基础权重保持官方参数。
  渐进体现为从“物理接口学习适应原生 Wan”过渡到“Wan 与 C 联合学会物理执行”，不是依靠生成视频打分达到阈值后解冻。

训练噪声范围应覆盖部署去噪过程；不只用低噪声下已有真实未来内容的输入学习 C。普通低噪声样本也保留，不把纯噪声端点当成唯一确定未来。既有数据与同一目标即可，不新增样本扰乱/反事实视频或对比实验阵列。

九、实现范围与与 V3 的具体差异

删除：source/scope/phase 标注 sidecar 依赖、三个损失和对应读出头；V3 独立 K_exec 写回路由。temporal FM 不启用。
保留/落实：Qwen 原生可微 latent reasoning、4096 处理后投影、独立 C K/V/O、原生文本路径、首帧几何对应、当前状态双角色读取、真实时间、两阶段 Wan LoRA 联合训练。
新增关键计算：将 A_scope 的读/写绑定为同一张多头关联；C 通过规则上下文与状态交互算子产生响应，不提供独立静态加法消息旁路。

data.py：保留全部 RGB PTS、latent 区间、图像几何与已有物理文本材料；不读区域/事件强标签。
knowledge/reasoner：原生 latent reasoning 与生成侧 LoRA 梯度，不再 detach；仅合法输入；新模块初始化。
PhysicalBlock：实现共享 A_scope 读写、状态交互、时间处理和独立输出；所有 attention 保留 mask，不构造 [B,R,T,P,3072] 巨型中间张量。
generator/native_attention：传递真实时间与 C context，保留原生 text attention；通过正常可微前向更新新模块。
training：仅 FM + C 物理语义；冻结 Wan 不能使用 no_grad 切断其输入梯度；joint 增加 self-attention LoRA。

十、可执行性与证据边界

无密集人工补标的训练方案成立：真实视频、首帧、caption、PTS 和 phys_law 材料已有。成本从新增人工位置/阶段标签，转为一次自动文本目标整理和本来就需要的模型训练。
相较 V3，明确放弃了精确区域/阶段的外部监督；内部关系的可辨识性较弱。架构共享读写、真实时间、物理语义与生成联合学习是解决这一缺口的主要方法，但不能保证从观察数据恢复唯一真实因果关系。
真正能支撑本方案的论点是学习路径和数据确实存在，不是“少了标签效果肯定一样”。目前没有新训练结果证明其优于旧 Q；也没有新实验被启动。

物理 query 使用 C 分支独立的 3072->3072 投影，原生文本 query 保留自己的投影。C 的调制输出为两组 3072 的 gamma/beta；来源映射 G 为 [B,P0,P]。

C 语义读出每批轮换一个实际注入层：三组实际 K/V 各 [B,128,3072]，沿通道拼成 9216，经训练 bridge 到 4096，再用冻结的原生语言解码器监督。该选择避免把十层同时拼成一个巨大通道；各层仍接收完整 FM 梯度。
