2026-10-28：WISA 能提供哪些物理监督，哪些还需要构建

当前设计更新：供检查方案为 PHYSICAL_ENHANCE_FUSION_BASELINE_V5.txt，来源/作用区域/过程阶段损失及相应复杂结构均移除，不开展区域/事件补标。下文保留数据能力与 V3/V4 方案的历史分析；C 类补标及第六节的双角色读取等不再是当前设计。已有数据能力与来源关联结论继续有效。

结论：可以基于现有 WISA 构建新的物理训练方案，但不能把它当作已具备逐帧位置、接触时刻和精确物理量的数据集。真实视频及其呈现时间可直接监督生成；物理文本可作为需要结合片段整理的弱语义来源；精确空间/事件阶段监督需要新增标注。整个方案不使用 verifier，不将未经测量的数量范围冒充真值。

二、已有字段及实际含义

1. 视频与时间：全部 3,857 条都有递增 PTS。当前 81 帧裁剪的呈现时间跨度约 1.333–5.333 秒。data.py 当前已提取每 4 帧一个 latent 时刻，但 native C 分支没有将 times 传给物理执行。
2. phys_law：全部 3,857 条有原始物理说明。可以补充条件、机制、持续/终止、允许变化等语义监督，但原文并不都是真实片段的事实描述。
3. q0/q1/q2：动力学、热学、光学的文本类别；q3 是相机运动，q4 是出现/消失/分合等变化类别。它们是片段级、自动生成的弱标注，不是逐帧事件状态。
4. n0/n1/n2 及 quantify 字段：密度、时间范围、温度的语言模型估计。不能当作实测物理参数或接触/响应事件时间。
5. label：原始收集类别，17 类。适合了解内容覆盖，不构成细粒度物理正确性真值，更不能把模型能力限制为 17 个固定专家。
6. 无语义 bbox/mask、逐帧参与区域、接触点、接触时间或状态转移事件表。text_bbox_num/text_bbox_ratio 是画面文字检测统计，不是物理主体或作用区域框。

现有缓存 category 是 unlabeled 或缺失；interactions/objects 均没有非空有效内容。当前 VideoDataset 不读取原始 physical_annotation。由此不能说这些原始物理标签已经训练了当前 C，也不能把恢复字段本身称为已完成物理监督。

三、时间字段尤其不能混淆

在 3,857 条关联记录中：
  - 3,311 条的 quantify_n1 上限超过原始视频 duration；约 85.8%。
  - 若把 n1 误当原片实际事件区间，有 685 条与缓存选取的原始 PTS 区间无重叠。

这些数字证明它不能直接作为片段事件定位，不是“85.8% 的所有物理知识都错了”的估计。官方论文的标注提示词明确要求语言模型基于 caption 估计现象时间范围，并非从逐帧观察测量事件边界。

另外，PTS 是视频呈现时间，未必等于现实物理时间。当前 caption 中至少 15 条明确提到 slow-motion / time-lapse 等词；这只是文本指示，不是完整的拍摄时间缩放标定。源数据没有可靠的通用播放时间到现实时间转换系数。

实施结论：生成器先接入可核实的 PTS 秒数及相邻间隔。普通实时视频中它可近似对应现实时间；慢动作/延时不能未经说明按现实秒数解释。没有测量依据时不监督绝对速度、密度或温度，也不把 n1 用作模型的时钟。

四、原始说明与当前 81 帧裁剪也不总是一致

1,893 条当前 caption 与原 WISA caption 文本不同。原 physical_annotation 是对原 caption 的分析，而训练读取的可能只是原视频的一小段。即使原文机制合理，也不能直接假设该机制的启动、全过程和终止都出现在当前裁剪中。

具体例子：source0000000 的真实裁剪显示煎盘上的肉饼及边缘液体/气泡，原收集 label 却为 collision，q1 又包含 combustion。这些字段不能证明画面发生了碰撞或燃烧。首批三个现有片段的抽帧记录已保存；抽帧只说明已查看的可见内容，不用它推断未观察到的精确事件边界。

这类问题应在制作物理训练目标时解决。不能简单把整个 phys_law 和 q 标签强制注入，也不能因为标注有缺陷就放弃 WISA 已有的视频与机制信息。它是新设计需要处理的监督内容问题，不是已量化的新旧 Q 相对退化归因。

五、可执行的监督构建办法

A. 可直接使用：
  配对真实视频的 FM；81 帧 PTS 与 latent 时间映射；首帧同区域的 Qwen/Wan 网格对应；原始输入来源与 train/validation 分割。历史 temporal FM 也可由已有视频计算，但已从新主方案移除，见 V3 第十二节。

B. 可以构建，但只能按弱标注或整理后的语义目标使用：
  从 phys_law 与当前 caption 整理场景相关的条件—响应、持续/终止、合理变化/保持和未知项。用于 C-only 教师强制监督，不作为推理时额外的标准答案，也不直接扩大原生文本提示词。
  原始数字估计不转为数值回归目标；宽泛类别只作辅助语义，不作为物理执行路由的硬标签。涉及实际裁剪外的具体事件，不成为该片段必须发生的执行目标。

C. 需要补标，原 WISA 不直接提供：
  少量关键时刻的条件相关区域与受影响区域，以及实际发生的过程事实/时间区间。标注锚定缓存选中的 RGB 帧与 PTS，不要求全视频逐帧实例分割、对象 ID 或轨迹。
  对持续过程，只标可见的持续/扩展状态，不强补开始与结束。对液体、气体、波，标区域或界面而非固定主体。看不见的接触、来源或参数保留未知，不能标成确定不存在。
  可用 MLLM 提议离线候选事实，但它们仍是弱标签，需要依据实际视频整理；没有证据时不能升级成强标签。此工作只制作真实训练数据的标注，不构建生成视频的评分器。

六、对模型设计的直接影响

1. Physical Block 保留来源桥接、当前条件/作用范围双读取、MLLM 隐规则调制、真实时间关系处理和全宽响应写入。
2. C 语义监督确实有可恢复的数据来源；已经准备了按片段关联的原始来源文件。
3. 精确的空间/阶段损失不再写成“现有 WISA 开箱即有”。在补标片段上监督；无该标注的片段继续贡献真实视频生成与适用语义监督，不伪造标签。
4. 直接生成学习的梯度进入 Physical Block 与 Wan LoRA；不通过 verifier、视频读出器评分、奖励、排序损失或自评校准来绕过缺失的标注。
5. 从官方 Qwen/Wan 基础模型全新训练项目模块，不读取已有实验 checkpoint。旧 Q 仅保留为画面质量的历史参考。
