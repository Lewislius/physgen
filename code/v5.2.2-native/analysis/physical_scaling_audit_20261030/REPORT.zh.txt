Physical scaling 训练与表示审计
2026-10-30；实验事实、解释与设计建议分开记录。

当前结论的集中整理见同目录 EVIDENCE_FOR_MANUSCRIPT.zh.txt。下文保留原三方案审计及后续实验的过程记录；开头涉及“当前三个版本”的结论指 Search66678/66706/66710。

结论

当前三个版本的训练和注入路径确实在运行，但“具有场景相关物理内容的 C，驱动正确的、随状态变化的物理执行”没有得到现有结果的支持。问题集中在三段：Q→C 丢失内容差异；辅助目标允许非常便宜的低信息解；实际生成目标没有充分区分物理过程中的关键错误与大量一般重建内容。继续按同一配方增加步数、Q 数量或辅助损失权重，缺少能够改善上述问题的机制。

这不是用 FM 是否单调下降判断模型好坏。也不把更大的 RGB 变化、更小的 RGB 变化或任意 token 多样性当成目标。目标是保留视觉稳定性，同时使生成满足相关物理条件、作用、响应和应保持的性质。

用户举的小球是“关键物理错误可能被整体目标稀释”的例子。问题同时涉及短暂事件、作用与响应不一致、错误的事件顺序、长时依赖，以及大范围但细微的变化，不能收窄为小物体优化。

二、实际训练范式

输入侧冻结 Qwen：首帧 + request → 最多 4 句物理分析 → 再读取首帧、request、分析，取得 hidden memory 和每句均值向量。生成侧没有未来视频输入。

Q 是 256×4096 可学习种子；assoc 把每句 relation 向量重复分给一组 64 个 Q。三个版本目前全都包含 self-attention：共享 MessageBlock 连续运行两轮，每轮 cross-attention → self-attention → FFN，使用残差连接。最后 RMSNorm → 4096→3072 线性投影 → RMSNorm 输出 C。

这两轮是新训练的共享增强模块，不能等同于冻结 Qwen 自身又执行了两轮预训练推理。

Wan 原生 text cross-attention 保留。在第 3、6、…、30 层加入独立 C K/V/O；query 来自当前 Wan 隐状态和时间特征。C 在一个视频内静态；物理写入从第二个 latent 时间步开始，首帧不写入。所有 30 层 native self-attention/FFN 配有 rank32 LoRA。

V6 的 C K/V 是冻结的原生文本权重副本加 rank32 LoRA；V5 的 C K/V 是独立全量可训练矩阵，因此 V5/V6 不只是 loss 不同。V6 可训练参数约 3.78 亿；V5 约 5.76 亿。Q128→Q256 仅新增 524288 个种子参数，不是整体模型容量翻倍。

训练为 128 步接口适配 + 872 步 joint，accumulation=4。每个完整 run 共 4000 次样本使用，3666 个不同训练样本，其中 3332 个见一次、334 个见两次；405 次条件 dropout，3595 次有效辅助监督。数据集验证集 191 个样本，但固定 FM validation 仅使用 4 个样本，不能据此评估全面泛化。

学习率角色峰值：enhancement 5e-5、fusion read 2e-5、fusion O 1e-5、Wan LoRA 2e-5；32 步模块 warmup、128 步 Wan warmup，后段衰减。assoc λ 从 .03 到 .015；write 从 .005 到 .002；V6 再乘 (1−σ)。CE λ 从 .03 到 .015，不乘 (1−σ)。旧 224 配方同时在阶段长度、LR、Q 数和损失权重上不同，不能把新旧差异全部归因于“步数”。

write 原 run 被 SIGKILL（137）中断，恢复的是本 run 自己的优化器、RNG、数据游标；最终完成 1000 步。日志不支持将问题归因于数值爆炸或恢复时换了训练目标。各模块都有梯度；没有持续的梯度裁剪饱和。接口期 O 的裁剪次数较多，不能因此断言后期训练失效。

三、V6-assoc：低 KL 基本可以被常数预测达到

目标每个位置有 5 类：[reference, relation1, relation2, relation3, relation4]。它们不是五个固定物理类别。

teacher 构造是：每句 relation 对视频 visual token 的注意力，先对多个 query token、head 和末四层做平均，再把每句在整段视频上的质量归一化为 1。背景句也同样处理。最后取 log(relation attention/background attention)，把 reference 的 logit 设为 0，再 softmax。

因此，当四句与背景看向相似位置时，五类自然接近各 20%。一条不适用的 relation 也被归一化为总质量 1；目标丢失了“这句话是否得到足够视频证据支持”的绝对信息。reference 不是校准过的“无事件/不适用”分类器。这是目标定义的问题，不能只靠调 temperature 修复。

3324 份目标的统计：
  平均归一化熵 H(P)/ln5 = 0.958626。
  均匀预测的 KL = 0.066589。
  reference 平均概率 = 0.204112；reference > .5 的位置比例只有 0.2217%。
  最大类别概率均值 = 0.308916；最大概率 > .5 的位置只有 2.6392%。

最后 50 步同一批 180 个有效 micro-sample：
  训练记录的实际模型 KL = 0.0675812。
  每个位置固定预测 [.2,.2,.2,.2,.2] 的 KL = 0.0676748。
  相对改善只有约 0.138%。

这组常数预测是在相同标签、相同有效区域上离线计算的比较器：不用读视频、C、时间、位置就能输出它。不是说生成模型完全没读视频，也不是把带未来信息的 teacher 当可部署 baseline。

公式：KL(P||Q)=Σk Pk ln(Pk/Qk)，先每位置求和，再按有效位置平均，模型辅助项再平均 10 个融合层。Q 是每头 attention 在各 relation 组内求和、跨头取平均后的实际路由概率。均匀 Q 时 KL=ln5−H(P)。95.9% 熵接近均匀，意味着即使不识别具体关系，也能拿到很低的 KL。

例：P=[.12,.32,.24,.18,.14]，Q=[.2,.2,.2,.2,.2]，KL≈.06396，归一化熵≈96.03%。如果 teacher 确认第二类为 1，uniform 的 KL 才是 ln5≈1.60944。95.9% 不是“95.9% 标签相同”或“模型准确率”。

第一段 50 步实际 KL≈.13876，uniform≈.06877；到最后接近 uniform。低 σ 分组也没有显著甩开常数解，所以不能全部归因于大噪声。各视频时间平均的 teacher 空间分布能把 KL 降到约 .03279，但这是使用 teacher 的诊断 oracle；它说明弱标签的变化更多是静态布局差异，不等于学到了时序物理执行。

梯度路径方面：当前层 association KL 直接约束 Q/K/路由，不直接监督同一层 V/O 写什么；后层损失可以通过隐状态间接影响前层写入。正确路由本身也不等于正确物理作用，而目前路由还接近常数解。

四、C：差异不是只在一个度量里变小

最终 48 样本均值：
                   token cosine     token 去均值能量/总能量     能量有效秩
  V6-assoc          .99995897         .000041649                1.000508
  V6-write          .99999815         .000002588                1.000046
  V5-CE             .99999601         .000004490                1.000079

上表去均值能量换成百分比为：assoc 0.004165%、write 0.000259%、CE 0.000449%。它表示远离同一视频 C token 均值的能量比例，不能解释成“剩余有效物理信息百分比”。能量有效秩定义为 exp(−Σ p_i ln p_i)，p_i 为奇异值平方归一化；不是严格代数秩。

仅 40 个 benchmark 样本，C 的样本均值两两 cosine：assoc≈.99996018，write≈.99999303，CE≈.99975145。除了视频内部 256 个 token 接近一致，不同输入视频的 C 也接近共同方向。

assoc 组内 cosine≈.99999897，组间≈.99994589。命名的四组并没有形成明显区分的物理 value 内容。

同一个 Q256 assoc run 的固定 probe：128 步去均值能量约 .0612%，500 步 .00565%，1000 步 .00421%，约缩小 14.5 倍。表示退化在接口期已经出现，之后继续加重。旧 Q128 assoc224 的 token cosine≈.9998688，也已有明显问题；1000 步不是首次出现问题。

一个固定样本 VP015 的两轮轨迹：
  加 relation 的 Q 种子     cosine .96203，RMS 1.004
  第一次 cross-attention   cosine .97896，RMS 1.360
  第一次 self-attention    cosine .99601，RMS 3.121
  第一次 FFN               cosine .99827，RMS 4.768
  第二次 cross-attention   cosine .99868，RMS 5.454
  第二次 self-attention    cosine .99937，RMS 7.902
  第二次 FFN               cosine .99957，RMS 9.620
  最终线性投影之后         cosine .99998

主要问题是共同更新的累积压过原有内容差异，最后投影再进一步压缩差异。原 Qwen memory 的采样 token cosine≈.209；四句 relation 均值 cosine≈.950。不能把最终 .99998 解释成“Qwen 本来就没有信息”。

在训练好的模型上临时去掉 self-attention，C cosine 仍≈.999891；去 FFN 或只做一轮也仍高度趋同。它说明有多处共同作用，不是支持“只删 self-attention 就能解决”。这些是推理结构干预，不是重新训练后的架构比较。

差异进入真实 learned V/O 后同样很小。第 3/15/30 层的 O V(C) token cosine：
  assoc .999987 / .999713 / .999909
  write .999642 / .999714 / .999860
  CE    .999999 / .999948 / .999976

如果 V_j≈v0，则 Σj a_ij V_j≈v0。即使 q 来自动态 Wan 隐状态，改变 a_ij 也难以改变写入方向。assoc 多一个零 value reference 后，能更容易调节公共方向的幅度；仍不等于按关系写入不同的物理内容。随机 query 探针只用于验证这一代数机制，不被当成真实 Wan 激活统计。

另一个接口线索：原生 T5 经 Wan text_embedding 后的有效内容 token RMS≈.133，C≈.998；前者 token cosine≈.059、去均值能量≈89.4%。当前 C 与原生上下文的尺度/分布差异很大，而 C K/V 初始化复制原生 text K/V。宽度都为 3072 不等于表示语义与统计接口已对齐。此比较排除了 padding；它是适配线索，不是断言 C 必须复制普通文本的全部分布。

五、V6-write：零写入并不是昂贵的错误

目标为 support × 原生文本 O(V(text_anchor))；每层只有最多 4 个 anchor 方向。这些向量来自文本特征，不是已被验证的“该时空位置应该加入的正确 Wan 隐状态残差”。目标对 V/O 语义与幅度的假设仍未建立。

全部 3324 份目标：support 总和均值约 .010876；虽然 90.74% 位置存在某个正值，80.77% 位置的 support 总和小于 .01。“有正支持”不等于“有强、可靠的监督”。每句除以全视频最大值，会使异常峰值支配其余位置的尺度；该异常机制是合理风险，原始未归一化 map 不在缓存内，尚未直接证实。

最后 50 步相同 180 个有效样本：实际 auxiliary≈.123775，完全零写入的离线目标损失≈.111384。按平均值，零写入更低；87/180 个单样本也由零写入取得更低损失。对模型不利的这条结论不是靠 FM 数字得出的。

正常的目标 RMS 都高于实现中的下限，不能把问题归咎于那个下限。真正的问题是目标是否代表正确执行、支持值的分布、按整段视频平均的回归，以及低秩文本方向构造出的捷径。

最后阶段 write 加权 auxiliary 相对 FM 的标量比约 .043%；assoc 约 .178%。这只说明标量量级，不能据此断言梯度影响同样小；判断应结合梯度路径和上述常数/零写入比较器。

六、V5-CE：要区分“前缀有用”与“前缀内容有用”

CE 的冻结 Qwen decoder 只有 bridge(C) 前缀、固定通用指令和 teacher-forced answer；没有原图/request 旁路。但是 teacher forcing 已经给了答案前文，因此低 CE 可能来自通用任务前缀和语言续写，未必来自当前样本的物理信息。

对应的直接实验已经完成 16 个均匀抽取的缓存样本：同一目标答案，分别使用正确 C、其他样本 C、将所有 C token 替换为本视频 C 均值、零 C、去掉 C 前缀。平均 CE 分别是 1.669017、1.688762、1.667950、3.068569、3.012386。前 8 个答案 token 的平均 CE 分别为 2.249855、2.332263、2.255892、7.318389、7.109345。完整结果写入 ce_probe/results.json；脚本 gpu_ce_probe.py。

正确 C 相比无关 C 有小幅收益，不能说毫无样本内容；但与去除整个前缀带来的大幅损失差相比，样本内容的作用弱得多。均值 token 替换几乎不影响 CE，直接说明这个 decoder 任务几乎未利用 256 个 token 之间的差异。

即使“零/无 C”明显变差，如果“错误场景的 C”几乎不变，也只能证明非零前缀有任务/分布作用，不能证明模型使用了正确条件的物理内容。若均值重复的 C 与原 C 近乎等效，256 个 token 的差异没有被该任务明显利用。

七、Qwen reasoning 与实际条件干预

3727 份训练 reasoning 全部正常结束，平均每句约 11.11 个词；128-token 生成预算不足不是这些缓存的主要问题。prompt 允许最多 4 句，但这些实际缓存全都生成了 4 句；需要避免以填满四句为习惯的无关内容。

实际缓存存在内容质量问题：某训练样本把阳光写成海浪起泡的原因；另一个把云底降低归因于云质量向下压。VP006 对请求的扭湿画布，分析偏向“画布干燥、未被操作”；VP032 对扣球请求写入不相干的汗滴。输入既可能遗漏未来需要发生的过程，也可能提供错误因果关系。

不过 raw hidden memory 保留了明显差异，Q→C 进一步抹平差异是独立且更直接的证据。只改善语言 prompt 而不修增强模块和目标，无法保证这些改善能传到生成。

实际生成干预固定首帧、原生 T5、噪声 seed42、50-step sampler、CFG5 和全部 Wan/LoRA：
  VP014 donor=VP025；VP015 donor=VP032。
  swapped 替换正/负 Qwen evidence；image_only 使用本图无 request 的 Qwen 分析；no_c 将物理输出矩阵置零。
  image_only 并非全零张量：首图及图像条件 reasoning 仍存在，原生 T5 request 也仍存在。

两例 unrelated C 相对原 C 的范数差异约 1.06%。在相同实际去噪状态 x 上替换 C，CFG velocity 相对差异约 1.1%–6.3%，正条件预测差异约 .18%–1.00%。因此不能说 conditioning 完全不起作用，也不能从 cosine 直接推出视频逐像素相同。

可视检查见 ablation_VP014.png / ablation_VP015.png：正确、无关、image-only 分析的大致过程高度相近；关闭 C 则可出现更明显的姿态/水滴分布变化。该结果支持“公共物理分支有影响，但针对正确 reasoning 的选择性收益很弱”的疑问；两例不足以证明全 benchmark 等价。视频干预不是简单的 hidden-state 距离探针。

这6段视频的独立AutoEval也已完成：正确、无关、image-only条件在VP014均为SA2/PC5，VP015均为SA3/PC4；关闭C后VP014为SA2/PC4，VP015仍为SA3/PC4。这些离散分数与视觉检查一致，但不能证明视频完全相同或对所有case等价。

全零 evidence 是另一种干预：它可使 C 发生很大改变，属于偏离正常输入分布的张量操作。不能拿这种变化作为“正确物理语言被有效理解”的证据。

八、VideoPhy2-40 的实际变化

V6-assoc：
  Q128/224：SA=3.125，PC=3.350，(SA+PC)/2=3.2375，Joint=11/40=27.5%。
  Q256/1000：SA=2.975，PC=3.450，(SA+PC)/2=3.2125，Joint=10/40=25%。
  SA：1 胜、32 平、7 负；PC：5 胜、34 平、1 负。
  28/40 个样本 SA 和 PC 两个分数都完全不变。
  Joint 唯一变化是 VP015 从通过到未通过，没有新增通过样本。

paired bootstrap 的 mean-score 差值 95% 区间为 [−.1125,.0625]。这不是有可信提升的结果。SA 差值区间 [−.275,−.025] 提示该固定子集上的语义遵循下降；40 个样本、单 seed、单自动 evaluator 的范围必须保留。

旧 V5-CE224：SA3.15/PC3.40/Joint25%；旧 write224：SA3.05/PC3.40/Joint22.5%。另两个 job 66761、66760 的完整推理和评分现已完成：CE1000 的 SA3.075/PC3.45/mean3.2625/Joint25%；write1000 的 SA3.00/PC3.475/mean3.2375/Joint22.5%。两者 Joint 通过的具体样本与各自224版完全相同，没有新增通过样本。CE的SA为0胜37平3负，write的SA为2胜34平4负。完整数据见 new_completed_evaluations.json。

历史 independent LoRA 的 Joint17.5%、历史 joint-LoRA-only 的22.5%，都不是这三个 1000-step run 的严格同配方基线。不能用 10/40 比历史 7/40，直接声称实现了可归因于 C 的相对提升。

外部协议：Joint 需要 SA 和 PC 均≥4；PC 只看视频，SA 看视频+caption。因此视觉上自洽但没有发生请求事件的视频可能 PC 较高。这里是固定首帧的 I2V-40 适配，不是官方完整 T2V 排行榜。官方来源：https://github.com/Hritikbansal/videophy/tree/main/VIDEOPHY2

例如 VP014 请求水气球向上抛出并在空中爆开，实际首帧和输出更接近水滴落入水面。PC 上升并不能证明请求的因果过程执行正确。VP025 的塑料蛋上滚再下滚、VP030 的雪球抛出破裂也需要分别看对象保持和事件完成；不能把“画面更平稳”本身写成物理改进。

九、FM 的关键问题：监督平均与物理相关性

当前实现 error=(prediction−(noise−clean))²，先对 latent channel 平均，再对全部有效未来时间/空间位置平均。没有按物理关系、关键事件、作用/响应或事件阶段单独分配预算。此处 FM velocity 是去噪路径导数，不是视频中的物理速度。

直观例子（说明机制，不是本 run 实测误差分布）：某关键过程覆盖 1% 有效时空位置，其误差从 1 变成 4，其他位置都为 1，总体平均只从 1 变成 1.03。如果其他99%位置改善约3.1%，整体 loss 甚至下降，但关键物理过程明显更错。关键内容可能因面积小、持续时间短、语义稀有、或只影响少量表征维度而被稀释。

同时，全局 FM 优化了真实视频重建，不等于它对每种物理语义的偏差有足够辨别力。不能因此把 FM 说成无用；应保留其真实生成监督，并补足“什么错误重要、C 如何对此负责”的训练结构。

设计建议详见 DESIGN_REPAIR.zh.txt。当前没有逐区域 FM 日志或逐事件真实标注，不能把“稀释机制成立”扩大成“已测得某次球形变贡献了某个百分比的 loss”。
