保持现有主干的物理内容修订：实施与迭代说明
2026-10-30

目标是 C 携带对当前场景有意义的物理差异，并使这些差异帮助模型正确生成过程。主干仍是冻结 Qwen → learnable Q 增强 → 全宽 C → 当前 Wan 状态参与的物理融合。原生文本和 Wan 执行能力保留。新版单独位于 experiments/physical_content_v7，不覆盖旧实验。

首个修订采取一条完整的改进链，而非继续给原来的均匀 KL 或合成 residual 提高权重：

1. Q 以真实物理语句的内容 token 为锚点。

原 assoc 把每句的一个均值复制到 64 个位置，而无分组的版本从小幅随机种子开始，第一次公共 cross-attention 更新就压过种子差异。新版从现有 Qwen memory 中恢复每个物理词的 hidden features，去掉 RELATION 编号等格式 token；依照各句真实词序为 Q 提供内容锚点，保留 learnable seed。

256 是槽位预算，不是必须制造 256 个不同物理概念。允许同一物理关系中的相关内容相似；不同条件和关系的差异应来自实际输入语义。

2. 保留 self-attention，改变混合方式和残差组织。

每个 Q 以本句的内容词为锚点。实际 R1 实现的 cross-attention 仍读取完整的可用 Qwen memory（首图、request、reasoning），其 mask 只排除无效 memory token，并没有限制为本句；随后 self-attention 使用本关系内的 Q token 和所有关系的摘要。两轮共享更新保留。内容锚点有直接残差路径，更新分支独立归一化，避免共同更新从 RMS1 累积到 RMS10 后淹没内容。关系内 token 加跨关系摘要限制的是 self-attention 的混合范围，不能把它表述为整条增强链都已按关系隔离。

简单删除 self-attention 不作为首选：已有模型临时删除后的 C 仍高度趋同，cross-attention、FFN 和最终 projection 都参与退化。也不把关系完全隔离，否则会损害相互作用推理。

3. 修复我们自己的 Qwen→C 接口，利用已有 Wan 语义空间。

仅有 3072 的宽度不足以使 C 自动成为预训练 Wan 可理解的条件。使用冻结的官方 T5 和 Wan text_embedding，对输入侧 Qwen 物理分析中的相同词取得原生语义目标。只使用训练集的首图/request reasoning，不使用未来视频分析。

在已有训练数据上拟合一个全宽的 Qwen-word-feature→native-word-feature 线性接口，作为本修订新模块的初始化。该映射的内容路径固定保留，Q 两轮更新学习全宽修正。推理时依然从 Qwen hidden 与 Q 生成 C，不增加一条直接把 T5 物理文本拼进 Wan 的替代路径。

这样既避免用随机方向制造差异，也不要求生成器从零猜测几乎任意的 C 坐标含义。接口拟合必须报告留出集误差和内容区分能力；若只拟合出公共均值，不作为成功初始化。

训练侧的内容辅助项直接约束对应物理词的全宽 C 表示。它不依靠 teacher-forced 答案前文续写，也不把句子平均成一个恒定任务前缀。它的作用明确限定为保留内容，执行是否正确仍由真实生成监督和视频结果判断。

4. 物理融合同时使用 C 内容和当前状态来产生写入方向。

保留独立 K/V/O 和当前 Wan hidden query。扩展为：
  z_i = Attention(q(h_i,t), K(C), V(C))
  write_i = O[z_i + U(norm(h_i)) ⊙ z_i]

U 输出全宽向量，初始为零，保持初始接口可控；它学习不同状态下物理内容怎样影响各特征维度。与只有 attention 权重变化相比，这使“相同物理规律在不同状态下产生不同作用”有直接表达路径。原生文本和 hidden-state 演化仍由 Wan 承担。

这条交互支路单独也可能退化成普通适配器，所以必须与内容保留及正确/无关条件对照联合验证，不能只展示写入场有变化。

5. 生成监督针对“错误被平均稀释”，不把任务收窄为小物体。

保留原始真实视频 FM target。首轮在平均 FM 之外，增加有限权重的时空分块高误差聚合；包含整幅画面和不同持续长度的片段，使短暂事件、局部错误或局部时间段不因覆盖率低而自动失去训练份额。该项只重排同一真实生成误差的预算，不添加轨迹/物理速度或人工事件标签。

它是对平均稀释的通用改善，不能被包装成完备的物理监督；高误差纹理也可能被选中。匹配 baseline 必须使用同一个生成目标，因此之后的条件对照才能检验 C 是否提供额外物理收益。

若内容链修复后仍存在“全局看起来合理、某个关键过程明显错误”，下一轮针对实际失败类型加入已有冻结模型提供的过程特征监督：在真实视频与当前预测的可比片段上进行表征匹配，保留梯度回到 C/融合和 Wan LoRA。空间范围可局部也可整帧，时间范围可短事件也可持续过程。不要固定成物体框损失，更不要把相邻帧越相似当成越物理。

可用的外部能力：SAM2 可提供可分割对象/材料的自动支持区域；DINOv2 可提供局部视觉特征。前者不能覆盖所有气体、波动、涌现过程，后者本身不是物理时序判别器。它们只为实际失败过程补充直接监督，不作为生成侧评分器，不以低特征距离代替物理改善结论。首轮不依赖下载新模型，以已有模型和缓存尽快建立可测结果。

6. Qwen reasoning 的内容也需要迭代。

分析必须围绕请求过程中的物理依赖，区分可见初态与未来条件响应，避免把“首帧尚未发生”写成“后续不应该发生”，也避免与过程无关的汗滴、气流或编造的因果链。允许只有一两条有依据的关系；不为填满四句加入内容。现有缓存的 token 预算和正常结束不是瓶颈。

首轮用现有缓存建立内容通路是否有效的可比结果，随后将暴露出的错误 reasoning 按新缓存版本修正。对实际生成要同时比较正确、语义接近但条件错误、无关、image-only 和关闭 C；先用少量有明确物理过程的固定案例定位，再扩大到固定 40 例。不能用全零张量导致的大变化充当语言内容被正确使用的证明。

7. RoPE 的结论与实施位置。

learnable query 可以用 RoPE，但需要先说明位置代表什么。当前槽位序号 0…255 不是物体坐标、时间或物理距离，直接旋转它们只会增加编号相关性。它不解决当前值内容趋同：若 V_j=v0，则对任意包括 RoPE 在内的注意力权重，Σa_ij V_j=v0。

内容锚定之后，组内每个位置对应物理句中真实词序，可在新增强模块的组内 Q/K 上使用相对位置旋转，按每句位置独立重置；关系编号本身不作为连续物理距离。跨关系摘要保留内容交互，不给它编造时间/空间坐标。冻结 Qwen 自身的位置编码和 Wan 原生位置编码保持原样。

因此首轮优先修复内容锚点、更新和投影，再比较有无组内 RoPE。不能通过旋转输出 C 的向量来人为降低 cosine，更不能用这种降低宣称物理信息增加。
  RoFormer 原始论文：https://arxiv.org/abs/2104.09864

8. 实验与判定。

新候选与 native Wan+LoRA baseline 从官方 foundations 开始，匹配训练数据顺序、噪声、总更新预算、生成目标和推理设置。候选保留 128 步接口适配，先运行到400步中期检查点；使用与继续至1000步兼容的同一schedule。native baseline在完整400/1000步内都训练LoRA，不跳过候选的接口阶段，因此它实际获得更多Wan-LoRA更新。这个差别必须明确报告。正确/无关/均值/关闭C的因果对照则固定同一候选checkpoint的所有Wan参数。

先看 C 内容是否保留、实际条件干预是否产生与条件相符的过程差异，然后比较真实视频的 SA/PC/Joint 与具体过程完成情况。成功需要正确条件的优势，而不是仅 no-C 与有-C 不同。若只是使错误条件变差，而正确生成没有优于匹配 baseline，也不满足目标。

当前修订是由实测问题驱动的候选，不把写出方案、单元验证、C 不趋同或 loss 降低当成完成。继续训练、配对评估和迭代，直到有足够的实际收益证据。
