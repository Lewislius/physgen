# Corrector 门控退化、写回影响与稀疏校正方案

对象：`20260912T151800Z-e189c27c` 的 A1 checkpoint。日期：2026-09-13。

**判断：值得将每次 Wan 前向的六个校正位置缩减为一到两个，重新验证位置；但“少插几个模块”主要减少冗余、容量和重复写回，并不能独自解决状态门关闭。更合理的方向是：稀疏位置 + 可持续学习的状态增量 + 保守写回 + 与部署一致的 P₀ 条件。**

本文重新核对了本 run 的 500 步日志和实现，只补充与上述问题直接有关的分析。没有修改训练/推理代码、没有运行新生成或新增测试。已有画面证据见[原诊断报告](20260913_61018_checkpoint_final_生成质量与训练全流程诊断.md)，本次新增统计见[JSON](corrector_gate_followup_stats_20260913.json)。

## 1. 先把“更新”和“写回”分清

`H` 是 Wan 当前层正在处理的视频特征；`P` 是外挂维护的时空状态；`P₀` 是这次前向的初始状态。一个校正位置实际做三件事：

```text
① 读取：让 P 查询当前 H，得到观察信息 O
② 更新：结合 P、O、文本和噪声强度，提出 delta，再更新 P
③ 写回：让 H 查询更新后的 P，生成 residual，加回 H

P_after = P_before + η(σ) × g_state × delta
H_after = H_before + γ(σ) × g_write × W(retrieve(H_before, P_after))
```

这里有三个不同的门：read gate 控制读取 H 的观察量；state gate 控制 P 的变化；write gate 控制向 H 写入的信息。**state gate 接近零，只关闭第二步的增量，不会自动关闭第三步。** [对应源码](../physgen_v4/corrector.py:411)

“写回”既不是保存 checkpoint，也不是直接修改 RGB 像素，而是改变 Wan 中间特征，之后经剩余 Wan 层、输出头和采样器影响生成视频。P 本身没有直接解码成视频。

还要区分三个次数：

| 层次 | 当前设置 | 本文建议 |
|---|---|---|
| 视频的去噪步数 | 50 步 | 暂保持不变 |
| 一次 Wan 前向中的校正位置 | A@5/10/15/20/25/30，共 6 处 | 优先研究 1–2 处非固定间隔的位置 |
| 一个位置内部的 `iterations` | 1 次 P 更新，然后写回一次 | 暂保持 1，不用增加它补偿位置减少 |

CFG 每步有两次 Wan 前向，所以现在每个去噪步调用 12 次 A、50 步共 600 次；若只留一个位置，则分别是 2 次和 100 次。`iterations` 循环中 H 不向后推进，最后才写回一次，因此“一个位置重复六次”不等价于“六个位置各校正一次”。

## 2. 不是后层没有候选，而是候选被门压住了

最后 100 个训练步骤的均值如下。候选 RMS 指乘 state gate 和 η **之前**的 `delta`。

| 位置 | 候选 delta RMS | state gate | 实际 ΔP RMS | 写回/H RMS | 更新带来的结构 MSE 改善 |
|---|---:|---:|---:|---:|---:|
| A@5 | 1.086 | 0.9931 | 0.2071 | 14.98% | 0.05467 |
| A@10 | 0.833 | 1.58e-4 | 2.51e-5 | 13.56% | 2.97e-8 |
| A@15 | 0.824 | 0.001884 | 3.00e-4 | 4.60% | 4.17e-9 |
| A@20 | 0.814 | 4.09e-5 | 6.41e-6 | 3.90% | -1.15e-8 |
| A@25 | 0.762 | 4.77e-6 | 7.01e-7 | 8.31% | 1.64e-9 |
| A@30 | 0.735 | 1.61e-7 | 1.99e-8 | 0.291% | 1.64e-9 |

**A@10 的候选大小并不比 A@5 小几个数量级，但真正写入 P 的量相差约四个数量级。** A@10 的 read gate 平均仍约 0.743、观察 RMS 约 2.264，也不是因为没有读到 H。

同一次前向里，各个 A 的 η 使用相同噪声强度和配置。没有“到第 10 层以后强制关闭”的代码。差异主要发生在可学习 state gate 上。

也不能说“前面已经把目标学完，后面自然不用改”：末 100 步初始 P 的 MSE 约 **1.5288**，结构 MSE 约 **1.4741**，仍有明显误差。大 ΔP 只说明移动得多，不等于运动/物理学得好。

## 3. 为什么 A@5 工作，后面逐渐关闭

### 3.1 当前目标给了前面位置更容易、覆盖更广的职责

六个更新后的 P 都对齐同一个完整 teacher target，并取平均：

```text
L_struct = [d(P5,Z) + d(P10,Z) + ... + d(P30,Z)] / 6
```

A@5 最先看到 P₀ 中尚未纠正的误差，能优先完成容易预测的全局/粗结构修正。后面的模块接到的是已经改过的 P，剩余误差可能更局部、更难预测，或与当前 H 尚不能确定的未来有关。

**新增的关键区别是监督路径不对称：** A@5 的状态增量能沿 P 的恒等传递路径影响全部六项结构损失；A@30 的状态增量只直接影响最后一项。若只看这条恒等路径，前后覆盖的损失项数是 6 对 1；这不是实际总梯度必然相差六倍，因为还有后层网络导数、H 写回和 FM 路径。[状态传递](../physgen_v4/backbone.py:120)、[结构损失](../physgen_v4/losses.py:40)

P₀ 也同时收到这些 dense struct 梯度，本次多数训练还给 P₀ 完整 GT。因此存在“初始化器和第一个模块承担主要拟合，后层规避新增误差”的机制倾向。**这说明第一个位置有结构性优势，不能据此证明 Wan block5 天生优于 block10。** 把单个新模块放到 block10，它就成为第一个校正器，任务已不同于当前的 A@10。

### 3.2 当候选方向不能继续降低误差，缩小 gate 是一种直接解法

看一个 token，设剩余误差 `r=Z−P_before`，实际更新是 `ηgδ`。结构平方误差的变化为：

```text
更新后误差 − 更新前误差 = η²g²‖δ‖² − 2ηg〈r,δ〉
```

如果候选 δ 没有对准剩余误差，或幅度过大，更新就可能增加 MSE。此时优化器既可以慢慢学好 δ，也可以通过一个标量门把这整个 1664 维 token 的更新压小。**关门不要求先解决复杂的残差预测任务。**

这是结构损失提供的局部机制解释；真实训练还有 FM、下游损失、Adam 动量等，现有日志没有按损失来源记录 gate 梯度，不能断言某一个 loss 是唯一推手。

### 3.3 日志确实呈现“先各层受益，再从深层开始关闭”

| optimizer step | A@5 gate | A@10 gate | A@15 gate | A@30 gate |
|---:|---:|---:|---:|---:|
| 25 | 0.9930 | 0.9949 | 0.9957 | 0.9961 |
| 50 | 0.9961 | 0.9956 | 0.9958 | 0.9797 |
| 75 | 0.9941 | 0.9867 | 0.2697 | 7.04e-7 |
| 100 | 0.4988 | 0.01508 | 5.29e-4 | 1.56e-7 |
| 120 | 0.9888 | 2.96e-4 | 3.51e-4 | 1.41e-7 |
| 500 | 0.9949 | 1.50e-4 | 0.002267 | 1.54e-7 |

step26–50，A@5 到 A@30 的平均结构改善依次约 `0.218/0.190/0.160/0.132/0.098/0.064`，六处都有收益；step51–75，A@30 已变为约 **−0.00228**。这与“后层增量不再改善目标，门向关闭方向走”的解释一致。这里是不同训练阶段的日志，不能替代固定样本的因果对照。

该转变还与学习率接近 warmup 峰值、struct 权重逐渐增大重叠；可能共同促成饱和，但没有单变量证据将责任只归给学习率或 struct_weight。

### 3.4 门关闭后，增量学习会受到进一步抑制

若 `g=sigmoid(a)`，局部偏导包含：

```text
∂P_after/∂δ = ηg
∂P_after/∂a = ηδ × g(1−g)
```

gate 很小时，候选增量支路的梯度以及门自身的导数都被压小，容易形成“改不好 → 关门 → 更难改好”的循环。A@5 虽然 gate 也接近饱和到 1，但它的 δ 梯度通路仍开放，和饱和到 0 不同。

零 gate 可以是合理的跳过策略，目标不应是“每层都必须有大更新”。当前值得处理的是：**长期保留六个大模块，却只有一个提供可见状态改善，其他位置仍显著写回，而且最终生成尚不合格。**

## 4. 不更新 P，为什么还会影响视频

写回读取的是 **整个 P_after，而非仅本层 ΔP**。即使 P 不变，当前层 H、查询、位置和各层投影参数不同，写回结果仍可不同。因此它既不等于零，也不等于把同一个向量原样复制六次。P 跨层变化小，也不代表 P 内部所有时间/空间 token 都相同。

这种行为本身未必错误：如果 P 已包含有用的场景/事件信息，不同层继续读取它，可能帮助保持条件一致。它可以成为有用的“少量状态更新 + 多处条件读取”设计。

风险在于 P 的信息不准、缺少动态细节或偏离部署分布时，多层 writer 仍可把这些信息反复注入 H，改变对象身份、轮廓、颜色和速度预测；有些干预可能相互抵消，有些可能被后续 Wan 层及 CFG 放大。**仅凭 15% 的写回/H RMS 不能证明有 15% 图像损坏，也不能跨层、跨 50 步直接相加。**

当前 reference 的严重闪色和 P02 的事件失败使这个风险值得优先检查，但已有日志还没有证明写回是全部问题的唯一原因。选择保留/删除一个位置的标准应是**输出是否改善**，不只是 gate 或 ΔP 大小。

因此不建议直接令 `write_gate *= state_gate`：本层不需改 P，不代表读取已有 P 无益。更合理的是独立控制“在哪里更新状态”和“在哪里向 Wan 写回”，再分别确认作用。

## 5. 减少位置是否有效，位置怎么选

### 5.1 值得做，但要分清期望解决的问题

| 能合理期待的收益 | 不能直接保证的收益 |
|---|---|
| 减少重复写回和相互干扰的机会 | 一定消除闪色/形变 |
| 降低新增参数量，集中有限数据的训练信号 | 剩下的 gate 一定不再关闭 |
| 让每个位置的贡献更容易解释 | 自动学会碰撞、连倒等事件 |
| 减少 corrector 的计算与优化器开销 | 整体推理按六倍提速；Wan 本身仍有 30 层 |

按本 run 的模块尺寸，六个 A + prior 约 **8.38 亿**可训练参数，一个 A + prior 约 **1.57 亿**，两个约 **2.93 亿**。在实际只有 1000 个训练视频的条件下，先验证小结构更有依据。

减少层数后，结构损失仍应按所选位置平均或明确定义归一化。当前代码已经求平均；不能删掉五层后又将 struct 权重随意乘六，混淆布局与损失强度。

### 5.2 不能只拿旧 checkpoint 的关闭门来排名位置

旧 A@10 学到的是“在 A@5 已修改 P、也已改过 H 之后工作”。它关闭，不等于一个从头训练、独立放在 block10 的校正器也无用。A@5 的大更新也不等于它对生成一定有益。

位置需要同时看：当前 H 能否支持有用状态预测、写回是否改善最终输出，以及该收益在高/中/低噪声下是否稳定。**层深度和去噪时间是两个独立维度。** 同一个 block 在不同 sigma 的输入信息质量不同。

从结构上，前段写回还有较多 Wan 层消化，也可能把错误传播更远；接近输出头的写回路径短，但缺少后续层修整。不能只凭这些直觉宣布最优层号，更不能预设 Wan 各层严格分工为“语义层/运动层/颜色层”。

已有图像扩散研究 REPA 在其 DiT/SiT 实验里发现，把表征对齐限制在较早位置可优于更深对齐；这支持“对齐位置应选择”的研究方向。但它是图像生成的 hidden 对齐，不是本项目的 Wan 视频 P 状态/写回，不能拿论文层号直接当这里的最优配置。[REPA 原文 §4.2](https://arxiv.org/html/2410.06940v4#S4.SS2)

### 5.3 推荐的选择顺序

1. **先验证一个位置：`[5]`。** 它是利用当前日志缩小起点，不是认定 5 最优。
2. **如果单点方案有希望，比较独立新训练的 `[10]`。** 使用相同训练配方、样本预算和初始化策略，检查“原 A@5 的优势来自层号，还是第一个校正器的职责”。有必要再扩大到 `[15]`，不要一开始扫描 30 层。
3. **只有单点留下明确可改善问题时，再加入一个间隔较大的位置**，例如 `[5,15]` 作为候选。要求第二次状态更新或写回在相同条件下带来增益；不是因为“两个看起来比一个强”就保留。

这些是候选实验，不是已验证最优布局。若比较不同数量的模块，收益同时包含容量和位置变化；若要专门判断位置，应先比较同数量的单点方案。

新训练的显式布局可写为以下配置片段，其他配置另行确定：

```yaml
parameter_sharing: per_block
a_every: 0
a_blocks: [5]  # 单点候选；后续可独立研究 [10] 或 [5, 15]
iterations: 1
```

`a_every=0` 允许自定义位置，不必每五层一次。**这用于新结构训练，不能改旧 checkpoint 的 config 后当作兼容恢复。** 当前权重加载明确要求 `a_blocks` 匹配；各层权重独立且输入分布不同，不能把旧 A@5 换个编号搬到 block15。[布局与载入检查](../physgen_v4/corrector.py:217)

## 6. 比单纯减少次数更关键的配套修改

### 6.1 先让状态增量有机会学好，再谈自适应关门

**推荐作为新训练对照：固定保守的状态步长，暂时不使用可学习的乘法 state gate；delta 输出层采用零或小初始化。** 此时“无需更新”可以由 δ 接近零表达，不会额外因为 sigmoid 接近零把整条增量支路封死。状态步长仍可随 sigma 调整，writer 仍独立控制。

这不是要求 P 一直大幅变化，也不保证优化成功；应同时观察增量幅度与真实收益。如果简单残差路径能学出有效更新，再考虑恢复可学习 gate，并使用温和初始化、更低 gate 学习率或有界门作为对照。不要给已经关闭的 final 强行开门。

代码里 **writer 已经零初始化，read gate 也已温和初始化；delta/state gate 目前是普通 Linear**。不能把“给 writer 加零初始化”重复当成新方案。[初始化实现](../physgen_v4/corrector.py:123)

从近似恒等残差开始有图像生成研究依据，例如 DiT 的 adaLN-Zero；但这只是初始化原则的参考，并不保证本项目使用零 delta 就能修好。[DiT 原文 §3](https://arxiv.org/html/2212.09748v2#S3)

### 6.2 减少重复监督，不让 P₀ 替动态模块承担全部任务

先让 P₀ 的额外条件与部署一致：使用首帧/文本，完整干净 GT 放在监督侧。对于多位置方案，可先对最后一个有效状态施加结构监督，或只保留少数有明确职责的监督点，避免每一层都重复追逐同一个完整目标；这也不是数学上保证后层必需。

当前 dense struct 可以直接沿 P 的恒等路径训练 P₀，单独减 `prior_weight` 不足以消除这条路径。如果仍由 P₀ 主导，应检查 FM/struct/prior 对初始化器、状态核心与 writer 的分项梯度，再决定冻结已训练的粗 prior 或调整辅助梯度路由。不要不加区分地 `detach(P₀)`，否则 FM 对初始化器的学习也会改变。

特别注意：把 `‖P_before+ΔP−Z‖²` 改名为 `‖ΔP−(Z−P_before)‖²`，在没有改变梯度路由时只是同一个损失，**不会凭名称“残差监督”就解决问题**。若保留 gate，可研究对未乘 gate 的候选增加直接监督，使它在门较小时仍有学习信号；但目标可预测性、幅度和噪声权重必须配套，不能逼高噪声分支凭空知道唯一未来。

### 6.3 给写回明确的保守约束，而不是只看配置系数

当前已有高噪声抑制、低噪声衰减和 `write_strength=0.1`，但实际写回仍可达到 H RMS 的 15% 左右。单纯降低训练中的常数，可能被 writer 权重变大抵消。

更有针对性的方向是：较低 writer 学习率；对实际 `RMS(residual)/RMS(H)` 超过预算的部分加软约束；或在保留普通画质的样本上约束相对冻结 Wan 的预测偏离。预算应由配对生成确定，不能凭空把 1% 或 5% 宣布为物理正确阈值。相对范数约束也要避免模型仅通过改变分母 H 的尺度降低惩罚。

这种约束可能牺牲必要的事件修改，不能要求所有输出都无限接近 base；需要同时检查画质与事件增益。**更大 state gate、更多 P 更新和更强写回，都不是独立的质量目标。**

### 6.4 如果一次状态更新已经足够，可以承认并简化这一结构

另一条合理路线是明确采用“一个状态生成/更新模块 + 少数读取模块”：后层只读取已有 P，不再保留长期关闭的大型状态更新网络。能否保留这些读取位置，仍由写回对照决定。

这比保留六个名义上的动态校正器更符合当前观察。但不能假设只去掉 delta 就省掉后层全部参数；后层仍有自己的读取、写回 attention 和投影。也不能只用学习到的 block5 状态证明它已表达充分物理信息。

如果单点或轻量读取仍不能稳定优于原 Wan，再考虑更简单的少量 adapter/低秩适配结合辅助表征监督，而不是继续堆叠独立 P 网络。事件窗口、动态目标和 no-GT 覆盖仍需满足，结构简化不能弥补错误监督。

## 7. 最小实施顺序与有效性的判断

**第一步先用旧 checkpoint 定位写回责任，不立即重训。** 固定 reference 和 P02，复用已有 full 结果，只补两组现有接口配置：

| 配置 | 作用 |
|---|---|
| `VARIANT=wan` | 禁用 corrector，检查共同推理路径及基础能力 |
| `WRITER_OFF='A@10 A@15 A@20 A@25 A@30'` | 保留各层 P 更新，只保留 A@5 写回，检查后五处写回的合并影响 |

每组两个案例，共四条新增生成即可形成第一轮判断；本次没有执行。第二组**不是**“只存在 A@5 的新模型”，也不会省去后五层的计算，因为现有开关是在计算后丢弃写回。它不能直接排名各个后层，也不能回答新训练单点是否更优。

如果后层关闭写回明显改善 reference，可再按需定位 A@10/A@25 等位置；如果 Wan 自身也闪色，先处理共同推理路径。对于输出层影响的低成本筛选，仓库已有[同 H/P 的后续前向归因脚本](../evaluation/attribute_correctors.py)，但它评价加噪 GT 的单次预测，不能替代完整生成，也不能判断从未训练的新插入位置。

**第二步建立部署条件一致的新单点基线。** 优先 `[5]`、`iterations=1`，P₀ 不输入 GT、保守增量/写回；若要判断 gate 修改的因果收益，在相同单点配置下只改变状态门机制。整个新配方相对旧模型的改善，不能全归给“减少位置”。

**第三步才比较单点层号、增加第二个位置。** 以相同 seed 的实际生成比较，初选后再用少量不同 seed 确认；如果第二点不提供稳定增益，就保留一个点。没有理由为维持原设计强行保留六次校正。

有效的标准是：

- 状态增量在适合的样本/噪声区间提供可复现改善，而非只把 gate 撑大。
- 相对 Wan 不出现新增严重闪色、身份/形状破坏；已有事件成功例也不明显退化。
- 碰撞等事件完成情况改善，而非靠静止输出获得更低帧间差。
- 每新增一个位置，带来的生成收益值得其参数、计算和训练复杂度。

**当前优先建议是“先验证一处，必要时两处”，同时治理门饱和与无约束写回。** 不建议直接将 `iterations` 增大、把 `state_warmup_every` 改成 1 当作本问题的修复、强行打开旧 gate，或仅凭 A@5 更新最大就永久锁定 block5。
