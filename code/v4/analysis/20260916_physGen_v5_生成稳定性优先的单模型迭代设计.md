# physGen v5：生成稳定性优先的单模型迭代设计

日期：2026-09-16。依据：[61018 checkpoint-final 诊断](20260913_61018_checkpoint_final_生成质量与训练全流程诊断.md)、[门控退化补充](20260913_corrector_门控退化与稀疏校正方案.md)及本次明确要求。

**本版固定为：按完整事件定位连续 121 帧；第 5、15 层各读取并写回一次；共享状态核心、两个独立 writer；仅三个加权损失目标；一个训练任务及一次最终推理验收。** 取消整片稀疏取帧和默认中心裁窗；新增模块不包含任何 read/state/write gate，不计算 RGB 重建损失。

这是待实现的设计规格，尚未修改模型代码或开展 v5 训练。参数值是有明确归一化、执行频率和梯度约束的固定起始配方，不是已经测得的最优值。实现可以保证输入条件一致及注入幅度受限；数量、形状、交互与颜色的生成质量仍需实际视频验收，不能在训练前承诺任意提示词都零缺陷。

## 1. 目前生成视频存在的问题

- 对象数量与身份不稳定，存在凭空增减、形变、穿模等用户反馈；正常遮挡、出入画及合理形变应单独识别。
- 部分视频有突发色调、曝光及外观变化，人物脸手结构不连续。
- 碰撞、反弹、连倒等事件可能只出现对象或运动，没有完成应有的交互和结果。
- 内部 JEPA/FM 指标与完整生成视频的可见质量尚未形成可靠对应。

## 2. 现有分析及要求暴露的问题

旧训练有六处独立校正，但后五处有效 ΔP 接近零，A@5/A@10 的 ΔH/H 仍约 15%/14%。writer 使用整个 P，因此“不更新状态”与“大量写回”可以同时发生；15% 本身不是已证明的致错阈值。

多数训练前向给初始化器完整干净未来，推理没有；六层重复追逐同一 teacher，初始化器还承接未来辅助梯度。末段初始化器占梯度平方范数约 84.27%，不能据此断言某个 loss 占了 84% 梯度。旧运行没有 NaN、Inf 或强裁剪导致失败的证据。

连续中心窗常与整片 caption 不匹配，关键因果过程可能不在输入内；旧训练只有 I2V，且实际仅 1000 个视频、500 updates。VAE 精度、solver、negative prompt 与原生配置也存在差异。reset 与旧训练一致，不应把改成 persistent 当成直接修复。

## 3. 相比原模型改正哪些部分

| 部分 | 本版固定改动 |
|---|---|
| 数据 | 按事件前态、关键交互和结果定位连续 121 帧；能容纳完整事件才入训，不再整片稀疏取帧或默认居中 |
| 校正结构 | 一个 512 宽共享状态核心调用两次；第 5、15 层各配一个独立 writer；取消其他位置和 B |
| 更新与写回 | 删除 read/state/write 标量门及旧 write_strength；状态残差与实际写回采用可微幅度限制 |
| 初始状态 | I2V 直接采用冻结 JEPA 从输入首图得到的空间锚点；T2V 使用小型文本初始化器；无干净未来条件 |
| 优化目标 | 仅 FM、最终状态对齐、RGB 时间差分三项；不计算绝对 RGB 重建误差 |
| 梯度职责 | 未来状态辅助监督只更新共享状态核心；writer 和 T2V 初始化器由生成目标学习 |
| 推理路径 | 正条件外挂残差放到原生 CFG 之外；画面监督及恢复任务检查实际带 CFG 的预测 |
| 基础配置 | 原始 FP32 VAE、原生 UniPC/50 步/shift=5、CFG=5、原生质量负提示词；75% I2V + 25% T2V 同训 |
| 训练与验收 | 固定 1200 updates，第 801–1200 步在同一任务内加入一步局部采样恢复；最终 EMA 统一记录视频和 P—JEPA 轨迹 |


相对前面讨论，本次最终落定的变化：

| 部分 | 最终版本 |
|---|---|
| 时间采样 | 从整片均匀稀疏抽帧改为事件优先的原始连续 121 帧，尽可能覆盖完整因果过程 |
| 读写结构 | 两次读取、两次写回；第二次观测读取被第一次写回影响后的主干特征 |
| gate | 新增分支不创建 read/state/write gate，不使用 sigmoid/tanh 标量门 |
| 损失 | 仅 FM、L_struct、L_temp；RGB 重建及其他独立辅助项删除 |
| 时间差分 | 限定低噪声、低权重，只用于局部变化误差，不当作物理正确性判据 |
| 配方 | 权重 1 / 0.03×q / 0.05；状态辅助梯度上限 20%；两个 writer 分别设置学习率和幅度上限 |

此前的整片必含源首末帧、仅一处写回及更高时间差分权重均不再作为本版执行规则。

## 4. 新模型的具体设计安排

### 4.1 基座规格、帧数与资源边界

| 项目 | 确定值 |
|---|---|
| 基座 | 原始 Wan2.2-TI2V-5B，Wan/T5/VAE/JEPA 参数冻结 |
| Wan | 30 blocks，hidden=3072，patch=(1,2,2) |
| 视频与 latent | 固定 F=121=4×30+1；VAE 48 通道、stride=(4,16,16)，T_latent=31 |
| 画布 | 横屏 1280×704、竖屏 704×1280，宽高均为 32 的倍数 |
| Wan token 数 | 两种画布均为 31×22×40=27280；不改变原生 RoPE、FM 符号或 t=1000×sigma 的约定 |
| 状态 | P∈R^(16×24×24×1664)，FP32 存储；核心宽度 512、8 heads、两层分解时空 Cell |
| 读写位置 | 第 5、15 个 block 输出后各读、更新状态、写回一次；层号从 1 开始 |
| 时间状态 | 每个去噪步 reset，P5 传给同次前向的 P15，不跨去噪步保存 P |
| 数据规模 | 从原始池重新准备 4000 条训练视频、200 条留出视频，按源视频隔离 |
| 训练配置 | 1×96GB，microbatch=1，accumulation=8，global batch=8，1200 optimizer updates |
| 推理配置 | step1200 EMA，UniPC/50 步/shift=5/CFG=5，固定 seed=42 |

121 帧与 latent 31 帧的接口直接符合[本地 TI2V 配置](../../../../../model/Wan2.2/wan/configs/wan_ti2v_5B.py)。[Wan 官方实现](https://github.com/Wan-Video/Wan2.2)说明 TI2V-5B 的 720P、24 fps 生成规格；本版保持其网络与采样接口，但“不同源帧率下连续 121 帧对应不同物理时长”的运动分布适配是新增训练职责，不能冒充基座已经验证的能力。

按原视频宽高比选择横/竖画布，等比缩放并 letterbox，保留完整空间内容。首图、视频、teacher、对象标注使用同一组合几何。该做法不同于原生 I2V 的空间中心裁剪，训练和推理必须一致；上采样不能恢复原素材没有的小物体细节。

### 4.2 两次读取、两次写回：本版固定连接

~~~text
输入：正 caption c、首图 I（T2V 时无）、时长 D、当前 x_sigma
I2V：冻结 JEPA(重复首图) → 空间锚点 A
T2V：文本初始化器(c)    → 空间锚点 A
A 沿 16 个状态时间槽复制 → P0

冻结 Wan blocks 1…5 → H5
  共享状态核心(P0,H5,c,sigma,D,site=5) → P5
  writer5(H5,P5) → 有界 ΔH5 → H5'
冻结 Wan blocks 6…15 → H15
  共享状态核心(P5,H15,c,sigma,D,site=15) → P15
  writer15(H15,P15) → 有界 ΔH15 → H15'
冻结 Wan blocks 16…30/head → v_plus
~~~

第一处把状态用于生成，第二处读取经过第一处写回和十个主干 block 处理后的特征，再更新状态、写回。第五层因此同时承担早期状态估计和生成干预；第二次读取有机会纠正第一次干预之后仍存在的偏差。

状态核心共享参数、使用 site embedding；两个 writer 独立，因为两处主干特征分布与后续传播长度不同。一次前向只调用两次共享核心，不保留六套独立 corrector、B 或最后几层的额外校正。

与“两次读取、一次写回”的区别是：后者在第二次观测前尚未改动主干，保留原始前半段且成本较低；本版第二次观测可以看到第一处干预的结果，表达能力和可干预深度更大，但也增加误差传播、梯度耦合和计算量。**两次写回不是天然更优；本次按用户指定采用它，并用更小的早层预算、独立学习率、最终状态监督和生成端校正上界控制代价。** 删除 RGB 后，绝对画面监督主要由 FM 承担，不能再以反馈结构本身保证对象数量或外观正确。

第 15 层后仍有 15 层主干处理注入。5/15 是固定工程布局，不声称 Wan 各层具有已经证明的“物理分工”。仅监督最终 P15，P5 记录误差/gain，不强制每次增量同样大或 gain 必须为正。

每个去噪步从 P0 reset，P5 传给同一次前向的 P15，不跨扩散步持有 P；P0 可缓存。x_sigma 已携带先前采样轨迹，reset 不会清空视频内部时序。

新增模块不包含 read gate、state gate、write gate、可学习幅度标量或所谓最低开门率；增量由残差网络直接预测。固定噪声日程与幅度限制器是数值控制，不进行可学习开关决策。冻结 Wan 原生 block 的预训练调制保持原样。

### 4.3 初始状态：删除未来输入，也删除额外锚定 loss

**I2V 采用冻结、可在部署获得的首图锚点。**

1. 将实际输入首图按训练画布和 teacher 几何处理，重复为 32 帧，送入冻结 V-JEPA。
2. 对 teacher 的 16 个时间槽求均值，保留 24×24 的空间网格，得到 A_image，宽度 1664。
3. P0[t,y,x]=A_image[y,x]，复制到 16 个时间槽。文本由状态核心读取。
4. 训练时缓存 A_image；推理时只计算一次。它只使用用户给定首图，不含真实未来，不需要训练一个大初始化器去重建同一首图。

这一步把原来的 L_anchor 及 I2V 可训练 prior 一起删掉，减少梯度集中于初始化器的机会。首图特征只是可见条件编码；重复图像经过视频 teacher 不等于获得真实动力学知识。核心必须从当前 Wan 特征学习后续变化。

**T2V 使用 512 宽、8 heads、两层的文本空间初始化器。** 输入只有有效 T5 tokens、空间 queries 和模式 embedding。输出为：

~~~text
A_text = mu_first + TextInit(c, spatial_queries)
P0[t,y,x] = A_text[y,x]
~~~

mu_first 是仅由训练集首图锚点得到的固定逐空间位置均值，有效区域按面积统计；不是当前样本的 teacher 或未来信息。TextInit 使用 512→1664→1664 非线性输出头，最后线性层零初始化。它仅接受 FM/时间差分产生的梯度，不接受最终状态对齐梯度，也不增加 prior loss。

T2V 前向不读取本条记录的 A_image，不能拿 GT 首帧做隐性条件。I2V 的 VAE 首片条件仍遵循原生路径，JEPA 首图编码只服务于新增状态支路。

GT 完整视频仍用于构造扩散加噪输入与监督目标；删除的是“额外把干净未来喂给学生模块”。本版不保留 GT posterior 条件或有/无 GT 的双学生分支。

### 4.4 共享状态核心与无门更新

~~~text
Q = Linear1664→512(LN(P)) + phase/spatial_position
    + sigma_embedding + duration_embedding + site_embedding
O = CrossAttention(Q, Linear3072→512(LN(H)))
U = 两层状态 Cell(Q + 0.1×O, text)
delta = Linear1664→1664(GELU(Linear512→1664(LN(U))))
u = f_P(sigma) × delta
ΔP = SoftBound(u; s_Z, 1.0)
P_after = P_before + ΔP
~~~

每个 Cell 顺序执行空间 attention、时间 attention、文本 cross-attention、MLP。空间 attention 分时间槽，时间 attention 分空间位置；不在全部 9216 个 P tokens 上直接堆叠全时空自注意力。H↔P 按视频相位插值对齐时间，再做对应时间片内的空间查询；两个方向使用相同几何。

固定 f_P(sigma)=0.25+0.75×clip(sigma/0.15,0,1)。s_Z 是训练集有效 GT teacher tokens 的全局 RMS，离线计算、冻结保存。删除 state gate；delta 最后一层零初始化，观察系数 0.1 固定而不可学习。状态不再额外乘旧 state_strength。

对指定 token 或归约组定义：

~~~text
a = b × stopgrad(s)
SoftBound(u; s,b) = a × u / sqrt(a² + mean(u²) + 1e-12)
~~~

所有归约和残差相加用 FP32，mean(u²) 保留梯度，参考 s 不反传。输出 RMS 不超过 a；a=0 时输出为零。当前 v4 的 rms() 会 detach，只能用于日志，新实现不能直接复用它构造限制器。

状态增量上界为每 token 的 1.0×s_Z，**它不是推荐 ΔP/P=100%**。两次更新应有足够空间重建与首图不同的状态，尤其是 T2V；不再把状态也限制为几％的小扰动。真正影响 Wan 和输出的幅度在 writer/velocity 两级单独控制。需要改多少由数据决定，不设置“ΔP 必须增大”的奖励。

连续限制器仍可能在大输入时减弱梯度，因此记录候选增量、有效增量与压缩比例；去掉 sigmoid 门不能保证一切退化自动消失。零初始化残差的原则可参考 [ControlNet](https://arxiv.org/abs/2302.05543)，本版的状态结构及数值不属于该论文的已验证结论。

### 4.5 两个无 gate writer：分别限制实际幅度

两个 writer 各采用 512 宽、8 heads 的空间 cross-attention，H 为 query、P 为 K/V，输出投影到 3072，最后投影零初始化。没有 write gate 或可学习 write_strength。

~~~text
S(x) = z²(3−2z), z=clip(x,0,1)
w(sigma) = S((1−sigma)/0.20) × S(sigma/0.15)
b5(sigma)  = 0.005 + 0.025 × w(sigma)
b15(sigma) = 0.010 + 0.040 × w(sigma)
~~~

帧级 ΔH/H 上界：writer5 在两端为 0.5%、中间主要区间为 3%；writer15 在两端为 1%、中间为 5%。早层传播路径更长，采用更小预算。**上界不是应该达到的平均比例，也不是已经实测最优的值。** 不要求非零最低写回率；3% 与 5% 不能相加为最终视频变化 8%。

对每处、每个 latent 时间片：

1. 无外挂的正条件 Wan 前向保存 H5_base/H15_base。帧参考为 min(RMS(H_base),RMS(H_before)) 并 stopgrad，防止 writer5 放大第 15 层的预算分母。
2. token 参考为 max(min(RMS(H_base,token),RMS(H_before,token)),0.1×s_frame)，先以 2×b_site 做 token 级 SoftBound。
3. 再以 b_site、s_frame 做帧级 SoftBound；排除纯 padding，I2V 首 latent 时间片 ΔH 为零，仍允许读取它。
4. FP32 相加并保留原生精度逻辑，记录实际 H_after−H_before 对当前 H 及 base H 的比例、逐帧分布与 token 峰值。

不添加预算惩罚 loss。连续限制器仍可能饱和，需记录候选/实际幅度和压缩比例。writer 使用整个 P_after，不仅是本次 ΔP；状态增量小不必然表示已有状态不值得写回，也不把 writer 强制乘 ΔP/P。

### 4.6 CFG 和训练使用的两种速度预测

三路预测来自同一 x_sigma、sigma、首片条件和画布：

~~~text
v_bc = 原 Wan 正条件预测（无外挂）
v_bn = 原 Wan 原生 negative 预测（无外挂）
r_v  = v_plus − stopgrad(v_bc)
Δv   = Bound_v(r_v)

v_cond   = stopgrad(v_bc) + Δv
v_guided = stopgrad(v_bn + 5×(v_bc−v_bn)) + Δv
~~~

推理使用 v_guided。新增校正的系数固定 1，不再像旧正负外挂 CFG 那样变成 5×delta_cond−4×delta_neg。负分支保留原 Wan 能力，不训练负提示词外挂，text_dropout=0。CFG 基本公式参见[原论文](https://arxiv.org/abs/2207.12598)；外挂放到 CFG 外是本版设计。

Bound_v 与 writer 一样先 token、后帧级限制，b_v=0.03+0.17×w(sigma)，帧参考=max(RMS(v_bc),0.1×s_v)，s_v 为训练集 FM target 的固定全局 RMS；token 上界为帧预算的两倍。I2V 首片 Δv=0。主区间上界 20%、两端 3%，参考是正条件基座速度，不是最终 RGB 或 CFG 速度；多步积分的最终变化不受“20% 图像变化”这样的保证。

普通 FM 使用 v_cond，与原来的有条件 FM 目标一致。**时间差分以及后段恢复任务使用实际 v_guided**，让画面监督看到部署时会采用的 CFG 结果。低噪声视觉任务因此需要额外无梯度负条件前向，普通 FM 曝光不需要。

base/plus 只共用第 1–5 层：正条件前 5 层一次，正条件 base 后 25 层一次，plus 后 25 层一次，负条件 30 层一次，共约 85 次 block 执行/采样步；两读一写约 75 次，原两分支约 60 次。普通训练前向约 55 次，时间差分曝光约 85 次，外挂计算另计；这不是实测耗时比例。

共享一份冻结 Wan 权重。前 5 层与额外 base/negative 路径可以 no_grad，plus 第 6–30 层必须保留输入梯度。每采样步有三个逻辑预测，不能沿用只有两个分支的耗时估算。

### 4.7 数据：按完整事件定位原始连续 121 帧

本版采用**源视频中相邻的真实帧**，不对整片均匀拉开间隔，不先抽稀再把抽稀后的序列称为连续帧：

~~~text
training_indices = [s,s+1,…,s+120]
F = 121，T_latent = 31
~~~

选择规则从“视频中心”改为“事件因果链优先”：

1. 在完整源片上定位事件前态、启动动作、关键交互和可见结果，得到核心帧区间 [a,b]。
2. 尽量为核心区间前后各保留 0.5 秒真实上下文；能同时容纳时，取包含这些上下文的连续 121 帧，剩余长度尽量均衡分到前后。
3. 上下文不足时，优先保证核心因果区间完整，缩短额外背景；不能为了凑固定窗口而删掉接触或结果。源边界处只能使用实际存在的帧。
4. 包含核心事件的合法起点范围为 max(0,b−120)≤s≤min(a,N−121)。在该范围内按上述上下文规则选 s；不是默认源片正中间。
5. N<121、b−a>120、原片缺前因/结果、切镜、关键状态不可见，或该起点范围为空时，整条不纳入本版训练池。不把不完整事件当合格物理训练样本，也不改回稀疏取帧来强塞进去。
6. 一个源片含多条独立事件时，可选一条有完整起止的事件；不从连倒等同一因果链中只取中间一段。每个源视频本版最多一个训练样本，按源视频隔离 train/validation。

因此“尽可能完整”落实为优先选择能完整容纳的事件和最大可用上下文，不是声称连续 121 帧能覆盖任意长物理过程。本版不要求同时包含原片第 0 帧和最后一帧，也不退回与事件无关的中心裁窗。固定帧数换取明确的基座接口和计算量。

**原始帧率与时间不能忽略。** 连续 121 帧在 24/30/60 fps 下的首末跨度约为 5/4/2 秒，60 fps 素材中的长事件更容易超窗。入训前按真实 PTS 检查事件覆盖和时间连续性，不伪造“全部都是 5 秒”。可变帧率且存在明显时间跳跃的片段排除。

模型相位 u_i=i/120，Wan 原生位置编码和 VAE 压缩不改；D=PTS[s+120]−PTS[s]。新增状态核心接收 log(D/5) 的正弦编码及线性投影，H↔P 按相位对齐。训练和有 GT 诊断使用真实 D，新提示词生成默认 D=5 秒，也可提供时长控制。输出固定 121 帧、fps=120/D，首末跨度为 D，最后一帧显示时长另计。源 fps/PTS、D 及输出 fps 都进入 metadata。

时长条件是新支路需要学习的适配，不代表只改播放 fps 就获得正确物理速度。冻结基座仍保留原生 121 帧、31 latent 帧、默认 24 fps 的接口；对超出训练时长分布的效果不作保证。这里严格选择原始连续帧，没有暗中把 60 fps 视频下采样到 24 fps。

数据准备一次完成：

- 从原始池重新筛选 4000 条训练、200 条留出记录，seed=20260916，先按源视频划分；不再 sample_limit=1000。
- caption 必须重写为所选事件片段实际可见的对象、可确认的数量、动作与结果；不得直接沿用覆盖源片其他事件的 caption。
- 本地 Qwen3-VL 生成事件/对象标注草稿，冻结 SAM 2.1 small 传播实例 mask；保存证据帧和可见性。不把自动置信度当真值；核心事件不可靠的记录排除，局部实例标注不可靠时关闭局部权重。
- 固定抽检 100 条，并审阅最终诊断集合；数量不足继续从原始池筛选，不放宽事件完整性来凑数。
- 覆盖碰撞/反弹、滑动/滚动、落下、推挤/连倒及普通人物/物体运动，分层打乱并遍历整个训练池。
- 每批 6 条 I2V、2 条 T2V，同一视频的模式随曝光轮转，不永久给某些视频指定无图模式。
- 各模型资产固定 hash；SAM 权重需在准备阶段确认。[SAM 2 官方接口](https://github.com/facebookresearch/sam2)仅用于离线对象传播，不参与生成。

GT teacher 仍用 32 帧、16 对在该连续训练序列内相邻的帧：

~~~text
a_j = round(j × 119 / 15), j=0…15
teacher_indices = [a_0,a_0+1,…,a_15,a_15+1]
P_phase[j] = (u[a_j] + u[a_j+1]) / 2
~~~

每对两帧现在也在原片中相邻，帧对之间有间隔，整体覆盖训练片段首尾。teacher 子采样不改变 Wan 的连续 121 帧输入；时间差分使用全部相邻帧，不只用 teacher 的 32 帧。V-JEPA 内部仍按输入序列编码时间，不宣称已经修改了其预训练时间位置编码。

统一源片→训练画布→teacher 的几何、有效 mask 和实例位置。P loss、attention、writer K/V 共用有效区域，纯 padding token 不可读。缓存包括连续帧起点、全部 PTS、FP32 GT latent、32 帧 JEPA、首图锚点、对象标注及 s_Z/s_v/mu_first。旧中心窗、BF16 VAE、16 帧 teacher 缓存全部失效。

### 4.8 仅三个损失目标及固定权重

| 编号 | 项目 | 基础权重 | 联合训练计算频率 | 直接职责 |
|---|---|---:|---|---|
| 1 | L_FM：速度回归 | 1.0 | 每条曝光 | 整段 latent 的外观、结构与运动生成；后段部分样本换为恢复目标 |
| 2 | L_struct：最终状态 JEPA MSE | 0.03×q(sigma) | 每条曝光 | P15 对齐 GT teacher 状态 |
| 3 | L_temp：RGB 相邻帧差分 L1 | 0.05 | 每个 global batch 的 1 条曝光 | 对齐 GT 中应有的画面变化，针对闪色和突发变化 |

**不计算 L_RGB。** 同时不保留 prior/anchor、JEPA cosine、P 时间差分、Sobel/边缘、颜色均值、生成端 JEPA、超预算惩罚等其他训练 loss。对应统计可以做诊断，不反传。使用 RGB 帧计算时间差分不等于恢复 RGB 重建目标，下面只对差分误差取 L1。

公共归约规则：

- FM 使用 latent 元素均值，预测整个画布；I2V 排除已知首 latent，T2V 覆盖全部 31 个 latent 时间片。
- struct/temp 排除纯 padding。有可靠对象时，全局有效区域均值与实例均衡均值各占 1/2；各实例先独立取均值再平均。无可靠实例时只用全局均值。这是同一种误差的空间权重，不是新增误差类型。
- 样本先内部归一化，再按各目标的活跃样本数归约；所有 GT stop-gradient，特征尺度只用训练集定标。

#### 4.8.1 L_FM：全视频生成主目标

~~~text
x_sigma = (1−sigma) × x_GT + sigma × epsilon
v_target = epsilon − x_GT
L_FM = mean((v_cond − v_target)²)
~~~

epsilon 为单位高斯噪声。I2V 固定实际首图编码的首 latent，首片 timestep=0，不计其速度误差；T2V 不执行首片固定。后段恢复样本使用 §4.9 的输入/速度目标替换本项，不与原目标相加。

FM 本来就覆盖全部有效生成时间片和空间位置，能够监督静态外观、数量与时序变化；删除 RGB 不意味着丢掉所有画面学习信号。不过 latent 速度误差不等于显式像素重建误差，不能宣称删除前后监督效果完全相同。

本版也不另加 latent 端点 MSE。对普通条件预测，该误差由 x_hat0−x_GT=−sigma×(v_cond−v_target) 可知只是 sigma² 倍的 FM。

#### 4.8.2 L_struct：原来状态对齐目标的收敛版本

~~~text
L_struct = weighted_mean((P15 − stopgrad(Z_GT))²) / (s_Z² + 1e-8)
q(sigma) = clip((1−sigma)/0.5, 0, 1)²
~~~

Z_GT 来自完整样本的 32 帧 teacher 视图，对应 16 个时间槽。s_Z 是训练集有效 teacher tokens 的固定全局 RMS，不逐样本变更，也不学习这个归一化分母。

这就是旧 L_struct 的同类 MSE，改动为只监督 P15、统一尺度、调整噪声权重和梯度去向。P0/P5 的误差与 gain 仅用于日志，不要求每个位置单独达到同一个 teacher 目标，也不隐藏 cosine 或状态差分子项。

q 在 sigma≤0.5 时为 1，sigma=0.75/0.9/0.98 时约为 0.25/0.04/0.0016，减弱几乎纯噪声时追逐唯一未来的压力。利用表示对齐辅助生成可参考 [REPA](https://arxiv.org/abs/2410.06940)，本版的结构、权重与视频效果不是该论文给出的结论。

#### 4.8.3 L_temp：只监督变化，不监督绝对 RGB

每个联合训练 global batch 的 8 条曝光中固定 1 条为时间差分曝光。普通曝光的 sigma∈[0.05,0.15]：

~~~text
x_hat0 = x_sigma − sigma × v_guided
V_hat = (Decode_FP32(x_hat0) + 1) / 2
V_ref = (Decode_FP32(x_GT) + 1) / 2

dV_hat[i] = V_hat[i+1] − V_hat[i]
dV_ref[i] = V_ref[i+1] − V_ref[i]
L_temp = weighted_mean(abs(dV_hat − dV_ref)), i=0…119
~~~

目标 V_ref 使用同一个 VAE 的 GT 重建，避免要求新增模块修复不可逆压缩误差。两侧均按约 [0,1] 的线性 RGB 尺度计算，loss 前不做硬 clamp；导出时才 clamp，并记录训练越界比例。这里**没有 mean(abs(V_hat−V_ref))**，也没有额外首帧、颜色均值或边缘误差。

FP32 decoder 参数冻结但保留输入梯度，按因果时间块解码并传递缓存，不从事件中间清空 cache 重启。I2V 解码前再次固定首 latent；时间差分覆盖全部 120 对相邻帧，包括 0→1。

全局变化在全部 121 帧上计算，最长边缩到 384。局部变化在 8 个均匀时刻和关键交互附近 16 个训练序列相邻帧对应的帧对上计算；直接从原画布提取对象及其周围 25% 上下文，最长边缩到 192。每一对使用两个时刻对象框的并集及相同裁剪坐标，再相减；不能各自将移动对象居中后消掉真实位移。局部跟踪不可靠时只保留全局项。

多个关键交互在曝光间确定性轮转；无明确接触时选运动变化最大的区间。这些只是辅助误差的局部取值位置，**Wan 输入仍是完整的连续 121 帧片段，全局时间差分覆盖这整个片段**。

匹配的是 GT 应有的变化，不是让预测的相邻帧越像越好。正常运动、光照变化、遮挡和形变不会因为变化大而自动被惩罚。本项在固定 121 帧网格上取差，不再除以不同源时长的秒间隔，以免短片在损失中被系统性放大；真实秒数用于时长条件和评价。

**删除 RGB 后的边界必须明确：** T2V 中对所有帧施加相同的颜色/外观偏差，时间差分可能完全不变；I2V 的已知首帧和 0→1 差分能提供锚点，但持续偏差可能只在起始边界受到惩罚，累积漂移也不由单步差分严格排除。绝对外观和对象结构因此主要依靠 FM、可见首图条件与冻结基座，不能把时间差分说成 RGB 的等价替代，更不能保证对象数量与穿模从此不会发生。


**时间差分的适用性：** 对整片稀疏抽帧，相邻样本可能跨越接触/遮挡/大位移，直接像素差分难以对应局部稳定性；改为原始连续帧后，比较相邻变化更有意义，但相机运动、遮挡及多种合理轨迹仍然存在。本版只在接近 GT 的低噪声重建任务中使用它，sigma≤0.15、权重 0.05，不用于要求自由生成逐帧复刻唯一 GT，也不把它称为物理损失。

#### 4.8.4 权重、频率与量纲必须一起落实

**固定采用 1.0 / 0.03 / 0.05，不根据旧 loss 占比机械换算。**

- FM=1 为基准，继续承担绝对结构与全视频生成职责。
- struct=0.03 建立在 MSE/s_Z² 后，再乘 q；相对四项方案的 0.05 减弱，防止删除直接生成辅助目标后，内部代理监督相对更重。另有 §4.10 的 20% 核心辅助梯度上限。
- temp=0.05，相对前述较高时间差分权重进一步减弱。时间差分缺少完整绝对外观约束，且一个中间帧参与前后两次差分，本版不通过放大它来填补被删除 RGB 的位置。
- 小系数不等于小参数梯度，VAE Jacobian、端点中的 sigma 和区域归约都会改变尺度。因此规定频率与梯度去向，记录实际范数，不宣称这些数值已经实测最优。

一个联合训练 global batch 的名义目标为：

~~~text
J = (1/8) × sum_{8条} L_FM
  + 0.03 × (1/8) × sum_{8条} q(sigma) × L_struct
  + 0.05 × mean_{时间差分活跃样本} L_temp
~~~

本版每批恰有 1 条时间差分样本，最后一项不再除以 8。microbatch accumulation 时 FM/struct 各除以 8；若框架把整个 microbatch loss 自动除以 accumulation，必须仅对 temp 补偿 8 倍，或单独累积。不能让 0.05 在实现中悄悄变成 0.00625。

这定义的是全噪声速度回归加低噪声时间差分的任务混合，不声称是原生训练分布的无偏重加权。记录三项原始/加权值和活跃数。RGB 等被删项没有占位反传或隐藏权重。

### 4.9 局部采样偏差恢复：改变 FM 样本，不增加第四项

steps 801–1200 每批那条时间差分曝光改为；本阶段共 400 个 optimizer updates、400 条恢复曝光，占该阶段全部样本的 1/8：

~~~text
sigma_a ~ Uniform(0.05, 0.15)
sigma_b = 0.8 × sigma_a
x_a = (1−sigma_a) × x_GT + sigma_a × epsilon

x_b = stopgrad(x_a + (sigma_b−sigma_a) × v_guided(x_a,sigma_a))
v_repair_target = stopgrad((x_b − x_GT) / sigma_b)

L_FM[该条] = mean((v_guided(x_b,sigma_b) − v_repair_target)²)
x_hat0[该条] = x_b − sigma_b × v_guided(x_b,sigma_b)
~~~

构造 x_b 的预测无梯度，有梯度前向时重新 reset P。I2V 两个状态均固定已知首 latent，FM 排除首片。L_temp 对这个 x_hat0 与同一 GT 重建计算变化误差，L_struct 使用 sigma_b；其余 7 条保持普通条件 FM。

恢复复用 L_FM 权重 1.0，不新增 L_repair 或另一个恢复系数。此时用 v_guided，因为要修复实际 CFG 采样的偏差；普通 FM 与恢复 FM 在日志中分别标记，总目标仍只有三项。

直观上，让模型先走一小步，接触自身预测误差，再学习从该状态指向正确端点。x_b 已不在最初的 GT—噪声直线上，因此不能沿用 epsilon−x_GT。该速度恢复仍会提供完整 latent 端点的学习信号，不是单靠时间差分修复所有问题。

单步 Euler 只用于构造训练扰动，正式推理仍用 UniPC；不通过 50 步反传，不增加修复网络，也不宣称一步扰动覆盖全部采样误差。

### 4.10 梯度分工：生成目标训练读写，状态目标只训练核心

| 参数组 | 接受的训练信号 |
|---|---|
| I2V 首图锚点/固定均值 | 冻结 |
| T2V 文本初始化器 | FM、时间差分，仅 T2V 曝光产生梯度 |
| 共享状态核心、读取与各条件投影 | FM、时间差分，以及受限的最终状态对齐 |
| writer5、writer15 | FM、时间差分 |
| Wan/T5/VAE/JEPA | 参数冻结；注入后 Wan 和 VAE decoder 保留输入梯度 |

两次写回使 L_struct 可能经 H15 绕回 writer5，因此辅助监督采用仅状态支路的重算：取主前向的 P0、H5、H15 并 detach，再用同一个共享核心依次重算 P5_aux、P15_aux，对 P15_aux 计算 L_struct。重算保留两次状态更新之间的梯度，但不经主干和 writer 回传。

状态支路 dropout=0、无随机层，中间不更新参数，重算 P15_aux 应与主前向 P15 数值一致；实现必须检查。它不增加 Wan 前向或第二套状态参数。生成路径正常保留 P0、H15 的梯度。

全批累积后：

~~~text
g_gen = grad(L_FM + 0.05 L_temp)
g_aux = grad(0.03 q L_struct)，只对共享核心求导
alpha = min(1, 0.20 × norm(g_gen_core) / (norm(g_aux) + 1e-12))
g_core = g_gen_core + stopgrad(alpha) × g_aux
其他可训练组 = 对应 g_gen
~~~

式中已包含 §4.8.4 的批次归约。alpha 在 FP32 全批梯度上计算，不逐 microbatch 裁剪，不构建二阶图。生成核心梯度为零时暂停额外辅助注入，前 100 步状态预热不采用此限制。

生成目标一次求梯度，状态重算支路一次求梯度，按组合并后全局裁剪；不进行在线生成端 JEPA 反传。使用梯度尺度分析辅助目标可参考 [GradNorm](https://arxiv.org/abs/1711.02257)，本版为固定上限而非复现其算法。20% 不是 AdamW 后参数更新的精确占比，必须记录实际范数与更新幅度。

### 4.11 固定训练参数与一次训练日程

| 参数组 | 峰值 LR | 最终 LR | 原因 |
|---|---:|---:|---|
| 共享状态核心及读取/条件投影 | 5e-5 | 5e-6 | 学习新的状态转换；低于旧版统一 1e-4 |
| T2V 文本初始化器 | 2e-5 | 2e-6 | 仅生成目标训练，避免初始化器再次成为主要优化出口 |
| writer5 | 1e-5 | 1e-6 | 早层写回传播更长，控制更新速度 |
| writer15 | 2e-5 | 2e-6 | 中层承担较大写回预算，但仍低于旧统一学习率 |

这些是结合参数职责、冻结基座和当前数据规模确定的工程数值，不由旧 loss 均值推导为最优学习率。1200 步版本保留表中峰值 LR，压缩预热与衰减日程，不因总步数缩短就把 LR 成倍放大。LR 控制参数更新速度，写回上界控制实际干预量，两者不互相替代。

优化器固定 AdamW：betas=(0.9,0.999)，eps=1e-8，weight_decay=0.01；bias、norm、位置/模式 embedding、空间 queries 不衰减。新增可训练参数及 Adam 矩保持 FP32，线性/attention 用 BF16 autocast，P/预算归约/速度和 solver latent 用 FP32。合并全批梯度后 global grad_clip=1；此前剪裁未触发，不能把它当旧版失败原因。

| optimizer step | 固定内容 |
|---|---|
| 1–100 | 仅状态预热：两个 writer 为零且冻结，TextInit 保持初始状态；核心学习最终 L_struct。Wan 只提供 H5/H15，无需主干反传。核心 LR 前 50 步线性升至 5e-5，随后保持至 100。此段不使用辅助/生成梯度比例限制。 |
| 101–200 | 启用 FM、低噪声时间差分、两个 writer 和 TextInit。核心 Adam 矩在第 101 步一次性清零，避免沿用纯代理目标的动量；不重置已学参数。所有可训练组 LR 以 r=(step−100)/100 升至表中峰值，writer 和输出幅度预算也乘 r。 |
| 201–800 | 固定最终预算，联合训练。LR 开始按固定 cosine 下降，不根据几次视频观感更换结构或权重。 |
| 801–1200 | 仍为同一个模型；每批那条时间差分曝光执行 §4.9 一步恢复，其他 7 条标准 FM。共保留 400 步局部恢复阶段，继续同一 cosine 日程。 |

对于 k∈[201,1200]，LR=peak×[0.1+0.9×(1+cos(pi×(k−200)/1000))/2]。第 200 步达到峰值，第 1200 步达到峰值的 10%；局部恢复开始时继续已有曲线，不重启 LR。阶段标记、清零完成标记、各组矩和 scheduler 状态都写进 checkpoint，恢复训练不能重复执行第 101 步转换。这个固定预热/联合/恢复日程属于一次训练，不产生多个候选模型。

world_size=1、microbatch=1、accumulation=8，实际 global batch=8。共 9600 次样本曝光：800 次状态预热，8800 次联合生成训练；联合阶段中 8400 次普通 FM、400 次恢复 FM。时间差分曝光共 1100 次，其中后 400 次同时承担恢复任务，不额外增加 optimizer steps。训练池为 4000 条时平均约 2.4 次曝光，较短预算优先用于验证机制和生成质量，不能据此承诺达到长训练的收敛程度。

联合阶段每批 6 条 I2V、2 条 T2V。每 4 批的时间差分曝光固定 3 条 I2V、1 条 T2V，具体位置按 seed 打乱；时间差分样本从训练池独立分层、无放回轮转，并让后段 400 条恢复曝光覆盖不同事件类别。1100 条时间差分曝光无法覆盖全部 4000 个视频，不再宣称每条视频都能获得该监督；同样记录实际 I2V/T2V 覆盖，不把配比等同于逐视频双模式覆盖。普通样本队列持续遍历训练池，不因阶段切换而从头重复固定子集。预热 sigma∈[0.02,0.999]；联合训练 7 条普通曝光也在此区间均匀采样，另一条在 [0.05,0.15] 采样。恢复阶段记录 sigma_a 和 sigma_b∈[0.04,0.12]，不把它误报为标准直线加噪。

第 101 步更新前创建 EMA，decay=0.995，之后每次 optimizer update 更新全部可训练参数。其有效平滑尺度约 200 步，避免短训练中使用 0.999 时过多保留 writer 初始状态；这不改变 AdamW 的 beta2=0.999。每 200 步保存可恢复 checkpoint，最终只用 step1200 EMA；不从一组 checkpoint 中挑最好看的视频。每 200 步在固定 16 条留出样本上做单步健康检查，不进行多套结构、loss 权重或采样配置扫描。

### 4.12 推理、缓存和计算资源

1. 固定原始 Wan2.2、FlowUniPC、50 步、shift=5、CFG=5。negative prompt 显式读取本地 shared_config.py 的 sample_neg_prompt，并记录文本与 hash，不能依赖空串的隐式替换。
2. VAE 从原始权重直接以 FP32 加载，权重、scale、输入和编解码计算均为 FP32、关闭外层 autocast；先加载 BF16 再转 float 不能恢复原始精度。重新生成 GT latent 缓存。
3. I2V 训练/推理使用相同首图变换，逐采样步固定首 latent、首片 timestep=0；T2V 不固定首片。三条预测分支执行相同模式约定。
4. I2V 首图 JEPA 编码只计算一次。训练读离线缓存；推理先算锚点再释放 teacher、执行 Wan 采样。T2V 只使用固定均值与 TextInit，不读当前样本首图。没有在线生成端 JEPA loss。
5. 时间差分曝光才进行可微 FP32 解码。GT 参考用无梯度解码，并只保留下采样全局画面和所需局部区域；不缓存全训练集原生尺寸的 FP32 RGB 重建。
6. student decoder 按因果时间块 checkpoint/recompute，保留正确缓存；不通过切断 cache 梯度偷换成独立片段解码。多个视频的 VAE cache 必须隔离。
7. 无梯度恢复预测、有梯度前向、checkpoint 重计算使用独立 autocast scope，cache_enabled=false，避免复用 no_grad 阶段缓存破坏梯度。
8. 固定单卡执行，不在本次混入多卡 FSDP 改造。新参数目标低于 1 亿，实际实例化后计数；不把未实例化的估算写成测量值。

缓存空间也计入准备：按两种固定画布，单条 FP32 GT latent 约 21 MB；4200 条约 88 GB，尚不含 teacher/首图锚点/标注。teacher 特征可按其原始 BF16 输出保存、读取后 FP32 计算误差，另外约 129 GB。缓存前核对磁盘容量，不能另将全部 121 帧原生 FP32 RGB 长期保存为数 TB 的无必要副本。

1×96GB 是拟采用资源，不是本设计阶段已经通过的显存测量。实现后在 121 帧、两种画布、时间差分/恢复任务上完成一次完整 forward/backward 峰值检查，采用冻结基座、分解 attention 和 activation checkpointing。不能因冻结参数就把 writer5 之后的全部 Wan 放进 no_grad；不能依据旧“4x96g”目录名假定有四卡。

### 4.13 一次最终验收与必要实现检查

最终仅加载 step1200 EMA，执行预先固定的 16 条训练诊断、24 条源视频隔离的留出样本，以及原 reference/20 个 demo。训练样本只用于记忆与机制诊断，不混入泛化统计；有 GT 的 40 条按 3:1 固定 I2V/T2V 模式，不靠反复换 seed 选结果。

有 GT 的样本分别记录两种任务：

- GT 加噪单步诊断：sigma=0.98/0.85/0.60/0.35/0.10，记录 P0/P5/P15 与对应 GT JEPA 的关系。
- 从随机噪声完整生成：只输入可部署条件，不输入未来 GT；在 solver 实际调用的每个 sigma 记录两处读写轨迹。

记录有效区域的 MSE/s_Z²、cosine、去时间均值后的动态相似度、实例区指标、P0→P5→P15 gain、实际 ΔP/P、两处 ΔH/H 及输出 Δv/v_bc。修正率同时报告候选与有效值，写回同时报告视频均值/逐帧分布/token P95 与峰值。近静止特征的动态 cosine 标记不适用。

生成结束后再提取 Z_generated，分别报告 P15—Z_GT、Z_generated—Z_GT、P15—Z_generated。P15 来自最后一次实际 solver 调用，保留其 sigma，不冒充 clean-video 编码。GT 相似度不是物理正确率，合理但不同的轨迹不能只凭低 cosine 判错。

实际视频审阅包括对象持续性/数量、非动机形变、可见接触与响应、遮挡顺序、闪色/曝光跳变及事件是否完成；不能以静止视频、低时间差分或高 JEPA 相似度冒充成功。二维 mask 重叠不是三维穿模判据。训练与留出集分别报告失败数和案例。

输出 videos、final_latents、trajectory.jsonl、p_jepa_similarity.csv、读写曲线、事件抽帧、quality_review.csv 和完整 metadata。固定 seed=42，一次批量推理任务完成。

必要实现检查不构成结构消融：连续索引与事件覆盖、零 writer 的基座一致性、I2V/T2V 首片约定、teacher/状态坐标与 padding、gate 参数确实不存在、实际幅度上界、辅助梯度不进入 writer/TextInit、重算状态数值一致、仅三项目标且 accumulation 缩放正确。通过这些检查才能启动训练；它们不等于生成质量已经验收。

### 4.14 一次实现的模块职责与冻结配置

独立实现于 code/v5，不覆盖 v4 checkpoint。data/prepare 负责事件定位、连续帧和 caption；coordinates 负责统一几何、PTS/phase 与 mask；encoders/cache 负责 FP32 VAE、首图锚点和离线 JEPA；corrector 负责共享无 gate 状态核心及两个有界 writer；backbone 负责三条速度路径和正确梯度；train/losses 只实现下面三项及固定日程；inference 负责一次最终生成和轨迹报告。
