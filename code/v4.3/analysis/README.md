## 当前结论

目标：学生正常 forward 的真实 FM 明显下降，修正能迁移到未见视频；完整生成不能新增大片颜色闪烁或明显变形，还要改善物理过程缺失与静止倾向。

**两轮直接回归原型均未达标。V4.3现有ΔH尚未证明是有效物理修正，部分生成表现为无效或负优化并伴随画面损坏。新监督方案和共享writer投影尚无真实Wan效果验证；本次更新的是分析文档，没有运行新的训练或GPU实验。**

V4.4 保留每个 block 内 P/H 同时交互，每个交互块后增加真实 H 写入，使第二轮读取第一次修正后的 H。原生宽度和三位置保留，P 不增加形式对称的 writer。原 STRUCT 保留，隐藏 Oracle 回归替换为输出蒸馏，8/10 加强负注入样本的 FM 更新，第 9 项经可微 VAE 与冻结 JEPA 训练学生达到有效教师动态收益的指定比例。推荐先训练新 writer/step，再以较低学习率解冻迁移参数，最后开启完整跨步反传。不增加画质专项、独立 H 读出器、额外 P 过程或绝对输出动态损失。

基础微批以 FM 与临时修正正则搜索 Oracle；联合微批从 GT 部分加噪起步，用学生建立有效 UniPC 历史，再在相邻两步窗口的第二次调用优化干净估计及动态误差。学生蒸馏同一噪声时刻的真实采样更新状态；标准 FM 始终在独立、标签合法的配对加噪分支计算，不把原 FM 标签套给轨迹状态，也不把仍有噪声的 latent 与干净 GT 直接比较。阶段 B 暂只反传末步，阶段 C 保留 latent/history 的完整跨步梯度。FM/JEPA 代理收益不冒称物理定律保证，局部重建训练不冒称完整自由生成效果已验证。

已只读核验本地 WISA 原始索引 79,480 条，当前 2400 条缓存均可匹配，但缓存尚无有效对象/交互标注。前期文档 causal_physics.md 的 §3.0.2 保留视觉片段标注、分割/跟踪与事件核验的流水线，当前首版不以它们为前置条件；原始 WISA 的密度、温度和时间范围来自文本推断，不能直接作为实测物理目标。自动伪标签与核验真值须区分，尚未启动批量标注。

既有记录保留了 16 项 CPU 检查、writer 投影代数检查，以及 P 残差、目标 detach 和末端梯度路径核验。它们只认证原实现的相应性质，不认证新版效果，也不作为继续修改的前置门槛。原结构最后位置的最终 P 更新受 STRUCT 监督，但该终点没有下游 FM 路径；较早 P 及最后块 P 的 K/V 仍参与生成。

按用户要求，不采用强化学习、奖励/偏好学习、对比学习或正负样本构造。用户明确“各向同性”指动作趋同、容易静止和缺少变化；完整 GT 教师与推理条件分离，观察视频的时序增强不冒充已证明的干预因果机制。完整设计只维护在上述文件中。

稳定历史参考是 `checkpoints/v43_native_joint_flow_oracle_20260918T143237Z-e47bdd74` 的 step800，FM=1、STRUCT=.1、Oracle=1；“稳定”不认证其物理修正有效或优于原Wan。当前默认 YAML 仍为 STRUCT=.01、Oracle=60，不能当成稳定参考配置。

Oracle60 对照 `checkpoints/v43_native_joint_flow_oracle_20260918T151935Z-69fbcbf3` 仅完成300步，在保存公共 latest 临时文件时报错；已有证据支持并发文件名竞争，不能写成已确认的数值发散。原始训练日志保留在项目 `logs/experiment_62369_trial_63534_logs.txt`、`logs/experiment_62370_trial_63535_logs.txt`，本目录不再保存可由日志重建的全套导出表和图。

两配置前300步配对学生 FM 约 .265388/.265398，几乎相同；STRUCT 和 Oracle 同时改变，不能单因素归因。

## 保留的实验依据

两轮均冻结稳定基座，仅训练 A@25 新增的两步、128维瓶颈修正器；只反传隐藏轨迹回归，真实 Wan FM 在训练后评分。原生产训练器则包含真实 FM，不能混淆。

| 实验 | 评估 | 基座 FM | 普通学生 FM | 临时教师 FM | 方向 cosine |
|---|---|---:|---:|---:|---:|
| v1 | 训练4状态 | .138451338 | .134869084 | .097556492 | .287789 |
| v1 | 验证4状态 | .118828921 | .118906142 | .082617243 | −.000733 |
| v2 | 训练32状态 | .134530321 | .134496940 | .092924184 | .023582 |
| v2 | 验证16状态 | .123662260 | .123663969 | .084460428 | .002819 |

v1 为2条训练/2条验证视频，σ=.35/.85，各一份噪声；v2 为8条训练/4条验证视频，各两份噪声。两轮数据组成不同，均值不能连成学习曲线，也不能与历史随机训练约 .25 直接比较。验证属于开发验证，没有同预算 FM-only 对照；没有生成新原型的视频。各轮曾验证一次完整普通 forward 与缓存 suffix 的 FM 一致。

第二轮训练拟合也弱，不能唯一归因为泛化或 GT 不可预测。两步共享的输出矩阵在实数计算下限制额外写入为至多128维通道子空间；尚未证明这是失败主因。

颜色诊断比较相同 step100、prompt/首图/seed42/UniPC50/CFG5/121帧等条件。Oracle60/.01 相对 Oracle1/.1：I2V 运动补偿色度变化均值2.2245倍，18/21条更差；T2V 为2.0070倍，15/20条更差。全局色度二阶变化分别7.2439倍、2.7059倍。该自定义诊断使用最长边192、灰度 Farneback 光流和一致性/越界 mask，不是 VBench，也未完成形变认证。

三个原视频目录仍在项目 `inference_outputs/`：`v43_flow_oracle_20260918T170900Z_1x96g`、`v43_flow_oracle_20260918T171158Z_1x96g`、`v43_flow_oracle_20260920T113239Z_1x96g`。

## 后续设计必须保留的边界

- Oracle 内层只更新临时 Δh；外层学生 Δh 保留梯度，AdamW 更新 Corrector。冻结 Wan 不阻止梯度穿过后缀传回修正参数。
- 三处写入位于 block5/15/25 之后；独立位置教师收益不能当作联合收益。当前 P 固定，但下游 Wan/Corrector 激活重新计算。
- A@25 最后写入没有旧 STRUCT 的直接梯度；本版用 FM、8—10 的实际收益约束与 Oracle 输出蒸馏训练写后作用。CFG5 下修正效应为 `5Δv_cond−4Δv_uncond`，隐藏限幅不保证采样稳定；联合两步模式按明确的训练 solver 设计，不声称等同完整部署采样。
- 自由教师使用未来 GT，可能包含推理条件无法预测的收益。必须分别报告基座、学生、原自由教师 FM，不更换较弱教师来提高恢复率。
- 候选筛选用的训练池 Q 不是独立验证；按视频来源划分最终测试。隐藏 cosine 只是诊断，真实 FM、物理过程和生成质量才是验收主体。
- 原训练仅覆盖 I2V，T2V 要单独评估。runtime 为 `moviestory`，JEPA 教师在独立 `vjepa2-312` 环境，不能假设能直接导入形成可微链。

下一项交付是新版两轮结构和有参数更新的训练目标，见新方案第 8 节；联合训练设计见第 7 节。现有 [writer_projection.py](../tools/writer_projection.py) 保留为可选定位工具，不作为开始实现或训练的前置条件。
