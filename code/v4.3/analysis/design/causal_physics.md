## 0. 本轮确定的改动：两轮实际写入与有参数更新的收益监督

用户本轮明确要求：注入前后的收益必须进入监督与参数更新，不能以测试、监控、分析报告代替结构和训练方法的修改。本节把首版修改明确为实现规格；仍遵守最初“先给初步方案”的交付范围，本文更新不代表代码或新训练已经完成。

### 0.1 架构：每个交互块后真正修改 H

V4.3 当前在一处连续执行两个 JointPHBlock，最后只通过一个 writer 写回原 H。V4.4 将其改为：

~~~text
(P⁰, H⁰) → JointPHBlock₁ → (P¹, Z¹) → writer₁ / step₁ → H¹
(P¹, H¹) → JointPHBlock₂ → (P², Z²) → writer₂ / step₂ → H²
H² → 下游 Wan；P² → 下一个位置与 STRUCT 解码头
~~~

每一轮的定义为：

\[
(P^{k+1},Z^{k+1})=G_{\theta,k}(P^k,H^k,c,\sigma),\qquad
D^k=W_k\operatorname{LN}(Z^{k+1}),
\]
\[
\alpha^k=\alpha_{\max}\operatorname{sigmoid}(a_{\theta,k}(H^k,P^k,\sigma)),\qquad
H^{k+1}=H^k+M\odot\alpha^kD^k,\quad k=0,1.
\]

G 复用现有两个原生宽度交互块；两块仍各自拥有参数，不额外复制整套注意力网络。每轮的 P/H 都从同一组写前状态同时交互；下一轮读取已更新的 P 与实际写入后的 H。这与在同一块内改成先 P 后 H 不同。Z 是生成本轮修正的内部特征，下一轮 H 输入明确使用 H^{k+1}。

两个 writer 均为 3072→3072，新增一个 writer 约 944 万参数/位置；不再引入 128 维输出瓶颈。步长头第一版输出每样本、每轮的标量，输入为归一化 H/P 摘要与噪声条件，避免逐 token 步长带来额外时空抖动。步长由真实输出损失反传学习，不能把 Oracle 在另一方向上的步长直接当作当前方向的最优幅度。

每轮都应用首 latent 保护 mask，残差在 FP32 中相加，总 ΔH=H²−H⁰。writer 可零初始化，但 sigmoid 步长初始化为严格正值，不能同时将输出矩阵和乘法门置零。幅度上限是可调训练参数，不以限幅代替学习正确方向，也不由它声称推理安全。

改变中间 H 的使用方式会改变前向语义。应使用独立的 V4.4 架构版本和显式初始化映射；可迁移原初始化器/交互块等匹配权重，但不能宣称装入旧 checkpoint 后输出逐点不变，也不能当作原 V4.3 的直接断点续训。

### 0.2 监督：收益直接参与 backward

在当前学生访问的位置 l、轮次 k，保持相同的写前 H、当前轮更新后的 P、文本、σ 和噪声，构造三个计算分支。S_{l,k} 必须包含本位置尚未执行的修正轮次、剩余 Wan 层和下游 Corrector；不能跳过第二轮后仍称为部署路径。

\[
v_\theta=S_{l,k}(H^k+\Delta H_\theta^k,P^{k+1}),\qquad
v_0=S_{l,k}(H^k,P^{k+1}).
\]

Oracle 从当前学生本轮 ΔH 出发，用 GT-FM 做两步有限优化；教师候选同时包含零写入和当前写入，选择同一真实后缀上误差最低的候选，得到停止梯度的 v_*。原 V4.3 自由 Oracle 的评测协议独立保留，不通过更换教师来制造恢复率。

定义 Eθ=MSE(vθ,Y)、E0=MSE(v0,Y)、E*=MSE(v*,Y)，仅计算未知帧。监督项为：

\[
L_{\rm gain}=
\left[E_\theta-\operatorname{sg}(E_0)
+\rho\operatorname{sg}([E_0-E_*]_+)\right]_+,
\qquad
L_{\rm effect}=\|v_\theta-\operatorname{sg}(v_*)\|^2.
\]

Lgain 对负注入和收益不足产生实际梯度；有可靠正收益的教师样本从较小的正 ρ 开始训练，例如先尝试 .25，而非长时间只要求“不变差”。教师没有正收益时 margin 为零。正 margin 使全零写入在这些状态上不能满足目标；FM 和效果蒸馏仍持续训练写入方向，步长头不能成为唯一接受更新的参数。

为了防止局部相互补偿掩盖整体退化，增加相同输入下相对冻结原 Wan 的 Lguard=[Efull−sg(EWan)]₊。全局分支全部关闭 writer；局部分支只关闭所选的一次写入，并保留相同的当前 P，再重算其后所有运算。两者不是同一个基准。

首版实际优化目标为：

\[
L=L_{\rm FM}+\lambda_P L_{\rm STRUCT}
+\lambda_G L_{\rm gain}+\lambda_B L_{\rm guard}
+\lambda_E L_{\rm effect}+\lambda_H L_{\Delta H}.
\]

有可靠标签/已校准读出时，再按后文接入 Lanchor、Lphys 和保真项。标签制作不阻止上述已有 GT 可支持的结构与训练修改。原隐藏回归保留为辅助；Lgain 与 Leffect 从首版进入优化器，不能仅以 `.item()`、日志或验证函数实现。

简化的更新逻辑如下，省略微批累积与分布式同步；teacher_search 内部只对临时残差求导，不更新模型参数：

~~~python
# v_on 是有梯度的学生输出；教师和 off/bare-Wan 分支停止梯度。
e_on = flow_mse(v_on, target)
e_off = flow_mse(v_off.detach(), target)
e_star = flow_mse(v_star.detach(), target)
margin = rho * (e_off - e_star).clamp_min(0).detach()
loss_gain = (e_on - e_off.detach() + margin).clamp_min(0)
loss_effect = flow_mse(v_on, v_star.detach())
loss_guard = (e_on - e_bare_wan.detach()).clamp_min(0)
loss = (e_on + w_struct * loss_struct + w_hidden * loss_hidden
        + w_gain * loss_gain + w_effect * loss_effect
        + w_guard * loss_guard)
optimizer.zero_grad(set_to_none=True)
loss.backward()
optimizer.step()
~~~

真实参数路径是 `Lgain/Leffect → velocity → Wan后缀 → H⁺ → ΔH → writer、步长头、JointPHBlock`；完整学生图还向上游交互、lift 和初始化器传播梯度。冻结的是 Wan 权重，不能对学生后缀使用 no_grad。教师快照可以 detach；用于构造 v_on 的实际 ΔH 和学生状态必须保留图，不能复用完全 detach 的 Oracle 快照替代学生前向。

Lgain 激活时主要重加权已有 FM 梯度，Lguard 也有同样性质；它们本身不产生新的知识。结构上的实际反馈、有限步教师的输出目标以及后续真实过程监督分别承担不同作用。联合随机优化不保证每步或每个未知样本单调下降，不能因此撤掉真实更新而只增加监控。

### 0.3 首版训练流程与交付

1. 直接实现两轮写入、step head、可继续执行剩余轮次的 suffix，以及上述实际训练损失；三位置保留。正常学生前向始终执行完整两轮，并联合更新三处交互、writer、步长头、初始化器和 lift。只训单 writer 不再是进入主线的前置门槛。
2. 教师每个微批轮换一个位置/轮次，或按固定频率抽样，控制后缀成本；基于当前学生状态重新生成标签。普通 FM/STRUCT 每个微批都训练所有位置，不能同时强迫模型匹配多个未经联合验证的独立教师终点。所有 rank 保持一致的调用计划。
3. 训练后段接入从低/中噪声 GT 加噪状态出发的 2—4 步可微重建，在真实 CFG 双分支与采样更新后监督输出的过程和保真。离开原加噪路径的中间状态不能继续套用原 ε−zGT 作为 FM 真值。此项需要训练计算图；只有完整生成打分不算实现。
4. `corrector.py` 对应两轮实际写入；`backbone.py` 对应轮次状态与准确续算；`oracle.py` 对应零/当前/优化候选与输出目标；`losses.py`、`train.py` 对应有梯度的辅助分支和 optimizer 更新；配置、checkpoint 与推理同时使用新架构版本。不得只增加 metrics 字段。
5. 验证围绕已做的改动开展，重点是新增分支确实更新目标参数及普通推理效果；共享投影、额外探针和大批报表不再列为实施前置步骤。先交付能训练的新结构和目标，再以有限的对照决定改进方向。

本节替代旧版“先完成共享投影/多轮诊断，再决定是否改结构或加入效果蒸馏”的执行顺序。以下关于物理标签、读出可靠性和独立效果评价的要求继续保留。

## 1. 先审查 V4.3，不能把“整体失败”解释成“模块无用”

现有主链：

~~~text
首图 latent + UMT5 文本 + 时空位置
  → P₀(1664) → lift → U₀(3072)
  → block5 后的双流 P/H 交互 → (U₅, H₅ + ΔH₅)
  → block15 后的双流 P/H 交互 → (U₁₅, H₁₅ + ΔH₁₅)
  → block25 后的双流 P/H 交互 → (U₂₅, H₂₅ + ΔH₂₅)
  → Wan 后缀 → velocity → 采样 / 视频

每处 U → 独立 JEPA 解码头 → STRUCT
每处交互后的 H 分支 → LayerNorm → Linear(3072,3072) → ΔH
~~~

P 表示过程表征的概念，U 是代码中持续传递的 3072 维工作状态；它们不是两套额外规划器。H 是 Wan 中间隐藏状态，不是 VAE latent z。

| 现有部分 | 作用与保留理由 | 尚未证明的部分 / 审查重点 | 本版决定 |
|---|---|---|---|
| 首图、文本、位置初始化 P₀ | 构造推理可获得的过程条件，提供时空槽位 | 首图/文本不能唯一决定未来；初始化器没有直接读取当前噪声状态 | 保留；后续由 H 交互补充当前状态 |
| 1664→3072 非线性 lift | 连接 JEPA 定义的初始表征与 Wan 工作宽度 | 相同宽度不证明表征已经对齐 | 保留；由真实输出梯度学习 |
| 持续传递的 U | 可以积累跨层更新，而不反复压回 1664 | 是否积累了有效动态信息，还是主要拟合外观 | 保留；检查时序读出和输出贡献 |
| 两个原生宽度双流 joint-attention 块 | 已支持 P 读 H、H 读 P，具备状态依赖校正能力 | H 可主要依赖 H 自身，P 也可能只追随 H；attention 权重不能证明物理信息被使用 | 保留；测真实梯度与模块消融 |
| 三处独立模块 @5/@15/@25 | 提供不同深度的干预能力 | 单处收益能否共同成立、是否有冗余尚未验证 | 保留三处；诊断阶段只更新一处不等于删除其他处 |
| 文本 cross-attention 与 σ 调制 | 分别提供完整语义和噪声阶段信息 | 与初始化文本是否部分重叠，需要实验判断 | 保留；不要先移除再让 MLLM 替代 |
| 位置编码与有效 token mask | 保证时空寻址、排除无效区域、保护已知首片的直接写入 | JEPA/Wan 采样是否对齐真实时间与空间 | 保留并核验 |
| 三个 U→JEPA 解码头 | 给真实工作状态提供视觉监督 | 头可以拟合，而实际 writer 没学好；最后 writer 不受最后 STRUCT 直接监督 | 保留；补充输出监督 |
| 3072→3072 writer | 已是把交互特征转为 H 残差的映射 | 输入特征、输出方向、幅度是否可学习且有益 | 优先检验，不先叠加映射 |
| FM | 直接监督实际生成网络的 velocity | 平均误差不专门关注交互过程，也不等于完整采样质量 | 保留为主目标与独立指标 |
| Flow-Oracle | 证明当前样本、当前层存在局部 FM 改善方向 | 不等于共享参数可实现，更不等于物理正确 | 保留诊断及辅助监督；改变验收方式 |
| CFG 与每次调用重置 P | 规定真实部署计算路径 | 训练单次预测不能覆盖整段 CFG 采样误差 | 保持训练/推理定义一致，增加轨迹检查 |

**目前没有充分证据认定上述某个结构“确定无用”。** 删除需要在相同数据与合理匹配的计算预算下，进行去除后的重新训练和独立评估；仅推理时关闭后变化不大、梯度小或一次实验无提升，都不足以证明可删。可逆消融用于诊断，不构造训练正负样本。

## 2. 关键质疑与设计修正

| 必须回答的问题 | 批判后的判断 | 对应设计 |
|---|---|---|
| Oracle 能到 .20，学生为什么不能直接学到？ | Oracle逐样本使用GT优化自由张量；学生用共享参数且推理时没有GT，问题不同 | 先测共享 writer 可实现性；保留原自由 Oracle 作固定参照 |
| Oracle 已有真实 FM 梯度，再加回归一定更强吗？ | 不一定。小步标签回归可能只是局部 FM 梯度的重加权 | 同预算比较直接 FM 与有限步输出蒸馏，不以辅助 loss 下降宣称有效 |
| JEPA/MLLM 特征包含“物理”就够了吗？ | 特征可能主要编码外观或文字先验；即使可读也不等于被生成器使用 | 真实视频的时空关系/变化监督，加实际输出和独立物理读出验收 |
| ΔH 需要像 H，才可相加吗？ | 不需要；残差是修改方向。RMS相似、维度相同均不是正确方向的证据 | 用同层坐标、真实后缀响应和生成结果定义兼容性 |
| 多加一个映射或 Connector 能补救吗？ | 只有缺少条件信息或现有映射表达不足时才有依据 | 先查瓶颈；分别定位 MLLM→U 和交互特征→ΔH 两个接口 |
| 只加强时间平滑能消除负优化吗？ | 可能仅学会静止，无法恢复正确动作 | 对齐 GT 中实际变化与稳定区间，禁止把小运动当作物理改善 |
| 损失设计能保证未知视频全部改善吗？ | 不能；还受到信息、数据覆盖、模型表达和采样分布限制 | 用固定目标、分阶段实验与失败分支约束结论，不给无依据的效果承诺 |

一个重要数学边界：设学生推理可用输入为 I，FM 目标为 Y，则平方误差最优预测是 E[Y|I]，剩余误差包含条件方差。MLLM 是同一输入的变换时可以帮助有限模型提取信息，却不会凭空消除不可辨识的未来。**这个边界不证明 .20 不可达；它说明必须测量，而不能从自由 Oracle 推导必达。**

同时比较了以下监督学习路线，而不把最近讨论过的组件当作必选项：

| 路线 | 可能解决的问题 | 在当前项目中的取舍 |
|---|---|---|
| 显式物理状态或模拟器驱动 | 有标签时直接约束轨迹、接触和材料响应 | 网络视频通常缺少完整状态；可用于受控子集，不能假定覆盖所有WISA/OpenVid现象 |
| 单独训练随机动力学/未来规划模型 | 表达同条件下多种合理未来 | 当前U已读取noisy H，尚无证据必须再加一套大模型；先测时序能力与多样性再决定 |
| 直接训练完整去噪轨迹 | 缩小单步监督与实际采样之间的差异 | 长视频显存与计算代价大，且单GT不是所有未来的唯一答案；先用低中噪声短轨迹监督 |
| 少量解冻原生Wan参数 | 当冻结后缀或条件接口确实限制可达输出时提高表达能力 | 需先证明瓶颈在这里；当前保留冻结策略，避免混淆Corrector本身的问题 |
| 共享writer/交互学习 + 写入后监督 | 直接检查现有结构能否把物理依据转成生成改善 | 已有接口可复用、成本可分阶段控制，选为主线；不声称它对所有任务最优 |

### 2.1 首先辨清 P 的含义：P′ 不是物理时间上的下一帧

本文沿用 P 的概念名；实际跨层传递的是 3072 维 U。P₀ 的 1664 维、工作状态的 3072 维和 JEPA 教师的 1664 维不能混为同一坐标系。

必须区分三个索引：

- 视频时间 t：P 的 token 已覆盖整段视频的时空槽位。
- 网络深度 l：P′ 是当前交互后、更深一层的过程表征，不自动表示物体在 t+Δt 的物理状态。
- 去噪阶段 σ：每次 Wan 调用重新初始化 P，再读取这次的 noisy H；默认不把上一去噪步的 P 作为记忆传入。

所以，“预测 ΔP”首先只能表示**网络深度上的表征增量**。没有额外状态定义时，不能称为物理速度、加速度或未来状态变化，也不能把跨 block 的 ΔP 直接与真实视频的时间差分监督相对应。

### 2.2 苏格拉底式核查：我们真的只给 H 用了残差吗？

若 P 是没有跳连的绝对覆盖，担忧有依据：每层都可能重建状态，恒等映射和信息保留更难。但当前代码不是这种实现。

[corrector.py](../../physgen_v43/corrector.py) 中，P 先接受文本残差，然后 P/H 的 Stream.finish 都执行：

~~~text
x_attention = x + gate_attention × AttentionOutput
x_next      = x_attention + gate_ff × FFN(normalized(x_attention))
~~~

因此，在一个插入位置内可以写成：

\[
P_{\rm out}=P_{\rm in}+\Delta P_{\rm internal},
\qquad
\widetilde H=H_{\rm in}+\Delta H_{\rm internal}.
\]

写回 Wan 时则为：

\[
\Delta H_{\rm write}=M W_H\,{\rm LN}(\widetilde H),
\qquad
H_{\rm out}=H_{\rm in}+\Delta H_{\rm write}.
\]

这里的两种 ΔH 不是一个量：内部 H 分支的更新用于形成 writer 特征，实际交给 Wan 的修正由独立 writer 产生。P 返回完整状态，是下一位置的状态接口；H 返回修正，是冻结 Wan 的写入接口。

**结论：现有系统两条流内部都有残差；真实差异是 H 多了一个可训练、零初始化的外部写入接口，而不是 P 没有残差。**

仅把接口改写成：

\[
\Delta P=P_{\rm out}-P_{\rm in},\qquad
P_{\rm next}=P_{\rm in}+\Delta P
\]

在不增加映射、不改变初始化、不停止梯度的情况下，前向函数和梯度相同；最多有浮点重排误差。它可以帮助命名和诊断，不能自行解释或修复生成损伤。

进一步追问“把 P 的标签也改为增量会不会更合理”：假设处于同一固定坐标系，P*=教师状态，则

\[
\|P+\Delta P-P^*\|^2
=\|\Delta P-(P^*-P)\|^2.
\]

不 detach 时两者连梯度都相同。若把右侧目标改为 sg(P*−P)，则取消了经目标中 P 返回上游的那部分梯度，已经改变训练问题，不能再声称只是对称化。本次标量检查确认了这一差别。

当前 3072 维 P 又没有唯一的 GT 绝对状态；GT 是通过独立解码头对齐的 1664 维 JEPA 特征。直接计算“JEPA_GT − P”不合法；用正在训练的 lift 把 GT 升维再当成固定 ΔP 真值，也缺少坐标和目标稳定性的依据。V4.4 保留对更新后状态的监督，不发明 ΔP 真值。

### 2.3 不对称什么时候合理，什么时候可能伤害生成？

P 是新学习的过程工作状态；H 是冻结预训练生成器中的表征。两者承担的任务不同，因此**不要求同一个输出头、同一个标签形式、同一个更新范数或同一套初始化**。H 的零初始化 writer 保护原 Wan 的初始行为，P 的内部残差门初值 0.1 则使状态学习从一开始即可发生。冻结主干与零初始化控制接口也有既有研究依据，但这只支持初始化方式，不认证本项目效果。[ControlNet](https://arxiv.org/abs/2302.05543)

反例能排除两个过强结论：一个不对称模块可以让 P 准确编码交互、让 ΔH 改善生成；一个完全对称的模块也可以同时输出错误更新。因此形式对称既不是有效性的必要条件，也不是充分条件。

真正应检验的是：

| 追问 | 可能的失效机制 | 可证伪检查 |
|---|---|---|
| P 越来越像教师，H 是否实际使用这些信息？ | 独立解码头或 P 的辅助支路可降低 STRUCT，writer 仍走 H 的外观捷径 | 控制容量的 P 贡献消融、生成梯度、普通 forward 与完整采样共同验证 |
| 两侧是否在优化同一个真实过程？ | P 追逐教师可重建性，ΔH 追逐模型相关 Oracle；两者未必要求同一种输出变化 | 同一 GT 的实际输出过程监督；分别统计共享交互参数上的梯度范数和方向 |
| P 的更新是否过大或阶段不稳定？ | 文本残差、注意力、FFN 的累计变化改变下游条件，逐层 writer 难以适应 | 记录有效 token 的 RMS(ΔP)/RMS(P)、各位置与各 σ 的分布，再关联实际视频故障 |
| 初始化是否造成不良学习先后次序？ | H writer 为零时，FM 对其输入特征的梯度为零；早期 P 主要受 STRUCT 驱动 | 对比起始、writer 打开后及训练中期的梯度；不能把第一步的零梯度误诊为永久断路 |
| 同宽是否意味着同语义空间？ | 独立 JEPA 解码头可吸收各层的不同表示方式，宽度相同并不认证可写入 | 保留真实 suffix 检查；不靠 RMS 接近、attention 热图或 head 拟合决定有效性 |

这些都是待检验机制；现有损坏视频不能唯一归因于其中任何一项。P 的累计更新发生在一次 forward 的插入位置之间，不能错误描述为跨 50 个去噪步直接累积。

如果额外增加 P 的零初始化 writer，使 P_out=P_in+W_P·feature，同时 W_H 也为零，那么首步输出梯度会被各自的零输出矩阵挡在内部特征之外。输出矩阵本身仍可学习，后续梯度可以恢复，因此不是永久失活；但它引入了新的学习时序，不能假定比当前结构更稳定。V4.4 不将此作为默认修改。

### 2.4 同时交互的真实计算图：承认边界，不改变更新顺序

以单个位置的两个 JointPHBlock 为例：

\[
(P^{(1)},\widetilde H^{(1)})=J_1(P^{(0)},H^{(0)}),
\quad
(P^{(2)},\widetilde H^{(2)})=J_2(P^{(1)},\widetilde H^{(1)}).
\]

每个 J 都从同一组输入生成两侧 Q/K/V，再同时计算更新。第二块的 H 读取 P^(1)，不会读取同一块刚输出的 P^(2)；P^(2) 传给下一插入位置。

在最后位置 A@25，P^(2) 的最终更新仍接受 STRUCT，但在本版每次 Wan 调用重置 P 的部署定义下，没有下一处生成交互使用它。非零 H writer 下，本次 CPU 小尺寸检查得到：

| 检查对象 | FM 梯度 | STRUCT 梯度 |
|---|---|---|
| 前一个位置输出的 P | 非零 | 非零 |
| 最后位置第一个交互块输出的 P^(1) | 非零 | 非零 |
| 最后位置第二个交互块最终输出的 P^(2) | 无下游 FM 路径 | 非零 |
| 最后块 P.finish 的输出映射与 FFN 输出参数 | 无下游 FM 路径 | 非零 |
| 最后位置的 H writer | 非零 | 无路径 |

检查使用 tests/test_v43.py 中显式的小尺寸夹具及非零 writer，不是 3072 维真实 Wan 效果实验。最后块的 P 侧 K/V 参数仍参与 H 的注意力，较早 P 状态也确实参与生成；不能从表中推导“P 分支无效”。

**这是一种并行更新下的辅助监督边界，不自动构成实现错误，也不构成改用顺序更新的理由。** 辅助终点可以通过共享参数改善中间表征，但不能仅凭最终 P 的 STRUCT 下降证明 writer 已经受益。V4.4 明确保留同时交互，以实际输出监督和模块贡献实验弥补证据缺口。

必要时可做“监督哪个 P”的单独对照：在最后块实际读取的 P^(1) 上复用同一 JEPA 解码头，与当前 P^(2) 监督比较；如同时监督两个状态，先平均再乘原 STRUCT 权重，不能靠翻倍权重制造收益。此实验不更改交互顺序，不默认增设解码头。若改动导致辅助终点参数无训练路径，需要显式处理优化器参数组，不能留下静默的无梯度参数。

## 3. 推荐主线：同时交互，统一状态与实际输出的监督依据

以下图包含可选 MLLM 扩展。内部联合注意力不改为顺序读写，也不新增第二套 Planner。主线从“多加一种输出损失”加强为：明确要修正的物理量，在原生 H 空间学习满足输出与保真要求的修正。

### 3.0 核心目标：有物理含义、可被 Wan 使用且受保真约束的 ΔH

#### 3.0.1 “同一语义空间”必须定义到作用，不能只定义到形状

ΔH 是依赖当前 H 的修改量，不是另一份完整的视频表征。H 已编码的运动方向错了，正确 ΔH 可能需要抵消这部分信息；不能因此要求 ΔH 单独长得像 H、单独重建完整 GT，或与 H 有高余弦相似度。

将“语义兼容”操作化为三点：

1. **坐标一致：** ΔH 与写前 H 对应同一层、同一 σ、同一时空 token 和 mask，维度均为 3072。
2. **物理作用一致：** 同一固定读出器观察 H 和 H+ΔH，后者朝 GT 的可观察物理状态靠近；不能分别训练两个任意旋转的头，再称它们对齐。
3. **实际解释一致：** 冻结 Wan 的真实后缀能将这项修改转化为目标物理过程，同时满足画质与语义约束。

维度、LayerNorm、一个 connector 或 hidden 分布匹配只能处理接口问题，不能代替后两项。也不存在一般可直接取得的 H_GT：把干净 GT 在 σ=0 编码得到的 H 拿来监督 noisy H，会混淆噪声阶段和模型职责。

上述定义针对指定物理任务的可读性和生成器的实际响应，不声称一个低维读出器能够认证整个隐藏空间的语义。物理与外观也未必占据互相正交的通道，不能先假定存在一个任意修改而不影响画质的“纯物理子空间”。

#### 3.0.2 先定义物理任务标签 q*，否则“含有物理信息”没有训练依据

q* 从同一 GT 视频取得，首轮选择可靠的可观察过程：对象轨迹/相对运动、可见接触时刻与顺序、接触后响应、支撑或容纳关系、对象持续存在。不能从普通二维视频臆造不可辨识的质量、摩擦或外力。

用受控数据或可靠标注子集提供这些物理锚；普通网络视频仍用于 FM 与稠密过程学习。未获得某项标签的样本，将相应损失 mask 掉，不将缺失标签当作“没有事件”。JEPA 特征提供覆盖面，但不能自动等同于接触、运动规律或因果机制。有关利用显式几何/物理标注加强特征对齐的先例见 [PhysAlign](https://arxiv.org/abs/2603.13770)，不将其效果直接外推到本项目。

这不要求为所有视频构造完整对象图，也不构造正确/错误视频对；采用同视频的连续状态与事件监督。若只有未经核验的 JEPA 特征，项目只能主张经验性的动态改善，不能据此宣称 ΔH 已具有用户要求的物理语义。

首版 Ephys 按标签类型实现：可见位置、相对位移和接触时刻用按尺度归一化的 Huber 回归；接触/支撑状态序列用逐时间窗的分类误差；接触后的运动变化与 GT 的变化匹配。每一项先按有效标签数量归约，再按开发集固定权重组合；对象对应、可见性和置信 mask 使用可靠标注，缺失状态不参与归约。状态分类是同一视频的监督标签，不需要人为制造错误视频或偏好对。未观测到三维状态时只声称学习了可观察过程，不把二维轨迹回归改称完整动力学辨识。

##### WISA 的可用性与标签制作流水线

2026-09-21 只读核验了本机原始 `/run/determined/NAS1/public/Dataset/WISA/data/wisa-80k.json`：实际 79,480 条，包含原视频、caption、类别及 `physical_annotation`。后者的 `q0/q1/q2` 是动力学/热学/光学类别，`q3/q4` 是相机运动/对象变化描述；`n0/n1/n2` 及其量化版本对应密度、时间范围和温度。它们不是本节定义的逐对象、逐时刻 q*。官方论文说明这些物理属性由 GPT-4o mini 根据 caption 自动推断；尤其不能把估计密度、温度和时间范围当成实测物理真值或精确接触时刻。[WISA 论文 §3.2 与标注提示词](https://papers.nips.cc/paper_files/paper/2025/file/0856bc553d3e3b9827e5140d0ad3bf8d-Paper-Conference.pdf)

当前 WISA2400 缓存全部可按 `video_name` 与原索引匹配；但 2400 条的 `category` 均为 `unlabeled`，`objects/interactions` 均为空，`objects_reliable` 均为 false。因此已有缓存不能直接训练上述读出器。原始类别中，当前子集有 collision 139 条、rigid body motion 223 条、elastic motion 84 条，合计 446 条首轮动力学候选；这是候选数量，不是已经核验可用的物理事件数量。现有缓存保留了 `indices/pts/geometry`，可据此补标并对齐。

可批量制作的三条路线：

| 路线 | 可生成的监督 | 在本项目中的用途与限制 |
|---|---|---|
| 视觉模型分析连续片段 | 可见对象、事件类别、发生区间、前后状态与顺序 | 适合筛选和粗过程伪标签；模型须看当前片段，不能只从整视频 caption 猜答案；不认证数值动力学 |
| 检测/分割 + 点/对象跟踪 + 事件核验 | 归一化轨迹、相对位移、可见性、运动变化及接触候选区间 | 首选真实视频路线；优先单镜头、对象清楚的样本，相机补偿失效、遮挡或对象错配时 mask；二维重叠不能直接判接触 |
| 可控模拟并同步渲染 | 模拟器中的位置、速度、接触对象与事件，以及对应 RGB | 用于读出器校准和明确任务的补充；模拟真值受模拟设定约束，不能取代真实视频上的独立验证 |

检测/分割和跟踪可复用 [Grounded SAM 2 的本地视频跟踪流程](https://github.com/IDEA-Research/Grounded-SAM-2) 与 [CoTracker3](https://github.com/facebookresearch/co-tracker)，无需把这些离线工具全部接入训练反向图。模拟路线可用 [Kubric/MOVi](https://github.com/google-research/kubric/blob/main/challenges/movi/README.md)，其公开格式已包含位置、速度、可见性和碰撞事件；短合成片段不能冒充现有 121 帧真实视频。

已有可借鉴的数据处理工作：[PhysVid](https://github.com/5aurabhpathak/PhysVid) 使用 WISA 与 VideoLLaMA3-7B 生成连续片段的局部物理描述，并公开数据准备入口；这些描述不等于精确轨迹/接触标注。只借鉴可见过程的离线标注部分，不采用其反事实/负物理提示路线。[PhysRAG](https://github.com/sediment1024/PhysRAG) 公布了从 WISA 筛选的 6,869 条视频，可作为候选池参考，仍需制作本文的 q 标签。已有标注及筛选结果须核对来源和片段范围，不直接混入独立测试。

首版按如下流水线实施，先在当前 446 条候选中做小批核验，再决定扩展全量原视频：

1. **检索与定位。** 通过原类别、描述与自动标签召回候选，执行解码/切镜/可见性检查；再让视觉模型检查实际训练片段，提出对象和事件区间。保留不确定项，不把“描述中提到”当作“该片段中确实发生”。
2. **测量可见变化。** 在事件前后连续帧上运行分割和跟踪，输出对象/点身份、二维轨迹、可见性与相对运动；优先固定相机，必要时用背景运动补偿。坐标按画面尺度归一化、差分按真实 pts 计算，不从单目视频虚构米制速度、质量或作用力。
3. **事件核验。** 综合接近/分离、运动变化、视觉接触证据和片段描述形成事件区间；不由单个框重叠、单帧问答或模型自报置信度直接确认。精确时刻不清楚时保留区间/缺失 mask，不制造伪精度。
4. **校准与抽检。** 区分人工核验或模拟真值 q* 与自动伪标签 q_tilde，记录 `label_source`、模型版本、有效字段和置信度。按事件、相机、遮挡等分层人工抽检，校准接收阈值及监督权重；未知/不可靠项屏蔽，自动一致性不能代替独立物理验收。
5. **缓存对齐。** 标签作为独立索引按样本 ID、源视频和片段绑定，保留原数据划分；使用现有 `indices/pts/geometry` 对齐 121 帧输入及 JEPA/Wan 坐标，不依赖稀疏 JEPA32 捕获短接触。若重裁视频以覆盖完整事件，必须生成对应的新版本 latent/教师缓存，不能沿用原片段的缓存。
6. **接入训练。** 离线标注工具可以不可微；训练期使用经校准的可微 R/Q。训练 Q 的模型输出样本时，标签仍来自该输出自身可见的过程，不能套用源 GT 的标签。伪标签误差与独立测试结果分别报告，防止只复现标注器偏差。

因此，WISA 足以支持可观察轨迹与事件的批量补标和首轮验证；仅凭其现成全局标注不足以满足精确物理监督，也不足以认证通用物理能力。此处记录的是数据设计与只读核验结果，尚未运行上述自动标注流水线。

#### 3.0.3 生成 ΔH：保留同时交互，给原生 writer 明确的任务

\[
(P'_l,Z_l)=J_l(P_l,H_l,\sigma,c),\qquad
\Delta H_l=M_lW_l\,{\rm LN}(Z_l),\qquad
H_l^+=H_l+\Delta H_l .
\]

J_l 仍由两个同时交互的块组成；Z_l 为 H 侧的交互后状态。推理只依赖首图、文本、当前 noisy H、σ 与位置，不读取 q* 或未来 GT。W_l 保持 3072→3072，不凭“语义空间不匹配”再叠一个线性层。

这个公式本身不能保证物理性；它只是有能力输出当前 H 所需的状态依赖修改。关键改变是：训练标签与梯度要告诉 W_l **哪种物理偏差需要怎样改变，哪些原有能力不得破坏**，而不是仅告诉它与某个自由张量接近。

#### 3.0.4 原生 H 的语义锚：直接监督 H+ΔH

为选定层和 σ 条件单独校准物理读出器 R_l。它读取原生 H、σ 与必要的坐标，预测 q*；不读取样本 ID、答案字幕、完整 GT 或 P 作为旁路。先在独立训练子集训练，在来源隔离的留出集核验，然后冻结其参数，保留对输入 H 的梯度。

首版读出采用保留时间轴的 token 池化与小型时序头，为可见轨迹和事件分别输出回归量/概率；不把全片压成一个全局向量。它只存在于训练和评估路径，不夹在 H 与 Wan 之间，也不改变 3072 维主通路。R_l 的容量、校准数据量和 σ 范围必须记录；若原生 H 上都无法可靠读出所选任务，先处理读出/标签问题，不能直接把其不可靠梯度交给 writer。

\[
L_{\rm anchor}
=\sum_l {\cal E}\big(R_l(H_l+\Delta H_l,\sigma),q^*\big).
\]

这里 R_l→q* 是“目标过程是否可从表征中读出”的任务监督，**不是**声称 R_l(H_l) 就等于当前模型实际生成视频的物理状态。实际过程由下一节的输出观测来判断。

对同一个固定 R_l，增量表述为：

\[
\delta q_l=R_l(H_l+\Delta H_l)-R_l(H_l),\qquad
e_l^*=q^*-R_l(H_l).
\]

要求 δq_l 靠近 e_l*。当使用相同平方误差且不额外 detach 时，这与 Lanchor 是同一个目标，不再另算一项“新损失”。它明确 ΔH 承载的是**相对于当前状态的物理修正**，而非完整绝对物理状态。

读出器在新 H 分布上可能失准，也可能被优化投机。须核验校准误差、σ 依赖及更新后分布；每轮校准结束后再冻结，不能与 Corrector 一起任意漂移。最终物理感知验收使用另一组独立、同容量探针；参与训练的 R_l 变好不算独立证据。

#### 3.0.5 输出作用与副作用：在真实生成路径上定义

令 X_l(d) 为同一捕获状态下，将 H_l+d 输入真实后缀、得到 velocity，再还原预测干净 latent 并解码得到的视频片段。这是单步重建读出，不等于完整去噪采样。单位置教师搜索中，该位置已计算出的 P′、条件与模型权重固定；后续 Wan/Corrector 激活，包括后续位置的 P 更新，按真实后缀重新计算。固定快照仅用于教师子问题，学生联合训练仍保留完整 P/H 计算图。

\[
L_{\rm phys}={\cal E}_{\rm phys}\big(Q(X_l(\Delta H_l)),q^*\big).
\]

Q 是经校准、冻结且具有可用输入梯度的视觉过程读出。它的状态回归必须用可靠标注核验；若用 latent 代理提速，代理标签来自该 latent 自己解码的视频，方向资格按 §4.4 检查。**R_l 的表征目标和 Q 的实际输出观测职责不同，不能互相替代。**

质量与语义采用独立约束：

\[
{\cal E}_{\rm vis}(X_\theta)\le b_{\rm vis}+\epsilon_{\rm vis},
\qquad
{\cal E}_{\rm sem}(X_\theta)\le b_{\rm sem}+\epsilon_{\rm sem}.
\]

b 是相同输入、σ、噪声与 GT 下固定参考的误差，停止梯度；容差在开发集预注册。视觉项关注身份、颜色、可见结构和运动补偿后的异常变化，不能要求全部 H 通道或全部视频像素保持原样，否则会连错误运动一起保留。GT 中的真实运动、光照和形变应允许改变。

外层保真参考默认使用关闭 Corrector 的原 Wan，历史稳定 V4.3 另行记录，避免每次拿当前学生作参考而逐轮放宽退化。局部教师同时比较搜索起点 d0；相对 d0 的改善只证明该处搜索有效，不能取代外层固定参考的完整 forward 验收。原 Wan 也可能有错误，因此约束的是预定义保真误差，不是要求复制其所有输出像素。

这些约束首先适用于配对重建训练与局部教师；自由生成不硬匹配任意唯一 GT 像素。完整采样必须另做固定条件、多 seed 的物理与画质验收。

#### 3.0.6 物理写入教师：在 H 的原生坐标中求可行修改

先在 A@25，以当前学生写入 d0 为搜索起点，优化同层临时张量：

\[
d^*=\arg\min_{Md=d}
\left[L_{\rm phys}(X_l(d))
+\lambda_A{\cal E}(R_l(H_l+d),q^*)
+\eta\|d/s_l\|^2\right],
\]
\[
\text{s.t.}\quad
{\cal E}_{\rm vis}(X_l(d))\le b_{\rm vis}+\epsilon_{\rm vis},
\quad
{\cal E}_{\rm sem}(X_l(d))\le b_{\rm sem}+\epsilon_{\rm sem},
\quad
L_{\rm FM}(d)\le b_{\rm FM}+\epsilon_{\rm FM}.
\]

必要的局部搜索半径用于保证局部近似与数值可靠，不把“小 ΔH”当作物理正确或无副作用。最小改动项在满足物理任务的方向中控制额外改动，不能以 d≈0 冒充物理提升。

梯度来自固定 R_l 和真实后缀/输出读出：

\[
g_d=
J_{X_l,d}^{\top}\nabla_X L_{\rm phys}
+\lambda_AJ_{R_l,H}^{\top}\nabla_R{\cal E}
+2\eta d/s_l^2 .
\]

这是对原生 H 坐标求导得到的修正依据，避免把 JEPA 特征直接当作 H 残差。可以通过 autograd 的向量—雅可比积计算，不显式构造巨大 Jacobian。

上式为目标函数的梯度，s_l 在该次搜索中固定且停止梯度；mask 外不得更新。约束须在回溯中逐项检查；若使用违约罚项求候选，还要加入相应梯度，不能仅计算物理梯度后忽略保真条件。

只接受物理输出改善、其他规定指标不退化的候选；某一表征指标已经足够好时要求不退化，不机械要求每项每次都严格下降。搜索失败不等于正确 ΔH=0，不能把失败强行标成零标签。基线本来物理正确且保真通过的样本，则通过最小改动原则学习不作多余修正。

原 FM-only Oracle 独立保留作诊断，不能将其标签重新命名为物理标签，也不能用新的受约束教师替换恢复率分母。受约束教师可能找不到可行改进；先区分读出误差、有限搜索/优化失败和约束冲突，不能由一次搜索失败断定冻结后缀或当前结构没有可行方向。找到自由张量的方向后，还必须检验共享 writer 能否学习、未见视频能否泛化。

这个教师只认证已检查状态上的数值/观测指标；蒸馏后的共享学生以及完整采样仍可能退化。用户要求的“无副作用”必须落到预先指定的指标和适用分布上验证，不能承诺所有未知输入上的严格保证。

### 3.1 MLLM 的具体职责与接入位置

这是条件信息不足时的扩展规格。先用无 MLLM 的主线建立收益；若失败来自 writer 不可学习或代理梯度不可靠，添加 MLLM 不能代替修复这些根本问题。

**推理条件：** C = frozen_MLLM(首图, 文本, 固定过程查询)。读取能够注意到首图和查询的连续 tokens，使用可见动作、关系与过程语义；不要求输出人工定义的对象图。冻结条件编码器后可离线缓存训练条件，推理每条件编码一次。

**第一版 connector：** 保留原初始化器，在 lift 前添加一个输出宽度 1664 的残差 cross-attention 适配分支，让 P₀ 查询 C；输出投影零初始化。P/H 主通路仍为 3072。先用一个块，只有相比简单投影具有验证收益才加深。现有跨层 U 与 P/H 交互负责把条件带到三个位置，不同时增设第二套 Planner。

> 注：这是借鉴 MetaQuery 的条件适配思想，不是直接加载其24层 connector。若以后训练进入 MLLM 的 MetaQueries，必须保留穿过冻结 MLLM 的输入梯度；缓存固定特征的版本只训练外部 connector。原论文支持这种条件接口的研究方向，不证明它能修复本项目的写入。[MetaQuery](https://arxiv.org/html/2504.06256v1)

**GT教师：** JEPA 提供按时间组织的稠密视觉特征；MLLM 提供视觉过程/动作特征。后者编码 GT 视频时使用统一查询，监督目标不能靠附带正确答案的字幕生成。文字描述可用于离线核验语义对应，不能作为视觉读出器的输入。

**两条边界：** GT未来特征只作标签；MLLM不担任奖励模型或偏好裁判。先检查真实视频上的时序读出质量，再决定保留哪些层。MLLM 的物理线索不一定在最后层最有效。[Pixels to Principles](https://arxiv.org/abs/2507.16572)

### 3.2 ΔH 映射的决定

沿用 §3.0 的 Z_l=H_joint,l，记 F_l=LayerNorm(Z_l)，则 ΔH_l=mask · W_l F_l。**已有 W_l 就是待学习映射。** 再接一个纯线性层可以与 W_l 合并，不能补充输入信息。

首版保持它不变。只有“共享线性 writer 拟合不足，且排除数值/优化问题；同一输入的非线性版本确有收益”时，才扩展为：

~~~text
ΔH_l = mask × [W_l F_l + W₂,l SiLU(W₁,l F_l + E_l(σ))]
~~~

新增分支隐藏宽度保持 3072，W₂ 零初始化、W₁ 正常初始化；不同时把乘法门和输出矩阵都置零，以免新分支没有梯度。保留原 W_l 与 checkpoint 行为，不把 H 压入128/512维瓶颈。是否增加分支由瓶颈实验决定，不能因为想“适配空间”就默认需要。

## 4. 学到有效写入：监督必须穿过真实输出

本次修订不再把原来的五类损失平铺为核心方案。FM 与 STRUCT 保留；新增原生 H 的物理语义锚和真实输出的物理任务，语义与画质从可选改进项提升为约束。核心优化为：

\[
\min_\theta\;\mathbb E\!\left[
L_{\rm FM}+\lambda_P L_{\rm STRUCT}
+\lambda_A L_{\rm anchor}+\lambda_O L_{\rm phys}\right],
\qquad
\text{s.t.}\;\mathbb E[{\cal E}_{\rm vis}]\le B_{\rm vis},
\ \mathbb E[{\cal E}_{\rm sem}]\le B_{\rm sem}.
\]

期望约束可通过固定阈值罚项或约束优化实现，但近似优化不保证每个样本满足，因此还须报告逐视频退化比例、严重退化和完整采样结果。不能通过改称“约束”声称这些目标自动满足或计算免费。

原隐藏回归 LΔH 与普通 Leffect 作为可选的教师学习工具，不是物理定义；FM-only 标签与 §3.0 物理教师标签必须区分记录。相应系数和预算在独立对照后决定，不能用更低的教师拟合误差代替主目标验收。

所有指标单独报告。从任务上看，STRUCT 回答“P 能表达什么”，Lanchor 回答“实际 H+ΔH 能读出什么物理过程”，Lphys 回答“真实输出完成了什么过程”，保真约束回答“修正是否破坏已有能力”。这四种证据不可互换，也不要求 ΔP 与 ΔH 拥有相同标签形式。

### 4.1 真实 FM：优化与验收的共同基准

按当前定义，未知帧的 zσ=(1−σ)zGT+σε，Y=ε−zGT，LFM=MSE(vθ,Y)。已知首 latent 不计入。记录原始、未重加权 FM；不同 σ 的平均规则固定。

### 4.2 U 的监督：保留 STRUCT，逐步补充过程关系

原 JEPA 解码 MSE 保留。增加的时序目标仅使用同一条真实视频：对齐多个时间尺度的特征关系与变化，避免只有静态背景被拟合。关系监督可借鉴 VideoREPA，但它只是辅助，不据此宣称物理正确。[VideoREPA](https://arxiv.org/abs/2505.23656)

不能强迫 P₀ 仅凭首图确定性重建整段唯一未来；主要对已经读取 noisy H 的 U 监督，高噪声时降低不可靠细节的权重。现有 U 已能依赖当前样本状态，先不增加另一套随机规划网络。

### 4.3 Oracle 效果监督：让学生复现“输出改善”

在单位置、固定相同写前 H、P 和真实 suffix S 的阶段：

\[
v_\theta=S(H+\Delta H_\theta),\quad
v^*=S(H+\Delta H^*),\quad
L_{\rm effect}=\|v_\theta-\operatorname{sg}(v^*)\|^2.
\]

原 LΔH 保留为较轻辅助。Leffect 允许不同 ΔH 产生相近效果；局部等价于更关注 suffix Jacobian 敏感的方向，而不是所有隐藏通道同等重要。**这仍是使用 GT 的模型相关教师，不增加独立物理真值；不保证优于直接FM。**

还应追问它是否在数学上增加了任务信息。固定教师 v*、相同 mask 与均方归约时：

\[
\|v-Y\|^2+\lambda_E\|v-v^*\|^2
=(1+\lambda_E)\left\|v-\frac{Y+\lambda_Ev^*}{1+\lambda_E}\right\|^2+C,
\]

其中 C 与学生参数无关。这相当于回归 GT 与教师的混合目标；有限步教师可能改善优化或目标平滑，但该项本身不能当作独立物理监督或强创新点。验收必须包含直接 FM 的同预算对照。本次 CPU 数值检查验证了这个恒等式，未认证蒸馏有效。

先在 A@25 做上述配对。多位置联合训练时，不能把三个独立 Oracle 输出同时当成一个一致目标：轮换位置监督，或顺序求解且在下一位置重新捕获状态，并用完整联合 forward 复核。上游一旦更新，旧 H/教师缓存就必须刷新或只用于固定上游阶段。

### 4.4 输出监督：直接训练语义、过程与画质

在未知帧计算 ẑ0=zσ−σvθ，已知首片仍固定。以实际过程观测 Q 和可靠 q* 定义 Lphys；预测 latent 的视觉读出 \(\Phi_J,\Phi_M\) 与真实解码片段提供稠密辅助和保真检查：

| 项 | 同一GT视频提供的目标 | 防止失效的要求 |
|---|---|---|
| 物理主项 | q* 中可核验的轨迹、接触与响应等过程量 | 仅对有可靠标签的量计算；Q 经过独立标注与输入梯度核验 |
| 动态辅助 Ldyn | 局部/跨片段特征关系，以及多尺度变化 | 同时保留空间与时间信息，真实静止区间也监督；不将其单独命名为物理正确 |
| 语义约束 Esem | 按时间窗口的主体、动作、交互与结果 | 读出器只看预测视觉输入；保留原文本通路；不让答案字幕代替视频证据 |
| 画质约束 Evis | 颜色、局部结构、首图身份延续与GT时序残差 | 对齐可靠运动、遮挡与可见性；允许真实光照、流体和柔性形变 |

例如令 \(\hat F=\Phi_J(\hat z_0)\)、\(F^*=JEPA(V_{\rm GT})\)：

\[
L_{\rm dyn}=
\sum_{(i,j)\in\Omega}w_{ij}
\left|\cos(\hat F_i,\hat F_j)-\cos(F_i^*,F_j^*)\right|
+\sum_{k\in K}a_k\|D_k\hat F-D_kF^*\|^2.
\]

Ω 是同视频内采样的时空 token 对，Dk 按真实时间戳计算跨窗口变化；不是正负样本或对比损失。先用固定归一化的同教师坐标比较变化，避免仅通过缩放降低损失。时间窗口要覆盖完整过程与局部交互，不能全压成一个均值。

修订后，Lphys=Ephys(Q(X),q*)+ηdyn Ldyn；JEPA-only 的 Ldyn 组保留为旧方案对照，不足以完成新的核心目标。新增物理训练从可靠标签子集的低/中噪声重建开始，保真约束同时生效；高噪声不强迫所有细节与某一个 GT 未来逐点相同。对条件无法确定的过程降低细节权重或使用已校准的不确定性表示，不能声称首图唯一决定未来。

Evis 第一版使用同GT对齐的解码片段：帧内颜色/结构重建，加可靠可见区域内的运动补偿时序残差匹配。匹配的是预测残差与GT残差的差，而不是把预测残差压到零；GT中真实运动和光照变化应保留。光流与遮挡mask停止梯度，低置信度区域降权。约束相对于固定参考与预设容差检查，仅用于配对重建，不把自由生成锁定到唯一 GT 像素。纯 latent 重建与 FM 的重复部分不算新增物理信息。

**可微实现：** 优先独立训练小型 latent→教师特征读出器，再固定其参数，让梯度穿过它回到 ẑ0、Wan后缀、writer和交互模块。校准数据包含GT latent及当前模型实际预测latent；后者的标签必须来自“它解码出的实际视频”，不能错误地一律标成对应GT特征。读出器不读取P、文本或样本ID。

> 注：JEPA目前运行在独立环境，离线特征文件不能直接反传。读出器需在留出数据上核验特征误差与过程变化；定期用真实解码重新核验。若读出器失准，就暂停相应代理损失并重新校准，而不是继续优化分数。已有可微VAE解码类可复用，但梯度、因果缓存、clamp饱和和显存必须检查，不能只因类名叫可微就视为已通过。

**读出器必须通过两种资格检查，而不仅是回归误差低：**

1. 数值资格：在来源隔离的真实 latent 和模型预测 latent 上，检验特征、关系与事件变化的误差；教师标签来自各 latent 自己解码的视频，分布更新后重新校准。
2. 方向资格：在开发样本上沿代理损失的负梯度做小幅 latent 扰动，再真实解码、重算冻结教师的同一损失；比较预测下降与实际下降、无改善及恶化比例。步长在开发阶段固定，并分 σ、运动和遮挡类型报告。它检验的是局部优化方向，不是构造训练正负样本，也不是偏好或奖励优化。

小的函数值误差并不推出小的导数误差；学生可能利用代理的错误梯度得到“特征更好、视频更差”的结果。方向资格不通过时，该代理不进入训练。可用少量真实可微解码及教师路径作参考；跨环境梯度桥、输入梯度与显存均需单独验证，不能把离线缓存称为可微教师。

还须按 σ 检查监督强度。由 ẑ0=zσ−σv 可得 ∂ẑ0/∂v=−σI；同一 mask 下，纯 latent 重建误差恰为 σ²LFM。σ 很低时预测本来就接近 GT，代理分数好可能主要来自输入，传给 writer 的梯度也可能很弱。首轮选低/中噪声，但必须报告开关 writer 的过程指标增量与输出梯度，不能仅展示低噪声重建效果；不默认用 1/σ² 补偿而放大不稳定梯度。

运动补偿解码必须保留因果 VAE 所需的前序上下文。不能把任意中间 latent 切片当成独立首片解码，再将边界伪影解释为物理误差。事件窗口的 GT 时间戳、JEPA 采样点与预测片段要一致；时间插值不能恢复原缓存没采到的短暂接触。

### 4.5 H 与 ΔH 到底监督什么

- **ΔH：** 以真实物理作用和原生语义锚定义其职责；受约束教师可提供同层修正标签，原 FM-only Oracle 仅作另外的诊断。不用 H 数值、JEPA 特征或任意 clean H 直接充当 ΔH 真值。
- **H后的实际输出：** FM、Lphys 与保真约束共同约束；最后一个 writer 因而收到真实任务梯度。
- **H的物理感知：** 训练期固定 R_l 对 H+ΔH 提供语义锚；验收再使用独立、同容量读出器，检查未见视频上的过程信息。控制 σ、输入协议和读出层，完整 GT 不作为读出输入。
- **最终证据：** 物理信息更可读与实际生成改善同时成立。仅探针更好、STRUCT更低、ΔH余弦更高均不足以验收。

## 5. Oracle .25→.20 如何变成学生的改善

### 5.1 先做共享可实现性诊断，避免继续盲目调权

固定稳定参考模型的上游，在 A@25 提取归一化 writer 输入 F_i、实际 ΔH_i 和额外教师改变量 e_i*=ΔH_i*−ΔH_i，拟合一个所有视频共用的矩阵：

\[
\Delta W=\arg\min_B\sum_iw_i\|F_iB^\top-e_i^*\|^2+\mu\|B\|^2.
\]

使用现有 [writer_projection.py](../../tools/writer_projection.py)，把 W+αΔW 装回相同 suffix 与普通 forward 检查。μ、α在训练/开发集选择，最终测试不参与选择；多份噪声不能冒充多条独立视频。

| 观察 | 能说明什么 | 下一步 |
|---|---|---|
| 线性拟合与真实FM都改善 | 现有特征至少包含部分可用方向 | 学习writer；随后解冻现有交互模块提高可迁移性 |
| 拟合差 | 可能是特征、表达、正则或数值问题，尚不能断定哪一个 | 检查精度/岭参数；再比较同输入非线性writer与解冻交互 |
| 拟合好但真实FM不改善 | 隐藏距离与输出作用不一致，或部署重放/精度有误 | 核验suffix一致性，增加Leffect；不能仅增大写入 |
| 训练有效、未见视频无效 | 共享规则泛化不足或输入信息不足 | 扩大视频覆盖、多噪声训练，检查MLLM增量信息 |
| FM改善、过程/画质不改善 | FM改善没有转成用户要的效果 | 增强实际输出监督与采样验证，不称为有效物理修正 |

这个岭解只是固定特征线性子问题的解，不是神经网络能力上限，更不是可保证最终FM下降的步骤。额外做1—4条视频的共享网络过拟合检查，验证训练链能工作；过拟合成功不代表泛化。

### 5.2 从诊断进入监督学习

1. 固定上游时训练现有 writer，比较直接 FM 与 FM + 原隐藏辅助，确认普通 forward 能学习有效写入。Leffect 单独形成后续对照，不默认同时加入。此时保留 STRUCT 记录，但它不直接训练 A@25 的最后 writer。
2. 解冻现有 A@25 交互模块，使 Z 也能朝可写入方向学习；冻结的是优化参数，不是切断 Wan suffix 的输入梯度。
3. 在可靠物理标签子集上校准并冻结 R_l 与输出读出，训练 Lanchor、Lphys 并同时约束保真；先 A@25，再逐步联合三个位置、初始化器和 lift。保留原 STRUCT，MLLM 另做增量实验。
4. 单处通过后检查多处联合效果。教师搜索只用抽样微批/轮换位置控制成本，其余微批仍训练FM和输出监督；不要把所有预算耗在越来越强的临时教师上。
5. 物理写入教师按 §3.0 优化真实物理任务与语义锚、检查保真及 FM 约束；其接受率与学生可学习性单独记录。原始 FM-only 自由 Oracle 单独保留，不能换教师后宣称恢复率提高。普通 Leffect 不作为完成本核心目标的必要条件。

**为什么不只把Oracle权重提高：** 对固定H的局部子问题，若 ΔH*=sg(ΔH)−ηg，那么回归梯度与 \(J_{\Delta H,\theta}^{\top}g\) 成比例，可能只是重加权FM梯度。现有有限步/回溯提供更长的目标，但收益仍要实测。权重根据writer及交互模块的梯度范数、方向关系和开发集效果校准，不根据标量loss占FM的5%机械决定。

### 5.3 固定目标，避免把“接近 .20”说空

固定数据、σ分布、噪声、首片mask、归一化、参考模型和原始Oracle预算，记录：

\[
R=\frac{\bar L_{\rm ref}-\bar L_{\rm student}}
        {\bar L_{\rm ref}-\bar L_{\rm free\ oracle}}.
\]

若参考=.25、原自由Oracle=.20，则学生=.21恢复80%，=.205恢复90%，=.202恢复96%。本方案建议把“.20左右”的预注册目标设为**≤.205且与参考的差异统计可靠**；这是工程验收容差，不是已取得结果。逐σ同时报告，分母近零时只报告原始值。

原 .25→.20 若基于另一checkpoint/样本组合，换基线后必须重测，不能沿用绝对值。自由Oracle的分数不是学生必能达到的理论下界；即使达到FM目标，语义、物理和画质仍须单独通过。

## 6. 为什么会闪烁/错误变形，如何训练而不是“压小了事”

这些是需要验证的机制假设，不是已经定位的历史故障根因：

- **错误写入方向：** 用真实输出监督纠正；限幅只能限制影响，不能把错误方向变正确。
- **样本/噪声特异的Oracle标签：** 用跨视频共享参数、多噪声训练和输出效果学习，避免逐状态记忆。
- **跨层或跨去噪步不一致：** 单处验证后联合训练；P仍按当前设计每次调用重置，但每次读取当前H。不要把它当必须删除的结构。
- **CFG效应：** 现有guidance=5时，ΔvCFG=5Δvcond−4Δvuncond。两个分支都要按各自文本/MLLM条件运行，文本dropout也同步到MLLM条件，防止空文本分支偷偷拿到完整提示。
- **监督覆盖不足：** JEPA32缓存不保证看清121帧中的短暂接触。复用旧缓存，同时只为需要的连续窗口补充教师特征；保留均匀采样，不能只挑快运动片段。

训练后期可在低/中噪声的GT加噪输入上增加2—4步可微去噪重建，用实际solver或明确标记的训练solver，监督真实解码片段的过程与质量。多步solver必须保留自身历史，梯度检查点不能复用错误VAE缓存。此项按资源与验证收益启用，不宣称短轨迹等于完整50步生成。

**完整自由采样不与任意单条GT逐像素硬对齐。** 相同条件可以有多个正确未来。完整采样用于独立验收；训练只用监督重建/蒸馏，不引入奖励、偏好或负样本。平滑损失只约束相对GT异常的变化，不最小化全部运动，也不强制ΔH在σ上恒定。

## 7. 按顺序执行，每一步都有继续与停止依据

| 阶段 | 具体工作 | 继续条件 / 失败处理 |
|---|---|---|
| S0：建立可信参考与物理任务 | 固定原Wan与稳定V4.3评测线；明确可靠 q* 子集；核验 mask、后缀重放、精度及梯度 | 无可靠物理任务标签/观测时，只能做动态表征实验，不认证物理目标 |
| S1：现有结构能否写对 | 保留所有模块；先只更新A@25 writer，做共享投影、小集监督拟合，再解冻该处交互 | 学生普通FM能改善；否则按§5.1定位，不急着加MLLM/新映射 |
| S2：原生物理修正 | 校准并冻结 R_l、Q/输出代理；学习 H+ΔH 的物理语义与真实输出过程，同时约束语义和画质；验证受约束教师 | 语义锚、实际过程和保真同时通过；仅有 JEPA 分数或 R_l 改善不算通过 |
| S3：三处联合与采样一致性 | 更新三处现有模块及初始化，刷新教师；验证实际CFG和完整生成；必要时少量短轨迹监督 | FM、物理与画质共同通过；位置间冲突用轮换更新/联合重放分析，不直接删层 |
| S4：独立验收 | 封存参数与阈值，按来源隔离视频，I2V/T2V分开、多seed评价 | 达到§8全部条件才能报告有效；T2V不能继承I2V结论 |

首轮可用8—16条训练视频、独立的少量开发视频和多个σ/噪声完成S1；这只是故障定位。之后使用既有2279/121划分开展开发，最终另留按来源隔离、未参与调参的测试集，排除WISA/OpenVid重复来源。不要继续只用“每rank一个验证样本”作效果结论。

开发按上述顺序推进，但正式消融必须从**同一初始化或同一个参考 checkpoint 分叉**，不能把连续追加训练的几个阶段直接当作公平对照。相同历史 checkpoint 带来的 Oracle 训练历史也要记录；它不能代表从未使用 Oracle 的从头训练。

最低限度的训练比较如下。所有组都保持 P/H 同时交互、相同参数规模、数据划分、噪声计划和生成条件：

| 对照 | 训练项 | 要回答的问题 |
|---|---|---|
| A | FM + STRUCT | 同结构继续监督训练能做到多少？ |
| B | A + 现有隐藏 Oracle 辅助 | 临时教师相对直接训练是否有增量？ |
| C | B + Leffect | 输出蒸馏是否值得额外后缀成本？ |
| D | A + JEPA-only 输出关系/动态监督 | 上一版仅有稠密输出代理能做到多少？ |
| E | A + Lphys + 保真约束 | 真实物理任务与保真要求是否比 D 有增量？ |
| F | E + Lanchor | 直接锚定 H+ΔH 是否同时改善物理感知和输出，而非只改善训练探针？ |
| G | F + 受约束物理教师的可选回归 | 明确原生修正标签是否比直接主目标训练更可学、更省预算？ |
| 后续单因素组 | 在已通过的组上分别加 Leffect 或 MLLM | 工具性扩展是否确有收益？ |

原 Wan 与历史稳定 V4.3 另作固定评测参考。统一其余设置，计入搜索、读出器训练与特征提取成本；同时报告相同数据曝光与相近总算力两种口径。诊断用的 writer 关闭、P 干预属于模块实验，不构造训练正负样本。

对“P/ΔH 不对称”的专门检验保持以下顺序：

1. 验证将 P′ 改写为 P+ΔP 的前向与梯度等价；等价改名不值得重新训练一遍。
2. 记录真实模型中 P 增量、H 写入、分项梯度及各 σ 的响应，核验本节之前提出的机制假设。
3. 如有证据指向监督位置，按 §2.4 比较实际被 H 读取的 P 状态与末端状态监督；同时交互不变。
4. P 的贡献不能只看一次推理关闭：用推理干预定位，再用匹配条件下的重新训练验证必要性。仅因梯度小、关闭后变化不大或一次试验失败，不判某模块无用。

不把“增加 P writer”“先 P 后 H”或“让两侧改变量同范数”作为这个问题的默认解决方式。

## 8. 验收：有效性、物理信息与视觉质量必须一起成立

| 目标 | 合格证据 | 不能替代它的指标 |
|---|---|---|
| 学到Oracle改善 | 固定面板的普通学生FM接近原自由Oracle目标；分σ、按视频统计区间 | Oracle自身越来越低、加权总loss变小 |
| 语义正确 | 主体、动作、交互与结果完成度提高 | 单纯主体/风格相似 |
| 物理生成 | 实际视频中交互次序、响应、轨迹与过程完整性改善 | JEPA/MLLM特征相似度 |
| H的物理感知 | 冻结H后独立、同容量监督读出在未见视频上改善 | 只检查参与训练的解码头 |
| 画质 | 闪烁、错误变形、身份漂移没有新增退化，运动补偿指标和实际视频一致 | 写入范数小、图像更静止 |
| 合理多样性 | 语义/物理/画质合格的视频中，多seed仍有合理变化 | 抖动、偏题、失真带来的差异 |

FM用按视频聚合的配对区间；画质允许差异的范围在开发阶段根据评估重复性预先设定，不能看完测试结果再定。“差异不显著”不自动等于等效。对初步合格样本检查动作趋同与静止比例，不能以画面冻结换取稳定分数。

加强版主线要求在可靠子集上核验连续轨迹、接触时刻或响应；若另有完整三维状态，可增加对应评测，不需要构造正负视频。不在未知质量、外力、相机几何的网络视频上硬套守恒公式。仅观察视频时序改善，不声称已经识别完整因果机制。保真约束通过只支持“画质不劣”，若要声称画质本身提升，还须在独立画质指标或固定规则盲评中显示优势。

### 8.1 先回答“什么结果能推翻物理改善”

一段视频可以运动平滑、颜色稳定、JEPA 特征接近，却仍出现穿透或在接触前响应。因此 Ldyn、FM 和画质分数均不是充分的物理定义。V4.4 必须设置一个独立于训练代理的事件评测面板：

- 明确条件下的支撑与运动：失去支撑后的响应、可见轨迹与对象持续存在。
- 可见接触：接触发生时刻、交互先后次序及之后的响应；不对未知外力场景套单一规则。
- 容纳或材料过程：过程开始、持续与结束是否完整，是否出现不合理消失、穿透或静止替代动作。

先覆盖 2—3 类有可靠可观察标签的过程以定位问题，再扩展材料与场景。小面板不能宣称通用物理能力。评估可采用受控数据的轨迹/接触标注或固定规则的盲评；不要让训练用的同一 JEPA/MLLM 代理同时充当唯一裁判。公开 benchmark 必须按其输入协议评价，I2V 与 T2V 不混用结论。

如果只有过程表征分数提高，而事件成功率、过程完成度或未见组合的表现不提高，物理改善假设被否定。若画质提升伴随静止率增加、动作趋同或合格样本的多 seed 多样性下降，同样不能通过。

模块干预可证明“模型是否使用 P”，并不等于已经学到现实世界的因果机制。若要进一步使用因果主张，需要在已知条件或参数可控的场景中改变条件，检验响应方向和跨场景稳定性；这属于额外证据，不作为无状态标签网络视频的既成结论。

### 8.2 H 探针也需要排除重建捷径

在低噪声训练输入中，H 本来就能接触含 GT 未来信息的 noisy latent。控制 σ、噪声、输入协议、读出容量和划分后，探针改善才有可比性；低 σ 上更容易读出 GT 不能直接称为“首图预测未来更强”。分别报告带噪重建状态和真实采样状态的结果。

JEPA 的按时间排列 token 也可能包含全视频上下文，不能仅按 token 所在时间就当成因果状态。教师完整未来可作训练标签；预测未来的独立评测必须限制探针实际可见的信息。

## 9. 可行性、边界与交付范围

- **可复用：** Wan/VAE/T5、I2V缓存、JEPA32、P/H模块、writer、Oracle suffix、共享writer投影、已有可微解码实现。三处结构与旧checkpoint不被本方案删除。
- **新增主线：** 可靠物理任务标签与观测、冻结的原生 H 物理读出、实际输出物理任务、语义/画质约束及受约束教师可实现性检查。JEPA 稠密特征保留为辅助，普通效果蒸馏与 MLLM 仍是候选工具。
- **新结构检查：** 若扩展 connector 或 writer，新增残差零初始化后先确认同条件输出与原 checkpoint 一致。首步检查输出投影与实际 ΔH 的梯度；零输出矩阵前面的层首步梯度为零是正常现象，输出矩阵更新后再检查内部梯度。不能要求零初始化分支的所有参数在第一步均有非零梯度。梯度非零只认证链路连通，不认证修正有效。
- **显存：** 原Corrector约2.476B可训练参数，全量FP32参数/梯度/Adam状态约36.89GiB，另有Wan/激活/教师搜索。单个3072² writer为9,437,184参数，其上述状态约144MiB，因此writer阶段是可执行的低成本起点，不代表全量训练已完成显存认证。
- **环境：** runtime使用moviestory，JEPA使用vjepa2-312；GT教师离线，MLLM固定条件可离线，训练时仅加载小型读出/connector。缓存特征不传梯度，Wan后缀不能整体no_grad。
- **计算：** Oracle按需轮换与抽样；目标生成和学生图先后执行释放显存。多步解码监督低频运行，先验证短窗口再扩展。多卡旧实现并未自动分片整个Corrector，需要另核验。
- **不默认更改：** 现有原生宽度、三位置、初始化路径、P重置和冻结Wan策略。若充分监督与信息均已验证，现有交互仍不能表达有效修正，才提出扩大writer/交互能力或少量解冻Wan的专项方案；这不是当前默认步骤。

预期有效性的依据，是把四个可检验环节接起来：**可用物理/语义信息 → 共享参数能表达的ΔH → 真实输出受到监督 → 未见视频与实际采样共同验证**。现有结构已有前两者的计算接口，却尚未证明它们有效；本方案保留结构，通过监督与可实现性实验补齐证据，而不是假定“加组件就会成功”。

外部研究仅支持局部选择：MLLM条件桥接见[MetaQuery](https://arxiv.org/abs/2504.06256)；稠密视觉动态特征见[V-JEPA 2.1](https://arxiv.org/abs/2603.14482)；生成模型的时空关系监督见[VideoREPA](https://arxiv.org/abs/2505.23656)。这些结果不是V4.3效果保证，也不作为删改现有模块的直接依据。

### 9.1 从设计到代码仍需完成的工程工作

| 当前代码事实 | V4.4 实现要求 |
|---|---|
| Corrector.set_stage 会启用全部参数；parameter_groups 返回完整模块 | writer 单独训练阶段必须有明确的冻结与活跃参数组；不能把现有 trainer 直接称为已支持 S1 |
| synchronize_gradients 要求活跃参数都有梯度 | 分阶段冻结、条件执行和监督位置变更须同步调整参数组及多卡调度，不能静默跳过错误 |
| OracleTarget 只有隐藏残差、scale 和指标 | Leffect 若启用，需要保存或重算接受后的 velocity 目标，detach 教师，并验证后缀重放一致性 |
| 当前 checkpoint 要求配置相同且 strict 加载 | 版本迁移显式区分复用参数、新模块、训练协议和优化器状态；不靠全局 strict=False 掩盖缺失 |
| 当前原生物理读出、输出过程读出与梯度方向检查尚不存在 | 分别训练、校准、冻结并记录版本；区分原生表征目标与实际输出标签，不共用一个未经核验的分数 |
| 当前 Oracle 只优化 FM 与隐藏范数 | 新物理教师使用真实物理任务和保真检查；原 Oracle 实现及评测单独保留 |
| 可微解码实现存在，但 CPU 小模型测试未认证真实 VAE 的完整梯度 | 检查真实短片段的因果缓存、重计算一致性、clamp 与显存，再扩大长度 |

主结构保持同时交互与原维度，已有 Corrector 权重在张量结构上可复用；新增训练协议和可选读出器仍需显式版本记录。若仅增加损失和诊断，不应无故改变基础 forward。

单 writer 的约 144 MiB 是其参数、梯度与 Adam 状态，不是整个训练进程的显存。固定上游可减少反向激活，但 Wan、其他模块权重、后缀反传和缓存仍有成本。三处完整 Corrector 约 2.476B 参数，不能称为轻量 adapter；多卡仅分片 Wan 也不会自动分摊这部分优化器状态。

### 9.2 加强版目标的最小实现顺序

1. **任务数据。** 先选择可见接触/响应、支撑/轨迹等 2—3 类过程；缓存 q*、时间戳、可见性与标签置信 mask。轨迹按画面尺度和真实时间归一化，接触用可靠时刻标注，不把二维框重叠自动当真实碰撞。标签文件只进 loss/校准，不进推理条件。
2. **读出校准。** 先做 A@25 的 R_l：从相同 σ 下原生 H 预测任务 q*，与外观/场景捷径对照。在单独数据上训练 Q 从实际视频读取物理量；给模型预测 latent 配标签时，读取它自己解码的视频，不能一律套用源 GT 的物理量。先证明读出器可用，再训练 Corrector。
3. **保持原同时交互。** Corrector 的基础 forward 不改顺序，新增未 detach 的 H_before、H_plus 与 ΔH 诊断出口，供原生锚和输出损失使用。Oracle 快照可 detach；学生这些张量不能误用已 detach 的快照，否则无法训练预期参数。
4. **学生梯度。** 固定 R_l、Q、VAE 和 Wan 的参数，但保留输入梯度；Lanchor 经 H_plus→writer/交互反传，Lphys 与保真项经实际输出→Wan 后缀→writer/交互反传。JEPA 解码头仍由 STRUCT 更新，冻结读出器不进入 Corrector 优化器。
5. **局部教师。** 复用现有同层快照、临时残差、回溯和指标接口，另加物理目标与约束验收；先采样少量微批生成标签。教师期间只优化临时 d，学生期间只优化共享参数，不做高阶求导。
6. **保真执行。** 首版可用 max(0, Evis−bvis−εvis)² 及对应语义违约罚项，实现可微的违约惩罚；开发集和完整生成仍硬性验收。罚项在容差内为零，不要求模型把原参考的错误过程逐像素保留。平均约束通过不能掩盖少量严重退化。
7. **从单点到整网。** A@25 通过后再联合三个位置并刷新所有模型相关标签/校准。检查真实 CFG 下的条件/空文本两支、完整采样的错误积累，以及原 Wan 与稳定 V4.3 两条参考。

本次仅完成上述设计修订；既有 CPU 检查认证的是原结构与代数，不认证新读出器、受约束物理教师或新目标的效果。

## 10. 创新性审查：哪些已有，什么才可能成为贡献

截至本次检索，不能把“JEPA + 冻结 Wan + P/H 交互 + MLLM”这个组合直接声称为新的物理生成范式。

| 最接近的研究 | 已覆盖的思路 | 本方案需要额外证明的区别 |
|---|---|---|
| [VideoREPA，2025](https://arxiv.org/abs/2505.23656) | 通过视频基础模型的时空 token 关系蒸馏改善物理生成 | 在实际输出上监督的必要性、共享 writer 收益及其超出中间表示对齐的效果 |
| [Phantom，2026](https://arxiv.org/abs/2604.08503) | 冻结 Wan2.2，使用 V-JEPA 物理表征、双向分支交互，并联合建模视觉与物理潜变量 | 本方案的 P 是跨层工作状态，不是第二条带独立噪声与 velocity 目标的物理 flow；这一不同是否带来可测的效果或成本优势 |
| [PhysAlign，2026](https://arxiv.org/abs/2603.13770) | I2V 的特征关系与 3D 几何监督，配合 LoRA 训练 | 缺少完整几何标注时能达到什么，以及较大的 Corrector 是否值得其额外成本 |
| [PhysVid，2026](https://arxiv.org/abs/2603.26285) | 在 WISA 上生成局部物理描述，以时间片段条件增强视频生成 | 自动局部物理标注本身不是新贡献；本方案还需证明原生 H 的可读修正与实际输出约束有独立收益 |
| [MetaQuery，2025](https://arxiv.org/abs/2504.06256) | 冻结 MLLM 与生成模型之间的条件桥接 | 固定特征 connector 在本任务中是否提供可验证的过程信息增量；接口本身不构成新贡献 |
| [LINA，2025](https://arxiv.org/abs/2512.13290) | 离线搜索干预强度，再监督学习共享预测器 | GT-FM 的同层内部写入与其 MLLM 评估/引导强度路线不同；“搜索教师再训练学生”本身不是新思想 |

引用不等于采用上述方法的全部训练方式；本方案仍遵守不使用奖励、偏好、对比训练和正负样本构造的约束。不同论文的模型、数据和输入条件不同，公开分数不可直接拿来证明本方案优劣。

**当前判断：结构组合的创新性有限；有效写入的可学习性分析和有证据支持的训练方法具有研究空间，但还没有结果足以认定创新成立。** 可发展的贡献应当是：

1. 在相同生成器上量化“P 可读、共享参数可写、实际生成有效”三者的差距，说明失败究竟来自何处，而不是仅展示中间特征更好。
2. 在保持同时交互的条件下，证明同一真实过程的状态监督和输出监督能带来未见视频上的物理改善，并排除简单增训、重复加权和代理投机。
3. 给出实际算力、质量与多样性约束下的受控证据，回答较复杂模型为何优于更简单的监督微调。

这些是待验证的研究主张，不声称首次。普通输出蒸馏、残差参数化、增加一个过程 loss 或把 P′ 改名 ΔP 均不单独作为核心创新。最终论文级对照至少应包含同结构 FM+STRUCT、VideoREPA 式中间关系监督，以及合适容量/预算的普通监督微调基线；外部基线比较不要求删除本方案的模块。

## 11. 定稿后的执行与结束条件

本版的结构决定已经固定：**P/H 同时交互；保留 P 的内部残差与完整状态接口；保留 H 的独立残差 writer；不增加形式对称的 P writer。** 后续实现应按 §7 的实验矩阵验证训练方案，不能在结果出来前将候选项全部设成必需。

| 里程碑 | 必须交付的可审查结果 | 未通过时的处理 |
|---|---|---|
| 设计定稿，本次交付 | 明确并行结构、P/ΔH 不对称的数学边界、监督职责、近作差异及实验门槛 | 不将尚无结果的假设写成历史故障根因 |
| S0/S1：训练链可用 | 真实前向/后缀一致；正确的活跃参数组；小集 writer 拟合及未见噪声/视频评估 | 区分表达、优化、数值与信息瓶颈；不能因一次岭拟合失败就断定整个结构不可学 |
| S2：物理语义与实际作用可信 | R_l 与 Q/代理各自校准；H+ΔH 在独立探针上改善；普通输出有独立事件收益且保真通过 | 若只提升训练读出或代理分数，不能认证 ΔH 有效；不以追加 MLLM 掩盖 |
| S3/S4：版本效果通过 | 同时交互的三位置联合模型，在完整 CFG 采样中改善物理与语义，画质不劣化且保留合理多样性 | 仅单步 FM 或 P 探针改善，不认证完整 V4.4 有效 |

最后保留四个持续反驳本设计的问题：如果 P 的过程信息不能影响生成，凭什么保留相关解释；如果输出代理下降而实际过程没变，凭什么信任代理；如果同预算直接 FM 已一样好，凭什么保留教师搜索；如果只有多加参数或更多训练才有收益，凭什么宣称新的物理机制。每一项都由受控结果回答，不靠增加组件结束讨论。
