# 保留 v4.2 读写模块，恢复 v4 式联合训练

日期：2026-09-18。范围：对比 v4 `20260912T151800Z-e189c27c` 与 v4.2 `stability_20260917T181001Z_a83129/step1200`。本文是具体设计，尚未改动训练、推理实现，也未启动训练。

## 已确认的结论

可以保留 v4.2 的 P0→P5→P15、两个独立 reader/core/writer、时间插值和空间/时间 attention，恢复简单的联合监督与残差写回。没有证据证明 v4 的梯度不冲突；v4 没记录分损失梯度，因此不能从下降曲线推断它没有冲突。

当前需要分开的三个概念是：监督定义（拟合什么）、优化规则（如何合并梯度）、监控（只记录、不修改前向或梯度）。梯度投影和残差限幅属于优化/模型行为，不属于纯监控。

## 两版究竟有什么不同

| 项目 | v4 实际训练 | 当前 v4.2 实际训练 |
|---|---|---|
| STRUCT | 六个实际前向状态的 dense MSE 平均 | 辅助重算支路最终 P15 的归一化 MSE |
| P0 | 独立的逐时间槽空间池化 PRIOR；STRUCT 也可回传 | 无独立 PRIOR，STRUCT 经 core 回传到 initializer |
| H 与 STRUCT 梯度 | 后层 STRUCT 可经 H 回传到前层 writer | 辅助支路 H detach，STRUCT 不训练 writer |
| 独立 WRITE loss | 没有 | 有，权重 0.05，监督人工扰动输入的隐藏状态修复 |
| WRITE 目标 | writer 主要接受 FM，前层 writer 也接受后层 STRUCT 的间接梯度 | 当前模型在正常 GT 加噪输入上的 post-write H，detach 后作为参考；还经过可达范围投影 |
| FM/辅助支路输入 | 同一 GT 加噪前向 | FM 用标准加噪输入；配置概率 75% 的辅助支路使用额外 warp/drift 扰动 |
| 梯度 | 加权总损失一次 backward | FM 与辅助梯度分开计算；逐参数组删除辅助梯度中与 FM 相反的分量，再相加 |
| P 更新 | 学习门控、噪声 taper 等 | teacher RMS 参考的 soft bound、噪声 taper 等 |
| H 写回 | 学习门控、写回强度及噪声 taper | 学习门控，再按 token 和 frame 两级 soft bound；两处 frame 预算最高约 3%/5% |
| 最终速度 | 校正后的 Wan head 直接输出 | plus−base 再经两级 soft bound，最后加回 base |
| 监控 | 各层 STRUCT、结构增益、state/write gate、写回 RMS、联合梯度范数 | 上述部分指标加压缩率、逐帧分布、梯度夹角、WRITE 拟合、固定 health 等 |

v4 也有门控、loss warmup、sigma 权重和全局梯度裁剪，并非没有限制。v4.2 当前 recipe 已不使用旧的 20% 辅助梯度占比上限，不能把这个历史上限归罪于 step1200。

## “98% 冲突，余弦 −0.73”是什么意思

统计范围是第 1001–1200 步、每步累积 8 个 micro 后、投影之前的同一参数组梯度。core5 的 98% 表示 200 次 optimizer update 中 196 次 FM 与加权 STRUCT 的梯度内积为负；不是 98% 视频错误或 98% 梯度被删除。writer 参数组的辅助项是 WRITE，不能把 writer 的冲突也称为 STRUCT 冲突。

记 gF=∇LFM，gS=∇(加权 STRUCT)。梯度余弦为 dot(gF,gS)/(||gF||||gS||)。负值表示：对当前批次、当前参数，在一阶近似下，单独沿降低 STRUCT 的方向走，会提高 FM；反过来也成立。−0.73/−0.81 是较强的反向趋势，不是一个通用意义上的训练失败阈值。

当前投影在 dot<0 时执行：

```
gS_projected = gS - dot(gS,gF)/dot(gF,gF) * gF
g_total = gF + gS_projected
```

它让投影后的辅助分量在欧氏空间中不反对 FM，却没有让两个原始目标变成一致目标。剩余辅助梯度仍存在；FM 也仍可能提高 STRUCT。有限步长、AdamW 预条件及验证分布下更没有共同下降的保证。

日志中的 TOTAL(nominal) 是加权标量和，其普通梯度通常不是投影后实际使用的梯度。因此不能把当前总 loss 曲线当作普通联合优化的完整说明。

v4 直接使用 gF+gS+gPrior。它允许优化器在多个目标间折中，不优先删除其中一个方向。两个目标即使部分梯度冲突，也可能在合适权重下同时取得长期下降。v4 没有分目标梯度记录，不能补推其历史冲突率。

## 为什么会冲突，哪些只是机制推断

确定事实：FM 拟合 Wan latent 的去噪速度；STRUCT 拟合干净视频的 JEPA 特征。两者使用共享的 P/core 参数，但目标并不等价。writer 映射不保证 JEPA 距离缩短就能降低速度误差。

v4.2 还叠加了不同输入分布、STRUCT 与 writer 梯度隔离、移动的 WRITE 参考、状态与写回压缩、优先保护 FM 的投影规则。这些都是代码事实，可能使两条路径更难共同适应；未逐项做因果对照，不能声称它们分别贡献了多少退化。现有 writer 在生成中通常没有贴住预算，不能仅凭存在预算就宣称已经证实限幅是主因。

v4 辅助损失下降也有条件差异：实际训练约 75% 步的 initializer 能读完整 GT latent，且有六处 STRUCT 和独立 PRIOR。v4.2 不给学生完整未来输入、同时训练 I2V/T2V，teacher/损失归一化也不同。不能要求其原始曲线数值完全相同，更不建议为了让 loss 好看恢复 GT 未来输入。

## 推荐的最终配方：简单联合监督

保留当前两处独立校正器与 initializer、当前 512 内部宽度、1664 维 P 和 3072 维 H；不同时扩大模型或增加插入点。

1. 只使用同一次标准 GT 加噪前向，FM 和 STRUCT 看同一个 x_sigma。取消人工 warp/drift 修复分支及独立 WRITE loss。
2. 返回实际前向中保持计算图的 P0/P5/P15；STRUCT 使用 P5、P15 的平均，不仅监督最终 P15。
3. 恢复 v4 式 P0 PRIOR：每个时间槽按有效空间 mask 池化后做 MSE。不混合时间，不向学生输入 GT 未来。
4. 三项加权后一次 backward，不执行冲突投影，不加辅助梯度占比上限，不另设轮流冻结规则。
5. P/H 的 actual-path 梯度保持连接。冻结 Wan 参数不等于在 writer 之后使用 no_grad；梯度仍要穿过后续 Wan 运算。

采用当前固定 s_z 归一化，定义 D(P,Z)=mask_mean((P−stopgrad(Z))²)/s_z²：

```
L_struct = (D(P5,Z) + D(P15,Z)) / 2
L_prior  = mean_over_time(MSE(pool_xy(P0), pool_xy(Z))) / s_z²
L_total  = L_FM + lambda_s * a(step) * w(sigma) * L_struct
                 + lambda_p * a(step) * L_prior
a(step)  = min(1, step/200)
w(sigma) = clip((1-sigma)/0.2, 0, 1)
```

lambda_s=0.1、lambda_p=0.02 可作为首个候选配方；由于归一化、teacher 和结构与 v4 不同，这不等于复刻 v4 梯度强度，也不保证最佳。保留现有学习率起点、warmup 和全局 grad_clip=1，避免同时扩大步长。权重是联合目标的折中系数，不强行要求梯度夹角非负。

梯度归属：FM→全部 adapter；STRUCT(P5/P15)→initializer、core5、core15，并经 P15 对 H15 的依赖间接到 writer5；PRIOR→initializer。writer15 由 FM 训练，因为它位于最后一个被监督 P 之后。这是因果路径决定的，不需要为了“每层都有独立 WRITE loss”强加修复目标。

不通过切断 FM→P 或把 STRUCT 移到不影响生成的独立 head，制造统计上的“零冲突”。那可能让 loss 好看，却丢失训练物理状态用于生成的目的。

## 读写限制如何恢复

最终简化目标：保留 zero-init 输出投影、现有 write sigmoid gate、已有噪声 taper、有效区域 mask、I2V 首片固定、FP32 残差和全局 grad_clip。

- P0/core 的 delta_P 移除 teacher-RMS soft bound，保留原有结构及噪声 taper。
- writer 输出使用 `H_plus = H + taper(sigma) * gate * projected_feature`，移除基于 H/base RMS 的 token/frame 预算。gate 仍学习是否写回，不设最低开门率。
- 最终条件速度直接使用校正路径的 Wan head 输出 plus，移除额外的 delta_v bound。base forward 仅作为诊断，按需计算。
- reader 当前 observation 系数 0.1 首轮保留；它属于结构选择，不把所有系数同时改成 1。

不能仅在 step1200 推理时关闭这些限制，然后把输出称为新配方效果。限制参与了训练函数，新配方需要独立训练身份、配置版本和权重；旧 checkpoint 必须保持旧行为。

训练逻辑和读写限幅分两步验证：先用联合目标、原有 bounds 做约 200 步有限对照；若固定 health 证实结构学习改善，再用同一初始化/曝光计划、同一联合目标比较移除 bounds 的版本。200 步只能检验早期可训练性，不能证明最终质量或完整收敛。已有原配方前 200 步日志可作参考，严格比较需控制噪声、样本与硬件差异。

## 推理语义必须配套

当最终恢复为 v4 式“校正后的 Wan 预测”时，CFG 也应对两个校正分支计算：v = v_negative_corrected + cfg * (v_positive_corrected−v_negative_corrected)。两个分支各自按对应文本建立 P0，每个 solver step 按训练方式重置 P 链。

这要求训练时恢复约 10% 空文本 dropout，首轮推理用对应的空负向文本；否则把当前仅按正文本训练的 step1200 直接塞进负分支不成立。I2V/T2V 条件覆盖保留，GT 只作监督。该项在最终配方中配套实现，在诊断梯度策略的首个对照中不同时修改 CFG，以免混淆原因。

## 保留监控，但不让监控自动改梯度

- 训练记录 raw/weighted 的 FM、STRUCT(P5/P15)、PRIOR；明确记录 clean 或 repair 条件，不能把两类 STRUCT 混画成同一个任务。
- 固定相同样本、噪声、sigma，分别报告 I2V/T2V、P0/P5/P15、静态与动态误差。动态误差是 JEPA 表征误差，不直接称为物理正确率。
- 稀疏记录分组的 FM/STRUCT/PRIOR 梯度 norm、cosine 和联合方向对各目标的内积，只记录，不投影；避免仅统计负余弦比例而忽略实际联合更新。
- writer 保留实际 delta_H/H、gate、时空分布及开/关 writer 的配对 FM；最终仍看少量固定案例完整生成。gate 开得大或 loss 小均不能代替画质。
- 新配方继续保存 raw 和 EMA；以固定验证和视频结果选择，不自动把最后一步视为最好。

验收条件不是“所有 step 的所有 loss 单调下降”或“梯度余弦全部非负”，而是固定验证上有可重复的结构学习进展，FM 没有实质退化，且完整生成至少保持正常可辨认画面。基座本身已经生成严重条纹/色块的条件须单独解决，辅助损失简化不能被承诺为该问题的完整修复。
