## 2. v4 并不是“后层 gate 很小，所以 H 几乎没被改”

重新读取 v4 原始 `steps.jsonl`，并核对已有 [门控统计](../../v4/analysis/corrector_gate_followup_stats_20260913.json)。最后 100 个训练步均值：

| 位置 | state gate | write gate | 实际写回 RMS / H RMS |
|---|---:|---:|---:|
| A@5 | 0.9931 | 0.99993 | 14.98% |
| A@10 | 0.000158 | 0.99999 | 13.56% |
| A@15 | 0.001884 | 0.4853 | 4.60% |
| A@25 | 0.00000477 | 0.8325 | 8.31% |
| A@30 | 0.000000161 | 0.0867 | 0.291% |

state gate 控制 P 的增量；writer 的条件是整个更新后 P，不是仅本层增量。即使本层 ΔP 接近零，writer 仍可根据已有 P 产生非零 ΔH。不能把不同层 H 的写回比例、最终 velocity 比例直接相加或跨版本直接比较。

本次恢复的是两个 **write gate**，用于控制注入 H 的候选；不恢复已出现饱和关闭的多重 state gate，不强制最低开门率。gate 的开度不是物理正确性概率，gate 全关也不是物理学习成功。

### 2.1 读写方向、ΔP 和 ΔH 的准确含义

这里的 reader / writer 是相对外挂状态通道命名，不是某一矩阵可以直接复制到另一空间。当前实现依次执行：

1. **P 读取 H 的观察**：以投影后的 P 为 query、投影后的 H 为 key/value，得到 observation；core 使用 P、observation、文本、噪声等计算有界的 `ΔP`，更新 `P′ = P + ΔP`。当前观察系数固定为 .1，没有可学习 read gate。
2. **H 查询更新后的 P′**：writer 以投影后的 H 为 query、投影后的 P′ 为 key/value，经过时间对齐与空间 attention 得到 512 维 retrieved 特征 `r`。这里“ H 读取 P ”只指查询方向，不是 H 的最终更新公式。
3. **生成 H 空间的增量**：`u_H = Linear(512→3072)(r)`，`g_w = sigmoid(Linear(512→1)(r))`；`ΔH = Bound(g_w × u_H; H, H_base, σ)`，最后 `H′ = H + ΔH`。I2V 已知首片的 ΔH 为零。

因此，准确说法是“根据 H 和 P′ 计算 ΔH，再对 H 作残差更新”；不能说“把 P 的残差直接写回 H”。`ΔP = P′−P` 属于 1664 维状态空间，`ΔH = H′−H` 属于 3072 维 Wan 隐空间，二者既不相等，也没有直接相加。writer 使用整个 P′ 作为条件，不是强制只使用 ΔP。

v4 的 cross-attention 分支也是这两个方向：P 查询 H 更新状态，H 查询更新后 P 并通过 writer 生成 ΔH。v4 另外有控制观察的 read gate、控制 ΔP 的 state gate；修正版本仅恢复 write gate，仍保留状态和 H 增量的实际幅度限制。write gate 从 retrieved 特征学习每个 H 位置的注入比例，接受 FM 梯度；没有直接读取物理真值、STRUCT 分数或“正确/错误”标签。门值不能解释成被监督校准的物理置信度。

上述运算链在维度和更新方式上成立，但这不证明生成有效：P 更接近 teacher 后，`Writer(H,P′)` 是否产生更有利的 ΔH，仍是必须实测的语义映射问题。第4节的 oracle 对照正是在检查这一点。

## 3. 去掉干净未来输入：修正了条件差异，同时丢掉了有价值的学习通路

### 3.1 不能把多项改动归为一句“不要泄漏未来”

| 项目 | 实际对比的 v4 `image_text_gt` | 故障版本 v4.2 |
|---|---|---|
| 初始化条件 | 首图 latent、文本；约 75% 训练 step 还给完整干净视频 latent | I2V 固定首图 JEPA；T2V 文本 + 固定首图均值 |
| noisy latent 是否直接进 P0 | **不进入这次使用的 initializer**；更早兼容分支才使用 | 不进入；通过 core 观察 H 获得带噪视频信息 |
| 时间表达 | 每个时空位置有位置 query，可生成不同时间状态 | 先产生单张状态，再复制到全部 16 个时间槽 |
| 初始化器的结构学习信号 | 独立 prior loss，且后续 STRUCT 可沿状态链回传 | P0 在辅助支路 detach；TextInit 无 STRUCT/prior 梯度 |
| T2V 训练覆盖 | 主训练始终带首图，T2V 部署缺对应训练条件 | 有 T2V，但 100 步只见 200 次曝光 |

“完整未来作为输入”和“完整未来作为监督目标”不同。去掉前者不要求切掉后者的梯度。推荐先恢复可部署 initializer 的监督，不直接恢复多数训练有 GT 输入、推理没有的路径。

### 3.2 实际 step0100 的 TextInit 很弱

[初始化实测](generation_failure_20260917/initialization_comparison.json)，使用真实 checkpoint 和缓存条件：

- P01/P02 两个不同提示词，EMA P0 的差异 RMS / `s_z` 为 `8.22e-5`，即 **0.0082%**；raw 为 0.0362%。这是两个提示词的有限证据，不是全语义空间测量。
- 两个训练样本：固定均值 P0 的归一化 teacher MSE 为 `0.50491 / 0.52205`，EMA TextInit 为 `0.50752 / 0.52420`；raw 为 `0.63181 / 0.64290`。没有证据说此时 TextInit 已建立有用的 teacher 先验。
- I2V 首图锚点误差为 `0.25656 / 0.15086`。但它只是首图信息，不能替代未来运动。
- I2V/T2V P0 的任意时间槽与首槽之差最大值均为 **0**，由代码的 expand 决定。

修正：在辅助重算中重新构造只含部署条件的 P0，让 STRUCT 回传到 TextInit 和两个 core；H5/H15 仍 detach，teacher 梯度不通过观察支路回传到 writer。保持 FM 到全部实际使用的模块。无需新增第三个 prior loss。

后续候选：让 initializer 接收时间位置、时长，以及 I2V 的首图+文本，生成粗时间轨迹；或读取当前 noisy H。应在恢复监督后单独比较，不能与多项损失/架构改动同时宣布有效。高噪声下未来本来就不唯一，不能要求 P0 准确复刻唯一 GT 轨迹。

## 4. STRUCT 为什么可能不起物理正作用

### 4.1 三种空间不是同一种东西

`Z_GT` 是干净视频的 JEPA 表征；P 是学着预测它的外挂状态；H 是 Wan 的去噪隐状态。P 的 1664 维与 teacher 相同、几何网格相同，并不意味着 P 的任意改进经 writer 映射到 3072 维 H 后都有正作用。代码没有把 1664 维向量硬加到 H，使用了可学习投影/attention；未发现这种形状级运算错误，但映射的有效性没有被结构 MSE 保证。

旧辅助梯度被刻意限制在 core，writer 从未由 STRUCT 直接训练。P 的 MSE 下降与 writer 的生成收益之间只能靠 FM 协调；两条梯度在 core 上可能冲突，而旧日志没有记录方向。

[REPA](https://arxiv.org/abs/2410.06940) 的结果是对去噪网络表示施加投影对齐的研究证据，不是“任意外挂状态对齐 JEPA，再写回就能提升物理性”的证明。[V-JEPA 2](https://arxiv.org/abs/2506.09985) 的理解、预测和规划能力也不能直接等同于当前 encoder 的 token MSE 是一个物理正确性评分器。本项目目前没有使用 action-conditioned dynamics predictor 作为物理判别器。

### 4.2 teacher oracle 已证明两个评价量并不等价

[真实视频干预记录](generation_failure_20260917/supervision_bridge.json)：固定 `source0000949` 的完整缓存画幅/帧数、同一噪声，临时用 GT teacher 替换两个 core 的输出，仅用于诊断，不进入训练或部署。

| T2V，σ=0.85 | conditional FM | STRUCT |
|---|---:|---:|
| 基座 | 0.26117 | 不适用 |
| 学习得到的状态 | 0.24579 | 0.50074 |
| 正确 teacher 状态 | 0.24842 | 0 |
| teacher 的时间均值 | 0.24811 | 0.17359 |

正确 teacher 没有优于学习状态，去掉 teacher 的时间变化也未明显变差。可能包括 writer 对 teacher 分布不适应、未学会使用动态信息等原因；不能只凭一个视频确定是哪一种，更不能据此说 teacher 没有任何价值。它足以否定“STRUCT=0 必然带来最佳输出”。

这些是 **单步速度 MSE**，不是生成质量或物理分数。完整轨迹中，修正改变下一步输入，后续 Jacobian 和 solver 历史可能放大偏差。conditional FM 与部署的 CFG 预测也不同。单步改善、自由生成退化可以同时发生。

### 4.3 当前标签没有直接告诉模型“哪里违反物理”

2400 条记录中没有可靠对象局部标注参与当前损失；原 caption 常是整片概述，连续中心窗不保证覆盖完整接触事件。不能把 WISA 来源或正常画面自动视为逐事件物理真值。

[32 条 teacher 特征审查](generation_failure_20260917/teacher_energy.json)：前 24 train + 前 8 validation 的时间变化能量占总特征能量均值 **17.56%**，范围 7.79%–33.40%。不是“完全没有运动信号”；但原始 MSE 确实允许大量静态内容贡献。这个能量占比不是损失或梯度贡献占比，也不是物理信息占比。

本次只增加静态/动态误差分解用于诊断，不暗中把时间差分另起名字加回训练，不将特征翻转/打乱自动标为违反物理。时间倒放有时是合理物理过程，自动负例需要机制验证。

## 5. 损失长期波动，应怎样解释和检查

本次 100 个 update 的 FM，每连续 20 步均值依次为：

`0.34120 → 0.33275 → 0.33859 → 0.29703 → 0.32223`

各段标准差约 0.060–0.075。没有稳定单调下降趋势。首尾均值不同不足以证明收敛，也不能因为训练抽样变化就宣布训练正常。800 次曝光只有 768 个不同训练视频，T2V 200 次；EMA=.995 在 100 次更新后仍保留约 60.6% 的初始化系数。原始 loss 是变化样本、模式、sigma 的混合量。

旧 health 每 200 步才运行，此 checkpoint 尚未到第一次正式 health。缺少同条件 base FM，缺少固定面板随 step 的改善，是评价设计缺口。

本次增加：step0 基线、每 100 步固定留出视频/模式/sigma/噪声评估 raw 与 EMA，记录 base/校正 FM、差值、改善样本数。旧 checkpoint 的固定 4 train + 4 validation、两种模式、σ=.1/.5/.9 面板已完成，见 [fixed_fm_panel.json](generation_failure_20260917/fixed_fm_panel.json)：

| 固定面板 | EMA100 相对 base 的 FM 降幅 | raw100 相对 base 的 FM 降幅 |
|---|---:|---:|
| train I2V | 2.78% | 5.61% |
| train T2V | 2.92% | 5.21% |
| validation I2V | 2.26% | 5.13% |
| validation T2V | 3.09% | 5.72% |

每格12个固定输入，两种权重的96次预测均比相应base低。说明该面板存在小幅单步学习，不能说完全没有学习；但它远不足以证明物理收益或自由生成稳定，也不说明应该将默认EMA改为raw。随机loss波动量大于这种百分之几的收益，旧日志没有分离两者。面板只是8个视频，不是完整验证集，也不是不同训练step的收敛曲线。

每次实际速度修正记录恒等式：

`FM_corrected − FM_base = mean(δ²) − 2 mean((v_target−v_base) δ)`

它区分幅度与方向；把 FM 改写成“拟合速度残差”在数学上仍是同一个损失，不当作新的物理监督。

## 6. 正式修正配方

### 6.1 保留 v4 的简单权重约束和实际幅度保护

只有 FM 与 STRUCT 两项：

`L_nominal = mean(L_FM + λ_i L_STRUCT)`

`λ_i = λ_max × min(step/200,1) × clip((1−σ_i)/0.2,0,1)`

默认 `λ_max=0.1`，配置允许 `[0,0.1]`，0 为明确的 FM-only 对照。STRUCT 仍为有效区域 teacher MSE / `s_z²`，所以是沿用 v4 的权重日程，不声称与 v4 未归一化 MSE 完全同量纲。raw loss 不硬 clamp，避免达到阈值后梯度消失。

旧 v4.2 为 `0.1×clip((1−σ)/0.5,0,1)²×alpha`。σ=.98 时，旧系数在 alpha 前为 .00016；新配方 step100 为 .005，step200 后为 .01。低噪声下新配方早期仍有 v4 风格预热，不是把所有噪声段一律放大。

旧 alpha 只有 14/100 步小于 1，不能说始终在疯狂裁剪。真正的问题是分母用了全模型梯度：step100 的有效 STRUCT core 梯度约 .007048，而 core 生成梯度约 .000194，约 **36.3 倍**；全模型“20%”不代表 core 里只有 20%。这个规则删除。

保留 `grad_clip=1`，保留 state soft bound、writer5/15 的帧预算 `0.005+0.025w / 0.010+0.040w`、两倍帧预算的 token 限制，以及最终 velocity 预算 `0.03+0.17w`。参考 RMS detach，I2V 已知首片禁止写回。它们是实际残差相对参考尺度的上限，不是物理有效性保证。

write gate 为每位置 sigmoid，初始 .5，writer 输出层仍零初始化。避免同时零 gate+零输出导致两边都收不到梯度；首步 writer 可学，gate 在非零候选出现后可学。不强迫 gate 打开。

### 6.2 简化采样，不加载训练 VAE

单队列、每次更新 8 条普通曝光；每条独立以 1/2 概率选择 I2V/T2V。8 仅为显存所需梯度累积，不再有特殊第八条；不强制每批恰好 4/4。统一 σ∼U(.02,.999)。删除默认 TEMP、低噪声专用队列和 801 步 repair，训练不加载 VAE decoder 或 negative 条件。

数据缓存、121 帧上限、512 尺寸桶、teacher 定义、基座路径、学习率组、1200 步、EMA=.995 均保留。没有证据直接证明这些学习率必须更大/更小，不同时擅改。

### 6.3 只移除与 FM 相反的辅助方向，不再凑梯度比例

默认 `auxiliary_gradient_policy=project_conflicts`，可显式设 `none` 做对照。core5、core15、TextInit 分别处理，完整 8 条累积之后计算：

`gS' = gS − min(〈gS,gF〉,0) / ||gF||² × gF`，当 `||gF||>0`。

FM 为零时保留 STRUCT，确保零 writer 初始化时 core/TextInit 仍可学习。writer 不参与此投影，其梯度来自 FM。只移除冲突方向，不把整个 STRUCT 统一缩小到任意全模型占比；同向和正交分量保留。日志逐组保存前后范数、内积、余弦及移除量。

这是单向使用 [PCGrad 的梯度投影思路](https://arxiv.org/abs/2001.06782)，不是新增物理 loss，也不是论文算法的完整复现。它只保证投影后的欧氏梯度内积在数值误差内非负；**不能保证 AdamW 有限更新、验证集 FM 或 50 步视频单调改善**。TOTAL 标为 nominal，因为投影后不存在这里声称的统一标量目标。

### 6.4 如何证明正作用，而不把关门当成功

需要相同数据、曝光预算与固定生成条件的三个训练对照：FM-only、FM+STRUCT（不投影）、FM+STRUCT（投影）。这三个对照检验结构监督与梯度规则各自的作用；本次没有冒称已经完成正式重训。

每个 checkpoint 用相同 seed/prompt 对比 `VARIANT=base/full` 的完整视频；先看物体/身份/颜色是否正常，再看接触前后轨迹与事件完成。内部 state cosine、单步 FM、视频平滑度不能直接作为物理正确率。仅损失降低、gate 更大、内部状态变化更大，都不足以保留某项设计。

## 7. 要把代理信号升级成物理监督，还缺什么

本轮代码修复的是学习通路、目标冲突和评价缺口，不能从没有物理标签的数据中保证学出正确碰撞/支撑关系。真正应优先补的是：

1. **有明确事件的训练窗和对应 caption。** 保留现有原数据，不自动编造标签；另建可追溯的事件子集，标注接触前/接触/接触后、可见对象轨迹及遮挡。无可靠跟踪的样本不启用对象约束。
2. **把监督接到生成结果。** 可靠对象位置/接触响应应约束生成视频的观测，而不只约束内部 P。像素速度不等于三维速度；相机运动、遮挡需显式处理。若使用冻结 teacher 的生成端表征对齐，先验证它能区分目标错误，再替换现有弱代理，不能无验证地再叠一项损失。
3. **先验证 teacher/监督的判别力。** 对物理成立与不成立、外观尽量匹配的场景对，检查分数是否按物理变化，而非按颜色/纹理变化。受控模拟中改变支撑、接触顺序或碰撞条件比随意打乱帧更可信。按基础场景划分训练/测试，避免同一场景泄漏。
4. **再决定执行通道是否够用。** 若正确状态仍无法改善输出，优先修复/训练 writer 的语义使用，而不是继续扩大 STRUCT 权重。若普通 FM 微调已达到同样收益，接受更简单的模型；不要强迫一个无增益的 P 通道参与生成。

这部分是后续方法建议，没有擅自引入新 teacher、LoRA、模型路径或未经标注的“物理负例”。

## 8. 实现与验证边界

正式入口仍为 `train/train_stability_1x96g.yaml`，但新配方必须新建 run，不能把无 gate 的 step0100 当作同架构断点继续。旧 checkpoint 按自己的 config 严格加载，仍可推理。
