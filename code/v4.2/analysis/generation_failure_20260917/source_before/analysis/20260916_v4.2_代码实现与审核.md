# physGen v4.2：当前实现与审核

当前版本：`physgen_v42_v4data_f121_stability_v2`。用户最新指令优先于初始设计中的自动事件标注方案：**不使用Qwen3-VL或SAM，数据处理按v4，视频帧数上限改为121。** 本文已按实际代码更新，旧事件筛选方案不再是运行要求。代码仅写入v4.2，不导入或改写v4。

## 1. 数据处理与v4逐项对齐

| 项目 | 当前行为 |
|---|---|
| 输入索引 | WISA原索引前4000条；支持v4的selection_file/clip_annotations，默认空 |
| caption | 原始captions；显式提供片段标注时才使用对应caption |
| 划分 | 按视频文件名分组，seed=20260909打乱，validation_stride=20；源文件不跨两组 |
| 时间窗 | 原fps，连续中心窗；`1+4*floor((min(T_source,121)-1)/4)`；短于5帧排除 |
| 图像 | v4的32像素bucket，最长边512、面积147456，等比缩放和居中padding，不放大小图 |
| 时间信息 | 保存原PTS、原fps、帧索引和真实时长，不稀疏抽帧或填充源视频 |
| 记录标识 | 索引号及文件名身份；源文件大小/mtime用于准备阶段一致性检查 |
| GPU编码 | FP32 VAE、T5、JEPA分别运行、分别释放显存 |
| 数量 | 正式约3800 train/200 validation，实际排除数写manifest；不再等待4000+200条语义合格事件 |

数据准备为`index → vae → text → teacher → finalize`，训练sh自动先完成它，不需要已有缓存。删除Qwen/SAM调用脚本、相关配置、资产依赖、审核门槛与自动补事件循环。旧事件目录不使用，新的缓存目录为`cache/wisa4000_nativefps_f121_a147456_fp32_jepa32/`。

VAE FP32、teacher 32帧/16时间槽和首图锚点属于v4.2模型与监督定义，继续保留；数据来源、caption、中心取窗与空间预处理按v4。源片短于32帧时，16个教师相邻帧对允许重复位置，时间插值显式处理重复坐标，避免零分母。

资产默认只检查存在性、大小与mtime，并标明`metadata_only/sha256=null`；不再为启动校验额外读取几十GiB权重。该检查不等于权重内容哈希。缓存文件、统计和checkpoint保留内容完整性检查及原子写，版本升级防止把旧事件缓存用于本版。

合理性与限制：恢复v4的来源与取样能去掉昂贵的语义筛选，减少准备依赖，并保持消融数据逻辑可比；但中心窗和原caption不保证包含完整因果事件、也不保证caption只描述该窗口。不能继续声称所有入训事件已审核完整或具备可靠实例监督。模型机制对稳定性的作用仍需训练后验证。

## 2. 固定模型与计算接口

输入采用v4的32像素尺寸桶：最长边512、最大面积147456，不放大小图，保持完整源图与居中padding。视频实际帧数T为5..121范围的4k+1；FP32 VAE输出`[1,48,1+(T-1)/4,H/16,W/16]`。Wan patch仍为`(1,2,2)`，RoPE、FM符号与`t=1000*sigma`不变；H与时间位置按实际latent长度构造。I2V首latent每次前向及solver更新后固定，首片timestep=0，FM/写回排除首片。

教师输入索引为 `round(j*(T-2)/15), +1`，j=0…15，共32帧；短片允许重复teacher采样位置，但源视频/VAE窗不补帧。teacher 画布384×384，由训练画布再次 letterbox 得到；P 为 `[1,16,576,1664]`。有效 mask 按两次几何变换计算面积，纯 padding 不作注意力 K/V、不参与状态误差。H 的时间位置采用 VAE 因果组：首帧0，其后组1…4、5…8等的相位中心；P 为对应教师帧对的相位中点。两方向先按相位线性插值时间，再做同时间片空间 cross-attention；两侧位置都映射到相同训练画布坐标。

I2V：重复实际首图32次→冻结 JEPA→时间均值 A_image→复制16次。T2V：固定训练集逐位置均值 mu_first + 两层文本空间初始化器输出→复制16次。TextInit 只接收有效 T5 tokens，末层零初始化。

核心：1664→512；H 3072→512；8 heads、两层空间 attention→时间 attention→文本 attention→MLP；sigma、log(D/5)、site、相位/空间编码。`Q+0.1*Observation`；512→1664→1664 输出末层零初始化，`fP=.25+.75*clip(sigma/.15)`；每 token ΔP RMS≤s_Z。相同核心只在第5、15层各调用一次，P5传给P15，每个去噪调用 reset。

两个独立 writer 的最终512→3072投影零初始化。预算平滑窗 `w=S((1-sigma)/.20)*S(sigma/.15)`，`S(z)=clip(z)^2*(3-2*clip(z))`。第5层预算 `.005+.025*w`，第15层 `.010+.040*w`。token 参考 `max(min(rms(base_token),rms(current_token)),.1*s_frame)`；帧参考 `min(rms(base_frame),rms(current_frame))`。先token两倍预算，后帧预算；最终记录相加后的实际变化。

三路预测：`r=v_plus-v_bc.detach()`；同样两级限制得到 Δv，帧预算`.03+.17*w`，参考`max(rms(v_bc),.1*s_v)`。普通 FM 用`v_bc.detach()+Δv`；时间差分、恢复和推理用`(v_bn+5*(v_bc-v_bn)).detach()+Δv`。普通曝光无需 negative；时间差分曝光才执行三路。零 writer 时与原生 base 一致。

## 3. 三项目标与训练日程

| 项目 | 公式与归约 | 梯度职责 |
|---|---|---|
| FM | 条件速度或恢复速度与目标的元素 MSE；I2V 排除首片；每条/8 | 核心、两个 writer、T2V TextInit |
| struct | 最终 P15 与 Z_GT 的有效区域全局 MSE/s_Z²；乘`.03*clip((1-sigma)/.5)^2/8` | 只对 detach 观测重算的共享核心求导 |
| temp | 同一 FP32 VAE 的学生/GT 重建相邻差分 L1；每批唯一曝光乘.05 | 生成支路，冻结 decoder 保留输入梯度 |

本版不产生对象mask或轨迹，struct/temp采用全局监督。temp覆盖实际片段全部T-1对相邻帧，在最长边384的全局RGB上计算；纯padding排除，不除以秒间隔、不做硬clamp。没有局部实例监督，也不能将已移除的对象追踪作为质量保证。

每批8条，6 I2V/2 T2V；每4批的temp固定3 I2V/1 T2V。普通队列与temp队列各分层、无放回轮转，跨阶段保留游标；依据逐视频曝光次数在满足批次配额时优先轮转模式，记录实际覆盖，不能虚称每条视频均有两种模式或temp曝光。

1–100：只训练核心，sigma U(.02,.999)，writer关闭、TextInit冻结；核心LR前50步升至5e-5。101–200：核心Adam矩清零一次，启用所有生成参数和EMA；LR与writer/velocity预算乘`(step-100)/100`。201–1200：LR按原文cosine到峰值10%。801–1200：唯一temp曝光先无梯度走一步Euler，`sigma_b=.8*sigma_a`，target=`(x_b-xGT)/sigma_b`，FM使用实际guided预测；重新reset P。其余7条仍普通FM。

AdamW峰值LR：核心5e-5、TextInit2e-5、writer5 1e-5、writer15 2e-5；betas(.9,.999)、eps1e-8、decay.01；bias/norm/位置/模式/queries不衰减。参数与优化器矩FP32，算子BF16 autocast，cache_enabled=false。辅助梯度按整批`alpha=min(1,.2*||g_gen_core||/(||g_aux||+1e-12))`合并；预热除外。EMA从101步更新，decay.995。

每200步保存并对固定16条留出记录做单步健康检查；不在训练中扫描采样设置或生成大量视频。最终step1200 EMA固定唯一验收模型。

## 4. 代码职责与启动闭环

| 文件 | 职责 |
|---|---|
| `tools/dataset_index.py` | 复制v4取窗与分组规则，读取元数据，保存可复用views及manifest；不依赖v4包 |
| `tools/prepare.py` | 可恢复VAE/T5/JEPA编码、完整性检查、只用train定标 |
| `tools/bootstrap.py` | 空目录自动准备，完成后训练；不要求外部提供manifest |

| `physgen_v42/model.py` / `backbone.py` | 共享状态核心、两个writer、三预测路径、幅度限制 |
| `physgen_v42/encoders.py` | FP32 VAE与可微分块解码、T5、冻结JEPA |
| `physgen_v42/data.py` / `losses.py` | 数据读入、曝光队列、三目标与归约 |
| `physgen_v42/optim.py` | 优化器、梯度合并、EMA、队列/RNG恢复及checkpoint |
| `train/train.py` | 正式1200更新、固定验证与实际显存日志 |
| `inference/infer.py` / `report.py` | 加载正式EMA、UniPC生成、教师比较与空白质量审核表 |
| `quick16/*.py` | 共用数据/编码/训练微步的16条、两轮短任务及保存后推理 |

Wan原始FP32 time embedding/projection、head、norm3、Q/K RMSNorm和block modulation从原权重恢复；其余冻结线性/卷积以原生BF16 autocast等价精度使用。VAE从原始FP32权重加载并禁用decoder autocast/TF32。可微decoder显式传递跨时间块cache，checkpoint返回新cache、不detach；保存的张量可卸载CPU，RGB损失只保留缩图。

正式输出位于`checkpoints/<run>/step0200...step1200/`与`train/train_log/<run>/`。完成标记最后发布；正式latest_final仅在1200步完成后写出。断点恢复队列、逐视频模式计数、优化器矩、EMA、阶段和RNG，冻结模型构造之后再恢复RNG。

单卡Determined资源仍为`blk-96g`、一个slot；runtime为moviestory，teacher为vjepa2-312。不修改共享环境、不自动升级依赖、不提交远端任务。实际提交命令见[README](../README.md)。

## 5. 16条、两轮快速版

入口为`train/train_quick16_2epochs_1x96g.sh/.yaml`，配置`configs/quick16.yaml`。与正式版共用WISA索引器；取前16个可用视频，seed打乱文件名后每4个取一个验证，得到12 train/4 validation。短于5帧或不可读取的输入才做机械替换，不调用语义模型。

训练集每条恰好遍历两次：24次曝光，accumulation=4，6次优化器更新，每批3 I2V/1 T2V。六次更新依次映射正式日程1/200/201/801/802/803，覆盖预热、联合训练、带输入梯度的VAE差分和真实CFG的一步修复。共享`train_micro`新增可选累积数参数，默认仍为8；快速版FM/struct除4，唯一temp保持0.05。EMA更新5次。

两轮后完成4条验证，保存adapter/EMA/优化器状态。新进程严格加载保存的EMA，I2V/T2V各生成一条4步UniPC视频，帧数与对应输入片段一致，CFG仍为5。只有这些阶段全部完成后才发布`quick16/work/SUCCESS.json`和`quick_pipeline_passed`日志。缓存、模型与输出完全隔离，不发布或覆盖正式latest_final。

该入口用于尽早发现数据、编码、张量尺寸、显存、梯度、保存/加载及视频导出问题；4步视频和两轮优化不能用于评价正式画质，也未运行生成后JEPA报告。原始模型文件仍必须加载，耗时以实际磁盘和GPU为准。

## 6. 验证与预期有效性审核

当前修改检查Python/YAML/shell及导入，并与v4函数逐项比较中心窗和bucket选择；覆盖短片的teacher索引、时间插值前向/反向及两轮曝光安排。实际读取前16条WISA索引已完成：12 train/4 validation，14条121帧、1条57帧、1条45帧；该索引阶段约17.6秒，未执行GPU编码和两轮GPU训练。

历史CPU机制和真实小规格Wan/VAE GPU数值验证记录保留在`analysis/contract_checks*.json`：零writer原生等价、辅助梯度隔离、FP32分块VAE的输出/输入梯度一致性。这些历史记录不等于修改后的完整训练已通过；当前GPU全流程以quick任务输出为准。无独立检测脚本或资源探针；用户要求保留的quick16是可提交的真实短运行。

| 问题 | 当前机制 | 限制 |
|---|---|---|
| 干净未来条件失配 | 部署可得I2V首图和T2V文本初始化 | 学到正确运动仍依赖数据和训练 |
| CFG放大外挂 | 原生CFG加系数1的有界外挂差量 | 多步累计效果仍须看视频 |
| 代理目标主导 | 辅助只进core，范数上限20% | 范数限制不保证梯度方向有益 |
| 闪色/曝光跳变 | 同VAE的全片相邻RGB差分 | 时间恒定的颜色偏差仍依赖FM修正 |
| 接触/事件结果缺失 | 保留联合训练与低噪声修复 | 按用户要求恢复中心窗后不再承诺事件完整 |
| 准备过慢/额外模型失败 | 移除Qwen/SAM和全量权重启动哈希 | 原生VAE/T5/JEPA实际编码仍有成本 |

本版完成的是可运行方案与必要接口检查，正式1200步训练和最终物理生成质量尚未实证。v4源代码/配置/文档保持不变。若旧任务仍显示annotating，它持有的是旧进程，需要取消后重提新入口，不能依靠改文件热切换。
