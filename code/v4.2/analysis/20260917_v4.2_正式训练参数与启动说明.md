# v4.2 正式训练参数与启动说明

日期：2026-09-17。对应 `configs/stability.yaml` 的 `fm_struct_write_repair_trajectory_v1`，与旧 step0100 的 TEMP 配方不同。本文按当前执行代码核对数值；这些是首轮完整训练采用的参数，不是已经通过新视频质量实验选出的最优值。

方法见[ΔH监督与时序状态增量设计](20260917_v4.2_DeltaH监督与时序状态增量设计.md)，代码与验证范围见[实现文档](20260916_v4.2_代码实现与审核.md)。原基座、teacher、数据路径不变。

## 1. 实际反传的损失共三项

| 项目 | 原始目标 | 系数上限 | 接受该梯度的参数 |
|---|---|---:|---|
| FM | 正常高斯加噪输入上的速度 MSE，目标为 `ε−x0` | 1.0 | initializer、两个 core、两个 writer/gate |
| STRUCT | 最终 P15 对原视频 JEPA 状态的尺度归一化 MSE | 0.10 | initializer、两个 core |
| WRITE | 实际 ΔH 对配对 H 参考修复向量的预算归一化 MSE | 0.05 | 两个 writer/gate |

TEMP=0，不参与反传。两个 writer 的 WRITE 先取均值，计作一项；不是每层各加0.05。FM方向、ΔH范数、时空变化、gate大小等诊断不另加损失。当前数据没有可靠对象标签，不假设存在额外对象物理损失。

每次更新8条样本，名义标量为：

`L_nominal = (1/8) Σ_i [L_FM,i + λ_S(i) L_STRUCT,i + λ_W(i) (L_WRITE,5,i + L_WRITE,15,i)/2]`。

设 `r(s)=min(s/200,1)`，`q(σ)=clip((1−σ)/0.2,0,1)`：

`λ_S=0.10·r(s)·q(σ)`；`λ_W=0.05·r(s)·q(σ)`。

| 更新步数 | σ≤0.8：STRUCT / WRITE | σ=0.85：STRUCT / WRITE | σ=0.98：STRUCT / WRITE |
|---:|---:|---:|---:|
| 1 | 0.0005 / 0.00025 | 0.000375 / 0.0001875 | 0.00005 / 0.000025 |
| 50 | 0.025 / 0.0125 | 0.01875 / 0.009375 | 0.0025 / 0.00125 |
| 100 | 0.05 / 0.025 | 0.0375 / 0.01875 | 0.005 / 0.0025 |
| ≥200 | 0.10 / 0.05 | 0.075 / 0.0375 | 0.01 / 0.005 |

选择理由：FM始终承担生成任务；STRUCT保留0.1上限，但去掉旧平方噪声衰减和全模型20%梯度缩放。高噪声时图像证据少，辅助监督线性减弱；σ≤0.8时不再因噪声额外缩小。200步预热让新writer与状态支路共同建立映射，三项从第一步就开始，不存在先等待200步才学辅助任务。

WRITE按允许的ΔH预算归一化，量纲与FM/STRUCT不同，0.05不等于其实际梯度占FM的5%。使用0.05作为首轮上限，是让直接写回监督进入优化，同时避免尚未验证的合成修复任务取得过大权重；没有证据支持首轮直接升到0.1或1。

辅助梯度按参数组移除与FM相反的分量，然后合并、统一裁剪。它不限制辅助梯度必须小于FM的固定百分比；FM梯度为零时保留辅助学习。该投影只约束当前梯度内积，不保证AdamW有限步或视频质量单调改善，因此日志明确写作 `TOTAL(nominal)`。原始loss不作硬截断，避免高误差样本失去梯度。

## 2. 学习率与优化器

| 参数组 | 峰值学习率 | step1200 学习率 | 选择理由 |
|---|---:|---:|---|
| core5 / core15 | 5e-5 | 5e-6 | 学习视频状态与H观察的关系；保留比writer更快的状态适配 |
| 条件时序 initializer，组名仍为 text_init | 2e-5 | 2e-6 | FM与STRUCT现在都能训练初始化；以独立较低速率适配首图、文本和时序条件 |
| writer5，含gate | 1e-5 | 1e-6 | 第5层写回还要经过较多主干层传播，使用较小学习率 |
| writer15，含gate | 2e-5 | 2e-6 | 后段写回承担更直接的细化，但仍低于core |

- 优化器：AdamW，`betas=(0.9,0.999)`，`eps=1e-8`。
- 权重衰减：矩阵参数0.01；一维参数、norm、embedding、queries为0。
- 学习率前50次更新线性预热，随后余弦衰减，到1200步为峰值的10%；step1为峰值的2%，step200约96.27%，step600约58.07%。不在训练后半程切换任务或冻结参数组。
- 全局梯度裁剪：1.0，在8条累积和辅助方向投影之后执行。它是上限，不是每一步强制把梯度归一化到1。
- EMA：0.995，每次优化器更新一次，半衰期约138次更新。EMA用于验证/推理，不作为WRITE的参考网络。
- Wan权重冻结，约68.27M校正参数训练。主干计算使用BF16，校正参数、优化器状态与关键残差/损失计算保持FP32；开启activation checkpointing。

本轮保留这些学习率的依据是：原证据没有定位到某组学习率过大导致数值发散，而新方法已改变监督目标和梯度流向；同时放大学习率、STRUCT和写回预算没有根据。维持分组差异，先让新增监督在完整训练中发挥作用。不是用更小学习率把新方法关掉。

EMA在step100仍有 `0.995^100≈60.6%` 的初始化系数，step600约4.94%，step1200约0.244%。这不是“60.6%的基座混合视频”，而是参数滑动平均中的初始化贡献。每100步同时看raw和EMA；早期EMA不代表raw没有学到，也不应仅凭step100视频判断完整方案。

## 3. 数据、批次与训练长度

| 参数 | 正式值 | 理由/含义 |
|---|---|---|
| 设备 | 1×96GB；资源池 `blk-96g` | 沿用完整121帧训练入口；48GB入口目前用于推理 |
| 微批次 / 梯度累积 | 1条视频 / 8条 | 每次更新8条，均计算正常FM和辅助任务 |
| 总更新 | 1200 | 9600次视频曝光，约4.21遍2279条训练数据 |
| I2V / T2V | 每条独立各50% | 长期期望各4800次，消除旧6/2偏置；不强制每批恰好4/4 |
| 噪声 | `σ∼U(0.02,0.999)` | 所有模式与微批使用同一范围；没有特殊第八条噪声范围 |
| 数据 | 原2400条：2279训练、121留出 | 沿用原source划分、caption、原fps与连续中心窗 |
| 视频尺寸 | 最多121帧；最长边512、面积上限147456 | 沿用缓存几何，不把所有训练视频强拉成512×288 |
| teacher视图 | 32帧、384尺寸 | 与已有JEPA目标/统计保持一致 |
| 随机种子 | 数据20260909；训练20260916 | 保留原选择和训练可复现性 |
| 保存 / 固定验证 | 每100步 | 保存raw/EMA和恢复状态，观察训练过程 |
| ΔH详细训练诊断 | step1及每25步 | 只记录，不改变训练目标；固定验证中前4例额外比较writer干预 |

1200步是这轮完整训练长度，不是已经证明收敛所需的最优步数。step100只有800次曝光；每步的样本、模式、σ、噪声都变化，训练FM在区间内波动不等于无学习。查看固定留出输入上的raw/EMA相对base变化，再结合新权重的视频，不能要求随机训练TOTAL单调下降——前200步辅助系数本身还在增加。

## 4. 辅助扰动与写回范围

| 参数 | 值 | 选择依据 |
|---|---:|---|
| 辅助输入保持正常的概率 | 0.25 | STRUCT保留正常输入学习，其余辅助输入学习轻度偏离后的恢复；所有样本的FM始终正常 |
| 扰动系数上限 | 0.2 | 实际 `e=σ(1−σ)·U(0,0.2)·d`，全局RMS最多是真实latent的5%，不是20% |
| 位移场RMS尺度 | 0.5 latent像素 | 构造轻度连续形变方向；混合、归一化后还受上述幅度约束，不是最终视频位移上限 |
| 形变 / 平滑通道漂移混合 | 0.75 / 0.25 | 同时覆盖几何与表征漂移；不为二者分别添加loss或物理真值标签 |
| WRITE目标可达余量 | 0.95 | 投影到两级soft-bound联合可达范围内部，避免追逐不可达的限幅边界 |
| write gate | 启用；sigmoid初值0.5 | writer输出层零初始化，初始实际ΔH为0；gate不置零，保留第一步输出层梯度 |

忽略数值舍入和退化掩码时，按当前σ/强度采样计算，受扰样本的平均全局RMS约为真实latent的1.70%；包含25%正常辅助输入后约1.28%。局部像素/通道没有逐点5%上限，不能把全局RMS界限解释成每个位置都只变化5%。这组设置产生邻域修复目标，而不把真实视频改造成重度损坏样本。

实际写回沿用原预算，不因新增WRITE扩大：第5层帧RMS系数在0.5%–3%，第15层在1%–5%；token级另设对应帧系数的2倍界限，并经帧级soft-bound共同限制。分母是实现中的基座/当前H参考尺度，不是RGB亮度或物理速度。去噪中段允许更充分修正，两端收紧。最终velocity还有3%–20%的预算；初始化ΔP和每处状态ΔP按teacher尺度限制。

因此保留v4式限制，同时改变“修正方向从哪里学”：WRITE监督具体的H空间向量，STRUCT监督视频状态，FM约束生成任务。gate大小、预算和loss系数是不同概念，不能把gate=0.5解释为向H写入50%。

## 5. 正式启动

在此前可以提交Determined任务的环境执行：

```bash
cd /home/liuzhirui/Project/physGen/code/v4.2
det experiment create train/train_stability_1x96g.yaml .
```

也可在原提交界面提交同一个 `train/train_stability_1x96g.yaml`。该YAML调用 `train/train_stability_1x96g.sh`，默认读取 `configs/stability.yaml`。按用户要求，正式YAML和shell默认均为 `PREPARE=0`，只使用已有前2400条缓存；跳过bootstrap、索引重建及VAE/T5/JEPA编码。训练入口仍校验已有manifest、统计和文件记录；缺失或不匹配会报错，不自动重算。初次更新前有模型加载、缓存检查及step0固定基线计算。

**这次新建run，不设置旧step0100的RESUME。** 新建指重新初始化校正模块并载入原预训练Wan基座，不是从头训练5B。新recipe自己的checkpoint以后可以正常恢复；`train_stability_resume_step0100.yaml`、旧quick16/batch1和推理YAML都不是本轮新训练入口。

若已在具有相同路径挂载的单卡96GB工作节点中，可直接执行：

```bash
env -u RESUME -u CONFIG PREPARE=0 bash train/train_stability_1x96g.sh
```

提交忽略规则排除了现有诊断视频/张量目录，避免约755MB证据随代码上传；本地证据和共享挂载上的数据均保留。

训练输出：

- `checkpoints/stability_<新时间>_<标识>/step0100` 至 `step1200`，每100步一份；程序正常完成后更新 `checkpoints/latest_final.json`。
- `train/train_log/<同一run>/run.json`：实际配置、参数量与loss口径。
- `updates.jsonl`：逐更新损失贡献、学习率、梯度、显存和固定验证汇总。
- `micro.jsonl`：逐样本模式/σ/原始loss及ΔH诊断；`health.jsonl`：固定留出明细。

后续推理仍使用 `inference/infer_stability_1x96g.yaml` 或48GB推理入口，但需要把其中 `CHECKPOINT` 显式设置为新run的检查点。原推理YAML仍保留旧step0100路径；直接重复提交它不会自动使用新训练结果。建议先比较新step0600与step1200，结合固定留出结果选择，而不是默认最后一步一定最好。

本文核对了配置、调度公式和启动入口；此前真实5B的小尺寸训练/推理链路检查已完成。尚未提交本轮完整训练，也未据新权重验证完整视频质量。
