# v4 式联合监督 + WRITE + 75% GT 初始化

本次按用户最终要求实现：保留额外 WRITE，恢复 v4 式多层 STRUCT、直接 PRIOR、加权联合反传，以及约75%训练步完整 GT latent 初始化。本文件取代此前设计中“取消WRITE、不恢复GT输入”的候选建议。

- 新 initializer 增加 GT 投影参数，不允许将旧 step1200 作为新配方的 RESUME。新配方保存完整 optimizer、EMA、曝光队列和 RNG，支持自己的续训。

## 损失与 v4 对齐之处

设 a=min(step/200,1)，w=clip((1−sigma)/0.2,0,1)：

`L = L_FM + 0.1*a*w*L_STRUCT + 0.02*a*L_PRIOR + 0.05*a*w*L_WRITE`。

- FM：标准 `(1−sigma)*GT + sigma*noise` 输入，目标 `noise−GT`。I2V排除已知首片，T2V监督全部片段。
- STRUCT：**实际前向** P5/P15 对同一 JEPA target 的有效区域原始 dense MSE，取两层均值；不除 teacher RMS，不使用额外扰动的重算状态。
- PRIOR：P0与target分别在每个时间槽按有效空间权重池化，再计算原始MSE。保留时间轴，不将整个视频先时间平均；不乘sigma权重。
- WRITE：保留v4.2的人工扰动、同模型参考H、可达目标投影与writer-only训练。只给这个额外目标保留受扰支路；STRUCT与PRIOR均来自正常前向。
- 每个micro把四项按8次梯度累积折算后相加，**一次 backward**。每8个micro后全局grad_clip=1、AdamW更新。无冲突投影，无辅助梯度占比上限。
- STRUCT可沿P15→H15回到writer5；writer15位于最终P之后，接受FM与WRITE。GT target、WRITE参考和WRITE输入保持detach。

两版数值不能直接跨版本等同：v4有六个状态，当前v4.2有两个；JEPA采样定义也不同。本次恢复的是loss定义、权重、warmup、sigma规则与联合优化方式。

## GT 条件

- 每个optimizer step只抽一次开关：`gt_condition_dropout=0.25`；同一步8个micro共享，长期约75%使用GT，非强制每4步固定3步。
- 将该样本完整缓存VAE latent作为initializer额外上下文，所有时间槽都保留，空间自适应池化到最多8×8，48通道归一化、投影并添加时空位置。
- GT只进入initializer，不直接替换输出预测或P监督target。GT latent detach，投影参数仍可学习。
- 保留v4.2 I2V/T2V各约一半的曝光；两种模式都遵守同一GT概率。v4实际训练只有I2V，此处不假装完全复刻其模式覆盖。
- 约10%曝光使用空文本，恢复v4 text dropout。训练加载Wan之前调用真实T5编码一次空字符串；不重建已有视频、文本或JEPA缓存。
- 固定health和推理不传GT。eval模式显式拒绝GT输入。训练GT开关与文本dropout写入日志，续训恢复RNG。
