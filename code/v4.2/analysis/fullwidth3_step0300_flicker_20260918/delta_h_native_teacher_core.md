**1. 本轮只定义 ΔH*，P 的监督保持原样**

P 保留 1664 维 JEPA 特征目标及当前内容加权 MSE 监督，不新增 Planner、事件 token 或新的 P 损失。本文件集中规定教师增量从哪里来、如何判断有效，以及它能够保证什么。

主目标是取得：**同一冻结 Wan 原生计算可产生的隐藏状态差，并在原样本上验证这个差值的输出收益。** 这是对上一版直接自由优化 H 的进一步约束，尚未实现或验证生成效果。

**2. 先明确“原生 H”能保证到哪一步**

固定 Wan 权重、完整输入 x_sigma、首帧、文本、sigma 和位置以后，确定性的原生前向只有一个 H_l。因此，如果要求 H_l* 来自所有输入都完全不变的同一原生前向，非零 H_l*-H_l 不存在。

对 H_l 自由求梯度得到的变化，属于同一数值坐标空间，但不保证 H_l* 能由冻结 Wan 前缀产生。使用原生 block 的可训练副本也不能证明这一点，因为副本更新后权重已经不同。

为加强来源约束，采用同一个冻结前缀 G_l 重新计算候选状态。G_l 使用已经确定的稳定 Wan 基线及其冻结 LoRA，不包含旧写回或学生 Writer；它不依赖 P。设 u 是只在教师搜索中使用的原生输入 latent 扰动，保持首帧输入不变；文本、sigma、位置、模型权重和 token 布局保持不变：

\[
H_l=G_l(x_\sigma;c,\sigma),\qquad
H_l^*=G_l(x_\sigma+u^*;c,\sigma),\qquad
\Delta H_l^*=H_l^*-H_l.
\]

这里的 H_l* 确实是**同一套冻结 Wan 权重在一个邻近辅助输入上产生的状态**，不是任意指定的 3072 维数组，也不是另一套模型坐标中的特征。把完整差值加回同一个 H_l，会恰好得到这个候选 H_l*。

这保证了“冻结前缀能够产生该状态”，不保证“该辅助输入及其状态一定符合正常数据分布”。优化过的输入仍可能异常；邻域搜索与输出验收继续必要。H_l* 与 H_l 之间的有限差值也不能自动称为流形的切向量。

**3. GT 用来选择有益候选，不直接指定隐藏特征**

GT 不参与一个额外的学生输入分支。它提供标准 FM 的 `noise-clean` 目标，以及同一片段的冻结 JEPA 输出目标。

每个训练样本固定原始 x_sigma、采样噪声和目标，只优化 u。u 从零开始；候选隐藏状态始终重新经过 G_l 计算。u 不是新增网络参数，不改变冻结 Wan 权重，也不改变主干 H 的 3072 维宽度。

将 H_l* 放到原样本的插入位置，运行完全相同的冻结 suffix；如使用 CFG，按实际部署的分支策略、负提示词与 guidance 组合速度。当前原生路径的其他条件全部固定。

```python
h_base = frozen_prefix(x_sigma, context)
h_candidate = frozen_prefix(x_sigma + u, context)
delta_candidate = h_candidate - h_base

# 实际在原样本上实施隐藏状态干预。
v_candidate = actual_output(h_base + delta_candidate, context)
fm = mse_future(v_candidate, original_noise - gt_latent)
z0_hat = fix_first(x_sigma - sigma * v_candidate, first)
physics = output_jepa_distance(decode(z0_hat), gt_jepa)
```

`actual_output` 包含已约定的 CFG 组合；另行检查标准条件分支 FM。这里只列出目标关系，不是可直接调用的已有 API。

必须保留原始 x_sigma 计算 z0_hat；不能改用 x_sigma+u。也不能给候选另造一个噪声标签后宣称修正有效。否则证明的只是辅助输入自己的预测情况，而非给原样本写入 ΔH 后的效果。

输出物理目标沿用 PhyBridge 方案中“重建视频经冻结 JEPA 与 GT 比较”的时空关系目标。它不等于 P 自身更接近 JEPA，也不直接等同于物理定律正确。GT 与预测必须使用同一片段、相同的 32 帧索引、相同几何和有效内容权重。

**4. 搜索与验收保持简单**

在 u=0 处，通过完整冻结 Wan 和输出教师求 FM、物理目标对 u 的一阶梯度。需要去掉冲突分量时，在 u 的可变坐标上操作，然后重新计算真实候选；不修改学生参数梯度。

首帧输入对应的 u 固定为零。使用一次候选方向和至多三个递减步长。初始搜索半径可从当前噪声分量 RMS 的 1% 起步，但该数值只是局部搜索起点，需要按有效教师记录校准；不是靠小幅度认定修正正确。

候选只有同时满足以下条件才成为非零教师：

- 在原始样本上，标准条件 FM 与实际 CFG 输出 FM 均不增加。
- 从原始 x_sigma 重建的视频，其输出物理表征目标有超过数值容差的改善。
- 不出现明显的单个时间片重建退化或无效输出；使用已计算的逐时间片 FM 检查，不增加颜色差分或多尺度损失。

优先保留改善有裕量的候选；无合格候选则拒绝。未找到不等于证明零最优；教师失效或未运行的样本不能直接标成“正确增量为零”。

搜索结束只保存 stop-gradient 的实际增量、原样本身份、噪声种子、sigma、层位置、上下文和验收结果。教师与当前 Writer/P 的预测无关，因此不会把学生自己的输出当成正确答案。

**5. 不能用写回后处理破坏来源保证**

上述等式保证的是完整差值 `H_l* - H_l`。事后对它做 token mask、通道裁剪、低维投影或乘一个任意 gate，得到的状态通常不再等于 G_l(x_sigma+u*)；不能继续宣称它是同一冻结前缀生成的那个状态。

I2V 首帧需要固定的是输入 latent 和最终已知首帧。即使首帧输入不变，原生视频 attention 也可能因未来 noisy token 改变而改变首帧位置的 hidden。首帧 hidden 不是首帧像素，不能为保护已知图片而默认它在所有原生前向中必须不变。本版不在教师差值上事后清零首帧 hidden；FM 仍排除已知首帧。

如果需要调整教师修正强度，应改变搜索变量为 a*u，再重新计算 G_l(x_sigma+a*u) 并验收，而不是直接缩放已得到的 hidden 差值。若实际 Writer 必须带 mask/gate，则要按它最终实际写入的结果验收，并明确不再拥有上述完整状态等式。

**6. P 只参与预测，是否有益由真实输出决定**

教师 ΔH* 独立于学生 P 构造；学生继续从可获得的信息产生 P，并通过 JEPA 目标训练。Writer 学习 `(当前状态, P, sigma) → ΔH*`，不把 GT 特征直接传给学生 Writer。

保留 FM、P 的原 JEPA 监督、实际写入增量的蒸馏三类目标。教师向量拟合误差下降不是充分验收条件；在已有教师样本上检查学生写入后能否保留教师的重建与过程收益。

直接蒸馏 ΔH 不自动继承“经冻结前缀产生状态”的结构保证。如果以后要求学生推理时也严格满足这个性质，应让学生预测 u，再通过冻结前缀计算真实差值；代价是推理需要重跑前缀。本轮不新增这套学生结构，也不把较便宜的直接 ΔH 蒸馏说成具备同样保证。

**7. 对当前问题的预期与代价**

该构造减少自由修改全部 hidden 元素的任意性，避免把跨模型特征直接认作生成修正，并让“是否写入”具有 GT 输出依据。它有望减少有害写入导致的外观破坏，并提供与物理过程相关的修正示范。

可严格说明的是：H_l* 来自同一个冻结前缀；通过的教师在该原样本、该 sigma、该插入位置和该 CFG 设置下满足已定义的验收目标。不能据此严格说明：它一定在正常数据流形上、JEPA 代理下降就是物理正确、学生完全学会，或完整视频必然不闪色。

完整轨迹、推理分布和教师不可预测的 GT 细节仍会影响泛化。如果正常 FM 已能处理某个样本而物理目标与之冲突，也可能没有非零合格候选。不能用大量零修正保持稳定来冒充物理生成改善。

相比上一版只对 H 求导，此方案需要对冻结前缀也反传，并在每个候选重算前缀，教师计算更贵。可沿用每个 optimizer step 只为一个 microbatch 构造教师的起点；不额外启动多组生成对比。本次只修订设计，未进行训练、显存或视频质量验证。

已有[扩散模型隐藏空间方向研究](https://arxiv.org/abs/2303.11073)支持需要识别与评价具体语义方向，而非将任意隐藏增量视为有效；它研究的特定扩散隐藏空间不能作为本 Wan 方案的直接验证。这里对“原生来源”的较强结论来自明确的前缀构造等式，对“有益”的结论来自实际输出验收，两者分别成立。
