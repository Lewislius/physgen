当前实施方向见 [PhyBridge：原生隐藏增量教师与蒸馏](phybridge_native_hidden_teacher.md)。本文保留原生层微调的备选设计，不与 PhyBridge 同时启用；两者均尚未接入正式训练。

**1. 在 Wan 原生层中学习物理过程信息**

采用已经生成稳定画面的 `v4-static-lora` 原生 Wan 前向与 I2V 条件处理路径。初始化使用原 Wan 权重及 `v4-static-lora/checkpoints/lora_20260917T140727Z_dae2a0/step0800/ema.pt`，冻结已有 LoRA 参数，不重新初始化或合并它们。

训练 Wan 第 5、15、25 个原生 block，即 `blocks[4]`、`blocks[14]`、`blocks[24]` 的原模型参数；其余 Wan 参数冻结。三个 block 各自保留 3072 维隐藏状态、24 个注意力头及 14336 维 FFN。它们使用已有预训练权重，继续执行原生 attention、文本交互和 FFN。

三个 block 的原模型参数共 **490,970,112** 个。物理过程信息直接在参与生成的 H 中学习，不另建递归 P、P0 初始化器、P 状态门或 P→ΔH 写回网络。不从当前闪色 checkpoint 继承这些旧模块。

```text
首帧 + 文本 + 当前噪声视频
          ↓
Wan 原生计算：第 5、15、25 个 block 可训练，H 始终为 3072 维
          ↓
Wan 原生输出头 → 预测速度 → 原生采样与视频解码
```

初始化时沿用稳定基线的同一组权重和计算路径。训练后的兼容性由预训练初始化及真实输出目标维持，不能仅凭维数相同宣称保证兼容。

**2. 只用 GT 视频构造两类监督**

第一类是原有 FM：用 GT 视频的 VAE latent 和本次采样噪声构造 `noise - clean`，监督最终预测速度；固定首帧不参与生成误差。

第二类是过程表征监督：从同一 GT 片段按已有相邻帧对规则采样 32 帧，通过冻结的 V-JEPA 2.1 得到目标特征。复用现有缓存，不在主前向中加载在线教师。

在第 5 个 Wan block 的输出 H 上增加一个仅训练使用的 `Linear(3072, 1664, bias=True)` 读取头，共 **5,113,472** 个参数。它读取当前 H，预测对应 GT 的 JEPA 特征。生成主干继续使用原始 H，读取头的输出不回写主干，推理时删除读取头。

```text
第 5 层 H ──→ 后续 Wan ──→ 预测速度 ──FM── GT 速度
    │
    └──→ 训练用读取头 ──表征损失── 冻结 JEPA(GT 视频)
```

读取头和第 5 层都接收表征损失梯度；三个可训练 block 均接收 FM 梯度。读取头输入不能 detach，后续冻结 block 的主计算不能包进 `no_grad`，否则会切断 FM 对前面可训练层的监督。

仅在较早的第 5 层增加表征目标，不再要求三个深度都拟合同一个 JEPA 状态。此做法参考 [REPA](https://arxiv.org/abs/2410.06940)：训练时使生成模型隐藏特征的投影预测干净数据表征。本方案是将这一思路用于当前 Wan 视频微调，原论文不是本方案消除闪色的验证。

GT JEPA 是独立、固定的视频表征目标，不是经过当前 writer 生成的自参照目标，也不称作“正确的 Wan H”。它提供过程信息的辅助监督；具体视频重建由真实 FM 目标负责。

**3. 对齐真实时空位置，保留完整生成状态**

先在 Wan 自己的 token 网格上读取 1664 维特征，再按当前样本的真实时间和画面坐标，固定插值到 GT 教师网格。121 帧的 Wan 通常有 31 个 latent 时间点；JEPA32 有 16 个成对时间点，不能按数组序号直接对应。

沿用教师 letterbox 的几何映射和有效内容权重，屏蔽补边；短视频重复采样的帧对合并权重，避免重复计数。不对整段视频先做时间平均，逐时空位置保留 GT 过程信息。

辅助分支的插值与 1664 维投影只服务于计算损失，不改变生成路径的 token 数或 3072 维 H。两路对应特征分别做通道 L2 归一化，计算有效位置的平均 `1 - cosine_similarity`。

本版不设置多个空间尺度的颜色损失，不加入相邻时间差分损失，不构造不同噪声水平下 H 的差值作为 ΔH 标签。

**4. 保持训练与推理的条件一致**

主模型只接收首帧、文本、当前带噪视频与噪声时间。完整干净视频只用于构造加噪训练样本、FM 目标和冻结 JEPA 目标，不作为额外的未来条件输入主网络。

训练继续使用最多 121 帧、JEPA32、仅 I2V。教师必须取自与 FM 相同的片段及空间预处理，不能将视频级其他时段的特征作为当前片段标签。若说明文本中的物理事件不在该片段中，应修正片段或说明的对应关系。

推理仅保留更新后的 Wan 参数和冻结的基线 LoRA，使用原生 I2V、CFG 及解码路径，无教师、无读取头、无额外 P 状态。

**5. 损失、优化与保存**

新结构使用两项损失，不继承旧 WRITE 自一致性目标及 P0 PRIOR。旧版“有/无 PRIOR”配置不能直接当作新结构配置。

```python
loss = fm_loss + 0.05 * min(1.0, step / 200) * representation_loss
```

`0.05` 是归一化余弦损失的初始系数，不与旧 STRUCT 的原始 MSE 系数直接比较，也不宣称已经验证最优。表征监督覆盖已采样的各噪声水平，首版不额外套用旧写回的噪声衰减门。初始化阶段观察同一第 5 层参数上的 FM/表征梯度比例与方向，防止仅凭 loss 数值判断贡献。

原生 block 的起始学习率为 `1e-5`，新读取头为 `1e-4`；这些是预训练层微调与新头训练的起始值。保留现有梯度累积得到的有效 batch 8、100 步学习率预热、800 步训练和每 100 步保存。训练用 FP32 主参数与优化器状态、原生混合精度及激活 checkpoint；96GB 显存占用需在接入时核对。

总可训练参数为 **496,083,584**，约 4.96 亿；推理新增的读取头参数为零。保存三个原生 block 的更新权重、训练用读取头、优化器与运行状态，同时记录冻结 LoRA 和原 Wan 的准确身份。

在 V4.2 中使用独立的 `native_wan_physics` 训练/推理入口与配置，复用原生实现，不把新权重交给旧 CORRECTOR loader。恢复训练须匹配结构、基线权重、步数与数据进度；此方案从上述稳定基线开始新的训练运行。

接入核对限于初始化输出与基线一致、两项梯度到达预期参数、GT 不成为额外输入，以及保存后能正确加载。最终按少量既有严重闪色案例检查完整视频，不能仅用辅助特征 loss 下降认定画质修复。
