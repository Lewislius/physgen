**FM 的校正收益目前缺少直接测量。** 代码已经计算 `result['base']`，但训练和 health 日志只记录校正后的 FM，没有记录同一个输入上的基座 FM。它们不能回答“这次校正究竟减少了多少误差”。[训练及验证记录](/home/liuzhirui/Project/physGen/code/v4.2/train/train.py:58) 也还没有这一配对差值；截至快照没有到第 200 步健康检查。

在同一个样本、模式、sigma 和噪声下，令基座速度为 v0，目标为 v*，校正为 δ，残差目标 r=v*−v0。把内积和平方范数都按与 FM 相同的有效元素数归一化，则有：

`FM_corrected − FM_base = ||δ||² − 2<r, δ>`。

这是由当前 MSE 直接展开得到的恒等式。更大的校正只有在方向足够正确时才会降低 FM；如果方向不对，增加参数或放大残差可能提高损失。建议记录 `FM_base`、`FM_corrected`、差值、相对下降、`<r,δ>` 和夹角，并按 I2V/T2V、sigma 分桶。修复样本使用 CFG 预测，必须与同一修复输入上的 CFG 基座比较；不能把 conditional 和 CFG 两种口径混在一起。

在总体数据分布上，FM 的随机目标也不要求 MSE 降到零。对模型可见输入 I=(x_sigma, sigma, condition)，平方损失满足 `E||f(I)−V||² = E||f(I)−E[V|I]||² + E||V−E[V|I]||²`。后一项是可见条件下的目标不确定性，并不能仅凭扩容消除。这是平方回归的条件期望分解；FM 的向量场回归定义见 [Flow Matching 原论文](https://arxiv.org/abs/2210.02747)。有限样本记忆、验证分布表现和物理质量必须分开评价。

**从结构看，确实存在几种潜在限制，但当前没有证明它们已成为主因。**

- 插入位置只有第 5、15 层。第 16–30 层只有冻结的原生运算，不能通过训练重新组织这些层的时空特征。早期校正可以经这些层传递，也可能被变换成对目标不利的方向；需要消融判断。
- 两套 core 内部宽度为 512、深度为 2，处理 1664 维 JEPA 状态和 3072 维 Wan 隐状态。writer 的候选写入经 `512 → 3072` 线性层输出，因此其通道变化来自一个受限的可学习子空间。这不意味着整段视频的最终输出秩被严格限制为 512，因为后续主干仍有非线性。
- 状态只有 16 个时间位置，写回最长 31 个 latent 时间位置时采用插值。对快速接触、细小物体等问题，这可能形成时间分辨率瓶颈；增加通道数不会自动增加时间分辨率。
- reader 的观测项带固定 0.1 系数，core 状态更新也有限幅。它们改变优化和表达的条件，但后续层可能补偿，不能只凭系数就认定失效。
- JEPA 状态逼近只是代理目标。P15 更接近 teacher，不保证 writer 产生的速度修正更接近 FM 残差，也不保证碰撞、重力等物理行为更正确。

残差预算是另一种与参数量独立的约束。writer5 的帧预算为 `0.005+0.025*w(sigma)`，writer15 为 `0.010+0.040*w(sigma)`，最终速度校正为 `0.03+0.17*w(sigma)`。中间噪声区间 w=1 时，名义上限分别为 3%、5%、20%；靠近两端时减小。例如 sigma=0.98 时，分别约为 0.57%、1.11%、3.48%。这些都是对各自参考 RMS 的上限，不是实际写入量，不可把两个 writer 的百分比直接相加当作最终速度幅度。[限幅实现](/home/liuzhirui/Project/physGen/code/v4.2/physgen_v42/model.py:18) 和 [最终输出限幅](/home/liuzhirui/Project/physGen/code/v4.2/physgen_v42/backbone.py:138) 同时施加 token、帧两级约束。

对单个 soft bound，`δ=a*u/sqrt(a²+RMS(u)²)`；候选幅度远大于 a 时，输出趋于饱和，而且沿候选径向的梯度也变小。因此，如果后续出现大面积预算饱和，单纯增加 core 或 LoRA 参数仍绕不过最终输出上限。这时应单独改变预算做对照。当前日志显示候选整体仍小，立即放大预算预计不是最直接的解决办法；这是基于当前幅度的判断，不是已经运行过放大预算实验。

**开放基座参数需要同时改训练路径，否则会出现“看似解冻、实际没训练”。**

- `optimizer_for` 只收集 `adapter.groups()`。只设置 Wan 参数 `requires_grad=True`，它们仍不会被优化器更新。
- `inputs()` 和第 1–5 层在 `torch.no_grad()` 中执行，文本、时间嵌入和前五层只靠解冻得不到梯度；必须在生成分支重算这些路径。
- base、plus 和 negative 当前共用同一套 Wan 对象。如果直接更新共享参数，下一步所谓 base 就会随之变化。`detach` 只停止梯度，不保留原始权重。若要保持“原生 Wan + 有界校正”，需让 LoRA 只在 plus 分支启用，base/negative 禁用；对于 norm、head 等直接训练方案，需使用独立副本或可关闭的参数增量。
- 新参数必须进入优化器、学习率、全局梯度预算的参考集合、裁剪、EMA、保存/恢复和推理加载。否则训练更新可能丢失，或恢复和推理行为不一致。
- 主干多数权重当前以 BF16 存储。直接微调时需要规划可训练权重或 master weights 的精度，不能假设极小更新能可靠写入 BF16 参数。

当前日志峰值 allocated 约 57.0 GiB、reserved 约 66.2 GiB，仅代表前 10 步覆盖到的形状；不能据此保证扩容后所有 121 帧样本及 VAE 反向都能放进 96G 卡。LoRA 的优化器参数开销较小，但新增路径的激活与重计算成本仍需实测。全量微调不适合作为第一轮诊断实验。

VAE、T5、JEPA teacher 不宜作为降低 FM 的首选开放对象。VAE decoder 不在 latent FM 的计算图上，单独解冻它最多直接改变 TEMP；VAE encoder 若改变，需要重建 latent 缓存、标定和 FM 目标。T5 的输出目前离线缓存，解冻编码器需要重建训练链；更低成本的选项是先训练读取 T5 特征的投影。JEPA 是固定监督来源，改变 teacher 可能让结构指标因目标变化而变小，并不证明生成改进，且当前 teacher/anchor 缓存不会自动随权重变化。

**训练覆盖和指标定义也可能限制结果。** 正式配置有 2279 条训练数据、1200 次更新、每次 8 个曝光，总曝光约等于 4.21 遍训练集；T2V 曝光均值约为每条 1.05 次，TEMP 曝光均值约为每条 0.53 次。不是说这必然不够，而是不能把 1200 步理解为所有分支都已充分见过每条数据。更大模型也需要足够的更新。

manifest 中训练集 `objects_reliable` 为真的记录数量为 0，类别均为 `unlabeled`，因此当前 STRUCT/TEMP 实际没有可靠物体局部损失分支。这不说明视频内容缺少物理现象，而是说明小物体和局部接触区域缺少专门权重。FM 是全 latent MSE，局部物理错误对总均值可能很小。padding 也包含在 FM 中，不过此数据几何的平均 padding 面积约 0.16%，暂不宜把它当作主要解释。

训练主要用 conditional FM，而 TEMP 和正式采样采用 `CFG_base + 1*delta`，并不是把校正残差乘以 CFG=5。前 800 步只有 TEMP 在这一 CFG 输出上训练，801 步之后每批一个修复样本的 FM 才使用 CFG。conditional FM 的改善幅度与最终 CFG 视频收益因此不必完全一致。这是当前训练目标的设计选择，不可直接当作参数不足的证据。

建议按下面顺序验证，每次只改变一个主要因素，先用相同样本、噪声和计算预算比较；这些是建议实验，本次未执行：

1. 为现有运行补充同条件基座 FM、校正 FM、修正方向、预算利用率，以及各 core 的分目标梯度统计。固定 train/validation 小面板，每个样本覆盖多个 sigma；与随机训练 loss 分开看。
2. 在独立诊断配置上做 16–32 条数据的小集拟合，同时保留固定噪声面板与新噪声验证。现有 quick16 只有 6 次优化器更新，目的是链路验收，不能用它判断拟合容量。先比较 FM-only 和当前多目标训练，辨别目标竞争、启动速度与参数容量。
3. 若校正始终很小，先检查 warmup 后梯度和更新是否仍受限，再单独尝试 writer 学习率等优化调整。若校正逼近预算且方向有利，再单独提高相应预算；不要同时加宽模型并放开所有上限。
4. 若未饱和、训练已充分、固定训练面板仍无法拟合，加入第 6–15 层 self-attention rank-16 LoRA，再视结果扩至第 6–30 层；之后才比较 cross-attention、FFN、后层 writer 或 core 加深。
5. 检查增加参数能否改善留出数据和同 seed 的实际生成。比较原生基座、当前外挂、LoRA-only、外挂+LoRA，并做状态/时间打乱或关闭 writer 的消融，确认收益确实使用了所设计的物理状态。训练 FM 下降而验证或物理表现不改善时，应优先处理监督和泛化，而不是继续扩容。

方案选择应由观测决定：预算饱和且方向正确支持调整幅度；去掉辅助目标后 FM 明显改善支持检查梯度竞争；相同训练条件下增加表达能力改善训练与验证才支持容量瓶颈；原始 loss 波动、启动阶段小残差或单独 STRUCT 下降均不足以下结论。当前最有依据的行动是先建立校正收益的配对度量，扩容时优先尝试中后段自注意力 LoRA。
