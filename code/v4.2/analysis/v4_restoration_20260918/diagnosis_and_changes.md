# V4.2 生成退化的记录分析及此次恢复

本次不把旧视频的少数可辨认帧当成恢复成功。用户描述的剧烈变色、后段失去内容是完整视频失败；低训练 loss、有限的单步 FM 改善、没有 NaN 都不能推导出视频可用。新版结构检查和训练更新检查也不能替代完整视频验收。目前没有可以称为“已恢复 V4 画质”的新版训练结果。

证据范围：旧 V4.2 `checkpoints/v4_joint_20260918T034836Z_16183b/step0400`、同名完整训练 JSONL、用户提供的 `logs/experiment_62252_trial_63417_logs.txt`、原 step0400 EMA 推理输出，以及 V4 `wisa_native_p_A1_4x96g_20260912T151800Z-e189c27c/checkpoint-final` 的配置、训练日志和实际生成记录。可复核汇总见 `../step0400_generation_failure_20260918/record_evidence.json`。旧版源码的完整删除清单/哈希见 `retired_source_manifest.json`，归档为 `retired_v42_source.tar.gz`。

## 参数差异不是单纯少了几层

| 模型 | 活动 CORRECTOR | 单个 CORRECTOR | P0 初始化器 | 可训练参数 |
|---|---:|---:|---:|---:|
| 有效 V4 | 6 | 136,224,515 | 20,610,880 | 837,957,970 |
| 旧 V4.2 | 2 | 25,308,929 | 17,674,336 | 68,292,194 |
| 此次新版 | 3 | 136,224,515 | 20,610,880 | 429,284,425 |

如果只把 V4 六个 CORRECTOR 减为两个，应有 293,059,910 可训练参数，而非 68,292,194。旧 V4.2 的 P 虽标称 1664 维，核心注意力和 MLP 实际先降至 512，heads 也由 26 变为 8，并修改了全时空注意力/读写结构。宽度平方比 `(1664/512)^2=10.5625`，这会显著减少注意力和 MLP 权重，不能用层数差解释。旧单个模块分解约为 core 20.247M + writer 5.062M。

新版本读入 Wan H 为 3072→1664，在 JEPA 原生 1664 维中执行 V4 完整读状态、更新状态和读写检索，然后 1664→3072 写回。这里跨 Wan/JEPA 的维度对应是必要接口。P0 初始化器原 V4 内部宽度仍是 512（输出原生 1664），已明确保留；它不是旧 V4.2 的 CORRECTOR 瓶颈。V4 保存文件还包含约 136.225M 的未训练 B；新版去掉未启用 B，保存参数和可训练参数均为 429,284,425。

## 旧记录指向的是整套训练/推理设计差异

1. **实际改动远多于损失名字。** 旧 V4.2 缩窄内部网络，将全时空注意力改为分解处理/时间插值，同时改了初始化、读写路径、幅度约束、推理 CFG、数据窗口及训练模式。把 FM/STRUCT/PRIOR 系数改成 V4 的数值，并不能把这些差异抵消。
2. **写回明显小且仍在被软限幅。** 351–400 步窗口中旧 V4.2 两处 write/H 平均约 1.27%、2.01%；writer 软界的输出/输入比例约 0.776、0.718，最终速度修正约 0.821。即使没有触及所谓 95% 边界，软限幅仍在减少 20%–30% 的有效写回。V4 同窗口六处约为 15.01%、14.46%、4.71%、4.22%、7.68%、0.25%。实际 P01 T2V 采样中旧 V4.2 约 1.00%、2.07%，V4 前五处约 14.81%、13.40%、5.33%、3.58%、6.68%。这些比例来自不同模型/轨迹，不能当作严格同输入消融；但它们直接否定了“写回强度和 V4 基本一样”。
3. **旧验证收益有限。** 固定健康验证中 base FM=0.34678673，step400 raw=0.33011838（改善约4.81%），EMA=0.33327660（约3.90%）；step600 raw=0.32885576、EMA=0.33096185。step400 EMA STRUCT 从初始约1.3591到1.2783。这只能说明 GT 加噪输入的单步误差略有改善，不能说明多步自回归式去噪/CFG 的分布外轨迹稳定。训练 FM 数值不能在不同样本长度、sigma 和模式混合间直接横比。
4. **WRITE 的旧单位会放大约束。** 旧版目标被投影到写回预算对应的“可达集合”，误差除以很小的 `budget * H_RMS` 后再平方。因而 `WRITE=0.05` 并非普通原始 H-MSE 的 0.05，不能直接迁移。原始 raw WRITE 大小也不能和新版原始 H-MSE 直接横比。
5. **梯度记录显示真实竞争，但不证明其为唯一原因。** step101–400 每25步记录的第一个 microbatch，共12份：旧 writer15 的 FM/辅助平均 cosine 约 -0.511，12/12 为负；writer5 约 -0.215，11/12 为负。末端 writer15 不影响更后面的 STRUCT/P0 PRIOR，该处辅助项只有 WRITE，因而这是 WRITE 与 FM 竞争的直接证据。这些是单个 microbatch 的诊断，不是8次累积后的优化器更新，不等价于“必须做梯度投影”。新版不引入投影或强制夹角约束。
6. **推理 CFG 不是 V4。** 旧版近似为原生负分支 + CFG×原生条件差 + 单份受限 CORRECTOR 残差；V4 则对修正后的正、负分支整体执行 CFG。旧版训练和采样时修正项的角色并不相同。新版恢复 `v_neg_corrected + cfg * (v_pos_corrected-v_neg_corrected)`，正负分支分别初始化 P，随每步重置，使用与训练空文本 dropout 对应的空负提示词。
7. **梯度裁剪不是本记录的主因。** 旧 V4.2 前400次更新只有1次总范数超过1；V4完整500步为0次。V4 351–400 步平均全局范数约0.06883，clip coefficient均为1。因此保留 V4 的 global grad_clip=1，不再把它误称为导致画面崩坏的主要处理。
8. **EMA 也不是补救。** beta=0.995、400次更新时初始权重贡献仍约13.5%，且该验证中 EMA 稍弱于 raw；但 raw 的改善也有限，改用 raw 并不等于已修好生成。

分辨率也不能单独解释本次 V4/V4.2 差异：两者已有输出都使用类似512面积桶，V4至少存在可看的结果。没有用少数高分辨率/短片段截图替代完整121帧验证，也没有开展新的分辨率/CFG/solver消融网格。

## V4 是否有梯度冲突

V4 将 `FM + 0.1*w*q*STRUCT + 0.02*w*PRIOR` 直接相加，一次反传；之后统一全局梯度裁剪和 AdamW。没有 PCGrad/投影，没有辅助梯度占比 cap，没有 WRITE。历史日志有各参数组的**合并梯度**范数，没有各损失独立梯度的两两夹角。`A@*/target_cosine` 是特征与 JEPA target 的相似度，不是梯度夹角。

因此不能用现有 V4 日志声称 FM/STRUCT/PRIOR 从未冲突。V4 有可看视频也不能推出梯度处处同向。可以从图结构确定：PRIOR 直接监督 P0，不直接更新各 CORRECTOR；最后一个 writer 的输出不再影响后续 P，故不会直接收到 STRUCT；更早的 writer 可以通过后续 H→P 收到 STRUCT。新版完整保留这些路径。新增 WRITE 的输入和目标明确停止梯度，使其不额外强迫状态核心绕开 FM/STRUCT 的训练目标；写回读投影、条件模块、检索注意力和输出矩阵仍正常接收 WRITE 梯度。

V4日志复核数字见 `v4_gradient_log_audit.json`。351–400步训练 FM 平均0.27283014，加权 STRUCT 0.13666170，加权 PRIOR 0.00851215，总计0.41800398。它们对应 V4 数据/模式，不能拿来与旧 V4.2 的混合模式批次做严格效果排名。

## 最终配置及两版区别

用户最终指定的共同设置：三个独立1664维 CORRECTOR（5/15/25）；121帧窗口；JEPA32；仅I2V。复用2400条缓存，2279 train/121 validation，使用已有32帧相邻对采样和原始时间戳；16个teacher时间token槽。I2V first latent始终保留，包括空文本dropout时。现有训练集中1651/2279条是完整121帧，其余源片较短，仍按已有连续窗口使用，不补造GT帧。

- `train/train_stability_1x96g.yaml` → `configs/stability_v4_fullwidth3.yaml`：四项损失，PRIOR=0.02。
- `train/train_stability_no_prior_1x96g.yaml` → `configs/stability_v4_fullwidth3_no_prior.yaml`：三项损失，PRIOR=0，不计算该监督；P0初始化器仍通过FM/STRUCT学习。

两版其余模型、数据、种子、学习率、500步日程和batch=8完全一致。不同run名称和各自latest checkpoint指针避免覆盖或混用；RESUME禁止跨PRIOR版本偷偷改变训练定义。新版本恢复原V4优化策略：全组峰值lr=1e-4，warmup100，cosine最低0.1，weight_decay0.01，75%GT初始化/25%无GT，10%空文本dropout，原始权重推理。保存和验证频率改为100步方便检查。

额外 WRITE 在 V4 实际3072维 H 上使用三个位置平均的 MSE：同视频正常FM前向的 `stopgrad(H_clean_after)` 为目标，扰动前向的H/P停止梯度，重新执行原V4 writer得到 `H_bad + R_bad`。不再投影至512，不裁剪目标，不除以小写回预算，也不对模型的写回和输出速度再施加RMS限幅。完整121帧检查测得raw WRITE MSE约0.004206；原0.01系数使其过弱，最终两版均改为1.0，并取消25%的无扰动零损失配对，每个样本执行扰动写回监督。相同输入下单项梯度会因系数改变放大100倍；实际训练轨迹仍须观察，不能把这个比例直接当成训练收益。沿用200步辅助预热及STRUCT的sigma权重，最终视频收益尚未验证。正常FM前向和采样仍保留V4原有门控、sigma幅度系数、直接Wan输出。
