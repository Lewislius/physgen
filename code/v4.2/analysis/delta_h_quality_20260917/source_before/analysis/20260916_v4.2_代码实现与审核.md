## 1. 配置与兼容边界

正式配置 `configs/stability.yaml` 的 recipe 为 `fm_struct_v4_limits_gated_uniform_v1`。仍使用原 Wan2.2-TI2V-5B、T5、FP32 VAE 与 V-JEPA 2.1 资产路径。数据配置逐项与旧 step0100 一致；2279 train / 121 validation 的缓存可复用，未重新编码或改写。`model_version` 保留用于原缓存契约，模型差异由保存的 `state.write_gate`、recipe 和严格 state_dict 匹配区分。

新训练与旧无 gate 的 step0100 不允许混合恢复。`load_training` 先核对 recipe，再核对配置、数据/资产/代码身份及完整训练状态；没有追加宽泛的旧→新源码恢复豁免。`configs/stability_legacy_step0100.yaml` 保留旧配方，历史 quick16 / batch1 明确引用它，不把旧 TEMP 链路误称为新配方验收。它们不代表新的正式训练默认。

## 2. 模型与初始化

- `physgen_v42/model.py`：第5、15层各有独立 core/reader/writer，新增两个 `Linear(512,1)` sigmoid write gate，共 **65,046,274** 参数，比旧版增加1026个。未增加 LoRA 或解冻 Wan。
- writer 输出层为零，gate 的线性权重/bias 为零，sigmoid=.5。初始输出等于基座，但 writer 输出矩阵可以从首步接收 FM 梯度，避免零 gate 和零输出相乘的死路。
- 明确两种增量：core 以 P 查询 H，计算 ΔP 并更新 P′；writer 以 H 查询整个 P′，将512维retrieved特征投影成3072维候选 ΔH，再经过write gate与RMS限制，执行 H′=H+ΔH。没有把1664维P或ΔP直接加到H。gate由retrieved特征预测并接受FM梯度，不是物理正确性监测器。
- I2V P0 仍为首图 JEPA anchor 复制，T2V 为 `mu_first + TextInit(text)` 再复制时间槽；不读取 GT 未来。动态初始化架构没有在本次无对照扩展。
- `Adapter.auxiliary(..., detach_initial=False)` 只用于新配方：在 FM 反向后重新构造部署条件 P0，STRUCT 可训练 TextInit 和两个 core；H 观察仍 detach，阻止辅助梯度通过 H15 回到 writer5。旧接口默认 `detach_initial=True`，旧 checkpoint 的数值路径不因此改写。

## 3. 两项损失和明确上限

`train_micro_gated` 始终使用普通 conditional FM，不计算 TEMP、VAE反向或 repair。

`coefficient = loss.struct * min(step/200,1) * clip((1-sigma)/0.2,0,1)`。

`loss.struct` 默认 .1，可显式设0进行同架构 FM-only 对照，最大 .1。STRUCT 原始定义保持有效区域 teacher MSE / s_z²。每条 FM 和加权 STRUCT 都除 accumulation=8。这里恢复的是 v4 的权重日程，不是声称 teacher 归一化、损失量纲与 v4 完全相同。

不 clamp 原始 loss，不再使用旧平方噪声衰减或全模型20%比例缩放。保留全局 grad_clip=1，以及两个 writer、状态和最终 velocity 的原实际残差限幅。限制的是相应参考 RMS，不是输出视频的正确率。

## 4. 梯度方向处理

`GradientMixer` 独立缓存已加权 STRUCT 梯度。默认 `auxiliary_gradient_policy=project_conflicts`：累计8条后按 core5/core15/TextInit 分别移除 STRUCT 中与 FM 相反的分量；`none` 为显式对照。没有新增损失、额外梯度占比目标或按样本挑选特殊支路。

FM梯度为零时保留结构学习；没有参与本批模式的参数保持 grad=None，不让 AdamW 对未使用 TextInit 执行动量/衰减。每组前后范数、余弦、内积与移除范数写日志。原全模型比例缩放仅留作旧代码路径兼容。

投影只约束当前累积梯度的欧氏内积，不能保证有限 AdamW 更新或生成视频变好。控制台 `TOTAL(nominal)` 是投影前加权标量和，不能解释成投影后梯度对应的精确损失。

## 5. 数据、日程、验证

`UniformExposurePlan` 使用一个持久队列，每次8条，逐条独立以1/2概率选择 I2V/T2V；不要求批内固定4/4。sigma均为 U(.02,.999)。保存队列cursor和每源模式曝光，恢复后不重复/跳过队列；8选1 TEMP、6/2和801步切换均不在正式默认。

原1200步、每100步保存、全部组LR前50步预热后余弦、EMA=.995、各组peak LR与AdamW参数保持原值。增加step0固定验证基线；每100步对同一留出面板评估raw和EMA，暂时装载EMA后在finally恢复raw，优化器和训练RNG不变。

新日志包含：

- `fm_base / fm / fm_delta` 与按I2V/T2V汇总；固定health的sigma、噪声和视频保持一致。
- `correction_benefit`：速度增量能量、与目标残差的内积、方向余弦，以及与FM差值严格一致的gain。
- `structure_components`：静态/动态全局特征误差分解，仅作诊断，不新增时序loss。
- `auxiliary_alignment`：三组梯度的投影前后统计；`loss_accounting` 说明标量统计口径。
- `health_summary`：raw/EMA/base固定FM、差值、改善案例数。它是GT加噪单步验证，不冒充自由生成或物理验收。

## 6. 推理

`inference/infer.py` 从 checkpoint 自带配置构造架构，支持旧无gate与新有gate权重，严格加载。sample是独立进程，现在显式插入原 `paths.wan_code` 并记录实际模块文件，防止prepare设置的sys.path丢失。原base模型路径未改变。

`VARIANT=full` 使用 `v_negative + 5*(v_base_positive-v_negative) + bounded_delta`；`VARIANT=base` 绕过全部adapter操作，不使用P0/anchor，不生成虚假的P诊断。report接受base的空P状态。默认solver、50步、shift5、CFG5、seed42与旧checkpoint路径都保留。

新输出后缀 `_r2_full` / `_r2_base` 与metadata中的实现/variant共同隔离旧输出。没有覆盖原视频。启动日志拆为NumPy/PIL、torch、推理模块和各模型加载阶段；未伪称已定位远端十分钟导入阻塞。
