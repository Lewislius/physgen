# 新版 v4.2：梯度冲突投影单变量对照

本实验以当前正式 v4.2（两个 corrector、多层 STRUCT、直接 PRIOR、额外 WRITE、75% GT 初始化）为基线，只改变梯度合并策略。这里的“梯度截断”指删除与 FM 冲突的辅助梯度分量，不是全局梯度范数裁剪；两组均保留 `grad_clip=1`。

## 两个独立入口

| | 正式基线 | 新增对照 |

| 提交 YAML | `train/train_stability_1x96g.yaml` | `train/train_stability_projected_1x96g.yaml` |
| 配置 | `configs/stability_v4_joint.yaml` | `configs/stability_v4_joint_projected.yaml` |

| 全局完成指针 | `checkpoints/latest_final.json` | `checkpoints/latest_final_projected.json` |

模型初始化、两个插入位置、数据、seed、曝光顺序规则、GT开关概率、文本dropout、噪声采样、损失公式/权重/梯度路由、WRITE修复规则、学习率、1200步、8次累积、EMA、验证、保存频率及推理均相同。原正式配置和提交YAML未改写。两组各自新建run，不从另一组checkpoint续训；配置摘要检查会拒绝中途切换策略。

## 具体运算

与基线完全相同的前向中计算：

`L_aux = 0.1*a*w*L_STRUCT + 0.02*a*L_PRIOR + 0.05*a*w*L_WRITE`。

两组都执行完全相同的联合损失 backward。对照组额外用 `autograd.grad` 读取FM梯度（不写入`.grad`），**完成同一步8个micro后才投影一次**，按 `core5/core15/text_init/writer5/writer15` 五个参数组分别处理：

```
g_aux = g_joint - g_FM
if dot(g_FM, g_aux) < 0 and ||g_FM||² > 0:
    g_joint -= dot(g_aux, g_FM) / ||g_FM||² * g_FM
```

数学上等于将辅助梯度的冲突分量删除，再加回FM。使用`joint−FM`作为辅助梯度定义，是为了保留基线联合反传的BF16求和路径；若改成FM/辅助分别backward，投影之前就会出现额外舍入差异。无冲突参数组完全不修改`.grad`。

之后执行与基线相同的全局grad_clip=1、AdamW和EMA。未增加20%等梯度占比上限，也不更改STRUCT/PRIOR/WRITE各自的计算图。FM梯度为零时联合梯度原样保留。额外FM梯度计算和缓存可能增加运行时间/显存，但不改变训练超参数。

投影只保证欧氏梯度空间中辅助分量不反对当前累积FM梯度，不保证AdamW实际更新、固定验证或生成质量更好；本实验正是用来比较其影响。

## 日志与比较

- 两组继续记录相同的raw/weighted四项loss、P5/P15误差、GT开关、text dropout与无GT固定验证。
- 对照组的 `auxiliary_alignment` 每步记录各组投影前夹角、内积、投影后内积、移除范数和冲突标记。
- `projected_auxiliary` 明确为加权STRUCT+PRIOR+WRITE，`projection_scope` 明确为8次累积后按参数组处理。
- `auxiliary_gradient_definition=joint_gradient_minus_FM_gradient`记录上述混合精度分解定义。
- 对照组 `loss_accounting=nominal_before_gradient_projection`；基线为 `exact_joint_objective`。投影后的更新不再等于日志总损失的普通梯度。
- `gradient_diagnostics` 仍是每25步第一个micro的只读诊断，不能与8次累积后的 `auxiliary_alignment` 混为一种统计。
- 比较同一步raw/EMA的无GT固定FM、STRUCT、PRIOR、动态误差，再比较相同条件的完整视频，不能只凭训练loss下降决定胜负。
